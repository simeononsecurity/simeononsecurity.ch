How the Math Works

  • Network address is the input address with every host bit cleared, found by ANDing with the netmask.
  • Broadcast address is the network address with every host bit set, found by ORing with the wildcard mask.
  • Usable hosts excludes the network and broadcast addresses, except on /31 and /32 where that rule does not apply.
  • Total addresses is 2 raised to the power of the host bit count, which is 32 minus the prefix length.
