NOTE: This tool runs entirely in your browser with client-side JavaScript. Input is transformed locally and is never transmitted, logged, or stored.

Supported Forms

  • Hexadecimal. \x3c for one byte, \u003c for a four digit code unit, and \u{1f600} for a full code point.
  • Octal. \074 up to three digits, which is how older C and shell strings are written.
  • Named escapes. \n, \r, \t, \b, \f, \v, \0, \a and \e, plus escaped quotes and backslashes.
  • Why this matters. Obfuscated payloads and log entries routinely hide the interesting characters this way. Decoding first is how you see the real string rather than a representation of it.
