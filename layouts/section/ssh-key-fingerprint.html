NOTE: This tool runs entirely in your browser with client-side JavaScript. Public keys are public by design, but the key you paste is still processed locally and is never transmitted, logged, or stored.

Results

Paste a public key to see its fingerprint.

How to Read This

  • The fingerprint hashes the decoded key, not the text. Reformatting the line, changing the comment, or altering whitespace does not change it.
  • Compare it against ssh-keygen -lf. The value here uses the same unpadded base64 form modern OpenSSH prints, so the two should match character for character.
  • MD5 fingerprints are deliberately absent. The Web Crypto API omits MD5 and OpenSSH has moved away from it, so the legacy colon form is left out rather than implemented badly.
  • A matching fingerprint proves the file is intact, not that the key is trustworthy. An unmodified key can still come from a compromised source.
