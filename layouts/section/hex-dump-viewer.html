Reading a Hex Dump

  • The left column is the offset from the start of the data, in hexadecimal, so you can point at an exact byte.
  • The middle is the bytes themselves, spaced in groups of one so a 16-byte row lines up.
  • The right gutter is the ASCII view. Anything outside the printable range shows as a dot, which is why a stray dot in a text string usually means an unexpected byte.
  • Text input is encoded as UTF-8. A character above the ASCII range becomes two or more bytes, so one accented letter shifts every offset after it. Tick the hex box when you need byte-exact input rather than a text encoding.
  • Look at the first bytes for a magic number. 50 4B 03 04 is a ZIP or Office file, 1F 8B is gzip, 4D 5A is a Windows executable, and 25 50 44 46 is a PDF.
