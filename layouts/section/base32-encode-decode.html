Why Base32 Exists Alongside Base64

  • Case-insensitive and human readable. The alphabet is A to Z and 2 to 7, so it survives being read aloud or typed by hand.
  • The cost is size. Base32 expands data by 60 percent while Base64 expands it by 33 percent. Base32 is chosen for legibility, not efficiency.
  • TOTP secrets use it. Two-factor setup strings are Base32, which makes this the first tool to reach for when a generated code will not validate.
