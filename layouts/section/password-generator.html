Why This Is Safe to Use

  • No network calls. The generator is plain JavaScript on this page.
  • Cryptographic randomness. Characters come from the browser CSPRNG, not Math.random().
  • No modulo bias. A rejection-sampling loop discards out-of-range values so every character is equally likely.
  • Nothing persisted. No cookies, no local storage, and no server-side logging of your output.
