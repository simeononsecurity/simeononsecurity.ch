What This Does and Does Not Prove

  • TOTP is time based. The code is an HMAC over the number of elapsed periods, truncated to the requested number of digits.
  • Your clock matters. If the server and this tool disagree by more than one period, codes will look valid here and fail there.
  • Verifying here only checks arithmetic. A match proves the secret and clock agree with this page, not that the account is secure or that the server accepts it.
  • A leaked secret defeats the second factor. Anyone who reads a TOTP secret can generate every future code, which is why it should never be typed into an untrusted site.
