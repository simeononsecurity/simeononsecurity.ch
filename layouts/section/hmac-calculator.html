Where HMAC Is Used

  • Webhook verification. Providers sign the request body so you can prove it came from them and was not altered in transit.
  • API request signing. A shared secret plus the request content produces a signature only a key holder can generate.
  • Comparison discipline. Compare signatures with a constant-time function. A normal string comparison leaks how many bytes matched.
