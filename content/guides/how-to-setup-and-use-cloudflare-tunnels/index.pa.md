**ਕਲਾਉਡਫਲੇਅਰ ਟਨਲ ਸੈਟਅਪ ਕਰਨ ਲਈ ਇੱਕ ਮਾਰਗਦਰਸ਼ਕ**

## ਪਰਿਚਯ
ਕਲਾਉਡਫਲੇਅਰ ਟਨਲ ਤੁਹਾਡੇ ਲੋਕਲ ਨੈੱਟਵਰਕ ਅਤੇ ਕਲਾਉਡਫਲੇਅਰ ਦੇ ਵਿਚਕਾਰ ਸਿੱਧਾ ਕਨੈਕਸ਼ਨ ਸਥਾਪਿਤ ਕਰਕੇ ਵੈੱਬਸਾਈਟਾਂ ਨੂੰ ਸੁਰੱਖਿਅਤ ਢੰਗ ਨਾਲ ਹੋਸਟ ਕਰਨ ਦਾ ਤਰੀਕਾ ਦਿੰਦੇ ਹਨ। ਇਹ ਮਾਰਗਦਰਸ਼ਕ ਤੁਹਾਡੇ ਵੈੱਬਸਾਈਟ ਦੀ ਸੁਰੱਖਿਆ ਅਤੇ ਪ੍ਰਦਰਸ਼ਨ ਨੂੰ ਵਧਾਉਣ ਲਈ ਕਲਾਉਡਫਲੇਅਰ ਟਨਲ ਸੈਟਅਪ ਕਰਨ ਦੀ ਪ੍ਰਕਿਰਿਆ ਵਿੱਚ ਤੁਹਾਡੀ ਮਦਦ ਕਰੇਗਾ।

______

## ਕਿਉਂ ਕਲਾਉਡਫਲੇਅਰ ਟਨਲ?
ਕਲਾਉਡਫਲੇਅਰ ਟਨਲ ਕਈ ਫਾਇਦੇ ਦਿੰਦੇ ਹਨ, ਜਿਵੇਂ ਕਿ ਹਮਲਿਆਂ ਦੇ ਰਸਤੇ ਘਟਾਉਣਾ ਅਤੇ ਨੈੱਟਵਰਕ ਸੰਰਚਨਾਵਾਂ ਨੂੰ ਸਧਾਰਨ ਬਣਾਉਣਾ। ਕਲਾਉਡਫਲੇਅਰ ਨੂੰ ਪ੍ਰਾਕਸੀ ਵਜੋਂ ਵਰਤ ਕੇ, ਤੁਸੀਂ ਬਾਹਰੀ ਪੋਰਟਾਂ ਨੂੰ ਬੰਦ ਕਰ ਸਕਦੇ ਹੋ ਅਤੇ ਯਕੀਨੀ ਬਣਾ ਸਕਦੇ ਹੋ ਕਿ ਸਾਰਾ ਟ੍ਰੈਫਿਕ ਕਲਾਉਡਫਲੇਅਰ ਦੇ ਸੁਰੱਖਿਅਤ ਨੈੱਟਵਰਕ ਰਾਹੀਂ ਜਾਂਦਾ ਹੈ। ਇਸ ਨਾਲ ਤੁਹਾਡੇ ਵੈੱਬਸਾਈਟ ਲਈ ਇੱਕ ਵਾਧੂ ਸੁਰੱਖਿਆ ਪਰਤ ਮਿਲਦੀ ਹੈ।

______

## ਲੋੜੀਂਦੀਆਂ ਚੀਜ਼ਾਂ
ਕਲਾਉਡਫਲੇਅਰ ਟਨਲ ਸੈਟਅਪ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ, ਇਹ ਯਕੀਨੀ ਬਣਾਓ ਕਿ ਤੁਹਾਡੇ ਕੋਲ ਹੇਠ ਲਿਖੀਆਂ ਚੀਜ਼ਾਂ ਹਨ:

1. ਇੱਕ ਸਰਗਰਮ ਕਲਾਉਡਫਲੇਅਰ ਖਾਤਾ।
2. ਉਬੁੰਟੂ ਚੱਲਾ ਰਹਾ ਸਰਵਰ।

______

## ਕਦਮ 1: ਇੰਸਟਾਲੇਸ਼ਨ
ਸ਼ੁਰੂ ਕਰਨ ਲਈ, ਤੁਹਾਨੂੰ ਆਪਣੇ ਉਬੁੰਟੂ ਸਰਵਰ 'ਤੇ ਕਲਾਉਡਫਲੇਅਰ ਟਨਲ ਪੈਕੇਜ ਇੰਸਟਾਲ ਕਰਨਾ ਪਵੇਗਾ। ਇਹ ਕਦਮ ਫਾਲੋ ਕਰੋ:

1. ਆਪਣੇ ਉਬੁੰਟੂ ਸਰਵਰ 'ਤੇ ਟਰਮੀਨਲ ਖੋਲ੍ਹੋ।
2. ਹੇਠਾਂ ਦਿੱਤਾ ਕਮਾਂਡ ਚਲਾ ਕੇ ਕਲਾਉਡਫਲੇਅਰ ਟਨਲ ਪੈਕੇਜ ਦਾ ਨਵਾਂ ਵਰਜਨ ਡਾਊਨਲੋਡ ਕਰੋ:

```shell
wget -q https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
```

## ਕਦਮ 2: ਪ੍ਰਮਾਣਿਕਤਾ
ਅਗਲੇ, ਤੁਹਾਨੂੰ ਕਲਾਉਡਫਲੇਅਰ ਟਨਲ ਸੇਵਾ ਨਾਲ ਆਪਣੇ ਕਲਾਉਡਫਲੇਅਰ ਖਾਤੇ ਦੀ ਪ੍ਰਮਾਣਿਕਤਾ ਕਰਨੀ ਪਵੇਗੀ। ਇਹ ਕਦਮ ਫਾਲੋ ਕਰੋ:

1. ਟਰਮੀਨਲ ਵਿੱਚ ਹੇਠਾਂ ਦਿੱਤਾ ਕਮਾਂਡ ਚਲਾਓ:

```shell
cloudflared tunnel login
```

2. ਉਸ ਸਾਈਟ 'ਤੇ ਕਲਿੱਕ ਕਰੋ ਜਿਸਨੂੰ ਤੁਸੀਂ ਆਪਣੇ ਟਨਲ ਨਾਲ ਵਰਤਣਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਜੋ ਪ੍ਰਮਾਣਿਕਤਾ ਪ੍ਰਕਿਰਿਆ ਪੂਰੀ ਹੋ ਜਾਵੇ।

## ਕਦਮ 3: ਟਨਲ ਬਣਾਉਣਾ

ਹੁਣ ਤੁਹਾਡੇ ਲਈ ਕਲਾਉਡਫਲੇਅਰ ਟਨਲ ਬਣਾਉਣ ਦਾ ਸਮਾਂ ਹੈ। ਇਹ ਕਦਮ ਫਾਲੋ ਕਰੋ:

1. ਟਰਮੀਨਲ ਵਿੱਚ ਹੇਠਾਂ ਦਿੱਤਾ ਕਮਾਂਡ ਚਲਾਓ ਤਾਂ ਜੋ ਟਨਲ ਬਣਾਇਆ ਜਾ ਸਕੇ:

```shell
cloudflared tunnel create name_of_tunnel
```

2. ਆਪਣੇ ਟਨਲ ਲਈ ਇੱਕ ਯਾਦਗਾਰ ਅਤੇ ਵੇਰਵਾ ਦਿੰਦਾ ਨਾਮ ਚੁਣੋ। ਧਿਆਨ ਰੱਖੋ ਕਿ ਟਨਲ ਦਾ ਨਾਮ ਬਾਅਦ ਵਿੱਚ ਬਦਲਿਆ ਨਹੀਂ ਜਾ ਸਕਦਾ।

3. ਟਨਲ ਬਣਾਉਣ ਤੋਂ ਬਾਅਦ, ਤੁਹਾਨੂੰ ਮਹੱਤਵਪੂਰਨ ਜਾਣਕਾਰੀ ਦਿੱਤੀ ਜਾਵੇਗੀ, ਜਿਸ ਵਿੱਚ ਤੁਹਾਡੇ ਟਨਲ ਦਾ UUID ਵੀ ਸ਼ਾਮਲ ਹੈ। ਇਸ UUID ਨੂੰ ਨੋਟ ਕਰ ਲਵੋ ਕਿਉਂਕਿ ਅੱਗੇ ਦੀ ਸੰਰਚਨਾ ਲਈ ਇਹ ਲੋੜੀਂਦਾ ਹੋਵੇਗਾ।

4. ਸਾਰੇ ਸਰਗਰਮ ਟਨਲਾਂ ਦੀ ਸੂਚੀ ਵੇਖਣ ਲਈ, ਇਹ ਕਮਾਂਡ ਵਰਤੋ:

```shell
cloudflared tunnel list
```

ਇਸ ਨਾਲ ਤੁਹਾਡੇ ਟਨਲਾਂ ਦੇ ਨਾਮ ਅਤੇ UUID ਦਿਖਾਏ ਜਾਣਗੇ।

### ਕਦਮ 4: ਟਨਲ ਸੰਰਚਨਾ

ਆਪਣੇ ਟਨਲ ਨੂੰ ਸੰਰਚਿਤ ਕਰਨ ਅਤੇ ਟ੍ਰੈਫਿਕ ਰੂਟਿੰਗ ਸ਼ੁਰੂ ਕਰਨ ਲਈ, ਇਹ ਕਦਮ ਫਾਲੋ ਕਰੋ:

1. ਆਪਣੇ ਸਰਵਰ 'ਤੇ ਕਲਾਉਡਫਲੇਅਰ ਟਨਲ ਡਾਇਰੈਕਟਰੀ ਵਿੱਚ ਜਾਓ। ਡਿਫਾਲਟ ਸਥਾਨ `/etc/cloudflared` ਹੈ।

2. ਇਸ ਡਾਇਰੈਕਟਰੀ ਵਿੱਚ, ਆਪਣੇ ਪਸੰਦ ਦੇ ਟੈਕਸਟ ਐਡੀਟਰ ਨਾਲ `config.yml` ਨਾਮ ਦਾ ਨਵਾਂ ਫਾਇਲ ਬਣਾਓ।

3. config.yml ਫਾਇਲ ਨੂੰ ਹੇਠ ਲਿਖੇ ਸਮੱਗਰੀ ਨਾਲ ਭਰੋ:

```yaml
tunnel: <your_tunnels_uuid>
credentials-file: /path/to/credentials/<UUID>.json
```

ਯਕੀਨੀ ਬਣਾਓ ਕਿ `<your_tunnels_uuid>` ਨੂੰ ਆਪਣੇ ਟਨਲ ਦੇ UUID ਨਾਲ ਬਦਲਿਆ ਗਿਆ ਹੈ, ਅਤੇ ਜੇ ਲੋੜ ਹੋਵੇ ਤਾਂ ਪ੍ਰਮਾਣ ਪੱਤਰ ਫਾਇਲ ਦਾ ਰਸਤਾ ਅਪਡੇਟ ਕਰੋ।

## ਕਦਮ 5: ਟ੍ਰੈਫਿਕ ਰੂਟਿੰਗ

ਆਪਣੇ ਟਨਲ ਰਾਹੀਂ ਸਰਵਿਸਾਂ ਨੂੰ ਸੇਵਾ ਦੇਣ ਲਈ, ਇਹ ਕਦਮ ਫਾਲੋ ਕਰੋ:

1. ਫਿਰ ਤੋਂ `Open the `config.yml` ਫਾਇਲ ਖੋਲ੍ਹੋ।

2. ਫਾਇਲ ਵਿੱਚ ingress ਪੈਰਾਮੀਟਰ ਸ਼ਾਮਲ ਕਰੋ ਤਾਂ ਜੋ ਤੁਸੀਂ ਕਲਾਉਡਫਲੇਅਰ ਰਾਹੀਂ ਰੂਟ ਕਰਨ ਵਾਲੀਆਂ ਸਰਵਿਸਾਂ ਨੂੰ ਪਰਿਭਾਸ਼ਿਤ ਕਰ ਸਕੋ। ਉਦਾਹਰਨ ਵਜੋਂ:

```yaml
tunnel: <your_tunnels_uuid>
credentials-file: /path/to/credentials/<UUID>.json

ingress:
  - hostname: example.com
    service: http://10.10.10.123:1234
  - hostname: subdomain.example.com
    service: http://10.10.10.123:8888
  - service: http_status:404

```

`<your_tunnels_uuid>` ਨੂੰ ਆਪਣੇ ਟਨਲ ਦੇ UUID ਨਾਲ ਬਦਲੋ, ਅਤੇ ਆਪਣੇ ਸੰਰਚਨਾ ਅਨੁਸਾਰ ਹੋਸਟਨੇਮ ਅਤੇ ਸਰਵਿਸ ਵੇਰਵੇ ਅਪਡੇਟ ਕਰੋ।

3. config.yml ਫਾਇਲ ਸੇਵ ਕਰੋ।


## ਕਦਮ 6: DNS ਰਿਕਾਰਡ ਬਣਾਉਣਾ

ਆਪਣੇ ਟਨਲ ਦੇ ਹੋਸਟਨੇਮ ਅਤੇ ਸਰਵਿਸਾਂ ਲਈ DNS ਰਿਕਾਰਡ ਬਣਾਉਣ ਲਈ, ਇਹ ਕਦਮ ਫਾਲੋ ਕਰੋ:

1. ਟਰਮੀਨਲ ਖੋਲ੍ਹੋ।

2. DNS ਰਿਕਾਰਡ ਬਣਾਉਣ ਲਈ ਹੇਠਾਂ ਦਿੱਤਾ ਕਮਾਂਡ ਵਰਤੋ:

```shell
cloudflared tunnel route dns <UUID or NAME of tunnel> <hostname>
```
`<UUID or NAME of tunnel>` ਨੂੰ ਆਪਣੇ ਟਨਲ ਦੇ UUID ਜਾਂ ਨਾਮ ਨਾਲ ਬਦਲੋ, ਅਤੇ `<hostname>` ਨੂੰ ਆਪਣੀ ਸਰਵਿਸ ਲਈ ਚਾਹੀਦਾ ਹੋਸਟਨੇਮ ਦਿਓ।

3. ਉਦਾਹਰਨ ਵਜੋਂ, example.com ਲਈ DNS ਰਿਕਾਰਡ ਬਣਾਉਣ ਲਈ, ਇਹ ਕਮਾਂਡ ਚਲਾਓ:

```shell
cloudflared tunnel route dns <UUID or NAME of tunnel> example.com
```

ਕਿਰਪਾ ਕਰਕੇ ਧਿਆਨ ਦਿਓ ਕਿ ਇਹ ਬਦਲਾਅ ਤੁਹਾਡੇ ਕਲਾਉਡਫਲੇਅਰ ਡੈਸ਼ਬੋਰਡ ਦੇ DNS ਸੈਕਸ਼ਨ ਵਿੱਚ ਦਰਸਾਏ ਜਾਣਗੇ।

## ਕਦਮ 7: ਟਨਲ ਸ਼ੁਰੂ ਕਰਨਾ

ਆਪਣੇ ਕਲਾਉਡਫਲੇਅਰ ਟਨਲ ਦੀ ਜਾਂਚ ਅਤੇ ਸ਼ੁਰੂਆਤ ਕਰਨ ਲਈ, ਇਹ ਕਦਮ ਫਾਲੋ ਕਰੋ:

1. ਟਰਮੀਨਲ ਖੋਲ੍ਹੋ।

2. ਟਨਲ ਸ਼ੁਰੂ ਕਰਨ ਲਈ ਹੇਠਾਂ ਦਿੱਤਾ ਕਮਾਂਡ ਚਲਾਓ:

```shell
cloudflared tunnel run <UUID or NAME of tunnel>
```

`<UUID or NAME of tunnel>` ਨੂੰ ਆਪਣੇ ਟਨਲ ਦੇ UUID ਜਾਂ ਨਾਮ ਨਾਲ ਬਦਲੋ।

3. ਹੁਣ Cloudflared ਤੁਹਾਡਾ ਟਨਲ ਸੈਟਅਪ ਕਰੇਗਾ ਅਤੇ ਇਸ ਦੀ ਸਥਿਤੀ ਬਾਰੇ ਜਾਣਕਾਰੀ ਦਿਖਾਏਗਾ। ਜਦੋਂ ਟਨਲ ਸਫਲਤਾਪੂਰਵਕ ਚੱਲਣ ਲੱਗੇ, ਤਾਂ ਤੁਸੀਂ ਅਗਲੇ ਕਦਮ ਵੱਲ ਵਧ ਸਕਦੇ ਹੋ।

4. ਜਦੋਂ ਤੁਸੀਂ ਟਰਮੀਨਲ ਬੰਦ ਕਰੋ ਤਾਂ ਟਨਲ ਬੰਦ ਨਾ ਹੋਵੇ, ਇਸ ਲਈ ਤੁਹਾਨੂੰ Cloudflared ਨੂੰ systemd ਸੇਵਾ ਵਜੋਂ ਚਲਾਉਣਾ ਪਵੇਗਾ। ਹੇਠਾਂ ਦਿੱਤਾ ਕਮਾਂਡ ਵਰਤੋ:

```shell
cloudflared --config /path/to/config.yml service install
```

`/path/to/config.yml` ਨੂੰ ਆਪਣੇ `config.yml` ਫਾਇਲ ਦੇ ਰਸਤੇ ਨਾਲ ਬਦਲੋ।

## ਨਤੀਜਾ

ਇਸ ਮਾਰਗਦਰਸ਼ਕ ਵਿੱਚ, ਅਸੀਂ ਉਬੁੰਟੂ 'ਤੇ ਕਲਾਉਡਫਲੇਅਰ ਟਨਲ ਸੈਟਅਪ ਕਰਨ ਦੇ ਕਦਮ ਕਵਰ ਕੀਤੇ ਹਨ। ਇਹ ਹਦਾਇਤਾਂ ਫਾਲੋ ਕਰਕੇ, ਤੁਸੀਂ ਕਲਾਉਡਫਲੇਅਰ ਦੇ ਨੈੱਟਵਰਕ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਆਪਣੀ ਵੈੱਬਸਾਈਟ ਦੀ ਸੁਰੱਖਿਆ ਅਤੇ ਪ੍ਰਦਰਸ਼ਨ ਨੂੰ ਵਧਾ ਸਕਦੇ ਹੋ। ਯਾਦ ਰੱਖੋ ਕਿ ਆਪਣੇ ਟਨਲਾਂ ਦੀ ਨਿਯਮਤ ਨਿਗਰਾਨੀ ਕਰੋ ਅਤੇ ਜਰੂਰਤ ਮੁਤਾਬਕ ਸੰਰਚਨਾ ਵਿੱਚ ਤਬਦੀਲੀ ਕਰੋ।

ਜੇ ਤੁਹਾਨੂੰ ਕਿਸੇ ਸਮੱਸਿਆ ਦਾ ਸਾਹਮਣਾ ਕਰਨਾ ਪਵੇ ਜਾਂ ਵਧੇਰੇ ਮਦਦ ਦੀ ਲੋੜ ਹੋਵੇ, ਤਾਂ [ਅਧਿਕਾਰਿਕ ਕਲਾਉਡਫਲੇਅਰ ਟਨਲ ਦਸਤਾਵੇਜ਼](https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/tunnel-guide/) ਨੂੰ ਵੇਖੋ।
