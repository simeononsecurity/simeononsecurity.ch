**ক্লাউডফ্লেয়ার টানেল সেট আপ করার একটি গাইড**

## পরিচিতি
ক্লাউডফ্লেয়ার টানেল আপনার লোকাল নেটওয়ার্ক এবং ক্লাউডফ্লেয়ারের মধ্যে সরাসরি সংযোগ স্থাপন করে ওয়েবসাইট হোস্ট করার একটি নিরাপদ উপায় প্রদান করে। এই গাইডটি ক্লাউডফ্লেয়ার টানেল সেট আপ করার প্রক্রিয়া আপনাকে দেখাবে যাতে আপনার ওয়েবসাইটের নিরাপত্তা এবং কর্মক্ষমতা উন্নত হয়।

______

## কেন ক্লাউডফ্লেয়ার টানেল?
ক্লাউডফ্লেয়ার টানেল বিভিন্ন সুবিধা প্রদান করে, যেমন আক্রমণের পথ কমানো এবং নেটওয়ার্ক কনফিগারেশন সহজ করা। ক্লাউডফ্লেয়ারকে প্রক্সি হিসেবে ব্যবহার করে, আপনি বাহ্যিক পোর্ট বন্ধ করতে পারেন এবং নিশ্চিত করতে পারেন যে সমস্ত ট্রাফিক ক্লাউডফ্লেয়ারের নিরাপদ নেটওয়ার্কের মাধ্যমে যায়। এটি আপনার ওয়েবসাইটের জন্য অতিরিক্ত সুরক্ষা স্তর প্রদান করে।

______

## পূর্বশর্ত
ক্লাউডফ্লেয়ার টানেল সেট আপ করার আগে, নিশ্চিত করুন আপনার কাছে নিম্নলিখিতগুলি আছে:

1. একটি সক্রিয় ক্লাউডফ্লেয়ার অ্যাকাউন্ট।
2. উবুন্টু চালানো একটি সার্ভার।

______

## ধাপ ১: ইনস্টলেশন
শুরু করতে, আপনাকে আপনার উবুন্টু সার্ভারে ক্লাউডফ্লেয়ার টানেল প্যাকেজ ইনস্টল করতে হবে। নিম্নলিখিত ধাপগুলি অনুসরণ করুন:

1. আপনার উবুন্টু সার্ভারে টার্মিনাল খুলুন।
2. নিম্নলিখিত কমান্ড চালিয়ে ক্লাউডফ্লেয়ার টানেল প্যাকেজের সর্বশেষ সংস্করণ ডাউনলোড করুন:

```shell
wget -q https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
```

## ধাপ ২: প্রমাণীকরণ
পরবর্তী, আপনাকে ক্লাউডফ্লেয়ার টানেল সার্ভিসের সাথে আপনার ক্লাউডফ্লেয়ার অ্যাকাউন্ট প্রমাণীকরণ করতে হবে। নিম্নলিখিত ধাপগুলি অনুসরণ করুন:

1. টার্মিনালে নিম্নলিখিত কমান্ড চালান:

```shell
cloudflared tunnel login
```

2. আপনার টানেলের জন্য ব্যবহার করতে চান এমন সাইটে ক্লিক করে প্রমাণীকরণ প্রক্রিয়া সম্পন্ন করুন।

## ধাপ ৩: একটি টানেল তৈরি করা

এখন আপনার ক্লাউডফ্লেয়ার টানেল তৈরি করার সময়। নিম্নলিখিত ধাপগুলি অনুসরণ করুন:

1. টার্মিনালে নিম্নলিখিত কমান্ড চালিয়ে একটি টানেল তৈরি করুন:

```shell
cloudflared tunnel create name_of_tunnel
```

2. আপনার টানেলের জন্য একটি স্মরণীয় এবং বর্ণনামূলক নাম নির্বাচন করুন। মনে রাখবেন, টানেলের নাম পরে পরিবর্তন করা যাবে না।

3. টানেল তৈরি করার পর, আপনাকে গুরুত্বপূর্ণ তথ্য প্রদান করা হবে, যার মধ্যে আপনার টানেলের UUID অন্তর্ভুক্ত। এই UUID নোট করে রাখুন কারণ এটি পরবর্তী কনফিগারেশনের জন্য প্রয়োজন হবে।

4. সক্রিয় সমস্ত টানেলের তালিকা দেখতে, নিম্নলিখিত কমান্ড ব্যবহার করুন:

```shell
cloudflared tunnel list
```

এটি আপনার টানেলের নাম এবং UUID প্রদর্শন করবে।

### ধাপ ৪: টানেল কনফিগারেশন

আপনার টানেল কনফিগার করে ট্রাফিক রাউটিং শুরু করতে, নিম্নলিখিত ধাপগুলি অনুসরণ করুন:

1. আপনার সার্ভারে ক্লাউডফ্লেয়ার টানেল ডিরেক্টরিতে যান। ডিফল্ট অবস্থান হল `/etc/cloudflared`।

2. এই ডিরেক্টরির মধ্যে, আপনার পছন্দের টেক্সট এডিটর ব্যবহার করে `config.yml` নামে একটি নতুন ফাইল তৈরি করুন।

3. config.yml ফাইলটি নিম্নলিখিত বিষয়বস্তু দিয়ে পূরণ করুন:

```yaml
tunnel: <your_tunnels_uuid>
credentials-file: /path/to/credentials/<UUID>.json
```

`<your_tunnels_uuid>` আপনার টানেলের UUID দিয়ে প্রতিস্থাপন করতে ভুলবেন না, এবং প্রয়োজনে ক্রেডেনশিয়াল ফাইলের পথ আপডেট করুন।

## ধাপ ৫: ট্রাফিক রাউটিং

আপনার টানেলের মাধ্যমে পরিবেশন করতে চান এমন অভ্যন্তরীণ সার্ভিস নির্দিষ্ট করতে, নিম্নলিখিত ধাপগুলি অনুসরণ করুন:

1. আবার `Open the `config.yml` ফাইল খুলুন।

2. ফাইলে ingress প্যারামিটার যোগ করুন যাতে আপনি ক্লাউডফ্লেয়ারের মাধ্যমে রাউট করতে চান এমন সার্ভিসগুলি সংজ্ঞায়িত করতে পারেন। উদাহরণস্বরূপ:

```yaml
tunnel: <your_tunnels_uuid>
credentials-file: /path/to/credentials/<UUID>.json

ingress:
  - hostname: example.com
    service: http://10.10.10.123:1234
  - hostname: subdomain.example.com
    service: http://10.10.10.123:8888
  - service: http_status:404

```

`<your_tunnels_uuid>` আপনার টানেলের UUID দিয়ে প্রতিস্থাপন করুন, এবং আপনার কনফিগারেশন অনুযায়ী হোস্টনেম এবং সার্ভিস বিবরণ আপডেট করুন।

3. config.yml ফাইল সংরক্ষণ করুন।


## ধাপ ৬: DNS রেকর্ড তৈরি করা

আপনার টানেলের হোস্টনেম এবং সার্ভিসের জন্য DNS রেকর্ড তৈরি করতে, নিম্নলিখিত ধাপগুলি অনুসরণ করুন:

1. টার্মিনাল খুলুন।

2. DNS রেকর্ড তৈরি করতে নিম্নলিখিত কমান্ড ব্যবহার করুন:

```shell
cloudflared tunnel route dns <UUID or NAME of tunnel> <hostname>
```
`<UUID or NAME of tunnel>` আপনার টানেলের UUID বা নাম দিয়ে এবং `<hostname>` আপনার সার্ভিসের জন্য পছন্দসই হোস্টনেম দিয়ে প্রতিস্থাপন করুন।

3. উদাহরণস্বরূপ, example.com এর জন্য DNS রেকর্ড তৈরি করতে, কমান্ড চালান:

```shell
cloudflared tunnel route dns <UUID or NAME of tunnel> example.com
```

দয়া করে মনে রাখবেন, পরিবর্তনগুলি আপনার ক্লাউডফ্লেয়ার ড্যাশবোর্ডের DNS সেকশনে প্রতিফলিত হবে।

## ধাপ ৭: টানেল শুরু করা

আপনার ক্লাউডফ্লেয়ার টানেল পরীক্ষা এবং শুরু করতে, নিম্নলিখিত ধাপগুলি অনুসরণ করুন:

1. টার্মিনাল খুলুন।

2. টানেল শুরু করতে নিম্নলিখিত কমান্ড চালান:

```shell
cloudflared tunnel run <UUID or NAME of tunnel>
```

`<UUID or NAME of tunnel>` আপনার টানেলের UUID বা নাম দিয়ে প্রতিস্থাপন করুন।

3. ক্লাউডফ্লেয়ারড এখন আপনার টানেল সেট আপ করবে এবং এর স্থিতি সম্পর্কে তথ্য প্রদর্শন করবে। টানেল সফলভাবে চালু হলে, আপনি পরবর্তী ধাপে যেতে পারেন।

4. টার্মিনাল থেকে বের হওয়ার সময় টানেল বন্ধ হওয়া থেকে রোধ করতে, আপনাকে ক্লাউডফ্লেয়ারডকে systemd সার্ভিস হিসেবে চালাতে হবে। নিম্নলিখিত কমান্ড ব্যবহার করুন:

```shell
cloudflared --config /path/to/config.yml service install
```

`/path/to/config.yml` আপনার `config.yml` ফাইলের পথ দিয়ে প্রতিস্থাপন করুন।

## উপসংহার

এই গাইডে, আমরা উবুন্টুতে ক্লাউডফ্লেয়ার টানেল সেট আপ করার ধাপগুলি আলোচনা করেছি। এই নির্দেশাবলী অনুসরণ করে, আপনি ক্লাউডফ্লেয়ারের নেটওয়ার্ক ব্যবহার করে আপনার ওয়েবসাইটের নিরাপত্তা এবং কর্মক্ষমতা উন্নত করতে পারবেন। নিয়মিত আপনার টানেলগুলি পর্যবেক্ষণ করতে এবং প্রয়োজনে কনফিগারেশন সামঞ্জস্য করতে ভুলবেন না।

যদি আপনি কোনো সমস্যা সম্মুখীন হন বা আরও সহায়তা প্রয়োজন হয়, তাহলে [অফিসিয়াল ক্লাউডফ্লেয়ার টানেল ডকুমেন্টেশন](https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/tunnel-guide/) দেখুন।
