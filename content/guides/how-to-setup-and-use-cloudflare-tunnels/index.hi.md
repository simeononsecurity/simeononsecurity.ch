**Cloudflare टनल सेटअप करने के लिए एक मार्गदर्शिका**

## परिचय
Cloudflare टनल आपके स्थानीय नेटवर्क और Cloudflare के बीच एक सीधा कनेक्शन स्थापित करके वेबसाइट होस्टिंग का एक सुरक्षित तरीका प्रदान करते हैं। यह मार्गदर्शिका आपको आपकी वेबसाइट की सुरक्षा और प्रदर्शन बढ़ाने के लिए Cloudflare टनल सेटअप करने की प्रक्रिया से परिचित कराएगी।

______

## क्यों Cloudflare टनल?
Cloudflare टनल कई लाभ प्रदान करते हैं, जिनमें हमले के रास्तों को कम करना और नेटवर्क कॉन्फ़िगरेशन को सरल बनाना शामिल है। Cloudflare को प्रॉक्सी के रूप में उपयोग करके, आप बाहरी पोर्ट बंद कर सकते हैं और सुनिश्चित कर सकते हैं कि सभी ट्रैफ़िक Cloudflare के सुरक्षित नेटवर्क के माध्यम से जाए। यह आपकी वेबसाइट के लिए एक अतिरिक्त सुरक्षा परत प्रदान करता है।

______

## आवश्यकताएँ
Cloudflare टनल सेटअप करने से पहले, सुनिश्चित करें कि आपके पास निम्नलिखित हैं:

1. एक सक्रिय Cloudflare खाता।
2. Ubuntu चलाने वाला एक सर्वर।

______

## चरण 1: स्थापना
शुरू करने के लिए, आपको अपने Ubuntu सर्वर पर Cloudflare टनल पैकेज इंस्टॉल करना होगा। इन चरणों का पालन करें:

1. अपने Ubuntu सर्वर पर टर्मिनल खोलें।
2. निम्नलिखित कमांड चलाकर Cloudflare टनल पैकेज का नवीनतम संस्करण डाउनलोड करें:

```shell
wget -q https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
```

## चरण 2: प्रमाणीकरण
अगला, आपको Cloudflare टनल सेवा के साथ अपने Cloudflare खाते को प्रमाणित करना होगा। इन चरणों का पालन करें:

1. टर्मिनल में निम्नलिखित कमांड चलाएं:

```shell
cloudflared tunnel login
```

2. उस साइट पर क्लिक करें जिसे आप अपने टनल के साथ उपयोग करना चाहते हैं ताकि प्रमाणीकरण प्रक्रिया पूरी हो सके।

## चरण 3: टनल बनाना

अब अपने Cloudflare टनल को बनाने का समय है। इन चरणों का पालन करें:

1. टर्मिनल में निम्नलिखित कमांड चलाकर टनल बनाएं:

```shell
cloudflared tunnel create name_of_tunnel
```

2. अपने टनल के लिए एक यादगार और वर्णनात्मक नाम चुनें। ध्यान दें कि टनल का नाम बाद में बदला नहीं जा सकता।

3. टनल बनाने के बाद, आपको महत्वपूर्ण जानकारी दी जाएगी, जिसमें आपके टनल का UUID शामिल है। इस UUID को नोट कर लें क्योंकि आगे की कॉन्फ़िगरेशन के लिए इसकी आवश्यकता होगी।

4. सभी सक्रिय टनलों की सूची देखने के लिए, इस कमांड का उपयोग करें:

```shell
cloudflared tunnel list
```

यह आपके टनलों के नाम और UUID दिखाएगा।

### चरण 4: टनल कॉन्फ़िगर करना

अपने टनल को कॉन्फ़िगर करने और ट्रैफ़िक रूटिंग शुरू करने के लिए, इन चरणों का पालन करें:

1. अपने सर्वर पर Cloudflare टनल निर्देशिका पर जाएं। डिफ़ॉल्ट स्थान है `/etc/cloudflared`।

2. इस निर्देशिका के भीतर, अपनी पसंद के टेक्स्ट एडिटर का उपयोग करके `config.yml` नाम की एक नई फ़ाइल बनाएं।

3. config.yml फ़ाइल को निम्नलिखित सामग्री से भरें:

```yaml
tunnel: <your_tunnels_uuid>
credentials-file: /path/to/credentials/<UUID>.json
```

`<your_tunnels_uuid>` को अपने टनल के UUID से बदलना सुनिश्चित करें, और यदि आवश्यक हो तो क्रेडेंशियल फ़ाइल के पथ को अपडेट करें।

## चरण 5: ट्रैफ़िक रूटिंग

अपने टनल के माध्यम से सेवा देने वाली आंतरिक सेवाओं को निर्दिष्ट करने के लिए, इन चरणों का पालन करें:

1. फिर से `Open the `config.yml` फ़ाइल खोलें।

2. फ़ाइल में ingress पैरामीटर जोड़ें ताकि आप Cloudflare के माध्यम से रूट करने वाली सेवाओं को परिभाषित कर सकें। उदाहरण के लिए:

```yaml
tunnel: <your_tunnels_uuid>
credentials-file: /path/to/credentials/<UUID>.json

ingress:
  - hostname: example.com
    service: http://10.10.10.123:1234
  - hostname: subdomain.example.com
    service: http://10.10.10.123:8888
  - service: http_status:404

```

`<your_tunnels_uuid>` को अपने टनल के UUID से बदलें, और होस्टनाम तथा सेवा विवरण को अपनी कॉन्फ़िगरेशन के अनुसार अपडेट करें।

3. config.yml फ़ाइल को सहेजें।


## चरण 6: DNS रिकॉर्ड बनाना

अपने टनल के होस्टनाम और सेवाओं के लिए DNS रिकॉर्ड बनाने के लिए, इन चरणों का पालन करें:

1. टर्मिनल खोलें।

2. DNS रिकॉर्ड बनाने के लिए निम्नलिखित कमांड का उपयोग करें:

```shell
cloudflared tunnel route dns <UUID or NAME of tunnel> <hostname>
```
`<UUID or NAME of tunnel>` को अपने टनल के UUID या नाम से बदलें, और `<hostname>` को अपनी सेवा के लिए इच्छित होस्टनाम से बदलें।

3. उदाहरण के लिए, example.com के लिए DNS रिकॉर्ड बनाने के लिए, यह कमांड चलाएं:

```shell
cloudflared tunnel route dns <UUID or NAME of tunnel> example.com
```

कृपया ध्यान दें कि ये परिवर्तन आपके Cloudflare डैशबोर्ड के DNS सेक्शन में परिलक्षित होंगे।

## चरण 7: टनल शुरू करना

अपने Cloudflare टनल का परीक्षण करने और शुरू करने के लिए, इन चरणों का पालन करें:

1. टर्मिनल खोलें।

2. टनल शुरू करने के लिए निम्नलिखित कमांड चलाएं:

```shell
cloudflared tunnel run <UUID or NAME of tunnel>
```

`<UUID or NAME of tunnel>` को अपने टनल के UUID या नाम से बदलें।

3. Cloudflared अब आपका टनल सेटअप करेगा और इसकी स्थिति के बारे में जानकारी दिखाएगा। एक बार टनल सफलतापूर्वक चलने लगे, आप अगले चरण पर जा सकते हैं।

4. टर्मिनल से बाहर निकलने पर टनल बंद न हो, इसके लिए आपको Cloudflared को systemd सेवा के रूप में चलाना होगा। इसके लिए निम्नलिखित कमांड का उपयोग करें:

```shell
cloudflared --config /path/to/config.yml service install
```

`/path/to/config.yml` को अपनी `config.yml` फ़ाइल के पथ से बदलें।

## निष्कर्ष

इस मार्गदर्शिका में, हमने Ubuntu पर Cloudflare टनल सेटअप करने के चरणों को कवर किया है। इन निर्देशों का पालन करके, आप Cloudflare के नेटवर्क का उपयोग करके अपनी वेबसाइट की सुरक्षा और प्रदर्शन बढ़ा सकते हैं। याद रखें कि नियमित रूप से अपने टनलों की निगरानी करें और आवश्यकतानुसार कॉन्फ़िगरेशन समायोजित करें।

यदि आपको कोई समस्या आती है या अतिरिक्त सहायता की आवश्यकता हो, तो [आधिकारिक Cloudflare टनल दस्तावेज़](https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/tunnel-guide/) देखें।
