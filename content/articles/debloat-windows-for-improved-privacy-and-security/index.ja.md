**Windows**は世界で最も広く使われているオペレーティングシステムです。そのため、サイバー犯罪者に狙われやすくなっています。データとプライバシーを守るには、システムを**強化し、不要なソフトウェアを削除する**対策が必要です。このガイドでは、Windowsを強化して不要なソフトウェアを削除する重要性と、セキュリティやプライバシー全般への効果を説明します。

## Windowsの強化とは
Windowsの強化とは、攻撃対象領域と脆弱性を減らしてWindowsオペレーティングシステムを保護することです。**不要な機能やサービスを無効化または削除**し、セキュリティ更新を適用し、[強力なパスワード](https://simeononsecurity.com/articles/how-to-create-strong-passwords/)と認証方式を使います。

## Windowsの強化が重要な理由
Windowsを強化すると、**攻撃に使われる可能性のある経路を減らし**、サイバー攻撃への対策になります。サイバー犯罪者はオペレーティングシステムやアプリケーションの脆弱性を悪用し、システムに侵入したり機密データを盗んだりします。システムを強化すれば、**攻撃対象領域を縮小**し、データやプライバシーを侵害されにくくできます。

## Windowsの不要なソフトウェアを削除するとは
Windowsから不要なソフトウェアを削除するとは、Windowsオペレーティングシステムから**必要のないソフトウェアやサービスを取り除く**ことです。システムの**パフォーマンスと安定性が向上**することがあります。また、Microsoftやサードパーティ製ソフトウェアが収集・保存するデータ量を減らし、プライバシーを高める効果もあります。

## 不要なソフトウェアの削除が重要な理由
Windowsから不要なソフトウェアを削除すると、**攻撃対象領域を縮小し、プライバシーを高める**ことができます。不要なソフトウェアやサービスの多くは、利用習慣や個人情報を収集します。こうした情報は販売されたり、ターゲット広告に使われたりする可能性があります。不要な機能を取り除けば、**収集・保存されるデータ量を減らし**、プライバシーとセキュリティを高められます。

## Windowsを強化して不要なソフトウェアを削除する方法
Windowsを強化し、不要なソフトウェアを削除するには、次の手順を実行します。

1. **更新プログラムをインストールする**: セキュリティ更新が提供されたら速やかに適用します。脆弱性を修正し、サイバー犯罪者による悪用を防ぐのに役立ちます。

2. **不要なサービスを無効にする**: バックグラウンドで動くサービスの中には、**攻撃対象領域を縮小し、パフォーマンスを高めるために無効化できるもの**があります。例として、Print Spooler、Remote Registry、Remote Procedure Call (RPC) サービスがあります。

3. **不要なソフトウェアを削除する**: **使わなくなったソフトウェアや必要のないソフトウェアをアンインストール**します。パフォーマンスの低下やセキュリティ上の脆弱性につながることがあります。

4. **強力なパスワードを使う**: すべてのアカウントで**強力かつ固有のパスワード**を使い、可能な場合は**二要素認証**を有効にします。

5. **ウイルス対策とマルウェア対策ソフトウェアを使う**: サイバー攻撃から守るため、**ウイルス対策とマルウェア対策ソフトウェア**をインストールして定期的に更新します。

## より安全な削除の順序

不要なソフトウェアの削除は、インストール済みアプリ、スケジュールされたタスク、サービス、ポリシー、データ収集設定を変更します。単なる片付けではなく、設定変更として扱ってください。

1. Windowsのエディションとビルド、インストール済みアプリ、スタートアップ項目、サービス、スケジュールされたタスク、現在のプライバシー設定を記録します。
2. テスト済みのバックアップを作成し、ローカル管理者アカウントで復旧できることを確認します。
3. 使っていないアプリは、設定またはベンダーがサポートするアンインストーラーから削除します。
4. サービスを変更する前に、目的、依存関係、スタートアップの種類、アカウント、実際の使用状況を確認します。
5. Defenderの攻撃対象領域削減機能は、ブロックを有効にする前に監査モードで試します。イベントを確認し、テスト後に必要最小限の許可ルールを追加します。
6. Windowsのオプション機能やスケジュールされたタスクは、所有者と目的を確認します。名前が見慣れないという理由だけで削除しないでください。
7. 再起動後、サインイン、ネットワーク、印刷、更新、バックアップ、VPN、アクセシビリティツール、業務アプリをテストします。
8. 変更記録を残し、テストに失敗した場合は一度に一つずつ元に戻します。

Microsoftは、Controlled Folder Accessを含む攻撃対象領域削減機能の監査モードを説明しています。監査モードは想定されるブロックを記録しますが、実際には適用しません。[Microsoftの攻撃対象領域削減の概要](https://learn.microsoft.com/en-us/defender-endpoint/attack-surface-reduction-overview?view=o365-worldwide)を参照してください。

## サービスの確認と変更の復元

元の例には注意点があります。**Remote Procedure Call (RPC) は多くのWindowsコンポーネントを支えているため、一般的なプライバシー対策として無効にしないでください**。Print Spoolerが必要かどうかは、コンピューターの役割によります。印刷サーバーには必要です。印刷を使わないコンピューターでも、変更前に依存関係とアプリケーションをテストしてください。Remote Registryも一部の管理ツールで使われます。

サービスを変更する前に、現在の状態を記録します。

```powershell
$name = 'Spooler'
Get-CimInstance Win32_Service -Filter "Name='$name'" |
    Select-Object Name, State, StartMode, StartName, PathName |
    Export-Csv "C:\Temp\$name-before.csv" -NoTypeInformation
Get-Service -Name $name -RequiredServices
Get-Service -Name $name -DependentServices
```

Windowsやアプリケーションが必要に応じてサービスを起動する場合は、**Disabled**より先に**Manual**を選びます。変更のたびにテストしてください。元に戻す場合は記録したスタートアップの種類を設定し、イベントビューアーを確認します。

```powershell
Set-Service -Name $name -StartupType Manual
Start-Service -Name $name
Get-Service -Name $name
```

レビューしていない不要ソフト削除スクリプトを本番システムで実行しないでください。変更チケットには、スクリプトのバージョン、エクスポートした設定、変更前のサービス値、回復キーの記録を添付します。

## プライバシー保護の限界

アプリを削除しても、Windowsや別のインストール済みアプリがテレメトリの送信を停止した証拠にはなりません。プライバシー設定、アカウント構成、診断ポリシー、アプリのアクセス許可、ネットワーク制御、ベンダーの規約はデータの流れに影響します。プライバシーが改善したという主張は、製品ドキュメントやローカルネットワーク、イベントの証拠で確認してください。

Windows 10の標準サポートも2025年10月14日に終了しました。不要なソフトウェアを削除したWindows 10でも、サポート対象の更新経路か、承認済みのライフサイクル例外が必要です。[Windows 10のサポート終了に関するMicrosoftの告知](https://learn.microsoft.com/en-us/lifecycle/announcements/windows-10-end-of-support)を参照してください。

Windowsの強化と不要なソフトウェアの削除は、セキュリティとプライバシーを高める重要な対策です。攻撃対象領域と収集・保存されるデータ量を減らせば、機密情報を守り、サイバー攻撃のリスクを抑えられます。**今日からこれらの対策を実行し、Windowsシステムを安全に保ちましょう**。
