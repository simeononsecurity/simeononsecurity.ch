## Introducció:

En l’entorn empresarial actual, que canvia de pressa, **les organitzacions busquen maneres de millorar la infraestructura de TI i seguir el ritme dels avenços tecnològics més recents**. Per això, moltes s’han de plantejar si **actualitzen el servidor actual o passen a una solució al núvol**. Aquest article explica per què les organitzacions poden valorar l’actualització del servidor a **Server 2019** o el pas a **Azure**.

### Criteris per decidir

| Opció | Més adequada per a | Limitació principal |
| --- | --- | --- |
| **Server 2019** | Càrregues de treball que necessiten control local, maquinari existent o baixa latència local | Tu t’encarregues dels pedaços, la capacitat i la recuperació davant desastres. |
| **Azure** | Càrregues de treball que necessiten capacitat elàstica o serveis de plataforma gestionats | Cal revisar els costos d’ús continuat, xarxa i transferència de dades. |
| **Híbrid** | Càrregues de treball repartides entre dependències locals i serveis al núvol | La identitat, les rutes de xarxa, la supervisió i els plans de recuperació passen a ser responsabilitats compartides. |

Abans de triar, documenta les dependències de les càrregues de treball, els objectius de recuperació, la ubicació de les dades i una estimació de costos a tres anys.

### Per què actualitzar a Server 2019?

1. **Seguretat millorada**: Server 2019 incorpora diverses millores de seguretat que el fan més segur que el seu predecessor, Server 2012. Per exemple, inclou **Windows Defender Advanced Threat Protection (ATP)**, una solució de seguretat completa que ajuda a protegir contra amenaces cibernètiques sofisticades.

2. **Rendiment millorat**: Server 2019 incorpora moltes millores de rendiment respecte de Server 2012. Per exemple, és compatible amb tecnologies d’emmagatzematge més ràpides, com ara **NVMe**, i millora el suport per a càrregues de treball de computació d’alt rendiment.

3. **Millor integració amb Azure**: Server 2019 està dissenyat per funcionar bé amb Azure, cosa que facilita el trasllat de les càrregues de treball locals al núvol. Aquesta integració permet aprofitar **l’escalabilitat i la rendibilitat d’Azure** i conservar el control de la infraestructura local.

4. **Suport a llarg termini**: Microsoft donarà suport a Server 2019 fins al 2029. Això permetrà que les organitzacions continuïn rebent actualitzacions de seguretat i correccions d’errors durant més temps. En canvi, el suport de Server 2012 acabarà el 2023; després, les organitzacions deixaran de rebre aquestes actualitzacions i correccions.

### Per què passar a Azure?

1. **Escalabilitat**: Azure és una plataforma al núvol molt escalable que permet ampliar la infraestructura de TI de manera ràpida i senzilla quan canvien les necessitats. Així, les organitzacions poden respondre ràpidament a les necessitats canviants del negoci sense preocupar-se pels límits de la infraestructura local.

2. **Rendibilitat**: Azure és una **solució rendible per a organitzacions de qualsevol mida**. En eliminar la necessitat de mantenir el maquinari i el programari, les organitzacions poden reduir els costos de TI i centrar-se a fer créixer el negoci.

3. **Fiabilitat més alta**: Azure està dissenyat per oferir alta disponibilitat i recuperació davant desastres. Això permet tenir la confiança que les dades sempre estaran disponibles i protegides, fins i tot si es produeix un desastre.

4. **Anàlisi avançada**: Azure inclou **eines d’anàlisi avançada**, com ara Azure Machine Learning i Azure Stream Analytics, que permeten obtenir informació útil de les dades de manera ràpida i senzilla. Això pot ajudar les organitzacions a prendre decisions empresarials més ben informades i a millorar la seva competitivitat general.

### Per què no fer totes dues coses?

Val la pena recordar que les organitzacions no han de triar entre actualitzar a Server 2019 o passar a Azure. Moltes opten per totes dues opcions perquè es complementen i ofereixen avantatges de cada entorn. Per exemple, una organització pot executar aplicacions empresarials crítiques localment a Server 2019 per tenir més control i seguretat, i aprofitar l’escalabilitat i la rendibilitat d’Azure per a càrregues de treball no crítiques. Aquest **enfocament híbrid permet aprofitar al màxim els beneficis de totes dues solucions i crear una infraestructura de TI flexible i resilient** que s’adapti a les necessitats empresarials canviants.

## Conclusió:

Les organitzacions haurien de valorar l’actualització a Server 2019 o el pas a Azure, perquè totes dues solucions milloren la seguretat, el rendiment, la integració i el suport. Si aprofiten l’escalabilitat i la rendibilitat d’Azure o la seguretat i el rendiment millorats de Server 2019, poden millorar la infraestructura de TI i avançar-se a la competència.
