## المقدمة:

في بيئة الأعمال سريعة التغير اليوم، **تبحث المؤسسات باستمرار عن طرق لتحسين بنيتها التحتية لتقنية المعلومات ومواكبة أحدث التطورات التقنية**. لذلك تواجه مؤسسات كثيرة قرارًا بين **ترقية خادمها الحالي أو الانتقال إلى حل قائم على السحابة**. يستعرض هذا المقال أسبابًا تدفع المؤسسات إلى التفكير في ترقية خوادمها إلى **Server 2019** أو الانتقال إلى **Azure**.

### معايير اتخاذ القرار

| الخيار | الأنسب لـ | القيد الرئيسي |
| --- | --- | --- |
| **Server 2019** | أعباء العمل التي تحتاج إلى تحكم محلي أو أجهزة موجودة أو زمن استجابة محلي | تتولى أنت إدارة التصحيحات والسعة والتعافي من الكوارث. |
| **Azure** | أعباء العمل التي تحتاج إلى سعة مرنة أو خدمات منصة مُدارة | ينبغي مراجعة تكاليف الاستخدام المستمر والشبكات ونقل البيانات. |
| **هجين** | أعباء العمل الموزعة بين الاعتماديات المحلية والخدمات السحابية | تصبح الهوية ومسارات الشبكة والمراقبة وخطط التعافي مسؤوليات مشتركة. |

وثّق اعتماديات أعباء العمل وأهداف التعافي وموقع البيانات وتقديرًا للتكلفة على مدى ثلاث سنوات قبل اختيار المسار.

### لماذا الترقية إلى Server 2019؟

1. **أمان محسّن**: يتضمن Server 2019 تحسينات أمنية عدة تجعله أكثر أمانًا من سابقه Server 2012. فعلى سبيل المثال، يتضمن **Windows Defender Advanced Threat Protection (ATP)**، وهو حل أمني شامل يساعد على الحماية من التهديدات السيبرانية المتطورة.

2. **أداء أفضل**: يتضمن Server 2019 تحسينات كثيرة في الأداء مقارنةً بـ Server 2012. فعلى سبيل المثال، يدعم تقنيات تخزين أسرع مثل **NVMe**، كما يحسّن دعم أعباء عمل الحوسبة عالية الأداء.

3. **تكامل أفضل مع Azure**: صُمم Server 2019 للعمل بسلاسة مع Azure، ما يسهّل على المؤسسات نقل أعباء العمل المحلية إلى السحابة. ويتيح هذا التكامل للمؤسسات الاستفادة من **قابلية Azure للتوسع وفعاليته من حيث التكلفة** مع الاحتفاظ بالتحكم في بنيتها التحتية المحلية.

4. **دعم طويل الأمد**: ستواصل Microsoft دعم Server 2019 حتى عام 2029، ما يعني أن المؤسسات ستتلقى تحديثات الأمان وإصلاحات الأخطاء مدة أطول. وبالمقارنة، سينتهي دعم Server 2012 في عام 2023، وبعد ذلك لن تتلقى المؤسسات تحديثات أمان أو إصلاحات أخطاء.

### لماذا الانتقال إلى Azure؟

1. **قابلية التوسع**: Azure منصة سحابية عالية القابلية للتوسع تتيح للمؤسسات توسيع بنيتها التحتية لتقنية المعلومات بسرعة وسهولة مع تغير احتياجاتها. وهذا يساعد المؤسسات على الاستجابة سريعًا لمتطلبات الأعمال المتغيرة دون القلق بشأن قيود بنيتها التحتية المحلية.

2. **الفعالية من حيث التكلفة**: يُعد Azure **حلًا فعّالًا من حيث التكلفة للمؤسسات بمختلف أحجامها**. ومن خلال الاستغناء عن صيانة الأجهزة والبرامج، تستطيع المؤسسات خفض تكاليف تقنية المعلومات والتركيز على تنمية أعمالها.

3. **موثوقية أعلى**: صُمم Azure لتوفير التوافر العالي والتعافي من الكوارث، ما يتيح للمؤسسات الاطمئنان إلى أن بياناتها متاحة ومحمية دائمًا، حتى عند وقوع كارثة.

4. **تحليلات متقدمة**: يتضمن Azure **أدوات تحليلات متقدمة** مثل Azure Machine Learning وAzure Stream Analytics، التي تساعد المؤسسات على استخلاص رؤى من بياناتها بسرعة وسهولة. وقد يساعد ذلك على اتخاذ قرارات أعمال أفضل استنادًا إلى المعلومات وتحسين القدرة التنافسية عمومًا.

### لماذا لا تجمع بين الخيارين؟

يجدر بالذكر أن المؤسسات ليست مضطرة للاختيار بين الترقية إلى Server 2019 والانتقال إلى Azure. تختار مؤسسات كثيرة الجمع بينهما لأنهما يكمل أحدهما الآخر ويوفران مزايا الخيارين. فمثلًا، يمكن للمؤسسة تشغيل تطبيقات الأعمال الحيوية على Server 2019 محليًا لتحسين التحكم والأمان، والاستفادة في الوقت نفسه من قابلية Azure للتوسع وفعاليته من حيث التكلفة لأعباء العمل غير الحيوية. ويساعد هذا **النهج الهجين المؤسسات على تعظيم فوائد الحلين وإنشاء بنية تحتية مرنة وقابلة للتكيف لتقنية المعلومات** تستجيب لاحتياجات الأعمال المتغيرة.

## الخلاصة:

ينبغي للمؤسسات التفكير في الترقية إلى Server 2019 أو الانتقال إلى Azure، لأن كلا الحلين يوفر أمانًا وأداءً وتكاملًا ودعمًا أفضل. ويمكن للمؤسسات تحسين بنيتها التحتية لتقنية المعلومات والتقدم على المنافسين بالاستفادة من قابلية Azure للتوسع وفعاليته من حيث التكلفة، أو من أمان Server 2019 وأدائه المحسّنين. كما يتيح النهج الهجين الاستفادة من مزايا الحلين وإنشاء بنية تحتية مرنة وقابلة للتكيف لتقنية المعلومات تستجيب
