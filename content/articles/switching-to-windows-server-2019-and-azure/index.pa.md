## ਜਾਣ-ਪਛਾਣ:

ਅੱਜ ਦੇ ਤੇਜ਼ੀ ਨਾਲ ਬਦਲਦੇ ਕਾਰੋਬਾਰੀ ਮਾਹੌਲ ਵਿੱਚ, **ਸੰਸਥਾਵਾਂ ਆਪਣੇ ਆਈਟੀ ਬੁਨਿਆਦੀ ਢਾਂਚੇ ਨੂੰ ਬਿਹਤਰ ਬਣਾਉਣ ਅਤੇ ਨਵੀਆਂ ਤਕਨੀਕੀ ਤਰੱਕੀਆਂ ਨਾਲ ਤਾਲਮੇਲ ਰੱਖਣ ਦੇ ਤਰੀਕੇ ਲੱਭਦੀਆਂ ਰਹਿੰਦੀਆਂ ਹਨ**। ਇਸ ਕਰਕੇ ਕਈ ਸੰਸਥਾਵਾਂ ਨੂੰ ਇਹ ਫ਼ੈਸਲਾ ਕਰਨਾ ਪੈਂਦਾ ਹੈ ਕਿ **ਮੌਜੂਦਾ ਸਰਵਰ ਅੱਪਗ੍ਰੇਡ ਕਰਨਾ ਹੈ ਜਾਂ ਕਲਾਊਡ-ਅਧਾਰਿਤ ਹੱਲ ਵੱਲ ਜਾਣਾ ਹੈ**। ਇਹ ਲੇਖ ਉਹ ਕਾਰਨ ਦੱਸਦਾ ਹੈ ਜਿਨ੍ਹਾਂ ਕਰਕੇ ਸੰਸਥਾਵਾਂ ਨੂੰ ਸਰਵਰ ਨੂੰ **Server 2019** ਵਿੱਚ ਅੱਪਗ੍ਰੇਡ ਕਰਨ ਜਾਂ **Azure** ਵੱਲ ਜਾਣ ਬਾਰੇ ਸੋਚਣਾ ਚਾਹੀਦਾ ਹੈ।

| **Server 2019** | ਸਥਾਨਕ ਕੰਟਰੋਲ, ਮੌਜੂਦਾ ਹਾਰਡਵੇਅਰ ਜਾਂ ਸਥਾਨਕ ਘੱਟ ਲੇਟੈਂਸੀ ਦੀ ਲੋੜ ਵਾਲੇ ਕੰਮਾਂ ਲਈ | ਪੈਚਿੰਗ, ਸਮਰੱਥਾ ਅਤੇ ਆਫ਼ਤ ਤੋਂ ਮੁੜ-ਬਹਾਲੀ ਦੀ ਜ਼ਿੰਮੇਵਾਰੀ ਤੁਹਾਡੀ ਹੈ। |

ਰਾਹ ਚੁਣਨ ਤੋਂ ਪਹਿਲਾਂ ਕੰਮਾਂ ਦੀਆਂ ਨਿਰਭਰਤਾਵਾਂ, ਮੁੜ-ਬਹਾਲੀ ਦੇ ਟੀਚੇ, ਡਾਟੇ ਦੀ ਥਾਂ ਅਤੇ ਤਿੰਨ ਸਾਲਾਂ ਦੀ ਲਾਗਤ ਦਾ ਅੰਦਾਜ਼ਾ ਦਰਜ ਕਰੋ।

### Server 2019 ਵਿੱਚ ਅੱਪਗ੍ਰੇਡ ਕਿਉਂ ਕਰੀਏ?

1. **ਬਿਹਤਰ ਸੁਰੱਖਿਆ**: Server 2019 ਵਿੱਚ ਕਈ ਸੁਰੱਖਿਆ ਸੁਧਾਰ ਹਨ ਜੋ ਇਸਨੂੰ ਪਿਛਲੇ Server 2012 ਨਾਲੋਂ ਵਧੇਰੇ ਸੁਰੱਖਿਅਤ ਬਣਾਉਂਦੇ ਹਨ। ਉਦਾਹਰਨ ਵਜੋਂ, ਇਸ ਵਿੱਚ **Windows Defender Advanced Threat Protection (ATP)** ਹੈ, ਜੋ ਉੱਨਤ ਸਾਈਬਰ ਖ਼ਤਰਿਆਂ ਤੋਂ ਬਚਾਉਣ ਵਿੱਚ ਮਦਦ ਕਰਨ ਵਾਲਾ ਪੂਰਾ ਸੁਰੱਖਿਆ ਹੱਲ ਹੈ।

2. **ਬਿਹਤਰ ਕਾਰਗੁਜ਼ਾਰੀ**: Server 2012 ਦੇ ਮੁਕਾਬਲੇ Server 2019 ਵਿੱਚ ਕਾਰਗੁਜ਼ਾਰੀ ਦੇ ਕਈ ਸੁਧਾਰ ਹਨ। ਉਦਾਹਰਨ ਵਜੋਂ, ਇਹ **NVMe** ਵਰਗੀਆਂ ਤੇਜ਼ ਸਟੋਰੇਜ ਤਕਨੀਕਾਂ ਅਤੇ ਉੱਚ-ਕਾਰਗੁਜ਼ਾਰੀ ਕੰਪਿਊਟਿੰਗ ਕੰਮਾਂ ਲਈ ਬਿਹਤਰ ਸਹਾਇਤਾ ਦਿੰਦਾ ਹੈ।

3. **Azure ਨਾਲ ਬਿਹਤਰ ਏਕੀਕਰਨ**: Server 2019 ਨੂੰ Azure ਨਾਲ ਸੁਚਾਰੂ ਤਰੀਕੇ ਨਾਲ ਕੰਮ ਕਰਨ ਲਈ ਬਣਾਇਆ ਗਿਆ ਹੈ, ਜਿਸ ਨਾਲ ਸੰਸਥਾਵਾਂ ਲਈ ਆਪਣੇ ਸਥਾਨਕ ਕੰਮਾਂ ਨੂੰ ਕਲਾਊਡ ਵਿੱਚ ਲਿਜਾਣਾ ਸੌਖਾ ਹੁੰਦਾ ਹੈ। ਇਸ ਏਕੀਕਰਨ ਨਾਲ ਸੰਸਥਾਵਾਂ ਆਪਣੇ ਸਥਾਨਕ ਬੁਨਿਆਦੀ ਢਾਂਚੇ ਉੱਤੇ ਕੰਟਰੋਲ ਰੱਖਦਿਆਂ **Azure ਦੀ ਵਧਾਉਣ ਦੀ ਸਮਰੱਥਾ ਅਤੇ ਲਾਗਤ-ਪ੍ਰਭਾਵਸ਼ੀਲਤਾ** ਦਾ ਲਾਭ ਲੈ ਸਕਦੀਆਂ ਹਨ।

4. **ਲੰਬੇ ਸਮੇਂ ਦੀ ਸਹਾਇਤਾ**: Microsoft 2029 ਤੱਕ Server 2019 ਲਈ ਸਹਾਇਤਾ ਦੇਵੇਗਾ। ਇਸ ਨਾਲ ਸੰਸਥਾਵਾਂ ਨੂੰ ਲੰਬੇ ਸਮੇਂ ਤੱਕ ਸੁਰੱਖਿਆ ਅੱਪਡੇਟ ਅਤੇ ਬੱਗ ਠੀਕ ਕਰਨ ਵਾਲੇ ਅੱਪਡੇਟ ਮਿਲਦੇ ਰਹਿਣਗੇ। ਇਸ ਦੇ ਉਲਟ, Server 2012 ਲਈ ਸਹਾਇਤਾ ਸਿਰਫ਼ 2023 ਤੱਕ ਹੈ, ਜਿਸ ਤੋਂ ਬਾਅਦ ਸੁਰੱਖਿਆ ਅੱਪਡੇਟ ਜਾਂ ਬੱਗ-ਫ਼ਿਕਸ ਨਹੀਂ ਮਿਲਣਗੇ।

### Azure ਵੱਲ ਕਿਉਂ ਜਾਈਏ?

1. **ਵਧਾਉਣ ਦੀ ਸਮਰੱਥਾ**: Azure ਇੱਕ ਬਹੁਤ ਵਧਣਯੋਗ ਕਲਾਊਡ ਪਲੇਟਫ਼ਾਰਮ ਹੈ, ਜੋ ਲੋੜਾਂ ਬਦਲਣ ’ਤੇ ਸੰਸਥਾਵਾਂ ਨੂੰ ਆਪਣਾ ਆਈਟੀ ਬੁਨਿਆਦੀ ਢਾਂਚਾ ਤੇਜ਼ੀ ਅਤੇ ਸੌਖੇ ਢੰਗ ਨਾਲ ਵਧਾਉਣ ਦਿੰਦਾ ਹੈ। ਇਸ ਨਾਲ ਉਹ ਸਥਾਨਕ ਬੁਨਿਆਦੀ ਢਾਂਚੇ ਦੀਆਂ ਹੱਦਾਂ ਦੀ ਚਿੰਤਾ ਬਿਨਾਂ ਬਦਲਦੀਆਂ ਕਾਰੋਬਾਰੀ ਲੋੜਾਂ ਦਾ ਜਲਦੀ ਜਵਾਬ ਦੇ ਸਕਦੀਆਂ ਹਨ।

2. **ਲਾਗਤ-ਪ੍ਰਭਾਵਸ਼ੀਲਤਾ**: Azure **ਹਰ ਆਕਾਰ ਦੀਆਂ ਸੰਸਥਾਵਾਂ ਲਈ ਲਾਗਤ-ਪ੍ਰਭਾਵਸ਼ੀਲ ਹੱਲ** ਹੈ। ਹਾਰਡਵੇਅਰ ਅਤੇ ਸੌਫ਼ਟਵੇਅਰ ਦੀ ਦੇਖਭਾਲ ਦੀ ਲੋੜ ਘਟਾ ਕੇ ਸੰਸਥਾਵਾਂ ਆਈਟੀ ਖ਼ਰਚੇ ਘਟਾ ਸਕਦੀਆਂ ਹਨ ਅਤੇ ਕਾਰੋਬਾਰ ਵਧਾਉਣ ’ਤੇ ਧਿਆਨ ਦੇ ਸਕਦੀਆਂ ਹਨ।

3. **ਵਧੀ ਭਰੋਸੇਯੋਗਤਾ**: Azure ਨੂੰ ਉੱਚ ਉਪਲਬਧਤਾ ਅਤੇ ਆਫ਼ਤ ਤੋਂ ਮੁੜ-ਬਹਾਲੀ ਲਈ ਬਣਾਇਆ ਗਿਆ ਹੈ। ਇਸ ਲਈ ਸੰਸਥਾਵਾਂ ਭਰੋਸਾ ਰੱਖ ਸਕਦੀਆਂ ਹਨ ਕਿ ਆਫ਼ਤ ਵੇਲੇ ਵੀ ਉਨ੍ਹਾਂ ਦਾ ਡਾਟਾ ਉਪਲਬਧ ਅਤੇ ਸੁਰੱਖਿਅਤ ਰਹੇਗਾ।

4. **ਉੱਨਤ ਵਿਸ਼ਲੇਸ਼ਣ**: Azure ਵਿੱਚ Azure Machine Learning ਅਤੇ Azure Stream Analytics ਵਰਗੇ **ਉੱਨਤ ਵਿਸ਼ਲੇਸ਼ਣ ਸਾਧਨ** ਸ਼ਾਮਲ ਹਨ, ਜੋ ਸੰਸਥਾਵਾਂ ਨੂੰ ਆਪਣੇ ਡਾਟੇ ਤੋਂ ਤੇਜ਼ੀ ਅਤੇ ਸੌਖੇ ਢੰਗ ਨਾਲ ਜਾਣਕਾਰੀ ਹਾਸਲ ਕਰਨ ਦਿੰਦੇ ਹਨ। ਇਸ ਨਾਲ ਉਹ ਜਾਣਕਾਰੀ-ਅਧਾਰਿਤ ਕਾਰੋਬਾਰੀ ਫ਼ੈਸਲੇ ਲੈ ਸਕਦੀਆਂ ਹਨ ਅਤੇ ਆਪਣੀ ਮੁਕਾਬਲੇ ਦੀ ਸਮਰੱਥਾ ਸੁਧਾਰ ਸਕਦੀਆਂ ਹਨ।

### ਦੋਵੇਂ ਕਿਉਂ ਨਹੀਂ?

ਇਹ ਦੱਸਣਾ ਜ਼ਰੂਰੀ ਹੈ ਕਿ ਸੰਸਥਾਵਾਂ ਨੂੰ Server 2019 ਵਿੱਚ ਅੱਪਗ੍ਰੇਡ ਕਰਨ ਅਤੇ Azure ਵੱਲ ਜਾਣ ਵਿੱਚੋਂ ਇੱਕ ਹੀ ਚੁਣਨ ਦੀ ਲੋੜ ਨਹੀਂ। ਕਈ ਸੰਸਥਾਵਾਂ ਦੋਵੇਂ ਰਾਹ ਚੁਣਦੀਆਂ ਹਨ, ਕਿਉਂਕਿ ਉਹ ਇੱਕ-ਦੂਜੇ ਦੇ ਪੂਰਕ ਹਨ ਅਤੇ ਦੋਹਾਂ ਦੇ ਫ਼ਾਇਦੇ ਦਿੰਦੇ ਹਨ। ਉਦਾਹਰਨ ਵਜੋਂ, ਕੋਈ ਸੰਸਥਾ ਵਧੇਰੇ ਕੰਟਰੋਲ ਅਤੇ ਸੁਰੱਖਿਆ ਲਈ ਮਹੱਤਵਪੂਰਨ ਕਾਰੋਬਾਰੀ ਐਪਲੀਕੇਸ਼ਨਾਂ ਨੂੰ ਸਥਾਨਕ Server 2019 ਉੱਤੇ ਚਲਾ ਸਕਦੀ ਹੈ ਅਤੇ ਘੱਟ ਮਹੱਤਵਪੂਰਨ ਕੰਮਾਂ ਲਈ Azure ਦੀ ਵਧਾਉਣ ਦੀ ਸਮਰੱਥਾ ਅਤੇ ਲਾਗਤ-ਪ੍ਰਭਾਵਸ਼ੀਲਤਾ ਵਰਤ ਸਕਦੀ ਹੈ। ਇਹ **ਹਾਈਬ੍ਰਿਡ ਪਹੁੰਚ ਦੋਹਾਂ ਹੱਲਾਂ ਦੇ ਲਾਭ ਵੱਧ ਤੋਂ ਵੱਧ ਕਰਨ ਅਤੇ ਬਦਲਦੀਆਂ ਕਾਰੋਬਾਰੀ ਲੋੜਾਂ ਮੁਤਾਬਕ ਢਲਣ ਵਾਲਾ ਲਚਕੀਲਾ ਤੇ ਅਨੁਕੂਲ ਆਈਟੀ ਬੁਨਿਆਦੀ ਢਾਂਚਾ ਬਣਾਉਣ ਵਿੱਚ ਮਦਦ ਕਰਦੀ ਹੈ**।

## ਨਤੀਜਾ:

ਸੰਸਥਾਵਾਂ ਨੂੰ Server 2019 ਵਿੱਚ ਅੱਪਗ੍ਰੇਡ ਕਰਨ ਜਾਂ Azure ਵੱਲ ਜਾਣ ਬਾਰੇ ਸੋਚਣਾ ਚਾਹੀਦਾ ਹੈ, ਕਿਉਂਕਿ ਦੋਵੇਂ ਹੱਲ ਸੁਰੱਖਿਆ, ਕਾਰਗੁਜ਼ਾਰੀ, ਏਕੀਕਰਨ ਅਤੇ ਸਹਾਇਤਾ ਵਿੱਚ ਸੁਧਾਰ ਦਿੰਦੇ ਹਨ। Azure ਦੀ ਵਧਾਉਣ ਦੀ ਸਮਰੱਥਾ ਅਤੇ ਲਾਗਤ-ਪ੍ਰਭਾਵਸ਼ੀਲਤਾ ਜਾਂ Server 2019 ਦੀ ਬਿਹਤਰ ਸੁਰੱਖਿਆ ਅਤੇ ਕਾਰਗੁਜ਼ਾਰੀ ਦਾ ਲਾਭ ਲੈ ਕੇ ਸੰਸਥਾਵਾਂ ਆਪਣਾ ਆਈਟੀ ਬੁਨਿਆਦੀ ਢਾਂਚਾ ਸੁਧਾਰ ਸਕਦੀਆਂ ਹਨ ਅਤੇ ਮੁਕਾਬਲੇ ਵਿੱਚ ਅੱਗੇ ਰਹਿ ਸਕਦੀਆਂ ਹਨ। ਹਾਈਬ੍ਰਿਡ ਪਹੁੰਚ ਨਾਲ ਦੋਹਾਂ ਦੇ ਫ਼ਾਇਦੇ ਲੈ ਕੇ ਬਦਲਦੀਆਂ ਕਾਰੋਬਾਰੀ ਲੋੜਾਂ ਮੁਤਾਬਕ ਢਲਣ ਵਾਲਾ ਲਚਕੀਲਾ ਤੇ ਅਨੁਕੂਲ ਆਈਟੀ ਬੁਨਿਆਦੀ ਢਾਂਚਾ ਬਣਾਇਆ ਜਾ ਸਕਦਾ ਹੈ
