## Introdução:

No ambiente empresarial atual, que muda rapidamente, **as organizações buscam maneiras de melhorar sua infraestrutura de TI e acompanhar os avanços tecnológicos mais recentes**. Por isso, muitas precisam decidir se devem **atualizar o servidor atual ou migrar para uma solução em nuvem**. Este artigo apresenta motivos para considerar a atualização do servidor para o **Server 2019** ou a migração para o **Azure**.

### Critérios para a decisão

| Opção | Mais indicada para | Principal limitação |
| --- | --- | --- |
| **Server 2019** | Cargas de trabalho que exigem controle local, hardware existente ou baixa latência local | Você é responsável por atualizações, capacidade e recuperação de desastres. |
| **Azure** | Cargas de trabalho que exigem capacidade elástica ou serviços de plataforma gerenciados | É preciso avaliar os custos contínuos de uso, rede e transferência de dados. |
| **Híbrida** | Cargas de trabalho divididas entre dependências locais e serviços em nuvem | Identidade, caminhos de rede, monitoramento e planos de recuperação passam a ser responsabilidades compartilhadas. |

Documente as dependências das cargas de trabalho, as metas de recuperação, a localização dos dados e uma estimativa de custos para três anos antes de escolher um caminho.

### Por que atualizar para o Server 2019?

1. **Segurança aprimorada**: O Server 2019 inclui várias melhorias de segurança que o tornam mais seguro que seu antecessor, o Server 2012. Por exemplo, ele inclui o **Windows Defender Advanced Threat Protection (ATP)**, uma solução abrangente que ajuda a proteger contra ameaças cibernéticas sofisticadas.

2. **Desempenho aprimorado**: O Server 2019 traz muitas melhorias de desempenho em relação ao Server 2012. Por exemplo, oferece suporte a tecnologias de armazenamento mais rápidas, como **NVMe**, e aprimora o suporte a cargas de trabalho de computação de alto desempenho.

3. **Melhor integração com o Azure**: O Server 2019 foi projetado para funcionar bem com o Azure, facilitando a migração de cargas de trabalho locais para a nuvem. Essa integração permite aproveitar a **escalabilidade e o custo-benefício do Azure** sem perder o controle da infraestrutura local.

4. **Suporte de longo prazo**: A Microsoft oferecerá suporte ao Server 2019 até 2029. Assim, as organizações continuarão recebendo atualizações de segurança e correções de bugs por mais tempo. Em comparação, o suporte ao Server 2012 terminará em 2023. Depois disso, as organizações não receberão atualizações de segurança nem correções de bugs.

### Por que migrar para o Azure?

1. **Escalabilidade**: O Azure é uma plataforma de nuvem altamente escalável que permite aumentar a infraestrutura de TI de maneira rápida e fácil conforme as necessidades mudam. Isso ajuda as organizações a responder rapidamente às mudanças nos negócios sem se preocupar com os limites da infraestrutura local.

2. **Custo-benefício**: O Azure é uma **solução econômica para organizações de todos os portes**. Ao eliminar a necessidade de manutenção de hardware e software, as organizações podem reduzir os custos de TI e se concentrar no crescimento dos negócios.

3. **Maior confiabilidade**: O Azure foi projetado para oferecer alta disponibilidade e recuperação de desastres. Assim, as organizações podem confiar que seus dados estarão disponíveis e protegidos, mesmo em caso de desastre.

4. **Análise avançada**: O Azure inclui **ferramentas avançadas de análise**, como Azure Machine Learning e Azure Stream Analytics, que ajudam as organizações a obter insights dos dados com rapidez e facilidade. Isso pode ajudar a tomar decisões empresariais mais bem informadas e melhorar a competitividade geral.

### Por que não fazer as duas coisas?

Vale lembrar que as organizações não precisam escolher entre atualizar para o Server 2019 e migrar para o Azure. Muitas optam por ambos, pois as soluções se complementam e oferecem o melhor dos dois mundos. Por exemplo, uma organização pode executar aplicações empresariais críticas localmente no Server 2019 para ter mais controle e segurança, enquanto aproveita a escalabilidade e o custo-benefício do Azure para cargas de trabalho não críticas. Essa **abordagem híbrida permite aproveitar ao máximo os benefícios das duas soluções e criar uma infraestrutura de TI flexível e resiliente**, capaz de se adaptar às mudanças nas necessidades empresariais.

## Conclusão:

As organizações devem considerar atualizar para o Server 2019 ou migrar para o Azure, pois ambas as soluções oferecem melhorias em segurança, desempenho, integração e suporte. Ao aproveitar a escalabilidade e o custo-benefício do Azure ou a segurança e o desempenho aprimorados do Server 2019, é possível melhorar a infraestrutura de TI e manter-se à frente da concorrência.
