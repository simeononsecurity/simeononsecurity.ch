**UPS**（不间断电源）能在停电时为家庭实验室争取时间，以便保存工作并关闭系统。仅看标签无法知道服务器能运行多久。你需要了解设备负载、UPS 的瓦数和 VA 限值、该负载下的续航估算，以及经过测试的关机流程。

## 要点

- **测量负载：** 记录每台需要由电池供电的设备在正常和高负载下的瓦数。
- **检查两项额定值：** UPS 必须满足所连接设备对瓦数和 VA 的要求。
- **查看续航曲线：** 续航时间取决于负载和电池状态。使用针对具体型号的估算值。
- **测试关机流程：** 确认 UPS 信号能到达每台主机，并且主机能在电池耗尽前停止。

## 开始之前

你需要一台适用于当地供电规格的功率计、一份设备和电源适配器清单，以及候选 UPS 型号的规格和续航曲线。要测试自动关机，还需要受支持的 USB 或网络管理连接，以及每台主机所需的软件。预留时间测量正常负载、观察高负载，并安排一次维护测试。这属于中级家庭实验室任务，因为完整的关机测试会中断服务。

网站的[浪涌保护插排指南](/articles/protecting-your-tech_-the-best-surge-protectors/)介绍浪涌防护。[UPS 型号汇总](/articles/best-ups-models-for-uninterrupted-connectivity/)列出产品。本指南说明如何根据你自己的负载选择并验证 UPS。Eaton 的[UPS 容量选择指南](https://www.eaton.com/us/en-us/products/backup-power-ups-surge-it-power-distribution/backup-power-ups/ups-sizing-guide.html)和 Schneider Electric 的[UPS 购买指南](https://www.se.com/us/en/work/support/product-support/ups-buying-guide-for-selecting-a-battery-backup-system/)都区分了输出容量与电池续航时间。

> **警告：** 仅使用 UPS 制造商认可的输出端口和负载。测试期间不得超过 UPS 的额定容量。真实关机测试会停止连接的实验室设备。

## 测量需要保持运行的设备

确定哪些设备必须运行到关机为止。如果主机需要网络连接才能接收关机信号，请把虚拟化主机、存储设备、网络交换机和路由器都纳入计划。除非计划明确要求，否则不要让显示器、打印机和其他可选设备占用电池供电插座。

在墙上插座处测量计划由电池供电的设备组。记录**正常运行瓦数**，以及代表性工作期间观察到的最高瓦数，例如启动主机或虚拟机时的读数。电源标签标示的是额定能力，不是整个系统的实测功耗。仍要查看设备标签上的输入和启动电流限制。把测量条件写入工作表。

| 设备 | 正常瓦数 | 观察到的最高瓦数 | 接电池供电插座？ |
|---|---:|---:|---|
| **路由器和交换机** | 30 | 35 | 是 |
| **NAS** | 60 | 90 | 是 |
| **小型服务器** | 90 | 135 | 是 |
| **示例总计** | **180** | **260** | 三台设备 |

以上数值仅为**示例**，不是某个实验室的实测数据。硬盘、GPU、电源设置和连接设备都会改变负载。重大硬件变更后应重新测量。

## 比较瓦数与 VA

**瓦数**表示设备使用的有功功率。**伏安（VA）**表示视在功率。两者的关系取决于**功率因数**：瓦数除以功率因数等于 VA。Eaton 在其[容量选择指南](https://www.eaton.com/us/en-us/products/backup-power-ups-surge-it-power-distribution/backup-power-ups/ups-sizing-guide.html)中说明了这个计算。不要把标有 1000 VA 的 UPS 当作 1000 瓦。还要检查 UPS 单独标出的瓦数额定值。

对于示例中的 260 W 高负载，增加 25% 容量余量后为 **325 W**。Schneider Electric 建议输出瓦数约比负载[高 20% 至 25%](https://www.se.com/us/en/work/support/product-support/ups-buying-guide-for-selecting-a-battery-backup-system/)。选择持续瓦数额定值高于计划峰值加余量的 UPS。如果知道组合功率因数，可用峰值瓦数除以该因数来估算峰值 VA，然后也为 VA 增加所选余量。否则，使用合适的仪表或制造商的选型工具确定 VA 要求和余量。没有测量时不要编造功率因数。

容量余量不能证明续航能力。瓦数上限很高但电池较小的 UPS 可能只能短时间供电。选择型号前，确认输出插座、插头类型、输入电压、通信接口和电池更换方式。

## 设定续航目标

写下实验室安全停止需要多长时间。计算关机通知到达主机、虚拟机停止、存储完成写入以及 UPS 切断输出所需的时间。为缓慢关机和老化电池留出余量。需要撑过短时停电的实验室，与只需要安全关机的实验室，续航目标不同。

举个**示例**：一次经过测试的关机需要 6 分钟，你预留 5 分钟余量。那么预期负载下至少需要 11 分钟续航。这只是规划示例，不是通用门槛。根据**实测的正常和高负载**，将目标与候选型号的续航曲线或选型工具比较，并随着电池老化重新检查。Schneider Electric 的[UPS 选型工具](https://www.se.com/us/en/work/products/tools/ups-selector/)根据输入负载和型号规格估算续航。Eaton 的[桌面 UPS 指南](https://www.eaton.com/us/en-us/products/backup-power-ups-surge-it-power-distribution/backup-power-ups/desktop-ups-buying-guide.html)也提供具体型号的续航数据。

为你的实验室复制这份**工作表**。根据功率计读数填写设备行。分别汇总正常和高负载瓦数，将选定余量加到高负载总和，并对实测或计算的峰值 VA 应用相同余量。将两项结果与候选 UPS 比较。若使用制造商选型工具，记录 VA 选型结果和余量。依据型号曲线估算续航。在测试过程中填写时间和恢复情况。

| 字段 | 你的结果 |
|---|---|
| **设备与电池供电插座** | 设备名称及分配给每台设备的插座 |
| **每台设备和总计的正常瓦数** | 实测值和总和 |
| **每台设备和总计的高负载瓦数** | 观察到的最高值和总和 |
| **实测或指定的功率因数** | 数值和来源，或“未知” |
| **实测或计算的峰值 VA** | 如已知，用峰值瓦数除以组合功率因数 |
| **容量余量** | 选择的百分比，以及余量后的瓦数和 VA |
| **候选 UPS 额定值** | 型号、输出瓦数与 VA、插座限制 |
| **续航目标和曲线估算** | 所需分钟数及该型号在你负载下的估算 |
| **告警和关机时间** | 电池告警时间和最后一台主机停止时间 |
| **恢复结果** | 主机启动、存储、应用和监控状态 |

如果功率因数未知，使用制造商选型工具，或用合适的仪表测量视在功率。不要报告基于猜测因数计算出的 VA。只有当型号满足两项输出限制，且估算续航超过关机目标时，工作表才算完成。

> **预期结果：** 工作表列出连接设备、实测负载、UPS 的瓦数和 VA 限值、续航目标以及具体型号的续航估算。

## 规划自动关机

UPS 只能暂时为设备供电。主机仍需要**关机信号**。检查 UPS 是否提供 USB、网络管理卡或其他受支持接口。确认每台需要停止的主机都有兼容的监控路径。Eaton 指出，许多型号支持通过 USB 或网络通信来[有序关闭 NAS 或服务器](https://www.eaton.com/us/en-us/products/backup-power-ups-surge-it-power-distribution/backup-power-ups/desktop-ups-buying-guide.html)。

在使用 **Network UPS Tools (NUT)** 的 Linux 实验室中，UPS 驱动读取设备状态，`upsd`共享状态，供电进入临界状态时由`upsmon`触发主机关机。直接连接 USB 或串口 UPS 的主机通常以 **Primary** 模式运行驱动、`upsd`和`upsmon`。其他主机通过该服务器以 **Secondary** 模式运行`upsmon`。网络管理型 UPS 需要兼容驱动和型号专用的 Primary 配置。[NUT 拓扑指南](https://networkupstools.org/docs/user-manual.chunked/ar01s02.html)说明了这些角色。配置路由器和交换机，确保监控主机在电池供电时仍保持连接。将关机命令及其权限限制为管理员可用。

测试关机前，确认驱动报告的是最新状态。将`myupsname`替换为 NUT 配置中的 UPS 名称：

```bash
upsc myupsname@localhost ups.status
```

NUT 的[配置指南](https://networkupstools.org/docs/user-manual.chunked/ar01s06.html)规定正常市电状态为`OL`，并说明电池供电状态为`OB`。在每台监控 UPS 的主机上运行状态检查；远程客户端使用正确的服务器名称。读数过时或缺失，表示应先修复信号路径，再进行关机测试。

记录**关机顺序**。例如，先停止应用虚拟机，再停止存储客户端，最后停止虚拟化主机和 NAS。检查供电恢复后每项服务和文件系统能否正常恢复。主机虽然停机，但应用无法正常恢复，不算完整成功。

## 不靠猜测进行测试

先在已配置 UPS 驱动的主机上执行**模拟运行**。NUT 将`upsdrvctl -t shutdown`记录为驱动关机顺序的预览，该命令不会调用驱动，也不会断电：

```bash
upsdrvctl -t shutdown
```

这项**驱动模拟运行**不能证明断电告警会到达每台主机。检查每项监控服务及其日志。在维护窗口中，NUT 的[关机测试说明](https://networkupstools.org/docs/user-manual.chunked/ar01s06.html)介绍了在 NUT 主机上运行`upsmon -c fsd`以进行强制关机测试。这项 **FSD 测试**会启动真实的关机流程。FSD 标志会一直保留，直到重启`upsd`。系统恢复后，确认`upsd`已重启且状态不再显示 FSD，然后再依赖监控功能。阅读当前的[upsmon 手册](https://networkupstools.org/docs/man/upsmon.html)，准备恢复方法，并在保存工作、通知实验室用户后再测试。

进行受控的**电池事件测试**时，先按 UPS 制造商的流程使用非关键负载测试。低负载测试能检查信号传递，但不能证明实验室的续航时间。之后在维护窗口中，用具有代表性的计划电池负载测试。安排人员观察 UPS，并在余量不足时恢复市电。记录 UPS 显示的负载、UPS 报告转为电池供电的时间、各主机开始关机的时间，以及最后一台主机停止的时间。确认主机停止前电池不会耗尽。市电恢复后，检查主机启动、应用状态、存储完整性和监控状态。NUT 指出，操作系统在电池耗尽前停止，并在供电恢复后重新运行，才算成功。

| 检查项 | 记录内容 |
|---|---|
| **信号路径** | 每台监控主机都能看到 UPS 事件 |
| **关机时间** | 最后一台主机在电池耗尽前停止 |
| **恢复情况** | 主机、存储和应用正常启动 |
| **容量** | UPS 负载保持在瓦数和 VA 限值内 |

## 故障排查

- **UPS 过载告警：** 移除可选负载。将实测高负载与 UPS 的两项额定值和型号插座限制比较。
- **续航短于预期：** 检查当前负载、电池使用年限、型号专属续航数据和最近的电池测试结果。不要只根据 VA 做线性推算。
- **某台主机仍在运行：** 检查监控服务、网络路径、关机权限和日志。
- **主机停止后无法恢复：** 检查供电恢复时 UPS 输出行为、主机固件的来电启动设置，以及 NUT 记录的[电源竞争情况](https://networkupstools.org/docs/user-manual.chunked/ar01s06.html)。
- **模拟运行成功，但停电测试失败：** 驱动预览只检查了较窄的路径。检查事件传递和实际主机关机顺序。

## 后续步骤

将工作表与家庭实验室资产清单一起保存。增加硬件后重新测量负载；更换 UPS、监控软件、主机启动策略或存储方案后，再次进行关机测试。单独检查备份和恢复计划。电池保护的是关机窗口，而[经过测试的家庭实验室备份](/articles/what-is-a-homelab-and-should-you-have-one/)能在其他故障中保护数据。
