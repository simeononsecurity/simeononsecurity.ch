**个人威胁模型**用简短的书面答案回答三个问题：谁可能会针对你，他们想要什么，以及他们如何取得目标。它能把模糊的风险感转化为可执行的计划。

*安全投入有限。威胁模型会把精力集中在最可能影响你的攻击上，避免为不会遇到的问题耗费精力。*

______

## 什么是个人威胁模型？

**威胁建模**是列出你的资产、可能觊觎资产的人，以及他们可能采用的路径。你平时也会粗略地这样判断，例如锁上家门，却没有给车库里的自行车上锁。把模型写下来，会让这些选择更有意识，也便于重复执行。

按顺序操作：列出资产、确定攻击者、绘制路径，然后选择防护措施。每一步都会缩小范围，让最终防护符合你的情况，而不是套用通用清单。

> **要点：**个人威胁模型不是一次性填写的表格。你应定期重新制定，并在生活出现重大变化后更新，例如换工作、搬家或卷入公开争议。

______

## 要点

- **先列资产。**你要保护的是具体事物，而不是抽象的安全概念。
- **威胁行为者各不相同。**诈骗者、跟踪者和国家级攻击者需要不同的防御措施。
- **攻击途径反复出现。**网络钓鱼、恶意软件、重复使用密码和设备丢失都会造成重大损失。
- **后果决定优先级。**把投入放在最不愿承受的损失上。
- **防护措施刻意保持简单。**强密码、多因素认证和更新能阻止许多攻击。

______

## 七个步骤一览

| 步骤 | 行动 | 结果 |
|------|------|------|
| **1** | 识别资产 | 按重要性排列的保护清单 |
| **2** | 评估威胁行为者 | 可能针对你的人 |
| **3** | 评估动机与能力 | 攻击者画像 |
| **4** | 识别攻击途径 | 攻击者的入侵方式 |
| **5** | 评估后果 | 每种损失的影响 |
| **6** | 实施缓解措施 | 你采用的控制措施 |
| **7** | 检查并更新 | 持续维护的文档 |

每一步都基于前一步。跳过一步就会留下攻击者可利用的缺口。

______

## 免费个人威胁模型清单

- [ ] **列出资产。**按价值排列财务、数字、个人和职业资产。
- [ ] **列出威胁行为者。**指出最可能针对每项资产的人或组织。
- [ ] **记录动机和能力。**涵盖从技能有限的攻击者到国家支持的组织。
- [ ] **绘制攻击途径。**例如网络钓鱼、恶意软件、密码攻击和设备盗窃。
- [ ] **评估后果。**考虑每项资产丢失或泄露造成的影响。
- [ ] **采用缓解措施。**例如唯一密码、多因素认证、更新和隐私设置。
- [ ] **安排复查。**每隔几个月以及生活发生重大变化后复查。

______

## 步骤 1：识别资产

**资产**是对你或攻击者有价值的任何事物。资产承载金钱、数据、身份或声誉。你要保护资产，因此先列出它们。

| 资产类别 | 示例 |
|----------|------|
| **财务** | 银行账户、银行卡、投资、加密货币钱包 |
| **数字** | 电子邮件、社交账号、云端文件、照片 |
| **个人** | 身份证件、医疗记录、家庭住址 |
| **职业** | 知识产权、客户数据、商业机密 |

根据丢失或泄露带来的代价为每项资产排序。排名靠前的项目决定模型的其余部分。

*不要漏掉电子邮件。它是你所有其他账户的主钥匙。*

______

## 步骤 2：评估潜在威胁行为者

**威胁行为者**有理由也有办法接触某项资产。不同的行为者目标不同，因此你需要不同的防御措施。

| 威胁行为者 | 目标 |
|------------|------|
| **黑客** | 凭据、数据、访问权限 |
| **诈骗者** | 金钱、银行卡号、礼品卡 |
| **网络跟踪者** | 恐吓、控制、骚扰 |
| **竞争对手** | 你的知识产权和客户 |
| **国家级攻击者** | 情报、影响力、访问权限 |

记者、企业高管和学生面对的行为者及其能力各不相同。为每项资产匹配最可能的行为者，而不是最令人害怕的对象。

______

## 步骤 3：评估动机和能力

威胁行为者有**动机**（攻击的原因）和**能力**（可调动的资源）。动机说明他们追求什么，能力决定你必须抵御什么。

| 动机 | 驱动因素 |
|------|----------|
| **经济利益** | 勒索、诈骗、出售窃取的数据 |
| **报复** | 个人或职业上的恩怨 |
| **间谍活动** | 秘密和知识产权 |
| **黑客行动主义** | 事业、宣传或破坏活动 |

能力范围从使用现成脚本的机会主义诈骗者，到资金充足且拥有定制工具的团队。*低技能攻击者仍然危险，因为大规模攻击会重复使用相同的网络钓鱼和密码攻击手段。*根据最可能出现的最高能力配置控制措施，并接受较低层次的剩余风险。

______

## 步骤 4：识别攻击途径

**攻击途径**是攻击者接触资产所用的路径。大多数个人安全事件集中在少数几种路径上。

| 攻击途径 | 攻击者如何入侵 |
|----------|----------------|
| **网络钓鱼** | 伪造的电子邮件、短信、链接或登录页面 |
| **恶意软件** | 下载、附件或自动安装 |
| **社会工程** | 施压或冒充他人 |
| **密码攻击** | 重复使用、暴力破解、泄露的凭据 |
| **实体盗窃** | 设备被盗或无人看管 |

列出与你的资产和行为者相关的途径。步骤 6 会为每种途径匹配防护措施。

______

## 步骤 5：评估后果

**后果**是资产丢失给你造成的代价。评估影响，然后把防护资源放在最不愿承受的结果上。

| 后果 | 影响 |
|------|------|
| **经济损失** | 账户被盗空、欺诈性扣款 |
| **声誉受损** | 诽谤、假账号、消息泄露 |
| **身份盗用** | 他人以你的名义开设账户和贷款 |
| **情绪困扰** | 骚扰、恐惧、失去控制 |

*拥有相同资产的两个人也可能有相反的优先级。公众人物可能把声誉放在首位，退休人士可能优先防范经济损失。你的排序就是这一步的成果。*

______

## 步骤 6：实施缓解措施

**缓解措施**能关闭攻击途径。请按照后果的严重程度安排控制措施，而不是按照便利程度。

| 控制措施 | 防范对象 |
|----------|----------|
| [**强且唯一的密码**](/articles/how-to-create-strong-passwords/)和密码管理器 | 密码攻击 |
| [**双因素认证（2FA）**](/articles/what-are-the-diferent-kinds-of-factors-in-mfa/) | 凭据窃取 |
| **软件和固件更新** | 已知漏洞 |
| [**防火墙和防病毒软件**](/recommendations/anti-virus) | 恶意软件 |
| **隐私设置** | 公开暴露 |
| [**安全教育**](/articles/what-is-a-common-indicator-of-a-phishing-attempt/) | 网络钓鱼和社会工程 |

> **提示：**将威胁模型保存在私密且加密的位置。文档列出了你的资产和薄弱环节，因此泄露后本身也会成为攻击目标。

这些措施简单，因为它们有效。攻击者指望人们跳过这些措施。

______

## 步骤 7：检查并更新

随着生活和周围威胁发生变化，模型也会过时。请定期复查，并在重大事件后更新。

- **保持了解。**通过 [SecurityWeek](https://www.securityweek.com/) 和 [Krebs on Security](https://krebsonsecurity.com/) 等来源关注新攻击和诈骗。
- **监测新兴威胁。**关注 [MITRE ATT&CK](https://attack.mitre.org/) 和 [CISA](https://www.cisa.gov/cybersecurity) 发布的新攻击技术。
- **重新评估新技术。**添加设备、应用或服务前，查看其安全和隐私记录。
- **关注法规。**查看 [GDPR](https://gdpr.eu/what-is-gdpr/) 和 [CCPA](https://oag.ca.gov/privacy/ccpa) 中影响你数据的规定。
- **定期评估风险。**重新执行步骤 1 到 6，查找缺口和过时的控制措施。

______

## 下一步

只有采取行动，威胁模型才有用。把模型转化为实际措施：

- [创建强且唯一的密码](/articles/how-to-create-strong-passwords/)，并存入密码管理器。
- [了解多因素认证的因素](/articles/what-are-the-diferent-kinds-of-factors-in-mfa/)，并在所有账户启用 2FA。
- [学会识别网络钓鱼](/articles/what-is-a-common-indicator-of-a-phishing-attempt/)，在点击前先检查。
- [查看防病毒和终端保护方案](/recommendations/anti-virus)。

然后安排三个月后的复查。持续更新的模型胜过被搁置的完美模型。
