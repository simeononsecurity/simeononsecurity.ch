**Python में सुरक्षित कोडिंग मानकों के सर्वोत्तम तरीके**

### 1. इनपुट का सत्यापन करें

उपयोगकर्ता का इनपुट अक्सर सुरक्षा जोखिमों का बड़ा स्रोत होता है। **इनपुट सत्यापन** यह जाँचता है कि उपयोगकर्ता का इनपुट अपेक्षित मानदंडों पर खरा उतरता है और एप्लिकेशन में उपयोग के लिए सुरक्षित है।

उदाहरण के लिए, क्रेडिट कार्ड नंबर में केवल अंक होने चाहिए, विशेष चिह्न नहीं। इनपुट जाँचने के लिए डेवलपर `isdigit()` जैसे अंतर्निहित फ़ंक्शन या रेगुलर एक्सप्रेशन इस्तेमाल कर सकते हैं।

```python
import re

def validate_input(input_string):
    """
    रेगुलर एक्सप्रेशन से इनपुट सत्यापित करने वाला फ़ंक्शन।
    """
    pattern = r"^[0-9]+$"
    if re.match(pattern, input_string):
        return True
    else:
        return False
```

### 2. असुरक्षित फ़ंक्शन इस्तेमाल करने से बचें

Python में कुछ फ़ंक्शन सावधानी से इस्तेमाल न किए जाएँ तो सुरक्षा समस्याएँ पैदा कर सकते हैं। `exec()`, `eval()` और `pickle` जैसे फ़ंक्शन हमलावरों को दुर्भावनापूर्ण कोड चलाने दे सकते हैं। डेवलपरों को **इन फ़ंक्शनों से बचना** चाहिए, या इनका उपयोग केवल ज़रूरत पड़ने पर, इनपुट पैरामीटर सीमित करके करना चाहिए।

उदाहरण के लिए, स्ट्रिंग को पूर्णांक में बदलने के लिए `eval()` के बजाय `int()` इस्तेमाल करें।

```py
# eval फ़ंक्शन इस्तेमाल करने के बजाय
x = eval('10')

# int फ़ंक्शन इस्तेमाल करें
x = int('10')
```

### 3. क्रिप्टोग्राफी लाइब्रेरी इस्तेमाल करें

[cryptography](https://pypi.org/project/cryptography/) और [PyCryptodome](https://pypi.org/project/pycryptodome/) जैसी **क्रिप्टोग्राफी लाइब्रेरी** एन्क्रिप्शन और डिक्रिप्शन का सुरक्षित तरीका देती हैं। कमजोरियों की आशंका वाली अपनी एन्क्रिप्शन विधियाँ बनाने के बजाय इनका उपयोग करें।

उदाहरण के लिए, पासवर्ड एन्क्रिप्ट करने के लिए [cryptography](https://pypi.org/project/cryptography/) लाइब्रेरी ऐसे इस्तेमाल करें:

```py
from cryptography.fernet import Fernet

def encrypt_password(password):
    """
    cryptography लाइब्रेरी से पासवर्ड एन्क्रिप्ट करने वाला फ़ंक्शन।
    """
    key = Fernet.generate_key()
    f = Fernet(key)
    encrypted_password = f.encrypt(password.encode('utf-8'))
    return encrypted_password

password = "उदाहरणपासवर्ड"
encrypted_password = encrypt_password(password)
```
`Fernet` ऑब्जेक्ट एक कुंजी बनाता है। `encrypt()` विधि इस कुंजी से पासवर्ड एन्क्रिप्ट करती है।

### 4. न्यूनतम विशेषाधिकार का सिद्धांत अपनाएँ

**न्यूनतम विशेषाधिकार का सिद्धांत** उपयोगकर्ताओं या प्रक्रियाओं की पहुँच को उनके काम के लिए आवश्यक न्यूनतम स्तर तक सीमित करता है। सुरक्षा उल्लंघन का असर घटाने के लिए डेवलपरों को कोड लिखते समय यह सिद्धांत अपनाना चाहिए।

उदाहरण के लिए, यदि एप्लिकेशन को डेटाबेस में केवल पढ़ने की पहुँच चाहिए, तो पूर्ण अनुमति वाले खाते की जगह केवल-पठन अनुमति वाला खाता इस्तेमाल करें। इससे हमलावर के एप्लिकेशन का दुरुपयोग करके डेटा बदलने या मिटाने का जोखिम घटता है।

### 5. लाइब्रेरी और फ्रेमवर्क अपडेट रखें

लाइब्रेरी और फ्रेमवर्क में ऐसी सुरक्षा कमजोरियाँ हो सकती हैं जिनका हमलावर फायदा उठाएँ। संभावित समस्याओं से बचने के लिए डेवलपरों को **लाइब्रेरी और फ्रेमवर्क के नवीनतम संस्करण इस्तेमाल करने** चाहिए।

उदाहरण के लिए, यदि एप्लिकेशन में [requests](https://pypi.org/project/requests/) जैसी तीसरे पक्ष की लाइब्रेरी में सुरक्षा कमजोरी हो, तो उसे ठीक करने वाले नवीनतम संस्करण पर अपडेट करें।

### 6. स्थैतिक कोड विश्लेषक इस्तेमाल करें

**स्थैतिक कोड विश्लेषक** कोड चलने से पहले उसमें संभावित सुरक्षा कमजोरियाँ खोज सकता है। तैनाती से पहले समस्याएँ खोजने और ठीक करने के लिए [Bandit](https://pypi.org/project/bandit/), [Pylint](https://pypi.org/project/pylint/) और [Pyflakes](https://pypi.org/project/pyflakes/) जैसे उपकरण इस्तेमाल करें।

उदाहरण के लिए, [Bandit](https://pypi.org/project/bandit/) Python कोड में संभावित सुरक्षा कमजोरियाँ खोजता है। यह कोड में सीधे लिखे पासवर्ड, SQL इंजेक्शन और असुरक्षित फ़ंक्शन के उपयोग जैसी समस्याएँ पहचान सकता है।

### 7. वेब एप्लिकेशन में सुरक्षित कोडिंग अभ्यास अपनाएँ

वेब एप्लिकेशन क्रॉस-साइट स्क्रिप्टिंग, SQL इंजेक्शन और कमांड इंजेक्शन जैसे सुरक्षा जोखिमों के संपर्क में रहते हैं। वेब एप्लिकेशन सुरक्षित रखने के लिए डेवलपरों को **सुरक्षित कोडिंग अभ्यास** जैसे इनपुट सत्यापन, आउटपुट एन्कोडिंग और पैरामीटरयुक्त क्वेरी अपनानी चाहिए।

उदाहरण के लिए, SQL क्वेरी लिखते समय उपयोगकर्ता का इनपुट जोड़ने के बजाय **पैरामीटरयुक्त क्वेरी** इस्तेमाल करें। इससे इनपुट को निष्पादन योग्य कोड नहीं, डेटा माना जाता है और SQL इंजेक्शन रुकता है।

```py
# इसके बजाय
query = "SELECT * FROM users WHERE username = '" + username + "';"

# पैरामीटरयुक्त क्वेरी इस्तेमाल करें
query = "SELECT * FROM users WHERE username = %s;"
cursor.execute(query, (username,))
```
डेवलपरों को **सभी उपयोगकर्ता इनपुट सत्यापित**, आउटपुट एन्कोड और नेटवर्क पर भेजे डेटा को एन्क्रिप्ट करने के लिए HTTPS इस्तेमाल करना चाहिए।

## Python फ्रेमवर्क के लिए सुरक्षित कोडिंग मानक

[Django](https://www.djangoproject.com/) और [Flask](https://flask.palletsprojects.com/) जैसे Python फ्रेमवर्क के अपने सुरक्षित कोडिंग मानक हैं। इनसे एप्लिकेशन बनाते समय डेवलपरों को ये मानक अपनाने चाहिए। कुछ मानक:

### 1. [Django](https://www.djangoproject.com/)

[Django](https://www.djangoproject.com/) Python का लोकप्रिय वेब फ्रेमवर्क है। इसके लिए सुरक्षित कोडिंग के कुछ मानक [Django](https://www.djangoproject.com/) के लिए:

- स्वयं प्रमाणीकरण प्रणाली बनाने के बजाय [Django](https://www.djangoproject.com/) की अंतर्निहित **प्रमाणीकरण प्रणाली** इस्तेमाल करें।
- स्वयं पासवर्ड हैशिंग विधि बनाने के बजाय [Django](https://www.djangoproject.com/) के अंतर्निहित **पासवर्ड हैशिंग फ़ंक्शन** इस्तेमाल करें।
- आउटपुट सुरक्षित रखने और क्रॉस-साइट स्क्रिप्टिंग कमजोरियों से बचाने के लिए [Django](https://www.djangoproject.com/) की **टेम्पलेट प्रणाली** इस्तेमाल करें।

उदाहरण के लिए, `django.contrib.auth.hashers` मॉड्यूल के `make_password()` फ़ंक्शन से [Django](https://www.djangoproject.com/) की अंतर्निहित पासवर्ड हैशिंग सुविधा इस्तेमाल करें।

```python
from [Django](https://www.djangoproject.com/).contrib.auth.hashers import make_password

password = "उदाहरणपासवर्ड"
hashed_password = make_password(password)
```

### 2. [Flask](https://flask.palletsprojects.com/)
[Flask](https://flask.palletsprojects.com/) Python का हल्का वेब फ्रेमवर्क है। इसके सुरक्षित कोडिंग मानक [Flask](https://flask.palletsprojects.com/):

- सुरक्षित सत्र प्रबंधन के लिए [Flask](https://flask.palletsprojects.com/) की अंतर्निहित **सत्र प्रबंधन प्रणाली** इस्तेमाल करें।
- आउटपुट सुरक्षित रखने और क्रॉस-साइट स्क्रिप्टिंग से बचाने के लिए [Flask](https://flask.palletsprojects.com/) के साथ [MarkupSafe](https://pypi.org/project/MarkupSafe/) इस्तेमाल करें।
- उपयोगकर्ता इनपुट सत्यापित करने और सुरक्षा जोखिम घटाने के लिए [Flask](https://flask.palletsprojects.com/) के साथ [WTForms](https://pypi.org/project/WTForms/) इस्तेमाल करें।
- सिग्नल सुरक्षित रूप से संभालने के लिए [Flask](https://flask.palletsprojects.com/) के साथ [Blinker](https://pypi.org/project/blinker/) इस्तेमाल करें।

उदाहरण के लिए, आउटपुट में HTML टैग से बचने के लिए [Flask](https://flask.palletsprojects.com/) के साथ [MarkupSafe](https://pypi.org/project/MarkupSafe/) इस्तेमाल करें।

```py
from markupsafe import escape

@app.route('/')
def hello():
    name = "<script>alert('xss');</script>"
    return 'नमस्ते, ' + escape(name)
```

## सीखी बातों को लागू करने के लिए अब क्या करें?

1. **जोखिम घटाने और संवेदनशील डेटा बचाने के लिए आज ही अपने Python कोड में ये तरीके लागू करें।** इनपुट सत्यापन, पासवर्ड हैशिंग और सत्र प्रबंधन जैसे जोखिम वाले हिस्से पहचानें। फिर Python के अंतर्निहित रेगुलर एक्सप्रेशन या [bcrypt](https://pypi.org/project/bcrypt/) जैसी सुरक्षित पासवर्ड हैशिंग लाइब्रेरी अपनाएँ।

2. **मौजूदा कोड में संभावित सुरक्षा कमजोरियाँ खोजें** और [Bandit](https://pypi.org/project/bandit/), [Pylint](https://pypi.org/project/pylint/) तथा [Pyflakes](https://pypi.org/project/pyflakes/) जैसे स्थैतिक विश्लेषक से समस्याएँ ठीक करें। ऐसे मुद्दों के लिए हाथ से कोड समीक्षा करें जिन्हें ये उपकरण नहीं पकड़ते। SQL इंजेक्शन, क्रॉस-साइट स्क्रिप्टिंग और इनपुट सत्यापन की गलतियाँ खोजें।

3. **नवीनतम सुरक्षा अभ्यास और उपकरणों से अपडेट रहें।** सुरक्षा ब्लॉग पढ़ें, सम्मेलनों में जाएँ और ऑनलाइन समुदायों में भाग लें। सुरक्षित नवीनतम संस्करण इस्तेमाल करने के लिए लाइब्रेरी और फ्रेमवर्क अपडेट रखें।

4. **ऑनलाइन समुदायों से जुड़ें और कार्यक्रमों में जाएँ** जहाँ Python की सुरक्षित कोडिंग पर विशेषज्ञों और अन्य डेवलपरों से सीख सकें। सुरक्षा चर्चा वाले मंच खोजें, अपना ज्ञान साझा करें और सम्मेलनों, वेबिनार तथा मीटअप में हिस्सा लें।

5. **अपनी टीम या सहकर्मियों के साथ ये अभ्यास साझा करें** ताकि सुरक्षा जागरूकता बढ़े और वे Python परियोजनाओं में सुरक्षित कोडिंग अपनाएँ। प्रशिक्षण आयोजित करें, संसाधन साझा करें और अपने कोड में इन तरीकों को लागू करके उदाहरण प्रस्तुत करें।

## निष्कर्ष

कोड को सुरक्षित, भरोसेमंद और कमजोरियों से मुक्त रखने के लिए सुरक्षित कोडिंग मानक आवश्यक हैं। Python लोकप्रिय प्रोग्रामिंग भाषा है और सुरक्षा जोखिम रोकने के लिए इसके डेवलपरों को सुरक्षित कोडिंग मानक अपनाने चाहिए। इनपुट सत्यापन, असुरक्षित फ़ंक्शन से बचना, क्रिप्टोग्राफी लाइब्रेरी इस्तेमाल करना और लाइब्रेरी व फ्रेमवर्क अपडेट रखना कोड की सुरक्षा में मदद करते हैं। Python फ्रेमवर्क इस्तेमाल करते समय उनके सुझाए सुरक्षित कोडिंग मानक अपनाएँ।

सुरक्षित कोडिंग मानक अपनाना एक सतत प्रक्रिया है, जिसके लिए नवीनतम सुरक्षा अभ्यास और उपकरणों से अपडेट रहना ज़रूरी है। विकास प्रक्रिया में इन मानकों को शामिल करने से सुरक्षा उल्लंघन का जोखिम घटता है और संवेदनशील डेटा सुरक्षित रहता है।
