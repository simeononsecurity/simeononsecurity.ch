**أفضل الممارسات لمعايير البرمجة الآمنة في Python**

### 1. التحقق من المدخلات

غالبًا ما تكون مدخلات المستخدم مصدرًا مهمًا للمخاطر الأمنية. **التحقق من المدخلات** هو فحص ما إذا كانت مدخلات المستخدم تستوفي المعايير المتوقعة وآمنة للاستخدام في التطبيق.

مثلًا، ينبغي ألا يحتوي رقم بطاقة ائتمان يدخله المستخدم إلا على أرقام، من دون محارف خاصة. للتحقق منه، يستطيع المطورون استخدام دوال مدمجة مثل `isdigit()` أو تعبيرات نمطية للتأكد من استيفائه للمعايير المتوقعة.

```python
import re

def validate_input(input_string):
    """
    دالة للتحقق من المدخلات باستخدام التعبيرات النمطية.
    """
    pattern = r"^[0-9]+$"
    if re.match(pattern, input_string):
        return True
    else:
        return False
```

### 2. تجنب استخدام الدوال غير الآمنة

تضم Python دوال قد تؤدي إلى مشكلات أمنية إذا لم تُستخدم بحذر. فقد تتيح دوال مثل `exec()` و`eval()` و`pickle` للمهاجمين تنفيذ شيفرة ضارة. ينبغي للمطورين **تجنب هذه الدوال** أو استخدامها بحذر، مع تقييد معاملات الإدخال وقصر استخدامها على الحالات الضرورية.

مثلًا، بدلًا من استخدام `eval()` لتحويل سلسلة نصية إلى عدد صحيح، ينبغي استخدام الدالة `int()`.

```py
# بدلاً من استخدام eval
x = eval('10')

# استخدم int
x = int('10')
```

### 3. استخدام مكتبات التشفير

توفر **مكتبات التشفير** مثل [cryptography](https://pypi.org/project/cryptography/) و[PyCryptodome](https://pypi.org/project/pycryptodome/) طريقة آمنة لتنفيذ عمليات التشفير وفك التشفير. استخدم هذه المكتبات بدل إنشاء أساليب تشفير مخصصة قد تكون عرضة للثغرات.

مثلًا، لتشفير كلمة مرور، استخدم مكتبة [cryptography](https://pypi.org/project/cryptography/) كما يلي:

```py
from cryptography.fernet import Fernet

def encrypt_password(password):
    """
    دالة لتشفير كلمة المرور باستخدام مكتبة التشفير.
    """
    key = Fernet.generate_key()
    f = Fernet(key)
    encrypted_password = f.encrypt(password.encode('utf-8'))
    return encrypted_password

password = "كلمةمرورمثال"
encrypted_password = encrypt_password(password)
```
ينشئ الكائن `Fernet` مفتاحًا يُستخدم لتشفير كلمة المرور بواسطة الطريقة `encrypt()`.

### 4. اتباع مبدأ أقل الصلاحيات

**مبدأ أقل الصلاحيات** هو ممارسة أمنية تحدّ وصول المستخدمين أو العمليات إلى الحد الأدنى اللازم لأداء وظائفهم. ينبغي للمطورين اتباع هذا المبدأ عند كتابة الشيفرة لتقليل أثر الاختراقات الأمنية.

مثلًا، إذا احتاج التطبيق إلى وصول للقراءة فقط إلى قاعدة بيانات، فاستخدم حساب قاعدة بيانات بصلاحيات القراءة فقط بدل حساب بصلاحيات كاملة. يقلل ذلك خطر استغلال مهاجم للتطبيق كي يعدّل البيانات أو يحذفها.

### 5. تحديث المكتبات وأطر العمل

قد تحتوي المكتبات وأطر العمل على ثغرات أمنية يستغلها المهاجمون. ينبغي للمطورين **تحديث المكتبات وأطر العمل** إلى أحدث إصدار لتجنب المشكلات الأمنية المحتملة.

مثلًا، إذا استخدم التطبيق مكتبة خارجية مثل [requests](https://pypi.org/project/requests/) وكانت فيها ثغرة أمنية، فينبغي للمطور تحديثها إلى أحدث إصدار يعالج الثغرة.

### 6. استخدام محلل للشيفرة الثابتة

**محلل الشيفرة الثابتة** أداة تحدد الثغرات الأمنية المحتملة في الشيفرة قبل تنفيذها. استخدم أدوات مثل [Bandit](https://pypi.org/project/bandit/) و[Pylint](https://pypi.org/project/pylint/) و[Pyflakes](https://pypi.org/project/pyflakes/) لاكتشاف المشكلات الأمنية وإصلاحها قبل النشر.

مثلًا، [Bandit](https://pypi.org/project/bandit/) محلل شائع يفحص شيفرة Python بحثًا عن ثغرات أمنية محتملة. يستطيع اكتشاف مشكلات مثل كلمات المرور المضمّنة مباشرة في الشيفرة وحقن SQL واستخدام الدوال غير الآمنة.

### 7. تطبيق ممارسات البرمجة الآمنة في تطبيقات الويب

تواجه تطبيقات الويب مخاطر أمنية متعددة، مثل البرمجة النصية عبر المواقع وحقن SQL وحقن الأوامر. ينبغي للمطورين **اتباع ممارسات البرمجة الآمنة** مثل التحقق من المدخلات وترميز المخرجات والاستعلامات ذات المعاملات لضمان أمن تطبيقات الويب.

مثلًا، عند كتابة استعلامات SQL، استخدم **الاستعلامات ذات المعاملات** بدل دمج مدخلات المستخدم في الاستعلام. تمنع هذه الاستعلامات هجمات حقن SQL لأنها تتعامل مع مدخلات المستخدم بوصفها بيانات لا شيفرة قابلة للتنفيذ.

```py
# بدلاً من ذلك
query = "SELECT * FROM users WHERE username = '" + username + "';"

# استخدم استعلاماً ذا معاملات
query = "SELECT * FROM users WHERE username = %s;"
cursor.execute(query, (username,))
```
ينبغي للمطورين أيضًا **التحقق من جميع مدخلات المستخدم**، وترميز المخرجات، واستخدام HTTPS لتشفير البيانات المنقولة عبر الشبكة.

## معايير البرمجة الآمنة لأطر Python

تتضمن أطر Python مثل [Django](https://www.djangoproject.com/) و[Flask](https://flask.palletsprojects.com/) معاييرها الخاصة للبرمجة الآمنة. ينبغي للمطورين اتباع هذه المعايير عند تطوير التطبيقات بهذه الأطر. فيما يلي بعض معايير البرمجة الآمنة لأطر Python:

### 1. [Django](https://www.djangoproject.com/)

[Django](https://www.djangoproject.com/) إطار ويب شائع لـ Python. فيما يلي بعض معايير البرمجة الآمنة الخاصة به الخاصة بـ [Django](https://www.djangoproject.com/):

- استخدم **نظام المصادقة** المدمج في [Django](https://www.djangoproject.com/) بدل إنشاء نظام مصادقة مخصص.
- استخدم **دوال تجزئة كلمات المرور** المدمجة في [Django](https://www.djangoproject.com/) بدل إنشاء أساليب مخصصة لتجزئة كلمات المرور.
- استخدم **نظام القوالب** في [Django](https://www.djangoproject.com/) لضمان أمن المخرجات وخلوها من ثغرات البرمجة النصية عبر المواقع.

مثلًا، لاستخدام دالة تجزئة كلمات المرور المدمجة في [Django](https://www.djangoproject.com/)، استخدم الدالة `make_password()` من الوحدة `django.contrib.auth.hashers`.

```python
from [Django](https://www.djangoproject.com/).contrib.auth.hashers import make_password

password = "كلمةمرورمثال"
hashed_password = make_password(password)
```

### 2. [Flask](https://flask.palletsprojects.com/)
[Flask](https://flask.palletsprojects.com/) إطار ويب مصغر لـ Python. فيما يلي بعض معايير البرمجة الآمنة الخاصة به [Flask](https://flask.palletsprojects.com/):

- استخدم **نظام إدارة الجلسات** المدمج في [Flask](https://flask.palletsprojects.com/) لضمان التعامل الآمن مع الجلسات.
- استخدم مكتبة [Flask](https://flask.palletsprojects.com/) مع [MarkupSafe](https://pypi.org/project/MarkupSafe/) لضمان أمن المخرجات وخلوها من ثغرات البرمجة النصية عبر المواقع.
- استخدم مكتبة [Flask](https://flask.palletsprojects.com/) مع [WTForms](https://pypi.org/project/WTForms/) للتحقق من مدخلات المستخدم والتأكد من خلوها من المخاطر الأمنية.
- استخدم مكتبة [Flask](https://flask.palletsprojects.com/) مع [Blinker](https://pypi.org/project/blinker/) للتعامل الآمن مع الإشارات.

مثلًا، لاستخدام [Flask](https://flask.palletsprojects.com/) مع [MarkupSafe](https://pypi.org/project/MarkupSafe/)، استورد المكتبة واستخدمها لتهريب وسوم HTML في المخرجات.

```py
from markupsafe import escape

@app.route('/')
def hello():
    name = "<script>alert('xss');</script>"
    return 'مرحباً، ' + escape(name)
```

2. **راجع قاعدة الشيفرة الحالية بحثًا عن ثغرات أمنية محتملة** واستخدم محللات الشيفرة الثابتة مثل [Bandit](https://pypi.org/project/bandit/) و[Pylint](https://pypi.org/project/pylint/) و[Pyflakes](https://pypi.org/project/pyflakes/) لاكتشاف المشكلات وإصلاحها. تستطيع أيضًا إجراء مراجعة يدوية لاكتشاف المشكلات التي قد لا ترصدها هذه المحللات. ابحث عن ثغرات شائعة مثل حقن SQL والبرمجة النصية عبر المواقع ومشكلات التحقق من المدخلات. بعد تحديد الثغرات المحتملة، طبّق أفضل الممارسات لمعالجتها.

3. **تابع أحدث ممارسات الأمن وأدواته** للحفاظ على أمن شيفرتك وخلوها من الثغرات. تابع مدونات الأمن، واحضر المؤتمرات، وشارك في المجتمعات عبر الإنترنت لمواكبة أحدث الاتجاهات والممارسات. حدّث المكتبات وأطر العمل باستمرار لضمان استخدام إصدارات آمنة حديثة.

4. **انضم إلى المجتمعات عبر الإنترنت واحضر الفعاليات** للتعلم من الخبراء والمطورين الآخرين عن ممارسات البرمجة الآمنة في Python. ابحث عن مجتمعات ومنتديات تناقش فيها المشكلات الأمنية وتتعلّم الاتجاهات الجديدة وتشارك خبرتك. واحضر مؤتمرات وندوات عبر الإنترنت ولقاءات للتعلم من خبراء الأمن والمطورين.

5. **شارك أفضل الممارسات هذه مع فريقك أو زملائك** لتعزيز الوعي الأمني وتشجيع اعتماد البرمجة الآمنة في مشاريع Python. نظّم جلسات تدريب أمنيًا، وشارك المقالات والموارد عن البرمجة الآمنة، وكن قدوة بتطبيق هذه الممارسات في مشاريعك. يساعد تعزيز الوعي الأمني على حماية شيفرة فريقك من الثغرات.

## الخلاصة

تُعد معايير البرمجة الآمنة ضرورية لجعل الشيفرة آمنة وموثوقة وخالية من الثغرات. Python لغة برمجة شائعة، ويتطلب استخدامها اتباع معايير البرمجة الآمنة للحد من المخاطر الأمنية. تساعد ممارسات مثل التحقق من المدخلات وتجنب الدوال غير الآمنة واستخدام مكتبات التشفير وتحديث المكتبات وأطر العمل المطورين على حماية شيفرتهم. وعند استخدام أطر Python، ينبغي اتباع معايير البرمجة الآمنة التي يوصي بها الإطار.

اعتماد معايير البرمجة الآمنة عملية مستمرة تتطلب مواكبة أحدث ممارسات الأمن وأدواته. ومن خلال دمج هذه المعايير في عملية التطوير، يستطيع المطورون تقليل مخاطر الاختراق وحماية البيانات الحساسة.
