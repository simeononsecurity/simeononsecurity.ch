**Python-এ নিরাপদ কোডিং মানের সর্বোত্তম অনুশীলন**

### 1. ইনপুট যাচাই করুন

ব্যবহারকারীর ইনপুট প্রায়ই নিরাপত্তা ঝুঁকির একটি উল্লেখযোগ্য উৎস। **ইনপুট যাচাই** হলো ব্যবহারকারীর দেওয়া তথ্য প্রত্যাশিত মানদণ্ড পূরণ করে এবং অ্যাপ্লিকেশনে ব্যবহারের জন্য নিরাপদ কি না তা পরীক্ষা করা।

উদাহরণস্বরূপ, ব্যবহারকারী ক্রেডিট কার্ড নম্বর দিলে তাতে শুধু অঙ্ক থাকা উচিত, বিশেষ চিহ্ন নয়। ইনপুট যাচাই করতে ডেভেলপাররা `isdigit()`-এর মতো বিল্ট-ইন ফাংশন বা রেগুলার এক্সপ্রেশন ব্যবহার করে প্রত্যাশিত মানদণ্ড নিশ্চিত করতে পারেন।

```python
import re

def validate_input(input_string):
    """
    রেগুলার এক্সপ্রেশন দিয়ে ইনপুট যাচাই করার ফাংশন।
    """
    pattern = r"^[0-9]+$"
    if re.match(pattern, input_string):
        return True
    else:
        return False
```

### 2. অনিরাপদ ফাংশন ব্যবহার এড়িয়ে চলুন

Python-এ এমন কিছু ফাংশন আছে, যা সতর্কভাবে ব্যবহার না করলে নিরাপত্তা সমস্যা তৈরি করতে পারে। `exec()`, `eval()` ও `pickle` আক্রমণকারীকে ক্ষতিকর কোড চালানোর সুযোগ দিতে পারে। ডেভেলপারদের **এসব ফাংশন এড়িয়ে চলা** উচিত, অথবা ইনপুট সীমাবদ্ধ করে এবং একান্ত প্রয়োজনেই ব্যবহার করে সতর্ক থাকা উচিত।

যেমন, স্ট্রিংকে পূর্ণসংখ্যায় রূপান্তর করতে `eval()`-এর বদলে `int()` ব্যবহার করুন।

```py
# eval ফাংশন ব্যবহারের বদলে
x = eval('10')

# int ফাংশন ব্যবহার করুন
x = int('10')
```

### 3. ক্রিপ্টোগ্রাফি লাইব্রেরি ব্যবহার করুন

[cryptography](https://pypi.org/project/cryptography/) ও [PyCryptodome](https://pypi.org/project/pycryptodome/)-এর মতো **ক্রিপ্টোগ্রাফি লাইব্রেরি** এনক্রিপশন ও ডিক্রিপশনের নিরাপদ উপায় দেয়। দুর্বল হতে পারে এমন নিজস্ব এনক্রিপশন পদ্ধতি তৈরির বদলে এসব লাইব্রেরি ব্যবহার করুন।

যেমন, পাসওয়ার্ড এনক্রিপ্ট করতে [cryptography](https://pypi.org/project/cryptography/) লাইব্রেরি এভাবে ব্যবহার করুন:

```py
from cryptography.fernet import Fernet

def encrypt_password(password):
    """
    ক্রিপ্টোগ্রাফি লাইব্রেরি দিয়ে পাসওয়ার্ড এনক্রিপ্ট করার ফাংশন।
    """
    key = Fernet.generate_key()
    f = Fernet(key)
    encrypted_password = f.encrypt(password.encode('utf-8'))
    return encrypted_password

password = "উদাহরণপাসওয়ার্ড"
encrypted_password = encrypt_password(password)
```
`Fernet` অবজেক্ট একটি কী তৈরি করে। `encrypt()` পদ্ধতি দিয়ে পাসওয়ার্ড এনক্রিপ্ট করতে এই কী ব্যবহৃত হয়।

### 4. সর্বনিম্ন অধিকারের নীতি অনুসরণ করুন

**সর্বনিম্ন অধিকারের নীতি** হলো ব্যবহারকারী বা প্রক্রিয়াকে কাজ সম্পাদনের জন্য যতটুকু প্রবেশাধিকার দরকার, ততটুকুতেই সীমিত রাখার নিরাপত্তা অনুশীলন। নিরাপত্তা লঙ্ঘনের প্রভাব কমাতে কোড লেখার সময় ডেভেলপারদের এই নীতি অনুসরণ করা উচিত।

যেমন, কোনো অ্যাপ্লিকেশনের ডেটাবেসে শুধু পড়ার অধিকার লাগলে পূর্ণ অনুমতিযুক্ত অ্যাকাউন্টের বদলে শুধু-পঠন অনুমতিযুক্ত অ্যাকাউন্ট ব্যবহার করুন। এতে আক্রমণকারী অ্যাপ্লিকেশন কাজে লাগিয়ে তথ্য বদলানো বা মুছে ফেলার ঝুঁকি কমে।

### 5. লাইব্রেরি ও ফ্রেমওয়ার্ক হালনাগাদ রাখুন

লাইব্রেরি ও ফ্রেমওয়ার্কে নিরাপত্তা দুর্বলতা থাকতে পারে, যা আক্রমণকারীরা কাজে লাগাতে পারে। সম্ভাব্য নিরাপত্তা সমস্যা এড়াতে ডেভেলপারদের **লাইব্রেরি ও ফ্রেমওয়ার্কের সর্বশেষ সংস্করণ ব্যবহার করা** উচিত।

যেমন, অ্যাপ্লিকেশনে [requests](https://pypi.org/project/requests/)-এর মতো তৃতীয় পক্ষের লাইব্রেরিতে দুর্বলতা থাকলে, সেটি সমাধান করা সর্বশেষ সংস্করণে হালনাগাদ করুন।

### 6. স্ট্যাটিক কোড বিশ্লেষক ব্যবহার করুন

**স্ট্যাটিক কোড বিশ্লেষক** এমন একটি সরঞ্জাম, যা কোড চালানোর আগেই সম্ভাব্য নিরাপত্তা দুর্বলতা শনাক্ত করতে পারে। নিরাপত্তা সমস্যা খুঁজে বের করে প্রকাশের আগে ঠিক করতে [Bandit](https://pypi.org/project/bandit/), [Pylint](https://pypi.org/project/pylint/) ও [Pyflakes](https://pypi.org/project/pyflakes/)-এর মতো সরঞ্জাম ব্যবহার করুন।

যেমন, [Bandit](https://pypi.org/project/bandit/) একটি জনপ্রিয় স্ট্যাটিক বিশ্লেষক, যা Python কোডে সম্ভাব্য নিরাপত্তা দুর্বলতা খোঁজে। এটি কোডে লেখা পাসওয়ার্ড, SQL ইনজেকশন এবং অনিরাপদ ফাংশনের ব্যবহার শনাক্ত করতে পারে।

### 7. ওয়েব অ্যাপ্লিকেশনে নিরাপদ কোডিং অনুশীলন করুন

ওয়েব অ্যাপ্লিকেশন ক্রস-সাইট স্ক্রিপ্টিং, SQL ইনজেকশন ও কমান্ড ইনজেকশনের মতো নিরাপত্তা ঝুঁকিতে থাকে। ওয়েব অ্যাপ্লিকেশন নিরাপদ রাখতে ডেভেলপারদের **নিরাপদ কোডিং অনুশীলন** যেমন ইনপুট যাচাই, আউটপুট এনকোডিং ও প্যারামিটারযুক্ত কোয়েরি অনুসরণ করা উচিত।

যেমন, SQL কোয়েরি লেখার সময় ব্যবহারকারীর ইনপুট জুড়ে দেওয়ার বদলে **প্যারামিটারযুক্ত কোয়েরি** ব্যবহার করুন। এতে ইনপুটকে চালানোর মতো কোড নয়, ডেটা হিসেবে বিবেচনা করা হয় এবং SQL ইনজেকশন ঠেকানো যায়।

```py
# এর বদলে
query = "SELECT * FROM users WHERE username = '" + username + "';"

# প্যারামিটারযুক্ত কোয়েরি ব্যবহার করুন
query = "SELECT * FROM users WHERE username = %s;"
cursor.execute(query, (username,))
```
ডেভেলপারদের **সব ব্যবহারকারী ইনপুট যাচাই**, আউটপুট এনকোড এবং নেটওয়ার্কে পাঠানো তথ্য এনক্রিপ্ট করতে HTTPS ব্যবহার করা উচিত।

## Python ফ্রেমওয়ার্কের নিরাপদ কোডিং মান

[Django](https://www.djangoproject.com/) ও [Flask](https://flask.palletsprojects.com/)-এর মতো Python ফ্রেমওয়ার্কের নিজস্ব নিরাপদ কোডিং মান আছে। এসব দিয়ে অ্যাপ্লিকেশন তৈরি করলে ডেভেলপারদের সংশ্লিষ্ট মান অনুসরণ করা উচিত। Python ফ্রেমওয়ার্কের কয়েকটি নিরাপদ কোডিং মান:

### 1. [Django](https://www.djangoproject.com/)

[Django](https://www.djangoproject.com/) Python-এর একটি জনপ্রিয় ওয়েব ফ্রেমওয়ার্ক। এর কয়েকটি নিরাপদ কোডিং মান [Django](https://www.djangoproject.com/)-এর জন্য:

- নিজস্ব প্রমাণীকরণ ব্যবস্থা তৈরির বদলে [Django](https://www.djangoproject.com/)-এর বিল্ট-ইন **প্রমাণীকরণ ব্যবস্থা** ব্যবহার করুন।
- নিজস্ব পাসওয়ার্ড হ্যাশিং পদ্ধতির বদলে [Django](https://www.djangoproject.com/)-এর বিল্ট-ইন **পাসওয়ার্ড হ্যাশিং ফাংশন** ব্যবহার করুন।
- আউটপুট নিরাপদ ও ক্রস-সাইট স্ক্রিপ্টিং দুর্বলতামুক্ত রাখতে [Django](https://www.djangoproject.com/)-এর **টেমপ্লেট ব্যবস্থা** ব্যবহার করুন।

যেমন, বিল্ট-ইন পাসওয়ার্ড হ্যাশিং ফাংশন ব্যবহার করতে `django.contrib.auth.hashers` মডিউলের `make_password()` ফাংশন ব্যবহার করুন। [Django](https://www.djangoproject.com/)

```python
from [Django](https://www.djangoproject.com/).contrib.auth.hashers import make_password

password = "উদাহরণপাসওয়ার্ড"
hashed_password = make_password(password)
```

### 2. [Flask](https://flask.palletsprojects.com/)
[Flask](https://flask.palletsprojects.com/) Python-এর একটি ক্ষুদ্র ওয়েব ফ্রেমওয়ার্ক। এর কয়েকটি নিরাপদ কোডিং মান [Flask](https://flask.palletsprojects.com/):

- সেশন নিরাপদে পরিচালনা করতে [Flask](https://flask.palletsprojects.com/)-এর বিল্ট-ইন **সেশন ব্যবস্থাপনা ব্যবস্থা** ব্যবহার করুন।
- আউটপুট নিরাপদ ও ক্রস-সাইট স্ক্রিপ্টিং দুর্বলতামুক্ত রাখতে [Flask](https://flask.palletsprojects.com/)-এর সঙ্গে [MarkupSafe](https://pypi.org/project/MarkupSafe/) লাইব্রেরি ব্যবহার করুন।
- ব্যবহারকারীর ইনপুট যাচাই ও নিরাপত্তা ঝুঁকি থেকে মুক্ত রাখতে [Flask](https://flask.palletsprojects.com/)-এর সঙ্গে [WTForms](https://pypi.org/project/WTForms/) ব্যবহার করুন।
- সিগন্যাল নিরাপদে পরিচালনা করতে [Flask](https://flask.palletsprojects.com/)-এর সঙ্গে [Blinker](https://pypi.org/project/blinker/) ব্যবহার করুন।

যেমন, আউটপুট থেকে HTML ট্যাগ এস্কেপ করতে [Flask](https://flask.palletsprojects.com/)-এর সঙ্গে [MarkupSafe](https://pypi.org/project/MarkupSafe/) ব্যবহার করুন।

```py
from markupsafe import escape

@app.route('/')
def hello():
    name = "<script>alert('xss');</script>"
    return 'নমস্কার, ' + escape(name)
```

## শেখা জ্ঞান কাজে লাগিয়ে এখন কী করবেন?

1. **নিরাপত্তা ঝুঁকি কমাতে ও সংবেদনশীল তথ্য রক্ষা করতে আজই Python কোডে এসব অনুশীলন প্রয়োগ শুরু করুন।** ইনপুট যাচাই, পাসওয়ার্ড হ্যাশিং ও সেশন ব্যবস্থাপনার মতো নিরাপত্তা ঝুঁকিপূর্ণ অংশ আগে শনাক্ত করুন। এরপর Python-এর বিল্ট-ইন রেগুলার এক্সপ্রেশন দিয়ে ইনপুট যাচাই বা [bcrypt](https://pypi.org/project/bcrypt/)-এর মতো নিরাপদ পাসওয়ার্ড হ্যাশিং লাইব্রেরি ব্যবহার করুন।

2. **বিদ্যমান কোডে সম্ভাব্য নিরাপত্তা দুর্বলতা খুঁজে দেখুন** এবং [Bandit](https://pypi.org/project/bandit/), [Pylint](https://pypi.org/project/pylint/) ও [Pyflakes](https://pypi.org/project/pyflakes/)-এর মতো স্ট্যাটিক বিশ্লেষক দিয়ে সমস্যা শনাক্ত ও ঠিক করুন। এসব সরঞ্জামে ধরা না পড়া সমস্যা খুঁজতে হাতে কোড পর্যালোচনাও করুন। SQL ইনজেকশন, ক্রস-সাইট স্ক্রিপ্টিং ও ইনপুট যাচাইয়ের ত্রুটির মতো পরিচিত দুর্বলতা দেখুন।

3. **সর্বশেষ নিরাপত্তা অনুশীলন ও সরঞ্জাম সম্পর্কে হালনাগাদ থাকুন**। নিরাপত্তা ব্লগ অনুসরণ করুন, সম্মেলনে যোগ দিন এবং অনলাইন কমিউনিটিতে অংশ নিন। নিরাপদ সংস্করণ ব্যবহার করতে লাইব্রেরি ও ফ্রেমওয়ার্ক হালনাগাদ রাখুন।

4. **অনলাইন কমিউনিটিতে যোগ দিন এবং অনুষ্ঠানে অংশ নিন** যেখানে Python-এর নিরাপদ কোডিং সম্পর্কে বিশেষজ্ঞ ও অন্যান্য ডেভেলপারের কাছ থেকে শিখতে পারবেন। নিরাপত্তা নিয়ে আলোচনা ও অভিজ্ঞতা ভাগ করার ফোরাম খুঁজুন। সম্মেলন, ওয়েবিনার ও মিটআপে যোগ দিয়ে নিরাপত্তা বিশেষজ্ঞদের কাছ থেকে শিখুন।

5. **নিরাপত্তা সচেতনতা বাড়াতে আপনার দল বা সহকর্মীদের সঙ্গে এসব অনুশীলন ভাগ করুন** এবং তাঁদের Python প্রকল্পে নিরাপদ কোডিং গ্রহণে উৎসাহ দিন। নিরাপত্তা প্রশিক্ষণের আয়োজন করুন, নিরাপদ কোডিংয়ের নিবন্ধ ও সংস্থান ভাগ করুন এবং নিজের প্রকল্পে অনুশীলনগুলো প্রয়োগ করে উদাহরণ তৈরি করুন।

## উপসংহার

কোড নিরাপদ, নির্ভরযোগ্য ও দুর্বলতামুক্ত রাখতে নিরাপদ কোডিং মান জরুরি। Python একটি জনপ্রিয় প্রোগ্রামিং ভাষা, তাই নিরাপত্তা ঝুঁকি ঠেকাতে ডেভেলপারদের নিরাপদ কোডিং মান অনুসরণ করতে হয়। ইনপুট যাচাই, অনিরাপদ ফাংশন এড়ানো, ক্রিপ্টোগ্রাফি লাইব্রেরি ব্যবহার এবং লাইব্রেরি ও ফ্রেমওয়ার্ক হালনাগাদ রাখার মতো অনুশীলনে কোড সুরক্ষিত থাকে। Python ফ্রেমওয়ার্ক ব্যবহারে সংশ্লিষ্ট ফ্রেমওয়ার্কের সুপারিশ করা নিরাপদ কোডিং মান অনুসরণ করুন।

নিরাপদ কোডিং মান গ্রহণ একটি চলমান প্রক্রিয়া। এর জন্য সর্বশেষ নিরাপত্তা অনুশীলন ও সরঞ্জাম সম্পর্কে হালনাগাদ থাকতে হয়। উন্নয়ন প্রক্রিয়ায় এসব মান যুক্ত করলে ডেভেলপাররা নিরাপত্তা লঙ্ঘনের ঝুঁকি কমাতে ও সংবেদনশীল তথ্য রক্ষা করতে পারেন।
