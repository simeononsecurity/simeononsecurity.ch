Linux نظام تشغيل شائع يستخدمه الأفراد والشركات على حد سواء. ورغم اعتباره غالبًا أكثر أمانًا من أنظمة التشغيل الأخرى بسبب طبيعته مفتوحة المصدر، فإنه لا يزال يحتاج إلى تقوية مناسبة لضمان سلامة النظام والبيانات التي يحتوي عليها. نستعرض في هذا المقال إرشادات عامة لما ينبغي فعله وما يجب تجنبه للمساعدة في الحفاظ على أمان نظام Linux.

## ما ينبغي فعله:

### حافظ على تحديث النظام

يُعد إبقاء [نظام Linux](https://simeononsecurity.com/articles/how-do-i-learn-linux/) محدّثًا أمرًا أساسيًا للحفاظ على أمانه. تساعد التحديثات المنتظمة على إصلاح الثغرات الأمنية والأخطاء، مما يبقي النظام محميًا من الهجمات المحتملة. فيما يلي أمثلة على تحديث نظام Linux باستخدام مدير الحزم **apt-get** أو **yum**:

#### تحديث Ubuntu باستخدام apt-get

لتحديث نظام Ubuntu باستخدام **apt-get**، افتح نافذة الطرفية واكتب:
```bash
sudo apt-get update
```

سيُنزّل ذلك أحدث قوائم الحزم من مستودعات Ubuntu. بعد اكتمال الأمر، يمكنك تثبيت التحديثات المتاحة باستخدام الأمر التالي:

```bash
sudo apt-get upgrade

```

سيُنزّل هذا الأمر التحديثات المتاحة للنظام ويثبتها.

### تحديث CentOS باستخدام yum

لتحديث نظام CentOS باستخدام **yum**، افتح نافذة طرفية واكتب:

```bash
sudo yum update
```

سيُنزّل هذا الأمر التحديثات المتاحة ويثبتها. ويمكنك أيضًا استخدام الأمر التالي لتنظيف الحزم القديمة أو غير المستخدمة:

```bash
sudo yum autoremove
```

سيزيل هذا الأمر الحزم التي لم تعد مطلوبة على النظام.

احرص على التحقق من التحديثات وتثبيتها بانتظام لضمان أمان نظام Linux واستقراره.


### استخدم جدار حماية

يُعد جدار الحماية إجراءً أمنيًا أساسيًا لأي نظام Linux، إذ يساعد على الحماية من الوصول غير المصرح به والتهديدات السيبرانية الأخرى. إليك طريقة استخدام جدار الحماية **ufw** في نظام Linux:

#### تثبيت ufw وتفعيله في الأنظمة المبنية على Ubuntu

لتثبيت **ufw** وتفعيله، افتح نافذة طرفية واكتب:

```bash
sudo apt install ufw -y
sudo ufw allow ssh
sudo ufw enable
```

للسماح بحركة مرور HTTP الواردة (المنفذ 80):

```bash
sudo ufw allow http
```

لحظر حركة المرور الواردة من عنوان IP محدد:

```bash
sudo ufw deny from <ip_address>
```

لحذف قاعدة:
```bash
sudo ufw delete <rule_number>
```

يمكنك عرض قواعد **ufw** الحالية بكتابة:

```bash
sudo ufw status
```


سيعرض ذلك القواعد الحالية وحالتها.

راجع قواعد **ufw** وحدّثها بانتظام للتأكد من حماية النظام من التهديدات المحتملة.


#### تثبيت firewalld وتفعيله في الأنظمة المبنية على CentOS

لتثبيت جدار الحماية الافتراضي في CentOS، وهو **firewalld**، وتفعيله، استخدم الأوامر التالية:

```bash
sudo yum install firewalld
sudo systemctl enable firewalld
sudo systemctl start firewalld
```

سيثبت هذا **firewalld** ويفعّله على النظام.

#### إعداد قواعد firewalld في الأنظمة المبنية على CentOS

بعد تفعيل **firewalld**، يمكنك إعداد قواعده للسماح بحركة المرور الواردة والصادرة أو حظرها. إليك بعض الأمثلة:

للسماح بحركة مرور SSH الواردة (المنفذ 22):

```bash
sudo firewall-cmd --permanent --add-service=ssh
sudo firewall-cmd --reload
```

للسماح بحركة مرور HTTP الواردة (المنفذ 80):

```bash
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --reload
```

لحظر حركة المرور الواردة من عنوان IP محدد:

```bash
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="<ip_address>" reject'
sudo firewall-cmd --reload
```

لحذف قاعدة:

```bash
sudo firewall-cmd --permanent --remove-<type>=<rule>
sudo firewall-cmd --reload
```

يمكنك عرض قواعد **firewalld** الحالية بكتابة:

```bash
sudo firewall-cmd --list-all
```

سيعرض ذلك القواعد الحالية وحالتها.

راجع قواعد **firewalld** وحدّثها بانتظام للتأكد من أن نظامك

### فعّل SELinux أو AppArmor

SELinux (Linux المحسّن أمنيًا) وAppArmor وحدتا أمان تُستخدمان لفرض سياسات التحكم الإلزامي بالوصول في أنظمة Linux. تأتي معظم توزيعات Linux الحديثة مزودة بإحدى هاتين الوحدتين، ويمكن تفعيلهما وإعدادهما لتعزيز أمان النظام.

#### تفعيل SELinux في الأنظمة المبنية على CentOS

للتحقق مما إذا كان SELinux مفعّلًا في نظامك، شغّل الأمر التالي:

```bash
sestatus
```

إذا لم يكن SELinux مثبتًا، فيمكنك تثبيته باستخدام الأمر التالي:

```bash
sudo yum install selinux-policy selinux-policy-targeted
```

لتفعيل SELinux، عدّل ملف **/etc/selinux/config** واضبط المتغير **SELINUX** على **enforcing**:

```bash
sudo nano /etc/selinux/config
```
**غيّر SELINUX=enforcing**
```
SELINUX=enforcing
```

احفظ الملف واخرج منه باستخدام CTRL+X ثم Y ثم Enter، وبعد ذلك أعد تشغيل النظام.

#### تفعيل AppArmor في الأنظمة المبنية على Ubuntu

للتحقق مما إذا كان AppArmor مفعّلًا، شغّل الأمر التالي:
```bash
sudo apparmor_status
```


إذا لم يكن AppArmor مثبتًا، فيمكنك تثبيته باستخدام الأمر التالي:
```bash
sudo apt-get install apparmor
```

لتفعيل AppArmor، عدّل ملف **/etc/default/grub** وأضف المعامل **security=apparmor** إلى المتغير **GRUB_CMDLINE_LINUX**:

```bash
sudo nano /etc/default/grub
```
**أضف security=apparmor**
```bash
GRUB_CMDLINE_LINUX="... security=apparmor"
```

احفظ الملف واخرج منه باستخدام CTRL+X ثم Y ثم Enter، ثم شغّل الأمر التالي لتحديث إعدادات محمّل الإقلاع:

```bash
sudo update-grub
```

أعد تشغيل النظام أخيرًا.

بعد تفعيل SELinux أو AppArmor، يمكنك إعداد سياساتهما لتقييد امتيازات العمليات والحد من وصولها إلى موارد النظام. يساعد ذلك على تقليل الأثر المحتمل للهجوم الناجح وتعزيز الأمان العام للنظام.


### إعداد سياسات كلمات المرور

يُعد إعداد سياسات كلمات المرور خطوة مهمة لتقوية أمان نظام Linux. وبفرض متطلبات قوية لكلمات المرور، يمكنك حماية حسابات المستخدمين من الهجمات المحتملة. إليك طريقة إعداد سياسات كلمات المرور في نظام Linux:

#### إعداد سياسات كلمات المرور في Ubuntu

لإعداد سياسات كلمات المرور في Ubuntu، يمكنك استخدام الوحدة **pam_pwquality**. توفر هذه الوحدة مجموعة من فحوص قوة كلمة المرور لفرض السياسات. لتثبيت الوحدة **pam_pwquality**، افتح نافذة طرفية واكتب:

```bash
sudo apt-get install libpam-pwquality
```

بعد تثبيت الوحدة، يمكنك ضبط إعداداتها بتحرير ملف **/etc/pam.d/common-password**. مثلًا، لفرض حد أدنى لطول كلمة المرور قدره 8 أحرف واشتراط حرف كبير وآخر صغير ورقم ورمز خاص، أضف السطر التالي إلى الملف:

```bash
password requisite pam_pwquality.so minlen=8 ucredit=-1 lcredit=-1 dcredit=-1 ocredit=-1
```

يمكنك أيضًا ضبط إعدادات أخرى، مثل الحد الأقصى لعمر كلمة المرور، بإضافة أسطر إلى الملف.

#### إعداد سياسات كلمات المرور في CentOS

لإعداد سياسات كلمات المرور في CentOS، يمكنك استخدام أداة **authconfig**. توفر هذه الأداة خيارات لضبط السياسات. مثلًا، لفرض حد أدنى للطول يبلغ 8 أحرف واشتراط حرف كبير وآخر صغير ورقم ورمز خاص، استخدم الأمر التالي:

```bash
sudo authconfig --passalgo=sha512 --update --enablereqlower --enablerequpper --enablereqdigit --enablereqother --passminlen=8
```

سيحدّث هذا الأمر الملفين **/etc/pam.d/system-auth** و**/etc/pam.d/password-auth** لفرض سياسات كلمات المرور المحددة.

راجع سياسات كلمات المرور وحدّثها بانتظام لضمان فعاليتها في مواجهة الهجمات المحتملة.


### راقب سجلات النظام

تُعد مراقبة سجلات النظام جزءًا مهمًا من الحفاظ على أمان Linux. تسجل هذه السجلات نشاط النظام، مثل محاولات تسجيل الدخول الفاشلة والأخطاء والأحداث المهمة الأخرى، وتوفر مؤشرات مفيدة على التهديدات الأمنية المحتملة أو المشكلات التي تتطلب الانتباه. إليك طريقة مراقبة سجلات النظام:

#### استخدام الأمر journalctl

في معظم توزيعات Linux الحديثة، يمكنك استخدام الأمر **journalctl** لعرض سجلات النظام. ويوفر هذا الأمر خيارات متعددة لتصفية إدخالات السجل والبحث فيها.

لعرض جميع إدخالات السجل، شغّل الأمر التالي:

```bash
sudo journalctl
```

سيعرض هذا الأمر جميع إدخالات السجل، مع ظهور أحدثها في الأسفل.

لتصفية السجلات حسب وحدة محددة، مثل خدمة أو عملية، استخدم الخيار **-u** متبوعًا باسم الوحدة. مثلًا، لعرض سجلات خدمة **sshd**، شغّل الأمر التالي:
```bash
sudo journalctl -u sshd
```


لتصفية السجلات حسب نطاق زمني، استخدم الخيارين **--since** و**--until** متبوعين بطابع زمني أو فترة زمنية. مثلًا، لعرض سجلات الساعة الماضية، شغّل الأمر التالي:

```bash
sudo journalctl --since "1 hour ago"
```

#### استخدام أداة لإدارة السجلات

في الأنظمة الكبيرة أو الأكثر تعقيدًا، قد يكون من المفيد استخدام أداة لإدارة السجلات لجمع سجلات النظام وتحليلها. توفر هذه الأدوات ميزات متقدمة، مثل المراقبة الفورية وتجميع السجلات وتحليلها، وتساعد على اكتشاف التهديدات الأمنية المحتملة والاستجابة لها بكفاءة أكبر.

تشمل أمثلة أدوات إدارة سجلات Linux ما يلي:

- **Logwatch**: أداة بسيطة لتحليل السجلات ترسل ملخصات يومية لسجلات النظام عبر البريد الإلكتروني
- **Logrotate**: أداة تدوّر ملفات السجل وتضغطها تلقائيًا لتوفير مساحة القرص
- **منظومة ELK**: أداة شائعة مفتوحة المصدر لإدارة السجلات، تجمع Elasticsearch وLogstash وKibana لمراقبة السجلات وتحليلها في الوقت الفعلي

راجع سجلات النظام وحللها بانتظام لاكتشاف التهديدات الأمنية المحتملة والاستجابة لها في الوقت المناسب.

## ما يجب تجنبه:

### لا تستخدم كلمات مرور ضعيفة

استخدام كلمات مرور ضعيفة خطأ شائع قد يجعل نظام Linux عرضة للهجمات. يستطيع المهاجمون تخمين كلمات المرور اعتمادًا على كلمات أو أسماء أو تواريخ شائعة. استخدم كلمات مرور قوية وفريدة يصعب تخمينها.

يمكنك إنشاء كلمات مرور قوية بمزيج من الأحرف الكبيرة والصغيرة والأرقام والرموز الخاصة. ومن الأفضل أيضًا استخدام [مدير كلمات المرور](https://simeononsecurity.com/articles/bitwarden-and-keepassxc-vs-the-rest/) لإنشاء كلمات معقدة وتخزينها بأمان. كما تساعد [مديرو كلمات المرور](https://simeononsecurity.com/articles/bitwarden-and-keepassxc-vs-the-rest/) على تذكر كلمات مرورك وتجنب استخدام كلمة المرور نفسها لحسابات متعددة.

### لا تسمح بدخول SSH إلى حساب root

السماح بدخول SSH إلى حساب root خطر أمني قد يمنح المهاجمين سيطرة كاملة على نظام Linux. استخدم بدلًا من ذلك حسابًا غير root لتسجيل الدخول، ثم ارفع الامتيازات باستخدام الأمر **sudo**. يحد ذلك من الأثر المحتمل للهجوم عبر تقييد امتيازات حسابات المستخدمين.

### لا تثبّت برامج غير ضرورية

قد يؤدي تثبيت برامج غير ضرورية إلى زيادة سطح الهجوم في نظام Linux وجعله أكثر عرضة للهجمات. ثبّت البرامج اللازمة فقط وأزل غير الضروري منها، لتقليل عدد الثغرات المحتملة والحد من خطر نجاح الهجوم.

### لا تستخدم برامج قديمة

قد تترك البرامج القديمة نظامك عرضة لهجمات تستغل ثغرات معروفة. استخدم أحدث إصدارات البرامج وحدّثها بانتظام للحفاظ على الأمان. فهذا يرقّع الثغرات المعروفة ويحمي النظام من الهجمات المحتملة.

## الخلاصة

تقوية نظام Linux أمر أساسي لضمان أمانه وحماية البيانات التي يحتوي عليها. باتباع ما ينبغي فعله وما يجب تجنبه في هذا المقال، يمكنك اتخاذ خطوات مهمة لتأمين النظام وتقليل خطر التهديدات السيبرانية. حافظ على تحديث النظام، واستخدم جدار حماية، واضبط سياسات كلمات المرور، وراقب سجلات النظام. وتجنب كلمات المرور الضعيفة وتعطيل التحديثات التلقائية والسماح بدخول SSH إلى حساب root وتثبيت البرامج غير الضرورية واستخدام البرامج القديمة. تساعد هذه الممارسات الأمنية على إبقاء نظام Linux آمنًا ومحميًا.
