Linux একটি জনপ্রিয় অপারেটিং সিস্টেম, যা ব্যক্তি ও ব্যবসা প্রতিষ্ঠান উভয়েই ব্যবহার করে। ওপেন-সোর্স হওয়ার কারণে একে প্রায়ই অন্য অপারেটিং সিস্টেমের চেয়ে নিরাপদ মনে করা হয়, তবু সিস্টেম ও এতে থাকা ডেটা সুরক্ষিত রাখতে যথাযথভাবে শক্তিশালী করা দরকার। এই নিবন্ধে Linux সিস্টেম সুরক্ষিত রাখতে সহায়ক কিছু সাধারণ করণীয় ও বর্জনীয় বিষয় তুলে ধরা হয়েছে।

## করণীয়:

### সিস্টেম আপডেট রাখুন

আপনার [Linux সিস্টেম](https://simeononsecurity.com/articles/how-do-i-learn-linux/) হালনাগাদ রাখা নিরাপত্তা বজায় রাখার জন্য অত্যন্ত জরুরি। নিয়মিত আপডেটে নিরাপত্তা দুর্বলতা ও ত্রুটি ঠিক হয়, ফলে সম্ভাব্য আক্রমণ থেকে সিস্টেম সুরক্ষিত থাকে। **apt-get** বা **yum** প্যাকেজ ম্যানেজার দিয়ে Linux সিস্টেম আপডেট করার কয়েকটি উদাহরণ নিচে দেওয়া হলো:

#### apt-get দিয়ে Ubuntu আপডেট করা

**apt-get** ব্যবহার করে Ubuntu সিস্টেম আপডেট করতে টার্মিনাল খুলে লিখুন:
```bash
sudo apt-get update
```

এতে Ubuntu প্যাকেজ রিপোজিটরি থেকে সর্বশেষ প্যাকেজ তালিকা ডাউনলোড হবে। কমান্ড শেষ হলে নিচের কমান্ড দিয়ে উপলভ্য আপডেট ইনস্টল করতে পারবেন:

```bash
sudo apt-get upgrade

```

এতে সিস্টেমের উপলভ্য আপডেট ডাউনলোড ও ইনস্টল হবে।

### yum দিয়ে CentOS আপডেট করা

**yum** দিয়ে CentOS সিস্টেম আপডেট করতে টার্মিনাল খুলে লিখুন:

```bash
sudo yum update
```

এতে উপলভ্য আপডেট ডাউনলোড ও ইনস্টল হবে। পুরোনো বা অব্যবহৃত প্যাকেজ পরিষ্কার করতেও নিচের কমান্ড ব্যবহার করতে পারেন:

```bash
sudo yum autoremove
```

এতে সিস্টেমে আর প্রয়োজন নেই এমন প্যাকেজ মুছে যাবে।

নিরাপত্তা ও স্থিতিশীলতা বজায় রাখতে নিয়মিত Linux সিস্টেমের আপডেট পরীক্ষা করে ইনস্টল করুন।


### ফায়ারওয়াল ব্যবহার করুন

যেকোনো Linux সিস্টেমের জন্য ফায়ারওয়াল একটি জরুরি নিরাপত্তা ব্যবস্থা। এটি অননুমোদিত প্রবেশ ও অন্যান্য সাইবার হুমকি থেকে রক্ষা করতে সাহায্য করে। Linux-এ **ufw** ফায়ারওয়াল ব্যবহারের পদ্ধতি নিচে দেওয়া হলো:

#### Ubuntu-ভিত্তিক সিস্টেমে ufw ইনস্টল ও চালু করা

**ufw** ইনস্টল ও চালু করতে টার্মিনাল খুলে লিখুন:

```bash
sudo apt install ufw -y
sudo ufw allow ssh
sudo ufw enable
```

আগত HTTP ট্র্যাফিক (পোর্ট 80) অনুমোদন করতে:

```bash
sudo ufw allow http
```

নির্দিষ্ট IP ঠিকানা থেকে আসা ট্র্যাফিক বন্ধ করতে:

```bash
sudo ufw deny from <ip_address>
```

কোনো নিয়ম মুছতে:
```bash
sudo ufw delete <rule_number>
```

বর্তমান **ufw** নিয়ম দেখতে লিখুন:

```bash
sudo ufw status
```


এতে বর্তমান নিয়ম ও তাদের অবস্থা দেখা যাবে।

সম্ভাব্য হুমকি থেকে সিস্টেম সুরক্ষিত রাখতে নিয়মিত **ufw** নিয়ম পর্যালোচনা ও হালনাগাদ করুন।


#### CentOS-ভিত্তিক সিস্টেমে firewalld ইনস্টল ও চালু করা

CentOS-এর ডিফল্ট ফায়ারওয়াল **firewalld** ইনস্টল ও চালু করতে নিচের কমান্ডগুলো ব্যবহার করুন:

```bash
sudo yum install firewalld
sudo systemctl enable firewalld
sudo systemctl start firewalld
```

এতে **firewalld** ইনস্টল হয়ে সিস্টেমে চালু হবে।

#### CentOS-ভিত্তিক সিস্টেমে firewalld নিয়ম কনফিগার করা

**firewalld** চালু হলে আগত ও বহির্গামী ট্র্যাফিক অনুমোদন বা বন্ধ করার নিয়ম কনফিগার করতে পারেন। কয়েকটি উদাহরণ:

আগত SSH ট্র্যাফিক (পোর্ট 22) অনুমোদন করতে:

```bash
sudo firewall-cmd --permanent --add-service=ssh
sudo firewall-cmd --reload
```

আগত HTTP ট্র্যাফিক (পোর্ট 80) অনুমোদন করতে:

```bash
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --reload
```

নির্দিষ্ট IP ঠিকানা থেকে আসা ট্র্যাফিক বন্ধ করতে:

```bash
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="<ip_address>" reject'
sudo firewall-cmd --reload
```

কোনো নিয়ম মুছতে:

```bash
sudo firewall-cmd --permanent --remove-<type>=<rule>
sudo firewall-cmd --reload
```

বর্তমান **firewalld** নিয়ম দেখতে লিখুন:

```bash
sudo firewall-cmd --list-all
```

এতে বর্তমান নিয়ম ও তাদের অবস্থা দেখা যাবে।

সিস্টেমটি সুরক্ষিত আছে তা নিশ্চিত করতে নিয়মিত **firewalld** নিয়ম পর্যালোচনা ও হালনাগাদ করুন

### SELinux অথবা AppArmor চালু করুন

SELinux (Security-Enhanced Linux) এবং AppArmor হলো দুটি নিরাপত্তা মডিউল, যা Linux সিস্টেমে বাধ্যতামূলক প্রবেশাধিকার নিয়ন্ত্রণ নীতি প্রয়োগ করতে ব্যবহার করা যায়। অধিকাংশ আধুনিক Linux ডিস্ট্রিবিউশনে এর এক বা উভয়টি থাকে। সিস্টেমের নিরাপত্তা বাড়াতে এগুলো চালু ও কনফিগার করা যায়।

#### CentOS-ভিত্তিক সিস্টেমে SELinux চালু করা

আপনার সিস্টেমে SELinux চালু আছে কি না দেখতে নিচের কমান্ড চালান:

```bash
sestatus
```

SELinux ইনস্টল না থাকলে নিচের কমান্ড দিয়ে ইনস্টল করতে পারেন:

```bash
sudo yum install selinux-policy selinux-policy-targeted
```

SELinux চালু করতে **/etc/selinux/config** ফাইল সম্পাদনা করে **SELINUX** ভেরিয়েবলের মান **enforcing** করুন:

```bash
sudo nano /etc/selinux/config
```
**SELINUX=enforcing সেট করুন**
```
SELINUX=enforcing
```

CTRL+X, তারপর Y ও Enter চেপে ফাইল সংরক্ষণ করে বেরিয়ে আসুন, এরপর সিস্টেম রিবুট করুন।

#### Ubuntu-ভিত্তিক সিস্টেমে AppArmor চালু করা

AppArmor চালু আছে কি না দেখতে নিচের কমান্ড চালান:
```bash
sudo apparmor_status
```


AppArmor ইনস্টল না থাকলে নিচের কমান্ড দিয়ে ইনস্টল করতে পারেন:
```bash
sudo apt-get install apparmor
```

AppArmor চালু করতে **/etc/default/grub** ফাইল সম্পাদনা করে **GRUB_CMDLINE_LINUX** ভেরিয়েবলে **security=apparmor** প্যারামিটার যোগ করুন:

```bash
sudo nano /etc/default/grub
```
**security=apparmor যোগ করুন**
```bash
GRUB_CMDLINE_LINUX="... security=apparmor"
```

CTRL+X, তারপর Y ও Enter চেপে ফাইল সংরক্ষণ করে বেরিয়ে আসুন। এরপর বুটলোডার কনফিগারেশন হালনাগাদ করতে নিচের কমান্ড চালান:

```bash
sudo update-grub
```

শেষে সিস্টেম রিবুট করুন।

SELinux বা AppArmor চালু হলে, প্রসেসের বিশেষাধিকার সীমিত করতে এবং সিস্টেম রিসোর্সে তাদের প্রবেশ নিয়ন্ত্রণ করতে নীতি কনফিগার করতে পারেন। এতে সফল আক্রমণের সম্ভাব্য প্রভাব কমে এবং সামগ্রিক নিরাপত্তা বাড়ে।


### পাসওয়ার্ড নীতি কনফিগার করুন

Linux সিস্টেমের নিরাপত্তা জোরদার করতে পাসওয়ার্ড নীতি কনফিগার করা গুরুত্বপূর্ণ। শক্তিশালী পাসওয়ার্ডের শর্ত প্রয়োগ করলে ব্যবহারকারীর অ্যাকাউন্ট নিরাপদ রাখা যায় এবং সম্ভাব্য আক্রমণ থেকে রক্ষা করা যায়। Linux-এ পাসওয়ার্ড নীতি কনফিগার করার পদ্ধতি নিচে দেওয়া হলো:

#### Ubuntu-তে পাসওয়ার্ড নীতি কনফিগার করা

Ubuntu-তে পাসওয়ার্ড নীতি কনফিগার করতে **pam_pwquality** মডিউল ব্যবহার করতে পারেন। এটি পাসওয়ার্ডের শক্তি যাচাই করে নীতি প্রয়োগে সাহায্য করে। **pam_pwquality** ইনস্টল করতে টার্মিনাল খুলে লিখুন:

```bash
sudo apt-get install libpam-pwquality
```

মডিউল ইনস্টল হলে **/etc/pam.d/common-password** ফাইল সম্পাদনা করে সেটিংস কনফিগার করতে পারেন। যেমন, সর্বনিম্ন দৈর্ঘ্য ৮ অক্ষর নির্ধারণ এবং অন্তত একটি বড় হাতের অক্ষর, একটি ছোট হাতের অক্ষর, একটি সংখ্যা ও একটি বিশেষ চিহ্ন বাধ্যতামূলক করতে ফাইলে নিচের লাইন যোগ করুন:

```bash
password requisite pam_pwquality.so minlen=8 ucredit=-1 lcredit=-1 dcredit=-1 ocredit=-1
```

সর্বোচ্চ পাসওয়ার্ড মেয়াদের মতো অন্যান্য সেটিংসও ফাইলে লাইন যোগ করে কনফিগার করতে পারেন।

#### CentOS-এ পাসওয়ার্ড নীতি কনফিগার করা

CentOS-এ পাসওয়ার্ড নীতি কনফিগার করতে **authconfig** টুল ব্যবহার করতে পারেন। এটি নীতি কনফিগার করার বিভিন্ন বিকল্প দেয়। যেমন, ন্যূনতম দৈর্ঘ্য ৮ অক্ষর এবং অন্তত একটি বড় হাতের অক্ষর, একটি ছোট হাতের অক্ষর, একটি সংখ্যা ও একটি বিশেষ চিহ্ন বাধ্যতামূলক করতে নিচের কমান্ড ব্যবহার করুন:

```bash
sudo authconfig --passalgo=sha512 --update --enablereqlower --enablerequpper --enablereqdigit --enablereqother --passminlen=8
```

নির্দিষ্ট পাসওয়ার্ড নীতি প্রয়োগ করতে এটি সিস্টেমের **/etc/pam.d/system-auth** এবং **/etc/pam.d/password-auth** ফাইল আপডেট করবে।

সম্ভাব্য আক্রমণের বিরুদ্ধে কার্যকর রাখতে নিয়মিত পাসওয়ার্ড নীতি পর্যালোচনা ও হালনাগাদ করুন।


### সিস্টেম লগ পর্যবেক্ষণ করুন

Linux সিস্টেমের নিরাপত্তা বজায় রাখতে সিস্টেম লগ পর্যবেক্ষণ জরুরি। ব্যর্থ লগইন প্রচেষ্টা, ত্রুটি এবং অন্যান্য গুরুত্বপূর্ণ ঘটনা সহ সিস্টেমের কার্যকলাপ লগে নথিভুক্ত হয়। সম্ভাব্য নিরাপত্তা হুমকি বা মনোযোগের প্রয়োজন এমন সমস্যা বোঝার জন্য এগুলো মূল্যবান তথ্য দেয়। লগ পর্যবেক্ষণের পদ্ধতি নিচে দেওয়া হলো:

#### journalctl কমান্ড ব্যবহার করা

অধিকাংশ আধুনিক Linux ডিস্ট্রিবিউশনে সিস্টেম লগ দেখতে **journalctl** কমান্ড ব্যবহার করা যায়। লগ এন্ট্রি ফিল্টার ও খোঁজার জন্য এতে নানা বিকল্প রয়েছে।

সব লগ এন্ট্রি দেখতে সরাসরি নিচের কমান্ড চালান:

```bash
sudo journalctl
```

এতে সব লগ এন্ট্রি দেখা যাবে, সর্বশেষ এন্ট্রিগুলো তালিকার নিচে থাকবে।

কোনো নির্দিষ্ট ইউনিট, যেমন সার্ভিস বা প্রসেস, অনুযায়ী লগ ফিল্টার করতে ইউনিটের নামের পরে **-u** বিকল্প ব্যবহার করুন। যেমন, **sshd** সার্ভিসের লগ দেখতে নিচের কমান্ড চালান:
```bash
sudo journalctl -u sshd
```


নির্দিষ্ট সময়সীমা অনুযায়ী লগ ফিল্টার করতে টাইমস্ট্যাম্প বা সময়সীমার পরে **--since** এবং **--until** বিকল্প ব্যবহার করুন। যেমন, গত এক ঘণ্টার লগ দেখতে নিচের কমান্ড চালান:

```bash
sudo journalctl --since "1 hour ago"
```

#### লগ ব্যবস্থাপনার টুল ব্যবহার করা

বড় বা জটিল সিস্টেমে লগ সংগ্রহ ও বিশ্লেষণের জন্য লগ ব্যবস্থাপনার টুল কাজে আসতে পারে। এগুলো রিয়েল-টাইম পর্যবেক্ষণ, লগ একত্রীকরণ ও বিশ্লেষণের মতো উন্নত সুবিধা দেয় এবং সম্ভাব্য নিরাপত্তা হুমকি দ্রুত শনাক্ত ও মোকাবিলায় সাহায্য করে।

Linux-এর লগ ব্যবস্থাপনা টুলের উদাহরণ:

- **Logwatch**: সহজ লগ বিশ্লেষণ টুল, যা প্রতিদিন ইমেইলে সিস্টেম লগের সারাংশ পাঠায়
- **Logrotate**: ডিস্কের জায়গা বাঁচাতে লগ ফাইল স্বয়ংক্রিয়ভাবে ঘোরায় ও সংকুচিত করে
- **ELK স্ট্যাক**: জনপ্রিয় ওপেন-সোর্স লগ ব্যবস্থাপনা টুল, যা রিয়েল-টাইম লগ পর্যবেক্ষণ ও বিশ্লেষণের জন্য Elasticsearch, Logstash এবং Kibana একত্র করে

সম্ভাব্য নিরাপত্তা হুমকি সময়মতো শনাক্ত ও মোকাবিলা করতে নিয়মিত সিস্টেম লগ পর্যালোচনা ও বিশ্লেষণ করুন।

## বর্জনীয়:

### দুর্বল পাসওয়ার্ড ব্যবহার করবেন না

দুর্বল পাসওয়ার্ড ব্যবহার সাধারণ ভুল, যা Linux সিস্টেমকে আক্রমণের ঝুঁকিতে ফেলতে পারে। আক্রমণকারীরা সাধারণ শব্দ, নাম বা তারিখের ভিত্তিতে পাসওয়ার্ড অনুমান করার টুল ব্যবহার করতে পারে। সহজে অনুমান করা যায় না এমন শক্তিশালী ও অনন্য পাসওয়ার্ড ব্যবহার করুন।

বড় ও ছোট হাতের অক্ষর, সংখ্যা এবং বিশেষ চিহ্ন মিলিয়ে শক্তিশালী পাসওয়ার্ড তৈরি করুন। জটিল পাসওয়ার্ড নিরাপদে তৈরি ও সংরক্ষণ করতে [পাসওয়ার্ড ম্যানেজার](https://simeononsecurity.com/articles/bitwarden-and-keepassxc-vs-the-rest/) ব্যবহার করাও ভালো। [পাসওয়ার্ড ম্যানেজার](https://simeononsecurity.com/articles/bitwarden-and-keepassxc-vs-the-rest/) পাসওয়ার্ড মনে রাখতে এবং একাধিক অ্যাকাউন্টে একই পাসওয়ার্ড ব্যবহার এড়াতেও সাহায্য করে।

### root অ্যাকাউন্টের SSH প্রবেশাধিকার দেবেন না

root অ্যাকাউন্টে SSH প্রবেশাধিকার দিলে আক্রমণকারীরা আপনার Linux সিস্টেমের সম্পূর্ণ নিয়ন্ত্রণ পেতে পারে। এর বদলে, root নয় এমন ব্যবহারকারী অ্যাকাউন্ট দিয়ে লগইন করুন এবং **sudo** কমান্ড ব্যবহার করে প্রয়োজনীয় বিশেষাধিকার বাড়ান। ব্যবহারকারী অ্যাকাউন্টের বিশেষাধিকার সীমিত রাখলে আক্রমণের সম্ভাব্য প্রভাব কমে।

### অপ্রয়োজনীয় সফটওয়্যার ইনস্টল করবেন না

অপ্রয়োজনীয় সফটওয়্যার ইনস্টল করলে Linux সিস্টেমের আক্রমণ-পরিসর বাড়ে এবং এটি আক্রমণের ঝুঁকিতে পড়ে। প্রয়োজনীয় সফটওয়্যারই ইনস্টল করুন এবং অপ্রয়োজনীয়গুলো সরিয়ে ফেলুন। এতে সম্ভাব্য দুর্বলতার সংখ্যা ও সফল আক্রমণের ঝুঁকি কমে।

### পুরোনো সফটওয়্যার ব্যবহার করবেন না

পুরোনো সফটওয়্যার পরিচিত দুর্বলতা কাজে লাগানো আক্রমণের মুখে সিস্টেমকে ঝুঁকিতে ফেলতে পারে। নিরাপত্তা বজায় রাখতে সফটওয়্যারের সর্বশেষ সংস্করণ ব্যবহার করুন এবং নিয়মিত আপডেট করুন। এতে পরিচিত দুর্বলতা বন্ধ হয় এবং সিস্টেম সম্ভাব্য আক্রমণ থেকে সুরক্ষিত থাকে।

## উপসংহার

Linux সিস্টেমকে শক্তিশালী করা এর নিরাপত্তা ও এতে থাকা ডেটা সুরক্ষার জন্য অত্যন্ত জরুরি। এই নিবন্ধের করণীয় ও বর্জনীয় বিষয় মেনে সিস্টেম সুরক্ষিত করতে এবং সাইবার হুমকির ঝুঁকি কমাতে পারেন। সিস্টেম আপডেট রাখুন, ফায়ারওয়াল ব্যবহার করুন, পাসওয়ার্ড নীতি কনফিগার করুন এবং লগ পর্যবেক্ষণ করুন। দুর্বল পাসওয়ার্ড, স্বয়ংক্রিয় আপডেট বন্ধ করা, root অ্যাকাউন্টে SSH প্রবেশাধিকার দেওয়া, অপ্রয়োজনীয় বা পুরোনো সফটওয়্যার ইনস্টল করা এড়িয়ে চলুন। এসব উত্তম নিরাপত্তা চর্চা Linux সিস্টেমকে নিরাপদ ও সুরক্ষিত রাখতে সাহায্য করবে।
