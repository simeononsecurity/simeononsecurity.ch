Linux — популярная операционная система, которой пользуются как частные лица, так и компании. Ее часто считают более безопасной, чем другие операционные системы, благодаря открытому исходному коду. Тем не менее систему и хранящиеся в ней данные необходимо надлежащим образом защищать. В этой статье собраны общие рекомендации о том, что следует и чего не следует делать для защиты Linux.

## Что следует делать:

### Регулярно обновляйте систему

Своевременное обновление [системы Linux](https://simeononsecurity.com/articles/how-do-i-learn-linux/) крайне важно для ее безопасности. Регулярные обновления устраняют уязвимости и ошибки, помогая защитить систему от возможных атак. Ниже приведены примеры обновления Linux с помощью менеджеров пакетов **apt-get** и **yum**:

#### Обновление Ubuntu с помощью apt-get

Чтобы обновить Ubuntu с помощью **apt-get**, откройте терминал и введите:
```bash
sudo apt-get update
```

Будут загружены последние списки пакетов из репозиториев Ubuntu. После завершения команды установите доступные обновления:

```bash
sudo apt-get upgrade

```

Команда загрузит и установит все доступные обновления для системы.

### Обновление CentOS с помощью yum

Чтобы обновить CentOS с помощью **yum**, откройте терминал и введите:

```bash
sudo yum update
```

Команда загрузит и установит доступные обновления. Для удаления старых или неиспользуемых пакетов также можно выполнить:

```bash
sudo yum autoremove
```

Эта команда удалит пакеты, которые больше не нужны системе.

Регулярно проверяйте и устанавливайте обновления Linux, чтобы поддерживать безопасность и стабильность системы.


### Используйте брандмауэр

Брандмауэр — важная мера защиты любой системы Linux. Он помогает предотвратить несанкционированный доступ и другие киберугрозы. Вот как использовать брандмауэр **ufw**:

#### Установка и включение ufw в системах на базе Ubuntu

Чтобы установить и включить **ufw**, откройте терминал и введите:

```bash
sudo apt install ufw -y
sudo ufw allow ssh
sudo ufw enable
```

Чтобы разрешить входящий HTTP-трафик (порт 80):

```bash
sudo ufw allow http
```

Чтобы заблокировать входящий трафик с определенного IP-адреса:

```bash
sudo ufw deny from <ip_address>
```

Чтобы удалить правило:
```bash
sudo ufw delete <rule_number>
```

Текущие правила **ufw** можно посмотреть командой:

```bash
sudo ufw status
```


Команда покажет действующие правила и их состояние.

Регулярно проверяйте и обновляйте правила **ufw**, чтобы система оставалась защищенной от потенциальных угроз.


#### Установка и включение firewalld в системах на базе CentOS

Чтобы установить и включить стандартный брандмауэр CentOS, **firewalld**, выполните следующие команды:

```bash
sudo yum install firewalld
sudo systemctl enable firewalld
sudo systemctl start firewalld
```

Команды установят **firewalld** и включат его в системе.

#### Настройка правил firewalld в системах на базе CentOS

После включения **firewalld** можно настроить правила для разрешения или блокировки входящего и исходящего трафика. Примеры:

Чтобы разрешить входящий SSH-трафик (порт 22):

```bash
sudo firewall-cmd --permanent --add-service=ssh
sudo firewall-cmd --reload
```

Чтобы разрешить входящий HTTP-трафик (порт 80):

```bash
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --reload
```

Чтобы заблокировать входящий трафик с определенного IP-адреса:

```bash
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="<ip_address>" reject'
sudo firewall-cmd --reload
```

Чтобы удалить правило:

```bash
sudo firewall-cmd --permanent --remove-<type>=<rule>
sudo firewall-cmd --reload
```

Текущие правила **firewalld** можно посмотреть командой:

```bash
sudo firewall-cmd --list-all
```

Команда покажет действующие правила и их состояние.

Регулярно проверяйте и обновляйте правила **firewalld**, чтобы система оставалась защищенной от потенциальных угроз.

### Включите SELinux или AppArmor

SELinux (Security-Enhanced Linux) и AppArmor — модули безопасности, позволяющие применять обязательные политики контроля доступа в Linux. В большинстве современных дистрибутивов Linux установлен SELinux или AppArmor. Их можно включить и настроить, чтобы повысить уровень защиты системы.

#### Включение SELinux в системах на базе CentOS

Чтобы проверить, включен ли SELinux, выполните:

```bash
sestatus
```

Если SELinux не установлен, установите его командой:

```bash
sudo yum install selinux-policy selinux-policy-targeted
```

Чтобы включить SELinux, измените файл **/etc/selinux/config** и задайте для переменной **SELINUX** значение **enforcing**:

```bash
sudo nano /etc/selinux/config
```
**Измените значение на SELINUX=enforcing**
```
SELINUX=enforcing
```

Сохраните файл и выйдите, нажав CTRL+X, затем Y и Enter. После этого перезагрузите систему.

#### Включение AppArmor в системах на базе Ubuntu

Чтобы проверить, включен ли AppArmor, выполните:
```bash
sudo apparmor_status
```


Если AppArmor не установлен, установите его командой:
```bash
sudo apt-get install apparmor
```

Чтобы включить AppArmor, измените файл **/etc/default/grub** и добавьте параметр **security=apparmor** в переменную **GRUB_CMDLINE_LINUX**:

```bash
sudo nano /etc/default/grub
```
**Добавьте параметр security=apparmor**
```bash
GRUB_CMDLINE_LINUX="... security=apparmor"
```

Сохраните файл и выйдите, нажав CTRL+X, затем Y и Enter. Затем обновите конфигурацию загрузчика командой:

```bash
sudo update-grub
```

В завершение перезагрузите систему.

После включения SELinux или AppArmor настройте политики, ограничивающие привилегии процессов и их доступ к системным ресурсам. Это поможет уменьшить возможный ущерб от успешной атаки и повысить общую безопасность системы.


### Настройте политику паролей

Настройка политики паролей — важный шаг для защиты Linux. Строгие требования к паролям помогают обезопасить учетные записи от атак. Ниже описана настройка политики паролей в Linux.

#### Настройка политики паролей в Ubuntu

В Ubuntu для этого можно использовать модуль **pam_pwquality**. Он проверяет надежность паролей и помогает применять заданные требования. Чтобы установить модуль, откройте терминал и введите:

```bash
sudo apt-get install libpam-pwquality
```

После установки модуля **pam_pwquality** измените файл **/etc/pam.d/common-password**, чтобы настроить модуль. Например, чтобы установить минимальную длину пароля в 8 символов и требовать хотя бы одну заглавную букву, одну строчную букву, одну цифру и один специальный символ, добавьте строку:

```bash
password requisite pam_pwquality.so minlen=8 ucredit=-1 lcredit=-1 dcredit=-1 ocredit=-1
```

В файл можно добавить и другие параметры, например максимальный срок действия пароля.

#### Настройка политики паролей в CentOS

В CentOS для настройки политики паролей можно использовать инструмент **authconfig**. Например, чтобы установить минимальную длину пароля в 8 символов и требовать заглавную и строчную буквы, цифру и специальный символ, выполните:

```bash
sudo authconfig --passalgo=sha512 --update --enablereqlower --enablerequpper --enablereqdigit --enablereqother --passminlen=8
```

Команда обновит файлы **/etc/pam.d/system-auth** и **/etc/pam.d/password-auth**, применив указанные требования к паролям.

Регулярно проверяйте и обновляйте политику паролей, чтобы она оставалась эффективной против потенциальных атак.


### Следите за системными журналами

Мониторинг системных журналов важен для защиты Linux. В журналах записываются события, например неудачные попытки входа, ошибки и другие важные действия. По ним можно выявить потенциальные угрозы и проблемы, требующие внимания. Вот как следить за журналами:

#### Команда journalctl

В большинстве современных дистрибутивов Linux для просмотра системных журналов используется команда **journalctl**. Она позволяет фильтровать и искать записи разными способами.

Чтобы просмотреть все записи, выполните:

```bash
sudo journalctl
```

Команда покажет все записи, самые новые будут внизу.

Чтобы отфильтровать записи по определенному модулю, например службе или процессу, используйте параметр **-u**, указав после него имя модуля. Например, чтобы посмотреть записи службы **sshd**, выполните:
```bash
sudo journalctl -u sshd
```


Для фильтрации по времени используйте параметры **--since** и **--until** со временной отметкой или диапазоном. Например, чтобы просмотреть записи за последний час, выполните:

```bash
sudo journalctl --since "1 hour ago"
```

#### Инструменты управления журналами

В крупных или сложных системах для сбора и анализа журналов может пригодиться специальный инструмент. Такие инструменты могут обеспечивать мониторинг в реальном времени, сбор записей из разных источников и анализ, помогая быстрее выявлять угрозы и реагировать на них.

Примеры инструментов для управления журналами Linux:

- **Logwatch**: простой инструмент анализа, который ежедневно отправляет сводку системных журналов по электронной почте
- **Logrotate**: автоматически ротирует и сжимает файлы журналов, экономя место на диске
- **стек ELK**: популярный инструмент с открытым исходным кодом, объединяющий Elasticsearch, Logstash и Kibana для мониторинга и анализа журналов в реальном времени

Регулярно проверяйте и анализируйте системные журналы, чтобы своевременно обнаруживать угрозы и реагировать на них.

## Чего не следует делать:

### Не используйте слабые пароли

Слабые пароли — распространенная ошибка, из-за которой система Linux может стать уязвимой для атак. Злоумышленники могут угадывать пароли по распространенным словам, именам или датам. Используйте надежные уникальные пароли, которые трудно подобрать.

Создавайте пароли из заглавных и строчных букв, цифр и специальных символов. Для создания и безопасного хранения сложных паролей также рекомендуется использовать [менеджер паролей](https://simeononsecurity.com/articles/bitwarden-and-keepassxc-vs-the-rest/). [Менеджеры паролей](https://simeononsecurity.com/articles/bitwarden-and-keepassxc-vs-the-rest/) помогают запоминать пароли и не использовать один пароль для разных учетных записей.

### Не разрешайте вход root по SSH

Разрешение входа root по SSH — риск для безопасности, который может дать злоумышленникам полный контроль над системой Linux. Вместо этого входите в систему под обычной учетной записью, а затем повышайте привилегии с помощью команды **sudo**. Ограничение привилегий учетных записей уменьшает возможный ущерб от атаки.

### Не устанавливайте ненужные программы

Установка ненужных программ увеличивает поверхность атаки Linux и делает систему более уязвимой. Устанавливайте только необходимые программы, а остальные удаляйте. Так вы уменьшите число потенциальных уязвимостей и риск успешной атаки.

### Не используйте устаревшее программное обеспечение

Устаревшее программное обеспечение может оставить систему уязвимой для атак, использующих уже известные уязвимости. Используйте актуальные версии и регулярно обновляйте программы. Это помогает устранять известные уязвимости и защищать систему от потенциальных атак.

## Заключение

Защита системы Linux крайне важна для безопасности самой системы и хранящихся в ней данных. Следуйте рекомендациям из этой статьи, чтобы повысить защиту и снизить риск киберугроз. Регулярно обновляйте систему, используйте брандмауэр, настройте политику паролей и следите за журналами. Не используйте слабые пароли, не отключайте автоматические обновления, не разрешайте вход root по SSH, не устанавливайте ненужные программы и не используйте устаревшее ПО. Эти рекомендации помогут поддерживать безопасность системы Linux.
