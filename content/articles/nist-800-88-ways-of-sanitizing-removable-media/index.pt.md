Mídias removíveis, como discos rígidos, unidades de estado sólido (SSD), unidades flash USB, CDs, DVDs e discos Blu-ray, são parte importante do mundo digital atual. Esses dispositivos são usados para armazenar e transferir dados confidenciais. Por isso, é preciso impedir que as informações neles contidas vazem ou sejam acessadas por pessoas não autorizadas. Este artigo apresenta os métodos aprovados pelo NIST para sanitizar todos os tipos de mídia removível.

## Por que sanitizar mídias removíveis?

**Sanitizar mídias removíveis é essencial porque os dados armazenados nelas podem ser recuperados com facilidade, mesmo depois de apagados.** Quando os dados são apagados, somente a referência a eles é removida. Os dados reais continuam no disco até serem sobrescritos. Isso permite que agentes mal-intencionados recuperem informações confidenciais usando programas de recuperação de dados.

## Tipos de destruição da NIST 800-88 Revision 1

O National Institute of Standards and Technology (NIST) publicou uma diretriz para sanitizar mídias removíveis, conhecida como NIST Special Publication 800-88 Revision 1. Ela descreve vários métodos, incluindo destruição física, Clear e Purge.

### Destruição física

**A destruição física é o método mais seguro para sanitizar mídias removíveis.** Esse método destrói fisicamente o dispositivo, tornando impossível recuperar os dados. É possível triturar, derreter ou pulverizar o dispositivo.

### Clear

Clear é o processo de sobrescrever os dados de um dispositivo com uma sequência de valores binários. É menos seguro que a destruição física, mas ainda é eficaz para sanitizar a maioria das mídias removíveis. A NIST 800-88 Revision 1 recomenda uma ferramenta de software que atenda aos padrões da especificação [5220.22-M](https://simeononsecurity.com/articles/dod-5220.22-m-data-sanitization-summarized/) do Departamento de Defesa dos EUA (DoD).

### Purge

Purge é o processo de sobrescrever os dados de um dispositivo várias vezes com um padrão de valores binários. É mais seguro que Clear e recomendado para sanitizar dados confidenciais. A NIST 800-88 Revision 1 recomenda uma ferramenta de software que atenda aos padrões da especificação [DoD 5220.22-M](https://simeononsecurity.com/articles/dod-5220.22-m-data-sanitization-summarized/).

## Conclusão

Em resumo, **sanitizar mídias removíveis é essencial para impedir que dados confidenciais armazenados nelas vazem ou sejam acessados por pessoas não autorizadas.** A NIST 800-88 Revision 1 apresenta diretrizes para sanitizar todos os tipos de mídia removível, incluindo discos rígidos, SSDs, unidades flash USB, CDs, DVDs e discos Blu-ray, por meio de destruição física, Clear e Purge. **A destruição física é o método mais seguro, mas Clear e Purge também são eficazes e oferecem um alto nível de segurança.**

**A sanitização de mídias removíveis é apenas uma parte de uma estratégia abrangente de segurança de dados.** Também é preciso adotar medidas como criptografia e armazenamento seguro para proteger dados confidenciais.
