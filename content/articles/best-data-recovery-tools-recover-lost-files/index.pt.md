## 5 melhores ferramentas de recuperação de dados para Linux

### TestDisk

**TestDisk** é um software de código aberto para recuperar partições perdidas e reparar sistemas de arquivos. Ele funciona em Linux, Windows e macOS.

Principais recursos:

- Recuperação de partições perdidas e reparo de sistemas de arquivos danificados.
- Suporte a NTFS, FAT32, exFAT, ext2, ext3, ext4 e outros.
- Linha de comando para usuários avançados e orientações passo a passo para iniciantes.

Consulte o [site oficial](https://www.cgsecurity.org/wiki/TestDisk) para informações e download.

### PhotoRec

**PhotoRec** é outro software de código aberto que recupera fotos, vídeos, documentos e arquivos compactados de diversos dispositivos.

Principais recursos:

- Suporte a muitos formatos e sistemas de arquivos.
- Opção para adicionar formatos personalizados.
- Linha de comando para usuários avançados.
- Compatibilidade com Linux, Windows e macOS.

Consulte o [site oficial](https://www.cgsecurity.org/wiki/PhotoRec) para informações e download.
