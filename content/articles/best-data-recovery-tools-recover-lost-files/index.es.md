## Introducción

Perder datos puede ser angustioso, sobre todo si se trata de archivos importantes. Hay herramientas fiables para recuperar información en distintos sistemas operativos. Esta lista presenta opciones para Android, Mac, Windows y Linux, junto con sus funciones principales, para ayudarte a elegir según tu situación.

## 5 mejores herramientas de recuperación de datos para Linux

### TestDisk

**TestDisk** es software de código abierto para recuperar particiones perdidas y reparar sistemas de archivos. Funciona en Linux, Windows y macOS.

Funciones principales:

- Recuperación de particiones y reparación de sistemas de archivos dañados.
- Compatibilidad con NTFS, FAT32, exFAT, ext2, ext3, ext4 y otros.
- Interfaz de línea de comandos para usuarios avanzados y guía paso a paso para principiantes.

Descarga TestDisk desde el [sitio oficial](https://www.cgsecurity.org/wiki/TestDisk).

### PhotoRec

**PhotoRec** es una herramienta de código abierto que recupera fotos, vídeos, documentos y archivos comprimidos de distintos dispositivos de almacenamiento.

Funciones principales:

- Compatibilidad con numerosos formatos y sistemas de archivos.
- Opción para agregar formatos personalizados.
- Interfaz de línea de comandos para usuarios avanzados.
- Compatibilidad con Linux, Windows y macOS.

Consulta información y descargas en el [sitio oficial](https://www.cgsecurity.org/wiki/PhotoRec).
