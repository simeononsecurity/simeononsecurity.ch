## I 5 migliori strumenti di recupero dati per Linux

### TestDisk

**TestDisk** è un software open source per recuperare partizioni perse e riparare file system. Supporta Linux, Windows e macOS.

Funzioni principali:

- Recupero di partizioni perse e riparazione di file system danneggiati.
- Supporto per NTFS, FAT32, exFAT, ext2, ext3, ext4 e altri file system.
- Interfaccia a riga di comando per utenti esperti e guida passo passo per principianti.

Per informazioni e download, visita il [sito ufficiale](https://www.cgsecurity.org/wiki/TestDisk).

### PhotoRec

**PhotoRec** è un altro strumento open source che recupera file persi, tra cui foto, video, documenti e archivi, da diversi dispositivi di archiviazione.

Funzioni principali:

- Supporto per numerosi formati e file system.
- Possibilità di aggiungere formati personalizzati.
- Interfaccia a riga di comando per utenti esperti.
- Compatibilità con Linux, Windows e macOS.

Trovi informazioni e download sul [sito ufficiale](https://www.cgsecurity.org/wiki/PhotoRec).
