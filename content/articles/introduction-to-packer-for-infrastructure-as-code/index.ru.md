**Введение в использование Packer для приложений инфраструктуры как кода**

**Packer**, популярный инструмент для создания **машинных образов** или **шаблонов виртуальных машин**, которые помогают развертывать одинаковые среды на разных платформах. Он автоматизирует создание образов для **AWS, Google Cloud Platform, Azure и VMware**. Packer, это инструмент с открытым исходным кодом, созданный HashiCorp, разработчиком таких популярных инструментов, как Vagrant, Consul и Terraform.

В этой статье вы познакомитесь с Packer и узнаете, как создавать с его помощью машинные образы для разных платформ. Мы также рассмотрим преимущества инструмента и несколько рекомендаций по его использованию.

## Что такое Packer?

Packer автоматизирует создание машинных образов для разных платформ. Это инструмент с открытым исходным кодом от HashiCorp, компании, создавшей также Vagrant, Consul и Terraform.

С помощью Packer разработчики создают машинные образы или шаблоны виртуальных машин для AWS, Google Cloud Platform, Azure и VMware. Эти образы позволяют развертывать одинаковые среды на разных платформах.

## Преимущества Packer

Packer дает несколько преимуществ:

- **Повторяемость**: создает машинные образы одинаковым способом при каждом запуске, обеспечивая повторяемость и согласованность сред.
- **Автоматизация**: автоматизирует создание образов, экономит время и снижает вероятность человеческой ошибки.
- **Поддержка нескольких платформ**: упрощает создание образов для разных сред.
- **Интеграция с другими инструментами**: работает с Ansible, Chef и Puppet, поэтому вы можете использовать уже знакомые средства.
- **Масштабируемость**: создает несколько машинных образов параллельно и помогает масштабировать процесс.

## Начало работы с Packer

Для начала скачайте и установите Packer. Он доступен для Windows, macOS и Linux.

Загрузите Packer с официального сайта: [https://www.packer.io/downloads](https://www.packer.io/downloads)

После установки вы сможете создавать машинные образы для разных платформ.

## Создание машинного образа с Packer

Чтобы создать машинный образ, задайте **шаблон**, описывающий его конфигурацию. Шаблон записывается в JSON и определяет шаги создания образа.

Ниже приведен пример шаблона Packer для создания машинного образа AWS:

```json
{
"builders": [{
"type": "amazon-ebs",
"access_key": "ACCESS_KEY",
"secret_key": "SECRET_KEY",
"region": "us-west-2",
"source_ami": "ami-0c55b159cbfafe1f0",
"instance_type": "t2.micro",
"ssh_username": "ubuntu",
"ami_name": "my-image-{{timestamp}}"
}]
}
```

В этом примере шаблон указывает Packer создать образ на базе Amazon EBS, используя AMI Ubuntu. Итоговый образ получит имя "my-image" с добавленной временной меткой.

После определения шаблона выполните команду `packer build`, чтобы создать машинный образ:

```bash
$ packer build template.json
```

### AMI AWS с provisioner Ansible
С помощью provisioner Ansible можно создать машинный образ AWS. Вот пример шаблона Packer:

```json
{
  "builders": [{
    "type": "amazon-ebs",
    "access_key": "ACCESS_KEY",
    "secret_key": "SECRET_KEY",
    "region": "us-west-2",
    "source_ami": "ami-0c55b159cbfafe1f0",
    "instance_type": "t2.micro",
    "ssh_username": "ubuntu",
    "ami_name": "my-image-{{timestamp}}"
  }],
  "provisioners": [{
    "type": "ansible",
    "playbook_file": "playbook.yml"
  }]
}
```
В этом примере шаблон создает машинный образ AWS и настраивает его с помощью Ansible. Раздел `provisioners` задает используемый playbook Ansible.

### Образ Google Cloud Platform
Packer также создает образы для Google Cloud Platform. Ниже приведен пример шаблона:
```json
{
  "builders": [{
    "type": "googlecompute",
    "project_id": "PROJECT_ID",
    "source_image_family": "ubuntu-1604-lts",
    "zone": "us-central1-f",
    "image_name": "my-image",
    "image_description": "Мой пользовательский образ машины"
  }],
  "provisioners": [{
    "type": "shell",
    "inline": [
      "echo 'Hello, World!' > /tmp/hello.txt"
    ]
  }]
}
```
Этот шаблон создает образ Google Cloud Platform и с помощью shell provisioner добавляет файл. Полученный образ будет называться "my-image", а его описание будет "Мой пользовательский образ машины".

### VMware

```json
{
  "builders": [
    {
      "type": "vmware-iso",
      "iso_url": "https://releases.ubuntu.com/20.04.2/ubuntu-20.04.2-live-server-amd64.iso",
      "iso_checksum_type": "sha256",
      "iso_checksum": "a244fe4adcc2ad92d15c12e47ca4ea97fb5b5d67b1ba50880c9e420ae3f3c083",
      "guest_os_type": "ubuntu-64",
      "disk_size": 40960,
      "vm_name": "ubuntu-20.04.2-server-amd64",
      "ssh_username": "ubuntu",
      "ssh_password": "ubuntu",
      "ssh_port": 22,
      "ssh_wait_timeout": "60m",
      "shutdown_command": "sudo shutdown -P now",
      "vmx_data": {
        "memsize": "4096",
        "numvcpus": "2"
      }
    }
  ],
  "provisioners": [
    {
      "type": "shell",
      "inline": [
        "sudo apt-get update",
        "sudo apt-get install -y nginx"
      ]
    }
  ]
}
```
В этом примере шаблон создает образ VMware из ISO Ubuntu Server. В готовой машине будет 4 ГБ ОЗУ, 2 ЦП и диск на 40 ГБ. Во время настройки также установится веб-сервер nginx.

Это лишь несколько примеров использования Packer. С его помощью можно создавать образы для многих платформ и настраивать их разными provisioner-инструментами.

## Рекомендации по использованию Packer

Следуйте этим рекомендациям:

- **Используйте контроль версий**: храните шаблоны Packer в системе контроля версий, чтобы отслеживать изменения и работать совместно.
- **Параметризуйте шаблоны**: используйте переменные для повторного применения шаблонов и упрощения обслуживания.
- **Тестируйте шаблоны**: проверяйте, что они создают ожидаемые машинные образы.
- **Соблюдайте рекомендации по безопасности**: защищайте среды, создаваемые на основе машинных образов.
- **Оставляйте шаблоны простыми**: избегайте сложных шаблонов, которые трудно обслуживать и отлаживать.
- **Используйте команду `packer init`**: инициализируйте новый шаблон с нужной конфигурацией.
