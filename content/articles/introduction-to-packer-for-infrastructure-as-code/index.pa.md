**ਇਨਫ੍ਰਾਸਟਰੱਕਚਰ ਐਜ਼ ਕੋਡ ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ Packer ਦੀ ਵਰਤੋਂ ਦੀ ਜਾਣ-ਪਛਾਣ**

**Packer** **ਮਸ਼ੀਨ ਇਮੇਜਾਂ** ਜਾਂ **ਵਰਚੁਅਲ ਮਸ਼ੀਨ ਟੈਂਪਲੇਟਾਂ** ਬਣਾਉਣ ਲਈ ਇੱਕ ਪ੍ਰਸਿੱਧ ਟੂਲ ਹੈ। ਇਨ੍ਹਾਂ ਦੀ ਮਦਦ ਨਾਲ ਕਈ ਪਲੇਟਫਾਰਮਾਂ ਉੱਤੇ ਇਕੋ ਜਿਹੇ ਵਾਤਾਵਰਣ ਤੈਨਾਤ ਕੀਤੇ ਜਾ ਸਕਦੇ ਹਨ। ਇਹ **AWS, Google Cloud Platform, Azure ਅਤੇ VMware** ਵਰਗੇ ਪਲੇਟਫਾਰਮਾਂ ਲਈ ਇਮੇਜ ਬਣਾਉਣ ਦੀ ਪ੍ਰਕਿਰਿਆ ਨੂੰ ਆਟੋਮੈਟਿਕ ਕਰਦਾ ਹੈ। Packer, HashiCorp ਵੱਲੋਂ ਬਣਾਇਆ ਓਪਨ-ਸੋਰਸ ਟੂਲ ਹੈ। HashiCorp ਨੇ Vagrant, Consul ਅਤੇ Terraform ਵਰਗੇ ਪ੍ਰਸਿੱਧ ਟੂਲ ਵੀ ਬਣਾਏ ਹਨ।

ਇਸ ਲੇਖ ਵਿੱਚ ਤੁਸੀਂ Packer ਬਾਰੇ ਜਾਣੋਗੇ ਅਤੇ ਵੱਖ-ਵੱਖ ਪਲੇਟਫਾਰਮਾਂ ਲਈ ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਣ ਦਾ ਤਰੀਕਾ ਵੇਖੋਗੇ। ਅਸੀਂ ਇਸਦੇ ਫਾਇਦਿਆਂ ਅਤੇ ਵਰਤੋਂ ਦੇ ਕੁਝ ਵਧੀਆ ਅਮਲਾਂ ਬਾਰੇ ਵੀ ਦੱਸਾਂਗੇ।

## Packer ਕੀ ਹੈ?

Packer ਵੱਖ-ਵੱਖ ਪਲੇਟਫਾਰਮਾਂ ਲਈ ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਣ ਦੀ ਪ੍ਰਕਿਰਿਆ ਆਟੋਮੈਟਿਕ ਕਰਦਾ ਹੈ। ਇਹ HashiCorp ਦਾ ਓਪਨ-ਸੋਰਸ ਟੂਲ ਹੈ, ਜਿਸ ਨੇ Vagrant, Consul ਅਤੇ Terraform ਵਰਗੇ ਹੋਰ ਪ੍ਰਸਿੱਧ ਟੂਲ ਵੀ ਬਣਾਏ ਹਨ।

Packer ਨਾਲ ਡਿਵੈਲਪਰ AWS, Google Cloud Platform, Azure ਅਤੇ VMware ਵਰਗੇ ਪਲੇਟਫਾਰਮਾਂ ਲਈ ਮਸ਼ੀਨ ਇਮੇਜ ਜਾਂ ਵਰਚੁਅਲ ਮਸ਼ੀਨ ਟੈਂਪਲੇਟ ਬਣਾ ਸਕਦੇ ਹਨ। ਫਿਰ ਇਨ੍ਹਾਂ ਇਮੇਜਾਂ ਨਾਲ ਕਈ ਪਲੇਟਫਾਰਮਾਂ ਉੱਤੇ ਇਕੋ ਜਿਹੇ ਵਾਤਾਵਰਣ ਤੈਨਾਤ ਕੀਤੇ ਜਾ ਸਕਦੇ ਹਨ।

## Packer ਵਰਤਣ ਦੇ ਫਾਇਦੇ

Packer ਵਰਤਣ ਦੇ ਕਈ ਫਾਇਦੇ ਹਨ:

- **ਦੁਹਰਾਉਣਯੋਗਤਾ**: ਹਰ ਵਾਰ ਮਸ਼ੀਨ ਇਮੇਜ ਇਕੋ ਤਰੀਕੇ ਨਾਲ ਬਣਾਉਂਦਾ ਹੈ, ਜਿਸ ਨਾਲ ਵਾਤਾਵਰਣਾਂ ਵਿੱਚ ਇਕਸਾਰਤਾ ਅਤੇ ਦੁਹਰਾਏ ਜਾ ਸਕਣ ਵਾਲੇ ਨਤੀਜੇ ਮਿਲਦੇ ਹਨ।
- **ਆਟੋਮੇਸ਼ਨ**: ਇਮੇਜ ਬਣਾਉਣ ਦਾ ਕੰਮ ਆਟੋਮੈਟਿਕ ਕਰਦਾ ਹੈ, ਸਮਾਂ ਬਚਾਉਂਦਾ ਹੈ ਅਤੇ ਮਨੁੱਖੀ ਗਲਤੀ ਦੀ ਸੰਭਾਵਨਾ ਘਟਾਉਂਦਾ ਹੈ।
- **ਬਹੁ-ਪਲੇਟਫਾਰਮ ਸਹਾਇਤਾ**: ਵੱਖ-ਵੱਖ ਵਾਤਾਵਰਣਾਂ ਵਿੱਚ ਵਰਤਣ ਲਈ ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਣਾ ਆਸਾਨ ਕਰਦਾ ਹੈ।
- **ਹੋਰ ਟੂਲਾਂ ਨਾਲ ਏਕੀਕਰਨ**: Ansible, Chef ਅਤੇ Puppet ਨਾਲ ਏਕੀਕ੍ਰਿਤ ਹੁੰਦਾ ਹੈ, ਇਸ ਲਈ ਤੁਸੀਂ ਪਹਿਲਾਂ ਤੋਂ ਵਰਤੇ ਜਾਂਦੇ ਟੂਲਾਂ ਨਾਲ ਇਮੇਜ ਬਣਾ ਸਕਦੇ ਹੋ।
- **ਵਿਸਥਾਰਯੋਗਤਾ**: ਕਈ ਮਸ਼ੀਨ ਇਮੇਜਾਂ ਇਕੱਠੇ ਬਣਾ ਸਕਦਾ ਹੈ, ਜਿਸ ਨਾਲ ਬਣਾਉਣ ਦੀ ਪ੍ਰਕਿਰਿਆ ਦਾ ਪੈਮਾਨਾ ਵਧਾਉਣਾ ਆਸਾਨ ਹੁੰਦਾ ਹੈ।

## Packer ਨਾਲ ਸ਼ੁਰੂਆਤ

ਸ਼ੁਰੂ ਕਰਨ ਲਈ Packer ਡਾਊਨਲੋਡ ਅਤੇ ਇੰਸਟਾਲ ਕਰੋ। ਇਹ Windows, macOS ਅਤੇ Linux ਲਈ ਉਪਲਬਧ ਹੈ।

Packer ਨੂੰ ਅਧਿਕਾਰਤ ਵੈੱਬਸਾਈਟ ਤੋਂ ਡਾਊਨਲੋਡ ਕਰੋ: [https://www.packer.io/downloads](https://www.packer.io/downloads)

ਇੰਸਟਾਲ ਕਰਨ ਤੋਂ ਬਾਅਦ ਤੁਸੀਂ ਵੱਖ-ਵੱਖ ਪਲੇਟਫਾਰਮਾਂ ਲਈ ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਣੇ ਸ਼ੁਰੂ ਕਰ ਸਕਦੇ ਹੋ।

## Packer ਨਾਲ ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਣਾ

Packer ਨਾਲ ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਣ ਲਈ ਉਸਦੀ ਸੰਰਚਨਾ ਦੱਸਣ ਵਾਲਾ **ਟੈਂਪਲੇਟ** ਪਰਿਭਾਸ਼ਿਤ ਕਰੋ। ਟੈਂਪਲੇਟ JSON ਫਾਰਮੈਟ ਵਿੱਚ ਲਿਖਿਆ ਜਾਂਦਾ ਹੈ ਅਤੇ ਇਮੇਜ ਬਣਾਉਣ ਲਈ ਲੋੜੀਂਦੇ ਕਦਮ ਦੱਸਦਾ ਹੈ।

AWS ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਣ ਲਈ Packer ਟੈਂਪਲੇਟ ਦੀ ਇੱਕ ਉਦਾਹਰਨ:

```json
{
"builders": [{
"type": "amazon-ebs",
"access_key": "ACCESS_KEY",
"secret_key": "SECRET_KEY",
"region": "us-west-2",
"source_ami": "ami-0c55b159cbfafe1f0",
"instance_type": "t2.micro",
"ssh_username": "ubuntu",
"ami_name": "my-image-{{timestamp}}"
}]
}
```

ਇਸ ਉਦਾਹਰਨ ਵਿੱਚ ਟੈਂਪਲੇਟ Packer ਨੂੰ Ubuntu AMI ਵਰਤ ਕੇ Amazon EBS-ਅਧਾਰਿਤ ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਣ ਲਈ ਕਹਿੰਦਾ ਹੈ। ਬਣੀ ਇਮੇਜ ਦਾ ਨਾਂ "my-image" ਹੋਵੇਗਾ ਅਤੇ ਅਖੀਰ ਵਿੱਚ ਟਾਈਮਸਟੈਂਪ ਜੋੜਿਆ ਜਾਵੇਗਾ।

ਟੈਂਪਲੇਟ ਪਰਿਭਾਸ਼ਿਤ ਕਰਨ ਤੋਂ ਬਾਅਦ ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਣ ਲਈ `packer build` ਕਮਾਂਡ ਚਲਾਓ:

```bash
$ packer build template.json
```

### Ansible ਪ੍ਰੋਵੀਜ਼ਨਰ ਨਾਲ AWS AMI
AWS ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਣ ਲਈ Packer ਨਾਲ Ansible ਪ੍ਰੋਵੀਜ਼ਨਰ ਵਰਤਿਆ ਜਾ ਸਕਦਾ ਹੈ। ਇਹ Packer ਟੈਂਪਲੇਟ ਉਦਾਹਰਨ ਵੇਖੋ:

```json
{
  "builders": [{
    "type": "amazon-ebs",
    "access_key": "ACCESS_KEY",
    "secret_key": "SECRET_KEY",
    "region": "us-west-2",
    "source_ami": "ami-0c55b159cbfafe1f0",
    "instance_type": "t2.micro",
    "ssh_username": "ubuntu",
    "ami_name": "my-image-{{timestamp}}"
  }],
  "provisioners": [{
    "type": "ansible",
    "playbook_file": "playbook.yml"
  }]
}
```
ਇਸ ਉਦਾਹਰਨ ਵਿੱਚ ਟੈਂਪਲੇਟ AWS ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਂਦਾ ਹੈ ਅਤੇ ਉਸਨੂੰ ਤਿਆਰ ਕਰਨ ਲਈ Ansible ਵਰਤਦਾ ਹੈ। `provisioners` ਭਾਗ ਵਰਤੇ ਜਾਣ ਵਾਲੇ Ansible playbook ਦਾ ਨਾਂ ਦੱਸਦਾ ਹੈ।

### Google Cloud Platform ਇਮੇਜ
Packer ਦੀ ਮਦਦ ਨਾਲ Google Cloud Platform ਉੱਤੇ ਵੀ ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਏ ਜਾ ਸਕਦੇ ਹਨ। ਇਹ ਨਮੂਨਾ ਟੈਂਪਲੇਟ ਵੇਖੋ:
```json
{
  "builders": [{
    "type": "googlecompute",
    "project_id": "PROJECT_ID",
    "source_image_family": "ubuntu-1604-lts",
    "zone": "us-central1-f",
    "image_name": "my-image",
    "image_description": "ਮੇਰੀ ਕਸਟਮ ਮਸ਼ੀਨ ਇਮੇਜ"
  }],
  "provisioners": [{
    "type": "shell",
    "inline": [
      "echo 'Hello, World!' > /tmp/hello.txt"
    ]
  }]
}
```
ਇਹ ਟੈਂਪਲੇਟ Google Cloud Platform ਇਮੇਜ ਬਣਾਉਂਦਾ ਹੈ ਅਤੇ ਫਾਈਲ ਜੋੜਨ ਲਈ shell ਪ੍ਰੋਵੀਜ਼ਨਰ ਵਰਤਦਾ ਹੈ। ਤਿਆਰ ਇਮੇਜ ਦਾ ਨਾਂ "my-image" ਅਤੇ ਵੇਰਵਾ "ਮੇਰੀ ਕਸਟਮ ਮਸ਼ੀਨ ਇਮੇਜ" ਹੋਵੇਗਾ।

### VMware

```json
{
  "builders": [
    {
      "type": "vmware-iso",
      "iso_url": "https://releases.ubuntu.com/20.04.2/ubuntu-20.04.2-live-server-amd64.iso",
      "iso_checksum_type": "sha256",
      "iso_checksum": "a244fe4adcc2ad92d15c12e47ca4ea97fb5b5d67b1ba50880c9e420ae3f3c083",
      "guest_os_type": "ubuntu-64",
      "disk_size": 40960,
      "vm_name": "ubuntu-20.04.2-server-amd64",
      "ssh_username": "ubuntu",
      "ssh_password": "ubuntu",
      "ssh_port": 22,
      "ssh_wait_timeout": "60m",
      "shutdown_command": "sudo shutdown -P now",
      "vmx_data": {
        "memsize": "4096",
        "numvcpus": "2"
      }
    }
  ],
  "provisioners": [
    {

      "inline": [
        "sudo apt-get update",
        "sudo apt-get install -y nginx"
      ]
    }

```
ਇਸ ਉਦਾਹਰਨ ਵਿੱਚ ਟੈਂਪਲੇਟ Ubuntu Server ISO ਵਰਤ ਕੇ VMware ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਂਦਾ ਹੈ। ਤਿਆਰ ਮਸ਼ੀਨ ਵਿੱਚ 4 GB RAM, 2 CPU ਅਤੇ 40 GB ਡਿਸਕ ਹੋਵੇਗੀ। ਪ੍ਰੋਵੀਜ਼ਨਿੰਗ ਦੌਰਾਨ nginx ਵੈੱਬ ਸਰਵਰ ਵੀ ਇੰਸਟਾਲ ਹੋਵੇਗਾ।

ਇਹ Packer ਨਾਲ ਕੀਤੇ ਜਾ ਸਕਣ ਵਾਲੇ ਕੁਝ ਕੰਮਾਂ ਦੀਆਂ ਉਦਾਹਰਨਾਂ ਹਨ। Packer ਕਈ ਪਲੇਟਫਾਰਮਾਂ ਲਈ ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾ ਸਕਦਾ ਹੈ ਅਤੇ ਉਨ੍ਹਾਂ ਨੂੰ ਸੰਰਚਿਤ ਕਰਨ ਲਈ ਵੱਖ-ਵੱਖ ਪ੍ਰੋਵੀਜ਼ਨਰ ਵਰਤ ਸਕਦਾ ਹੈ।

## Packer ਵਰਤਣ ਦੇ ਵਧੀਆ ਅਮਲ

Packer ਵਰਤਦੇ ਸਮੇਂ ਇਹ ਵਧੀਆ ਅਮਲ ਅਪਣਾਓ:

- **ਵਰਜਨ ਕੰਟਰੋਲ ਵਰਤੋ**: ਤਬਦੀਲੀਆਂ ਦਰਜ ਕਰਨ ਅਤੇ ਮਿਲ ਕੇ ਕੰਮ ਕਰਨ ਲਈ Packer ਟੈਂਪਲੇਟਾਂ ਨੂੰ ਵਰਜਨ ਕੰਟਰੋਲ ਵਿੱਚ ਰੱਖੋ।
- **ਟੈਂਪਲੇਟਾਂ ਵਿੱਚ ਪੈਰਾਮੀਟਰ ਵਰਤੋ**: ਮੁੜ ਵਰਤੋਂ ਅਤੇ ਰੱਖ-ਰਖਾਅ ਆਸਾਨ ਬਣਾਉਣ ਲਈ ਵੇਰੀਏਬਲ ਵਰਤੋ।
- **ਟੈਂਪਲੇਟਾਂ ਦੀ ਜਾਂਚ ਕਰੋ**: ਯਕੀਨੀ ਬਣਾਓ ਕਿ ਉਹ ਉਮੀਦ ਕੀਤੀਆਂ ਮਸ਼ੀਨ ਇਮੇਜਾਂ ਬਣਾਉਂਦੇ ਹਨ।
- **ਸੁਰੱਖਿਆ ਦੇ ਵਧੀਆ ਅਮਲ ਮੰਨੋ**: ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਂਦੇ ਸਮੇਂ ਤਿਆਰ ਵਾਤਾਵਰਣਾਂ ਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖੋ।
- **ਟੈਂਪਲੇਟ ਸੌਖੇ ਰੱਖੋ**: ਗੁੰਝਲਦਾਰ ਟੈਂਪਲੇਟਾਂ ਤੋਂ ਬਚੋ ਜਿਨ੍ਹਾਂ ਦੀ ਸਾਂਭ-ਸੰਭਾਲ ਅਤੇ ਡੀਬੱਗ ਕਰਨਾ ਔਖਾ ਹੋਵੇ।
- **`packer init` ਕਮਾਂਡ ਵਰਤੋ**: ਲੋੜੀਂਦੀ ਸੰਰਚਨਾ ਨਾਲ ਨਵਾਂ ਟੈਂਪਲੇਟ ਸ਼ੁਰੂ ਕਰੋ।

## ਨਤੀਜਾ

Packer ਵੱਖ-ਵੱਖ ਪਲੇਟਫਾਰਮਾਂ ਲਈ ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਣ ਦਾ ਲਾਭਕਾਰੀ ਟੂਲ ਹੈ। ਇਹ ਦੁਹਰਾਉਣਯੋਗਤਾ, ਆਟੋਮੇਸ਼ਨ, ਬਹੁ-ਪਲੇਟਫਾਰਮ ਸਹਾਇਤਾ ਅਤੇ ਵਿਸਥਾਰਯੋਗਤਾ ਦਿੰਦਾ ਹੈ। ਵਧੀਆ ਅਮਲ ਅਪਣਾਉਣ ਨਾਲ ਤੁਸੀਂ ਅਜਿਹੀਆਂ ਮਸ਼ੀਨ ਇਮੇਜਾਂ ਬਣਾ ਸਕਦੇ ਹੋ ਜੋ ਸੰਭਾਲਣ ਵਿੱਚ ਆਸਾਨ ਅਤੇ ਸੁਰੱਖਿਅਤ ਹੋਣ।

ਇਸ ਲੇਖ ਵਿੱਚ ਅਸੀਂ Packer ਦੀ ਜਾਣ-ਪਛਾਣ ਕਰਵਾਈ ਅਤੇ ਵੱਖ-ਵੱਖ ਪਲੇਟਫਾਰਮਾਂ ਲਈ ਮਸ਼ੀਨ ਇਮੇਜ ਬਣਾਉਣ ਦਾ ਤਰੀਕਾ ਦਿਖਾਇਆ। ਅਸੀਂ ਇਸਦੇ ਫਾਇਦਿਆਂ ਅਤੇ ਵਰਤੋਂ ਦੇ ਕੁਝ ਵਧੀਆ ਅਮਲਾਂ ਬਾਰੇ ਵੀ ਚਰਚਾ ਕੀਤੀ।

Packer ਬਾਰੇ ਹੋਰ ਜਾਣਨ ਲਈ [ਅਧਿਕਾਰਤ ਦਸਤਾਵੇਜ਼](https://www.packer.io/docs) ਵੇਖੋ।
