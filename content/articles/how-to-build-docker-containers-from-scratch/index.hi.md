**Docker कंटेनर कैसे बनाएँ**

Docker एक शक्तिशाली टूल है, जिसका उपयोग पोर्टेबल और आसानी से डिप्लॉय होने वाले एप्लिकेशन बनाने के लिए किया जा सकता है। इस मार्गदर्शिका में हम Docker कंटेनर बनाने और बिल्ड करने के मूल चरण बताएँगे। हम कुछ सर्वोत्तम तरीके और सुझाव भी देंगे, ताकि आपके Docker कंटेनर कुशल, सुरक्षित और उपयोग में आसान रहें।

## Docker को समझना

Docker कंटेनर बनाना शुरू करने से पहले यह समझना ज़रूरी है कि Docker क्या है और यह कैसे काम करता है।

Docker ऐसा टूल है जो किसी एप्लिकेशन और उसकी निर्भरताओं को एक कंटेनर में पैकेज करने देता है, जिसे किसी भी सिस्टम पर चलाया जा सकता है। कंटेनर होस्ट सिस्टम से अलग रहता है और एप्लिकेशन चलाने के लिए ज़रूरी सभी चीज़ें इसमें शामिल होती हैं, जैसे कोड, रनटाइम, सिस्टम टूल, लाइब्रेरी और सेटिंग्स।

कंटेनर हल्के होते हैं और आसानी से डिप्लॉय किए जा सकते हैं, इसलिए एप्लिकेशन बनाने और डिप्लॉय करने के लिए लोकप्रिय हैं। Docker के साथ आप एक सरल कमांड-लाइन इंटरफ़ेस से कंटेनर बना, प्रबंधित और चला सकते हैं।

## Docker इमेज बनाना

Docker कंटेनर बनाने के लिए पहले Docker इमेज बनानी होगी। Docker इमेज कंटेनर का एक स्नैपशॉट है, जिसमें एप्लिकेशन चलाने के लिए आवश्यक सभी फ़ाइलें, लाइब्रेरी और निर्भरताएँ शामिल होती हैं।

Docker इमेज बनाने के मूल चरण ये हैं:

1. **Dockerfile बनाएँ**
2. **इमेज बनाएँ**
3. **कंटेनर चलाएँ**

### चरण 1: Dockerfile बनाएँ

Docker इमेज बनाने का पहला चरण Dockerfile बनाना है। Dockerfile एक टेक्स्ट फ़ाइल होती है, जिसमें इमेज बनाने के लिए आवश्यक निर्देश होते हैं। यहाँ एक सरल Dockerfile का उदाहरण है:

```bash
FROM ubuntu:latest
RUN apt-get update && apt-get install -y nginx
COPY index.html /var/www/html/
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

आइए इस Dockerfile को समझें:

- `FROM ubuntu:latest` कंटेनर के लिए उपयोग की जाने वाली बेस इमेज बताता है। इस उदाहरण में हम Ubuntu का नवीनतम संस्करण उपयोग कर रहे हैं।
- `RUN apt-get update && apt-get install -y nginx` पैकेज सूची अपडेट करता है और nginx वेब सर्वर इंस्टॉल करता है।
- `COPY index.html /var/www/html/` index.html फ़ाइल को कंटेनर की वेब रूट डायरेक्टरी में कॉपी करता है।
- `EXPOSE 80` होस्ट सिस्टम के लिए पोर्ट 80 उपलब्ध कराता है।
- `CMD ["nginx", "-g", "daemon off;"]` nginx सर्वर शुरू करता है और उसे फ़ोरग्राउंड में चलाता है।

### चरण 2: इमेज बनाएँ

Dockerfile बनाने के बाद `docker build` कमांड से इमेज बनाई जा सकती है। उदाहरण:

```bash
docker run -d -p 80:80 my-nginx-image
```

आइए इस कमांड को समझें:

- `docker run` Docker को कंटेनर चलाने के लिए कहता है।
- `-d` कंटेनर को अलग मोड में चलाता है, यानी वह बैकग्राउंड में चलता है।
- `-p 80:80` होस्ट सिस्टम के पोर्ट 80 को कंटेनर के पोर्ट 80 से मैप करता है।
- `my-nginx-image` कंटेनर के लिए उपयोग की जाने वाली Docker इमेज का नाम बताता है।

## सर्वोत्तम तरीके

अब आप Docker कंटेनर बनाना जानते हैं। उन्हें कुशल, सुरक्षित और उपयोग में आसान रखने के लिए कुछ सर्वोत्तम तरीके देखते हैं।

### छोटी बेस इमेज का उपयोग करें

Docker कंटेनर छोटे रखने और तेज़ी से डिप्लॉय करने के लिए ऐसी छोटी बेस इमेज उपयोग करना बेहतर है जिसमें केवल आपके एप्लिकेशन की निर्भरताएँ हों। Ubuntu या CentOS जैसे पूरे ऑपरेटिंग सिस्टम की जगह Alpine Linux या BusyBox जैसी छोटी इमेज उपयोग की जा सकती है।

### लेयर कम करें

Dockerfile की हर पंक्ति Docker इमेज में एक नई लेयर बनाती है और हर लेयर इमेज का आकार बढ़ाती है। Docker इमेज का आकार यथासंभव कम रखने के लिए लेयर की संख्या घटाएँ। इसका एक तरीका समान कमांड को Dockerfile की एक ही पंक्ति में समूहित करना है। उदाहरण के लिए, पैकेज सूची अपडेट करने और पैकेज इंस्टॉल करने के लिए दो अलग-अलग `RUN` कमांड के बजाय एक `RUN` कमांड दोनों काम कर सकता है।

उदाहरण:
```dockerfile
RUN apt update
RUN apt install apache -y
```
के बजाय
```dockerfile
RUN apt update && apt install apache -y
```

### एनवायरनमेंट वेरिएबल का उपयोग करें

Dockerfile में मानों को हार्डकोड करने के बजाय एनवायरनमेंट वेरिएबल इस्तेमाल करने से रनटाइम पर कंटेनर को अनुकूलित करना आसान होता है और Dockerfile पोर्टेबल रहती है। उदाहरण के लिए, इन वेरिएबल से एप्लिकेशन का पोर्ट या कॉन्फ़िगरेशन फ़ाइल का स्थान तय किया जा सकता है।

उदाहरण:
```bash
docker run -e PORT=3000 my-app
```
```Dockerfile
FROM node:14

# कार्यशील डायरेक्टरी सेट करें
WORKDIR /app

# package.json और yarn.lock को कंटेनर में कॉपी करें
COPY package.json yarn.lock ./

# निर्भरताएँ इंस्टॉल करें
RUN yarn install --frozen-lockfile

# एप्लिकेशन कोड को कंटेनर में कॉपी करें
COPY . .

# एप्लिकेशन पोर्ट उपलब्ध कराएँ
EXPOSE $PORT

# एप्लिकेशन शुरू करें
CMD ["yarn", "start"]
```


### वॉल्यूम माउंट का उपयोग करें

वॉल्यूम माउंट से होस्ट सिस्टम और Docker कंटेनर के बीच डेटा साझा किया जा सकता है। इससे डेटा प्रबंधित करना आसान होता है और Docker कंटेनर का आकार घटता है। उदाहरण के लिए, होस्ट सिस्टम और कंटेनर के बीच डेटाबेस फ़ाइल साझा करने के लिए वॉल्यूम माउंट किया जा सकता है।

उदाहरण:
```bash
docker run -v /home/user/app/data:/app/data my-app
```

```Dockerfile
FROM node:14

# कार्यशील डायरेक्टरी सेट करें
WORKDIR /app

# package.json और yarn.lock फ़ाइलों को कंटेनर में कॉपी करें
COPY package.json yarn.lock ./

# निर्भरताएँ इंस्टॉल करें
RUN yarn install --frozen-lockfile

# एप्लिकेशन का बाकी कोड कंटेनर में कॉपी करें
COPY . .

# एप्लिकेशन पोर्ट उपलब्ध कराएँ
EXPOSE 3000

# एप्लिकेशन शुरू करें
CMD ["yarn", "start"]

# एप्लिकेशन डेटा के लिए वॉल्यूम माउंट करें
VOLUME ["/app/data"]
```

### रूट के रूप में चलाने से बचें

Docker कंटेनर को रूट उपयोगकर्ता के रूप में चलाना सुरक्षा जोखिम पैदा कर सकता है। इसके बजाय Dockerfile में नया उपयोगकर्ता बनाएँ और कंटेनर उसी उपयोगकर्ता के रूप में चलाएँ। उदाहरण के लिए, Dockerfile में `USER` कमांड से नया उपयोगकर्ता बनाएँ, फिर कंटेनर चलाते समय उस उपयोगकर्ता पर स्विच करें।

उदाहरण:
```Dockerfile
FROM node:14

# कंटेनर चलाने के लिए नया उपयोगकर्ता बनाएँ
RUN useradd --user-group --create-home --shell /bin/false app

# कार्यशील डायरेक्टरी को app उपयोगकर्ता की होम डायरेक्टरी पर बदलें
WORKDIR /home/app

# app उपयोगकर्ता के रूप में निर्भरताएँ इंस्टॉल करें
COPY package.json yarn.lock ./
RUN chown -R app:app /home/app
USER app
RUN yarn install --frozen-lockfile --production

# app उपयोगकर्ता के रूप में एप्लिकेशन कोड कॉपी करें
COPY --chown=app:app . .

# पोर्ट उपलब्ध कराएँ
EXPOSE 3000

# app उपयोगकर्ता के रूप में एप्लिकेशन शुरू करें
CMD ["yarn", "start"]
```

### इमेज को अप-टू-डेट रखें

Docker कंटेनर को सुरक्षित और कमज़ोरियों से मुक्त रखने के लिए Docker इमेज को अप-टू-डेट रखना ज़रूरी है। इसका अर्थ है बेस इमेज और एप्लिकेशन की निर्भरताओं को नियमित रूप से अपडेट करना। उदाहरण के लिए, कंटेनर में नवीनतम सुरक्षा पैच और बग फ़िक्स रखने के लिए Dockerfile में `apt-get update` और `apt-get upgrade` कमांड उपयोग कर सकते हैं।

उदाहरण:
```Dockerfile
FROM ubuntu:latest

# पैकेज सूची अपडेट करें और सुरक्षा अपडेट इंस्टॉल करें
RUN apt-get update && apt-get upgrade -y && apt-get clean

# nginx वेब सर्वर इंस्टॉल करें
RUN apt-get install -y nginx

# एप्लिकेशन कोड कंटेनर में कॉपी करें
COPY . /var/www/html/

# होस्ट सिस्टम के लिए पोर्ट 80 उपलब्ध कराएँ
EXPOSE 80

# nginx सर्वर शुरू करें
CMD ["nginx", "-g", "daemon off;"]

```
## आगे पढ़ें
### Docker दस्तावेज़
[Docker](https://www.docker.com/) कंटेनर में एप्लिकेशन बनाने, भेजने और चलाने का ओपन-सोर्स प्लेटफ़ॉर्म है। Docker दस्तावेज़ वेबसाइट में विभिन्न ऑपरेटिंग सिस्टम और उपयोग के मामलों के लिए Docker इंस्टॉल, कॉन्फ़िगर और उपयोग करने की विस्तृत जानकारी है। इसमें Docker API, Docker CLI कमांड और समस्या निवारण सुझाव भी शामिल हैं।

Docker दस्तावेज़ के कुछ उपयोगी अनुभाग:

- [Docker के साथ शुरुआत करें](https://docs.docker.com/get-started/)
- [Docker CLI संदर्भ](https://docs.docker.com/engine/reference/commandline/cli/)
- [Docker API संदर्भ](https://docs.docker.com/engine/api/v1.41/)
- [Docker Compose संदर्भ](https://docs.docker.com/compose/compose-file/)
- [Dockerfile संदर्भ](https://docs.docker.com/engine/reference/builder/)

Docker का उपयोग सीखने और आने वाली समस्याओं के समाधान के लिए Docker दस्तावेज़ एक उपयोगी संसाधन है।

### Docker Hub

[Docker Hub](https://hub.docker.com/) क्लाउड-आधारित रिपॉज़िटरी है, जहाँ Docker इमेज संग्रहीत, साझा और प्रबंधित की जा सकती हैं। इसमें सार्वजनिक और निजी रिपॉज़िटरी के साथ स्वचालित बिल्ड और वर्कफ़्लो भी हैं। आप अपनी Docker इमेज संग्रहीत करने के साथ-साथ लोकप्रिय सॉफ़्टवेयर एप्लिकेशन और टूल के पहले से बने इमेज भी खोज सकते हैं।

Docker Hub की कुछ उपयोगी सुविधाएँ:

- [Docker इमेज खोजें](https://hub.docker.com/search?type=image)
- [रिपॉज़िटरी में इमेज संग्रहीत और प्रबंधित करें](https://hub.docker.com/repositories)
- [Docker Hub वर्कफ़्लो से बिल्ड और परीक्षण स्वचालित करें](https://docs.docker.com/docker-hub/builds/)

Docker के साथ काम करने के लिए Docker Hub एक ज़रूरी टूल है। इमेज प्रबंधित और साझा करते समय यह आपका बहुत समय और मेहनत बचा सकता है।

## निष्कर्ष

Docker एक शक्तिशाली टूल है, जो एप्लिकेशन को अधिक पोर्टेबल, कुशल और आसानी से डिप्लॉय करने योग्य बना सकता है। इन सर्वोत्तम तरीकों और सुझावों का पालन करके आप सुरक्षित, उपयोग में आसान और तेज़ी से डिप्लॉय होने वाले Docker कंटेनर बना सकते हैं। चाहे आप नया एप्लिकेशन बना रहे हों या किसी मौजूदा एप्लिकेशन को Docker में माइग्रेट कर रहे हों, ये चरण Docker कंटेनर बनाना शुरू करने में आपकी मदद करेंगे।
