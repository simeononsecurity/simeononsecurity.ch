**Docker ਕੰਟੇਨਰ ਕਿਵੇਂ ਬਣਾਉਣੇ ਹਨ**

Docker ਇੱਕ ਤਾਕਤਵਰ ਔਜ਼ਾਰ ਹੈ ਜਿਸ ਨਾਲ ਪੋਰਟੇਬਲ ਅਤੇ ਆਸਾਨੀ ਨਾਲ ਡਿਪਲੌਇ ਹੋਣ ਵਾਲੀਆਂ ਐਪਲੀਕੇਸ਼ਨਾਂ ਬਣਾਈਆਂ ਜਾ ਸਕਦੀਆਂ ਹਨ। ਇਸ ਗਾਈਡ ਵਿੱਚ ਅਸੀਂ Docker ਕੰਟੇਨਰ ਬਣਾਉਣ ਦੇ ਬੁਨਿਆਦੀ ਕਦਮਾਂ ਬਾਰੇ ਦੱਸਾਂਗੇ। ਅਸੀਂ ਵਧੀਆ ਤਰੀਕਿਆਂ ਅਤੇ ਸੁਝਾਵਾਂ ਬਾਰੇ ਵੀ ਗੱਲ ਕਰਾਂਗੇ ਤਾਂ ਜੋ ਤੁਹਾਡੇ Docker ਕੰਟੇਨਰ ਕੁਸ਼ਲ, ਸੁਰੱਖਿਅਤ ਅਤੇ ਵਰਤਣ ਵਿੱਚ ਆਸਾਨ ਹੋਣ।

## Docker ਨੂੰ ਸਮਝਣਾ

Docker ਕੰਟੇਨਰ ਬਣਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਇਹ ਸਮਝਣਾ ਮਹੱਤਵਪੂਰਨ ਹੈ ਕਿ Docker ਕੀ ਹੈ ਅਤੇ ਇਹ ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ।

Docker ਇੱਕ ਔਜ਼ਾਰ ਹੈ ਜੋ ਐਪਲੀਕੇਸ਼ਨ ਅਤੇ ਉਸ ਦੀਆਂ ਨਿਰਭਰਤਾਵਾਂ ਨੂੰ ਇੱਕ ਕੰਟੇਨਰ ਵਿੱਚ ਪੈਕੇਜ ਕਰਨ ਦਿੰਦਾ ਹੈ, ਜਿਸ ਨੂੰ ਕਿਸੇ ਵੀ ਸਿਸਟਮ ਉੱਤੇ ਚਲਾਇਆ ਜਾ ਸਕਦਾ ਹੈ। ਕੰਟੇਨਰ ਹੋਸਟ ਸਿਸਟਮ ਤੋਂ ਅਲੱਗ ਹੁੰਦਾ ਹੈ ਅਤੇ ਐਪਲੀਕੇਸ਼ਨ ਚਲਾਉਣ ਲਈ ਲੋੜੀਂਦੀ ਹਰ ਚੀਜ਼ ਰੱਖਦਾ ਹੈ, ਜਿਸ ਵਿੱਚ ਕੋਡ, ਰਨਟਾਈਮ, ਸਿਸਟਮ ਔਜ਼ਾਰ, ਲਾਇਬ੍ਰੇਰੀਆਂ ਅਤੇ ਸੈਟਿੰਗਾਂ ਸ਼ਾਮਲ ਹਨ।

ਕੰਟੇਨਰ ਹਲਕੇ ਹੁੰਦੇ ਹਨ ਅਤੇ ਆਸਾਨੀ ਨਾਲ ਡਿਪਲੌਇ ਕੀਤੇ ਜਾ ਸਕਦੇ ਹਨ, ਇਸ ਲਈ ਐਪਲੀਕੇਸ਼ਨਾਂ ਬਣਾਉਣ ਅਤੇ ਡਿਪਲੌਇ ਕਰਨ ਲਈ ਇਹ ਪ੍ਰਸਿੱਧ ਚੋਣ ਹਨ। Docker ਨਾਲ ਤੁਸੀਂ ਇੱਕ ਸਧਾਰਨ ਕਮਾਂਡ-ਲਾਈਨ ਇੰਟਰਫੇਸ ਰਾਹੀਂ ਕੰਟੇਨਰ ਬਣਾ, ਸੰਭਾਲ ਅਤੇ ਚਲਾ ਸਕਦੇ ਹੋ।

## Docker ਇਮੇਜ ਬਣਾਉਣਾ

Docker ਕੰਟੇਨਰ ਬਣਾਉਣ ਲਈ ਪਹਿਲਾਂ Docker ਇਮੇਜ ਬਣਾਉਣੀ ਪੈਂਦੀ ਹੈ। Docker ਇਮੇਜ ਕੰਟੇਨਰ ਦਾ ਸਨੈਪਸ਼ਾਟ ਹੁੰਦੀ ਹੈ, ਜਿਸ ਵਿੱਚ ਐਪਲੀਕੇਸ਼ਨ ਚਲਾਉਣ ਲਈ ਲੋੜੀਂਦੀਆਂ ਸਾਰੀਆਂ ਫਾਈਲਾਂ, ਲਾਇਬ੍ਰੇਰੀਆਂ ਅਤੇ ਨਿਰਭਰਤਾਵਾਂ ਸ਼ਾਮਲ ਹੁੰਦੀਆਂ ਹਨ।

Docker ਇਮੇਜ ਬਣਾਉਣ ਦੇ ਬੁਨਿਆਦੀ ਕਦਮ ਇਹ ਹਨ:

1. **Dockerfile ਬਣਾਓ**
2. **ਇਮੇਜ ਬਣਾਓ**
3. **ਕੰਟੇਨਰ ਚਲਾਓ**

### ਕਦਮ 1: Dockerfile ਬਣਾਓ

Docker ਇਮੇਜ ਬਣਾਉਣ ਦਾ ਪਹਿਲਾ ਕਦਮ Dockerfile ਬਣਾਉਣਾ ਹੈ। Dockerfile ਇੱਕ ਟੈਕਸਟ ਫਾਈਲ ਹੁੰਦੀ ਹੈ ਜਿਸ ਵਿੱਚ ਇਮੇਜ ਬਣਾਉਣ ਲਈ ਲੋੜੀਂਦੀਆਂ ਹਦਾਇਤਾਂ ਹੁੰਦੀਆਂ ਹਨ। ਇਹ ਇੱਕ ਸਧਾਰਨ Dockerfile ਦੀ ਉਦਾਹਰਨ ਹੈ:

```bash
FROM ubuntu:latest
RUN apt-get update && apt-get install -y nginx
COPY index.html /var/www/html/
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

ਆਓ ਇਸ Dockerfile ਨੂੰ ਸਮਝੀਏ:

- `FROM ubuntu:latest` ਕੰਟੇਨਰ ਲਈ ਵਰਤੀ ਜਾਣ ਵਾਲੀ ਬੇਸ ਇਮੇਜ ਦੱਸਦਾ ਹੈ। ਇਸ ਮਾਮਲੇ ਵਿੱਚ ਅਸੀਂ Ubuntu ਦਾ ਨਵੀਨਤਮ ਵਰਜਨ ਵਰਤ ਰਹੇ ਹਾਂ।
- `RUN apt-get update && apt-get install -y nginx` ਪੈਕੇਜਾਂ ਦੀ ਸੂਚੀ ਅੱਪਡੇਟ ਕਰਦਾ ਹੈ ਅਤੇ nginx ਵੈੱਬ ਸਰਵਰ ਇੰਸਟਾਲ ਕਰਦਾ ਹੈ।
- `COPY index.html /var/www/html/` index.html ਫਾਈਲ ਨੂੰ ਕੰਟੇਨਰ ਦੀ ਵੈੱਬ ਰੂਟ ਡਾਇਰੈਕਟਰੀ ਵਿੱਚ ਕਾਪੀ ਕਰਦਾ ਹੈ।
- `EXPOSE 80` ਹੋਸਟ ਸਿਸਟਮ ਲਈ ਪੋਰਟ 80 ਖੋਲ੍ਹਦਾ ਹੈ।
- `CMD ["nginx", "-g", "daemon off;"]` nginx ਸਰਵਰ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ ਅਤੇ ਉਸ ਨੂੰ ਫੋਰਗ੍ਰਾਊਂਡ ਵਿੱਚ ਚਲਾਉਂਦਾ ਹੈ।

### ਕਦਮ 2: ਇਮੇਜ ਬਣਾਓ

Dockerfile ਬਣਾਉਣ ਤੋਂ ਬਾਅਦ ਤੁਸੀਂ `docker build` ਕਮਾਂਡ ਨਾਲ ਇਮੇਜ ਬਣਾ ਸਕਦੇ ਹੋ। ਉਦਾਹਰਨ:

```bash
docker run -d -p 80:80 my-nginx-image
```

ਆਓ ਇਸ ਕਮਾਂਡ ਨੂੰ ਸਮਝੀਏ:

- `docker run` Docker ਨੂੰ ਕੰਟੇਨਰ ਚਲਾਉਣ ਲਈ ਕਹਿੰਦਾ ਹੈ।
- `-d` ਕੰਟੇਨਰ ਨੂੰ ਵੱਖਰੇ ਢੰਗ ਨਾਲ ਚਲਾਉਂਦਾ ਹੈ, ਜਿਸ ਦਾ ਮਤਲਬ ਹੈ ਕਿ ਇਹ ਪਿਛੋਕੜ ਵਿੱਚ ਚੱਲਦਾ ਹੈ।
- `-p 80:80` ਹੋਸਟ ਸਿਸਟਮ ਦੇ ਪੋਰਟ 80 ਨੂੰ ਕੰਟੇਨਰ ਦੇ ਪੋਰਟ 80 ਨਾਲ ਜੋੜਦਾ ਹੈ।
- `my-nginx-image` ਕੰਟੇਨਰ ਲਈ ਵਰਤੀ ਜਾਣ ਵਾਲੀ Docker ਇਮੇਜ ਦਾ ਨਾਮ ਦੱਸਦਾ ਹੈ।

## ਵਧੀਆ ਤਰੀਕੇ

ਹੁਣ ਜਦੋਂ ਤੁਸੀਂ Docker ਕੰਟੇਨਰ ਬਣਾਉਣਾ ਜਾਣਦੇ ਹੋ, ਆਓ ਕੁਝ ਵਧੀਆ ਤਰੀਕੇ ਵੇਖੀਏ ਜੋ ਉਨ੍ਹਾਂ ਨੂੰ ਕੁਸ਼ਲ, ਸੁਰੱਖਿਅਤ ਅਤੇ ਵਰਤਣ ਵਿੱਚ ਆਸਾਨ ਬਣਾਉਂਦੇ ਹਨ।

### ਛੋਟੀਆਂ ਬੇਸ ਇਮੇਜਾਂ ਵਰਤੋ

Docker ਕੰਟੇਨਰ ਛੋਟੇ ਰੱਖਣ ਅਤੇ ਤੇਜ਼ੀ ਨਾਲ ਡਿਪਲੌਇ ਕਰਨ ਲਈ ਅਜਿਹੀਆਂ ਛੋਟੀਆਂ ਬੇਸ ਇਮੇਜਾਂ ਵਰਤਣਾ ਚੰਗਾ ਹੈ ਜਿਨ੍ਹਾਂ ਵਿੱਚ ਸਿਰਫ਼ ਐਪਲੀਕੇਸ਼ਨ ਦੀਆਂ ਲੋੜੀਂਦੀਆਂ ਨਿਰਭਰਤਾਵਾਂ ਹੋਣ। Ubuntu ਜਾਂ CentOS ਵਰਗੇ ਪੂਰੇ ਓਪਰੇਟਿੰਗ ਸਿਸਟਮ ਦੀ ਥਾਂ Alpine Linux ਜਾਂ BusyBox ਵਰਗੀ ਛੋਟੀ ਇਮੇਜ ਵਰਤੀ ਜਾ ਸਕਦੀ ਹੈ।

### ਲੇਅਰਾਂ ਘੱਟ ਰੱਖੋ

Dockerfile ਦੀ ਹਰ ਲਾਈਨ Docker ਇਮੇਜ ਵਿੱਚ ਇੱਕ ਨਵੀਂ ਲੇਅਰ ਬਣਾਉਂਦੀ ਹੈ ਅਤੇ ਹਰ ਲੇਅਰ ਇਮੇਜ ਦਾ ਆਕਾਰ ਵਧਾਉਂਦੀ ਹੈ। Docker ਇਮੇਜਾਂ ਸੰਭਵ ਹੋ ਸਕਣ ਤੱਕ ਛੋਟੀਆਂ ਰੱਖਣ ਲਈ ਲੇਅਰਾਂ ਦੀ ਗਿਣਤੀ ਘਟਾਉਣ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰੋ। ਇਸ ਦਾ ਇੱਕ ਤਰੀਕਾ ਮਿਲਦੀਆਂ-ਜੁਲਦੀਆਂ ਕਮਾਂਡਾਂ ਨੂੰ Dockerfile ਦੀ ਇੱਕੋ ਲਾਈਨ ਵਿੱਚ ਜੋੜਨਾ ਹੈ। ਉਦਾਹਰਨ ਵਜੋਂ, ਪੈਕੇਜ ਸੂਚੀ ਅੱਪਡੇਟ ਕਰਨ ਅਤੇ ਪੈਕੇਜ ਇੰਸਟਾਲ ਕਰਨ ਲਈ ਦੋ ਵੱਖਰੀਆਂ `RUN` ਕਮਾਂਡਾਂ ਦੀ ਥਾਂ ਇੱਕ `RUN` ਕਮਾਂਡ ਦੋਵੇਂ ਕੰਮ ਕਰ ਸਕਦੀ ਹੈ।

ਉਦਾਹਰਨ:
```dockerfile
RUN apt update
RUN apt install apache -y
```
ਦੀ ਥਾਂ
```dockerfile
RUN apt update && apt install apache -y
```

### ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ ਵਰਤੋ

Dockerfile ਵਿੱਚ ਮੁੱਲਾਂ ਨੂੰ ਪੱਕਾ ਲਿਖਣ ਦੀ ਥਾਂ ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ ਵਰਤਣ ਨਾਲ ਰਨਟਾਈਮ ਉੱਤੇ ਕੰਟੇਨਰ ਨੂੰ ਆਪਣੀ ਲੋੜ ਮੁਤਾਬਕ ਬਦਲਣਾ ਆਸਾਨ ਹੁੰਦਾ ਹੈ ਅਤੇ Dockerfile ਪੋਰਟੇਬਲ ਰਹਿੰਦੀ ਹੈ। ਉਦਾਹਰਨ ਵਜੋਂ, ਤੁਸੀਂ ਐਪਲੀਕੇਸ਼ਨ ਦਾ ਪੋਰਟ ਜਾਂ ਸੰਰਚਨਾ ਫਾਈਲ ਦੀ ਥਾਂ ਦੱਸਣ ਲਈ ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ ਵਰਤ ਸਕਦੇ ਹੋ।

ਉਦਾਹਰਨ:
```bash
docker run -e PORT=3000 my-app
```
```Dockerfile
FROM node:14

# ਕੰਮ ਕਰਨ ਵਾਲੀ ਡਾਇਰੈਕਟਰੀ ਸੈੱਟ ਕਰੋ
WORKDIR /app

# package.json ਅਤੇ yarn.lock ਨੂੰ ਕੰਟੇਨਰ ਵਿੱਚ ਕਾਪੀ ਕਰੋ
COPY package.json yarn.lock ./

# ਨਿਰਭਰਤਾਵਾਂ ਇੰਸਟਾਲ ਕਰੋ
RUN yarn install --frozen-lockfile

# ਐਪਲੀਕੇਸ਼ਨ ਕੋਡ ਕੰਟੇਨਰ ਵਿੱਚ ਕਾਪੀ ਕਰੋ
COPY . .

# ਐਪਲੀਕੇਸ਼ਨ ਪੋਰਟ ਖੋਲ੍ਹੋ
EXPOSE $PORT

# ਐਪਲੀਕੇਸ਼ਨ ਸ਼ੁਰੂ ਕਰੋ
CMD ["yarn", "start"]
```


### ਵਾਲਿਊਮ ਮਾਊਂਟ ਵਰਤੋ

ਵਾਲਿਊਮ ਮਾਊਂਟ ਹੋਸਟ ਸਿਸਟਮ ਅਤੇ Docker ਕੰਟੇਨਰ ਵਿਚਕਾਰ ਡਾਟਾ ਸਾਂਝਾ ਕਰਨ ਦਾ ਤਰੀਕਾ ਹਨ। ਇਸ ਨਾਲ ਡਾਟਾ ਸੰਭਾਲਣਾ ਆਸਾਨ ਹੁੰਦਾ ਹੈ ਅਤੇ Docker ਕੰਟੇਨਰ ਦਾ ਆਕਾਰ ਘਟਦਾ ਹੈ। ਉਦਾਹਰਨ ਵਜੋਂ, ਹੋਸਟ ਸਿਸਟਮ ਅਤੇ ਕੰਟੇਨਰ ਵਿਚਕਾਰ ਡਾਟਾਬੇਸ ਫਾਈਲ ਸਾਂਝੀ ਕਰਨ ਲਈ ਵਾਲਿਊਮ ਮਾਊਂਟ ਵਰਤਿਆ ਜਾ ਸਕਦਾ ਹੈ।

ਉਦਾਹਰਨ:
```bash
docker run -v /home/user/app/data:/app/data my-app
```

```Dockerfile
FROM node:14

# ਕੰਮ ਕਰਨ ਵਾਲੀ ਡਾਇਰੈਕਟਰੀ ਸੈੱਟ ਕਰੋ
WORKDIR /app

# package.json ਅਤੇ yarn.lock ਫਾਈਲਾਂ ਕੰਟੇਨਰ ਵਿੱਚ ਕਾਪੀ ਕਰੋ
COPY package.json yarn.lock ./

# ਨਿਰਭਰਤਾਵਾਂ ਇੰਸਟਾਲ ਕਰੋ
RUN yarn install --frozen-lockfile

# ਐਪਲੀਕੇਸ਼ਨ ਦਾ ਬਾਕੀ ਕੋਡ ਕੰਟੇਨਰ ਵਿੱਚ ਕਾਪੀ ਕਰੋ
COPY . .

# ਐਪਲੀਕੇਸ਼ਨ ਪੋਰਟ ਖੋਲ੍ਹੋ
EXPOSE 3000

# ਐਪਲੀਕੇਸ਼ਨ ਸ਼ੁਰੂ ਕਰੋ
CMD ["yarn", "start"]

# ਐਪਲੀਕੇਸ਼ਨ ਡਾਟਾ ਲਈ ਵਾਲਿਊਮ ਮਾਊਂਟ ਕਰੋ
VOLUME ["/app/data"]
```

### ਰੂਟ ਵਜੋਂ ਚਲਾਉਣ ਤੋਂ ਬਚੋ

Docker ਕੰਟੇਨਰ ਨੂੰ ਰੂਟ ਵਰਤੋਂਕਾਰ ਵਜੋਂ ਚਲਾਉਣਾ ਸੁਰੱਖਿਆ ਲਈ ਖਤਰਾ ਬਣ ਸਕਦਾ ਹੈ। ਇਸ ਦੀ ਥਾਂ Dockerfile ਵਿੱਚ ਨਵਾਂ ਵਰਤੋਂਕਾਰ ਬਣਾਓ ਅਤੇ ਕੰਟੇਨਰ ਉਸ ਵਰਤੋਂਕਾਰ ਵਜੋਂ ਚਲਾਓ। ਉਦਾਹਰਨ ਵਜੋਂ, Dockerfile ਵਿੱਚ `USER` ਕਮਾਂਡ ਨਾਲ ਨਵਾਂ ਵਰਤੋਂਕਾਰ ਬਣਾਇਆ ਜਾ ਸਕਦਾ ਹੈ ਅਤੇ ਫਿਰ ਕੰਟੇਨਰ ਚਲਾਉਂਦੇ ਸਮੇਂ ਉਸ ਵਰਤੋਂਕਾਰ ਉੱਤੇ ਬਦਲਿਆ ਜਾ ਸਕਦਾ ਹੈ।

ਉਦਾਹਰਨ:
```Dockerfile
FROM node:14

# ਕੰਟੇਨਰ ਚਲਾਉਣ ਲਈ ਨਵਾਂ ਵਰਤੋਂਕਾਰ ਬਣਾਓ
RUN useradd --user-group --create-home --shell /bin/false app

# ਕੰਮ ਵਾਲੀ ਡਾਇਰੈਕਟਰੀ ਨੂੰ app ਵਰਤੋਂਕਾਰ ਦੇ ਘਰੇਲੂ ਡਾਇਰੈਕਟਰੀ ਵਿੱਚ ਬਦਲੋ
WORKDIR /home/app

# app ਵਰਤੋਂਕਾਰ ਵਜੋਂ ਨਿਰਭਰਤਾਵਾਂ ਇੰਸਟਾਲ ਕਰੋ
COPY package.json yarn.lock ./
RUN chown -R app:app /home/app
USER app
RUN yarn install --frozen-lockfile --production

# app ਵਰਤੋਂਕਾਰ ਵਜੋਂ ਐਪਲੀਕੇਸ਼ਨ ਕੋਡ ਕਾਪੀ ਕਰੋ
COPY --chown=app:app . .

# ਪੋਰਟ ਖੋਲ੍ਹੋ
EXPOSE 3000

# app ਵਰਤੋਂਕਾਰ ਵਜੋਂ ਐਪਲੀਕੇਸ਼ਨ ਸ਼ੁਰੂ ਕਰੋ
CMD ["yarn", "start"]
```

### ਇਮੇਜਾਂ ਨੂੰ ਅੱਪ-ਟੂ-ਡੇਟ ਰੱਖੋ

Docker ਕੰਟੇਨਰ ਸੁਰੱਖਿਅਤ ਅਤੇ ਕਮਜ਼ੋਰੀਆਂ ਤੋਂ ਮੁਕਤ ਰੱਖਣ ਲਈ Docker ਇਮੇਜਾਂ ਨੂੰ ਅੱਪ-ਟੂ-ਡੇਟ ਰੱਖਣਾ ਮਹੱਤਵਪੂਰਨ ਹੈ। ਇਸ ਦਾ ਮਤਲਬ ਬੇਸ ਇਮੇਜ ਅਤੇ ਐਪਲੀਕੇਸ਼ਨ ਦੀਆਂ ਨਿਰਭਰਤਾਵਾਂ ਨੂੰ ਨਿਯਮਿਤ ਤੌਰ ਉੱਤੇ ਅੱਪਡੇਟ ਕਰਨਾ ਹੈ। ਉਦਾਹਰਨ ਵਜੋਂ, Dockerfile ਵਿੱਚ `apt-get update` ਅਤੇ `apt-get upgrade` ਕਮਾਂਡਾਂ ਵਰਤ ਕੇ ਕੰਟੇਨਰ ਵਿੱਚ ਨਵੀਨਤਮ ਸੁਰੱਖਿਆ ਪੈਚ ਅਤੇ ਬੱਗ ਫਿਕਸ ਰੱਖੇ ਜਾ ਸਕਦੇ ਹਨ।

ਉਦਾਹਰਨ:
```Dockerfile
FROM ubuntu:latest

# ਪੈਕੇਜ ਸੂਚੀ ਅੱਪਡੇਟ ਕਰੋ ਅਤੇ ਸੁਰੱਖਿਆ ਅੱਪਡੇਟ ਇੰਸਟਾਲ ਕਰੋ
RUN apt-get update && apt-get upgrade -y && apt-get clean

# nginx ਵੈੱਬ ਸਰਵਰ ਇੰਸਟਾਲ ਕਰੋ
RUN apt-get install -y nginx

# ਐਪਲੀਕੇਸ਼ਨ ਕੋਡ ਕੰਟੇਨਰ ਵਿੱਚ ਕਾਪੀ ਕਰੋ
COPY . /var/www/html/

# ਹੋਸਟ ਸਿਸਟਮ ਲਈ ਪੋਰਟ 80 ਖੋਲ੍ਹੋ
EXPOSE 80

# nginx ਸਰਵਰ ਸ਼ੁਰੂ ਕਰੋ
CMD ["nginx", "-g", "daemon off;"]

```
## ਹੋਰ ਪੜ੍ਹੋ
### Docker ਦਸਤਾਵੇਜ਼
[Docker](https://www.docker.com/) ਕੰਟੇਨਰਾਂ ਵਿੱਚ ਐਪਲੀਕੇਸ਼ਨ ਬਣਾਉਣ, ਭੇਜਣ ਅਤੇ ਚਲਾਉਣ ਲਈ ਓਪਨ-ਸੋਰਸ ਪਲੇਟਫਾਰਮ ਹੈ। Docker ਦਸਤਾਵੇਜ਼ੀ ਵੈੱਬਸਾਈਟ ਵਿੱਚ ਵੱਖ-ਵੱਖ ਓਪਰੇਟਿੰਗ ਸਿਸਟਮਾਂ ਅਤੇ ਵਰਤੋਂ ਦੇ ਮਾਮਲਿਆਂ ਲਈ Docker ਇੰਸਟਾਲ ਕਰਨ, ਸੰਰਚਿਤ ਕਰਨ ਅਤੇ ਵਰਤਣ ਬਾਰੇ ਵਿਸਤ੍ਰਿਤ ਜਾਣਕਾਰੀ ਹੈ। ਇਸ ਵਿੱਚ Docker APIs, Docker CLI ਕਮਾਂਡਾਂ ਅਤੇ ਸਮੱਸਿਆਵਾਂ ਹੱਲ ਕਰਨ ਦੇ ਸੁਝਾਅ ਵੀ ਹਨ।

Docker ਦਸਤਾਵੇਜ਼ਾਂ ਦੇ ਕੁਝ ਲਾਭਦਾਇਕ ਭਾਗ:

- [Docker ਨਾਲ ਸ਼ੁਰੂ ਕਰੋ](https://docs.docker.com/get-started/)
- [Docker CLI ਹਵਾਲਾ](https://docs.docker.com/engine/reference/commandline/cli/)
- [Docker API ਹਵਾਲਾ](https://docs.docker.com/engine/api/v1.41/)
- [Docker Compose ਹਵਾਲਾ](https://docs.docker.com/compose/compose-file/)
- [Dockerfile ਹਵਾਲਾ](https://docs.docker.com/engine/reference/builder/)

Docker ਦਸਤਾਵੇਜ਼ Docker ਵਰਤਣਾ ਸਿੱਖਣ ਅਤੇ ਆਉਣ ਵਾਲੀਆਂ ਸਮੱਸਿਆਵਾਂ ਦਾ ਹੱਲ ਲੱਭਣ ਲਈ ਵਧੀਆ ਸਰੋਤ ਹਨ।

### Docker Hub

[Docker Hub](https://hub.docker.com/) ਇੱਕ ਕਲਾਊਡ-ਅਧਾਰਿਤ ਰਿਪੋਜ਼ਟਰੀ ਹੈ ਜੋ ਤੁਹਾਨੂੰ Docker ਇਮੇਜਾਂ ਸੰਭਾਲਣ, ਸਾਂਝੀਆਂ ਕਰਨ ਅਤੇ ਪ੍ਰਬੰਧਿਤ ਕਰਨ ਦਿੰਦੀ ਹੈ। Docker Hub ਵਿੱਚ ਜਨਤਕ ਅਤੇ ਨਿੱਜੀ ਰਿਪੋਜ਼ਟਰੀਆਂ ਦੇ ਨਾਲ ਆਟੋਮੈਟਿਕ ਬਿਲਡ ਅਤੇ ਵਰਕਫਲੋ ਵੀ ਹਨ। ਤੁਸੀਂ ਆਪਣੀਆਂ Docker ਇਮੇਜਾਂ ਸੰਭਾਲਣ ਦੇ ਨਾਲ ਪ੍ਰਸਿੱਧ ਸਾਫਟਵੇਅਰ ਐਪਲੀਕੇਸ਼ਨਾਂ ਅਤੇ ਔਜ਼ਾਰਾਂ ਲਈ ਪਹਿਲਾਂ ਤੋਂ ਬਣੀਆਂ ਇਮੇਜਾਂ ਵੀ ਲੱਭ ਸਕਦੇ ਹੋ।

Docker Hub ਦੀਆਂ ਕੁਝ ਲਾਭਦਾਇਕ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ:

- [Docker ਇਮੇਜਾਂ ਲੱਭੋ](https://hub.docker.com/search?type=image)
- [ਰਿਪੋਜ਼ਟਰੀਆਂ ਵਿੱਚ ਇਮੇਜਾਂ ਸੰਭਾਲੋ ਅਤੇ ਪ੍ਰਬੰਧਿਤ ਕਰੋ](https://hub.docker.com/repositories)
- [Docker Hub ਵਰਕਫਲੋ ਨਾਲ ਬਿਲਡ ਅਤੇ ਟੈਸਟਿੰਗ ਆਟੋਮੈਟਿਕ ਕਰੋ](https://docs.docker.com/docker-hub/builds/)

Docker ਨਾਲ ਕੰਮ ਕਰਨ ਲਈ Docker Hub ਇੱਕ ਜ਼ਰੂਰੀ ਔਜ਼ਾਰ ਹੈ ਅਤੇ ਇਮੇਜਾਂ ਸੰਭਾਲਣ ਅਤੇ ਸਾਂਝੀਆਂ ਕਰਨ ਵਿੱਚ ਤੁਹਾਡਾ ਬਹੁਤ ਸਮਾਂ ਅਤੇ ਮਿਹਨਤ ਬਚਾ ਸਕਦਾ ਹੈ।

## ਨਤੀਜਾ

Docker ਇੱਕ ਤਾਕਤਵਰ ਔਜ਼ਾਰ ਹੈ ਜੋ ਐਪਲੀਕੇਸ਼ਨਾਂ ਨੂੰ ਹੋਰ ਪੋਰਟੇਬਲ, ਕੁਸ਼ਲ ਅਤੇ ਆਸਾਨੀ ਨਾਲ ਡਿਪਲੌਇ ਹੋਣ ਯੋਗ ਬਣਾਉਂਦਾ ਹੈ। ਇਨ੍ਹਾਂ ਵਧੀਆ ਤਰੀਕਿਆਂ ਅਤੇ ਸੁਝਾਵਾਂ ਦੀ ਪਾਲਣਾ ਕਰਕੇ ਤੁਸੀਂ ਸੁਰੱਖਿਅਤ, ਵਰਤਣ ਵਿੱਚ ਆਸਾਨ ਅਤੇ ਤੇਜ਼ੀ ਨਾਲ ਡਿਪਲੌਇ ਹੋਣ ਵਾਲੇ Docker ਕੰਟੇਨਰ ਬਣਾ ਸਕਦੇ ਹੋ। ਤੁਸੀਂ ਨਵੀਂ ਐਪਲੀਕੇਸ਼ਨ ਬਣਾ ਰਹੇ ਹੋਵੋ ਜਾਂ ਮੌਜੂਦਾ ਐਪਲੀਕੇਸ਼ਨ ਨੂੰ Docker ਵੱਲ ਲਿਜਾ ਰਹੇ ਹੋਵੋ, ਇਹ ਕਦਮ Docker ਕੰਟੇਨਰ ਬਣਾਉਣ ਦੀ ਸ਼ੁਰੂਆਤ ਵਿੱਚ ਮਦਦ ਕਰਨਗੇ।
