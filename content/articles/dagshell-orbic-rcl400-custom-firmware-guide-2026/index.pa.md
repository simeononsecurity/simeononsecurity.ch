## ਜਾਣ-ਪਛਾਣ: ਹੈਕਰਾਂ ਦਾ ਹੌਟਸਪੌਟ

**DagShell**, **Orbic RCL400 ਮੋਬਾਈਲ ਹੌਟਸਪੌਟ** ਲਈ ਓਪਨ-ਸੋਰਸ ਕਸਟਮ ਫਰਮਵੇਅਰ ਹੈ। ਇਹ ਆਮ ਸੈਲੂਲਰ ਡਿਵਾਈਸ ਨੂੰ **ਪੋਰਟੇਬਲ ਸੁਰੱਖਿਆ ਖੋਜ ਅਤੇ ਗੋਪਨੀਯਤਾ ਟੂਲਕਿੱਟ** ਵਿੱਚ ਬਦਲਦਾ ਹੈ। ਸੁਰੱਖਿਆ ਖੋਜਕਾਰ “dag” ਵੱਲੋਂ ਬਣਾਇਆ ਇਹ ਟਰਮੀਨਲ-ਸ਼ੈਲੀ ਫਰਮਵੇਅਰ ਹਰੇ-ਕਾਲੇ ਹੈਕਰ ਇੰਟਰਫੇਸ ਵਿੱਚ **ਹੈਕਿੰਗ ਟੂਲ, ਗੋਪਨੀਯਤਾ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਅਤੇ ਨੈੱਟਵਰਕ ਨਿਗਰਾਨੀ** ਦਿੰਦਾ ਹੈ।

ਇਸ ਵਿਸਤ੍ਰਿਤ ਗਾਈਡ ਵਿੱਚ ਇਹ ਸ਼ਾਮਲ ਹੈ:
- **DagShell ਕੀ ਹੈ** ਅਤੇ ਇਸ ਦੀਆਂ ਸਾਰੀਆਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ

- ਸਾਰੇ ਟੂਲ ਅਤੇ ਉਨ੍ਹਾਂ ਦੀਆਂ ਸਮਰੱਥਾਵਾਂ
- ਵਾਧੂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਲਈ **Raspberry Pi ਸਾਥੀ** ਸੈੱਟਅੱਪ

## DagShell ਕੀ ਹੈ?

### ਝਲਕ

**DagShell** ਓਪਨ-ਸੋਰਸ ਕਸਟਮ ਫਰਮਵੇਅਰ ਹੈ, ਜੋ Orbic RCL400 ਦੇ ਮੂਲ ਵੈੱਬ ਇੰਟਰਫੇਸ ਦੀ ਥਾਂ **ਸੁਰੱਖਿਆ ਟੂਲਕਿੱਟ** ਦਿੰਦਾ ਹੈ। ਇਸ ਵਿੱਚ ਸ਼ਾਮਲ ਹਨ:

- ASCII ਕਲਾ ਅਤੇ ਹੈਕਰ ਦਿੱਖ ਵਾਲਾ **ਟਰਮੀਨਲ-ਸ਼ੈਲੀ ਇੰਟਰਫੇਸ**
- **TLS 1.2+ ਇਨਕ੍ਰਿਪਸ਼ਨ** ਵਾਲਾ ਵੈੱਬ ਇੰਟਰਫੇਸ (ਆਪਣੇ ਦਸਤਖ਼ਤ ਵਾਲਾ ਸਰਟੀਫਿਕੇਟ)
- **ਗੋਪਨੀਯਤਾ ਸੁਰੱਖਿਆ ਟੂਲ** (TTL ਮਾਸਕਿੰਗ, MAC ਸਪੂਫਿੰਗ, DNS ਰਾਹੀਂ ਵਿਗਿਆਪਨ ਰੋਕਣਾ)
- **ਨੈੱਟਵਰਕ ਨਿਗਰਾਨੀ** (ਸਰਗਰਮ ਕਨੈਕਸ਼ਨ, ਰੂਟਿੰਗ ਟੇਬਲਾਂ, DNS ਸਵਾਲ)
- **ਹੈਕਿੰਗ ਟੂਲ** (IMSI ਕੈਚਰ ਪਛਾਣ, ਪੋਰਟ ਸਕੈਨਿੰਗ, ARP ਖੋਜ)
- **ਹਮਲਾ ਕਰਨ ਦੀਆਂ ਸਮਰੱਥਾਵਾਂ** (Evil Twin AP, ਕੈਪਟਿਵ ਪੋਰਟਲ ਫਿਸ਼ਿੰਗ, ਡੀ-ਆਥ ਹਮਲੇ)
- Wigle-ਅਨੁਕੂਲ CSV ਨਿਰਯਾਤ ਨਾਲ **GPS ਟ੍ਰੈਕਿੰਗ ਅਤੇ ਵਾਰਡਰਾਈਵਿੰਗ**
- GPS, Bluetooth ਸਕੈਨਿੰਗ ਅਤੇ WiFi ਜਾਂਚ ਲਈ **Raspberry Pi ਸਾਥੀ**
- ਬ੍ਰਾਊਜ਼ਰ ਫਾਈਲ ਮੈਨੇਜਰ ਰਾਹੀਂ **ਫਾਈਲ ਸਿਸਟਮ ਪਹੁੰਚ**
- AT ਕਮਾਂਡਾਂ ਰਾਹੀਂ **SMS ਵਿਸ਼ੇਸ਼ਤਾ**
- **ਸਥਾਈ ਸ਼ੁਰੂਆਤ**: ਬੂਟ ਵੇਲੇ ਆਪਣੇ ਆਪ ਚੱਲਦਾ ਹੈ

## ਸਾਰੀਆਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ

### 🏠 ਡੈਸ਼ਬੋਰਡ

**ਸਿਸਟਮ ਝਲਕ**:
- **ਚੱਲਣ ਦਾ ਸਮਾਂ**: ਡਿਵਾਈਸ ਕਿੰਨੇ ਸਮੇਂ ਤੋਂ ਚੱਲ ਰਿਹਾ ਹੈ
- **AT ਕਮਾਂਡ ਇੰਟਰਫੇਸ**: ਤਜਰਬੇਕਾਰ ਵਰਤੋਂਕਾਰਾਂ ਲਈ ਸਿੱਧਾ ਮੋਡਮ ਕੰਟਰੋਲ
- **ਤੁਰੰਤ ਸਥਿਤੀ**: IP ਪਤਾ ਅਤੇ ਕਨੈਕਸ਼ਨ ਦੀ ਹਾਲਤ

**AT ਕਮਾਂਡਾਂ** ਮੋਡਮ ਉੱਤੇ ਹੇਠਲੇ ਪੱਧਰ ਦਾ ਕੰਟਰੋਲ ਦਿੰਦੀਆਂ ਹਨ:
```
Example AT Commands:
AT+CSQ       - Signal quality
AT+COPS?     - Current network operator  
AT+CREG?     - Network registration status
AT+CIMI      - Get IMSI (subscriber identity)
AT+CGSN      - Get IMEI (device identifier)
```

### 🌐 ਨੈੱਟਵਰਕ ਟੂਲ

**ਮੌਜੂਦਾ ਨੈੱਟਵਰਕ ਜਾਣਕਾਰੀ**:
- **IP ਪਤਾ ਅਤੇ ਇੰਟਰਫੇਸ** ਦੇ ਵੇਰਵੇ
- **ਸਬਨੈੱਟ ਮਾਸਕ, ਗੇਟਵੇ**, ਬਰਾਡਕਾਸਟ ਪਤਾ
- **ਨੈੱਟਵਰਕ ਅੰਕੜੇ** (ਭੇਜੇ ਅਤੇ ਪ੍ਰਾਪਤ ਕੀਤੇ ਪੈਕੇਟ)

**ਰੂਟਿੰਗ ਟੇਬਲ ਦਰਸ਼ਕ**:
- ਸਾਰੇ ਨੈੱਟਵਰਕ ਰੂਟ ਵੇਖੋ
- ਮੂਲ ਗੇਟਵੇ ਦੀ ਜਾਣਕਾਰੀ
- ਇੰਟਰਫੇਸਾਂ ਦੀ ਮੈਪਿੰਗ

**ਸਰਗਰਮ ਕਨੈਕਸ਼ਨ ਨਿਗਰਾਨੀ**:
- ਰੀਅਲ-ਟਾਈਮ ਵਿੱਚ **ਸਾਰੇ TCP/UDP ਕਨੈਕਸ਼ਨਾਂ** ਦੀ ਸੂਚੀ
- ਸਥਾਨਕ ਅਤੇ ਦੂਰਲੇ IP ਪਤੇ
- ਪੋਰਟ ਨੰਬਰ ਅਤੇ ਕਨੈਕਸ਼ਨ ਦੀਆਂ ਸਥਿਤੀਆਂ
- ਡਿਵਾਈਸ ਕਿਸ ਨਾਲ ਸੰਚਾਰ ਕਰਦਾ ਹੈ, ਇਹ **ਨਿਗਰਾਨੀ ਕਰਨ** ਲਈ ਲਾਭਦਾਇਕ

### 🔒 ਗੋਪਨੀਯਤਾ ਸੁਰੱਖਿਆ ਟੂਲਕਿੱਟ

#### TTL ਸੁਧਾਰ

**ਉਦੇਸ਼**: ਕੈਰੀਅਰ ਦੀ ਪਛਾਣ ਤੋਂ ਹੌਟਸਪੌਟ ਟ੍ਰੈਫਿਕ ਲੁਕਾਉਣਾ

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
- IP ਪੈਕੇਟਾਂ ਵਿੱਚ **Time To Live (TTL)** ਮੁੱਲ ਨੂੰ **65** ਕਰਦਾ ਹੈ
- TTL ਘਟਣ ਰਾਹੀਂ ਕੈਰੀਅਰ ਟੈਦਰਿੰਗ ਪਛਾਣਦੇ ਹਨ (ਫੋਨ=64, ਟੈਦਰ ਕੀਤਾ ਡਿਵਾਈਸ=63)
- TTL ਨੂੰ 65 ਕਰਨ ਨਾਲ **ਸਾਰਾ ਟ੍ਰੈਫਿਕ ਸਥਾਨਕ ਦਿਸਦਾ ਹੈ**

**ਵਰਤੋਂ**: ਕੈਰੀਅਰ ਦੀਆਂ ਟੈਦਰਿੰਗ ਪਾਬੰਦੀਆਂ ਜਾਂ ਗਤੀ ਸੀਮਾਵਾਂ ਤੋਂ ਬਚਣਾ

**ਕਮਾਂਡਾਂ**:
```bash
# Enable TTL fix
iptables -t mangle -A POSTROUTING -j TTL --ttl-set 65

# Disable TTL fix  
iptables -t mangle -D POSTROUTING -j TTL --ttl-set 65
```

#### MAC ਪਤਾ ਸਪੂਫਿੰਗ

**ਉਦੇਸ਼**: ਗੋਪਨੀਯਤਾ ਲਈ ਡਿਵਾਈਸ ਦਾ MAC ਪਤਾ ਬਦਲਣਾ

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
- WiFi ਇੰਟਰਫੇਸ `wlan0` ਦਾ MAC ਪਤਾ ਬਦਲਦਾ ਹੈ
- **ਬੇਤਰਤੀਬ MAC** ਬਣਾਉਂਦਾ ਹੈ ਜਾਂ ਆਪਣਾ ਮੁੱਲ ਦਰਜ ਕਰਨ ਦਿੰਦਾ ਹੈ
- ਵੱਖ-ਵੱਖ ਸੈਸ਼ਨਾਂ ਵਿੱਚ ਡਿਵਾਈਸ ਨੂੰ **ਟ੍ਰੈਕ ਕਰਨਾ ਔਖਾ** ਕਰਦਾ ਹੈ

**ਵਰਤੋਂ**: ਜਿਨ੍ਹਾਂ ਨੈੱਟਵਰਕਾਂ ਨਾਲ ਤੁਸੀਂ ਜੁੜਦੇ ਹੋ, ਉਨ੍ਹਾਂ ਵੱਲੋਂ MAC ਅਧਾਰਿਤ ਟ੍ਰੈਕਿੰਗ ਰੋਕਣਾ

**ਪ੍ਰਕਿਰਿਆ**:
1. ਇੰਟਰਫੇਸ ਬੰਦ ਹੁੰਦਾ ਹੈ
2. ਨਵਾਂ MAC ਪਤਾ ਲਾਗੂ ਹੁੰਦਾ ਹੈ
3. ਇੰਟਰਫੇਸ ਮੁੜ ਚਾਲੂ ਹੁੰਦਾ ਹੈ
4. ਕਨੈਕਸ਼ਨ ਮੁੜ ਸਥਾਪਤ ਹੁੰਦਾ ਹੈ

#### DNS ਰਾਹੀਂ ਵਿਗਿਆਪਨ ਰੋਕਣਾ

**ਉਦੇਸ਼**: DNS ਪੱਧਰ ਉੱਤੇ ਵਿਗਿਆਪਨ ਅਤੇ ਟ੍ਰੈਕਿੰਗ ਰੋਕਣਾ

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
- `/etc/hosts` ਫਾਈਲ ਵਿੱਚ **ਬਲਾਕਲਿਸਟ** ਜੋੜਦਾ ਹੈ
- ਸੂਚੀ ਦੇ ਡੋਮੇਨ **127.0.0.1** (localhost) ਵੱਲ ਜਾਂਦੇ ਹਨ
- **ਸਾਰੇ ਜੁੜੇ ਡਿਵਾਈਸਾਂ** ਲਈ ਵਿਗਿਆਪਨ ਰੋਕਦਾ ਹੈ

**ਵਰਤੋਂ**: ਹਰ ਡਿਵਾਈਸ ਦੀ ਵੱਖਰੀ ਸੈਟਿੰਗ ਤੋਂ ਬਿਨਾਂ ਪੂਰੇ ਨੈੱਟਵਰਕ ਉੱਤੇ ਵਿਗਿਆਪਨ ਰੋਕਣਾ

**ਬਲਾਕਲਿਸਟ ਸਰੋਤ**: ਆਮ ਵਿਗਿਆਪਨ ਅਤੇ ਟ੍ਰੈਕਿੰਗ ਡੋਮੇਨ (ਬਦਲਣਯੋਗ)

### 🔧 ਹੈਕਿੰਗ ਟੂਲ

#### IMSI ਕੈਚਰ ਡਿਟੈਕਟਰ

**ਉਦੇਸ਼**: ਸੈੱਲ ਟਾਵਰਾਂ ਦੀ ਜਾਣਕਾਰੀ ਵਿੱਚ ਉਹ ਅਸਧਾਰਨਤਾਵਾਂ ਵੇਖਣਾ ਜੋ **IMSI ਕੈਚਰ/Stingray** ਡਿਵਾਈਸਾਂ ਵੱਲ ਇਸ਼ਾਰਾ ਕਰਦੀਆਂ ਹਨ

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
- ਮੋਡਮ ਤੋਂ **ਸੈੱਲ ਟਾਵਰ ਡਾਟਾ** ਲੈਂਦਾ ਹੈ:
  - **Cell ID** (ਟਾਵਰ ਦੀ ਪਛਾਣ)
  - **LAC** (Location Area Code)
  - **MCC/MNC** (Mobile Country/Network Code)
  - **ਸਿਗਨਲ ਤਾਕਤ** (RSSI)
  - **ਨੈੱਟਵਰਕ ਪੀੜ੍ਹੀ** (2G/3G/4G)
- ਸ਼ੱਕੀ ਟਾਵਰ ਬਦਲਾਅ ਪਛਾਣਨ ਲਈ **ਬਦਲਾਅ ਲੌਗ ਕਰਦਾ ਹੈ**
- ਆਮ ਇਲਾਕਾਈ ਟਾਵਰਾਂ ਦੀ **ਮੁੱਢਲੀ ਸਥਿਤੀ ਦਰਜ ਕਰਦਾ ਹੈ**

**ਪਛਾਣ ਦੇ ਸੰਕੇਤ**:
- ਸਥਿਰ ਰਹਿੰਦਿਆਂ **ਸੈੱਲ ਟਾਵਰ ਦਾ ਅਚਾਨਕ ਬਦਲਣਾ**
- **2G ਉੱਤੇ ਘਟਣਾ** *(IMSI ਕੈਚਰ ਅਕਸਰ ਇਨਕ੍ਰਿਪਸ਼ਨ ਹਟਾਉਣ ਲਈ 2G ਮਜਬੂਰ ਕਰਦੇ ਹਨ)*
- **ਅਣਜਾਣ Cell ID** ਦਾ ਦਿਖਣਾ
- ਨਕਲੀ ਟਾਵਰ ਤੋਂ **ਕਮਜ਼ੋਰ ਸਿਗਨਲ**
- ਵਾਰ-ਵਾਰ ਮੁੜ ਕਨੈਕਸ਼ਨ

**RayHunter ਨਾਲ ਸਾਂਝਾ ਕੰਮ**: DagShell **ਸੈੱਲ ਟਾਵਰਾਂ ਦੀ ਨਿਗਰਾਨੀ** ਕਰਦਾ ਹੈ, ਜਦਕਿ RayHunter ਹੋਰ ਗਹਿਰੇ ਵਿਸ਼ਲੇਸ਼ਣ ਨਾਲ **IMSI ਕੈਚਰਾਂ ਦੀ ਖ਼ਾਸ ਪਛਾਣ** ਕਰਦਾ ਹੈ (ਹੇਠਾਂ ਭਾਗ ਵੇਖੋ)।

#### ਪੋਰਟ ਸਕੈਨਰ

**ਉਦੇਸ਼**: ਖੁੱਲ੍ਹੇ ਪੋਰਟ ਲੱਭਣ ਲਈ ਨਿਸ਼ਾਨਾ IP ਪਤਿਆਂ ਨੂੰ ਸਕੈਨ ਕਰਨਾ

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
- **TCP SYN ਸਕੈਨਿੰਗ**: ਨਿਸ਼ਾਨਾ ਪੋਰਟਾਂ ਵੱਲ SYN ਪੈਕੇਟ ਭੇਜਦਾ ਹੈ
- **ਟਾਈਮਆਉਟ ਪਛਾਣ**: ਖੁੱਲ੍ਹਾ, ਬੰਦ ਜਾਂ ਫਿਲਟਰ ਕੀਤਾ ਪੋਰਟ ਪਛਾਣਦਾ ਹੈ
- **ਰੇਂਜ ਸਹਾਇਤਾ**: ਇਕ ਪੋਰਟ ਜਾਂ ਪੋਰਟਾਂ ਦੀ ਰੇਂਜ ਸਕੈਨ ਕਰੋ

**ਵਰਤੋਂ**:
- **ਨੈੱਟਵਰਕ ਰੀਕਾਨੈਸੈਂਸ**
- **IoT ਡਿਵਾਈਸ ਖੋਜ**
- ਸਥਾਨਕ ਨੈੱਟਵਰਕਾਂ ਦਾ **ਸੁਰੱਖਿਆ ਆਡਿਟ**
- ਸੇਵਾਵਾਂ ਦੀ ਪਛਾਣ

**ਕਮਾਂਡ**:
```bash
# Scan ports 1-1000 on target
nc -zv -w 2 TARGET_IP 1-1000 2>&1
```

#### ਫਾਇਰਵਾਲ ਮੈਨੇਜਰ

**ਉਦੇਸ਼**: iptables ਰਾਹੀਂ IP ਪਤੇ ਰੋਕਣ ਜਾਂ ਮੁੜ ਖੋਲ੍ਹਣੇ

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
- ਦਿੱਤੇ IP ਤੋਂ ਜਾਂ ਵੱਲ ਆਉਂਦੇ ਪੈਕੇਟ DROP ਕਰਨ ਲਈ **iptables ਨਿਯਮ**
- ਸੰਭਾਲੇ ਹੋਣ ਉੱਤੇ **ਸਥਾਈ ਨਿਯਮ** ਰੀਬੂਟ ਤੋਂ ਬਾਅਦ ਵੀ ਲਾਗੂ ਰਹਿੰਦੇ ਹਨ
- **ਵਾਈਟਲਿਸਟ/ਬਲੈਕਲਿਸਟ** ਵਿਸ਼ੇਸ਼ਤਾ

**ਵਰਤੋਂ**:
- **ਖ਼ਤਰਨਾਕ IP ਰੋਕੋ**
- **ਬਿਨਾਂ ਇਜਾਜ਼ਤ ਪਹੁੰਚ ਰੋਕੋ**
- ਟ੍ਰੈਫਿਕ ਨੂੰ ਤਰਜੀਹ ਦੇਣਾ ਜਾਂ ਫਿਲਟਰ ਕਰਨਾ
- ਮਾਪਿਆਂ ਦੇ ਕੰਟਰੋਲ

**ਕਮਾਂਡਾਂ**:
```bash
# Block IP
iptables -I INPUT -s IP_ADDRESS -j DROP
iptables -I OUTPUT -d IP_ADDRESS -j DROP

# Unblock IP
iptables -D INPUT -s IP_ADDRESS -j DROP
iptables -D OUTPUT -d IP_ADDRESS -j DROP
```

### ⚔️ ਹਮਲਾ ਟੂਲ

**ਮਹੱਤਵਪੂਰਨ ਕਾਨੂੰਨੀ ਸੂਚਨਾ**: ਇਹ ਟੂਲ ਸਿਰਫ਼ **ਅਧਿਕਾਰਤ ਸੁਰੱਖਿਆ ਟੈਸਟਿੰਗ** ਲਈ ਹਨ। ਜਿਨ੍ਹਾਂ ਨੈੱਟਵਰਕਾਂ ਦੇ ਤੁਸੀਂ ਮਾਲਕ ਨਹੀਂ ਜਾਂ ਜਿਨ੍ਹਾਂ ਦੀ ਲਿਖਤੀ ਇਜਾਜ਼ਤ ਨਹੀਂ, ਉਨ੍ਹਾਂ ਉੱਤੇ ਵਰਤਣਾ ਜ਼ਿਆਦਾਤਰ ਖੇਤਰਾਂ ਵਿੱਚ **ਗੈਰਕਾਨੂੰਨੀ** ਹੈ (ਅਮਰੀਕਾ ਦਾ Computer Fraud and Abuse Act, ਬ੍ਰਿਟੇਨ ਦਾ Computer Misuse Act ਆਦਿ)। ਇਨ੍ਹਾਂ ਨੂੰ ਸਿਰਫ਼ **ਆਪਣੇ ਨੈੱਟਵਰਕਾਂ** ਜਾਂ **ਨਿਯੰਤਰਿਤ ਲੈਬ ਮਾਹੌਲ** ਵਿੱਚ ਵਰਤੋ।

#### DNS ਸਨਿਫ਼ਰ

**ਉਦੇਸ਼**: ਜੁੜੇ ਕਲਾਇੰਟਾਂ ਦੇ DNS ਸਵਾਲ ਲੌਗ ਕਰਨਾ

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
- DNS ਪੋਰਟ 53 ਉੱਤੇ **iptables ਲੌਗਿੰਗ**
- **promiscuous mode ਦੀ ਲੋੜ ਨਹੀਂ**
- ਹੌਟਸਪੌਟ ਕਲਾਇੰਟਾਂ ਦੀਆਂ ਸਾਰੀਆਂ DNS ਬੇਨਤੀਆਂ ਲੌਗ ਕਰਦਾ ਹੈ
- ਕਲਾਇੰਟ ਕਿਹੜੀਆਂ **ਵੈੱਬਸਾਈਟਾਂ ਜਾਂ ਸੇਵਾਵਾਂ** ਖੋਲ੍ਹ ਰਹੇ ਹਨ, ਇਹ ਦਿਖਾਉਂਦਾ ਹੈ

**ਵਰਤੋਂ** (ਅਧਿਕਾਰਤ):
- **ਨੈੱਟਵਰਕ ਟ੍ਰੈਫਿਕ ਵਿਸ਼ਲੇਸ਼ਣ**
- **ਮਾਪਿਆਂ ਦੀ ਨਿਗਰਾਨੀ** (ਆਪਣੇ ਪਰਿਵਾਰ ਲਈ)
- ਆਪਣੇ ਡਿਵਾਈਸਾਂ ਉੱਤੇ **ਸੁਰੱਖਿਆ ਖੋਜ**
- **ਮੈਲਵੇਅਰ ਵਿਹਾਰ ਵਿਸ਼ਲੇਸ਼ਣ**

*ਇਹ ਜੁੜੇ ਕਲਾਇੰਟਾਂ ਤੋਂ ਮੈਟਾਡਾਟਾ (ਖੋਲ੍ਹੇ ਡੋਮੇਨ) ਇਕੱਠਾ ਕਰਦਾ ਹੈ। ਇਸ ਨੂੰ ਸਿਰਫ਼ ਆਪਣੇ ਜਾਂ ਆਪਣੇ ਪ੍ਰਬੰਧ ਹੇਠਲੇ ਨੈੱਟਵਰਕਾਂ ਉੱਤੇ ਲਾਗੂ ਕਰੋ।*

#### ARP ਸਕੈਨਰ

**ਉਦੇਸ਼**: ਸਥਾਨਕ ਨੈੱਟਵਰਕ ਉੱਤੇ ਡਿਵਾਈਸਾਂ ਲੱਭਣੇ

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
- ਸਬਨੈੱਟ ਦੇ ਸਾਰੇ IP ਪਤਿਆਂ ਵੱਲ **ARP ਬੇਨਤੀਆਂ** ਭੇਜਦਾ ਹੈ
- ਡਿਵਾਈਸ ਆਪਣੇ **MAC ਪਤਿਆਂ** ਨਾਲ ਜਵਾਬ ਦਿੰਦੇ ਹਨ
- **OUI ਖੋਜ** ਨਿਰਮਾਤਾ ਦੀ ਪਛਾਣ ਕਰਦੀ ਹੈ (Apple, Samsung ਆਦਿ)
- ਸਰਗਰਮ ਡਿਵਾਈਸਾਂ ਦਾ **ਨੈੱਟਵਰਕ ਨਕਸ਼ਾ** ਬਣਾਉਂਦਾ ਹੈ

**ਵਰਤੋਂ**:
- **ਨੈੱਟਵਰਕ ਸੂਚੀ**
- **ਅਣਜਾਣ ਡਿਵਾਈਸ ਪਛਾਣ**
- **BYOD ਨੈੱਟਵਰਕ ਵਿਸ਼ਲੇਸ਼ਣ**
- **IoT ਡਿਵਾਈਸ ਖੋਜ**

**ਨਤੀਜੇ ਦੀ ਉਦਾਹਰਨ**:
```
IP: 192.168.1.50
MAC: A4:83:E7:XX:XX:XX
Vendor: Apple, Inc.

IP: 192.168.1.75
MAC: 2C:54:91:XX:XX:XX
Vendor: Samsung Electronics
```

#### Traceroute

**ਉਦੇਸ਼**: ਮੰਜ਼ਿਲ ਤੱਕ ਨੈੱਟਵਰਕ ਰਸਤਾ ਦਿਖਾਉਣਾ

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
- ਵਧਦੇ **TTL** ਵਾਲੇ ਪੈਕੇਟ ਭੇਜਦਾ ਹੈ
- ਹਰ hop TTL ਘਟਾਉਂਦਾ ਹੈ ਅਤੇ **ICMP Time Exceeded** ਜਵਾਬ ਦਿੰਦਾ ਹੈ
- ਮੰਜ਼ਿਲ ਤੱਕ ਦੇ **ਰਾਊਟਰ ਅਤੇ ਰਸਤਾ** ਦਿਖਾਉਂਦਾ ਹੈ
- ਹਰ hop ਲਈ **Round-Trip Time (RTT)** ਮਾਪਦਾ ਹੈ

**ਵਰਤੋਂ**:
- **ਨੈੱਟਵਰਕ ਸਮੱਸਿਆ ਹੱਲ**
- ਰਸਤੇ ਦਾ ਵਿਸ਼ਲੇਸ਼ਣ
- ਲੈਟੈਂਸੀ ਦੀ ਜਾਂਚ
- ISP ਪੀਅਰਿੰਗ ਦੀ ਜਾਂਚ

#### Evil Twin AP

**ਉਦੇਸ਼**: ਮੌਜੂਦਾ SSID ਦੀ ਨਕਲ ਕਰਨ ਵਾਲਾ ਨਕਲੀ WiFi ਐਕਸੈਸ ਪੁਆਇੰਟ ਬਣਾਉਣਾ

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
- **wlan1** ਵਰਤਦਾ ਹੈ (Pi ਸਾਥੀ ਰਾਹੀਂ ਉਪਲਬਧ ਹੋਵੇ ਤਾਂ ਦੂਜਾ WiFi ਇੰਟਰਫੇਸ)
- ਨਿਸ਼ਾਨਾ ਨੈੱਟਵਰਕ ਦਾ **SSID ਅਤੇ ਇਨਕ੍ਰਿਪਸ਼ਨ ਕਿਸਮ** ਨਕਲ ਕਰਦਾ ਹੈ
- ਜੁੜਨ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਦੇ **ਕਲਾਇੰਟ ਫੜਦਾ ਹੈ**
- ਪਛਾਣ ਵੇਰਵੇ ਇਕੱਠੇ ਕਰਨ ਲਈ **ਕੈਪਟਿਵ ਪੋਰਟਲ** ਦਿਖਾਉਂਦਾ ਹੈ

**ਲੈਬ ਹਮਲੇ ਦਾ ਦ੍ਰਿਸ਼**:
1. ਅਸਲੀ WiFi ਨੈੱਟਵਰਕ ਸਕੈਨ ਕਰੋ
2. ਉਸੇ SSID ਨਾਲ **ਨਕਲੀ AP** ਬਣਾਓ
3. ਕਲਾਇੰਟਾਂ ਨੂੰ ਅਸਲੀ AP ਤੋਂ ਹਟਾਉਣ ਲਈ **ਡੀ-ਆਥ ਹਮਲਾ** ਵਰਤੋ
4. ਕਲਾਇੰਟ ਆਪਣੇ ਆਪ **ਨਕਲੀ AP** ਨਾਲ ਜੁੜਦੇ ਹਨ
5. ਕੈਪਟਿਵ ਪੋਰਟਲ ਪਛਾਣ ਵੇਰਵੇ ਲੌਗ ਕਰਦਾ ਹੈ

*ਪਛਾਣ: ਜੇ ਦੋਵੇਂ AP ਇਕੱਠੇ ਦਿਸਦੇ ਹਨ ਤਾਂ ਕਲਾਇੰਟਾਂ ਨੂੰ **ਇੱਕੋ SSID ਦੀਆਂ ਦੋ ਨਕਲਾਂ** ਦਿਖਦੀਆਂ ਹਨ।*

#### ਕੈਪਟਿਵ ਪੋਰਟਲ

**ਉਦੇਸ਼**: ਪਛਾਣ ਵੇਰਵੇ ਇਕੱਠੇ ਕਰਨ ਵਾਲੇ ਫਿਸ਼ਿੰਗ ਪੰਨਿਆਂ ਦੇ ਨਮੂਨੇ

**ਸ਼ਾਮਲ ਨਮੂਨੇ**:
- ਆਮ ISP ਜਾਂ ਹੋਟਲ ਸ਼ੈਲੀ ਦਾ **WiFi ਲੌਗਇਨ ਪੰਨਾ**
- **ਸੋਸ਼ਲ ਮੀਡੀਆ ਲੌਗਇਨ** (Facebook, Twitter, Instagram ਵਰਗੇ)
- **ਕਾਰਪੋਰੇਟ ਲੌਗਇਨ** ਪੋਰਟਲ
- **ਹਵਾਈ ਅੱਡੇ ਜਾਂ ਕੌਫੀ ਸ਼ਾਪ** ਦੇ WiFi ਪੰਨੇ

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
1. Evil Twin AP **ਸਾਰਾ ਟ੍ਰੈਫਿਕ** ਪੋਰਟਲ ਵੱਲ ਮੋੜਦਾ ਹੈ
2. ਕਲਾਇੰਟ ਨੂੰ **ਲੌਗਇਨ ਪੰਨਾ** ਦਿਖਦਾ ਹੈ
3. ਕਲਾਇੰਟ ਪਛਾਣ ਵੇਰਵੇ ਦਾਖ਼ਲ ਕਰਦਾ ਹੈ
4. ਪਛਾਣ ਵੇਰਵੇ **ਫਾਈਲ ਵਿੱਚ ਲੌਗ** ਹੁੰਦੇ ਹਨ
5. ਕਲਾਇੰਟ ਨੂੰ ਇੰਟਰਨੈੱਟ ਮਿਲਦਾ ਹੈ ਜਾਂ ਗਲਤੀ ਦਿਖਾਈ ਜਾਂਦੀ ਹੈ

**ਸਿੱਖਿਆ ਦਾ ਉਦੇਸ਼**: **ਸੋਸ਼ਲ ਇੰਜੀਨੀਅਰਿੰਗ ਦੇ ਜੋਖਮ** ਦਿਖਾਉਣਾ ਅਤੇ URL ਜਾਂਚਣ ਦੀ ਲੋੜ ਸਮਝਾਉਣਾ

- Pi ਸਾਂਝੀਆਂ **ਡਾਟਾ ਫਾਈਲਾਂ** ਰਾਹੀਂ Orbic ਨੂੰ ਕੋਆਰਡੀਨੇਟ ਭੇਜਦਾ ਹੈ
- **ECEF ਤੋਂ Lat/Long** ਤਬਦੀਲੀ ਆਪਣੇ ਆਪ ਹੁੰਦੀ ਹੈ

**ਡੈਸ਼ਬੋਰਡ ਉੱਤੇ ਦਿੱਖ**:
- ਦਸ਼ਮਲਵ ਡਿਗਰੀਆਂ ਵਿੱਚ **ਅਕਸ਼ਾਂਸ਼/ਦੇਸ਼ਾਂਤਰ**

**ਸਾਂਝੀ GPS ਸਥਿਤੀ**:

- ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਵਿਚਕਾਰ ਟਕਰਾਅ ਨਹੀਂ ਹੁੰਦਾ

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
1. **ਵੈਧ GPS fix** ਦੀ ਉਡੀਕ ਕਰਦਾ ਹੈ (0,0 ਕੋਆਰਡੀਨੇਟ ਲੌਗ ਨਹੀਂ ਹੁੰਦੇ)

   - **SSID** (ਨੈੱਟਵਰਕ ਨਾਮ)

   - **ਇਨਕ੍ਰਿਪਸ਼ਨ ਕਿਸਮ** (WPA2, WPA3, Open)

   - **ਚੈਨਲ ਨੰਬਰ**

   - **ਸਮਾਂ-ਮੋਹਰ**
4. **Wigle-ਅਨੁਕੂਲ CSV** ਫਾਰਮੈਟ ਵਿੱਚ ਨਿਰਯਾਤ ਕਰਦਾ ਹੈ

- DagShell CSV ਨੂੰ ਸਿੱਧਾ WiGLE ਉੱਤੇ **ਅੱਪਲੋਡ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ**
- Files ਪੰਨੇ ਤੋਂ **ਬ੍ਰਾਊਜ਼ਰ ਰਾਹੀਂ ਅੱਪਲੋਡ** (ਬਾਹਰੀ ਟੂਲ ਦੀ ਲੋੜ ਨਹੀਂ)
- WiFi ਟਿਕਾਣਿਆਂ ਦੇ **ਜਨਤਕ ਡਾਟਾਬੇਸ** ਵਿੱਚ ਯੋਗਦਾਨ

- **WiFi ਕਵਰੇਜ ਨਕਸ਼ਾ**
- ISP ਲਈ **ਨੈੱਟਵਰਕ ਸਰਵੇਖਣ**
- ਸਿਗਨਲ ਤਾਕਤ ਦਾ ਵਿਸ਼ਲੇਸ਼ਣ
- **ਸੁਰੱਖਿਆ ਖੋਜ** (ਖੁੱਲ੍ਹੇ ਨੈੱਟਵਰਕ, ਕਮਜ਼ੋਰ ਇਨਕ੍ਰਿਪਸ਼ਨ)

### 🥧 Raspberry Pi ਸਾਥੀ

**Raspberry Pi ਸਾਥੀ** ਬਾਹਰੀ **ਹਾਰਡਵੇਅਰ** ਰਾਹੀਂ DagShell ਦੀਆਂ ਸਮਰੱਥਾਵਾਂ ਵਧਾਉਂਦਾ ਹੈ:

#### ਹਾਰਡਵੇਅਰ ਦੀਆਂ ਲੋੜਾਂ

**ਘੱਟੋ-ਘੱਟ**:
- **Raspberry Pi 3B+** ਜਾਂ ਨਵਾਂ *(Pi Zero ਵਿੱਚ ਪੈਰੀਫ਼ਰਲਾਂ ਲਈ USB ਪਾਵਰ ਘੱਟ ਹੈ)*
- **USB GPS ਡੌਂਗਲ** (U-Blox 7 chipset ਦੀ ਸਿਫ਼ਾਰਸ਼)
- **ਪਾਵਰ ਸਪਲਾਈ** *(Pi ਲਈ ਵੱਖਰੀ ਪਾਵਰ ਚਾਹੀਦੀ ਹੈ। Orbic ਦਾ USB ਪੋਰਟ ਕਾਫ਼ੀ ਪਾਵਰ ਨਹੀਂ ਦਿੰਦਾ।)*

**ਵਿਕਲਪਿਕ**:
- **WiFi ਅਡੈਪਟਰ** (ਲਿੰਕ ਕਾਇਮ ਰੱਖਦਿਆਂ ਸਕੈਨ ਕਰਨ ਲਈ ਦੂਜਾ ਇੰਟਰਫੇਸ)
- **Bluetooth ਡੌਂਗਲ** (ਜੇ Pi ਦਾ ਅੰਦਰੂਨੀ BT ਕਮਜ਼ੋਰ ਹੋਵੇ)

#### GPS ਮੋਡੀਊਲ (U-Blox 7)

**ਕਨੈਕਸ਼ਨ**: USB GPS ਡੌਂਗਲ Pi ਨਾਲ\

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:

- ਨਿਰਮਾਤਾ ਦੀ ਪਛਾਣ ਲਈ **OUI ਖੋਜ** ਕਰਦਾ ਹੈ
- ਡਾਟਾ **CSV ਫਾਰਮੈਟ** ਵਿੱਚ ਲੌਗ ਕਰਦਾ ਹੈ

**ਦੂਰੋਂ ਕੰਟਰੋਲ**:

- ਸਥਿਤੀ ਰੀਅਲ-ਟਾਈਮ ਵਿੱਚ ਦਿਖਦੀ ਹੈ

**ਵਰਤੋਂ ਦੇ ਮਾਮਲੇ**:
- **ਡਿਵਾਈਸ ਟ੍ਰੈਕਿੰਗ** ਅਤੇ ਗਿਣਤੀ
- **ਲੋਕਾਂ ਦੀ ਆਵਾਜਾਈ ਦਾ ਵਿਸ਼ਲੇਸ਼ਣ**
- **Bluetooth ਡਿਵਾਈਸ ਖੋਜ**
- **IoT ਸੁਰੱਖਿਆ ਖੋਜ**

**CSV ਆਉਟਪੁੱਟ**:

#### WiFi ਸਕੈਨਿੰਗ

**ਉਦੇਸ਼**: Pi WiFi ਨੈੱਟਵਰਕ ਸਕੈਨ ਕਰਦਾ ਹੈ ਅਤੇ ਡਾਟਾ Orbic ਨੂੰ ਭੇਜਦਾ ਹੈ

**ਫ਼ਾਇਦਾ**: ਸਕੈਨਿੰਗ ਲਈ ਵੱਖਰਾ ਇੰਟਰਫੇਸ, ਜਦੋਂ ਕਿ **Orbic ਹੌਟਸਪੌਟ ਚਲਦਾ ਰਹਿੰਦਾ ਹੈ**

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
- Pi **ਦੂਜਾ WiFi ਅਡੈਪਟਰ** ਜਾਂ ਅੰਦਰੂਨੀ WiFi ਵਰਤਦਾ ਹੈ, ਜੇ ਉਹ ਕਨੈਕਟੀਵਿਟੀ ਲਈ ਲੋੜੀਂਦਾ ਨਾ ਹੋਵੇ
- **ਸਾਰੇ ਚੈਨਲ** ਸਕੈਨ ਕਰਦਾ ਹੈ (2.4GHz ਲਈ 1-14, ਅਤੇ ਸਹਾਇਤਾ ਹੋਣ ਉੱਤੇ 5GHz ਲਈ 36-165)
- ਸਾਂਝੀ ਸਟੋਰੇਜ ਰਾਹੀਂ ਨਤੀਜੇ Orbic ਨੂੰ ਭੇਜਦਾ ਹੈ
- DagShell ਨਤੀਜੇ **wardriver CSV** ਵਿੱਚ ਲੌਗ ਕਰਦਾ ਹੈ

**ਤਾਲਮੇਲ**:
- Pi ਅਤੇ Orbic GPS ਸਮਾਂ-ਮੋਹਰ ਦੇ ਆਧਾਰ ਉੱਤੇ **ਸਿੰਕ** ਹੁੰਦੇ ਹਨ
- ਦੁਹਰੀਆਂ ਐਂਟਰੀਆਂ ਰੋਕਦਾ ਹੈ
- **ਦੋਵੇਂ ਸਕੈਨ ਸਰੋਤਾਂ** ਨੂੰ ਇਕੋ ਲੌਗ ਵਿੱਚ ਜੋੜਦਾ ਹੈ

#### ਡੀ-ਆਥ ਹਮਲੇ

**ਉਦੇਸ਼**: ਲੈਬ ਟੈਸਟਿੰਗ ਲਈ ਕਲਾਇੰਟਾਂ ਨੂੰ WiFi ਨੈੱਟਵਰਕ ਤੋਂ ਡਿਸਕਨੈਕਟ ਕਰਨਾ

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
- **802.11 deauthentication ਫਰੇਮ** ਭੇਜਦਾ ਹੈ
- **AP ਦਾ MAC ਪਤਾ** ਸਪੂਫ ਕਰਦਾ ਹੈ
- ਕਲਾਇੰਟ ਨੂੰ AP ਵੱਲੋਂ ਡਿਸਕਨੈਕਸ਼ਨ ਸੁਨੇਹਾ ਮਿਲਦਾ ਹੈ
- ਕਲਾਇੰਟ **ਕਨੈਕਸ਼ਨ ਛੱਡ ਕੇ** ਮੁੜ ਜੁੜਨ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਦਾ ਹੈ

**ਕੰਟਰੋਲ ਤਰੀਕੇ**:
- **ਇਕ ਵਾਰ ਦਾ deauth**: ਫਰੇਮਾਂ ਦਾ ਇਕ ਛੋਟਾ ਸਮੂਹ
- **ਲਗਾਤਾਰ deauth**: ਮੁੜ ਜੁੜਨ ਤੋਂ ਰੋਕਦਾ ਹੈ (DoS)
- **ਦੂਰੋਂ ਕੰਟਰੋਲ**: DagShell ਸਕੈਨ ਪੰਨੇ ਤੋਂ ਚਾਲੂ ਹੁੰਦਾ ਹੈ

**ਵਰਤੋਂ ਦੇ ਮਾਮਲੇ** (ਅਧਿਕਾਰਤ):
- ਆਪਣੇ ਨੈੱਟਵਰਕ ਤੋਂ **ਗੈਰ-ਮਨਜ਼ੂਰ ਡਿਵਾਈਸ ਹਟਾਉਣਾ**
- ਇਜਾਜ਼ਤ ਨਾਲ **ਪੈਨੀਟ੍ਰੇਸ਼ਨ ਟੈਸਟਿੰਗ**
- ਲੈਬ ਵਿੱਚ **Evil Twin ਹਮਲੇ** (ਕਲਾਇੰਟਾਂ ਨੂੰ ਨਕਲੀ AP ਨਾਲ ਜੋੜਨਾ)

**⚠️ ਕਾਨੂੰਨੀ ਚੇਤਾਵਨੀ**: ਆਪਣੇ ਮਾਲਕੀ ਵਾਲੇ ਨੈੱਟਵਰਕ ਤੋਂ ਇਲਾਵਾ ਹੋਰ ਨੈੱਟਵਰਕਾਂ ਵਿਰੁੱਧ deauth ਹਮਲੇ **ਗੈਰਕਾਨੂੰਨੀ ਹਨ**। FCC ਉਲੰਘਣਾ ਅਤੇ CFAA ਹੇਠ ਸੰਭਾਵਿਤ ਦੋਸ਼ ਲੱਗ ਸਕਦੇ ਹਨ।

#### ਆਪਣੇ ਆਪ ਸ਼ੁਰੂ ਹੋਣ ਵਾਲੀ ਸੇਵਾ

**systemd ਸੇਵਾ**: Pi ਸਾਥੀ ਬੂਟ ਵੇਲੇ ਆਪਣੇ ਆਪ ਸ਼ੁਰੂ ਹੁੰਦਾ ਹੈ

**ਸੇਵਾ ਫਾਈਲ** (`/etc/systemd/system/pi-companion.service`):
```ini
[Unit]
Description=DagShell Pi Companion
After=network.target

[Service]
ExecStart=/usr/bin/python3 /opt/dagshell/pi_companion.py
Restart=always
User=root

[Install]
WantedBy=multi-user.target
```

**ਕਮਾਂਡਾਂ**:
```bash
# Enable auto-start
sudo systemctl enable pi-companion

# Start service
sudo systemctl start pi-companion

# Check status
sudo systemctl status pi-companion
```

#### OUI ਡਾਟਾਬੇਸ

**ਉਦੇਸ਼**: MAC ਪਤੇ ਦੇ ਵਿਕਰੇਤਾ ਜਾਂ ਨਿਰਮਾਤਾ ਦੀ ਪਛਾਣ

**ਡਾਟਾਬੇਸ**: prefix-ਅਧਾਰਿਤ API [OUI Master Database](https://standards.ieee.org/products-programs/regauth/)

**ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ**:
- MAC ਪਤੇ ਦੇ **ਪਹਿਲੇ 3 bytes** (OUI prefix) ਕੱਢਦਾ ਹੈ
- API ਨੂੰ ਪੁੱਛਦਾ ਹੈ: `api.example.com/oui/A4:83:E7`
- **ਨਿਰਮਾਤਾ ਦਾ ਨਾਮ** ਵਾਪਸ ਦਿੰਦਾ ਹੈ

**ਉਦਾਹਰਨ**:
```
MAC: A4:83:E7:12:34:56
OUI: A4:83:E7
```

## Raspberry Pi ਸਾਥੀ ਸੈੱਟਅੱਪ

ਪੂਰੀ ਕਾਰਗੁਜ਼ਾਰੀ ਲਈ **ਵਿਕਲਪਿਕ, ਪਰ ਜ਼ੋਰਦਾਰ ਸਿਫ਼ਾਰਸ਼ੀ**

### ਹਾਰਡਵੇਅਰ ਸੈੱਟਅੱਪ

**ਕਦਮ 1**: ਹਿੱਸੇ ਇਕੱਠੇ ਕਰੋ
- **Raspberry Pi 3B+** ਜਾਂ ਨਵਾਂ ($35-55)
- U-Blox 7 chipset ਵਾਲਾ **USB GPS ਡੌਂਗਲ** ($15-30)
- Pi OS ਲਈ ਘੱਟੋ-ਘੱਟ 16GB ਦਾ **MicroSD ਕਾਰਡ** ($10)
- Pi ਲਈ **ਪਾਵਰ ਸਪਲਾਈ** ($10)

**ਕਦਮ 2**: Raspberry Pi OS ਇੰਸਟਾਲ ਕਰੋ
```bash
# Download Raspberry Pi Imager
# https://www.raspberrypi.org/software/

# Flash "Raspberry Pi OS Lite" to SD card
# Boot Pi and complete setup
```

**ਕਦਮ 3**: GPS ਡੌਂਗਲ ਜੋੜੋ
- USB GPS ਨੂੰ Pi ਨਾਲ ਜੋੜੋ
- `lsusb` ਨਾਲ ਜਾਂਚੋ (GPS ਡਿਵਾਈਸ ਦਿਖਣਾ ਚਾਹੀਦਾ ਹੈ)
- `ls /dev/ttyUSB*` ਜਾਂ `ls /dev/ttyACM*` ਨਾਲ serial port ਵੇਖੋ

### ਸਾਫਟਵੇਅਰ ਇੰਸਟਾਲੇਸ਼ਨ

**ਕਦਮ 1**: Pi ਉੱਤੇ DagShell ਰਿਪੋਜ਼ਟਰੀ ਕਲੋਨ ਕਰੋ

```bash
git clone https://github.com/dagnazty/DagShell.git
cd DagShell/pi_companion
```

**ਕਦਮ 2**: ਨਿਰਭਰਤਾਵਾਂ ਇੰਸਟਾਲ ਕਰੋ

```bash
# Update package list
sudo apt-get update

# Install required packages
sudo apt-get install python3-serial python3-requests gpsd gpsd-clients

# Install Python modules
pip3 install pyserial gps3 bluetooth pybluez
```

**ਕਦਮ 3**: GPS daemon ਸੈੱਟ ਕਰੋ

```bash
# Edit gpsd config
sudo nano /etc/default/gpsd

# Set DEVICES line to your GPS serial port
DEVICES="/dev/ttyUSB0"  # Adjust if different

# Restart gpsd
sudo systemctl restart gpsd

# Test GPS
cgps -s  # Should show satellite data after ~30 seconds
```

**ਕਦਮ 4**: Pi ਸਾਥੀ ਸੈੱਟ ਕਰੋ

```bash
# Edit configuration file
nano pi_companion/config.py

# Set Orbic IP address
ORBIC_IP = "192.168.1.1"
ORBIC_PORT = "8443"

# Set GPS serial port
GPS_DEVICE = "/dev/ttyUSB0"

# Save and exit
```

**ਕਦਮ 5**: systemd ਸੇਵਾ ਇੰਸਟਾਲ ਕਰੋ

```bash
# Copy service file
sudo cp pi_companion.service /etc/systemd/system/

# Reload systemd
sudo systemctl daemon-reload

# Enable auto-start
sudo systemctl enable pi-companion

# Start service
sudo systemctl start pi-companion

# Check status
sudo systemctl status pi-companion
```

**ਕਦਮ 6**: ਸੰਚਾਰ ਦੀ ਜਾਂਚ ਕਰੋ

```bash
# Check logs
journalctl -u pi-companion -f

# Should see GPS coordinates being sent to Orbic
```

### ਨੈੱਟਵਰਕ ਸੈੱਟਅੱਪ

**ਚੋਣ A**: WiFi ਕਨੈਕਸ਼ਨ

```bash
# Pi connects to Orbic hotspot
# Edit wpa_supplicant config
sudo nano /etc/wpa_supplicant/wpa_supplicant.conf

# Add network
network={
    ssid="Orbic_SSID"
    psk="PASSWORD"
}

# Restart WiFi
sudo systemctl restart networking
```

**ਚੋਣ B**: USB Ethernet (ਸਿਫ਼ਾਰਸ਼ੀ)

- **USB ਕੇਬਲ** ਰਾਹੀਂ Pi ਨੂੰ Orbic ਨਾਲ ਜੋੜੋ (Pi ਦਾ USB ਪੋਰਟ Orbic ਦੇ USB ਪੋਰਟ ਨਾਲ)
- Pi ਉੱਤੇ **USB gadget mode** ਚਾਲੂ ਕਰੋ
- Pi **USB Ethernet ਡਿਵਾਈਸ** ਵਜੋਂ ਕੰਮ ਕਰਦਾ ਹੈ
- *ਲਗਾਤਾਰ ਡਾਟਾ ਭੇਜਣ ਲਈ WiFi ਨਾਲੋਂ ਵਧੇਰੇ ਭਰੋਸੇਯੋਗ*
- Pi, Orbic ਰਾਹੀਂ ਇੰਟਰਨੈੱਟ ਵਰਤਦਾ ਹੈ

**USB Gadget ਸੰਰਚਨਾ**:
```bash
# Edit config.txt
sudo nano /boot/config.txt

# Add at end
dtoverlay=dwc2

# Edit cmdline.txt
sudo nano /boot/cmdline.txt

# Add after rootwait
modules-load=dwc2,g_ether

# Reboot
sudo reboot
```

### ਇਕੱਠੇ ਵਰਤੋਂ ਦੇ ਮਾਮਲੇ

#### 1. **IMSI ਕੈਚਰਾਂ ਤੋਂ ਪੂਰੀ ਰੱਖਿਆ**

**ਸਥਿਤੀ**: ਵਧੇਰੇ ਨਿਗਰਾਨੀ ਵਾਲੇ ਖੇਤਰ ਵਿੱਚ ਯਾਤਰਾ

**DagShell ਦਾ ਯੋਗਦਾਨ**:
- ਸੈੱਲ ਟਾਵਰਾਂ ਦੇ ਬਦਲਾਅ ਦੀ **ਰੀਅਲ-ਟਾਈਮ ਨਿਗਰਾਨੀ**
- ਸ਼ੱਕੀ ਬਦਲਾਅ ਵੇਲੇ **GPS ਟਿਕਾਣਾ ਟ੍ਰੈਕ** ਕਰਨਾ
- ਬਾਅਦਲੇ ਵਿਸ਼ਲੇਸ਼ਣ ਲਈ **ਟਾਵਰ ਡਾਟਾ ਲੌਗ** ਕਰਨਾ

**RayHunter ਦਾ ਯੋਗਦਾਨ**:
- ਸੈਲੂਲਰ ਪ੍ਰੋਟੋਕੋਲਾਂ ਵਿੱਚ **ML ਅਧਾਰਿਤ ਅਸਧਾਰਨਤਾ ਪਛਾਣ**
- ਉੱਨਤ ਹਮਲਿਆਂ ਲਈ **SS7/Diameter ਪੈਕੇਟ ਜਾਂਚ**
- ਤੁਲਨਾ ਲਈ ਜਾਣੇ-ਪਛਾਣੇ ਸੁਰੱਖਿਅਤ ਟਾਵਰਾਂ ਦਾ **ਡਾਟਾਬੇਸ**

**ਦੋਵਾਂ ਦਾ ਲਾਭ**: DagShell **ਲਗਾਤਾਰ ਨਿਗਰਾਨੀ** ਕਰਦਾ ਹੈ, ਜਦਕਿ RayHunter **ਡੂੰਘਾ ਵਿਸ਼ਲੇਸ਼ਣ** ਕਰਦਾ ਹੈ

**DagShell ਦਾ ਯੋਗਦਾਨ**:
- GPS ਕੋਆਰਡੀਨੇਟਾਂ ਨਾਲ **WiFi ਸਕੈਨਿੰਗ**
- ਸਿਗਨਲ ਤਾਕਤ ਅਤੇ ਇਨਕ੍ਰਿਪਸ਼ਨ ਲਈ **ਨੈੱਟਵਰਕ ਵਿਸ਼ਲੇਸ਼ਣ** ਟੂਲ
- ਨਕਸ਼ਾ ਬਣਾਉਣ ਲਈ **Wigle CSV ਨਿਰਯਾਤ**

**RayHunter ਦਾ ਯੋਗਦਾਨ**:

- WiFi ਸਕੈਨ ਕਰਦਿਆਂ **IMSI ਕੈਚਰ ਪਛਾਣ**
- ਸੈਲੂਲਰ ਸੁਰੱਖਿਆ ਸਮਝੌਤਾ ਹੋਵੇ ਤਾਂ **ਚੇਤਾਵਨੀ**

**ਦੋਵਾਂ ਦਾ ਲਾਭ**: **ਸੈਲੂਲਰ ਸੁਰੱਖਿਆ ਦੀ ਜਾਣਕਾਰੀ** ਨਾਲ ਸੁਰੱਖਿਅਤ ਵਾਰਡਰਾਈਵਿੰਗ

#### 3. **ਸੁਰੱਖਿਆ ਖੋਜ ਲੈਬ**

#### 4. **ਗੋਪਨੀਯਤਾ-ਕੇਂਦਰਿਤ ਯਾਤਰਾ**

**ਪ੍ਰੋਫ਼ਾਈਲ**: WiFi ਸੁਰੱਖਿਆ ਮੁਲਾਂਕਣ ਕਰਦਾ ਪੈਨੀਟ੍ਰੇਸ਼ਨ ਟੈਸਟਰ

**ਵਰਤੇ DagShell ਟੂਲ**:
- ਕਲਾਇੰਟ ਨੈੱਟਵਰਕਾਂ ਦਾ ਨਕਸ਼ਾ ਬਣਾਉਣ ਲਈ **WiFi ਵਾਰਡਰਾਈਵਿੰਗ**
- ਡਿਵਾਈਸ ਲੱਭਣ ਲਈ **ARP ਸਕੈਨਰ**
- ਸੇਵਾਵਾਂ ਪਛਾਣਨ ਲਈ **ਪੋਰਟ ਸਕੈਨਰ**
- ਸੋਸ਼ਲ ਇੰਜੀਨੀਅਰਿੰਗ ਰੋਧਕਤਾ ਜਾਂਚਣ ਲਈ **Evil Twin / ਕੈਪਟਿਵ ਪੋਰਟਲ**
- ਨਤੀਜੇ ਕੱਢਣ ਲਈ **ਫਾਈਲ ਐਕਸਪਲੋਰਰ**

**ਕਾਰਜ-ਪ੍ਰਵਾਹ**:
1. ਕਲਾਇੰਟ ਦੀ ਸਹੂਲਤ ਦੇ ਘੇਰੇ ਵਿੱਚ ਗੱਡੀ ਚਲਾਓ
2. WiFi ਕਵਰੇਜ ਦਾ ਨਕਸ਼ਾ ਬਣਾਉਣ ਲਈ ਵਾਰਡਰਾਈਵ ਕਰੋ
3. ਇਜਾਜ਼ਤ ਨਾਲ ਕਲਾਇੰਟ ਨੈੱਟਵਰਕ ਦਾ Evil Twin ਬਣਾਓ
4. ਕਲਾਇੰਟਾਂ ਦੀਆਂ ਕਨੈਕਸ਼ਨ ਕੋਸ਼ਿਸ਼ਾਂ ਵੇਖੋ
5. ਇਕੱਠੇ ਡਾਟੇ ਨਾਲ ਰਿਪੋਰਟ ਬਣਾਓ

**RayHunter ਇੰਟੀਗ੍ਰੇਸ਼ਨ**: ਮੁਲਾਂਕਣ ਦੌਰਾਨ ਖੋਜਕਾਰ ਦੀ ਨਿਗਰਾਨੀ ਹੋਣ ਦੀ ਪਛਾਣ ਵਿੱਚ ਮਦਦ ਕਰਦਾ ਹੈ

- ਡਿਵਾਈਸ ਦੀ ਪਛਾਣ ਲੁਕਾਉਣ ਲਈ **MAC ਸਪੂਫਿੰਗ**

**ਕਾਰਜ-ਪ੍ਰਵਾਹ**:

5. ਸ਼ੱਕੀ ਸੈਲੂਲਰ ਗਤੀਵਿਧੀ ਲੌਗ ਕਰੋ

**RayHunter ਇੰਟੀਗ੍ਰੇਸ਼ਨ**: ਮੁੱਢਲੀ ਨਿਗਰਾਨੀ ਤੋਂ ਅੱਗੇ ਵਧ ਕੇ IMSI ਕੈਚਰ ਪਛਾਣ ਕਰਦਾ ਹੈ

4. ਫਾਇਰਵਾਲ ਰਾਹੀਂ ਖ਼ਤਰਨਾਕ IP ਬਲਾਕ ਕਰੋ
5. ਦਸਤਾਵੇਜ਼ੀਕਰਨ ਲਈ ਰਿਪੋਰਟ ਨਿਰਯਾਤ ਕਰੋ

**RayHunter ਇੰਟੀਗ੍ਰੇਸ਼ਨ**: ਮੋਬਾਈਲ ਡਿਵਾਈਸ ਵਾਲੀਆਂ ਸਹੂਲਤਾਂ ਲਈ ਸੈਲੂਲਰ ਸੁਰੱਖਿਆ ਨਿਗਰਾਨੀ

### ਵਰਤੋਂ 4: IoT ਸੁਰੱਖਿਆ ਖੋਜਕਾਰ

## ਕਾਨੂੰਨੀ ਅਤੇ ਨੈਤਿਕ ਵਿਚਾਰ

### ਕਾਨੂੰਨੀ ਢਾਂਚਾ

**DagShell ਵਰਗੇ ਟੂਲ ਕਾਨੂੰਨੀ ਅਸਪਸ਼ਟਤਾ ਵਾਲੇ ਖੇਤਰ ਵਿੱਚ ਆਉਂਦੇ ਹਨ**:

**ਕਾਨੂੰਨੀ ਵਰਤੋਂ**:
✅ **ਆਪਣੇ ਨੈੱਟਵਰਕ**: ਆਪਣੇ ਡਿਵਾਈਸਾਂ ਅਤੇ ਨੈੱਟਵਰਕਾਂ ਦੀ ਜਾਂਚ ਕਰੋ
✅ **ਅਧਿਕਾਰਤ ਟੈਸਟਿੰਗ**: ਲਿਖਤੀ ਇਜਾਜ਼ਤ ਨਾਲ ਪੈਨੀਟ੍ਰੇਸ਼ਨ ਟੈਸਟਿੰਗ
✅ **ਸਿੱਖਿਆ**: ਅਲੱਗ ਲੈਬ ਮਾਹੌਲ ਵਿੱਚ ਸਿੱਖਣਾ
✅ **ਗੋਪਨੀਯਤਾ ਸੁਰੱਖਿਆ**: ਆਪਣੇ ਡਿਵਾਈਸ ਉੱਤੇ TTL ਸੁਧਾਰ ਅਤੇ MAC ਸਪੂਫਿੰਗ
✅ **ਸੁਰੱਖਿਆ ਖੋਜ**: ਜ਼ਿੰਮੇਵਾਰ ਖੁਲਾਸੇ ਨਾਲ ਕਮਜ਼ੋਰੀਆਂ ਦੀ ਖੋਜ

**ਗੈਰਕਾਨੂੰਨੀ ਵਰਤੋਂ**:
❌ **ਬਿਨਾਂ ਅਧਿਕਾਰ ਪਹੁੰਚ**: ਆਪਣੇ ਨਾ ਹੋਣ ਵਾਲੇ ਨੈੱਟਵਰਕਾਂ ਉੱਤੇ ਹਮਲਾ (CFAA ਦੀ ਉਲੰਘਣਾ)
❌ ਹੋਰ ਨੈੱਟਵਰਕਾਂ ਉੱਤੇ **deauth ਹਮਲੇ** (FCC ਦੀ ਉਲੰਘਣਾ ਅਤੇ ਸੰਭਾਵਿਤ ਗੰਭੀਰ ਜੁਰਮ)
❌ ਜਨਤਕ ਲੋਕਾਂ ਵਿਰੁੱਧ **Evil Twin ਹਮਲੇ** (ਸੰਚਾਰ ਧੋਖਾਧੜੀ, ਪਛਾਣ ਚੋਰੀ)
❌ ਸਹਿਮਤੀ ਤੋਂ ਬਿਨਾਂ ਹੋਰਾਂ ਦਾ **DNS ਸਨਿਫ਼ ਕਰਨਾ** (ਸੰਚਾਰ ਵਿੱਚ ਗੈਰਕਾਨੂੰਨੀ ਦਖ਼ਲ)
❌ ਧੋਖਾਧੜੀ ਲਈ ਸੁਰੱਖਿਆ ਨੂੰ ਬਾਈਪਾਸ ਕਰਨਾ

### ਧਿਆਨ ਵਿੱਚ ਰੱਖਣ ਵਾਲੇ ਕਾਨੂੰਨ

**ਸੰਯੁਕਤ ਰਾਜ**:
- **Computer Fraud and Abuse Act (CFAA)**: ਕੰਪਿਊਟਰਾਂ ਜਾਂ ਨੈੱਟਵਰਕਾਂ ਤੱਕ ਬਿਨਾਂ ਅਧਿਕਾਰ ਪਹੁੰਚ
- **Wiretap Act**: ਇਲੈਕਟ੍ਰਾਨਿਕ ਸੰਚਾਰ ਨੂੰ ਰੋਕ ਕੇ ਪੜ੍ਹਨਾ
- **FCC ਨਿਯਮ**: ਰੇਡੀਓ ਫ੍ਰੀਕਵੈਂਸੀ ਵਿੱਚ ਦਖ਼ਲ (deauth ਹਮਲੇ)

**ਯੂਨਾਈਟਡ ਕਿੰਗਡਮ**:
- **Computer Misuse Act 1990**: CFAA ਵਰਗਾ ਕਾਨੂੰਨ
- **Regulation of Investigatory Powers Act (RIPA)**: ਸੰਚਾਰ ਰੋਕਣ ਉੱਤੇ ਪਾਬੰਦੀਆਂ

**ਯੂਰਪੀ ਸੰਘ**:
- **GDPR**: ਡਾਟਾ ਸੁਰੱਖਿਆ (ਪਛਾਣਯੋਗ ਡਾਟਾ ਦੀ BLE/WiFi ਸਕੈਨਿੰਗ)
- *ਸਥਾਨਕ ਕਾਨੂੰਨ ਅਤੇ ਉਨ੍ਹਾਂ ਦੀ ਲਾਗੂਅਤ ਦੇਸ਼ ਅਨੁਸਾਰ ਵੱਖਰੇ ਹਨ*

### ਨੈਤਿਕ ਦਿਸ਼ਾ-ਨਿਰਦੇਸ਼

**ਕਰੋ**:
- ✅ ਸਿਰਫ਼ **ਆਪਣੇ ਡਿਵਾਈਸਾਂ** ਅਤੇ ਨੈੱਟਵਰਕਾਂ ਉੱਤੇ ਵਰਤੋ
- ✅ ਹੋਰਾਂ ਦੇ ਸਿਸਟਮ ਟੈਸਟ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ **ਲਿਖਤੀ ਇਜਾਜ਼ਤ** ਲਵੋ
- ✅ ਕਮਜ਼ੋਰੀਆਂ ਮਿਲਣ ਉੱਤੇ **ਜ਼ਿੰਮੇਵਾਰ ਖੁਲਾਸਾ** ਕਰੋ
- ✅ ਨਿਯੰਤਰਿਤ ਮਾਹੌਲ ਵਿੱਚ **ਸਿੱਖਿਆ ਲਈ** ਵਰਤੋ
- ✅ ਆਪਣੀ **ਗੋਪਨੀਯਤਾ ਦੀ ਰੱਖਿਆ** ਕਰੋ

**ਨਾ ਕਰੋ**:

- ❌ ਅਣਜਾਣ ਲੋਕਾਂ ਦੇ ਪਾਸਵਰਡ ਜਾਂ ਪਛਾਣ ਜਾਣਕਾਰੀ ਨਾ ਇਕੱਠੀ ਕਰੋ
- ❌ ਜ਼ਰੂਰੀ ਢਾਂਚੇ ਵਿੱਚ ਦਖ਼ਲ ਨਾ ਦਿਓ
- ❌ ਟੂਲਾਂ ਨੂੰ ਨੁਕਸਾਨਦੇਹ ਕੰਮਾਂ ਲਈ ਨਾ ਵਰਤੋ
- ❌ ਇਕੱਠਾ ਕੀਤਾ ਡਾਟਾ ਵੰਡੋ ਨਾ

- **ਖੁਲਾਸਾ** (ਨਤੀਜੇ ਰਿਪੋਰਟ ਕਰਨਾ ਜਾਂ ਉਨ੍ਹਾਂ ਦਾ ਗਲਤ ਫਾਇਦਾ ਲੈਣਾ)

DagShell ਨੂੰ **ਜ਼ਿੰਮੇਵਾਰੀ ਨਾਲ** ਅਤੇ **ਨੈਤਿਕ ਢੰਗ ਨਾਲ** ਵਰਤੋ। *ਜੇ ਕਾਨੂੰਨੀ ਹੋਣ ਬਾਰੇ ਯਕੀਨ ਨਹੀਂ, ਤਾਂ ਰੁਕੋ ਅਤੇ ਅੱਗੇ ਵਧਣ ਤੋਂ ਪਹਿਲਾਂ ਵਕੀਲ ਨਾਲ ਸਲਾਹ ਕਰੋ.*

## ਸਮੱਸਿਆ ਹੱਲ

### ਇੰਸਟਾਲੇਸ਼ਨ ਸਮੱਸਿਆਵਾਂ

**ਸਮੱਸਿਆ**: `enable_shell.py` ਕਨੈਕਟ ਨਹੀਂ ਕਰਦਾ

**ਹੱਲ**:
- ਜਾਂਚੋ ਕਿ ਤੁਸੀਂ **Orbic WiFi** ਨਾਲ ਜੁੜੇ ਹੋ
- ਪਤਾ ਕਰੋ ਕਿ IP **192.168.1.1** (ਮੂਲ) ਹੈ
- ਐਡਮਿਨ ਪਾਸਵਰਡ ਮੁੜ ਪਾਓ (ਵੱਡੇ ਅਤੇ ਛੋਟੇ ਅੱਖਰ ਵੱਖਰੇ ਹਨ)
- port 80 ਉਪਲਬਧ ਹੈ ਜਾਂ ਨਹੀਂ ਜਾਂਚੋ: `telnet 192.168.1.1 80`

**ਸਮੱਸਿਆ**: ਫਰਮਵੇਅਰ ਅੱਪਲੋਡ ਅਸਫਲ ਹੁੰਦਾ ਹੈ

**ਹੱਲ**:
- ਪਹਿਲਾਂ root shell ਚਾਲੂ ਹੋਣ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ (`enable_shell.py` ਸਫਲ ਹੋਇਆ)
- ਨੈੱਟਵਰਕ ਦੀ ਸਥਿਰਤਾ ਜਾਂਚੋ (ਸੰਭਵ ਹੋਵੇ ਤਾਂ ਤਾਰ ਵਾਲਾ ਕਨੈਕਸ਼ਨ ਵਰਤੋ)
- `deploy_base64.py` ਦੀ ਥਾਂ `deploy_net.py` ਵਰਤ ਕੇ ਵੇਖੋ
- `/data` ਭਾਗ ਵਿੱਚ ਖਾਲੀ ਥਾਂ ਜਾਂਚੋ: `df -h /data`

**ਸਮੱਸਿਆ**: ਸਰਟੀਫਿਕੇਟ ਚੇਤਾਵਨੀ ਹਟਦੀ ਨਹੀਂ

**ਹੱਲ**:
- *ਆਪਣੇ ਦਸਤਖ਼ਤ ਵਾਲੇ ਸਰਟੀਫਿਕੇਟ ਲਈ ਇਹ **ਆਮ** ਹੈ। ਕਨੈਕਸ਼ਨ ਫਿਰ ਵੀ ਇਨਕ੍ਰਿਪਟ ਹੈ*
- ਹਰ ਵਾਰ “Advanced” ਚੁਣ ਕੇ “Proceed anyway” ਦਬਾਓ
- **ਵਿਕਲਪਿਕ**: `root.der` ਨੂੰ ਡਿਵਾਈਸ ਦੇ trust store ਵਿੱਚ ਇੰਸਟਾਲ ਕਰੋ (ਉੱਨਤ ਵਰਤੋਂ)

### ਚੱਲਣ ਸਮੇਂ ਦੀਆਂ ਸਮੱਸਿਆਵਾਂ

**ਸਮੱਸਿਆ**: DagShell ਬੂਟ ਵੇਲੇ ਸ਼ੁਰੂ ਨਹੀਂ ਹੁੰਦਾ

**ਹੱਲ**:
- ਬੂਟ ਸਕ੍ਰਿਪਟ ਜਾਂਚੋ: `ls -la /etc/rc.d/dagshell_boot.sh`
- ਚੱਲਣ ਦੀ ਇਜਾਜ਼ਤ ਜਾਂਚੋ: `chmod +x /etc/rc.d/dagshell_boot.sh`
- ਲੌਗ ਵੇਖੋ: `logread | grep dagshell`
- ਹੱਥੀਂ ਸ਼ੁਰੂ ਕਰੋ: `/data/orbic_app &`

**ਸਮੱਸਿਆ**: GPS ਕੰਮ ਨਹੀਂ ਕਰ ਰਿਹਾ

**ਹੱਲ**:
- **Pi ਸਾਥੀ** ਚੱਲਦਾ ਹੈ ਜਾਂ ਨਹੀਂ ਜਾਂਚੋ: `systemctl status pi-companion`
- GPS ਨੂੰ ਸੈਟੇਲਾਈਟ ਸਿਗਨਲ ਮਿਲਦਾ ਹੈ ਜਾਂ ਨਹੀਂ ਵੇਖੋ: `cgps -s` (Pi ਉੱਤੇ)
- GPS ਡੌਂਗਲ ਜੁੜਿਆ ਹੈ ਜਾਂ ਨਹੀਂ ਜਾਂਚੋ: `lsusb`
- *ਪਹਿਲੀ ਠੰਢੀ ਸ਼ੁਰੂਆਤ ਉੱਤੇ GPS fix ਲਈ 5-10 ਮਿੰਟ ਉਡੀਕੋ। ਪਹਿਲੀ ਵਾਰ ਬਾਹਰ GPS fix ਵਿੱਚ ਵਧੇਰੇ ਸਮਾਂ ਲੱਗਦਾ ਹੈ.*

**ਸਮੱਸਿਆ**: ਵਾਰਡਰਾਈਵਿੰਗ ਲੌਗ ਨਹੀਂ ਬਣਾਉਂਦੀ

**ਹੱਲ**:
- ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ GPS fix ਆਉਣ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ
- `/data` ਲਈ ਲਿਖਣ ਦੀ ਇਜਾਜ਼ਤ ਜਾਂਚੋ
- CSV ਬਣ ਰਿਹਾ ਹੈ ਜਾਂ ਨਹੀਂ ਵੇਖੋ: `ls -la /data/wardrive_log.csv`
- WiFi ਇੰਟਰਫੇਸ ਚਾਲੂ ਹੈ ਜਾਂ ਨਹੀਂ ਜਾਂਚੋ: `ifconfig wlan0`

**ਸਮੱਸਿਆ**: Pi ਸਾਥੀ Orbic ਨਾਲ ਸੰਚਾਰ ਨਹੀਂ ਕਰਦਾ

**ਹੱਲ**:
- ਨੈੱਟਵਰਕ ਕਨੈਕਟੀਵਿਟੀ ਜਾਂਚੋ: `ping 192.168.1.1`
- ਸੰਰਚਨਾ ਫਾਈਲ ਵਿੱਚ ਸਹੀ IP ਪਤਾ ਜਾਂਚੋ
- port 8443 ਖੁੱਲ੍ਹਾ ਹੈ ਜਾਂ ਨਹੀਂ ਵੇਖੋ: `telnet 192.168.1.1 8443`
- Pi ਸਾਥੀ ਦੇ ਲੌਗ ਵੇਖੋ: `journalctl -u pi-companion`

### ਕਾਰਗੁਜ਼ਾਰੀ ਦੀਆਂ ਸਮੱਸਿਆਵਾਂ

**ਸਮੱਸਿਆ**: ਵੈੱਬ ਇੰਟਰਫੇਸ ਹੌਲੀ ਜਾਂ ਅਟਕਦਾ ਹੈ

- WiFi ਦੀ ਥਾਂ Orbic ਨਾਲ **ਤਾਰ ਵਾਲਾ** ਕਨੈਕਸ਼ਨ ਵਰਤੋ
- DagShell ਮੁੜ ਚਾਲੂ ਕਰੋ: `killall orbic_app && /data/orbic_app &`

**ਸਮੱਸਿਆ**: ਵਾਰਡਰਾਈਵਿੰਗ ਸਕੈਨ ਵਿੱਚ ਬਹੁਤ ਸਮਾਂ ਲੱਗਦਾ ਹੈ

**ਹੱਲ**:
- ਕਾਰਗੁਜ਼ਾਰੀ ਵਧਾਉਣ ਲਈ ਸੈਟਿੰਗਾਂ ਵਿੱਚ ਸਕੈਨ ਅੰਤਰਾਲ ਵਧਾਓ
- ਸਕੈਨ ਕੀਤੇ ਚੈਨਲਾਂ ਦੀ ਗਿਣਤੀ ਘਟਾਓ
- *ਕਮਜ਼ੋਰ GPS fix ਸਕੈਨ ਹੌਲਾ ਕਰਦਾ ਹੈ। ਲੌਗ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਸਿਸਟਮ ਵੈਧ ਕੋਆਰਡੀਨੇਟਾਂ ਦੀ ਉਡੀਕ ਕਰਦਾ ਹੈ.*

## ਨਤੀਜਾ: ਪੂਰੀ ਮੋਬਾਈਲ ਲੈਬ

**DagShell** Orbic RCL400 ਹੌਟਸਪੌਟ ਨੂੰ **ਮੋਬਾਈਲ ਸੁਰੱਖਿਆ ਖੋਜ ਲੈਬ** ਵਿੱਚ ਬਦਲਦਾ ਹੈ, ਜਿਸ ਵਿੱਚ ਹਨ:

✅ **ਗੋਪਨੀਯਤਾ ਸੁਰੱਖਿਆ** (TTL ਮਾਸਕਿੰਗ, MAC ਸਪੂਫਿੰਗ, AdBlock)
✅ **ਨੈੱਟਵਰਕ ਨਿਗਰਾਨੀ** (ਕਨੈਕਸ਼ਨ, DNS, ਰੂਟਿੰਗ)

✅ **Raspberry Pi ਵਿਸਤਾਰ** (BLE, WiFi, GPS)
✅ **ਪੋਰਟੇਬਲ ਅਤੇ ਬੈਟਰੀ ਨਾਲ ਚੱਲਣ ਵਾਲਾ**
✅ **ਓਪਨ-ਸੋਰਸ ਅਤੇ ਕਸਟਮਾਈਜ਼ ਕਰਨ ਯੋਗ**
