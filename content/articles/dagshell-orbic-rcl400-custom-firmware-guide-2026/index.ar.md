## ما DagShell؟

### نظرة عامة

**DagShell** برنامج ثابت مخصص مفتوح المصدر يستبدل واجهة الويب الأصلية لجهاز Orbic RCL400 **بمجموعة أدوات أمنية شاملة** تشمل:

- **واجهة بأسلوب الطرفية** مع رسوم ASCII ومظهر الهاكرز
- **واجهة ويب مشفرة بـ TLS 1.2 أو أحدث** (شهادة موقعة ذاتيًا)
- **أدوات حماية الخصوصية** (إخفاء TTL وانتحال MAC وحظر الإعلانات عبر DNS)
- **مراقبة الشبكة** (الاتصالات النشطة وجداول التوجيه واستعلامات DNS)
- **أدوات اختراق** (كشف ملتقطات IMSI ومسح المنافذ واكتشاف ARP)
- **إمكانات هجوم** (نقطة وصول Evil Twin وبوابة أسيرة للتصيد وهجمات إلغاء المصادقة)
- **تتبع GPS ومسح شبكات WiFi أثناء التنقل** مع تصدير CSV متوافق مع Wigle
- **Raspberry Pi مرافق** لنظام GPS ومسح Bluetooth واستطلاع WiFi
- **الوصول إلى نظام الملفات** عبر مدير ملفات في المتصفح
- **وظائف SMS** عبر أوامر AT
- **الاستمرارية**: يبدأ تلقائيًا عند الإقلاع

### المواصفات التقنية

**المنصة**: نقطة اتصال محمولة Orbic RCL400\
**البنية**: ARM Linux (kernel 3.18)\
**اللغة**: C/C++ (ملف ARM ثنائي ثابت)\
**التشفير**: TLS 1.2 أو أحدث بشهادات موقعة ذاتيًا (بنية PKI من مستويين)\
**خادم الويب**: خادم HTTPS مضمن مخصص (المنفذ 8443)\
**الواجهة**: واجهة طرفية في المتصفح\
**الترخيص**: MIT (مفتوح المصدر)\
**GitHub**: [github.com/dagnazty/DagShell](https://github.com/dagnazty/DagShell)

- **شعار ASCII** في كل صفحة

- **خط أحادي المسافة** (Fira Code)

## تفاصيل الميزات كاملة

### 🏠 لوحة المعلومات

**نظرة عامة على النظام**:
- **مدة التشغيل**: المدة منذ بدء الجهاز
- **واجهة أوامر AT**: تحكم مباشر بالمودم للمستخدمين المتقدمين
- **الحالة السريعة**: عنوان IP وحالة الاتصال

تتيح **أوامر AT** التحكم بالمودم على مستوى منخفض:
```
Example AT Commands:
AT+CSQ       - Signal quality
AT+COPS?     - Current network operator  
AT+CREG?     - Network registration status
AT+CIMI      - Get IMSI (subscriber identity)
AT+CGSN      - Get IMEI (device identifier)
```

### 🌐 أدوات الشبكة

**معلومات الشبكة الحالية**:
- تفاصيل **عنوان IP والواجهة**
- **قناع الشبكة الفرعية والبوابة** وعنوان البث
- **إحصاءات الشبكة** (الحزم المرسلة والمستلمة)

**عارض جدول التوجيه**:
- عرض مسارات الشبكة كافة
- معلومات البوابة الافتراضية
- تعيين الواجهات

**مراقبة الاتصالات النشطة**:
- قائمة آنية **بكل اتصالات TCP/UDP**
- عناوين IP المحلية والبعيدة
- أرقام المنافذ وحالات الاتصال
- مفيد **لمراقبة اتصالات الجهاز**

### 🔒 مجموعة حماية الخصوصية

#### إصلاح TTL

**الغرض**: إخفاء حركة مرور نقطة الاتصال عن كشف شركة الاتصالات

**آلية العمل**:
- يعدّل قيمة **Time To Live (TTL)** في حزم IP إلى **65**
- تكتشف شركات الاتصالات مشاركة الإنترنت عبر انخفاض TTL (الهاتف = 64، الجهاز المتصل = 63)
- يجعل تعيين TTL إلى 65 **كل حركة المرور تبدو محلية**

**حالة الاستخدام**: تجاوز قيود مشاركة الإنترنت أو خفض السرعة لدى شركة الاتصالات

**الأوامر**:
```bash
# Enable TTL fix
iptables -t mangle -A POSTROUTING -j TTL --ttl-set 65

# Disable TTL fix  
iptables -t mangle -D POSTROUTING -j TTL --ttl-set 65
```

#### انتحال عنوان MAC

**الغرض**: تغيير عنوان MAC للجهاز عشوائيًا لحماية الخصوصية

**آلية العمل**:
- يغيّر عنوان MAC للواجهة **wlan0** (واجهة WiFi)
- ينشئ **عنوان MAC عشوائيًا** أو يقبل إدخال عنوان مخصص
- يجعل تتبع الجهاز **أصعب بين الجلسات**

**حالة الاستخدام**: منع الشبكات التي تتصل بها من تتبع الجهاز عبر عنوان MAC

**الخطوات**:
1. تتوقف الواجهة
2. يطبّق عنوان MAC جديد
3. تعمل الواجهة مجددًا
4. يعاد الاتصال

#### حظر الإعلانات عبر DNS

**الغرض**: حظر الإعلانات وأدوات التتبع على مستوى DNS

**آلية العمل**:
- يعدّل ملف `/etc/hosts` باستخدام **قائمة حظر**
- تُحلّ النطاقات المدرجة إلى **127.0.0.1** (localhost)
- يحظر الإعلانات **على كل الأجهزة المتصلة**

**حالة الاستخدام**: حظر الإعلانات على مستوى الشبكة دون إعداد كل جهاز على حدة

**مصدر قائمة الحظر**: نطاقات شائعة للإعلانات والتتبع (قابلة للتخصيص)

### 📱 إدارة SMS

**إرسال SMS**:
- إرسال رسائل نصية إلى المودم عبر **أوامر AT**
- مفيد **للإشعارات عن بعد** أو الاختبار

**عرض الرسائل**:
- رابط إلى صندوق الوارد الأصلي في Orbic
- قراءة رسائل SMS المستلمة

**أمر AT المستخدم**:
```
AT+CMGS="PHONE_NUMBER"
Message text here^Z
```

### 🔧 أدوات الاختراق

#### كاشف ملتقطات IMSI

**الغرض**: مراقبة معلومات أبراج الهاتف بحثًا عن حالات شاذة تدل على أجهزة **IMSI catcher أو Stingray**

**آلية العمل**:
- يستعلم المودم عن **بيانات البرج الخلوي**:
  - **Cell ID** (معرّف البرج)
  - **LAC** (رمز منطقة الموقع)
  - **MCC/MNC** (رمز بلد الهاتف المحمول ورمز الشبكة)
  - **قوة الإشارة** (RSSI)
  - **جيل الشبكة** (2G/3G/4G)
- **يسجل التغييرات** لكشف التحولات المشبوهة بين الأبراج
- **تتبّع خط الأساس**: يحدد الأبراج المعتادة في المنطقة

**مؤشرات الكشف**:
- **تحول مفاجئ إلى برج آخر** أثناء الثبات في المكان
- **الانتقال إلى 2G** *(غالبًا ما تفرض ملتقطات IMSI شبكة 2G لإزالة التشفير)*
- ظهور **Cell ID غير معروف**
- **إشارة ضعيفة** من برج مزيف
- **إعادة اتصال متكررة**

**التكامل مع RayHunter**: يوفر DagShell **مراقبة الأبراج الخلوية**. أما RayHunter فيوفر **كشفًا مخصصًا لملتقطات IMSI** بتحليل أكثر تقدمًا (راجع القسم التالي).

#### ماسح المنافذ

**الغرض**: فحص عناوين IP المستهدفة بحثًا عن منافذ مفتوحة

**آلية العمل**:
- **فحص TCP SYN**: يرسل حزم SYN إلى المنافذ المستهدفة
- **كشف انتهاء المهلة**: يحدد إن كان المنفذ مفتوحًا أو مغلقًا أو مرشحًا
- **دعم النطاقات**: فحص منفذ واحد أو نطاق من المنافذ

**حالات الاستخدام**:
- **استطلاع الشبكات**
- **اكتشاف أجهزة إنترنت الأشياء**
- **تدقيق أمن** الشبكات المحلية
- **تحديد الخدمات**

**الأمر**:
```bash
# Scan ports 1-1000 on target
nc -zv -w 2 TARGET_IP 1-1000 2>&1
```

#### مدير جدار الحماية

**الغرض**: حظر عناوين IP أو إلغاء حظرها باستخدام iptables

**آلية العمل**:
- يستخدم **قواعد iptables** لإسقاط الحزم من عناوين IP محددة أو إليها
- **تستمر القواعد** بعد إعادة التشغيل إذا حفظتها
- يدعم **قوائم السماح والحظر**

**حالات الاستخدام**:
- **حظر عناوين IP ضارة**
- **منع الوصول غير المصرح به**
- **تشكيل حركة المرور أو تصفيتها**
- **الرقابة الأبوية**

**الأوامر**:
```bash
# Block IP
iptables -I INPUT -s IP_ADDRESS -j DROP
iptables -I OUTPUT -d IP_ADDRESS -j DROP

# Unblock IP
iptables -D INPUT -s IP_ADDRESS -j DROP
iptables -D OUTPUT -d IP_ADDRESS -j DROP
```

### ⚔️ أدوات الهجوم

**إخلاء مسؤولية قانوني مهم**: هذه الأدوات مخصصة **لاختبارات الأمن المصرح بها فقط**. استخدامها ضد شبكات لا تملكها أو دون إذن كتابي صريح غير **قانوني** في كثير من الولايات القضائية (مثل Computer Fraud and Abuse Act في الولايات المتحدة وComputer Misuse Act في المملكة المتحدة). استخدمها فقط على **شبكاتك الخاصة** أو في **مختبرات مضبوطة**.

#### مستشعر DNS

**الغرض**: تسجيل استعلامات DNS من العملاء المتصلين

**آلية العمل**:
- **تسجيل عبر iptables** على المنفذ 53 (DNS)
- **لا يتطلب الوضع المختلط**
- يسجل كل طلبات DNS من عملاء نقطة الاتصال
- يكشف **المواقع والخدمات** التي يصل إليها العملاء

**حالات استخدام مصرح بها**:
- **تحليل حركة مرور الشبكة**
- **مراقبة الأسرة** (عائلتك فقط)
- **أبحاث الأمن** على أجهزتك
- **تحليل سلوك البرامج الضارة**

*تلتقط هذه الوظيفة بيانات وصفية (النطاقات التي زارها العملاء المتصلون). انشرها على الشبكات التي تملكها أو تديرها فقط.*

#### ماسح ARP

**الغرض**: اكتشاف الأجهزة على الشبكة المحلية

**آلية العمل**:
- يرسل **طلبات ARP** إلى كل عناوين IP في الشبكة الفرعية
- ترد الأجهزة **بعناوين MAC** الخاصة بها
- يحدد **بحث OUI** الشركة المصنعة (Apple أو Samsung وغيرها)
- ينشئ **خريطة شبكة** للأجهزة النشطة

**حالات الاستخدام**:
- **جرد الشبكة**
- **اكتشاف الأجهزة غير المعروفة**
- **تحليل شبكات BYOD**
- **اكتشاف أجهزة إنترنت الأشياء**

**مثال على المخرجات**:
```
IP: 192.168.1.50
MAC: A4:83:E7:XX:XX:XX
Vendor: Apple, Inc.

IP: 192.168.1.75
MAC: 2C:54:91:XX:XX:XX
Vendor: Samsung Electronics
```

#### Traceroute

**الغرض**: عرض مسار الشبكة إلى وجهة معينة

**آلية العمل**:
- يرسل حزمًا بقيمة **TTL متزايدة**
- يخفض كل انتقال TTL ويرسل **ICMP Time Exceeded**
- يكشف **أجهزة التوجيه والمسار** إلى الوجهة
- يقيس **زمن الذهاب والإياب (RTT)** لكل انتقال

**حالات الاستخدام**:
- **استكشاف مشكلات الشبكة**
- **تحليل المسارات**
- **تشخيص زمن التأخير**
- **فحص الربط بين مزودي الإنترنت**

#### نقطة وصول Evil Twin

**الغرض**: إنشاء نقطة وصول WiFi مزيفة تستنسخ SSID موجودة

**آلية العمل**:
- تستخدم **wlan1** (واجهة WiFi ثانية إذا وفرها Raspberry Pi المرافق)
- تستنسخ **SSID ونوع التشفير** للشبكة المستهدفة
- **تلتقط العملاء** الذين يحاولون الاتصال
- تعرض **بوابة أسيرة** لجمع بيانات الاعتماد

**سيناريو الهجوم** (مختبر):
1. افحص شبكات WiFi الشرعية
2. أنشئ **نقطة وصول مزيفة** بالـ SSID نفسها
3. استخدم **هجوم إلغاء المصادقة** لفصل العملاء عن نقطة الوصول الحقيقية
4. يعاود العملاء الاتصال تلقائيًا **بنقطة الوصول المزيفة**
5. تجمع البوابة الأسيرة بيانات الاعتماد

*الكشف: يرى العملاء **SSID مكررة** إذا ظهرت نقطتا الوصول معًا.*

#### البوابة الأسيرة

**الغرض**: توفير قوالب صفحات تصيد لجمع بيانات الاعتماد

**القوالب المتاحة**:
- **صفحة تسجيل دخول WiFi** (نمط عام لمزود إنترنت أو فندق)
- **صفحات دخول للشبكات الاجتماعية** (نسخ شبيهة بـ Facebook وTwitter وInstagram)
- بوابات **دخول للشركات**
- بوابات WiFi في **المطارات والمقاهي**

**آلية العمل**:
1. تعيد نقطة وصول Evil Twin توجيه **كل حركة المرور** إلى البوابة
2. يرى العميل **صفحة تسجيل الدخول**
3. يدخل العميل بيانات الاعتماد
4. **تُسجل بيانات الاعتماد في ملف**
5. يُمنح العميل الإنترنت أو تظهر له رسالة خطأ

**الغرض التعليمي**: توضيح **مخاطر الهندسة الاجتماعية** وأهمية التحقق من عناوين URL

### 📍 متعقب GPS ومسح الشبكات أثناء التنقل

#### وظائف GPS

**مصدر GPS**: **Raspberry Pi المرافق فقط**
- *لا يحتوي Orbic RCL400 على **GPS مدمج**. من دون Pi مرافق لن تتوفر بيانات الموقع.*
- يوصل Pi **وحدة GPS USB** (يوصى بمجموعة شرائح U-Blox 7)
- يرسل Pi الإحداثيات إلى Orbic عبر **ملفات بيانات مشتركة**
- يجري تحويل **ECEF إلى خط العرض والطول** تلقائيًا

**عرض لوحة المعلومات**:
- **خط العرض والطول** بالدرجات العشرية
- **الارتفاع** عن مستوى سطح البحر
- **حالة إشارة GPS** (الدقة)
- **تحديث تلقائي** كل 5 ثوانٍ
- **لا تظهر طلبات تحديد الموقع من المتصفح** (لا تستخدم واجهة المتصفح البرمجية)

**حالة GPS المشتركة**:
- تتاح بيانات GPS **لكل عمليات DagShell**
- يستخدم وضع المسح أثناء التنقل GPS تلقائيًا
- لا تتعارض الميزات

#### وضع مسح الشبكات أثناء التنقل

**الغرض**: مسح شبكات WiFi بإحداثيات GPS لرسم خريطة لها

**آلية العمل**:
1. ينتظر **إشارة GPS صالحة** (لا يسجل إحداثيات 0,0)
2. يمسح شبكات WiFi كل **5 ثوانٍ** في حلقة مستمرة
3. يسجل بيانات الشبكة:
   - **SSID** (اسم الشبكة)
   - **BSSID** (عنوان MAC)
   - **نوع التشفير** (WPA2 أو WPA3 أو مفتوح)
   - **قوة الإشارة** (RSSI بوحدة dBm)
   - **رقم القناة**
   - **إحداثيات GPS** (خط العرض والطول)
   - **الطابع الزمني**
4. يصدّر البيانات بتنسيق **CSV متوافق مع Wigle**

**تكامل Wigle**:
- **WiGLE** (wigle.net) مشروع عالمي لرسم خرائط WiFi
- يمكن **رفع CSV من DagShell مباشرة** إلى WiGLE
- **الرفع عبر المتصفح** من صفحة Files دون أدوات خارجية
- يساهم في **قاعدة بيانات عامة** لمواقع شبكات WiFi

**حالات الاستخدام**:
- **رسم خرائط تغطية WiFi**
- **مسح الشبكات** لمزودي الإنترنت
- **تحليل قوة الإشارة**
- **أبحاث الأمن** (الشبكات المفتوحة والتشفير الضعيف)
- **تحليلات المواقع**

**مثال على تنسيق CSV**:
```csv
MAC,SSID,AuthMode,FirstSeen,Channel,RSSI,Latitude,Longitude,AltitudeMeters
A1:B2:C3:D4:E5:F6,HomeNetwork,WPA2,2026-05-28 10:30:15,6,-45,40.7128,-74.0060,10
```

### 🥧 Raspberry Pi المرافق

يوسّع **Raspberry Pi المرافق** قدرات DagShell باستخدام **عتاد خارجي**.

#### متطلبات العتاد

**الحد الأدنى**:
- **Raspberry Pi 3B+** أو أحدث *(لا يوفر Pi Zero طاقة USB كافية للأجهزة الطرفية)*
- **وحدة GPS USB** (يوصى بمجموعة شرائح U-Blox 7)
- **مزود طاقة** *(يحتاج Pi إلى مصدر طاقة منفصل، إذ لا يوفر منفذ USB في Orbic طاقة كافية)*

**اختياري**:
- **محول WiFi** (واجهة ثانية للمسح مع الحفاظ على الاتصال)
- **وحدة Bluetooth USB** (إذا كان Bluetooth الداخلي في Pi ضعيفًا)

#### وحدة GPS (U-Blox 7)

**الاتصال**: وحدة GPS USB إلى Pi\
**البروتوكول**: جمل NMEA عبر المنفذ التسلسلي\
**التحويل**: يحول Pi إحداثيات ECEF إلى خط العرض والطول تلقائيًا\
**مشاركة البيانات**: يكتب إحداثيات GPS إلى **ملف مشترك** على Orbic

**تحليل الجمل**:
```
$GPGGA,123519,4807.038,N,01131.000,E,1,08,0.9,545.4,M,46.9,M,,*47
       |       |          |           |  |  |   |
       Time    Latitude   Longitude   Fix Sats  Altitude
```

#### مسح Bluetooth (BLE)

**الغرض**: اكتشاف أجهزة Bluetooth القريبة

**آلية العمل**:
- يمسح **إعلانات BLE**
- يلتقط **عناوين MAC**
- يستخدم **بحث OUI** لتحديد الشركة المصنعة
- يسجل النتائج بتنسيق **CSV**

**التحكم عن بعد**:
- بدء المسح أو إيقافه من واجهة DagShell على الويب
- لا حاجة للاتصال بـ Pi عبر SSH
- تحديثات فورية للحالة

**حالات الاستخدام**:
- **تتبع الأجهزة وإحصاؤها**
- **تحليل حركة المارة**
- **اكتشاف أجهزة Bluetooth**
- **أبحاث أمن إنترنت الأشياء**

**مخرجات CSV**:
```csv
Timestamp,MAC,RSSI,Name,Manufacturer
2026-05-28 10:30:15,AA:BB:CC:DD:EE:FF,-65,Fitbit Charge,Fitbit Inc.
```

#### مسح WiFi

**الغرض**: يمسح Pi شبكات WiFi ويرسل بياناتها إلى Orbic

**الميزة**: يوفر واجهة مخصصة للمسح بينما **يحافظ Orbic على نقطة الاتصال**

**آلية العمل**:
- يستخدم Pi **محول WiFi ثانيًا** أو WiFi المدمج إذا لم يكن مطلوبًا للاتصال
- يمسح **كل القنوات** (1-14 على 2.4GHz و36-165 على 5GHz إذا كان العتاد يدعمها)
- يرسل النتائج إلى Orbic عبر التخزين المشترك
- يسجل DagShell البيانات في **ملف CSV للمسح أثناء التنقل**

**التنسيق**:
- يتزامن Pi وOrbic حسب **طابع GPS الزمني**
- يمنع السجلات المكررة
- يجمع **مصدرَي المسح** في سجل واحد

#### هجمات إلغاء المصادقة

**الغرض**: فصل العملاء عن شبكات WiFi (للاختبار في المختبر)

**آلية العمل**:
- يرسل **إطارات إلغاء مصادقة 802.11**
- ينتحل **عنوان MAC لنقطة الوصول**
- يتلقى العميل أمر الفصل من نقطة الوصول
- **ينقطع العميل** ويحاول إعادة الاتصال

**طرق التحكم**:
- **إلغاء مصادقة لمرة واحدة**: دفعة واحدة من الإطارات
- **إلغاء مصادقة مستمر**: يمنع إعادة الاتصال (DoS)
- **تحكم عن بعد**: يبدأ من صفحة مسح DagShell

**حالات استخدام مصرح بها**:
- **إزالة جهاز دخيل** من شبكتك
- **اختبار اختراق** بإذن
- **هجمات Evil Twin** في المختبر (إجبار العملاء على الاتصال بنقطة مزيفة)

**⚠️ تحذير قانوني**: هجمات إلغاء المصادقة **غير قانونية ضد الشبكات التي لا تملكها**. وقد تؤدي إلى مخالفات لقواعد FCC وملاحقة بموجب CFAA.

#### خدمة التشغيل التلقائي

**خدمة systemd**: يبدأ برنامج Pi المرافق تلقائيًا عند الإقلاع

**ملف الخدمة** (`/etc/systemd/system/pi-companion.service`):
```ini
[Unit]
Description=DagShell Pi Companion
After=network.target

[Service]
ExecStart=/usr/bin/python3 /opt/dagshell/pi_companion.py
Restart=always
User=root

[Install]
WantedBy=multi-user.target
```

**الأوامر**:
```bash
# Enable auto-start
sudo systemctl enable pi-companion

# Start service
sudo systemctl start pi-companion

# Check status
sudo systemctl status pi-companion
```

#### قاعدة بيانات OUI

**الغرض**: البحث عن الشركة المصنعة أو المورد المرتبط بعنوان MAC

**قاعدة البيانات**: واجهة API قائمة على البادئات لـ [قاعدة بيانات OUI الرئيسية](https://standards.ieee.org/products-programs/regauth/)

**آلية العمل**:
- يستخرج **أول 3 بايتات** من عنوان MAC (بادئة OUI)
- يستعلم من API: `api.example.com/oui/A4:83:E7`
- يعرض **اسم الشركة المصنعة**

**مثال**:
```
MAC: A4:83:E7:12:34:56
OUI: A4:83:E7
Vendor: Apple, Inc.
```

**التكامل**: يستخدمه ماسح ARP وماسح BLE ومسح WiFi أثناء التنقل

### 📁 مستكشف الملفات

**الغرض**: تصفح ملفات الجهاز وإدارتها

**الموقع**: المجلد `/data/` (قسم قابل للكتابة)

**الإمكانات**:
- **تصفح الملفات** والمجلدات الفرعية
- **تنزيل** الملفات إلى جهازك
- **حذف** الملفات (بعد التأكيد)
- **عرض أحجام الملفات** والطوابع الزمنية

**ملفات شائعة**:
- `wardrive_log.csv`: بيانات مسح WiFi
- `bluetooth_scan.csv`: بيانات أجهزة BLE
- `gps_track.gpx`: مسارات GPS
- `dns_queries.log`: استعلامات DNS الملتقطة
- `arp_scan.txt`: قائمة أجهزة الشبكة

**الرفع إلى Wigle**:
- **رفع مباشر عبر المتصفح** من صفحة Files
- تسجيل الدخول إلى حساب WiGLE
- رفع CSV دون تنزيله أولًا

- افتح المتصفح على: `https://192.168.1.1:8443/`
- اقبل **تحذير الأمان** (الشهادة الموقعة ذاتيًا متوقعة)
- سجّل الدخول ببيانات الاعتماد الافتراضية إذا طُلبت

### تحذير شهادة الأمان

عند فتح DagShell، سيظهر تحذير **"Not Secure"** أو **"Not Trusted"**:

**متصفحات الحاسوب**:
- انقر **"Advanced"**
- انقر **"Proceed to 192.168.1.1 (unsafe)"**

- اضغط **"Show Details"**
- اضغط **"visit this website"**

**سبب التحذير**:
- الشهادة **موقعة ذاتيًا** (وليست صادرة عن CA موثوقة مثل Let's Encrypt)

- **نعم**. الاتصال مشفر بـ **TLS 1.2 أو أحدث**
- لا يمكن اعتراض البيانات
- *الشهادة ليست مرتبطة بسلسلة ثقة إلى CA عامة، لكن التشفير حقيقي.*

**اختياري**: ثبّت `root.der` في مخزن الثقة بجهازك لإزالة التحذير.

## اعتبارات قانونية وأخلاقية

### الإطار القانوني

**تعمل أدوات مثل DagShell في نطاقات قانونية ملتبسة**:

**استخدامات قانونية**:
✅ **شبكاتك الخاصة**: اختبر أجهزتك وشبكاتك\
✅ **الاختبار المصرح به**: اختبر الاختراق بإذن كتابي\
✅ **أغراض تعليمية**: تعلّم في مختبرات معزولة\
✅ **حماية الخصوصية**: استخدم إصلاح TTL وانتحال MAC على جهازك\
✅ **أبحاث الأمن**: ابحث عن الثغرات وأفصح عنها بمسؤولية

**استخدامات غير قانونية**:
❌ **الوصول غير المصرح به**: مهاجمة شبكات لا تملكها (مخالفة CFAA)\
❌ **هجمات إلغاء المصادقة** على شبكات الآخرين (مخالفة قواعد FCC واحتمال تهم جنائية)\
❌ هجمات **Evil Twin** على الجمهور (احتيال عبر الاتصالات وسرقة هوية)\
❌ **التقاط DNS** للآخرين دون موافقتهم (اعتراض للاتصالات)\
❌ **تجاوز الأمن** لارتكاب الاحتيال

### قوانين ينبغي معرفتها

**الولايات المتحدة**:
- **Computer Fraud and Abuse Act (CFAA)**: الوصول غير المصرح به إلى الحواسيب والشبكات
- **Wiretap Act**: اعتراض الاتصالات الإلكترونية
- **لوائح FCC**: التداخل مع الترددات الراديوية (هجمات إلغاء المصادقة)

**المملكة المتحدة**:
- **Computer Misuse Act 1990**: شبيه بـ CFAA
- **Regulation of Investigatory Powers Act (RIPA)**: قيود الاعتراض

**الاتحاد الأوروبي**:
- **GDPR**: حماية البيانات (مسح WiFi وBLE لبيانات تحدد هوية الأشخاص)
- *تختلف القواعد المحلية وتطبيقها من دولة إلى أخرى.*

### إرشادات أخلاقية

**افعل**:
- ✅ استخدم الأدوات على **أجهزتك وشبكاتك**
- ✅ احصل على **إذن كتابي** قبل اختبار أنظمة الآخرين
- ✅ اتبع **الإفصاح المسؤول** عند العثور على ثغرات
- ✅ استخدم الأدوات **للتعليم** في بيئات مضبوطة
- ✅ احمِ **خصوصيتك**

**لا تفعل**:
- ❌ تهاجم شبكات لا تملكها
- ❌ تجمع بيانات اعتماد من أشخاص لا تعرفهم
- ❌ تتدخل في البنى التحتية الحيوية
- ❌ تستخدم الأدوات لأغراض ضارة
- ❌ توزع البيانات الملتقطة

### بيان الاستخدام المسؤول

DagShell **أداة لأبحاث الأمن والخصوصية**. تشبه إمكاناتها أدوات اختبار الاختراق الاحترافية مثل **Kali Linux** و**WiFi Pineapple** و**HackRF**.

**النية مهمة**: يستخدم **الهاكرز الخبيثون** و**متخصصو الأمن** أدوات متشابهة. ويكمن الفرق في:
- **التصريح** (الإذن بالاختبار)
- **النية** (تحسين الأمن أو إلحاق الضرر)
- **الإفصاح** (الإبلاغ عن النتائج أو استغلالها)

استخدم DagShell **بمسؤولية** و**بأخلاق**. *إذا لم تكن متأكدًا من قانونية إجراء ما، فتوقف واستشر محاميًا قبل المتابعة.*

## الخلاصة: المختبر المحمول المتكامل

يحوّل **DagShell** نقطة الاتصال **Orbic RCL400** إلى **مختبر أمن محمول** يجمع بين:

✅ **حماية الخصوصية** (إخفاء TTL وانتحال MAC وحظر الإعلانات)\
✅ **مراقبة الشبكة** (الاتصالات وDNS والتوجيه)\
✅ **أدوات اختراق** (كشف IMSI ومسح المنافذ واكتشاف ARP)\
✅ **إمكانات الهجوم** (Evil Twin والبوابة الأسيرة وإلغاء المصادقة)\
✅ **مسح GPS للشبكات أثناء التنقل** مع تكامل Wigle\
✅ **توسعة Raspberry Pi** (BLE وWiFi وGPS)\
✅ **محمول ويعمل بالبطارية**\
✅ **مفتوح المصدر وقابل للتخصيص**

- **قدرات متكاملة** من دون تداخل
