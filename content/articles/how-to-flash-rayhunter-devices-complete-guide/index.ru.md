## Часто задаваемые вопросы

### Нужна ли активная SIM-карта для использования Rayhunter?

**Rayhunter** требует установленную в устройстве SIM-карту, но ей не нужен активный тариф. SIM необходима, чтобы устройство подключалось к сотовым сетям и выявляло подозрительную активность. Если вы хотите использовать устройство как точку доступа одновременно с **Rayhunter**, понадобится активный тариф.

### Как проверить, что устройство Rayhunter работает?

Включите тестовую эвристику в настройках **Rayhunter**. Устройство будет отправлять оповещение каждый раз при обнаружении базовой станции. Так вы проверите, что система работает. Тестовый режим создаёт много уведомлений, поэтому отключите его после проверки.

### Какое устройство выбрать: заблокированное или разблокированное?

Для **Rayhunter** обычно предпочтительны разблокированные устройства, особенно если вы планируете использовать SIM-карты не Verizon. Большинство устройств Orbic с маркировкой Verizon на самом деле разблокированы, но перед покупкой проверьте совместимость. ## Руководство по установке

### Установка последней версии

Установку **Rayhunter** проверяли в macOS и Ubuntu 24.04. Если возникают проблемы с готовыми сборками, возможно, потребуется установка из исходного кода.

#### Требования

Перед установкой **Rayhunter** убедитесь, что устройство совместимо. Для записи на устройствах TP-Link вставьте SD-карту, отформатированную в FAT.

#### Загрузка и настройка

1. **Загрузите последнюю версию**: скачайте подходящий файл `rayhunter-vX.X.X-PLATFORM.zip` со страницы официальных выпусков:
   - Linux x64: `linux-x64`
   - Linux ARM64: `linux-aarch64`
   - Linux ARM v7/v8: `linux-armv7`
   - macOS Intel: `macos-intel`
   - macOS ARM (M1/M2): `macos-arm`
   - Windows: `windows-x86_64`

2. **Распакуйте архив и перейдите в папку**:
   ```bash
   unzip ~/Downloads/rayhunter-vX.X.X-PLATFORM.zip
   cd ~/Downloads/rayhunter-vX.X.X-PLATFORM
   ```

3. **Подключитесь к устройству**: включите его и подключитесь через WiFi или USB-модем. Должен открыться адрес:
   - Устройства Orbic: `http://192.168.1.1`
   - Устройства TP-Link: `http://192.168.0.1`

#### Установка для конкретных устройств

**Для устройств Orbic RC400L** (доступны **[с Rayhunter](https://stscollective.com)**):

**Rayhunter** поддерживает два способа установки на Orbic RC400L. Большинству пользователей рекомендуется установка через WiFi. Метод через USB предоставляет дополнительные возможности отладки.

**Установка через WiFi (рекомендуется)**:
```bash
# Пользователям macOS сначала нужно выполнить эту команду:
xattr -d com.apple.quarantine installer

# Для Verizon RC400L (пароль администратора совпадает с паролем WiFi):
./installer orbic --admin-password 'YourWiFiPassword'

# Для Kajeet/Smartspot RC400L:
./installer orbic --admin-password='$m@rt$p0tc0nf!g'

# Для устройств Moxee (формат пароля: 12$ + последние 3 цифры пароля WiFi):
./installer orbic --admin-password='12$XXX'
```

**Установка через USB (для опытных пользователей)**:
Метод USB предоставляет доступ к ADB (Android Debug Bridge) для расширенной отладки, но не рекомендуется для обычной установки:

```bash
# ПРЕДУПРЕЖДЕНИЕ: USB-установщик не рекомендуется для большинства сценариев
./installer orbic-usb
```

Этот метод переводит устройство в режим отладки для включения ADB, устанавливает rootshell и **Rayhunter**, а затем перезагружает устройство. Используйте его только при необходимости доступа к ADB для других задач.

**Для устройств TP-Link M7350** (доступны **[с Rayhunter](https://stscollective.com)**):
```bash
./installer tplink
```

Установщик завершит прошивку **Rayhunter** и перезагрузит устройство. Зелёная линия на дисплее указывает, что **Rayhunter** успешно запущен.

### Сборка из исходного кода

Для разработчиков и пользователей, которым нужно собрать **Rayhunter** из исходного кода, проект включает:

- **Интерфейсная часть**: приложение SvelteKit на JavaScript (`./daemon/web/`)
- **Серверная часть**: исполняемый файл Rust `rayhunter-daemon` (`./daemon/`)
- **Установщик**: исполняемый файл Rust со всеми компонентами (`./installer`)

#### Зависимости для сборки

Установите следующие компоненты:
- Язык программирования Rust
- Node.js/npm
- Инструменты для компиляции C (`build-essential` в Linux, `xcode-select --install` в macOS)

#### Процесс сборки

```bash
./scripts/build-dev.sh
./scripts/install-dev.sh orbic  # Замените 'orbic' типом устройства
```

Для разработки интерфейса с автоматической перезагрузкой:
```bash
cd daemon/web
npm run dev
# Или с собственной целью:
API_TARGET=http://192.168.1.1:8080 npm run dev
```

Обновление **Rayhunter** выполняется так же, как установка. Повторите шаги установки с последней версией, чтобы обновить устройство до актуального выпуска **Rayhunter**.

#### Основные параметры настройки

**Уровень отображения на устройстве**: определяет, что **Rayhunter** показывает на экране:
- **Невидимый режим**: ничего не отображается

**Режим кнопок устройства**: настройте поведение кнопки питания:
- **Отключить управление кнопкой**: кнопка питания отключена для **Rayhunter**

**Настройки уведомлений**: настройте URL ntfy для удалённых оповещений и включите или отключите уведомления о предупреждениях и низком заряде аккумулятора.

```bash
./installer util orbic-shell --admin-password mypassword
```

В оболочке устройства выполните команды:

> **Предупреждение:** Эти команды безвозвратно удаляют файлы Rayhunter и сценарии его запуска. Убедитесь, что открыта оболочка нужного устройства, сохраните необходимые записи и настройки, подготовьте установщик и совместимую прошивку. Затем проверьте, что файлы отсутствуют, а устройство перезагружается без службы Rayhunter. Чтобы отменить изменения, переустановите нужную версию из официального репозитория.

echo 3 > /usrdata/mode.cfg
rm -rf /data/rayhunter /etc/init.d/rayhunter_daemon /bin/rootshell

```

### Устройства TP-Link

Для удаления Rayhunter с устройств TP-Link:

> **Предупреждение:** Эти команды удаляют файлы Rayhunter и сценарий запуска с устройства TP-Link. Сначала экспортируйте записи и настройки. Чтобы откатить изменения, установите соответствующий выпуск из официального репозитория.

```

Удалите оставшиеся правила переадресации портов в панели администратора TP-Link: Settings > NAT Settings > Port Triggers.

## Использование Rayhunter

После установки **Rayhunter** запускается автоматически и постоянно отслеживает сотовые сети на подозрительную активность. При обычной работе на дисплее устройства видна зелёная линия. При обнаружении возможного IMSI-catcher она сменяется жёлтыми точками, оранжевыми штрихами или сплошной красной линией.

### Эвристики обнаружения Rayhunter

**Rayhunter** использует несколько сложных алгоритмов для выявления возможной активности IMSI-catcher:

#### Обнаружение запросов IMSI
Эта эвристика выявляет подозрительные последовательности, в которых сотовые вышки запрашивают идентификатор устройства (IMSI, International Mobile Subscriber Identity), не соблюдая надлежащие процедуры аутентификации. **Rayhunter** отслеживает время и контекст запросов, помечая необычные шаблоны, которые могут указывать на оборудование для слежки.

Легитимные сотовые сети следуют стандартным процедурам аутентификации, прежде чем запрашивать конфиденциальные идентификаторы. IMSI-catcher часто обходят эти процедуры, чтобы быстро собирать идентификаторы устройств, создавая заметные отклонения в последовательности аутентификации. Метод особенно эффективен против простых «пассивных» IMSI-catcher, которые только собирают информацию об устройствах.

#### Обнаружение разрыва соединения и перехода на 2G
**Rayhunter** постоянно отслеживает подозрительные попытки отключить мобильные устройства от защищённых сетей 4G/5G и подключить их к менее защищённым сетям 2G. Такая атака с переходом на старую сеть распространена, поскольку в 2G используется более слабое шифрование и перехватить связь проще.

Система анализирует шаблоны разрывов соединения, выявляя необычную частоту, время и контекст, которые могут указывать на злой умысел, а не на обычную оптимизацию сети. Легитимные сети иногда предлагают перейти на старшее поколение из-за покрытия или ёмкости, но **Rayhunter** отличает это от возможной слежки.

#### Обнаружение перехода через LTE SIB6/7
System Information Blocks (SIB) — широковещательные сообщения, с помощью которых сотовые сети передают устройствам конфигурационную информацию. **Rayhunter** отдельно отслеживает сообщения SIB6 и SIB7 с данными о соседних сотах и перенаправлении частот.

Злоумышленники могут передавать поддельные сообщения SIB6/7, чтобы заставить устройства отказаться от защищённого подключения 4G и перейти в контролируемую ими сеть 2G. **Rayhunter** анализирует такие передачи на несоответствия, необычные шаблоны перенаправления и другие признаки поддельных базовых станций, которые принудительно понижают поколение сети для перехвата.

#### Обнаружение нулевого шифрования
Этот важный метод обнаружения выявляет предложения сети использовать соединение без шифрования, то есть нулевое шифрование. Легитимные коммерческие сотовые сети не должны предлагать незашифрованное соединение, поскольку оно нарушает стандарты безопасности и требования законодательства.

**Rayhunter** помечает сеть, предлагающую нулевое шифрование, как крайне подозрительную. *Легитимная сеть никогда не предложит нулевое шифрование.* Это явный признак попытки оборудования для слежки перехватить связь в открытом виде. Эвристика особенно эффективна против IMSI-catcher, которые предпочитают сбор данных сохранению видимости легитимной сети.

#### Обнаружение неполных SIB
Легитимные базовые станции передают полные System Information Blocks с необходимыми данными настройки сети. **Rayhunter** отслеживает станции, передающие неполную или отсутствующую системную информацию. Это часто указывает на поспешно развёрнутое или неправильно настроенное оборудование для слежки.

IMSI-catcher часто не реализуют все функции сотовой сети и ограничиваются минимумом, необходимым для подключения устройств и перехвата данных. Обнаруживая такие неполные реализации, **Rayhunter** может выявлять потенциально вредоносные базовые станции без полного набора функций легитимной сотовой инфраструктуры.

**Уровень сложности угрозы**: от продвинутого до профессионального

- Протестующие и активисты во время демонстраций
- Слежка за населением в районах с повышенными требованиями к безопасности
- Иностранные граждане и дипломатический персонал

**Шаблоны обнаружения**: Государственные IMSI-catcher часто используют сложное оборудование, способное обходить базовые эвристики. При этом они нередко применяют **атаки с переходом на 2G** и **схемы разрыва соединения**, чтобы перевести устройства в менее защищённые сети для упрощения перехвата. Обнаружение перехода через LTE SIB6/7 и отслеживание разрывов соединения в **Rayhunter** особенно эффективны против методов слежки правоохранительных органов.

## Эффективность Rayhunter в эпоху 5G

{{< figure src="rayhunter-5g-downgrade-attack-persistence.webp" alt="Схема телефона с 5G, который атакой принудительно переводят в контролируемую сеть 4G или 3G, что Rayhunter продолжает обнаруживать и в эпоху 5G" >}}

По мере перехода сотовых сетей на 5G возникает вопрос о дальнейшей эффективности **Rayhunter**: система обнаруживает угрозы в сетях 2G, 3G и 4G/LTE, но не исходные методы слежки 5G. Для планирования долгосрочного обнаружения важно понимать текущие ограничения и сохраняющуюся актуальность **Rayhunter** в мире 5G.

### Почему Rayhunter остаётся эффективным в сетях 5G

#### Устойчивость атак с переходом на старые сети
Основной тип атаки, который обнаруживает **Rayhunter**, — принуждение устройств к подключению к менее защищённым сетям — остаётся актуальным при развёртывании 5G. **IMSI-catcher продолжают использовать переходы на 2G и 3G**, потому что:

- **Меньшая стоимость внедрения**: оборудование для старых протоколов обходится намного дешевле, чем разработка систем с поддержкой 5G.
- **Более широкая совместимость с устройствами**: атаки на 2G/3G работают также против старых устройств без поддержки 5G.
- **Проверенные методы атаки**: методы слежки в сетях 2G/3G хорошо документированы и испытаны.
- **Преимущества с точки зрения регулирования**: на некоторые старые технологии слежки может распространяться меньше юридических ограничений, чем на продвинутый перехват 5G.

#### Обратная совместимость сетей
Сети 5G сохраняют **обратную совместимость с 4G/LTE**, а большинство мобильных устройств поддерживают сразу несколько поколений сетей. Это создаёт возможности для атак с переходом на старые сети, на обнаружении которых специализируется **Rayhunter**:

- **Автоматическое переключение**: при слабом покрытии 5G устройства естественным образом переходят на 4G, и оборудование для слежки может перехватить этот переход.
- **Уязвимости согласования протоколов**: сложные IMSI-catcher могут управлять процедурой рукопожатия между поколениями сетей.
- **Использование пробелов в покрытии**: оборудование, стратегически размещённое в местах с неполным покрытием 5G, может переводить устройства в контролируемые сети 4G/LTE.

#### Постепенное развёртывание 5G
**Медленное внедрение полного покрытия 5G** означает, что **Rayhunter** останется актуальным ещё несколько лет:

- **Различия между городом и сельской местностью**: многие регионы по-прежнему в основном используют 4G/LTE, где обнаружение с помощью **Rayhunter** особенно применимо.
- **Ограниченное покрытие внутри помещений**: сигналы 5G часто хуже проходят через стены, и устройства возвращаются в сети 4G, которые **Rayhunter** умеет отслеживать.
- **Международные поездки**: темпы внедрения 5G в разных странах значительно различаются, поэтому слежка через 4G/LTE остаётся риском для путешественников.

#### Технологическое отставание участников угроз
Циклы **закупки и внедрения оборудования для слежки** часто отстают от коммерческих сетевых технологий:

- **Сроки госзакупок**: правоохранительные и разведывательные службы могут годами пользоваться существующим оборудованием для слежки через 4G после развёртывания 5G.
- **Анализ затрат и выгод**: многие операции достигают цели с помощью более дешёвого перехвата 4G/LTE, поэтому переход на системы 5G не всегда оправдан.
- **Требования к обучению и квалификации**: для работы с оборудованием 5G нужны специальные знания, освоение которых может занять время.

### Ограничения Rayhunter в настоящих сетях 5G

#### Слепые зоны при исходной слежке 5G
*Это главное ограничение Rayhunter.* **Rayhunter не обнаруживает исходные операции IMSI-catcher в сетях 5G**, если они не используют атаки с переходом на старые сети:

- **Автономные сети 5G (SA)**: если устройство подключается к чистой сети 5G и не переходит в 4G, **Rayhunter** не сможет отслеживать эту связь.
- **Продвинутое оборудование для слежки через 5G**: сложные участники угроз с доступом к передовым технологиям потенциально могут перехватывать связь 5G, не активируя эвристики **Rayhunter**.
- **Использование сегментации сети**: функции сегментации сети 5G потенциально можно использовать для слежки способами, которые **Rayhunter** не обнаруживает.

#### Улучшенные функции безопасности 5G
Сети 5G используют **улучшенные меры безопасности**, которые способны снизить эффективность традиционных методов слежки:

- **Более надёжные протоколы шифрования**: 5G применяет более устойчивые стандарты, которые сложнее взломать, чем в предыдущих поколениях.
- **Улучшенная аутентификация**: усовершенствованная аутентификация устройств в 5G может затруднить сбор IMSI.
- **Мониторинг безопасности сети**: инфраструктура 5G лучше обнаруживает вторжения и может выявлять и пресекать попытки слежки.

#### Изменение поведения устройств
По мере распространения 5G **поведение мобильных устройств может меняться**, что повлияет на возможности обнаружения **Rayhunter**:

- **Меньшая готовность переходить на старые сети**: будущие обновления программного обеспечения могут усилить защиту от таких атак по мере расширения покрытия 5G.
- **Приоритет 5G**: устройства могут чаще отдавать предпочтение 5G и подозрительнее относиться к запросам использовать старые протоколы.
- **Повышенное внимание к безопасности**: мобильные ОС могут улучшить обнаружение подозрительного поведения сетей.

### Стратегические соображения по развёртыванию Rayhunter

#### Текущие рекомендации по развёртыванию
Для текущего и ближайшего применения **Rayhunter** предлагает **комплексные возможности обнаружения слежки**:

- **Использование в городах**: даже в крупных городах с широким покрытием 5G **Rayhunter** обнаруживает попытки слежки через 4G/LTE.
- **Защита на важных мероприятиях**: во время протестов, конфиденциальных встреч и рискованных действий **Rayhunter** обеспечивает важное обнаружение независимо от доступности 5G.
- **Безопасность в поездках**: **Rayhunter** остаётся эффективным средством обнаружения слежки во время поездок по стране и за границу.

#### Стратегии подготовки к будущему
Организациям и людям, которые планируют долгосрочное обнаружение слежки, следует учитывать следующее:

- **Гибридный подход к обнаружению**: сочетание **Rayhunter** с другими средствами безопасности и мониторинга обеспечивает покрытие разных векторов угроз.
- **Регулярное обновление оценки угроз**: отслеживание развития технологий слежки помогает решить, когда дополнить или заменить возможности **Rayhunter**.
- **Поддержка развития сообщества**: поддержка разработки **Rayhunter** с открытым исходным кодом повышает вероятность, что будущие версии получат обнаружение 5G.

#### Отслеживание развития технологий
Сообщество **Rayhunter** и EFF продолжают исследовать **обнаружение слежки через 5G**:

- **Исследование анализа протоколов**: текущие исследования протоколов 5G могут выявить новые возможности обнаружения для будущих версий **Rayhunter**.
- **Исследования совместимости оборудования**: проверка возможности улучшить устройства, уже совместимые с **Rayhunter**, чтобы обнаруживать попытки слежки через 5G.
- **Мониторинг картины угроз**: отслеживание разработки и развёртывания оборудования для слежки через 5G помогает расставлять приоритеты при развитии **Rayhunter**.

**Rayhunter** остаётся **важным инструментом обнаружения слежки** в современной телекоммуникационной среде и, вероятно, будет полезен ещё несколько лет, пока 5G развёртывается постепенно, а участники угроз продолжают использовать проверенные атаки с переходом на старые сети.

## Документация REST API

**Rayhunter** предоставляет полноценный REST API для программного доступа к состоянию устройства, записям и настройкам. API позволяет интегрировать систему с другими инструментами безопасности и автоматизированными системами мониторинга.

### Официальная документация API

Полный справочник API, включая спецификации конечных точек, примеры запросов и ответов и способы аутентификации, доступен в **[официальной документации REST API Rayhunter](https://efforg.github.io/rayhunter/api-docs/)**.

### Конечные точки API

API **Rayhunter** доступен по адресу `http://[device-ip]:8080/api/` и предоставляет конечные точки для:

- **Состояния системы**: мониторинг состояния устройства и работы **Rayhunter**
- **Управления записями**: запуск, остановка и загрузка записей
- **Получения оповещений**: просмотр оповещений об обнаружении и результатов анализа
- **Настройки**: программное обновление параметров **Rayhunter**
- **Управления эвристиками**: включение и отключение отдельных алгоритмов обнаружения
- **Сведений об устройстве**: получение характеристик и возможностей устройства
- **Мониторинга сети**: доступ к данным сотовой сети в реальном времени
- **Журнала событий**: просмотр прошлых событий обнаружения и оповещений

### Аутентификация

Для доступа к API используется та же аутентификация, что и в веб-интерфейсе. Защитите устройство **Rayhunter** и предоставляйте доступ только авторизованным пользователям.

### Примеры интеграции

REST API **Rayhunter** можно интегрировать с разными платформами мониторинга безопасности, SIEM-системами и пользовательскими средствами автоматизации. Примеры реализации и рекомендации доступны в **[официальной документации API](https://efforg.github.io/rayhunter/api-docs/)**.

## Часто задаваемые вопросы (FAQ)

### Общие вопросы

#### Что такое IMSI-catcher и как он работает?
IMSI-catcher, также называемый StingRay, имитатором базовой станции или фальшивой сотовой вышкой, — оборудование для слежки, которое имитирует легитимные базовые станции для перехвата мобильной связи. Оно заставляет устройства поблизости подключаться к вредоносному оборудованию вместо легитимных вышек, что позволяет операторам собирать идентификаторы устройств (номера IMSI), данные о местоположении, метаданные вызовов и, возможно, перехватывать связь. **Rayhunter** обнаруживает эти устройства, выявляя аномальные шаблоны поведения сотовой сети.

#### Может ли Rayhunter обнаруживать все виды оборудования для слежки?
**Rayhunter** обнаруживает IMSI-catcher и имитаторы базовых станций, работающие в сетях 2G, 3G и 4G/LTE. Он не выявляет другие виды слежки, такие как мониторинг WiFi, GPS-трекеры, физическое наблюдение или изначальные методы слежки 5G без атаки перехода на старую сеть. **Rayhunter** — один из компонентов комплексной защиты конфиденциальности.

#### Законно ли использовать Rayhunter?
В большинстве юрисдикций **Rayhunter** можно использовать как пассивное средство мониторинга, которое не вмешивается в работу сотовых сетей или других устройств. Оно просто анализирует сотовые сигналы, естественным образом получаемые вашим устройством. Законы в разных регионах отличаются, поэтому проверьте местные требования. EFF разработала **Rayhunter** как легитимный инструмент защиты конфиденциальности.

### Технические вопросы

#### Зачем Rayhunter нужна SIM-карта, если активный тариф не требуется?
SIM-карта содержит IMSI (International Mobile Subscriber Identity), необходимый устройству для аутентификации в сотовых сетях и участия в обмене протокольными сообщениями, который отслеживает **Rayhunter**. Без SIM-карты устройство не подключится к сети, и **Rayhunter** будет нечего анализировать на предмет подозрительных шаблонов.

#### Сколько данных использует Rayhunter при обычной работе?
Для базового мониторинга **Rayhunter** использует мало данных, так как анализирует информацию о сотовых протоколах, а не интернет-трафик. Однако трафик увеличится, если включить удалённые уведомления через ntfy или одновременно использовать устройство как точку доступа. Сам мониторинг практически не расходует пропускную способность.

#### Можно ли использовать Rayhunter одновременно с мобильной точкой доступа?
Да, **Rayhunter** может работать одновременно с функцией мобильной точки доступа. Для этого нужен активный тариф сотовой связи. Мониторинг **Rayhunter** не зависит от функции точки доступа, но совместное использование функций увеличит расход аккумулятора.

#### Чем отличается установка через WiFi от установки через USB?
**Метод WiFi** (рекомендуется большинству пользователей) устанавливает **Rayhunter** через беспроводной интерфейс устройства и обеспечивает обычные функции. **Метод USB** предоставляет опытным пользователям доступ к Android Debug Bridge (ADB) для отладки, но сложнее и не нужен для типичной установки.

### Вопросы об устройствах и совместимости

#### Почему Rayhunter поддерживает только некоторые устройства?
**Rayhunter** требует устройство с модемом Qualcomm, который предоставляет интерфейс `/dev/diag` для доступа к информации о сотовых протоколах. Большинство потребительских устройств не предоставляют этот интерфейс по соображениям безопасности. Поддерживаемые устройства специально протестированы и подтверждённо отвечают требованиям **Rayhunter**.

#### Можно ли установить Rayhunter на обычный смартфон?
Нет, **Rayhunter** нельзя установить на обычные смартфоны. Нужны специализированные мобильные точки доступа с конкретными модемами Qualcomm, предоставляющими диагностические интерфейсы. Среди поддерживаемых устройств — Orbic RC400L, TP-Link M7350 и другие модели мобильных точек доступа.

#### Что произойдёт, если попытаться установить Rayhunter на несовместимое устройство?
Установщик **Rayhunter** определяет устройство и обычно отказывается устанавливаться на несовместимое оборудование. Принудительная установка неподдерживаемого ПО может повредить устройство или вывести его из строя. Всегда проверяйте совместимость перед установкой.

#### Нужны ли разные устройства для разных регионов?
Да. Сотовые частоты различаются в зависимости от региона. Orbic RC400L оптимизирован для сетей Америки, а TP-Link M7350 хорошо работает в Европе, Африке и на Ближнем Востоке. В информации о совместимости **Rayhunter** есть региональные рекомендации для выбора устройства под ваше местоположение.

### Вопросы об использовании и настройке

#### Как узнать, что устройство Rayhunter работает правильно?
Включите тестовую эвристику в настройках **Rayhunter**. Она будет отправлять оповещения при каждом обнаружении сотовой вышки, подтверждая работу системы. При обычной работе на дисплее должна отображаться зелёная линия. Отключите тестовую эвристику после проверки, поскольку она создаёт много оповещений.

#### Что делать, если Rayhunter отправил оповещение?
Когда **Rayhunter** обнаруживает подозрительную активность, сначала отметьте местоположение и обстоятельства. Оптимизация сети и проблемы оборудования могут вызывать ложные срабатывания. Если оповещения повторяются в одном месте или во время чувствительных действий, рассмотрите возможность сменить местоположение и изучите подробности в веб-интерфейсе.

#### Как часто нужно обновлять Rayhunter?
**Обновляйте Rayhunter ежемесячно.** Проверяйте страницу выпусков на наличие новых эвристик и улучшений совместимости. Они добавляются часто. EFF постоянно совершенствует возможности **Rayhunter** в ответ на развитие методов слежки. Обновление выполняется так же, как первоначальная установка.

#### Может ли Rayhunter одновременно защищать нескольких людей?
**Rayhunter** обнаруживает IMSI-catcher в окружающей области и потенциально может защищать нескольких людей в радиусе действия, обычно в пределах нескольких сотен метров в зависимости от силы сигнала. Но каждому, кто серьёзно относится к обнаружению слежки, стоит подумать о собственном устройстве **Rayhunter** для максимальной защиты и контроля настроек.

### Вопросы безопасности и конфиденциальности

#### Стану ли я заметнее для слежки, если буду использовать Rayhunter?
**Rayhunter** работает пассивно и не передаёт сигналы, по которым оборудование для слежки могло бы его определить. Однако использование любого средства безопасности говорит о внимании к конфиденциальности. Обычно преимущества обнаружения превышают риски, особенно для людей с высоким уровнем риска, таких как журналисты и активисты.

#### Может ли оборудование для слежки определить, что я использую Rayhunter?
**Rayhunter** — пассивная система мониторинга, которая не передаёт идентифицирующих сигналов. Операторы слежки не могут обнаружить использование **Rayhunter** на уровне сотового протокола. Физическое наблюдение за устройством или анализ сетевого трафика могут выявить использование **Rayhunter**, если включены удалённые уведомления.

#### Какие сведения Rayhunter собирает обо мне?
**Rayhunter** анализирует информацию о сотовых протоколах и хранит оповещения локально на устройстве. Он не собирает личные сведения, содержимое сообщений или данные о местоположении сверх необходимого для алгоритмов обнаружения. Все данные остаются на устройстве, если вы не включите удалённые уведомления.

### Дополнительные вопросы

#### Можно ли анализировать данные Rayhunter на компьютере?
Да. **Rayhunter** включает инструмент командной строки `rayhunter-check` для анализа записанных файлов PCAP и QMDL на настольных компьютерах. Это позволяет опытным пользователям подробно изучать события обнаружения и расследовать подозрительную активность с помощью ресурсов компьютера.

#### Как Rayhunter работает в густонаселённых городах?
В густонаселённых районах с большим количеством легитимных базовых станций оптимизация сети и частая смена вышек могут увеличить число ложных срабатываний. Алгоритмы **Rayhunter** различают обычное поведение сети и слежку, но в городских районах может потребоваться изменить чувствительность.

#### Работает ли Rayhunter во время международных поездок?
Эффективность **Rayhunter** в поездках зависит от совместимости устройства с местными сотовыми частотами и условий роуминга. Алгоритмы обнаружения работают во всём мире, но проверьте поддержку частот в стране назначения. Для полноценной работы может потребоваться международный роуминг.
