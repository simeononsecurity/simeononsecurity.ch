## 网络基础：什么是 IP 地址？IPv4 与 IPv6 有何区别？

### 简介

在网络中，IP 地址用于识别连接到互联网的设备，并与这些设备通信。每台连接到互联网的设备，无论是电脑、智能手机还是智能家居设备，都会分配一个唯一的 IP 地址。本文介绍 IP 地址的含义、IPv4 与 IPv6 的区别，以及个人和企业了解这些概念的重要性。

## 了解 IP 地址

### 什么是 IP 地址？

**IP 地址**（互联网协议地址）是分配给计算机网络中每台设备的数字标签。它有两个主要作用：识别主机或网络接口，并指明设备在网络中的位置。设备需要 IP 地址才能彼此通信并通过互联网交换数据。

IP 地址通常由四组数字组成，组与组之间用句点分隔，例如 192.168.0.1。每组数值的范围为 0 到 255，因此总共有约 43 亿种唯一组合。不过，随着接入互联网的设备不断增加，IPv4 地址空间日渐受限，因此人们开发了 IPv6。

### IPv4：旧标准

{{< youtube id="O48yc2nYBRA" >}}

IPv4，即**互联网协议第 4 版**，是互联网协议的第四个版本。多年来，它一直是互联网中占主导地位的 IP 编址方案。IPv4 地址为 32 位数字，使用前文所述的十进制格式表示，例如 192.168.0.1。

互联网的广泛普及和联网设备的迅速增长，导致可用 IPv4 地址逐渐耗尽。约 43 亿种唯一组合已不足以满足全球设备数量的增长。

### IPv6：新一代协议

{{< youtube id="pUrdDelghwA" >}}

为解决 IPv4 的局限，人们开发了**IPv6**（互联网协议第 6 版）。IPv6 使用 128 位地址，地址空间远大于 IPv4。IPv6 地址采用十六进制格式，并以冒号分隔，而不是熟悉的十进制格式，例如 2001:0db8:85a3:0000:0000:8a2e:0370:7334。

采用 IPv6 后，可用的唯一 IP 地址数量几乎不受限制，因此互联网能够连接数量持续增长的设备。IPv6 还带来其他优势，例如增强安全性、更好地支持移动网络，以及更完善的网络自动配置。

### IPv4 与 IPv6 的主要区别

{{< youtube id="ThdO9beHhpA" >}}

#### 地址空间

IPv4 与 IPv6 最显著的区别在于地址空间。IPv4 提供约 43 亿个唯一地址，而 IPv6 提供约 340 涧个唯一地址（3.4×10^38）。如此庞大的地址空间支持互联网持续扩展，并连接越来越多的设备。

#### 地址格式

两者的地址格式也不同。IPv4 地址由四组十进制数字组成，IPv6 地址则由八组十六进制数字组成。此外，IPv6 地址中连续的零可以用 `::` 表示。此压缩写法简化了地址表示，并缩短了地址长度。

#### 地址配置

IPv4 地址通常由人工分配，也可以通过动态主机配置协议（DHCP）等动态分配方式设置。IPv6 地址则经常通过无状态地址自动配置与 DHCPv6（动态主机配置协议第 6 版）的组合自动分配和配置。

#### 安全性与服务质量

与 IPv4 相比，IPv6 在安全性和服务质量方面提供了多项改进。它集成了 IPsec（互联网协议安全）支持，为网络通信提供端到端加密和身份验证。IPv6 还支持服务质量（QoS）机制，以便为特定类型的网络流量设置优先级。

### 采用 IPv6 的重要性

[从 IPv4 过渡到 IPv6](https://simeononsecurity.com/articles/ipv4-to-ipv6-transition-mechanisms/) 对互联网未来的发展和持续运行至关重要。随着联网设备数量不断增加，IPv4 地址耗尽的问题日益迫近。个人和企业采用 IPv6 后，便能让设备连接互联网，并使用新协议提供的增强功能。

世界各地的政府和监管机构也认识到采用 IPv6 的重要性，并推出倡议和法规来推动过渡。例如，美国政府于 2020 年发布指令，要求所有联邦机构在面向公众的网站和服务中启用 IPv6。

## 结论

IP 地址是设备通过互联网通信和交换数据的基础。IPv4 和 IPv6 是互联网协议的两个版本。IPv4 是较早的标准，IPv6 则提供了可扩展性更强的方案。过渡到 IPv6 对互联网持续发展和连接更多设备十分重要。了解 IP 编址基础，以及 IPv4 与 IPv6 的区别，有助于个人和企业为网络基础设施和未来的互联网连接做出明智选择。
