**ਸਾਫ਼ Windows 10 ਜਾਂ 11 ISO ਕਿਵੇਂ ਡਾਊਨਲੋਡ ਕਰੀਏ ਅਤੇ Windows ਨੂੰ ਸ਼ੁਰੂ ਤੋਂ ਇੰਸਟਾਲ ਕਰੀਏ**

ਜੇ ਤੁਸੀਂ ਨਵੇਂ ਕੰਪਿਊਟਰ 'ਤੇ Windows ਇੰਸਟਾਲ ਕਰਨ ਦੀ ਯੋਜਨਾ ਬਣਾ ਰਹੇ ਹੋ ਜਾਂ ਕਿਸੇ ਸਮੱਸਿਆ ਤੋਂ ਬਚਣ ਲਈ ਸਾਫ਼ ਇੰਸਟਾਲ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਸਾਫ਼ Windows ISO ਫਾਈਲ ਡਾਊਨਲੋਡ ਕਰਨਾ ਪਹਿਲਾ ਜਰੂਰੀ ਕਦਮ ਹੈ। ਇਸ ਲੇਖ ਵਿੱਚ, ਅਸੀਂ ਸਾਫ਼ Windows 10 ਜਾਂ 11 ISO ਡਾਊਨਲੋਡ ਕਰਨ ਦੇ ਕਦਮਾਂ ਨੂੰ ਕਵਰ ਕਰਾਂਗੇ ਅਤੇ ਇੰਸਟਾਲੇਸ਼ਨ ਪ੍ਰਕਿਰਿਆ ਵਿੱਚ ਤੁਹਾਡੀ ਮਦਦ ਕਰਾਂਗੇ।

## ਭਾਗ 1: ਸਾਫ਼ Windows ISO ਫਾਈਲ ਡਾਊਨਲੋਡ ਕਰਨਾ

### ਕਦਮ 1: ਆਪਣੀ ਸਿਸਟਮ ਕਿਸਮ ਚੈੱਕ ਕਰੋ

ਸਾਫ਼ Windows ISO ਡਾਊਨਲੋਡ ਕਰਨ ਦਾ ਪਹਿਲਾ ਕਦਮ ਆਪਣੀ ਸਿਸਟਮ ਕਿਸਮ ਚੈੱਕ ਕਰਨਾ ਹੈ। ਤੁਹਾਨੂੰ ਇਹ ਜਾਣਨਾ ਜਰੂਰੀ ਹੈ ਕਿ ਤੁਹਾਡੇ ਕੋਲ 32-ਬਿਟ ਜਾਂ 64-ਬਿਟ ਸਿਸਟਮ ਹੈ, ਕਿਉਂਕਿ ਇਹ ਇਹ ਨਿਰਧਾਰਤ ਕਰੇਗਾ ਕਿ ਕਿਹੜੀ ISO ਫਾਈਲ ਡਾਊਨਲੋਡ ਕਰਨੀ ਹੈ।

Windows 10 'ਤੇ ਆਪਣੀ ਸਿਸਟਮ ਕਿਸਮ ਚੈੱਕ ਕਰਨ ਲਈ, ਇਹ ਕਦਮ ਫਾਲੋ ਕਰੋ:

1. ਸਟਾਰਟ ਮੀਨੂ ਖੋਲ੍ਹੋ ਅਤੇ "ਸੈਟਿੰਗਜ਼" 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
2. "ਸਿਸਟਮ" 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
3. "ਅਬਾਊਟ" 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
4. "ਡਿਵਾਈਸ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ" ਹੇਠਾਂ, "ਸਿਸਟਮ ਕਿਸਮ" ਦੀ ਐਂਟਰੀ ਚੈੱਕ ਕਰੋ।

ਜੇ ਤੁਹਾਡੇ ਕੋਲ 32-ਬਿਟ ਸਿਸਟਮ ਹੈ, ਤਾਂ ਤੁਹਾਨੂੰ Windows ਦਾ 32-ਬਿਟ ਵਰਜ਼ਨ ਡਾਊਨਲੋਡ ਕਰਨਾ ਪਵੇਗਾ। ਜੇ ਤੁਹਾਡੇ ਕੋਲ 64-ਬਿਟ ਸਿਸਟਮ ਹੈ, ਤਾਂ ਤੁਸੀਂ 32-ਬਿਟ ਜਾਂ 64-ਬਿਟ ਦੋਹਾਂ ਵਿੱਚੋਂ ਕੋਈ ਵੀ ਡਾਊਨਲੋਡ ਕਰ ਸਕਦੇ ਹੋ, ਪਰ ਅਸੀਂ ਵਧੀਆ ਪ੍ਰਦਰਸ਼ਨ ਲਈ 64-ਬਿਟ ਵਰਜ਼ਨ ਦੀ ਸਿਫਾਰਸ਼ ਕਰਦੇ ਹਾਂ।

### ਕਦਮ 2: ਮੀਡੀਆ ਕ੍ਰੀਏਸ਼ਨ ਟੂਲ ਡਾਊਨਲੋਡ ਕਰੋ

ਸਾਫ਼ Windows ISO ਡਾਊਨਲੋਡ ਕਰਨ ਲਈ, ਅਸੀਂ Microsoft ਦਾ ਮੀਡੀਆ ਕ੍ਰੀਏਸ਼ਨ ਟੂਲ ਵਰਤਾਂਗੇ। ਤੁਸੀਂ ਇਸਨੂੰ ਸਿੱਧਾ Microsoft ਦੀ ਵੈੱਬਸਾਈਟ ਤੋਂ ਡਾਊਨਲੋਡ ਕਰ ਸਕਦੇ ਹੋ, ਇਹ ਕਦਮ ਫਾਲੋ ਕਰਕੇ:

1. [Microsoft Windows 10 ਡਾਊਨਲੋਡ ਪੇਜ](https://www.microsoft.com/en-us/software-download/windows10) 'ਤੇ ਜਾਓ।
2. "Windows 10 ਇੰਸਟਾਲੇਸ਼ਨ ਮੀਡੀਆ ਬਣਾਓ" ਸੈਕਸ਼ਨ ਤੱਕ ਸਕ੍ਰੋਲ ਕਰੋ ਅਤੇ "ਟੂਲ ਹੁਣ ਡਾਊਨਲੋਡ ਕਰੋ" 'ਤੇ ਕਲਿੱਕ ਕਰੋ।
3. ਫਾਈਲ ਨੂੰ ਆਪਣੇ ਕੰਪਿਊਟਰ 'ਤੇ ਸੇਵ ਕਰੋ।

ਜੇ ਤੁਸੀਂ Windows 11 ਡਾਊਨਲੋਡ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਪ੍ਰਕਿਰਿਆ ਸਮਾਨ ਹੈ। ਤੁਸੀਂ [Microsoft Windows 11 ਡਾਊਨਲੋਡ ਪੇਜ](https://www.microsoft.com/en-us/software-download/windows11) ਤੋਂ ਮੀਡੀਆ ਕ੍ਰੀਏਸ਼ਨ ਟੂਲ ਡਾਊਨਲੋਡ ਕਰ ਸਕਦੇ ਹੋ ਅਤੇ ਉਹੀ ਕਦਮ ਫਾਲੋ ਕਰੋ।

### ਕਦਮ 3: ਮੀਡੀਆ ਕ੍ਰੀਏਸ਼ਨ ਟੂਲ ਚਲਾਓ

ਜਦੋਂ ਤੁਸੀਂ ਮੀਡੀਆ ਕ੍ਰੀਏਸ਼ਨ ਟੂਲ ਡਾਊਨਲੋਡ ਕਰ ਲੈਂਦੇ ਹੋ, ਤਾਂ ਇਸਨੂੰ ਆਪਣੇ ਕੰਪਿਊਟਰ 'ਤੇ ਚਲਾਓ। ਤੁਹਾਨੂੰ ਪੁੱਛਿਆ ਜਾਵੇਗਾ ਕਿ ਕੀ ਤੁਸੀਂ ਆਪਣੇ ਮੌਜੂਦਾ PC ਨੂੰ ਅੱਪਗ੍ਰੇਡ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ ਜਾਂ ਇੰਸਟਾਲੇਸ਼ਨ ਮੀਡੀਆ ਬਣਾਉਣਾ ਚਾਹੁੰਦੇ ਹੋ। "ਇੰਸਟਾਲੇਸ਼ਨ ਮੀਡੀਆ ਬਣਾਓ" ਵਿਕਲਪ ਚੁਣੋ ਅਤੇ "ਅਗਲਾ" 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

### ਕਦਮ 4: ਆਪਣੀ ਭਾਸ਼ਾ, ਐਡੀਸ਼ਨ ਅਤੇ ਆਰਕੀਟੈਕਚਰ ਚੁਣੋ

ਅਗਲਾ ਕਦਮ ਆਪਣੀ ਭਾਸ਼ਾ, ਐਡੀਸ਼ਨ ਅਤੇ ਆਰਕੀਟੈਕਚਰ ਚੁਣਨਾ ਹੈ। ਤੁਸੀਂ ਭਾਸ਼ਾ ਵਿਕਲਪ ਨੂੰ ਆਪਣੀ ਮੌਜੂਦਾ ਭਾਸ਼ਾ 'ਤੇ ਛੱਡ ਸਕਦੇ ਹੋ ਜਾਂ ਜੇ ਚਾਹੋ ਤਾਂ ਵੱਖਰੀ ਭਾਸ਼ਾ ਚੁਣ ਸਕਦੇ ਹੋ।

ਐਡੀਸ਼ਨ ਲਈ, ਉਸ Windows ਵਰਜ਼ਨ ਨੂੰ ਚੁਣੋ ਜੋ ਤੁਸੀਂ ਇੰਸਟਾਲ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ। ਤੁਹਾਨੂੰ Windows 10 ਹੋਮ ਅਤੇ Windows 10 ਪ੍ਰੋ, ਜਾਂ Windows 11 ਹੋਮ ਅਤੇ Windows 11 ਪ੍ਰੋ ਵਿੱਚੋਂ ਚੋਣ ਕਰਨ ਲਈ ਕਿਹਾ ਜਾਵੇਗਾ।

ਆਰਕੀਟੈਕਚਰ ਲਈ, ਉਹ ਸਿਸਟਮ ਕਿਸਮ ਚੁਣੋ ਜੋ ਤੁਸੀਂ ਕਦਮ 1 ਵਿੱਚ ਨਿਰਧਾਰਤ ਕੀਤੀ ਸੀ। ਜੇ ਤੁਹਾਡੇ ਕੋਲ 64-ਬਿਟ ਸਿਸਟਮ ਹੈ, ਤਾਂ ਵਧੀਆ ਪ੍ਰਦਰਸ਼ਨ ਲਈ 64-ਬਿਟ ਵਰਜ਼ਨ ਚੁਣਨ ਦੀ ਸਿਫਾਰਸ਼ ਕੀਤੀ ਜਾਂਦੀ ਹੈ।

### ਕਦਮ 5: ਆਪਣੀ ਮੀਡੀਆ ਕਿਸਮ ਚੁਣੋ

ਅਗਲਾ ਕਦਮ ਆਪਣੀ ਮੀਡੀਆ ਕਿਸਮ ਚੁਣਨਾ ਹੈ। ਤੁਸੀਂ ਜਾਂ ਤਾਂ ਬੂਟੇਬਲ USB ਡਰਾਈਵ ਬਣਾ ਸਕਦੇ ਹੋ ਜਾਂ ISO ਫਾਈਲ ਡਾਊਨਲੋਡ ਕਰ ਸਕਦੇ ਹੋ।

ਜੇ ਤੁਸੀਂ ਬੂਟੇਬਲ USB ਡਰਾਈਵ ਬਣਾਉਣ ਦਾ ਚੋਣ ਕਰਦੇ ਹੋ, ਤਾਂ ਤੁਹਾਨੂੰ ਘੱਟੋ-ਘੱਟ 8 GB ਦੀ ਜਗ੍ਹਾ ਵਾਲਾ USB ਡਰਾਈਵ ਚਾਹੀਦਾ ਹੋਵੇਗਾ। ਮੀਡੀਆ ਕ੍ਰੀਏਸ਼ਨ ਟੂਲ ਆਪਣੇ ਆਪ ਡਰਾਈਵ ਨੂੰ ਫਾਰਮੈਟ ਕਰੇਗਾ ਅਤੇ ਜ਼ਰੂਰੀ ਫਾਈਲਾਂ ਕਾਪੀ ਕਰੇਗਾ।

ਜੇ ਤੁਸੀਂ ISO ਫਾਈਲ ਡਾਊਨਲੋਡ ਕਰਨ ਦਾ ਚੋਣ ਕਰਦੇ ਹੋ, ਤਾਂ ਮੀਡੀਆ ਕ੍ਰੀਏਸ਼ਨ ਟੂਲ ਫਾਈਲ ਡਾਊਨਲੋਡ ਕਰਕੇ ਆਪਣੇ ਕੰਪਿਊਟਰ 'ਤੇ ਸੇਵ ਕਰੇਗਾ। ਫਿਰ ਤੁਸੀਂ ਤੀਜੀ-ਪੱਖੀ ਟੂਲ ਵਰਤ ਕੇ ਬੂਟੇਬਲ USB ਡਰਾਈਵ ਬਣਾ ਸਕਦੇ ਹੋ ਜਾਂ ISO ਨੂੰ DVD 'ਤੇ ਬਰਨ ਕਰ ਸਕਦੇ ਹੋ।

### ਕਦਮ 6: ISO ਫਾਈਲ ਡਾਊਨਲੋਡ ਕਰੋ

ਜੇ ਤੁਸੀਂ ISO ਫਾਈਲ ਡਾਊਨਲੋਡ ਕਰਨ ਦਾ ਚੋਣ ਕੀਤਾ ਹੈ, ਤਾਂ ਮੀਡੀਆ ਕ੍ਰੀਏਸ਼ਨ ਟੂਲ ਫਾਈਲ ਡਾਊਨਲੋਡ ਕਰਨਾ ਸ਼ੁਰੂ ਕਰੇਗਾ। ਇਹ ਤੁਹਾਡੇ ਇੰਟਰਨੈੱਟ ਕਨੈਕਸ਼ਨ ਦੀ ਗਤੀ 'ਤੇ ਨਿਰਭਰ ਕਰਦਾ ਹੈ ਕਿ ਇਸ ਵਿੱਚ ਕੁਝ ਸਮਾਂ ਲੱਗ ਸਕਦਾ ਹੈ।

ਡਾਊਨਲੋਡ ਮੁਕੰਮਲ ਹੋਣ 'ਤੇ, ਟੂਲ ਫਾਈਲ ਦੀ ਪੁਸ਼ਟੀ ਕਰੇਗਾ ਕਿ ਇਹ ਸਾਫ਼ ISO ਹੈ।

### ਕਦਮ 7: ISO ਫਾਈਲ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ

ISO ਫਾਈਲ ਦੀ ਪੁਸ਼ਟੀ ਕਰਨਾ ਜਰੂਰੀ ਕਦਮ ਹੈ ਤਾਂ ਜੋ ਇਹ ਯਕੀਨੀ ਬਣਾਇਆ ਜਾ ਸਕੇ ਕਿ ਤੁਸੀਂ ਜੋ ਫਾਈਲ ਡਾਊਨਲੋਡ ਕੀਤੀ ਹੈ ਉਹ ਸਾਫ਼ ਹੈ ਅਤੇ ਇਸ ਵਿੱਚ ਕੋਈ ਤਬਦੀਲੀ ਨਹੀਂ ਕੀਤੀ ਗਈ। ਫਾਈਲ ਦੀ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ, ਤੁਸੀਂ [HashCalc](https://www.slavasoft.com/hashcalc/) ਜਾਂ [MD5 ਅਤੇ SHA ਚੈਕਸਮ ਯੂਟਿਲਿਟੀ](https://raylin.wordpress.com/downloads/md5-sha-1-checksum-utility/) ਵਰਗਾ ਟੂਲ ਵਰਤ ਸਕਦੇ ਹੋ।

ਜਦੋਂ ਤੁਸੀਂ ਪੁਸ਼ਟੀ ਟੂਲ ਡਾਊਨਲੋਡ ਅਤੇ ਇੰਸਟਾਲ ਕਰ ਲੈਂਦੇ ਹੋ, ਇਸਨੂੰ ਖੋਲ੍ਹੋ ਅਤੇ ਉਹ ISO ਫਾਈਲ ਚੁਣੋ ਜੋ ਤੁਸੀਂ ਡਾਊਨਲੋਡ ਕੀਤੀ ਹੈ। ਟੂਲ ਫਾਈਲ ਦਾ ਹੈਸ਼ ਮੁੱਲ ਕੈਲਕੁਲੇਟ ਕਰੇਗਾ ਅਤੇ ਇਸਨੂੰ Microsoft ਵੱਲੋਂ Windows ਡਾਊਨਲੋਡ ਪੇਜ 'ਤੇ ਦਿੱਤੇ ਗਏ ਹੈਸ਼ ਮੁੱਲ ਨਾਲ ਤੁਲਨਾ ਕਰੇਗਾ। ਜੇ ਹੈਸ਼ ਮੁੱਲ ਮਿਲਦੇ ਹਨ, ਤਾਂ ISO ਫਾਈਲ ਸਾਫ਼ ਹੈ ਅਤੇ Windows ਇੰਸਟਾਲ ਕਰਨ ਲਈ ਵਰਤੀ ਜਾ ਸਕਦੀ ਹੈ।

## ਭਾਗ 2: ਸਾਫ਼ ISO ਤੋਂ Windows ਇੰਸਟਾਲ ਕਰਨਾ

ਜਦੋਂ ਤੁਹਾਡੇ ਕੋਲ ਸਾਫ਼ Windows ISO ਫਾਈਲ ਹੋਵੇ, ਤੁਸੀਂ ਇਸਨੂੰ ਆਪਣੇ ਕੰਪਿਊਟਰ 'ਤੇ Windows ਇੰਸਟਾਲ ਕਰਨ ਲਈ ਵਰਤ ਸਕਦੇ ਹੋ। ਇੱਥੇ ਕਦਮ ਹਨ ਜੋ ਤੁਹਾਨੂੰ ਫਾਲੋ ਕਰਨੇ ਹਨ:

### ਕਦਮ 1: ਇੰਸਟਾਲੇਸ਼ਨ ਮੀਡੀਆ ਬਣਾਓ

ISO ਫਾਈਲ ਤੋਂ Windows ਇੰਸਟਾਲ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ, ਤੁਹਾਨੂੰ ਇੰਸਟਾਲੇਸ਼ਨ ਮੀਡੀਆ ਬਣਾਉਣੀ ਪਵੇਗੀ। ਤੁਸੀਂ ਇਹ ਬੂਟੇਬਲ USB ਡਰਾਈਵ ਜਾਂ DVD ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਕਰ ਸਕਦੇ ਹੋ।

ਬੂਟੇਬਲ USB ਡਰਾਈਵ ਬਣਾਉਣ ਲਈ, ਤੁਸੀਂ [Rufus](https://rufus.ie/) ਜਾਂ [Windows USB/DVD ਡਾਊਨਲੋਡ ਟੂਲ](https://www.microsoft.com/en-us/download/windows-usb-dvd-download-tool) ਵਰਗਾ ਟੂਲ ਵਰਤ ਸਕਦੇ ਹੋ। ਸਿਰਫ USB ਡਰਾਈਵ ਪਲੱਗ ਕਰੋ, ਟੂਲ ਖੋਲ੍ਹੋ ਅਤੇ ਬੂਟੇਬਲ ਡਰਾਈਵ ਬਣਾਉਣ ਲਈ ਹਦਾਇਤਾਂ ਦੀ ਪਾਲਣਾ ਕਰੋ।

ਜੇ ਤੁਸੀਂ DVD ਵਰਤਣਾ ਪਸੰਦ ਕਰਦੇ ਹੋ, ਤਾਂ ਤੁਸੀਂ [ImgBurn](https://www.imgburn.com/) ਜਾਂ [CDBurnerXP](https://cdburnerxp.se/en/home) ਵਰਗਾ ਟੂਲ ਵਰਤ ਸਕਦੇ ਹੋ। DVD ਦਾਖਲ ਕਰੋ, ਟੂਲ ਖੋਲ੍ਹੋ ਅਤੇ ISO ਫਾਈਲ ਨੂੰ DVD 'ਤੇ ਬਰਨ ਕਰਨ ਲਈ ਹਦਾਇਤਾਂ ਦੀ ਪਾਲਣਾ ਕਰੋ।

### ਕਦਮ 2: ਇੰਸਟਾਲੇਸ਼ਨ ਮੀਡੀਆ ਤੋਂ ਬੂਟ ਕਰੋ

ਜਦੋਂ ਤੁਸੀਂ ਇੰਸਟਾਲੇਸ਼ਨ ਮੀਡੀਆ ਬਣਾਉ ਲੈਂਦੇ ਹੋ, ਤਾਂ ਤੁਹਾਨੂੰ ਆਪਣੇ ਕੰਪਿਊਟਰ ਨੂੰ ਇਸ ਤੋਂ ਬੂਟ ਕਰਨਾ ਪਵੇਗਾ। ਇਸ ਲਈ, ਤੁਹਾਨੂੰ ਆਪਣੇ ਕੰਪਿਊਟਰ ਦੇ BIOS ਜਾਂ UEFI ਫਰਮਵੇਅਰ ਵਿੱਚ ਬੂਟ ਆਰਡਰ ਬਦਲਣ ਦੀ ਲੋੜ ਪੈ ਸਕਦੀ ਹੈ।

BIOS ਜਾਂ UEFI ਫਰਮਵੇਅਰ ਵਿੱਚ ਜਾਣ ਲਈ, ਆਪਣੇ ਕੰਪਿਊਟਰ ਨੂੰ ਰੀਸਟਾਰਟ ਕਰੋ ਅਤੇ ਉਹ ਕੁੰਜੀ ਦਬਾਓ ਜੋ ਸਕ੍ਰੀਨ 'ਤੇ ਦਿਖਾਈ ਦੇਂਦੀ ਹੈ। ਆਮ ਤੌਰ 'ਤੇ ਇਹ F2, F10 ਜਾਂ Del ਹੁੰਦੀ ਹੈ। ਜਦੋਂ ਤੁਸੀਂ BIOS ਜਾਂ UEFI ਫਰਮਵੇਅਰ ਵਿੱਚ ਹੋ, "Boot" ਮੀਨੂ ਲੱਭੋ ਅਤੇ ਬੂਟ ਆਰਡਰ ਬਦਲੋ ਤਾਂ ਜੋ ਤੁਹਾਡਾ ਇੰਸਟਾਲੇਸ਼ਨ ਮੀਡੀਆ ਸੂਚੀ ਦੇ ਸਿਰੇ 'ਤੇ ਹੋਵੇ।

### ਕਦਮ 3: Windows ਇੰਸਟਾਲ ਕਰੋ

ਜਦੋਂ ਤੁਹਾਡਾ ਕੰਪਿਊਟਰ ਇੰਸਟਾਲੇਸ਼ਨ ਮੀਡੀਆ ਤੋਂ ਬੂਟ ਕਰ ਲੈਂਦਾ ਹੈ, ਤਾਂ ਤੁਹਾਨੂੰ Windows ਸੈਟਅੱਪ ਸਕ੍ਰੀਨ ਦਿਖਾਈ ਦੇਵੇਗੀ। Windows ਇੰਸਟਾਲ ਕਰਨ ਲਈ ਹਦਾਇਤਾਂ ਦੀ ਪਾਲਣਾ ਕਰੋ।

ਤੁਹਾਨੂੰ ਆਪਣੀ ਭਾਸ਼ਾ, ਸਮਾਂ ਖੇਤਰ ਅਤੇ ਕੀਬੋਰਡ ਲੇਆਉਟ ਚੁਣਨ ਲਈ ਕਿਹਾ ਜਾਵੇਗਾ। ਫਿਰ ਤੁਹਾਨੂੰ ਆਪਣੀ ਉਤਪਾਦ ਕੁੰਜੀ ਦਰਜ ਕਰਨ ਲਈ ਕਿਹਾ ਜਾਵੇਗਾ। ਜੇ ਤੁਹਾਡੇ ਕੋਲ ਉਤਪਾਦ ਕੁੰਜੀ ਨਹੀਂ ਹੈ, ਤਾਂ ਤੁਸੀਂ "ਮੇਰੇ ਕੋਲ ਉਤਪਾਦ ਕੁੰਜੀ ਨਹੀਂ ਹੈ" ਵਿਕਲਪ ਚੁਣ ਸਕਦੇ ਹੋ ਅਤੇ ਇੰਸਟਾਲੇਸ਼ਨ ਜਾਰੀ ਰੱਖ ਸਕਦੇ ਹੋ। Windows ਇੰਸਟਾਲ ਹੋਣ ਤੋਂ ਬਾਅਦ ਤੁਸੀਂ ਇਸਨੂੰ ਐਕਟੀਵੇਟ ਕਰ ਸਕਦੇ ਹੋ।

ਅਗਲੇ, ਤੁਹਾਨੂੰ ਇੰਸਟਾਲੇਸ਼ਨ ਦੀ ਕਿਸਮ ਚੁਣਨ ਲਈ ਕਿਹਾ ਜਾਵੇਗਾ। ਸਾਫ਼ ਇੰਸਟਾਲੇਸ਼ਨ ਕਰਨ ਲਈ "ਕਸਟਮ" ਵਿਕਲਪ ਚੁਣੋ।

ਤੁਹਾਨੂੰ ਫਿਰ ਉਹ ਪਾਰਟੀਸ਼ਨ ਚੁਣਨ ਲਈ ਕਿਹਾ ਜਾਵੇਗਾ ਜਿੱਥੇ ਤੁਸੀਂ Windows ਇੰਸਟਾਲ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ। ਜੇ ਤੁਸੀਂ ਨਵੇਂ ਕੰਪਿਊਟਰ ਜਾਂ ਖਾਲੀ ਹਾਰਡ ਡ੍ਰਾਈਵ ਵਾਲੇ ਕੰਪਿਊਟਰ 'ਤੇ Windows ਇੰਸਟਾਲ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਤੁਹਾਨੂੰ ਅਣਵੰਡਿਤ ਸਪੇਸ ਦਿਖਾਈ ਦੇਵੇਗੀ। ਅਣਵੰਡਿਤ ਸਪੇਸ ਚੁਣੋ ਅਤੇ ਨਵਾਂ ਪਾਰਟੀਸ਼ਨ ਬਣਾਉਣ ਅਤੇ Windows ਇੰਸਟਾਲ ਕਰਨ ਲਈ "ਅਗਲਾ" 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

ਇੰਸਟਾਲੇਸ਼ਨ ਪੂਰੀ ਹੋਣ ਤੋਂ ਬਾਅਦ, Windows ਰੀਸਟਾਰਟ ਹੋਵੇਗਾ ਅਤੇ ਤੁਹਾਨੂੰ ਆਪਣਾ ਯੂਜ਼ਰ ਖਾਤਾ ਸੈੱਟਅਪ ਕਰਨ ਲਈ ਕਿਹਾ ਜਾਵੇਗਾ।

## ਨਤੀਜਾ

Windows ਦਾ ਸਾਫ਼ ISO ਡਾਊਨਲੋਡ ਕਰਨਾ ਅਤੇ Windows ਨੂੰ ਮੁੜ ਤੋਂ ਇੰਸਟਾਲ ਕਰਨਾ ਮੁਸ਼ਕਲ ਲੱਗ ਸਕਦਾ ਹੈ, ਪਰ ਇਹ ਇੱਕ ਸਿੱਧਾ ਪ੍ਰਕਿਰਿਆ ਹੈ ਜੋ ਕੋਈ ਵੀ ਕਰ ਸਕਦਾ ਹੈ। ਇਸ ਗਾਈਡ ਵਿੱਚ ਦਿੱਤੇ ਕਦਮਾਂ ਦੀ ਪਾਲਣਾ ਕਰਕੇ, ਤੁਸੀਂ ਯਕੀਨੀ ਬਣਾ ਸਕਦੇ ਹੋ ਕਿ ਤੁਹਾਡੇ ਕੋਲ ਸਾਫ਼ Windows ਹੈ।
