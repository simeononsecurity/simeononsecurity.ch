**साफ़ Windows 10 या 11 ISO कैसे डाउनलोड करें और Windows को स्क्रैच से इंस्टॉल करें**

यदि आप नए कंप्यूटर पर Windows इंस्टॉल करने की योजना बना रहे हैं या किसी समस्या से छुटकारा पाने के लिए साफ़ इंस्टॉल करना चाहते हैं, तो साफ़ Windows ISO फ़ाइल डाउनलोड करना पहला आवश्यक कदम है। इस लेख में, हम साफ़ Windows 10 या 11 ISO डाउनलोड करने के चरणों को कवर करेंगे और इंस्टॉलेशन प्रक्रिया में आपका मार्गदर्शन करेंगे।

## भाग 1: साफ़ Windows ISO फ़ाइल डाउनलोड करना

### चरण 1: अपने सिस्टम प्रकार की जांच करें

साफ़ Windows ISO डाउनलोड करने का पहला कदम है अपने सिस्टम प्रकार की जांच करना। आपको यह जानना होगा कि आपका सिस्टम 32-बिट है या 64-बिट, क्योंकि यह तय करेगा कि कौन सी ISO फ़ाइल डाउनलोड करनी है।

Windows 10 पर अपने सिस्टम प्रकार की जांच करने के लिए, ये चरण अपनाएं:

1. स्टार्ट मेनू खोलें और "सेटिंग्स" पर क्लिक करें।
2. "सिस्टम" पर क्लिक करें।
3. "अबाउट" पर क्लिक करें।
4. "डिवाइस स्पेसिफिकेशन" के तहत, "सिस्टम प्रकार" प्रविष्टि देखें।

यदि आपका सिस्टम 32-बिट है, तो आपको Windows का 32-बिट संस्करण डाउनलोड करना होगा। यदि आपका सिस्टम 64-बिट है, तो आप 32-बिट या 64-बिट संस्करण दोनों डाउनलोड कर सकते हैं, लेकिन बेहतर प्रदर्शन के लिए हम 64-बिट संस्करण की सलाह देते हैं।

### चरण 2: मीडिया क्रिएशन टूल डाउनलोड करें

साफ़ Windows ISO डाउनलोड करने के लिए, हम Microsoft का मीडिया क्रिएशन टूल उपयोग करेंगे। आप इसे Microsoft की वेबसाइट से सीधे डाउनलोड कर सकते हैं, इसके लिए ये चरण अपनाएं:

1. [Microsoft Windows 10 डाउनलोड पेज](https://www.microsoft.com/en-us/software-download/windows10) पर जाएं।
2. "Create Windows 10 installation media" सेक्शन तक स्क्रॉल करें और "Download tool now" पर क्लिक करें।
3. फ़ाइल को अपने कंप्यूटर पर सेव करें।

यदि आप Windows 11 डाउनलोड करना चाहते हैं, तो प्रक्रिया समान है। आप [Microsoft Windows 11 डाउनलोड पेज](https://www.microsoft.com/en-us/software-download/windows11) से मीडिया क्रिएशन टूल डाउनलोड कर सकते हैं और वही चरण फॉलो कर सकते हैं।

### चरण 3: मीडिया क्रिएशन टूल चलाएं

मीडिया क्रिएशन टूल डाउनलोड करने के बाद, इसे अपने कंप्यूटर पर चलाएं। आपसे पूछा जाएगा कि क्या आप अपने वर्तमान पीसी को अपग्रेड करना चाहते हैं या इंस्टॉलेशन मीडिया बनाना चाहते हैं। "Create installation media" विकल्प चुनें और "Next" पर क्लिक करें।

### चरण 4: अपनी भाषा, संस्करण और आर्किटेक्चर चुनें

अगला कदम है अपनी भाषा, संस्करण और आर्किटेक्चर चुनना। आप भाषा विकल्प को अपनी वर्तमान भाषा पर छोड़ सकते हैं, या यदि चाहें तो कोई अलग भाषा चुन सकते हैं।

संस्करण के लिए, उस Windows संस्करण को चुनें जिसे आप इंस्टॉल करना चाहते हैं। आपको Windows 10 Home और Windows 10 Pro, या Windows 11 Home और Windows 11 Pro के बीच विकल्प मिलेगा।

आर्किटेक्चर के लिए, उस सिस्टम प्रकार का चयन करें जिसे आपने चरण 1 में निर्धारित किया था। यदि आपका सिस्टम 64-बिट है, तो बेहतर प्रदर्शन के लिए 64-बिट संस्करण चुनने की सलाह दी जाती है।

### चरण 5: अपनी मीडिया प्रकार चुनें

अगला कदम है अपनी मीडिया प्रकार चुनना। आप या तो बूटेबल USB ड्राइव बना सकते हैं या ISO फ़ाइल डाउनलोड कर सकते हैं।

यदि आप बूटेबल USB ड्राइव बनाना चुनते हैं, तो आपको कम से कम 8 GB की जगह वाला USB ड्राइव चाहिए होगा। मीडिया क्रिएशन टूल स्वचालित रूप से ड्राइव को फॉर्मेट करेगा और आवश्यक फ़ाइलें कॉपी करेगा।

यदि आप ISO फ़ाइल डाउनलोड करना चुनते हैं, तो मीडिया क्रिएशन टूल फ़ाइल डाउनलोड करेगा और इसे आपके कंप्यूटर पर सेव करेगा। आप फिर किसी थर्ड-पार्टी टूल का उपयोग करके बूटेबल USB ड्राइव बना सकते हैं या ISO को DVD पर बर्न कर सकते हैं।

### चरण 6: ISO फ़ाइल डाउनलोड करें

यदि आपने ISO फ़ाइल डाउनलोड करना चुना है, तो मीडिया क्रिएशन टूल फ़ाइल डाउनलोड करना शुरू कर देगा। यह आपके इंटरनेट कनेक्शन की गति पर निर्भर करते हुए कुछ समय ले सकता है।

डाउनलोड पूरा होने के बाद, टूल फ़ाइल की पुष्टि करेगा कि यह एक साफ़ ISO है।

### चरण 7: ISO फ़ाइल सत्यापित करें

ISO फ़ाइल की पुष्टि करना एक आवश्यक कदम है ताकि यह सुनिश्चित किया जा सके कि आपने जो फ़ाइल डाउनलोड की है वह साफ़ है और उसमें कोई बदलाव नहीं किया गया है। फ़ाइल सत्यापित करने के लिए, आप [HashCalc](https://www.slavasoft.com/hashcalc/) या [MD5 और SHA चेकसम यूटिलिटी](https://raylin.wordpress.com/downloads/md5-sha-1-checksum-utility/) जैसे टूल का उपयोग कर सकते हैं।

सत्यापन टूल डाउनलोड और इंस्टॉल करने के बाद, इसे खोलें और डाउनलोड की गई ISO फ़ाइल चुनें। टूल फ़ाइल का हैश मान गणना करेगा और इसे Microsoft द्वारा Windows डाउनलोड पेज पर प्रदान किए गए हैश मान से तुलना करेगा। यदि हैश मान मेल खाते हैं, तो ISO फ़ाइल साफ़ है और Windows इंस्टॉल करने के लिए उपयोग की जा सकती है।

## भाग 2: साफ़ ISO से Windows इंस्टॉल करना

एक बार जब आपके पास साफ़ Windows ISO फ़ाइल हो, तो आप इसका उपयोग अपने कंप्यूटर पर Windows इंस्टॉल करने के लिए कर सकते हैं। यहां पालन करने के चरण हैं:

### चरण 1: इंस्टॉलेशन मीडिया बनाएं

ISO फ़ाइल से Windows इंस्टॉल करने से पहले, आपको इंस्टॉलेशन मीडिया बनाना होगा। आप यह बूटेबल USB ड्राइव या DVD का उपयोग करके कर सकते हैं।

बूटेबल USB ड्राइव बनाने के लिए, आप [Rufus](https://rufus.ie/) या [Windows USB/DVD डाउनलोड टूल](https://www.microsoft.com/en-us/download/windows-usb-dvd-download-tool) जैसे टूल का उपयोग कर सकते हैं। बस USB ड्राइव लगाएं, टूल खोलें, और बूटेबल ड्राइव बनाने के निर्देशों का पालन करें।

यदि आप DVD का उपयोग करना पसंद करते हैं, तो आप [ImgBurn](https://www.imgburn.com/) या [CDBurnerXP](https://cdburnerxp.se/en/home) जैसे टूल का उपयोग कर सकते हैं। DVD डालें, टूल खोलें, और ISO फ़ाइल को DVD पर बर्न करने के निर्देशों का पालन करें।

### चरण 2: इंस्टॉलेशन मीडिया से बूट करें

इंस्टॉलेशन मीडिया बनाने के बाद, आपको अपने कंप्यूटर को उससे बूट करना होगा। इसके लिए, आपको अपने कंप्यूटर के BIOS या UEFI फर्मवेयर में बूट ऑर्डर बदलना पड़ सकता है।

BIOS या UEFI फर्मवेयर में प्रवेश करने के लिए, अपने कंप्यूटर को रीस्टार्ट करें और स्क्रीन पर दिखाए गए की को दबाएं। यह आमतौर पर F2, F10, या Del होता है। BIOS या UEFI फर्मवेयर में, "Boot" मेनू खोजें और बूट ऑर्डर बदलें ताकि आपका इंस्टॉलेशन मीडिया सूची में सबसे ऊपर हो।

### चरण 3: Windows इंस्टॉल करें

जब आपका कंप्यूटर इंस्टॉलेशन मीडिया से बूट हो जाए, तो आप Windows सेटअप स्क्रीन देखेंगे। Windows को अपने कंप्यूटर पर इंस्टॉल करने के लिए निर्देशों का पालन करें।

आपसे अपनी भाषा, टाइम ज़ोन, और कीबोर्ड लेआउट चुनने के लिए कहा जाएगा। फिर आपसे प्रोडक्ट की दर्ज करने के लिए कहा जाएगा। यदि आपके पास प्रोडक्ट की नहीं है, तो आप "मेरे पास प्रोडक्ट की नहीं है" विकल्प चुन सकते हैं और इंस्टॉलेशन जारी रख सकते हैं। Windows इंस्टॉल होने के बाद आप इसे बाद में सक्रिय कर सकते हैं।

अगला, आपसे इंस्टॉलेशन का प्रकार चुनने के लिए कहा जाएगा। साफ़ इंस्टॉलेशन करने के लिए "Custom" विकल्प चुनें।

फिर आपसे उस विभाजन का चयन करने के लिए कहा जाएगा जहाँ आप Windows स्थापित करना चाहते हैं। यदि आप Windows एक नए कंप्यूटर या खाली हार्ड ड्राइव वाले कंप्यूटर पर स्थापित कर रहे हैं, तो आप अनअलोकेटेड स्पेस देखेंगे। अनअलोकेटेड स्पेस का चयन करें और नया विभाजन बनाने और Windows स्थापित करने के लिए "Next" पर क्लिक करें।

स्थापना पूरी होने के बाद, Windows पुनः आरंभ होगा, और आपसे अपना उपयोगकर्ता खाता सेटअप करने के लिए कहा जाएगा।

## निष्कर्ष

एक साफ Windows ISO डाउनलोड करना और Windows को शुरू से स्थापित करना चुनौतीपूर्ण लग सकता है, लेकिन यह एक सरल प्रक्रिया है जिसे कोई भी कर सकता है। इस गाइड के चरणों का पालन करके, आप सुनिश्चित कर सकते हैं कि आपके पास एक साफ Windows है।
