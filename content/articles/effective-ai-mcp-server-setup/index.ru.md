**Используйте MCP-сервер, когда задаче нужен повторно используемый инструмент или актуальная информация за пределами проекта.** Model Context Protocol, или MCP, описывает обмен сведениями об инструментах, ресурсах и промптах между клиентом и сервером. Запись сервера сама по себе не доказывает, что инструмент работает. В этом уроке проверяется подключение к документации только для чтения.

**Результат обучения:** вы отличите настройку от реального чтения через MCP и зафиксируете безопасное удаление.

## Главное

- **Хост MCP:** приложение ИИ, координирующее пользователей, модели, разрешения и клиенты.
- **Клиент MCP:** компонент протокола, который связывается с сервером.
- **Сервер MCP:** программа или удаленная служба, предоставляющая инструменты, ресурсы или промпты.
- **Обнаружение инструмента:** подтверждение, что в клиенте появился именованный инструмент.
- **Выполнение инструмента:** подтверждение реального вызова и полученного содержимого.
- **Область разрешений:** доступ, который предоставляют хост, сервер, учетная запись и пользователь.

## Перед началом

**Требования:** [практика работы с контекстом и передачей задач](/articles/effective-ai-context-window-management/) и актуальная установка Codex CLI для пошагового примера. Выделите 35 минут. Уровень сложности: средний. Для других кодовых агентов есть отдельные инструкции. Официальный [сервер OpenAI Docs MCP](https://learn.chatgpt.com/learn/docs-mcp) предоставляет документацию разработчика только для чтения и не требует загружать данные курса.

**Используйте синтетическую лабораторную среду курса.** Не подключайте календарь, почту или рабочую систему. Для изучения состояний соединения достаточно прочитать документацию.

## Поймите границы

| Состояние | Что оно подтверждает | Чего оно не подтверждает |
|---|---|---|
| **Настроен** | Запись сервера существует | Доступность сервера |
| **Подключен** | Клиент связался с сервером | Наличие полезных инструментов |
| **Обнаружен** | Показан именованный инструмент | Успех его вызова |
| **Выполнен** | Вызов вернул содержимое | Правильность итоговой задачи |
| **Проверен** | Источник и результат отвечают на вопрос | Надежность будущих вызовов |

**Сам MCP не предоставляет разрешения учетной записи.** Важны хост клиента, сервер, аутентификация, область доступа учетной записи и локальные настройки подтверждения. [Спецификация MCP](https://modelcontextprotocol.io/specification/2026-07-28) определяет протокол, а пользовательский интерфейс зависит от продукта.

**Считайте ответ сервера исходным материалом.** Полученная страница не отменяет задачу и не разрешает записывать файлы. Описания инструментов также расходуют контекст, поэтому подключайте сервер только для нужного чтения и удаляйте его после упражнения.

## Подключите сервер только для чтения

**В Codex CLI** выполните команды в терминале. Первая добавляет общедоступный сервер документации, вторая показывает настроенные серверы.

```bash
codex mcp add openaiDeveloperDocs --url https://developers.openai.com/mcp
codex mcp list
```

**Ожидаемое подтверждение настройки:** в списке есть `openaiDeveloperDocs`. Это доказывает только регистрацию. Запустите новый сеанс Codex в распакованной папке лаборатории и просмотрите инструменты MCP командой `/mcp`. Используйте имена, показанные установленной версией.

**Запросите реальное чтение:**

```text
Используй сервер MCP документации разработчика OpenAI, чтобы найти актуальные указания AGENTS.md.
Верни заголовок и URL страницы-источника, два пункта для лаборатории и название использованного инструмента MCP.
Не изменяй файлы.
```
**Проверьте ответ.** Страница должна описывать `AGENTS.md` как инструкции репозитория и содержать точный URL источника. Откройте указанную страницу и проверьте ее тему. Ответ без вызова MCP в журнале диалога является обычным ответом, а не доказательством выполнения инструмента.

## Диагностируйте сбой

**Если `codex mcp list` показывает сервер, а `/mcp` не показывает инструментов,** регистрация прошла, но обнаружение не удалось. Перезапустите сеанс, проверьте активные серверы через `/mcp`, сохраненную конфигурацию через `codex mcp get openaiDeveloperDocs`, URL сервера и сетевой доступ. Не считайте одну запись подтверждением успешной настройки MCP.

**Если инструмент появился, но чтение завершилось ошибкой,** запишите ошибку и повторите попытку один раз после проверки соединения. При повторном сбое откройте указанную официальную страницу в браузере и отметьте упражнение MCP как незавершенное. Не выдумывайте результат вызова.

## Удалите подключение

**После чтения** удалите тестовый сервер из Codex CLI и убедитесь, что запись исчезла.

```bash
codex mcp remove openaiDeveloperDocs
codex mcp list
```

**Ожидаемое подтверждение удаления:** в новом списке нет `openaiDeveloperDocs`. Перед проверкой доступных инструментов перезапустите активный сеанс Codex. Удаление локальной записи не отзывает отдельное разрешение учетной записи, используемое другой службой.

## Используйте другой клиент

**Claude Code и OpenCode также поддерживают MCP.** Следуйте [руководству MCP для Claude Code](https://code.claude.com/docs/en/mcp) или [руководству OpenCode](https://opencode.ai/docs/mcp-servers/) для установленного выпуска. Фиксируйте те же пять состояний: настроен, подключен, обнаружен, выполнен, проверен. Схема конфигурации и разрешения агентов OpenCode различаются по версиям. Берите примеры из руководства для своей установки.

**Для варианта только с браузером** прочитайте [официальную страницу AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md) и заполните ту же форму проверки. Для обнаружения и выполнения инструмента укажите «не выполнялось». Этот вариант учит проверять источники, но не подтверждает работу MCP.

## Практика и проверка

**Ваш результат:** запись из пяти пунктов с именем сервера и инструмента, URL источника, наблюдаемым ответом и подтверждением удаления. Не включайте токены и идентификаторы учетных записей в снимки экрана и журналы.

**Критерий выполнения:** подключенный вариант пройден после реального чтения инструментом и последующего удаления настройки. Запасной вариант проходит проверку источника, если MCP помечен как невыполненный.

## Проверьте понимание

1. **Вопрос:** доказывает ли сохраненная запись MCP, что инструмент работал? **Ответ:** нет. Проверьте обнаружение, разрешения и один реальный запрос чтения.
2. **Вопрос:** какие дополнительные затраты контекста дает широкое подключение MCP? **Ответ:** описания и схемы инструментов занимают часть активного контекста.

## Устранение неполадок

- **Команда `codex` не найдена:** установите или обновите Codex CLI по связанной официальной инструкции.
- **Сервер есть в списке, инструмента нет:** проверьте состояние сеанса и диагностику сервера.
- **Вызов вернул нерелевантные данные:** уточните запрос и проверьте страницу-источник.
- **Удаление не помогло:** запустите новый сеанс и проверьте список активных серверов.
