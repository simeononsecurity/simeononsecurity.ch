[ਵਿਹਾਰਕ AI ਵਰਕਫਲੋ ਕੋਰਸ ਵੱਲ ਵਾਪਸ ਜਾਓ](/effective-ai-course-start/)

**ਜਦੋਂ ਕਿਸੇ ਕੰਮ ਲਈ ਮੁੜ ਵਰਤਣਯੋਗ ਟੂਲ ਜਾਂ ਪ੍ਰੋਜੈਕਟ ਤੋਂ ਬਾਹਰ ਦੀ ਨਵੀਂ ਜਾਣਕਾਰੀ ਲੋੜੀਂਦੀ ਹੋਵੇ, ਤਾਂ MCP ਸਰਵਰ ਵਰਤੋ।** Model Context Protocol, ਜਾਂ MCP, ਦੱਸਦਾ ਹੈ ਕਿ ਕਲਾਇੰਟ ਅਤੇ ਸਰਵਰ ਟੂਲਾਂ, ਸਰੋਤਾਂ ਅਤੇ ਪ੍ਰੌਂਪਟਾਂ ਬਾਰੇ ਜਾਣਕਾਰੀ ਕਿਵੇਂ ਸਾਂਝੀ ਕਰਦੇ ਹਨ। ਸਰਵਰ ਦੀ ਐਂਟਰੀ ਹੋਣ ਨਾਲ ਇਹ ਸਾਬਤ ਨਹੀਂ ਹੁੰਦਾ ਕਿ ਟੂਲ ਚੱਲਦਾ ਹੈ। ਇਹ ਪਾਠ ਇੱਕ ਪੜ੍ਹਨ-ਮਾਤਰ ਦਸਤਾਵੇਜ਼ੀ ਕਨੈਕਸ਼ਨ ਦੀ ਜਾਂਚ ਕਰਦਾ ਹੈ।

**ਸਿੱਖਣ ਦਾ ਨਤੀਜਾ:** ਤੁਸੀਂ ਸੈੱਟਅੱਪ ਅਤੇ ਅਸਲ MCP ਪੜ੍ਹਤ ਵਿਚਲਾ ਫ਼ਰਕ ਪਛਾਣੋਗੇ ਅਤੇ ਸੁਰੱਖਿਅਤ ਹਟਾਉਣਾ ਦਰਜ ਕਰੋਗੇ।

## ਮੁੱਖ ਗੱਲਾਂ

- **MCP ਹੋਸਟ:** AI ਐਪਲੀਕੇਸ਼ਨ ਜੋ ਵਰਤੋਂਕਾਰਾਂ, ਮਾਡਲਾਂ, ਇਜਾਜ਼ਤਾਂ ਅਤੇ ਕਲਾਇੰਟਾਂ ਦਾ ਤਾਲਮੇਲ ਕਰਦੀ ਹੈ।
- **MCP ਕਲਾਇੰਟ:** ਪ੍ਰੋਟੋਕੋਲ ਦਾ ਹਿੱਸਾ ਜੋ ਇੱਕ ਸਰਵਰ ਨਾਲ ਗੱਲ ਕਰਦਾ ਹੈ।
- **MCP ਸਰਵਰ:** ਪ੍ਰੋਗਰਾਮ ਜਾਂ ਦੂਰਲੀ ਸੇਵਾ ਜੋ ਟੂਲ, ਸਰੋਤ ਜਾਂ ਪ੍ਰੌਂਪਟ ਦਿੰਦੀ ਹੈ।
- **ਟੂਲ ਦੀ ਖੋਜ:** ਕਲਾਇੰਟ ਵਿੱਚ ਨਾਮ ਵਾਲੀ ਸਮਰੱਥਾ ਦਿਖਣ ਦਾ ਸਬੂਤ।
- **ਟੂਲ ਚਲਾਉਣਾ:** ਅਸਲ ਕਾਲ ਅਤੇ ਵਾਪਸ ਆਈ ਸਮੱਗਰੀ ਦਾ ਸਬੂਤ।
- **ਇਜਾਜ਼ਤ ਦੀ ਹੱਦ:** ਹੋਸਟ, ਸਰਵਰ, ਖਾਤੇ ਅਤੇ ਵਰਤੋਂਕਾਰ ਵੱਲੋਂ ਦਿੱਤੀ ਪਹੁੰਚ।

## ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ

**ਲੋੜਾਂ:** [ਸੰਦਰਭ ਅਤੇ ਕੰਮ ਸੌਂਪਣ ਦੀ ਕਸਰਤ](/articles/effective-ai-context-window-management/) ਅਤੇ ਇਸ ਕਦਮ-ਦਰ-ਕਦਮ ਉਦਾਹਰਨ ਲਈ ਮੌਜੂਦਾ Codex CLI ਇੰਸਟਾਲੇਸ਼ਨ। 35 ਮਿੰਟ ਰੱਖੋ। ਔਖਿਆਈ ਮੱਧਮ ਹੈ। ਹੋਰ ਕੋਡਿੰਗ ਏਜੰਟਾਂ ਲਈ ਵੱਖਰੇ ਸੈੱਟਅੱਪ ਗਾਈਡ ਹਨ। [ਅਧਿਕਾਰਤ OpenAI Docs MCP ਸਰਵਰ](https://learn.chatgpt.com/learn/docs-mcp) ਪੜ੍ਹਨ-ਮਾਤਰ ਡਿਵੈਲਪਰ ਦਸਤਾਵੇਜ਼ ਦਿੰਦਾ ਹੈ ਅਤੇ ਕੋਰਸ ਡਾਟਾ ਅੱਪਲੋਡ ਨਹੀਂ ਮੰਗਦਾ।

**ਕੋਰਸ ਦੀ ਨਕਲੀ ਲੈਬ ਵਰਤੋ।** ਇਸ ਅਭਿਆਸ ਲਈ ਕੈਲੰਡਰ, ਈਮੇਲ ਜਾਂ ਉਤਪਾਦਨ ਸਿਸਟਮ ਨਾ ਜੋੜੋ। ਕਨੈਕਸ਼ਨ ਦੀਆਂ ਹਾਲਤਾਂ ਸਿੱਖਣ ਲਈ ਦਸਤਾਵੇਜ਼ ਪੜ੍ਹਨਾ ਕਾਫ਼ੀ ਹੈ।

## ਹੱਦ ਸਮਝੋ

| ਹਾਲਤ | ਇਹ ਕੀ ਸਾਬਤ ਕਰਦੀ ਹੈ | ਇਹ ਕੀ ਸਾਬਤ ਨਹੀਂ ਕਰਦੀ |
|---|---|---|
| **ਸੈੱਟ ਕੀਤਾ** | ਸਰਵਰ ਦੀ ਐਂਟਰੀ ਮੌਜੂਦ ਹੈ | ਪਹੁੰਚਯੋਗਤਾ |
| **ਜੁੜਿਆ** | ਕਲਾਇੰਟ ਸਰਵਰ ਤੱਕ ਪਹੁੰਚਿਆ | ਲਾਭਦਾਇਕ ਟੂਲ ਮੌਜੂਦ ਹਨ |
| **ਖੋਜਿਆ** | ਨਾਮ ਵਾਲਾ ਟੂਲ ਦਿਖਦਾ ਹੈ | ਇਸਦੀ ਕਾਲ ਸਫ਼ਲ ਹੋਵੇਗੀ |
| **ਚਲਾਇਆ** | ਇੱਕ ਕਾਲ ਨੇ ਸਮੱਗਰੀ ਵਾਪਸ ਕੀਤੀ | ਅੰਤਿਮ ਕੰਮ ਸਹੀ ਹੈ |
| **ਤਸਦੀਕ ਕੀਤਾ** | ਸਰੋਤ ਅਤੇ ਨਤੀਜਾ ਸਵਾਲ ਦਾ ਜਵਾਬ ਦਿੰਦੇ ਹਨ | ਭਵਿੱਖ ਦੀਆਂ ਕਾਲਾਂ ਹਮੇਸ਼ਾ ਚੱਲਣਗੀਆਂ |

**MCP ਆਪਣੇ ਆਪ ਖਾਤੇ ਦੀ ਇਜਾਜ਼ਤ ਨਹੀਂ ਦਿੰਦਾ।** ਕਲਾਇੰਟ ਹੋਸਟ, ਸਰਵਰ, ਪ੍ਰਮਾਣਿਕਤਾ, ਖਾਤੇ ਦੀ ਹੱਦ ਅਤੇ ਸਥਾਨਕ ਮਨਜ਼ੂਰੀ ਸੈਟਿੰਗਾਂ ਵੀ ਮਹੱਤਵ ਰੱਖਦੀਆਂ ਹਨ। [MCP ਨਿਰਧਾਰਨ](https://modelcontextprotocol.io/specification/2026-07-28) ਪ੍ਰੋਟੋਕੋਲ ਦੱਸਦਾ ਹੈ, ਜਦਕਿ ਹਰ ਉਤਪਾਦ ਆਪਣਾ ਵਰਤੋਂਕਾਰ ਅਨੁਭਵ ਤੈਅ ਕਰਦਾ ਹੈ।

**ਸਰਵਰ ਦੇ ਨਤੀਜੇ ਨੂੰ ਸਰੋਤ ਸਮੱਗਰੀ ਮੰਨੋ।** ਪ੍ਰਾਪਤ ਪੰਨਾ ਤੁਹਾਡੇ ਕੰਮ ਦੀ ਥਾਂ ਨਹੀਂ ਲੈਂਦਾ ਅਤੇ ਫ਼ਾਈਲ ਲਿਖਣ ਦੀ ਇਜਾਜ਼ਤ ਨਹੀਂ ਦਿੰਦਾ। ਹਰ ਟੂਲ ਦਾ ਵੇਰਵਾ ਵੀ ਸੰਦਰਭ ਵਰਤਦਾ ਹੈ, ਇਸ ਲਈ ਇਸ ਪੜ੍ਹਤ ਲਈ ਲੋੜੀਂਦਾ ਸਰਵਰ ਹੀ ਜੋੜੋ ਅਤੇ ਅਭਿਆਸ ਤੋਂ ਬਾਅਦ ਹਟਾਓ।

## ਪੜ੍ਹਨ-ਮਾਤਰ ਸਰਵਰ ਜੋੜੋ

**Codex CLI ਵਿੱਚ** ਟਰਮੀਨਲ ਤੋਂ ਇਹ ਕਮਾਂਡਾਂ ਚਲਾਓ। ਪਹਿਲੀ ਜਨਤਕ ਦਸਤਾਵੇਜ਼ੀ ਸਰਵਰ ਜੋੜਦੀ ਹੈ। ਦੂਜੀ ਸੈੱਟ ਕੀਤੇ ਸਰਵਰ ਦਿਖਾਉਂਦੀ ਹੈ।

```bash
codex mcp add openaiDeveloperDocs --url https://developers.openai.com/mcp
codex mcp list
```

**ਉਮੀਦ ਕੀਤਾ ਸੈੱਟਅੱਪ ਸਬੂਤ:** ਸੂਚੀ ਵਿੱਚ `openaiDeveloperDocs` ਹੋਵੇ। ਇਹ ਸਿਰਫ਼ ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਸਾਬਤ ਕਰਦਾ ਹੈ। ਖੋਲ੍ਹੀ ਹੋਈ ਲੈਬ ਫੋਲਡਰ ਵਿੱਚ Codex ਦਾ ਨਵਾਂ ਸੈਸ਼ਨ ਸ਼ੁਰੂ ਕਰੋ ਅਤੇ `/mcp` ਨਾਲ MCP ਟੂਲਾਂ ਦੀ ਸੂਚੀ ਵੇਖੋ। ਆਪਣੇ ਇੰਸਟਾਲ ਕੀਤੇ ਵਰਜਨ ਵੱਲੋਂ ਦਿਖਾਏ ਨਾਮ ਵਰਤੋ।

**ਇੱਕ ਅਸਲ ਪੜ੍ਹਤ ਮੰਗੋ:**

```text
OpenAI ਡਿਵੈਲਪਰ ਦਸਤਾਵੇਜ਼ MCP ਸਰਵਰ ਵਰਤ ਕੇ ਮੌਜੂਦਾ AGENTS.md ਹਦਾਇਤਾਂ ਲੱਭੋ।
ਸਰੋਤ ਪੰਨੇ ਦਾ ਸਿਰਲੇਖ, URL ਅਤੇ ਇਸ ਲੈਬ ਲਈ ਦੋ ਲਾਭਦਾਇਕ ਗੱਲਾਂ ਦਿਓ। ਵਰਤਿਆ MCP ਟੂਲ ਦੱਸੋ।
ਫ਼ਾਈਲਾਂ ਨਾ ਸੋਧੋ।
```
**ਨਤੀਜਾ ਵੇਖੋ।** ਵਾਪਸ ਆਇਆ ਪੰਨਾ `AGENTS.md` ਨੂੰ ਰਿਪੋਜ਼ਟਰੀ ਦੀਆਂ ਹਦਾਇਤਾਂ ਵਜੋਂ ਸਮਝਾਏ ਅਤੇ ਸਹੀ ਸਰੋਤ URL ਦੇਵੇ। ਦਿੱਤਾ ਪੰਨਾ ਖੋਲ੍ਹ ਕੇ ਵਿਸ਼ਾ ਖੁਦ ਪੱਕਾ ਕਰੋ। ਗੱਲਬਾਤ ਦੇ ਰਿਕਾਰਡ ਵਿੱਚ MCP ਕਾਲ ਨਾ ਹੋਵੇ ਤਾਂ ਉਹ ਸਧਾਰਨ ਜਵਾਬ ਹੈ, ਟੂਲ ਚੱਲਣ ਦਾ ਸਬੂਤ ਨਹੀਂ।

## ਇੱਕ ਨਾਕਾਮੀ ਦੀ ਜਾਂਚ ਕਰੋ

**ਜੇ `codex mcp list` ਸਰਵਰ ਦਿਖਾਏ ਪਰ `/mcp` ਟੂਲ ਨਾ ਦਿਖਾਏ,** ਤਾਂ ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਸਫ਼ਲ ਹੋਈ ਪਰ ਖੋਜ ਨਾਕਾਮ ਰਹੀ। ਸੈਸ਼ਨ ਮੁੜ ਸ਼ੁਰੂ ਕਰੋ, `/mcp` ਨਾਲ ਸਰਗਰਮ ਸਰਵਰ ਅਤੇ `codex mcp get openaiDeveloperDocs` ਨਾਲ ਸੰਭਾਲੀ ਸੈਟਿੰਗ ਵੇਖੋ, ਫਿਰ ਸਰਵਰ URL ਤੇ ਨੈੱਟਵਰਕ ਪਹੁੰਚ ਜਾਂਚੋ। ਸਿਰਫ਼ ਸੈਟਿੰਗ ਐਂਟਰੀ ਦੇ ਆਧਾਰ ਤੇ MCP ਦੀ ਸਫ਼ਲਤਾ ਨਾ ਦੱਸੋ।

**ਜੇ ਟੂਲ ਦਿਖੇ ਪਰ ਪੜ੍ਹਤ ਨਾਕਾਮ ਹੋਵੇ,** ਗ਼ਲਤੀ ਦਰਜ ਕਰੋ ਅਤੇ ਕਨੈਕਸ਼ਨ ਜਾਂਚਣ ਤੋਂ ਬਾਅਦ ਇੱਕ ਵਾਰ ਫਿਰ ਕੋਸ਼ਿਸ਼ ਕਰੋ। ਜੇ ਉਹੀ ਕਾਲ ਮੁੜ ਨਾਕਾਮ ਹੋਵੇ, ਦਿੱਤਾ ਅਧਿਕਾਰਤ ਪੰਨਾ ਬ੍ਰਾਊਜ਼ਰ ਵਿੱਚ ਖੋਲ੍ਹ ਕੇ ਵਿਕਲਪੀ ਸਰੋਤ ਵਰਤੋ ਅਤੇ MCP ਅਭਿਆਸ ਅਧੂਰਾ ਦਰਜ ਕਰੋ। ਟੂਲ ਦਾ ਨਤੀਜਾ ਨਾ ਘੜੋ।

## ਕਨੈਕਸ਼ਨ ਹਟਾਓ

**ਪੜ੍ਹਨ ਤੋਂ ਬਾਅਦ** Codex CLI ਵਿੱਚੋਂ ਅਭਿਆਸ ਸਰਵਰ ਹਟਾਓ ਅਤੇ ਪੱਕਾ ਕਰੋ ਕਿ ਐਂਟਰੀ ਗਾਇਬ ਹੈ।

```bash
codex mcp remove openaiDeveloperDocs
codex mcp list
```

**ਉਮੀਦ ਕੀਤਾ ਹਟਾਉਣ ਦਾ ਸਬੂਤ:** ਨਵੀਂ ਸੂਚੀ ਵਿੱਚ `openaiDeveloperDocs` ਨਾ ਹੋਵੇ। ਸਰਗਰਮ Codex ਸੈਸ਼ਨ ਦੇ ਉਪਲਬਧ ਟੂਲ ਬਦਲੇ ਕਿ ਨਹੀਂ, ਇਹ ਵੇਖਣ ਤੋਂ ਪਹਿਲਾਂ ਸੈਸ਼ਨ ਮੁੜ ਸ਼ੁਰੂ ਕਰੋ। ਸਥਾਨਕ ਪਰਿਭਾਸ਼ਾ ਹਟਾਉਣ ਨਾਲ ਕਿਸੇ ਹੋਰ ਸੇਵਾ ਦੀ ਵੱਖਰੀ ਖਾਤਾ ਮਨਜ਼ੂਰੀ ਵਾਪਸ ਨਹੀਂ ਹੁੰਦੀ।

## ਹੋਰ ਕਲਾਇੰਟ ਵਰਤੋ

**Claude Code ਅਤੇ OpenCode ਵੀ MCP ਸਹਾਇਕ ਹਨ।** ਆਪਣੇ ਇੰਸਟਾਲ ਵਰਜਨ ਲਈ [Claude Code MCP ਗਾਈਡ](https://code.claude.com/docs/en/mcp) ਜਾਂ [OpenCode MCP ਗਾਈਡ](https://opencode.ai/docs/mcp-servers/) ਦੀ ਪਾਲਣਾ ਕਰੋ। ਉਹੀ ਪੰਜ ਹਾਲਤਾਂ ਦਰਜ ਕਰੋ: ਸੈੱਟ ਕੀਤਾ, ਜੁੜਿਆ, ਖੋਜਿਆ, ਚਲਾਇਆ ਅਤੇ ਤਸਦੀਕ ਕੀਤਾ। OpenCode ਦੀ ਸੈਟਿੰਗ ਬਣਤਰ ਅਤੇ ਏਜੰਟ ਇਜਾਜ਼ਤਾਂ ਵਰਜਨ ਅਨੁਸਾਰ ਬਦਲਦੀਆਂ ਹਨ, ਇਸ ਲਈ ਆਪਣੇ ਵਰਜਨ ਵਾਲੀ ਗਾਈਡ ਤੋਂ ਉਦਾਹਰਨਾਂ ਲਵੋ।

**ਸਿਰਫ਼ ਬ੍ਰਾਊਜ਼ਰ ਵਾਲੇ ਰਸਤੇ ਲਈ,** [ਅਧਿਕਾਰਤ AGENTS.md ਪੰਨਾ](https://learn.chatgpt.com/docs/agent-configuration/agents-md) ਪੜ੍ਹੋ ਅਤੇ ਉਹੀ ਤਸਦੀਕ ਰਿਕਾਰਡ ਭਰੋ। ਟੂਲ ਖੋਜ ਅਤੇ ਚਲਾਉਣ ਨੂੰ “ਨਹੀਂ ਕੀਤਾ” ਲਿਖੋ। ਇਹ ਰਸਤਾ ਸਰੋਤ ਜਾਂਚ ਸਿਖਾਉਂਦਾ ਹੈ, ਪਰ MCP ਚੱਲਣ ਦੀ ਪੁਸ਼ਟੀ ਨਹੀਂ ਕਰਦਾ।

## ਅਭਿਆਸ ਅਤੇ ਜਾਂਚ

**ਤੁਹਾਡਾ ਨਤੀਜਾ:** ਪੰਜ ਕਤਾਰਾਂ ਦਾ ਕਨੈਕਸ਼ਨ ਰਿਕਾਰਡ: ਸਰਵਰ ਨਾਮ, ਟੂਲ ਨਾਮ, ਸਰੋਤ URL, ਵੇਖਿਆ ਨਤੀਜਾ ਅਤੇ ਹਟਾਉਣ ਦਾ ਸਬੂਤ। ਸਕ੍ਰੀਨਸ਼ਾਟਾਂ ਅਤੇ ਲੌਗਾਂ ਵਿੱਚ ਟੋਕਨ ਜਾਂ ਖਾਤਾ ਪਛਾਣ ਨਾ ਰੱਖੋ।

**ਪੂਰਾ ਹੋਣ ਦੀ ਜਾਂਚ:** ਜੁੜਿਆ ਰਸਤਾ ਤਾਂ ਹੀ ਪਾਸ ਹੈ ਜਦੋਂ ਟੂਲ ਨੇ ਅਸਲ ਪੜ੍ਹਤ ਕੀਤੀ ਅਤੇ ਬਾਅਦ ਵਿੱਚ ਸੈਟਿੰਗ ਹਟਾਈ ਗਈ। ਵਿਕਲਪੀ ਰਸਤੇ ਵਿੱਚ ਸਰੋਤ ਜਾਂਚ ਪੂਰੀ ਹੋਵੇ ਅਤੇ MCP ਨੂੰ ਨਾ ਚਲਾਇਆ ਦਰਜ ਕੀਤਾ ਹੋਵੇ।

## ਆਪਣੀ ਸਮਝ ਜਾਂਚੋ

1. **ਸਵਾਲ:** ਕੀ ਸੰਭਾਲੀ MCP ਸਰਵਰ ਐਂਟਰੀ ਸਾਬਤ ਕਰਦੀ ਹੈ ਕਿ ਟੂਲ ਚੱਲਿਆ? **ਜਵਾਬ:** ਨਹੀਂ। ਖੋਜ, ਇਜਾਜ਼ਤ ਅਤੇ ਅਸਲ ਪੜ੍ਹਤ ਜਾਂਚੋ।
2. **ਸਵਾਲ:** ਵਿਸ਼ਾਲ MCP ਕਨੈਕਸ਼ਨ ਦਾ ਵਾਧੂ ਸੰਦਰਭ ਖ਼ਰਚ ਕੀ ਹੈ? **ਜਵਾਬ:** ਟੂਲ ਵੇਰਵੇ ਅਤੇ ਸਕੀਮਾ ਸਰਗਰਮ ਸੰਦਰਭ ਦਾ ਕੁਝ ਹਿੱਸਾ ਵਰਤਦੇ ਹਨ।

## ਸਮੱਸਿਆ ਹੱਲ

- **`codex` ਕਮਾਂਡ ਅਣਜਾਣ:** ਲਿੰਕ ਕੀਤੀ ਅਧਿਕਾਰਤ ਗਾਈਡ ਤੋਂ Codex CLI ਇੰਸਟਾਲ ਜਾਂ ਅੱਪਡੇਟ ਕਰੋ।
- **ਸਰਵਰ ਸੂਚੀ ਵਿੱਚ, ਟੂਲ ਨਹੀਂ:** ਸੈਸ਼ਨ ਹਾਲਤ ਅਤੇ ਸਰਵਰ ਜਾਂਚ ਵੇਖੋ।
- **ਟੂਲ ਨੇ ਬੇਸਬੰਧ ਸਮੱਗਰੀ ਦਿੱਤੀ:** ਸਵਾਲ ਸੀਮਿਤ ਕਰੋ ਅਤੇ ਸਰੋਤ ਪੰਨਾ ਜਾਂਚੋ।
- **ਹਟਾਉਣਾ ਅਸਰਦਾਰ ਨਹੀਂ ਲੱਗਦਾ:** ਨਵਾਂ ਸੈਸ਼ਨ ਸ਼ੁਰੂ ਕਰੋ ਅਤੇ ਸਰਗਰਮ ਸਰਵਰ ਸੂਚੀ ਵੇਖੋ।
