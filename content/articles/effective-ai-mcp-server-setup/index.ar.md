[العودة إلى دورة سير العمل العملي للذكاء الاصطناعي](/effective-ai-course-start/)

**استخدم خادم MCP عندما تحتاج المهمة إلى أداة قابلة لإعادة الاستخدام أو معلومات حديثة خارج المشروع.** يحدد Model Context Protocol، أو MCP، كيفية تبادل العميل والخادم معلومات الأدوات والموارد والمطالبات. وجود إدخال للخادم لا يثبت أن الأداة تعمل. يختبر هذا الدرس اتصالًا واحدًا بتوثيق للقراءة فقط.

**هدف التعلم:** ستميّز بين الإعداد وقراءة MCP فعلية، وستوثق الإزالة الآمنة.

## النقاط الأساسية

- **مضيف MCP:** تطبيق ذكاء اصطناعي ينسق المستخدمين والنماذج والأذونات والعملاء.
- **عميل MCP:** مكوّن البروتوكول الذي يتواصل مع خادم واحد.
- **خادم MCP:** برنامج أو خدمة بعيدة توفر أدوات أو موارد أو مطالبات.
- **اكتشاف الأداة:** دليل على ظهور قدرة مسماة في العميل.
- **تنفيذ الأداة:** دليل على استدعاء فعلي ومحتوى مسترجع.
- **نطاق الأذونات:** الوصول الذي يمنحه المضيف والخادم والحساب والمستخدم.

## قبل البدء

**المتطلبات:** [تدريب السياق وتسليم العمل](/articles/effective-ai-context-window-management/) وتثبيت حديث لـ Codex CLI للمسار المشروح. خصص 35 دقيقة. المستوى متوسط. تتوفر أدلة إعداد منفصلة لوكلاء البرمجة الآخرين. يوفر [خادم OpenAI Docs MCP الرسمي](https://learn.chatgpt.com/learn/docs-mcp) توثيقًا للمطورين للقراءة فقط ولا يحتاج إلى رفع بيانات الدورة.

**استخدم مختبر الدورة الاصطناعي.** لا تربط تقويمًا أو بريدًا أو نظام إنتاج بهذا التمرين. تكفي قراءة التوثيق للتعرف على حالات الاتصال.

## افهم الحدود

| الحالة | ما تثبته | ما لا تثبته |
|---|---|---|
| **مُعدّ** | وجود إدخال للخادم | إمكانية الوصول |
| **متصل** | وصول العميل إلى الخادم | توفر أدوات مفيدة |
| **مكتشف** | ظهور أداة مسماة | نجاح استدعائها |
| **منفذ** | إرجاع استدعاء لمحتوى | صحة المهمة النهائية |
| **متحقق منه** | إجابة المصدر والنتيجة عن السؤال | نجاح الاستدعاءات المستقبلية دائمًا |

**لا يمنح MCP إذنًا للحساب من تلقاء نفسه.** تهم أيضًا واجهة العميل والخادم والمصادقة ونطاق الحساب وإعدادات الموافقة المحلية. تحدد [مواصفة MCP](https://modelcontextprotocol.io/specification/2026-07-28) البروتوكول، بينما يتحكم كل منتج في تجربة المستخدم.

**تعامل مع مخرجات الخادم بوصفها مصدرًا.** لا تستبدل الصفحة المسترجعة مهمتك ولا تمنح إذنًا لكتابة الملفات. تستهلك تعريفات الأدوات مساحة من السياق أيضًا، لذلك صِل الخادم اللازم لهذه القراءة فقط، ثم أزله بعد التمرين.

## صِل خادمًا للقراءة فقط

**في Codex CLI،** نفذ هذه الأوامر في طرفية. يضيف الأول خادم التوثيق العام، ويعرض الثاني الخوادم المعدة.

```bash
codex mcp add openaiDeveloperDocs --url https://developers.openai.com/mcp
codex mcp list
```

**دليل الإعداد المتوقع:** تتضمن القائمة `openaiDeveloperDocs`. هذا يثبت التسجيل فقط. ابدأ جلسة Codex جديدة في مجلد المختبر بعد استخراجه، وافحص أدوات MCP باستخدام `/mcp`. استخدم أسماء الأدوات التي تعرضها نسختك المثبتة.

**اطلب قراءة حقيقية واحدة:**

```text
استخدم خادم MCP لوثائق مطوري OpenAI للعثور على إرشادات AGENTS.md الحالية.
أعد عنوان صفحة المصدر ورابطها ونقطتين تهمان هذا المختبر، واذكر أداة MCP المستخدمة.
لا تعدل أي ملفات.
```
**افحص النتيجة.** ينبغي أن تصف الصفحة `AGENTS.md` على أنها إرشادات للمستودع وأن تعرض رابط المصدر الدقيق. افتح الصفحة المشار إليها وتحقق من موضوعها. الإجابة التي لا تتضمن استدعاء MCP في سجل المحادثة إجابة عادية، وليست دليلًا على تنفيذ الأداة.

## شخّص عطلًا واحدًا

**إذا أظهر `codex mcp list` الخادم ولم يعرض `/mcp` أي أدوات،** فقد نجح التسجيل وفشل الاكتشاف. أعد تشغيل الجلسة، وافحص الخوادم النشطة عبر `/mcp` والإعداد المحفوظ عبر `codex mcp get openaiDeveloperDocs`، ثم تحقق من رابط الخادم واتصال الشبكة. لا تعتبر إدخال الإعداد وحده دليلًا على نجاح MCP.

**إذا ظهرت أداة وفشلت القراءة،** سجل الخطأ وأعد المحاولة مرة بعد فحص الاتصال. إذا فشل الاستدعاء نفسه، استخدم الصفحة الرسمية المشار إليها في المتصفح مصدرًا بديلًا، وسجل أن تمرين MCP غير مكتمل. لا تختلق نتيجة أداة.

## أزل الاتصال

**بعد القراءة،** أزل خادم التدريب من Codex CLI وتأكد من اختفاء الإدخال.

```bash
codex mcp remove openaiDeveloperDocs
codex mcp list
```

**دليل الإزالة المتوقع:** لا يظهر `openaiDeveloperDocs` في القائمة الجديدة. أعد تشغيل أي جلسة Codex نشطة قبل فحص تغيّر الأدوات المتاحة فيها. لا يؤدي حذف تعريف محلي إلى إلغاء إذن حساب منفصل يستخدمه جهاز آخر.

## استخدم عميلًا آخر

**يدعم Claude Code وOpenCode بروتوكول MCP أيضًا.** اتبع [دليل MCP لـ Claude Code](https://code.claude.com/docs/en/mcp) أو [دليل MCP لـ OpenCode](https://opencode.ai/docs/mcp-servers/) المطابق للإصدار المثبت. سجل الحالات الخمس نفسها: مُعدّ، متصل، مكتشف، منفذ، ومتحقق منه. يختلف مخطط إعداد OpenCode وأذونات الوكلاء بين الإصدارات، لذا خذ الأمثلة من الدليل المطابق لتثبيتك.

**للمسار الذي يستخدم المتصفح فقط،** اقرأ [صفحة AGENTS.md الرسمية](https://learn.chatgpt.com/docs/agent-configuration/agents-md) وأكمل سجل التحقق نفسه. ضع علامة «لم ينفذ» على اكتشاف الأدوات وتنفيذها. يعلمك هذا المسار فحص المصادر، لكنه لا يثبت عمل MCP.

## تدرب وتحقق

**المخرج المطلوب:** سجل اتصال من خمسة أسطر يتضمن اسم الخادم واسم الأداة ورابط المصدر والنتيجة الملحوظة ودليل الإزالة. أبق الرموز ومعرفات الحساب خارج لقطات الشاشة والسجلات.

**شرط الإكمال:** ينجح المسار المتصل بعد قراءة حقيقية بواسطة أداة ثم إزالة الإعداد. ينجح المسار البديل في تمرين فحص المصدر مع تسجيل MCP على أنه لم ينفذ.

## اختبر فهمك

1. **السؤال:** هل يثبت إدخال MCP محفوظ أن الأداة عملت؟ **الإجابة:** لا. تحقق من الاكتشاف والإذن وقراءة فعلية واحدة.
2. **السؤال:** ما كلفة السياق الإضافية لاتصال MCP واسع؟ **الإجابة:** تستهلك أوصاف الأدوات ومخططاتها جزءًا من السياق النشط.

## استكشاف الأخطاء وإصلاحها

- **الأمر `codex` غير معروف:** ثبت Codex CLI أو حدثه من الدليل الرسمي المرتبط.
- **الخادم ظاهر ولا توجد أداة:** افحص حالة الجلسة وتشخيص الخادم.
- **أعاد استدعاء الأداة محتوى غير ذي صلة:** ضيّق الاستعلام وتحقق من صفحة المصدر.
- **يبدو أن الإزالة لم تنجح:** ابدأ جلسة جديدة وافحص قائمة الخوادم النشطة.
