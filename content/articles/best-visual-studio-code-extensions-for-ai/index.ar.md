يعتمد المطورون في مجال الذكاء الاصطناعي على أدوات قوية لتبسيط العمل وزيادة الإنتاجية. Visual Studio Code (VS Code) إحدى هذه الأدوات. فهو محرر أكواد خفيف يضم ميزات كثيرة. وتوسّع الإضافات إمكاناته لتطوير الذكاء الاصطناعي. نستعرض في هذا المقال بعض **أفضل إضافات Visual Studio Code للذكاء الاصطناعي**.

______

## مقدمة إلى Visual Studio Code

قبل استعراض إضافات الذكاء الاصطناعي، إليك نبذة عن Visual Studio Code لمن لم يستخدم هذا المحرر متعدد الاستخدامات من قبل.

Visual Studio Code، المعروف أيضًا باسم VS Code، محرر أكواد مجاني ومفتوح المصدر طورته Microsoft. يمكن تخصيصه بدرجة كبيرة، ويدعم لغات برمجة كثيرة، لذلك يحظى بشعبية بين المطورين. يوفر VS Code بيئة خفيفة وسريعة من دون التضحية بالميزات. وهو مناسب لمهام تطوير متعددة، منها تطوير الذكاء الاصطناعي.

## إضافات الذكاء الاصطناعي لـ Visual Studio Code

### 1. Python

تُستخدم Python على نطاق واسع في مجال الذكاء الاصطناعي. لذلك تُعد **إضافة Python لـ Visual Studio Code** أداة مهمة لمطوري الذكاء الاصطناعي. توفر إكمال الأكواد وفحصها وتصحيحها ومحطة طرفية مدمجة. تساعد هذه الميزات على تبسيط التطوير باستخدام Python. كما تعزز إمكانات IntelliSense الإنتاجية وتساعد على اكتشاف الأخطاء مبكرًا.

نزّل إضافة Python من السوق الرسمي لـ Visual Studio Code: [إضافة Python](https://marketplace.visualstudio.com/items?itemName=ms-python.python).

### 2. Jupyter

أصبحت دفاتر Jupyter خيارًا شائعًا لتجارب الذكاء الاصطناعي وبناء النماذج الأولية. تنقل **إضافة Jupyter لـ Visual Studio Code** الدفاتر إلى محرر الأكواد. يمكنك إنشاء دفاتر Jupyter وتحريرها وتشغيلها داخل VS Code. توفر الخلايا التفاعلية والمخرجات الغنية وتنفيذ الأكواد بيئة مناسبة لاستكشاف البيانات وتحليلها.

نزّل إضافة Jupyter من السوق الرسمي لـ Visual Studio Code: [إضافة Jupyter](https://marketplace.visualstudio.com/items?itemName=ms-toolsai.jupyter).

### 3. Git

تُعد إدارة الإصدارات جزءًا أساسيًا من تطوير البرامج، بما في ذلك مشاريع الذكاء الاصطناعي. تسهّل **إضافة Git لـ Visual Studio Code** إدارة قاعدة الأكواد والتعاون مع الآخرين وتتبع التغييرات. توفر واجهة مرئية لأوامر Git، ما يتيح لك تجهيز التغييرات واعتمادها ودفعها وسحبها من دون مغادرة المحرر. كما توفر عرض الفروق وإدارة الفروع وحل التعارضات. تفيد هذه الميزات مطوري الذكاء الاصطناعي الذين يعملون ضمن فرق.

نزّل إضافة Git من السوق الرسمي لـ Visual Studio Code: [إضافة Git](https://marketplace.visualstudio.com/items?itemName=GitExtensionsApp.v341).

### 4. IntelliCode

تضيف **إضافة IntelliCode لـ Visual Studio Code**، التي طورتها Microsoft، اقتراحات أكواد مدعومة بالذكاء الاصطناعي إلى المحرر. تستخدم نماذج تعلم آلي دُرّبت على قدر كبير من الأكواد مفتوحة المصدر لاقتراح إكمالات تناسب السياق. تتوقع IntelliCode عناصر الأكواد التالية الأكثر احتمالًا. وهذا يوفر الوقت ويزيد الإنتاجية ويقلل الأخطاء.

نزّل إضافة IntelliCode من السوق الرسمي لـ Visual Studio Code: [إضافة IntelliCode](https://marketplace.visualstudio.com/items?itemName=VisualStudioExptTeam.vscodeintellicode).

يُستخدم Docker كثيرًا لإنشاء الحاويات في سير عمل الذكاء الاصطناعي. تسهّل **إضافة Docker لـ Visual Studio Code** إدارة حاويات Docker وصورها داخل المحرر. وتوفر واجهة رسومية لإنشاء الحاويات وتشغيلها وتصحيحها. بذلك يستطيع المطورون التركيز على نماذج الذكاء الاصطناعي بدلًا من التعامل مع أوامر Docker المعقدة.
