W obszarze sztucznej inteligencji (AI) programiści często korzystają z zaawansowanych narzędzi, które upraszczają pracę i zwiększają produktywność. Jednym z nich jest Visual Studio Code (VS Code), lekki edytor kodu z wieloma funkcjami. VS Code zapewnia solidną podstawę do tworzenia rozwiązań AI, a rozszerzenia pozwalają rozbudować jego możliwości. W tym artykule omawiamy **najlepsze rozszerzenia Visual Studio Code do AI**.

______

## Visual Studio Code w skrócie

Zanim przejdziemy do rozszerzeń AI, krótko przedstawimy Visual Studio Code osobom, które dopiero poznają ten wszechstronny edytor.

Visual Studio Code, często nazywany VS Code, to bezpłatny edytor kodu open source opracowany przez Microsoft. Można go szeroko dostosowywać i obsługuje wiele języków programowania, dlatego jest popularny wśród programistów. VS Code działa szybko i lekko, a jednocześnie oferuje wiele funkcji. Sprawdza się przy różnych zadaniach programistycznych, w tym przy AI.

______

## Rozszerzenia AI do Visual Studio Code

### 1. Python

Python jest powszechnie używany w AI. **Rozszerzenie Python do Visual Studio Code** to ważne narzędzie dla osób tworzących rozwiązania AI. Oferuje uzupełnianie kodu, lintowanie, debugowanie i zintegrowany terminal. Ułatwia dzięki temu programowanie w Pythonie. Funkcje IntelliSense zwiększają produktywność i pomagają wcześnie wykrywać błędy.

Rozszerzenie Python pobierzesz z oficjalnego marketplace Visual Studio Code: [rozszerzenie Python](https://marketplace.visualstudio.com/items?itemName=ms-python.python).

### 2. Jupyter

Notatniki Jupyter są popularne przy eksperymentach i prototypach AI. **Rozszerzenie Jupyter do Visual Studio Code** przenosi obsługę notatników bezpośrednio do edytora. Pozwala tworzyć, edytować i uruchamiać notatniki Jupyter w VS Code. Interaktywne komórki, rozbudowane wyniki i wykonywanie kodu ułatwiają eksplorację i analizę danych.

Rozszerzenie Jupyter pobierzesz z oficjalnego marketplace Visual Studio Code: [rozszerzenie Jupyter](https://marketplace.visualstudio.com/items?itemName=ms-toolsai.jupyter).

### 3. Git

Kontrola wersji jest ważną częścią tworzenia oprogramowania, także projektów AI. **Rozszerzenie Git do Visual Studio Code** ułatwia zarządzanie bazą kodu, współpracę i śledzenie zmian. Udostępnia wizualny interfejs poleceń Git. Możesz w nim przygotowywać zmiany, zatwierdzać je, wysyłać i pobierać kod bez opuszczania edytora. Rozszerzenie oferuje też podgląd różnic, zarządzanie gałęziami i rozwiązywanie konfliktów. To przydatne funkcje dla zespołów pracujących nad AI.

Rozszerzenie Git pobierzesz z oficjalnego marketplace Visual Studio Code: [rozszerzenie Git](https://marketplace.visualstudio.com/items?itemName=GitExtensionsApp.v341).

### 4. IntelliCode

Opracowane przez Microsoft **rozszerzenie IntelliCode do Visual Studio Code** dodaje w edytorze sugestie kodu wspierane przez AI. Wykorzystuje modele uczenia maszynowego wytrenowane na dużej ilości kodu open source, aby dobierać uzupełnienia do kontekstu. IntelliCode przewiduje najbardziej prawdopodobne kolejne elementy kodu. Oszczędza czas, zwiększa produktywność i pomaga ograniczać błędy.

Rozszerzenie IntelliCode pobierzesz z oficjalnego marketplace Visual Studio Code: [rozszerzenie IntelliCode](https://marketplace.visualstudio.com/items?itemName=VisualStudioExptTeam.vscodeintellicode).

### 5. Docker

Docker jest często używany do konteneryzacji przepływów pracy AI. **Rozszerzenie Docker do Visual Studio Code** upraszcza zarządzanie kontenerami i obrazami w edytorze. Udostępnia interfejs graficzny do budowania, uruchamiania i debugowania kontenerów. Dzięki temu programiści mogą skupić się na modelach AI, zamiast obsługiwać złożone polecenia Dockera.

Rozszerzenie Docker pobierzesz z oficjalnego marketplace Visual Studio Code: [rozszerzenie Docker](https://marketplace.visualstudio.com/items?itemName=ms-azuretools.vscode-docker).

### 6. TensorFlow

**Rozszerzenie TensorFlow do Visual Studio Code** obsługuje jedną z najpopularniejszych bibliotek AI. Oferuje fragmenty kodu, podświetlanie składni i dedykowany debugger TensorFlow. Ułatwia pracę nad projektami TensorFlow w edytorze.

Dowiedz się, jak zainstalować TensorFlow do Visual Studio Code: [rozszerzenie TensorFlow](https://reason.town/how-to-install-tensorflow-in-visual-studio-code/#:~:text=First%2C%20you%20will%20need%20to%20download%20TensorFlow%20from,type%20%E2%80%9CTensorFlow%E2%80%9D%20and%20install%20the%20extension%20that%20appears.).

### 7. Kite

**Rozszerzenie Kite do Visual Studio Code** wykorzystuje AI, aby podczas pisania podpowiadać kod i wyświetlać dokumentację. Obsługuje wiele języków programowania, w tym Python i JavaScript. Przydaje się programistom AI, którzy chcą otrzymywać szybsze i dokładniejsze sugestie.

Rozszerzenie Kite pobierzesz tutaj: [rozszerzenie Kite](https://www.kite.com/blog/press/vscode/).

### 8. Azure Machine Learning

**Rozszerzenie Azure Machine Learning do Visual Studio Code** integruje się z usługą Azure Machine Learning. Pozwala zarządzać eksperymentami uczenia maszynowego i modelami oraz monitorować je bezpośrednio w edytorze. Zapewnia dostęp do magazynów danych, zestawów danych i śledzenia eksperymentów, co wspiera wydajną pracę nad AI.

Rozszerzenie Azure Machine Learning pobierzesz z oficjalnego marketplace Visual Studio Code: [rozszerzenie Azure Machine Learning](https://marketplace.visualstudio.com/items?itemName=ms-toolsai.vscode-ai).

### 9. Data Preview

**Rozszerzenie Data Preview do Visual Studio Code** pozwala przeglądać i eksplorować pliki danych bezpośrednio w edytorze. Obsługuje różne formaty, w tym CSV i JSON. Dzięki temu możesz analizować dane bez opuszczania środowiska programistycznego.

Rozszerzenie Data Preview pobierzesz z oficjalnego marketplace Visual Studio Code: [rozszerzenie Data Preview](https://marketplace.visualstudio.com/items?itemName=RandomFractalsInc.vscode-data-preview).

Te rozszerzenia uzupełniają funkcje Visual Studio Code i usprawniają pracę nad AI. Dzięki nim edytor lepiej wspiera przepływy pracy związane ze sztuczną inteligencją.
