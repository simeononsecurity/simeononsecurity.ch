## ভূমিকা

Microsoft-এর তৈরি Windows Defender হলো Windows অপারেটিং সিস্টেমের **সমন্বিত অ্যান্টিভাইরাস ও নিরাপত্তা সমাধান**। এটি নিরাপত্তা সেটিংস পরিচালনার জন্য সহজ ইন্টারফেস দেয়। কমান্ড লাইনে নিয়ন্ত্রণ পছন্দ করেন এমন অভিজ্ঞ ব্যবহারকারীরা এর PowerShell কমান্ড ব্যবহার করতে পারেন। এই নিবন্ধে **Windows Defender PowerShell কমান্ড** এবং Windows পরিবেশে নিয়ন্ত্রণ ও সিস্টেম নিরাপত্তা বাড়াতে সেগুলোর ব্যবহার দেখানো হয়েছে।

## Windows Defender PowerShell কমান্ডের সক্ষমতা

Windows Defender PowerShell কমান্ড কমান্ড-লাইন ইন্টারফেস থেকে **উন্নত নিরাপত্তা কার্যক্রম** চালাতে সাহায্য করে। ম্যালওয়্যার স্ক্যানের মতো সাধারণ কাজ থেকে উন্নত নিরাপত্তা সেটিংস কনফিগার করা পর্যন্ত এর নানা ব্যবহার রয়েছে। PowerShell দিয়ে নিরাপত্তা কার্যক্রম স্বয়ংক্রিয় করা, কাস্টম স্ক্রিপ্ট তৈরি করা এবং বিদ্যমান কাজের ধারায় Windows Defender যুক্ত করা যায়।

## Windows Defender PowerShell শুরু করা

Windows Defender PowerShell কমান্ড ব্যবহারের জন্য **প্রশাসনিক অধিকারসহ PowerShell সেশন** খুলুন। শুরু করতে:

1. `Win + X` চাপুন এবং মেনু থেকে **Windows PowerShell (Admin)** (প্রশাসক হিসেবে) বেছে নিন।
2. অনুমতি চাইলে, অ্যাপটিকে ডিভাইসে পরিবর্তন করার অনুমতি দিতে **Yes** (হ্যাঁ) ক্লিক করুন।

PowerShell সেশন খোলার পর Windows Defender PowerShell কমান্ড ব্যবহার শুরু করুন।

## প্রচলিত Windows Defender PowerShell কমান্ড

### 1. **Get-MpComputerStatus**: Windows Defender-এর অবস্থা পরীক্ষা

`Get-MpComputerStatus` কমান্ডটি আপনার সিস্টেমে Windows Defender-এর বর্তমান অবস্থা দেখায়। এতে **অ্যান্টিভাইরাস ইঞ্জিনের সংস্করণ**, শেষ স্ক্যানের সময় এবং রিয়েল-টাইম সুরক্ষার অবস্থা থাকে। কমান্ডটি চালিয়ে Windows Defender-এর সার্বিক অবস্থা দ্রুত যাচাই করুন।

Windows Defender-এর অবস্থা দেখতে প্রশাসনিক অধিকারসহ PowerShell সেশন খুলে এই কমান্ড চালান:

```powershell
Get-MpComputerStatus
```

কমান্ডটি যেমন তথ্য দেখাবে:

- **AntivirusEngineVersion**: Windows Defender-এর অ্যান্টিভাইরাস ইঞ্জিনের সংস্করণ নম্বর।
- **LastFullScanTime**: Windows Defender-এর শেষ পূর্ণ স্ক্যানের তারিখ ও সময়।
- **LastQuickScanTime**: Windows Defender-এর শেষ দ্রুত স্ক্যানের তারিখ ও সময়।
- **RealTimeProtectionEnabled**: রিয়েল-টাইম সুরক্ষা চালু না বন্ধ, তা নির্দেশ করে।

`Get-MpComputerStatus` দিয়ে নিয়মিত অবস্থা পর্যবেক্ষণ করলে **সম্ভাব্য হুমকি**র বিরুদ্ধে সিস্টেমের সুরক্ষা সম্পর্কে জানা যায়।

### 2. [**Update-MpSignature**](https://learn.microsoft.com/en-us/powershell/module/defender/update-mpsignature?view=windowsserver2022-ps)

`Update-MpSignature` কমান্ড দিয়ে Windows Defender-এর ব্যবহৃত অ্যান্টিভাইরাস সিগনেচার হাতে আপডেট করা যায়। সিগনেচারে পরিচিত ম্যালওয়্যার সম্পর্কে গুরুত্বপূর্ণ তথ্য থাকে, যা Windows Defender-কে হুমকি শনাক্ত ও আটকাতে সাহায্য করে। কমান্ডটি চালালে সিস্টেমে সাম্প্রতিক সিগনেচার আসে, যা নতুন হুমকির বিরুদ্ধে সুরক্ষা বাড়ায়।

Windows Defender সিগনেচার হাতে আপডেট করতে প্রশাসনিক অধিকারসহ PowerShell সেশন খুলে এই কমান্ড চালান:

```powershell
Update-MpSignature
```

কমান্ডটি আপডেট শুরু করে। Windows Defender Microsoft সার্ভারে সংযোগ করে **সর্বশেষ অ্যান্টিভাইরাস সিগনেচার** ডাউনলোড করে। আপডেট শেষে পরিচিত ম্যালওয়্যার সম্পর্কে হালনাগাদ তথ্য পাওয়া যায়, যা হুমকি শনাক্ত ও সরাতে সাহায্য করে।

পরিবর্তনশীল ম্যালওয়্যার ও সাইবার হুমকির বিরুদ্ধে সুরক্ষা বজায় রাখতে সিগনেচার আপডেট রাখা জরুরি। `Update-MpSignature` নিয়মিত চালিয়ে Windows Defender-কে আপনার সিস্টেম কার্যকরভাবে সুরক্ষিত রাখতে সাহায্য করুন।

### 3. [**Set-MpPreference**](https://learn.microsoft.com/en-us/powershell/module/defender/set-mppreference?view=windowsserver2022-ps)

`Set-MpPreference` কমান্ড দিয়ে **Windows Defender**-এর নানা সেটিংস আপনার নিরাপত্তার প্রয়োজন অনুযায়ী বদলানো যায়। এতে **রিয়েল-টাইম সুরক্ষা**, **ক্লাউড-ভিত্তিক সুরক্ষা** এবং **নেটওয়ার্ক পরিদর্শন ব্যবস্থা**র সেটিংস অন্তর্ভুক্ত।

উদাহরণস্বরূপ, `Set-MpPreference` দিয়ে রিয়েল-টাইম সুরক্ষা চালু বা বন্ধ করা যায়। এই সুরক্ষা সিস্টেমে ক্ষতিকর কার্যকলাপ পর্যবেক্ষণ করে এবং হুমকির দ্রুত প্রতিক্রিয়া দেয়। চালু করতে:

```powershell
Set-MpPreference -DisableRealtimeMonitoring:$false
```

ক্লাউড-ভিত্তিক সুরক্ষার সেটিংসও বদলানো যায়। এটি হুমকি শনাক্তকরণ উন্নত করতে এবং নতুন হুমকির দ্রুত প্রতিক্রিয়ায় **ক্লাউড সম্পদ** ব্যবহার করে। চালু করতে:

```powershell
Set-MpPreference -EnableCloudProtection:$true
```

`Set-MpPreference` দিয়ে নেটওয়ার্ক পরিদর্শন ব্যবস্থার সেটিংসও কাস্টমাইজ করা যায়। এই ব্যবস্থা সন্দেহজনক কার্যকলাপ ও সম্ভাব্য হুমকির জন্য নেটওয়ার্ক ট্র্যাফিক বিশ্লেষণ করে। সেটিংস বদলাতে:

```powershell
Set-MpPreference -DisableIOAVProtection:$false
```

`Set-MpPreference` দিয়ে এসব সেটিংস আপনার নিরাপত্তার প্রয়োজন অনুযায়ী সাজান এবং ম্যালওয়্যার ও অন্যান্য ক্ষতিকর কাজের বিরুদ্ধে **Windows Defender**-এর সুরক্ষা বজায় রাখুন।

### 4. [**Start-MpScan**](https://learn.microsoft.com/en-us/powershell/module/defender/start-mpscan?view=windowsserver2022-ps)

`Start-MpScan` কমান্ড সিস্টেমে ম্যালওয়্যার স্ক্যান শুরু করে, যাতে ক্ষতিকর ফাইল আগেভাগে খুঁজে সরানো যায়। এতে **দ্রুত স্ক্যান**, **পূর্ণ স্ক্যান** এবং নির্দিষ্ট পথের **কাস্টম স্ক্যান** রয়েছে।

`Start-MpScan` দিয়ে **দ্রুত স্ক্যান** চালাতে এই PowerShell কমান্ডটি চালান:

```powershell
Start-MpScan -ScanType QuickScan
```

দ্রুত স্ক্যান সিস্টেমের সেই গুরুত্বপূর্ণ অংশগুলো পরীক্ষা করে যেখানে সাধারণত ম্যালওয়্যার পাওয়া যায়। এতে সম্ভাব্য হুমকির দ্রুত মূল্যায়ন হয়।

সিস্টেমের সব ফাইল ও ডিরেক্টরি পরীক্ষা করতে `Start-MpScan` দিয়ে **পূর্ণ স্ক্যান** শুরু করুন:

```powershell
Start-MpScan -ScanType FullScan
```

পূর্ণ স্ক্যানে ম্যালওয়্যার খোঁজার পরিধি বিস্তৃত, তবে দ্রুত স্ক্যানের চেয়ে বেশি সময় লাগতে পারে।

আগে থেকে নির্ধারিত স্ক্যানের পাশাপাশি `Start-MpScan` দিয়ে নির্দিষ্ট পথ বা ফাইল স্ক্যান করা যায়। উদাহরণস্বরূপ, নির্দিষ্ট ডিরেক্টরি স্ক্যান করতে:

```powershell
Start-MpScan -ScanType CustomScan -ScanPath "C:\Path\To\Directory"
```

এই কমান্ড নির্দিষ্ট ডিরেক্টরিতে কাস্টম স্ক্যান চালায়, ফলে সিস্টেমের নির্দিষ্ট অংশে ম্যালওয়্যার শনাক্ত করা যায়।

`Start-MpScan` ব্যবহার করে স্ক্যানের সময় নির্ধারণ, নিরাপত্তা প্রক্রিয়া স্বয়ংক্রিয় করা এবং নিয়মিত ম্যালওয়্যার শনাক্ত ও মোকাবিলা নিশ্চিত করুন।

### 5. [**Get-MpThreatCatalog**](https://learn.microsoft.com/en-us/powershell/module/defender/get-mpthreatcatalog?view=windowsserver2022-ps)

`Get-MpThreatCatalog` কমান্ড পরিচিত হুমকি ও সেগুলোর বৈশিষ্ট্য সম্পর্কে বিস্তারিত তথ্য দেয়। এতে হুমকির মাত্রা, সংশ্লিষ্ট ফাইলের নাম এবং ঝুঁকি কমানোর সুপারিশসহ একটি বিস্তৃত তালিকা পাওয়া যায়।

`Get-MpThreatCatalog` দিয়ে নির্দিষ্ট হুমকির তথ্য পেতে:

1. প্রশাসনিক অধিকারসহ PowerShell সেশন খুলুন।
2. এই কমান্ডটি চালান:

```powershell
   Get-MpThreatCatalog
```

কমান্ডটি পরিচিত হুমকির তালিকা ও সংশ্লিষ্ট বিবরণ দেখায়।

`Get-MpThreatCatalog` কমান্ডের আউটপুটে গুরুত্বপূর্ণ তথ্য থাকে, যেমন:

- **ThreatID**: হুমকির অনন্য শনাক্তকারী।
- **Severity**: হুমকির মাত্রা, Low (নিম্ন) থেকে Severe (গুরুতর) পর্যন্ত।
- **Name**: হুমকির নাম বা বিবরণ।
- **Path**: হুমকির সঙ্গে যুক্ত ফাইলের পথ।
- **RecommendedAction**: হুমকি কমাতে নেওয়ার সুপারিশকৃত পদক্ষেপ।

`Get-MpThreatCatalog` থেকে পাওয়া তথ্য সম্ভাব্য হুমকি বুঝতে এবং সেগুলো মোকাবিলার যথাযথ পদক্ষেপ বেছে নিতে সাহায্য করে। নির্দিষ্ট হুমকি বিচ্ছিন্ন করা, সরানো বা পর্যবেক্ষণ করা যাই হোক, বিস্তারিত তালিকা নিরাপত্তা ঘটনার কার্যকর প্রতিক্রিয়ায় সহায়তা করে।

`Get-MpThreatCatalog` ব্যবহার ও ফলাফল ব্যাখ্যা সম্পর্কে আরও জানতে Microsoft-এর আনুষ্ঠানিক নথি দেখুন।

সতর্ক থাকুন এবং পরিবর্তনশীল হুমকি সম্পর্কে জানতে ও সিস্টেমের নিরাপত্তা বাড়াতে নিয়মিত `Get-MpThreatCatalog` চালান।

### 6. [**Add-MpPreference**](https://learn.microsoft.com/en-us/powershell/module/defender/add-mppreference?view=windowsserver2022-ps)

`Add-MpPreference` কমান্ড দিয়ে Windows Defender-এ ব্যতিক্রম যোগ করে স্ক্যান ও রিয়েল-টাইম সুরক্ষার আচরণ কাস্টমাইজ করা যায়। ব্যতিক্রমের মাধ্যমে নির্দিষ্ট ফাইল, ফোল্ডার বা প্রক্রিয়াকে নিরাপত্তা স্ক্যান কিংবা রিয়েল-টাইম সুরক্ষার সময় উপেক্ষা করতে বলা হয়।

`Add-MpPreference` দিয়ে ব্যতিক্রম যোগ করতে বাদ দেওয়া ফাইল, ফোল্ডার বা প্রক্রিয়ার পথ বা নাম দিন। ফোল্ডার বাদ দেওয়ার উদাহরণ:

```powershell
Add-MpPreference -ExclusionPath "C:\MyFolder"
```

এই কমান্ডে Windows Defender নির্দিষ্ট ফোল্ডার স্ক্যান করে না, ফলে অপ্রয়োজনীয় সতর্কতা ও কাজের ব্যাঘাত কমে।

বিশ্বস্ত অ্যাপ্লিকেশন, উন্নয়ন পরিবেশ বা ভুল শনাক্তকরণ ঘটাতে পারে এমন নির্দিষ্ট ফাইল বাদ দিতে ব্যতিক্রম কাজে লাগে। `Add-MpPreference` দিয়ে নিরাপত্তার প্রয়োজন অনুযায়ী Windows Defender সাজিয়ে এর কার্যক্ষমতা উন্নত করুন।

`Add-MpPreference`-এর ব্যতিক্রম সুবিধা কাজে লাগিয়ে ভুল শনাক্তকরণ ও অপ্রয়োজনীয় স্ক্যানের বাধা কমিয়ে সিস্টেম সুরক্ষিত রাখুন।

## 2026 সালের Defender কমান্ড যাচাই

কাজে উন্নত অধিকার প্রয়োজন হলেই কেবল উন্নত অধিকারসহ সেশন থেকে Defender কমান্ড চালান। কোনো প্যারামিটার ব্যবহারের আগে লক্ষ্য Windows সংস্করণের বর্তমান মডিউল সহায়িকা দেখুন। বর্তমান কনফিগারেশন নথিবদ্ধ করুন, একবারে একটি সেটিং বদলান, ফল যাচাই করুন এবং আগের অবস্থায় ফেরার কমান্ড লিখে রাখুন।

উপকারী পর্যালোচনার মধ্যে সুরক্ষা অবস্থা, সিগনেচারের বয়স, ব্যতিক্রম, পছন্দসমূহ, স্ক্যানের ইতিহাস এবং সাম্প্রতিক শনাক্তকরণ পরীক্ষা করা রয়েছে। ব্যতিক্রম সীমিত রাখুন এবং দায়িত্বপ্রাপ্ত ব্যক্তি ও মেয়াদ শেষের তারিখ লিখুন। বর্তমান cmdlet ও আচরণের জন্য [Microsoft Defender PowerShell মডিউলের নথি](https://learn.microsoft.com/en-us/powershell/module/defender/) এবং [Microsoft Defender Antivirus-এর নথি](https://learn.microsoft.com/en-us/defender-endpoint/microsoft-defender-antivirus-windows) দেখুন।

## উপসংহার

Windows Defender PowerShell কমান্ড Windows সিস্টেমের নিরাপত্তা পরিচালনা ও উন্নত করার জন্য **কার্যকর সরঞ্জামের একটি সমষ্টি** দেয়। এগুলো দিয়ে *নিরাপত্তা কার্যক্রম স্বয়ংক্রিয়*, *উন্নত সেটিংস কনফিগার* এবং বিদ্যমান কাজের ধারায় Windows Defender যুক্ত করা যায়। আপনি সিস্টেম প্রশাসক বা অভিজ্ঞ ব্যবহারকারী হলে এসব কমান্ড আপনার সিস্টেমের নিরাপত্তা জোরদার করে।

PowerShell কমান্ড চালানোর আগে সতর্ক থাকুন এবং সেগুলোর প্রভাব বুঝে নিন। Windows Defender PowerShell কমান্ড সম্পর্কে আপনার জ্ঞান কাজে লাগিয়ে পরিবর্তনশীল হুমকি থেকে সিস্টেমকে সুরক্ষিত রাখতে আগাম পদক্ষেপ নিন।
