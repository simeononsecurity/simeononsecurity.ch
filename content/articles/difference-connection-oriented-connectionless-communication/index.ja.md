## はじめに

ネットワーク通信には、コネクション型とコネクションレスという2つの一般的な方式があります。ネットワーク機器間で通信を確立し、維持する方法が異なります。この記事では、それぞれの主な違い、プロトコル、サービス、ルーティング方式を説明します。

## コネクション型通信

コネクション型通信では、データ転送の前に送信側と受信側の間で専用の接続を確立します。この接続は通信セッション全体を通じて維持されます。代表的なプロトコルは**伝送制御プロトコル（TCP）**です。

### コネクション型通信の仕組み

データ転送を始める前に、送信側と受信側は接続を確立するための制御情報を交換します。情報には送信元と宛先のアドレス、エラー検査の仕組み、順序付けの情報が含まれます。

接続が確立すると、データは信頼性を保って正しい順序で転送されます。TCPはパケットが損失や破損なく、正しい順序で宛先に届くようにします。この方式はフロー制御、輻輳制御、エラー回復などの機能を備え、信頼性の高いデータ配信を支えます。

### コネクション型通信の利点

コネクション型通信には次の利点があります。

1. **信頼性**: エラーのない順序どおりの転送により、データを確実に配信します。

2. **エラー回復**: TCPはネットワークエラーを検出して回復し、データの完全性を保ちます。

3. **フロー制御**: コネクション型プロトコルは、受信側に過剰なデータが届かないよう制御します。

4. **順序制御**: 送信順序が維持されるため、受信側は正しい順序でデータを受け取ります。

5. **輻輳制御**: TCPは輻輳を避け、ネットワークの安定性を保つために送信速度を調整します。

## コネクションレス通信

コネクション型と異なり、コネクションレス通信ではデータ転送の前に専用の接続を確立しません。各パケットを独立した単位として扱い、ネットワーク内で個別にルーティングします。よく知られたプロトコルは**ユーザーデータグラムプロトコル（UDP）**です。

### コネクションレス通信の仕組み

パケットは事前の設定や受信確認なしにネットワークへ送信されます。各パケットには送信元と宛先のアドレスなど、個別にルーティングして配信するための情報が含まれます。接続の確立や維持に伴うオーバーヘッドがないため、コネクション型より高速になりやすい一方、信頼性は低くなります。

### コネクションレス通信の利点

コネクションレス通信には次の利点があります。

1. **効率**: 接続の確立と維持に伴うオーバーヘッドがなく、ネットワークリソースと処理を効率よく使えます。

2. **低遅延**: 接続確立が不要なため遅延を抑えられます。動画配信やオンラインゲームなどのリアルタイムアプリケーションに適しています。

3. **単純さ**: 接続の設定と維持が不要なため、通信処理が簡潔になり、複雑さも減ります。

## 2つの通信方式の比較

コネクション型通信とコネクションレス通信の主な違いを比較します。

| | コネクション型通信 | コネクションレス通信 |
|--------------------|----------------------------------------|---------------------------------------|
| 確立 | 接続確立の段階が必要 | 接続確立は不要 |
| 信頼性 | 信頼性の高いデータ転送 | データ転送は保証されない |
| 順序 | パケットは順番どおりに届く | パケットの到着順が変わる場合がある |
| オーバーヘッド | 接続設定のため大きい | 接続がないため小さい |
| エラー処理 | エラー回復の仕組みがある | エラー回復の仕組みを含まない |
| 用途 | 信頼性と順序を保つデータ配信が | 低遅延が必要なリアルタイム |
| | 必要なアプリケーションに適する | アプリケーションに適する |

## コネクション型とコネクションレスのルーティング

通信方式はネットワーク内のルーティングにも関係します。ルーティングとは、送信元から宛先へデータを送るための適切な経路を選ぶことです。

コネクション型ルーティングでは、接続の確立時にネットワークインフラがあらかじめ経路を設定します。経路は通信セッション中に変わりません。コネクションレスルーティングでは固定の経路を必要としません。各パケットは現在のネットワーク状況と利用可能な経路に基づいて個別にルーティングされます。

## まとめ

主な違いは、データ転送の前に専用の接続を確立するかどうかです。TCPのようなコネクション型通信は、信頼性、エラー回復、フロー制御、順序制御、輻輳制御を提供します。UDPのようなコネクションレス通信は、効率、低遅延、単純さを提供します。適切な方式はアプリケーションの要件で決まります。信頼性と順序を保つ配信が必要ならコネクション型を選び、低遅延が必要なリアルタイム用途ならコネクションレスを選びます。
