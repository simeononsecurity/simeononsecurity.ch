[Nmap](https://nmap.org/download.html) (Network Mapper (أي أداة لرسم خرائط الشبكات)) أداة مفتوحة المصدر قوية ومتعددة الاستخدامات لفحص الشبكات واكتشاف المضيفين والخدمات في شبكة الحاسوب. توفر معلومات قيّمة عن البنية التحتية للشبكة وتساعد في تقييم أمنها. يشرح هذا المقال أساسيات Nmap وميزاته وكيفية استخدامه بفعالية.

## فهم Nmap

Nmap أداة تعمل من سطر الأوامر على أنظمة تشغيل متعددة، منها Windows وLinux وmacOS. تستخدم حزم IP الخام لتحديد المضيفين المتاحين على الشبكة والخدمات التي يقدمونها وأنظمة التشغيل التي يشغّلونها ومعلومات مفيدة أخرى.

تتيح مجموعة ميزات Nmap الواسعة لمسؤولي الشبكات ومتخصصي الأمن وحتى المخترقين الأخلاقيين جمع معلومات قيّمة عن الشبكة. وتشمل قدراته ما يلي:

1. **اكتشاف المضيفين**: يفحص Nmap نطاقاً من عناوين IP أو شبكة فرعية محددة لتحديد المضيفين النشطين. ويستخدم أساليب مختلفة، مثل طلبات صدى ICMP وفحوص TCP SYN وطلبات ARP، لتحديد المضيفين الذين يستجيبون.

2. **فحص المنافذ**: يتميز Nmap بفحص المنافذ المفتوحة على المضيف المستهدف. ويمكنه تنفيذ فحوص متعددة، منها TCP SYN واتصال TCP وUDP. يوضح فحص المنافذ الخدمات التي تعمل على مضيف معين ويمكن الوصول إليها.

3. **اكتشاف الخدمات**: يحلل Nmap حركة الشبكة والاستجابات للتعرف إلى الخدمات التي تعمل على المنافذ المفتوحة. وقد يكتشف إصدار الخدمة أيضاً. تساعد هذه المعلومات في فهم الثغرات المحتملة المرتبطة بخدمات محددة.

4. **اكتشاف نظام التشغيل**: يستخدم Nmap تقنيات البصمة لتحديد نظام التشغيل على المضيف المستهدف. ويحلل بروتوكولات الشبكة والاستجابات لتقدير نظام التشغيل الأساسي.

5. **إمكانات البرمجة النصية**: يدعم Nmap استخدام محرك البرمجة النصية Nmap (NSE) لأتمتة المهام وإجراء فحوص متقدمة للشبكات. يوفر NSE مجموعة كبيرة من النصوص البرمجية لاكتشاف الثغرات والشبكات وغير ذلك.

## تثبيت Nmap

لاستخدام Nmap، ثبّته على نظامك. تختلف خطوات التثبيت باختلاف نظام التشغيل.

### Windows

يمكن لمستخدمي Windows تنزيل Nmap من الموقع الرسمي: [https://nmap.org/download.html](https://nmap.org/download.html). اختَر أداة التثبيت المناسبة لنظامك واتبع معالج التثبيت.

### Linux

يمكن تثبيت Nmap في معظم توزيعات Linux باستخدام مدير الحزم. افتح الطرفية ونفّذ الأمر التالي:

```shell
sudo apt-get install nmap
```
استبدل apt-get بمدير الحزم الذي تستخدمه توزيعتك عند الحاجة.

### macOS

يمكن لمستخدمي macOS تثبيت Nmap باستخدام مدير الحزم Homebrew. افتح الطرفية ونفّذ الأمر التالي:

```shell
brew install nmap
```

## الفحص باستخدام Nmap

بعد تثبيت Nmap، ابدأ فحص شبكتك لجمع المعلومات. فيما يلي بعض أساليب الفحص الشائعة:

1. **فحص ping**: أبسط طريقة للتحقق من اتصال المضيفين هي إجراء فحص ping. نفّذ الأمر التالي:

```shell
nmap -sn <target>
```
استبدل `<target>` بعنوان IP أو الشبكة الفرعية المستهدفة.

2. **فحص TCP SYN**: يستخدم هذا الفحص لتحديد منافذ TCP المفتوحة على المضيف المستهدف. نفّذ الأمر التالي:

```shell
nmap -sS <target>
```
استبدل `<target>` بعنوان IP أو اسم المضيف المستهدف.

3. **اكتشاف الخدمات وإصداراتها**: لتحديد الخدمات العاملة على المنافذ المفتوحة وإصداراتها، نفّذ الأمر التالي:

```shell
nmap -sV <target>
```

استبدل `<target>` بعنوان IP أو اسم المضيف المستهدف.

4. **اكتشاف نظام التشغيل**: لتحديد نظام التشغيل على المضيف المستهدف، نفّذ الأمر التالي:

```shell
nmap -O <target>
```
استبدل `<target>` بعنوان IP أو اسم المضيف المستهدف.

هذه بعض الأمثلة فقط على خيارات الفحص المتاحة في Nmap. راجع وثائق Nmap الرسمية للاطلاع على أساليب وخيارات أكثر تقدماً.

## أفضل الممارسات والاعتبارات

عند استخدام Nmap، ضع أفضل الممارسات والاعتبارات التالية في الحسبان:

1. **الإذن والقانونية**: قبل فحص أي شبكة، تأكد من حصولك على تفويض مناسب. قد يكون الفحص غير المصرح به مخالفاً للقانون وقد ينتهك تشريعات مثل قانون الاحتيال وإساءة استخدام الحاسوب (CFAA) في الولايات المتحدة. احصل دائماً على إذن مالك الشبكة أو التزم بالقوانين في نطاقك القضائي.

2. **تأثير الشبكة**: قد يولّد فحص Nmap حركة مرور كبيرة على الشبكة، خصوصاً أثناء الفحوص المكثفة. راعِ التأثير المحتمل على أداء الشبكة وفكّر في جدولة الفحوص خلال فترات انخفاض حركة المرور.

3. **الفحص الموجّه**: تجنب فحص الشبكات عشوائياً. ركّز على أهداف محددة وحدد نطاق أنشطة الفحص. يساعد هذا النهج على تقليل تعطيل الشبكة غير الضروري وخفض احتمال إطلاق تنبيهات أمنية.

4. **حماية البيانات**: احرص على عدم كشف المعلومات الحساسة عند فحص الشبكات. تجنب جمع معلومات التعريف الشخصية (PII) أو أي بيانات سرية أو تخزينها. امتثل لقوانين حماية البيانات، مثل اللائحة العامة لحماية البيانات (GDPR)، عند انطباقها.

## الخلاصة

Nmap أداة واسعة الاستخدام لفحص الشبكات وتقدم معلومات قيّمة عن البنية التحتية للشبكة وأمنها. بفهم أساسيات Nmap واتباع أفضل الممارسات، يستطيع مسؤولو الشبكات ومتخصصو الأمن تقييم ثغرات الشبكة وتحديد المخاطر المحتملة والحفاظ على بيئة شبكة آمنة.
