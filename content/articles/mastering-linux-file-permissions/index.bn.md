**Linux ফাইলের অনুমতিতে দক্ষতা: ফাইল সিস্টেম সুরক্ষার সম্পূর্ণ নির্দেশিকা**

**Linux** একটি শক্তিশালী ও নমনীয় অপারেটিং সিস্টেম, যাতে ফাইলের অনুমতিসহ নির্ভরযোগ্য নিরাপত্তা বৈশিষ্ট্য রয়েছে। **ফাইলের অনুমতি** বুঝে সঠিকভাবে নির্ধারণ করা **নিরাপদ ফাইল সিস্টেম** বজায় রাখার জন্য জরুরি। এই নির্দেশিকায় Linux ফাইলের অনুমতি ব্যাখ্যা করা হয়েছে, যাতে আপনি সিস্টেম নিরাপত্তার এই গুরুত্বপূর্ণ দিকটি আয়ত্ত করতে পারেন।

## Linux ফাইলের অনুমতির পরিচিতি

Linux একটি **বহু-ব্যবহারকারী** অপারেটিং সিস্টেম, যেখানে একাধিক ব্যবহারকারী একই সময়ে সিস্টেম ব্যবহার করতে পারেন। ফাইলের অনুমতি ফাইল ও ডিরেক্টরিতে প্রবেশ নিয়ন্ত্রণ করে, যাতে কেবল অনুমোদিত ব্যবহারকারীরা **পড়তে**, **লিখতে** বা **চালাতে** পারেন।

Linux-এর প্রতিটি ফাইল ও ডিরেক্টরির জন্য অনুমতির তিনটি দল আছে: **ব্যবহারকারী**, **গোষ্ঠী** এবং **অন্যরা**। **ব্যবহারকারী** অনুমতি ফাইলের মালিকের জন্য, **গোষ্ঠী** অনুমতি সংশ্লিষ্ট গোষ্ঠীর জন্য এবং **অন্যরা** অনুমতি বাকি সবার জন্য প্রযোজ্য।

### অনুমতির ধরন বুঝুন

Linux ফাইলের অনুমতি তিন ধরনের: **পড়া**, **লেখা** ও **চালানো**। এগুলোকে নিচের চিহ্ন দিয়ে প্রকাশ করা হয়:

- **r**: পড়ার অনুমতি দিয়ে ফাইলের বিষয়বস্তু দেখা বা ডিরেক্টরির বিষয়বস্তুর তালিকা দেখা যায়।
- **w**: লেখার অনুমতি দিয়ে ফাইলের বিষয়বস্তু বদলানো, অথবা ডিরেক্টরিতে ফাইল যোগ, মুছে ফেলা বা নাম বদলানো যায়।
- **x**: চালানোর অনুমতি দিয়ে ফাইলকে প্রোগ্রাম হিসেবে চালানো বা ডিরেক্টরির বিষয়বস্তুতে প্রবেশ করা যায়।

তিনটি দলের প্রতিটির জন্য প্রতিটি অনুমতি দেওয়া বা বন্ধ করা যায়: **ব্যবহারকারী**, **গোষ্ঠী** এবং **অন্যরা**।

### অনুমতির সংখ্যাসূচক প্রকাশ

প্রতীক ছাড়াও Linux ফাইলের অনুমতি সংখ্যা দিয়ে প্রকাশ করা যায়। প্রতিটি ধরনের একটি মান আছে: **পড়া (4)**, **লেখা (2)** ও **চালানো (1)**। মানগুলো যোগ করলে তিন অঙ্কের একটি অক্টাল সংখ্যা পাওয়া যায়, যা ফাইল বা ডিরেক্টরির অনুমতি প্রকাশ করে।

উদাহরণস্বরূপ, ব্যবহারকারী ফাইলটি পড়তে ও লিখতে পারেন, গোষ্ঠী পড়তে পারে এবং অন্যদের কোনো অনুমতি নেই, তাহলে সংখ্যাসূচক প্রকাশ হবে **640**।

## ফাইলের অনুমতি পরিবর্তন

Linux-এ ফাইলের অনুমতি পরিবর্তন করতে **chmod** কমান্ড ব্যবহার করা হয়। এটি ব্যবহারকারী, গোষ্ঠী ও অন্যদের অনুমতি আলাদাভাবে বদলাতে দেয়।

### প্রতীকী পদ্ধতিতে অনুমতি বদলানো

পড়ার সুবিধাজনক প্রতীক ব্যবহার করে অনুমতি বদলানো যায়। মৌলিক বাক্যরীতি:

```shell
chmod <permissions> <file>
```

<permissions>-এ u (ব্যবহারকারী), g (গোষ্ঠী), o (অন্যরা), + (অনুমতি যোগ), - (অনুমতি বাদ) এবং = (অনুমতি নির্ধারণ) ব্যবহার করা যায়।

উদাহরণস্বরূপ, ব্যবহারকারীকে পড়া ও লেখার অনুমতি দিতে চালান:

```bash
chmod u+rw file.txt
```
### সংখ্যাসূচক পদ্ধতিতে অনুমতি বদলানো

অক্টাল সংখ্যা দিয়ে সংক্ষেপে অনুমতি বদলানো যায়। আগেই বলা হয়েছে, প্রতিটি অনুমতির ধরন একটি সংখ্যার মান দিয়ে প্রকাশ করা হয়।

ব্যবহারকারীকে পড়া, লেখা ও চালানোর অনুমতি; গোষ্ঠীকে পড়া ও চালানোর অনুমতি; এবং অন্যদের কোনো অনুমতি না দিতে চালান:

```bash
chmod 750 file.txt
```
## ফাইলের মালিকানা ও গোষ্ঠী

অনুমতির পাশাপাশি Linux প্রতিটি ফাইল ও ডিরেক্টরির মালিকানার তথ্যও রাখে। কোন ব্যবহারকারী ও গোষ্ঠী ফাইলটি নিয়ন্ত্রণ করবে, মালিকানা তা নির্ধারণ করে।

### ব্যবহারকারীর মালিকানা

যে ব্যবহারকারী ফাইল তৈরি করেন, তিনিই তার মালিক। মালিক ফাইল নিয়ন্ত্রণ করতে, অনুমতি বদলাতে, নাম পাল্টাতে, সরাতে বা মুছতে পারেন। `chown` কমান্ড দিয়ে ফাইল বা ডিরেক্টরির মালিক বদলানো হয়।

`chown`-এর মৌলিক বাক্যরীতি:

```shell
chown <user> <file>
```

<user>-এর জায়গায় ব্যবহারকারীর নাম বা ব্যবহারকারী পরিচয় নম্বর (UID) দেওয়া যায়। উদাহরণস্বরূপ, ফাইলটির মালিক johndoe করতে চালান:

```bash
chown johndoe file.txt
```

### গোষ্ঠীর মালিকানা
প্রতিটি ফাইল ও ডিরেক্টরি একটি গোষ্ঠীর সঙ্গেও যুক্ত। ডিফল্টভাবে এটি ফাইল তৈরিকারী ব্যবহারকারীর প্রাথমিক গোষ্ঠী। chgrp কমান্ড দিয়ে গোষ্ঠীর মালিকানা বদলানো যায়।

chgrp-এর মৌলিক বাক্যরীতি:

```bash
chgrp <group> <file>
```

<group>-এর জায়গায় গোষ্ঠীর নাম বা গোষ্ঠী পরিচয় নম্বর (GID) দেওয়া যায়। উদাহরণস্বরূপ, ফাইলটির গোষ্ঠী developers করতে চালান:

```bash
chgrp developers file.txt
```

## বিশেষ ফাইলের অনুমতি
পড়া, লেখা ও চালানোর সাধারণ অনুমতির পাশাপাশি Linux নিরাপত্তা ও কার্যকারিতা বাড়াতে বিশেষ অনুমতিও দেয়।

### ব্যবহারকারীর পরিচয় নির্ধারণ (SUID)
ব্যবহারকারীর পরিচয় নির্ধারণ (SUID) অনুমতিতে ফাইলটি চালালে, চালক নিজের অনুমতির বদলে ফাইলের মালিকের অনুমতি ব্যবহার করেন। ব্যবহারকারীর চেয়ে বেশি বিশেষাধিকার দরকার হলে এটি কাজে লাগে।

ফাইলে SUID নির্ধারণ করতে সংখ্যাসূচক পদ্ধতিতে chmod ব্যবহার করুন:

```bash
chmod 4755 file.txt
```

শুরুর 4 অঙ্কটি ব্যবহারকারীর জন্য SUID অনুমতি নির্ধারণ করে।

### গোষ্ঠীর পরিচয় নির্ধারণ (SGID)
গোষ্ঠীর পরিচয় নির্ধারণ (SGID) অনুমতি SUID-এর মতো, তবে এটি ব্যবহারকারীর বদলে গোষ্ঠীর ক্ষেত্রে প্রযোজ্য। SGID-সহ ফাইল চালালে সেটি মালিক গোষ্ঠীর অনুমতিতে চলে।

ফাইলে SGID নির্ধারণ করতে সংখ্যাসূচক পদ্ধতিতে chmod ব্যবহার করুন:

```bash
chmod 2755 file.txt
```
শুরুর 2 অঙ্কটি গোষ্ঠীর জন্য SGID অনুমতি নির্ধারণ করে।

### Sticky bit
Sticky bit অননুমোদিতভাবে ডিরেক্টরি থেকে ফাইল মুছে ফেলা ঠেকানোর নিরাপত্তা বৈশিষ্ট্য। ডিরেক্টরিতে এটি নির্ধারণ করলে কেবল ফাইলের মালিকই সেই ডিরেক্টরি থেকে ফাইলটি মুছতে পারেন।

ডিরেক্টরিতে sticky bit নির্ধারণ করতে সংখ্যাসূচক পদ্ধতিতে chmod ব্যবহার করুন:

```bash
chmod 1755 directory/
```

শুরুর 1 অঙ্কটি sticky bit নির্ধারণ করে।

## ফাইলের অনুমতির ভালো পদ্ধতি
Linux-এ অনুমতি নির্ধারণ করার সময় নিরাপদ ফাইল সিস্টেম বজায় রাখতে এই পদ্ধতিগুলো অনুসরণ করুন:

### ন্যূনতম বিশেষাধিকারের নীতি
ন্যূনতম বিশেষাধিকারের নীতি অনুযায়ী ব্যবহারকারী ও প্রক্রিয়াকে কাজের জন্য প্রয়োজনীয় সর্বনিম্ন প্রবেশাধিকার দিতে হয়। অনুমতি নির্ধারণের সময় প্রতিটি ব্যবহারকারী ও গোষ্ঠীকে কেবল প্রয়োজনীয় অনুমতি দিন।

### নিয়মিত ফাইলের অনুমতি নিরীক্ষা করুন

ফাইল সিস্টেম নিরাপদ রাখতে নিয়মিত অনুমতি নিরীক্ষা জরুরি। এতে অননুমোদিত প্রবেশ ও সম্ভাব্য নিরাপত্তা দুর্বলতা চিহ্নিত করা যায়। এই ধাপগুলো অনুসরণ করুন:

1. **গুরুত্বপূর্ণ ফাইল ও ডিরেক্টরি চিহ্নিত করুন**: কোন ফাইল ও ডিরেক্টরিতে সংবেদনশীল বা গুরুত্বপূর্ণ তথ্য আছে এবং কঠোর অনুমতি দরকার, তা নির্ধারণ করুন।

2. **অনুমতি পর্যালোচনা করুন**: অনুমতিসহ ফাইল ও ডিরেক্টরির বিস্তারিত দেখতে `-l` বিকল্পসহ `ls` কমান্ড ব্যবহার করুন। অতিরিক্ত খোলা অনুমতির কারণে ঝুঁকি হতে পারে এমন উপাদান খুঁজুন।

3. **অনুমতি সংশোধন করুন**: ভুল বা অনিরাপদ অনুমতি পেলে সেগুলো বদলাতে `chmod` কমান্ড ব্যবহার করুন। কেবল অনুমোদিত ব্যবহারকারী বা গোষ্ঠী যেন প্রয়োজনীয় অনুমতি পায়, তা নিশ্চিত করুন।

4. **নিয়মিত নিরীক্ষার সময়সূচি করুন**: সাপ্তাহিক, মাসিক বা প্রতিষ্ঠানের নিরাপত্তানীতি অনুযায়ী ফাইলের অনুমতি নিরীক্ষার সময় ঠিক করুন। নিয়মিত নিরীক্ষা ফাইল সিস্টেমের অখণ্ডতা বজায় রাখতে এবং অনুমতি-সংক্রান্ত সমস্যা দ্রুত সমাধান করতে সাহায্য করে।

### নিয়ম ও বিধি নথিভুক্ত করুন

প্রতিষ্ঠানের ফাইলের অনুমতি ও প্রবেশাধিকার নীতি নথিভুক্ত করা জরুরি। প্রশাসক ও ব্যবহারকারীদের জন্য এই নথি একটি নির্দেশিকা হবে। এতে অন্তর্ভুক্ত করুন:

- ফাইলের অনুমতির ধরন ও অর্থের ব্যাখ্যা।
- ফাইলের অনুমতি নির্ধারণ ও পরিবর্তনের নির্দেশনা।
- ব্যবহারকারী ও গোষ্ঠীকে অনুমতি দেওয়ার ভালো পদ্ধতি।
- প্রতিষ্ঠানের জন্য প্রযোজ্য নিয়ন্ত্রক চাহিদা বা শিল্পমান, যেমন **সাধারণ তথ্য সুরক্ষা বিধিমালা (GDPR)** অথবা **স্বাস্থ্যবিমা বহনযোগ্যতা ও জবাবদিহি আইন (HIPAA)**।

নিয়ম নথিভুক্ত করা ও স্পষ্ট নির্দেশনা দেওয়া প্রতিষ্ঠানে ধারাবাহিকতা এবং নিরাপত্তা সচেতনতা বাড়ায়।

## উপসংহার

নিরাপদ ফাইল সিস্টেম বজায় রাখতে Linux ফাইলের অনুমতিতে দক্ষ হওয়া জরুরি। অনুমতি বোঝা, সঠিকভাবে বদলানো এবং ভালো পদ্ধতি অনুসরণ করা Linux সিস্টেমকে আরও সুরক্ষিত করে। নিয়মিত নিরীক্ষা ও নিয়ম নথিভুক্তকরণ সিস্টেমের অখণ্ডতা রক্ষা করে এবং সংবেদনশীল তথ্যে প্রবেশাধিকার অনুমোদিত ব্যবহারকারীদের মধ্যে সীমিত রাখে।

ফাইলের অনুমতি সামগ্রিক সিস্টেম নিরাপত্তার একটি অংশ মাত্র। সম্পূর্ণ ও শক্তিশালী নিরাপত্তা কৌশল গড়তে এনক্রিপশন, ব্যবহারকারী ব্যবস্থাপনা এবং নেটওয়ার্ক নিরাপত্তার মতো অন্যান্য ব্যবস্থাও বিবেচনা করুন।

এই নির্দেশিকার নিয়মগুলো অনুসরণ করলে আপনি Linux ফাইলের অনুমতি ভালোভাবে পরিচালনা করতে এবং ফাইল সিস্টেম সুরক্ষিত রাখতে পারবেন।
