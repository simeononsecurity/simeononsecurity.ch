Visual Studio Code (VS Code) محرر شيفرة شائع وقوي يدعم لغات برمجة متعددة. تتوفر للمطورين الذين يعملون بلغة C++ **إضافات** عديدة تحسّن تجربة البرمجة وتزيد الإنتاجية. نستعرض في هذا المقال بعضًا من أفضل إضافات C++ لـ Visual Studio Code.

______

## المقدمة

C++ لغة برمجة قوية ومتعددة الاستخدامات، تُستخدم على نطاق واسع لتطوير برمجيات الأنظمة ومحركات الألعاب والأنظمة المضمنة وغيرها. Visual Studio Code محرر خفيف وغني بالميزات، ويوفر بيئة ممتازة لتطوير C++. باستخدام الإضافات المناسبة، يمكنك توسيع إمكانات Visual Studio Code وتبسيط سير عملك في C++.

______

## 1. C/C++ IntelliSense

إضافة **C/C++ IntelliSense** لـ Visual Studio Code ضرورية لمطوري C++. توفر إكمالًا ذكيًا للشيفرة وتمييزًا للصياغة وتشخيصًا للأخطاء، ما يسهّل كتابة شيفرة خالية من الأخطاء. تساعدك على التنقل في قاعدة الشيفرة، واستعراض تعريفات الدوال، والانتقال سريعًا إلى التصريحات. كما توفر تنسيقًا تلقائيًا للشيفرة وتدعم مترجمات C++ مختلفة، منها GCC وClang.

## 2. C++ Intellisense

إضافة أخرى شائعة لتطوير C++ في Visual Studio Code هي **C++ Intellisense**. توفر تحليلًا قويًا للشيفرة وتمييزًا دلاليًا يساعدانك على فهم الشيفرة. وتشمل فحص الأخطاء في الوقت الفعلي، والتنقل في الشيفرة، والبحث عن توثيق رموز C++. تدعم **C++ Intellisense** أيضًا مترجمات C++ وأنظمة بناء مختلفة، ما يتيح دمجها بسلاسة مع مجموعة الأدوات التي تفضلها.

## 3. C++ TestMate

**C++ TestMate** إضافة مفيدة لمطوري C++ الذين يكتبون اختبارات الوحدات. تتكامل بسلاسة مع أطر اختبار C++ الشائعة مثل Google Test وCatch2 وBoost.Test. تتيح لك تشغيل الاختبارات وتصحيحها مباشرة من Visual Studio Code. كما توفر مستكشف اختبارات سهل الاستخدام، وعرضًا مرئيًا للنتائج، ووصولًا ميسرًا إلى أوامر الاختبار. تساعدك **C++ TestMate** على ضمان موثوقية شيفرة C++ وجودتها بكتابة اختبارات وحدات شاملة وتشغيلها.

## 4. CMake Tools

إذا كنت تستخدم CMake نظامًا للبناء في مشاريع C++، فإضافة **CMake Tools** خيار ممتاز لإعداد Visual Studio Code. توفر مجموعة أدوات قوية لإعداد مشاريع CMake وبنائها واختبارها مباشرة من المحرر. باستخدام **CMake Tools**، يمكنك إدارة إعدادات CMake وإنشاء ملفات البناء وتنفيذ مهام بناء متعددة دون مغادرة Visual Studio Code. تبسّط الإضافة سير عمل CMake بدرجة كبيرة وتزيد إنتاجيتك كمطور C++.

نزّل إضافة **CMake Tools** من Visual Studio Code Marketplace: [إضافة CMake Tools](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cmake-tools)

______

## 5. Better Comments

تساعدك إضافة **Better Comments** على كتابة تعليقات أوضح وأكثر تنظيمًا في شيفرة C++. تضيف ألوانًا إلى أنواع التعليقات المختلفة لتمييزها بصريًا. باستخدام **Better Comments**، يمكنك تحديد التعليقات المهمة أو التي تطرح سؤالًا أو التي أصبحت قديمة، ما يحسّن توثيق الشيفرة والتعاون. وتجعل الإضافة قاعدة الشيفرة أسهل فهمًا وأكثر قابلية للقراءة.
