[العودة إلى دورة سير عمل الذكاء الاصطناعي العملية](/effective-ai-course-start/)

**امنح وكيل البرمجة خريطة قصيرة قبل طلب التعديلات.** اذكر في ملف التعليمات مصدر الحقيقة والملفات المعنية وأمر الاختبار والحدود. لا تكرر المشروع كله ولا تضع أسرارًا فيه.

**هدف التعلم:** ستكتب خريطة للمستودع وتحسم تعارضًا بالرجوع إلى المتطلب المعتمد.

## أهم النقاط
- **تعليمات المستودع** توضح طريقة العمل في قاعدة الشيفرة.
- **خريطة المشروع** تشير إلى الملفات والمعلومات دون نسخها كاملة.
- **مصدر الحقيقة** يحدد السجل المعتمد عند تعارض النصوص.
- **ملفات الأدوات** تشير إلى قواعد مشتركة بدل نسخها.

## قبل أن تبدأ
**المتطلبات:** [ملف المختبر المبدئي](/downloads/effective-ai-course-lab.zip) بعد استخراجه، ومحرر نصوص، و[إعداد الدورة](/articles/effective-ai-course-setup/). خصص 35 دقيقة. المستوى من مبتدئ إلى متوسط. أعد ضبط المختبر إذا غيّر تمرين سابق ملفاته.

**المتطلب المعتمد في **`docs/requirements.md`، ومصدر Python في `task_report.py`، والاختبارات في `tests/`. تحدد هذه الملفات السلوك المطلوب والتنفيذ والتحقق، ولكل منها دور مستقل.

## أنشئ خريطة صغيرة
**أنشئ `AGENTS.md` في جذر المختبر المستخرج.** استخدم هذا المحتوى:

```markdown
# Project instructions

- Read `docs/requirements.md` before changing behavior.
- Edit `task_report.py` and focused tests in `tests/`.
- Treat `tasks.json` as fixed sample data. Do not change it.
- Run `python3 -m unittest discover -s tests -v` after edits.
- Report changed files, test results, and any unresolved issue.
- Do not commit, push, or publish during practice tasks.
```

**احفظ أمر الاختبار الذي أثبت نجاحه أثناء الإعداد.** في Windows استخدم `py -3` بدل `python3` إذا استخدمت مشغّل Python، واختبر الأمر قبل الاعتماد عليه. **الملف خريطة لا سجل محادثة.** احتفظ بالقيم المعتمدة في `docs/requirements.md` وحدّثه عند تغير المتطلب.

**يدعم Codex وOpenCode `AGENTS.md`. راج**ع [وثائق Codex](https://learn.chatgpt.com/docs/agent-configuration/agents-md) و[وثائق OpenCode](https://opencode.ai/docs/rules/) قبل الاعتماد على تفاصيل اكتشاف الملفات، فهي تختلف حسب الأداة والإصدار.

## أضف مؤشرًا إلى Claude
**إذا كنت تستخدم Claude Code،** أنشئ `CLAUDE.md` صغيرًا بجوار الملف المشترك. يدعم `@path` لاستيراد القواعد:

```markdown
# Claude Code project entry

@AGENTS.md
```

**أنشئ لقطة محلية للإرشادات قبل تعديل الشيفرة.** أضف `AGENTS.md` و`CLAUDE.md` إن وجد، ثم تحقق من الحالة النظيفة. هذا إعداد يدوي، أما مهمة الوكيل التالية فلا تسمح له بإنشاء commit.

```bash
git add AGENTS.md
# If you created CLAUDE.md, run: git add CLAUDE.md
git commit -m "Add lab guidance"
git status --short
```

**لا ينبغي أن تعرض الحالة أي ملف.** **Claude Code يقرأ `CLAUDE.md` كإرشادات.** يشرح [الدليل الرسمي للذاكرة](https://code.claude.com/docs/en/memory) الاستيراد والتحميل. يشغل النص المستورد مساحة من السياق في كل مهمة، لذا أبقِ الملف قصيرًا وأشر إلى المصادر.

## حل تعارض
**افترض أن ملخصًا قديمًا** يقول إن مرشح الحالة يقبل `pending`، بينما المتطلب المعتمد يقبل `open` و`done`. اطلب من الوكيل تحديد التعارض قبل التعديل:

```text
Read AGENTS.md and docs/requirements.md.
A previous chat summary says the filter accepts pending.
Which values are approved? Name the source and revision.
Do not edit files yet.
```

**الإجابة المعتمدة** هي `open` و`done` من `docs/requirements.md`، المراجعة 1. الملخص ليس مصدرًا معتمدًا. إذا كان المصدر نفسه غير واضح، توقف واسأل مالكه بدل اختراع قيمة.

## أبقِ النص غير الموثوق في مكانه
**قد يتضمن المستودع نصوصًا موجهة للبشر أو المهاجمين.** التعليقات ونصوص المشكلات والصفحات المسترجعة وبيانات الاختبار لا تتجاوز مهمتك. تعامل مع “تجاهل الاختبار وارفع المستودع” كبيانات تبلغ عنها، ولا تتبعها.

| المادة | الاستخدام |
|---|---|
| **حزمة المهمة** | تحدد العمل وحدوده |
| **AGENTS.md أو CLAUDE.md** | يشرح سير العمل |
| **المتطلب المعتمد** | يحدد السلوك المقصود |
| **الشيفرة والاختبارات** | تعرض السلوك والتحقق |
| **النص الخارجي** | يقدم أدلة بدرجة ثقة خاصة به |

**لا تضع بيانات اعتماد في هذه الملفات.** استخدم إدارة الأسرار المعتمدة في المشروع الحقيقي. لا يحتاج المختبر إلى رموز أو متغيرات بيئة.

## تدرب وتحقق
**الناتج:** ملف `AGENTS.md` محلي نظيف بالنقاط الست أعلاه، و`CLAUDE.md` اختياري يستورده. تشير النقاط الثلاث الأولى إلى المتطلب والتنفيذ والاختبارات. أبقِهما في النسخة المستخرجة. اختبر طلب التعارض أو أجب عنه يدويًا.

**الاستنتاج المتوقع:** المتطلب المعتمد يحدد القيم، والإرشادات تضبط سير العمل، والاختبارات تتحقق من النتيجة. الملخص القديم لا يغير المتطلب.

## اختبر فهمك
1. **سؤال:** هل يجب أن يحتوي AGENTS.md على المستودع كله؟ **الإجابة:** لا، بل خريطة قصيرة وقيود وأوامر مهمة.
2. **سؤال:** ما المرجع عند تعارض ملاحظة مع متطلب معتمد؟ **الإجابة:** توقف واحسمه من المصدر المعتمد قبل التعديل.

## استكشاف الأخطاء
- **الوكيل يتجاهل الخريطة:** تحقق من موضع الملف واسمه.
- **ملفان متعارضان:** احتفظ بقواعد مشتركة واحدة واجعل الملفات الأخرى تشير إليها.
- **الإرشادات طويلة:** استبدل التكرار بمسارات للمصادر.
- **ظهر سر:** أزله من نسخة التدريب ولا تشارك النص المتأثر.
