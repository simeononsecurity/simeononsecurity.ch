What the numbers mean

Mining net subtracts GPU power from the current Hashrate.no gross daily estimate. Local API savings multiply Qwen generation speed by 86,400 seconds, then subtract AI power. Missing mining rows show n/a instead of inventing a crypto return.

Benchmark boundary

The RTX 3090 Qwen result is measured. Other generation rates use reported results, memory bandwidth, architecture estimates, or a named range. Runtime, quantization, context length, and drivers change the result. Legacy warnings cover cards that need pinned drivers, older ROCm, or custom builds.
