**ਗ੍ਰਾਫਿਕਲ ਕੋਡਿੰਗ ਏਜੰਟ** ਕੰਮ ਦੀ ਗੱਲਬਾਤ ਨੂੰ ਫਾਈਲਾਂ, ਡਿਫ, ਡਾਇਗਨੋਸਟਿਕ ਅਤੇ ਐਪਲੀਕੇਸ਼ਨ ਝਲਕਾਂ ਦੇ ਨਾਲ ਰੱਖਦੇ ਹਨ। ਇਹ ਗਾਈਡ Cursor, Windsurf/Cascade ਉਤਪਾਦ ਲੜੀ, VS Code ਵਿੱਚ Cline ਐਕਸਟੈਂਸ਼ਨ, VS Code ਵਿੱਚ GitHub Copilot ਅਤੇ Continue IDE ਐਕਸਟੈਂਸ਼ਨ ਦੀ ਤੁਲਨਾ ਕਰਦੀ ਹੈ। Roo Code ਨੂੰ ਪੁਰਾਣੇ ਮਾਈਗ੍ਰੇਸ਼ਨ ਵਿਕਲਪ ਵਜੋਂ ਦਰਸਾਇਆ ਗਿਆ ਹੈ ਕਿਉਂਕਿ ਦਸਤਾਵੇਜ਼ ਬੰਦ ਹੋਣ ਦੀ ਜਾਣਕਾਰੀ ਦਿੰਦੇ ਹਨ।

**ਮਾਡਲ ਤੋਂ ਪਹਿਲਾਂ ਵਰਕਸਪੇਸ ਚੁਣੋ।** ਸੁਤੰਤਰ ਐਡੀਟਰ ਤੁਹਾਡਾ ਵਿਕਾਸ ਵਾਤਾਵਰਣ ਬਦਲਦਾ ਹੈ। ਐਕਸਟੈਂਸ਼ਨ ਮੌਜੂਦਾ ਐਡੀਟਰ ਵਿੱਚ ਏਜੰਟ ਜੋੜਦੀ ਹੈ। ਬਣੇ ਪੈਚ ਅਤੇ ਉਸ ਦੀ ਜਾਂਚ ਲਈ ਲੱਗਣ ਵਾਲੇ ਕੰਮ ਦੋਵੇਂ ਮਾਪੋ।

## ਮੁੱਖ ਨੁਕਤੇ

- **Cursor ਅਤੇ Windsurf ਲੜੀ** ਪੂਰੇ ਐਡੀਟਰਾਂ ਵਿੱਚ ਆਉਂਦੇ ਹਨ।
- **Cline, Copilot ਅਤੇ Continue** ਮੌਜੂਦਾ ਐਡੀਟਰ ਵਿੱਚ ਏਜੰਟ ਵਰਕਫਲੋ ਦਿੰਦੇ ਹਨ।
- **Roo Code ਨੂੰ ਮਾਈਗ੍ਰੇਸ਼ਨ ਯੋਜਨਾ ਚਾਹੀਦੀ ਹੈ**, ਆਮ ਨਵੀਂ ਤੈਨਾਤੀ ਨਹੀਂ।
- **ਦਿਖਣ ਵਾਲੀਆਂ ਤਬਦੀਲੀਆਂ ਲਈ ਵੀ ਟੈਸਟ**, ਡਿਪੈਂਡੈਂਸੀ ਸਮੀਖਿਆ ਅਤੇ ਸਪਸ਼ਟ ਮਨਜ਼ੂਰੀ ਚਾਹੀਦੀ ਹੈ।

**ਦਾਇਰਾ ਅਤੇ ਮਿਤੀ:** ਅਧਿਕਾਰਤ ਦਸਤਾਵੇਜ਼ 6 ਅਕਤੂਬਰ 2026 ਨੂੰ ਜਾਂਚੇ ਗਏ। ਇਹ ਵਰਕਫਲੋ ਤੁਲਨਾ ਹੈ, ਗਤੀ ਜਾਂ ਕੋਡ ਗੁਣਵੱਤਾ ਬੈਂਚਮਾਰਕ ਨਹੀਂ। ਟਰਮੀਨਲ ਉਤਪਾਦ [CLI ਤੁਲਨਾ](/articles/cli-coding-agents-comparison/) ਵਿੱਚ ਹਨ।

**ਲੋੜਾਂ:** ਮੌਜੂਦਾ ਪ੍ਰੋਜੈਕਟ, ਚੱਲਦੇ ਟੈਸਟ ਅਤੇ ਚੁਣੇ ਐਡੀਟਰ ਜਾਂ ਐਕਸਟੈਂਸ਼ਨ ਨੂੰ ਇੰਸਟਾਲ ਕਰਨ ਦੀ ਆਗਿਆ। ਦੋ ਉਤਪਾਦਾਂ ਦੀ ਜਾਂਚ ਲਈ ਇੱਕ ਦੁਪਹਿਰ ਰੱਖੋ।

## ਮੌਜੂਦਾ ਨਾਮ ਅਤੇ ਸਥਿਤੀ

**Windsurf ਦੇ Cascade ਦਸਤਾਵੇਜ਼ Devin Desktop ਵੱਲ ਭੇਜਦੇ ਹਨ।** ਮੌਜੂਦਾ [Cascade ਹਵਾਲਾ](https://docs.devin.ai/desktop/cascade/cascade) ਇਸਨੂੰ ਹੋਰ ਸਥਾਨਕ ਏਜੰਟ ਦੇ ਨਾਲ Devin Desktop ਵਿੱਚ ਰੱਖਦਾ ਹੈ। ਪੁਰਾਣੇ ਨਾਮ ਨੂੰ ਮੌਜੂਦਾ ਦਸਤਾਵੇਜ਼ ਨਾਲ ਜੋੜਨ ਲਈ ਇਹ ਲੇਖ “Windsurf/Cascade” ਵਰਤਦਾ ਹੈ। ਪੁਰਾਣੇ ਟਿਊਟੋਰਿਅਲ ਤੋਂ ਪਹਿਲਾਂ ਇੰਸਟਾਲ ਉਤਪਾਦ ਅਤੇ ਸਰਗਰਮ ਏਜੰਟ ਜਾਂਚੋ।

**Roo Code ਦਸਤਾਵੇਜ਼ 2026-05-15 ਨੂੰ ਐਕਸਟੈਂਸ਼ਨ ਬੰਦ ਹੋਣ ਦੀ ਜਾਣਕਾਰੀ ਦਿੰਦੇ ਹਨ।** [ਅਧਿਕਾਰਤ ਨੋਟਿਸ](https://roocodeinc.github.io/Roo-Code/) ਵਿਕਲਪਾਂ ਵੱਲ ਭੇਜਦਾ ਹੈ। ਮੌਜੂਦਾ ਕੋਡ ਚੱਲਦੀ ਸੰਭਾਲ ਦਾ ਸਬੂਤ ਨਹੀਂ। ਨਵੀਂ ਤੈਨਾਤੀ ਵਿੱਚ Roo ਨਾ ਵਰਤੋ ਜਦ ਤੱਕ fork, ਮਾਲਕੀ, ਰਿਲੀਜ਼ ਅਤੇ ਸਹਾਇਤਾ ਦੀ ਵੱਖਰੀ ਜਾਂਚ ਨਾ ਕਰੋ।

| ਉਤਪਾਦ ਸਤਹ | ਸ਼੍ਰੇਣੀ | ਸੂਚੀ ਵਿੱਚ ਭੂਮਿਕਾ |
|---|---|---|
| **Cursor ਐਡੀਟਰ** | ਪੂਰਾ ਗ੍ਰਾਫਿਕਲ ਐਡੀਟਰ | ਏਕੀਕ੍ਰਿਤ ਏਜੰਟ ਅਤੇ ਸਮੀਖਿਆ |
| **Windsurf/Cascade** | ਪੂਰੇ ਐਡੀਟਰ ਲੜੀ | Devin Desktop ਵਿੱਚ ਮੌਜੂਦਾ ਵਰਕਫਲੋ |
| **VS Code ਵਿੱਚ Cline** | ਐਡੀਟਰ ਐਕਸਟੈਂਸ਼ਨ | ਪ੍ਰੋਵਾਈਡਰ ਅਤੇ ਟੂਲ ਕੰਮ |
| **VS Code ਵਿੱਚ Copilot** | ਐਡੀਟਰ ਏਕੀਕਰਨ | ਸੁਝਾਅ, ਚੈਟ ਅਤੇ ਏਜੰਟ ਕੰਮ |
| **Continue ਐਕਸਟੈਂਸ਼ਨ** | ਐਡੀਟਰ ਐਕਸਟੈਂਸ਼ਨ | ਮਾਡਲ ਅਤੇ ਟਾਸਕ ਮੋਡ |
| **Roo Code** | ਪੁਰਾਣੀ ਐਕਸਟੈਂਸ਼ਨ | ਮਾਈਗ੍ਰੇਸ਼ਨ ਹਵਾਲਾ, ਸਰਗਰਮ ਸਿਫਾਰਸ਼ ਨਹੀਂ |

## ਪੂਰੇ ਐਡੀਟਰ

**Cursor Agent** ਹਦਾਇਤਾਂ, ਟੂਲ ਅਤੇ ਚੁਣਿਆ ਮਾਡਲ ਜੋੜਦਾ ਹੈ। [ਏਜੰਟ ਝਲਕ](https://cursor.com/docs/agent/overview) ਫਾਈਲ ਤਬਦੀਲੀ, ਟਰਮੀਨਲ, ਬ੍ਰਾਊਜ਼ਰ ਅਤੇ ਚੈਕਪੁਆਇੰਟ ਦਰਜ ਕਰਦੀ ਹੈ। **Cascade** ਕੋਡ ਅਤੇ ਚੈਟ ਮੋਡ, ਐਡੀਟਰ ਸੰਦਰਭ, ਟੂਲ ਅਤੇ ਚੈਕਪੁਆਇੰਟ ਦਿੰਦਾ ਹੈ। ਮਾਈਗ੍ਰੇਸ਼ਨ ਜਾਂਚ ਲਈ ਭਾਸ਼ਾ ਸਹਾਇਤਾ, ਫਾਰਮੈਟਿੰਗ, ਡੀਬੱਗਿੰਗ, ਸ਼ਾਰਟਕੱਟ ਅਤੇ ਐਕਸਟੈਂਸ਼ਨ ਜਾਂਚੋ।

| ਟੈਸਟ | ਸਬੂਤ |
|---|---|
| **ਪ੍ਰੋਜੈਕਟ ਸ਼ੁਰੂਆਤ** | ਬਿਲਡ ਅਤੇ ਲਾਂਚ ਕੰਮ ਚੱਲਦੇ ਹਨ |
| **ਭਾਸ਼ਾ ਟੂਲ** | ਡਾਇਗਨੋਸਟਿਕ ਅਤੇ ਨੇਵੀਗੇਸ਼ਨ ਬੇਸਲਾਈਨ ਨਾਲ ਮਿਲਦੇ ਹਨ |
| **ਏਜੰਟ ਤਬਦੀਲੀ** | ਸਮੀਖਿਆਯੋਗ ਡਿਫ ਵਿੱਚ ਦਿਖਦੀ ਹੈ |
| **ਰਿਕਵਰੀ** | Undo ਮੈਨੂਅਲ ਕੰਮ ਬਚਾਉਂਦਾ ਹੈ |
| **ਐਪ ਜਾਂਚ** | ਟੈਸਟ ਅਤੇ ਵਿਵਹਾਰ ਮਿਲਦੇ ਹਨ |

## ਤੁਹਾਡੇ ਐਡੀਟਰ ਵਿੱਚ ਐਕਸਟੈਂਸ਼ਨ

**Cline ਐਕਸਟੈਂਸ਼ਨ** ਫਾਈਲਾਂ ਪੜ੍ਹਦੀ, ਲਿਖਦੀ ਅਤੇ ਕਮਾਂਡ ਚਲਾਉਂਦੀ ਹੈ। [Cline ਝਲਕ](https://docs.cline.bot/cline-overview) ਪ੍ਰੋਵਾਈਡਰ ਕਰੈਡੈਂਸ਼ਲ ਅਤੇ ਸਥਾਨਕ ਰਨਟਾਈਮ ਦੱਸਦੀ ਹੈ। **GitHub Copilot** ਸੁਝਾਅ, ਚੈਟ ਅਤੇ ਏਜੰਟ ਤਬਦੀਲੀਆਂ ਦਿੰਦਾ ਹੈ। [IDE ਝਲਕ](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-in-ides) ਅਨੁਭਵ ਵੱਖ ਕਰਦੀ ਹੈ। **Continue** Chat, Plan ਅਤੇ Agent ਮੋਡ ਵੱਖ ਕਰਦੀ ਹੈ। [Agent ਸ਼ੁਰੂਆਤ](https://docs.continue.dev/ide-extensions/agent/quick-start) ਪੜ੍ਹਨ-ਮਾਤਰ ਯੋਜਨਾ ਅਤੇ ਟੂਲ ਕਾਰਜ ਸਮਝਾਉਂਦੀ ਹੈ।

## ਸਮੀਖਿਆ ਅਤੇ ਨਿਯੰਤਰਣ

**ਉਪਯੋਗੀ GUI ਫੈਸਲੇ ਦਾ ਆਧਾਰ ਦਿਖਾਉਂਦਾ ਹੈ।** ਬਦਲੀਆਂ ਫਾਈਲਾਂ, ਕਮਾਂਡ ਆਉਟਪੁੱਟ, ਬਾਕੀ ਕੰਮ ਅਤੇ ਦਿਸ਼ਾ ਬਦਲਣ ਦਾ ਤਰੀਕਾ ਵੇਖੋ। **ਮਨਜ਼ੂਰੀ ਅਤੇ ਅੰਤਿਮ ਸਵੀਕ੍ਰਿਤੀ ਵੱਖ ਰੱਖੋ।** ਕਮਾਂਡ ਮਨਜ਼ੂਰ ਕਰਨ ਨਾਲ ਏਜੰਟ ਕੰਮ ਕਰਦਾ ਹੈ। ਪੈਚ ਸਵੀਕਾਰ ਕਰਨ ਦਾ ਮਤਲਬ ਦਾਇਰਾ ਅਤੇ ਵਿਵਹਾਰ ਜਾਂਚਣਾ ਹੈ।

| ਸਵਾਲ | ਜਾਂਚ |
|---|---|
| **ਕੀ ਬਦਲਿਆ?** | ਕੌਂਫਿਗਰੇਸ਼ਨ ਅਤੇ ਲਾਕਫਾਈਲ ਸਮੇਤ ਪੂਰਾ ਡਿਫ |
| **ਕਿਉਂ?** | ਲੋੜ ਅਤੇ ਹਰ ਸੋਧ ਦਾ ਸੰਬੰਧ |
| **ਕੀ ਚੱਲਿਆ?** | ਕਮਾਂਡ, ਐਗਜ਼ਿਟ ਸਥਿਤੀ ਅਤੇ ਆਉਟਪੁੱਟ |
| **ਕੀ ਅਸਫਲ ਹੋਇਆ?** | ਖੁੱਲ੍ਹੀਆਂ ਗਲਤੀਆਂ ਅਤੇ ਛੱਡੇ ਢੰਗ |
| **ਕੀ ਵਾਪਸ ਆ ਸਕਦਾ ਹੈ?** | ਚੈਕਪੁਆਇੰਟ ਅਤੇ Git ਬੇਸਲਾਈਨ |

ਡਿਸਪੋਜ਼ੇਬਲ ਕਾਪੀ ਵਿੱਚ ਬਿਨਾਂ ਕਮਿਟ ਕੀਤੀ ਸੋਧ ਨੂੰ ਰਿਕਵਰੀ ਟੈਸਟ ਬਣਾਓ। ਏਜੰਟ ਤੋਂ ਵੱਖਰੀ ਤਬਦੀਲੀ ਕਰਵਾਓ, ਉਸਨੂੰ ਵਾਪਸ ਕਰੋ ਅਤੇ ਮੂਲ ਸੋਧ ਬਚੀ ਹੈ ਜਾਂ ਨਹੀਂ ਵੇਖੋ।

## ਮਾਡਲ, ਨਿੱਜਤਾ ਅਤੇ ਬਿਲਿੰਗ

**ਐਡੀਟਰ ਵਿੰਡੋ ਇਨਫਰੈਂਸ ਦਾ ਟਿਕਾਣਾ ਨਹੀਂ ਦੱਸਦੀ।** ਮਾਡਲ, ਪ੍ਰੋਵਾਈਡਰ ਖਾਤਾ, ਰਿਪੋਜ਼ਟਰੀ ਇੰਡੈਕਸਿੰਗ, ਟੂਲ ਕਨੈਕਸ਼ਨ ਅਤੇ ਚਲਾਉਣ ਵਾਲਾ ਵਾਤਾਵਰਣ ਦਰਜ ਕਰੋ। ਸਥਾਨਕ ਐਕਸਟੈਂਸ਼ਨ ਅਤੇ ਸਥਾਨਕ ਮਾਡਲ ਵੱਖ ਗੁਣ ਹਨ। ਕੀਮਤ ਨੂੰ ਪਹੁੰਚ ਦੇ ਰਸਤੇ ਨਾਲ ਜੋੜੋ। ਟੀਮ ਲਈ ਮਨਜ਼ੂਰ ਮਾਡਲ, ਕਰੈਡੈਂਸ਼ਲ ਨੀਤੀ, ਰਿਪੋਜ਼ਟਰੀ ਛੋਟ ਅਤੇ ਸਹਾਇਤਾ ਮਾਲਕੀ ਜਾਂਚੋ।
