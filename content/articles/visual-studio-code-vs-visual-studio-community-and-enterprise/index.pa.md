## Visual Studio Code ਵਿਰੁੱਧ Visual Studio Community ਅਤੇ Enterprise: ਕਿਹੜਾ ਸਭ ਤੋਂ ਵਧੀਆ ਹੈ?

### ਪਰਿਚਯ

ਸੌਫਟਵੇਅਰ ਵਿਕਾਸ ਦੀ ਦੁਨੀਆ ਵਿੱਚ, **Visual Studio** ਇੱਕ ਪ੍ਰਸਿੱਧ ਅਤੇ ਵਿਆਪਕ ਤੌਰ 'ਤੇ ਵਰਤਿਆ ਜਾਣ ਵਾਲਾ ਇੰਟੀਗ੍ਰੇਟਿਡ ਡਿਵੈਲਪਮੈਂਟ ਇਨਵਾਇਰਨਮੈਂਟ (IDE) ਹੈ ਜੋ **ਮਾਈਕ੍ਰੋਸੌਫਟ** ਵੱਲੋਂ ਵਿਕਸਿਤ ਕੀਤਾ ਗਿਆ ਹੈ। ਪਰ, Visual Studio ਦਾ ਸਹੀ ਵਰਜਨ ਚੁਣਨ ਵੇਲੇ, ਵਿਕਾਸਕਾਰ ਅਕਸਰ **Visual Studio Code**, **Visual Studio Community**, ਅਤੇ **Visual Studio Enterprise** ਵਿਚਕਾਰ ਸੋਚਦੇ ਹਨ। ਹਰ ਵਰਜਨ ਦੀ ਆਪਣੀ ਵਿਲੱਖਣ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਅਤੇ ਲਕੜੀ ਦਰਸ਼ਕ ਹੈ, ਜਿਸ ਕਰਕੇ ਵਿਕਾਸਕਾਰਾਂ ਲਈ ਇਹ ਸਮਝਣਾ ਜ਼ਰੂਰੀ ਹੈ ਕਿ ਫਰਕ ਕੀ ਹਨ ਅਤੇ ਉਹ ਆਪਣੀਆਂ ਜ਼ਰੂਰਤਾਂ ਲਈ ਸਭ ਤੋਂ ਵਧੀਆ ਚੋਣ ਕਿਹੜੀ ਹੈ।

### [Visual Studio Code: ਹਲਕਾ ਅਤੇ ਬਹੁਪੱਖੀ](https://code.visualstudio.com/)

**Visual Studio Code** ਇੱਕ ਹਲਕਾ ਅਤੇ ਬਹੁਪੱਖੀ ਕੋਡ ਐਡੀਟਰ ਹੈ ਜਿਸ ਨੇ ਹਾਲੀਆ ਸਾਲਾਂ ਵਿੱਚ ਵਿਕਾਸਕਾਰਾਂ ਵਿਚ ਬਹੁਤ ਪ੍ਰਸਿੱਧੀ ਹਾਸਲ ਕੀਤੀ ਹੈ। ਇਹ **ਕ੍ਰਾਸ-ਪਲੇਟਫਾਰਮ** ਹੈ, ਜਿਸਦਾ ਮਤਲਬ ਇਹ ਹੈ ਕਿ ਇਹ Windows, macOS, ਅਤੇ Linux 'ਤੇ ਵਰਤਿਆ ਜਾ ਸਕਦਾ ਹੈ। ਪੂਰੇ IDE ਦੀ ਥਾਂ ਇੱਕ ਕੋਡ ਐਡੀਟਰ ਹੋਣ ਦੇ ਬਾਵਜੂਦ, Visual Studio Code ਵਿਸ਼ਾਲ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਅਤੇ ਕਸਟਮਾਈਜ਼ੇਸ਼ਨ ਵਿਕਲਪ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ। ਇਹ ਕਈ ਪ੍ਰੋਗ੍ਰਾਮਿੰਗ ਭਾਸ਼ਾਵਾਂ ਨੂੰ ਸਹਿਯੋਗ ਦਿੰਦਾ ਹੈ ਅਤੇ **ਸਿੰਟੈਕਸ ਹਾਈਲਾਈਟਿੰਗ**, **ਕੋਡ ਪੂਰਨਤਾ**, ਅਤੇ **ਡੀਬੱਗਿੰਗ ਸਮਰੱਥਾਵਾਂ** ਵਰਗੀਆਂ ਸੁਵਿਧਾਵਾਂ ਮੁਹੱਈਆ ਕਰਵਾਉਂਦਾ ਹੈ।

Visual Studio Code ਦਾ ਇੱਕ ਮੁੱਖ ਫਾਇਦਾ ਇਸ ਦੀ **ਵਿਸਤਾਰਯੋਗਤਾ** ਹੈ। ਇਸਦਾ ਇੱਕ ਧਨਾਢ **ਐਕਸਟੈਂਸ਼ਨ ਇਕੋਸਿਸਟਮ** ਹੈ ਜੋ ਵਿਕਾਸਕਾਰਾਂ ਨੂੰ ਖਾਸ ਪ੍ਰੋਗ੍ਰਾਮਿੰਗ ਭਾਸ਼ਾਵਾਂ, ਫਰੇਮਵਰਕਾਂ ਜਾਂ ਟੂਲਾਂ ਲਈ ਐਕਸਟੈਂਸ਼ਨ ਜੋੜ ਕੇ ਆਪਣਾ ਕੋਡਿੰਗ ਅਨੁਭਵ ਬਿਹਤਰ ਬਣਾਉਣ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ। ਇਹ ਐਕਸਟੈਂਸ਼ਨ ਵਾਧੂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਜਿਵੇਂ ਕਿ **ਲਿੰਟਿੰਗ**, **ਟੈਸਟਿੰਗ**, **ਸੋਰਸ ਕੰਟਰੋਲ ਇੰਟੀਗ੍ਰੇਸ਼ਨ**, ਅਤੇ ਹੋਰ ਪ੍ਰਦਾਨ ਕਰ ਸਕਦੇ ਹਨ। [Visual Studio Marketplace](https://marketplace.visualstudio.com/vscode) ਵਿੱਚ ਐਕਸਟੈਂਸ਼ਨਾਂ ਦਾ ਇੱਕ ਵੱਡਾ ਸੰਗ੍ਰਹਿ ਹੈ ਜਿਸ ਵਿੱਚੋਂ ਵਿਕਾਸਕਾਰ Visual Studio Code ਨੂੰ ਆਪਣੀਆਂ ਖਾਸ ਜ਼ਰੂਰਤਾਂ ਅਨੁਸਾਰ ਅਨੁਕੂਲਿਤ ਕਰ ਸਕਦੇ ਹਨ।

ਇਸਦੀ ਹਲਕੀ ਕੁਦਰਤ ਦੇ ਬਾਵਜੂਦ, Visual Studio Code ਇੱਕ ਸ਼ਕਤੀਸ਼ਾਲੀ ਟੂਲ ਹੈ ਜੋ ਆਸਾਨੀ ਨਾਲ **ਵੱਡੇ ਪੱਧਰ ਦੇ ਪ੍ਰੋਜੈਕਟਾਂ** ਨੂੰ ਸੰਭਾਲ ਸਕਦਾ ਹੈ। ਇਹ Git ਨਾਲ ਇੰਟੀਗ੍ਰੇਟਿਡ **ਵਰਜ਼ਨ ਕੰਟਰੋਲ** ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ, ਜੋ ਸਹਿਯੋਗੀ ਵਿਕਾਸ ਲਈ ਸੁਵਿਧਾਜਨਕ ਹੈ। Visual Studio Code **ਇੰਟੀਗ੍ਰੇਟਿਡ ਟਰਮੀਨਲ** ਸਹਿਯੋਗ ਵੀ ਦਿੰਦਾ ਹੈ, ਜਿਸ ਨਾਲ ਵਿਕਾਸਕਾਰ ਸਿੱਧਾ ਐਡੀਟਰ ਵਿੱਚ ਕਮਾਂਡ ਚਲਾ ਸਕਦੇ ਹਨ ਅਤੇ ਸਕ੍ਰਿਪਟਾਂ ਚਲਾ ਸਕਦੇ ਹਨ। ਇਹ ਜਰੂਰੀ ਵਿਕਾਸ ਟੂਲਾਂ ਦੀ ਸੁਚੱਜੀ ਇੰਟੀਗ੍ਰੇਸ਼ਨ Visual Studio Code ਨੂੰ ਕਈ ਵਿਕਾਸਕਾਰਾਂ ਲਈ ਲੋਕਪ੍ਰਿਯ ਚੋਣ ਬਣਾਉਂਦੀ ਹੈ।

### [Visual Studio Community: ਵਿਅਕਤੀਗਤ ਵਿਕਾਸਕਾਰਾਂ ਅਤੇ ਛੋਟੀਆਂ ਟੀਮਾਂ ਲਈ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਨਾਲ ਭਰਪੂਰ IDE](https://visualstudio.microsoft.com/vs/community/)

**Visual Studio Community** Visual Studio ਦਾ ਇੱਕ **ਮੁਫ਼ਤ, ਪੂਰੀ ਤਰ੍ਹਾਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਵਾਲਾ** ਵਰਜਨ ਹੈ ਜੋ ਵਿਅਕਤੀਗਤ ਵਿਕਾਸਕਾਰਾਂ ਅਤੇ ਛੋਟੀਆਂ ਟੀਮਾਂ ਲਈ ਨਿਸ਼ਾਨਾ ਬਣਾਇਆ ਗਿਆ ਹੈ। ਇਹ ਇੱਕ ਵਿਸ਼ਤ੍ਰਿਤ IDE ਅਨੁਭਵ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ ਅਤੇ ਕਈ ਪ੍ਰੋਗ੍ਰਾਮਿੰਗ ਭਾਸ਼ਾਵਾਂ ਅਤੇ ਪਲੇਟਫਾਰਮਾਂ ਨੂੰ ਸਹਿਯੋਗ ਦਿੰਦਾ ਹੈ। Visual Studio Community ਨਾਲ, ਵਿਕਾਸਕਾਰਾਂ ਕੋਲ **ਉੱਨਤ ਡੀਬੱਗਿੰਗ**, **ਪ੍ਰੋਫਾਈਲਿੰਗ**, ਅਤੇ **ਡਾਇਗਨੋਸਟਿਕ ਟੂਲ** ਹਨ ਜੋ ਵਿਕਾਸ ਅਤੇ ਸਮੱਸਿਆ ਨਿਵਾਰਣ ਪ੍ਰਕਿਰਿਆ ਵਿੱਚ ਮਦਦ ਕਰਦੇ ਹਨ।

Visual Studio Community ਦਾ ਇੱਕ ਮੁੱਖ ਫਾਇਦਾ ਇਸਦੀ ਹੋਰ ਮਾਈਕ੍ਰੋਸੌਫਟ ਟੂਲਾਂ ਅਤੇ ਸੇਵਾਵਾਂ ਨਾਲ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਹੈ। ਇਹ ਕਲਾਉਡ ਵਿਕਾਸ ਲਈ **ਅਜ਼ੂਰ**, ਡੇਟਾਬੇਸ ਪ੍ਰਬੰਧਨ ਲਈ **SQL ਸਰਵਰ**, ਅਤੇ ਹੋਰ ਮਾਈਕ੍ਰੋਸੌਫਟ ਸੇਵਾਵਾਂ ਨਾਲ ਸੁਚੱਜੀ ਤਰ੍ਹਾਂ ਜੁੜਦਾ ਹੈ, ਜਿਸ ਨਾਲ ਇੱਕ ਇਕਜੁੱਟ ਵਿਕਾਸ ਵਾਤਾਵਰਣ ਬਣਦਾ ਹੈ। ਇਹ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਵਿਕਾਸਕਾਰਾਂ ਲਈ ਮਾਈਕ੍ਰੋਸੌਫਟ ਇਕੋਸਿਸਟਮ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਆਪਣੇ ਐਪਲੀਕੇਸ਼ਨਾਂ ਨੂੰ ਬਣਾਉਣਾ, ਤੈਨਾਤ ਕਰਨਾ ਅਤੇ ਪ੍ਰਬੰਧਿਤ ਕਰਨਾ ਆਸਾਨ ਬਣਾਉਂਦਾ ਹੈ।

Visual Studio Community **ਸਹਿਯੋਗੀ ਵਿਕਾਸ** ਲਈ ਭੀ ਮਜ਼ਬੂਤ ਸਹਿਯੋਗ ਦਿੰਦਾ ਹੈ। ਇਸ ਵਿੱਚ Git ਨਾਲ ਬਣਿਆ ਹੋਇਆ **ਵਰਜ਼ਨ ਕੰਟਰੋਲ** ਸਮਰੱਥਾਵਾਂ ਹਨ, ਜੋ ਵਿਕਾਸਕਾਰਾਂ ਨੂੰ ਪ੍ਰੋਜੈਕਟਾਂ 'ਤੇ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਤਰੀਕੇ ਨਾਲ ਮਿਲ ਕੇ ਕੰਮ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ। ਇਸਦੇ ਨਾਲ-ਨਾਲ, Visual Studio Community **ਅਜ਼ੂਰ ਡੈਵਓਪਸ** ਨਾਲ ਜੁੜਦਾ ਹੈ ਜੋ **ਲਗਾਤਾਰ ਇੰਟੀਗ੍ਰੇਸ਼ਨ** ਅਤੇ **ਲਗਾਤਾਰ ਡਿਲਿਵਰੀ** (CI/CD) ਲਈ ਹੈ, ਜਿਸ ਨਾਲ ਟੀਮਾਂ ਆਪਣੇ ਸੌਫਟਵੇਅਰ ਵਿਕਾਸ ਪ੍ਰਕਿਰਿਆਵਾਂ ਨੂੰ ਆਟੋਮੇਟ ਕਰ ਸਕਦੀਆਂ ਹਨ।

### [Visual Studio Enterprise: ਸਕੇਲ ਕਰਨ ਯੋਗ ਅਤੇ ਐਂਟਰਪ੍ਰਾਈਜ਼-ਗਰੇਡ ਵਿਕਾਸ ਪਲੇਟਫਾਰਮ](https://visualstudio.microsoft.com/vs/enterprise/)

**Visual Studio Enterprise** ਮਾਈਕ੍ਰੋਸੌਫਟ ਵੱਲੋਂ ਸਭ ਤੋਂ ਵਿਸ਼ਤ੍ਰਿਤ ਅਤੇ ਐਂਟਰਪ੍ਰਾਈਜ਼-ਗਰੇਡ ਪੇਸ਼ਕਸ਼ ਹੈ। ਇਹ ਵੱਡੇ ਪੱਧਰ ਦੇ ਸੌਫਟਵੇਅਰ ਵਿਕਾਸ ਪ੍ਰੋਜੈਕਟਾਂ ਲਈ ਡਿਜ਼ਾਈਨ ਕੀਤਾ ਗਿਆ ਹੈ ਅਤੇ ਜਟਿਲ ਵਿਕਾਸ ਸਥਿਤੀਆਂ ਲਈ ਉੱਨਤ ਟੂਲ ਅਤੇ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ। Visual Studio Enterprise ਵਿੱਚ Visual Studio Community ਦੀਆਂ ਸਾਰੀਆਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਸ਼ਾਮਲ ਹਨ ਅਤੇ ਵੱਡੀਆਂ ਟੀਮਾਂ ਅਤੇ ਐਂਟਰਪ੍ਰਾਈਜ਼ ਪੱਧਰ ਦੇ ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ ਵਾਧੂ ਸਮਰੱਥਾਵਾਂ ਨਾਲ ਵਧਾਇਆ ਗਿਆ ਹੈ।

Visual Studio Enterprise ਦੀਆਂ ਮੁੱਖ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਵਿੱਚੋਂ ਇੱਕ ਇਸਦੀ **ਪ੍ਰਦਰਸ਼ਨ ਪ੍ਰੋਫਾਈਲਿੰਗ** ਅਤੇ **ਡੀਬੱਗਿੰਗ ਟੂਲ** ਹਨ। ਇਹ ਟੂਲ ਐਪਲੀਕੇਸ਼ਨ ਦੀ ਪ੍ਰਦਰਸ਼ਨ ਨੂੰ ਪ੍ਰਭਾਵਿਤ ਕਰਨ ਵਾਲੀਆਂ ਸਮੱਸਿਆਵਾਂ ਜਿਵੇਂ ਕਿ ਪ੍ਰਦਰਸ਼ਨ ਦੀਆਂ ਰੁਕਾਵਟਾਂ, ਮੈਮੋਰੀ ਲੀਕ, ਅਤੇ ਹੋਰ ਮੁੱਦਿਆਂ ਦੀ ਪਛਾਣ ਅਤੇ ਹੱਲ ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰਦੇ ਹਨ। Visual Studio Enterprise **ਉੱਨਤ ਟੈਸਟਿੰਗ** ਸਮਰੱਥਾਵਾਂ ਵੀ ਦਿੰਦਾ ਹੈ, ਜਿਵੇਂ ਕਿ **ਲੋਡ ਟੈਸਟਿੰਗ** ਅਤੇ **ਆਟੋਮੇਟਿਡ UI ਟੈਸਟਿੰਗ**, ਜੋ ਵਿਕਸਿਤ ਸੌਫਟਵੇਅਰ ਦੀ ਗੁਣਵੱਤਾ ਅਤੇ ਭਰੋਸੇਯੋਗਤਾ ਨੂੰ ਯਕੀਨੀ ਬਣਾਉਂਦੇ ਹਨ।

ਪ੍ਰਦਰਸ਼ਨ ਅਤੇ ਟੈਸਟਿੰਗ ਟੂਲਾਂ ਦੇ ਇਲਾਵਾ, Visual Studio Enterprise **ਆਰਕੀਟੈਕਚਰਲ ਵਿਸ਼ਲੇਸ਼ਣ** ਅਤੇ **ਕੋਡ ਮੈਟ੍ਰਿਕਸ** ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ। ਇਹ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਵਿਕਾਸਕਾਰਾਂ ਨੂੰ ਆਪਣੇ ਕੋਡਬੇਸ ਦੀ ਗੁਣਵੱਤਾ ਅਤੇ ਸੰਭਾਲਯੋਗਤਾ ਦਾ ਮੁਲਾਂਕਣ ਕਰਨ, ਨਿਰਭਰਤਾਵਾਂ ਦੀ ਪਛਾਣ ਕਰਨ, ਅਤੇ ਆਰਕੀਟੈਕਚਰਲ ਦਿਸ਼ਾ-ਨਿਰਦੇਸ਼ਾਂ ਦੀ ਪਾਲਣਾ ਯਕੀਨੀ ਬਣਾਉਣ ਵਿੱਚ ਸਹਾਇਤਾ ਕਰਦੀਆਂ ਹਨ। Visual Studio Enterprise **ਐਂਟਰਪ੍ਰਾਈਜ਼-ਪੱਧਰ ਦਾ ਵਰਜ਼ਨ ਕੰਟਰੋਲ** ਅਤੇ **ਸਹਿਯੋਗੀ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ** ਵੀ ਸਹਿਯੋਗ ਦਿੰਦਾ ਹੈ, ਜਿਵੇਂ ਕਿ **ਕੋਡ ਸਮੀਖਿਆਵਾਂ**, **ਟਾਸਕ ਪ੍ਰਬੰਧਨ**, ਅਤੇ **ਟੀਮ ਡੈਸ਼ਬੋਰਡ**, ਜੋ ਵੱਡੀਆਂ ਵਿਕਾਸ ਸੰਸਥਾਵਾਂ ਵਿੱਚ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਟੀਮ ਵਰਕ ਨੂੰ ਸਹੂਲਤ ਦਿੰਦੇ ਹਨ।

### ਨਤੀਜਾ

ਸਾਰ ਵਿੱਚ, Visual Studio Code, Visual Studio Community, ਅਤੇ Visual Studio Enterprise ਵਿੱਚ ਚੋਣ ਆਖ਼ਿਰਕਾਰ ਵਿਕਾਸਕਾਰਾਂ ਅਤੇ ਸੰਗਠਨਾਂ ਦੀਆਂ ਖਾਸ ਜ਼ਰੂਰਤਾਂ ਅਤੇ ਮੰਗਾਂ 'ਤੇ ਨਿਰਭਰ ਕਰਦੀ ਹੈ।

- **Visual Studio Code** ਉਹਨਾਂ ਵਿਕਾਸਕਾਰਾਂ ਲਈ ਬਹੁਤ ਵਧੀਆ ਚੋਣ ਹੈ ਜੋ ਇੱਕ ਹਲਕਾ-ਫੁਲਕਾ, ਕਸਟਮਾਈਜ਼ੇਬਲ ਕੋਡ ਐਡੀਟਰ ਚਾਹੁੰਦੇ ਹਨ ਜਿਸ ਵਿੱਚ ਵਿਸ਼ਾਲ ਐਕਸਟੈਂਸ਼ਨ ਇਕੋਸਿਸਟਮ ਹੋਵੇ।
- **Visual Studio Community** ਉਹਨਾਂ ਵਿਅਕਤੀਗਤ ਵਿਕਾਸਕਾਰਾਂ ਅਤੇ ਛੋਟੀਆਂ ਟੀਮਾਂ ਲਈ ਆਦਰਸ਼ ਹੈ ਜਿਨ੍ਹਾਂ ਨੂੰ ਪੂਰੀ ਤਰ੍ਹਾਂ ਫੀਚਰ-ਭਰਪੂਰ IDE ਅਤੇ ਮਾਈਕਰੋਸਾਫਟ ਟੂਲਜ਼ ਅਤੇ ਸੇਵਾਵਾਂ ਨਾਲ ਸੁਚੱਜਾ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਚਾਹੀਦਾ ਹੈ।
- **Visual Studio Enterprise** ਵੱਡੇ ਪੱਧਰ ਦੇ ਵਿਕਾਸ ਪ੍ਰੋਜੈਕਟਾਂ ਲਈ ਹੈ ਅਤੇ ਪ੍ਰਦਰਸ਼ਨ ਪ੍ਰੋਫਾਈਲਿੰਗ, ਟੈਸਟਿੰਗ, ਆਰਕੀਟੈਕਚਰਲ ਵਿਸ਼ਲੇਸ਼ਣ ਅਤੇ ਸਹਿਯੋਗ ਲਈ ਉੱਨਤ ਟੂਲਜ਼ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ।

ਹਰ ਵਰਜਨ ਦੇ ਫਰਕਾਂ ਅਤੇ ਸਮਰੱਥਾਵਾਂ ਨੂੰ ਸਮਝ ਕੇ, ਵਿਕਾਸਕਾਰ ਸੂਚਿਤ ਫੈਸਲਾ ਕਰ ਸਕਦੇ ਹਨ ਅਤੇ ਆਪਣੀ ਉਤਪਾਦਕਤਾ ਵਧਾਉਣ ਅਤੇ ਵਿਕਾਸ ਕਾਰਜ ਪ੍ਰਵਾਹ ਨੂੰ ਸੁਧਾਰਨ ਲਈ ਸਹੀ ਟੂਲ ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦੇ ਹਨ।
