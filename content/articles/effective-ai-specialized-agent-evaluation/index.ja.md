[実践的な AI ワークフローコースに戻る](/effective-ai-course-start/)

**タスクと必要なアクセス権に基づいて、特化型エージェントを選びましょう。** 1 つのファイルを確認する作業エージェントは、メッセージを受け取り、メモリーを保存し、予定されたアクションを実行する継続稼働型システムとは異なります。この任意レッスンでは OpenClaw と Hermes Agent を例にし、インストール前の評価ワークシートを紹介します。

**学習目標：** エージェントのアクセス権とトリガーを比較し、範囲を限定したパイロットの判断を記録します。

## 要点

- **役割を限定した作業エージェント：** 1 つの質問または成果物を担当するエージェント。
- **継続稼働型エージェント：** 状態を保持する、または後続のトリガーに応答するサービスやセッション。
- **トリガー：** 作業を開始するイベント、メッセージ、またはスケジュール。
- **アクセス一覧：** エージェントに与えるツール、アカウント、ファイル、書き込み権限の一覧。
- **パイロット判断：** 拒否する、限定的な試験を行う、または用途を定めて承認する。

## 始める前に

**前提条件：** [委任](/articles/effective-ai-agent-delegation/)、[範囲を限定したエージェントループ](/articles/effective-ai-bounded-agent-loops/)、架空のユースケース。所要時間は 35 分です。難易度は中級です。このレッスンでは継続稼働型エージェントをインストールする必要はありません。

**ユースケース：** ワークショップの調整担当者が、アシスタントに予定表を読み、リマインダーの下書きを作成してほしいと考えています。この依頼はリマインダーの送信を許可していません。評価ではこの境界を維持してください。

## 役割を比較する

| 方法 | 典型的なタスク | 最初に確認すること |
|---|---|---|
| **単一チャット** | リマインダーを 1 件作成する | 予定表は用意されているか |
| **読み取り専用エージェント** | 予定表の事実を独立して確認する | どの情報源を読むべきか |
| **コーディングエージェント** | ローカルのレポートプログラムを更新する | 対象となるファイルとテストは何か |
| **継続稼働型プラットフォーム** | メッセージや予定に長期的に反応する | どのトリガー、ツール、保存状態が存在するか |

**OpenClaw** は、ゲートウェイ、メッセージングチャネル、ツール、メモリー、MCP 接続、サブエージェントを備えたオープンソースのエージェントプラットフォームです。これらの構成要素は[概要](https://docs.openclaw.ai/start/why-openclaw)、[MCP 接続ガイド](https://docs.openclaw.ai/tools/mcp)、[サブエージェントガイド](https://docs.openclaw.ai/tools/subagents)で説明されています。パイロット前に、実際に有効なチャネル、ツール、サンドボックス設定を確認してください。

**Hermes Agent** は Nous Research のエージェントアプリケーションです。Hermes モデルファミリーとは別のものです。[ドキュメント](https://hermes-agent.nousresearch.com/docs/)、[委任ガイド](https://hermes-agent.nousresearch.com/docs/user-guide/features/delegation)、[設定ガイド](https://hermes-agent.nousresearch.com/docs/user-guide/configuration/)では CLI、メッセージング、ツール、メモリー、委任タスクを扱っています。[メモリーガイド](https://hermes-agent.nousresearch.com/docs/user-guide/features/memory/)ではローカルストアと書き込み承認を説明しています。`memory.write_approval` と `skills.write_approval` の文書上の既定値は `false` です。書き込み確認が必要なパイロットでは承認を有効にするか、該当ストアを無効にしてください。どちらの制御に依存する場合も、実行中の設定を確認してください。

| 評価項目 | OpenClaw | Hermes Agent |
|---|---|---|
| **入口** | ゲートウェイと接続済みチャネル | CLI または設定済みメッセージング画面 |
| **委任作業** | プラットフォーム固有のセッション規則とツール規則を持つサブエージェント | プラットフォーム固有のツール規則を持つ委任タスク |
| **継続状態** | 有効なメモリーとセッションストレージを確認する | メモリーやプロファイルの設定とスキルの書き込みを確認する |
| **定期作業** | 設定済みのトリガーとスケジュールを確認する | [cron ジョブ](https://hermes-agent.nousresearch.com/docs/user-guide/features/cron/)とゲートウェイの状態を確認する |
| **最初のパイロット** | 選択したチャネルから手動で 1 件依頼する | CLI またはメッセージングから手動で 1 件依頼する |

この表は確認項目を示すもので、同等のセキュリティ既定値を示すものではありません。実データやアカウントへのアクセスを許可する前に、インストール済みバージョンと有効な設定を記録してください。

**名称だけでは共通の権限モデルは分かりません。** ある製品の「サブエージェント」は、別製品の作業エージェントとは異なるファイル、ツール、履歴を受け取る場合があります。ツール間で前提を流用せず、インストール済みバージョンのドキュメントと有効な設定を確認してください。

## アクセスワークシートを記入する

**システムのインストールや接続前に、機能ごとに 1 行記入します。** 製品を使える場合は実際の設定を使ってください。推測せず「不明」と記入します。

| 質問 | ワークショップパイロットの回答 |
|---|---|
| **タスク** | 合成データの予定表からリマインダーを作成する |
| **入力** | 承認済みの予定表ファイル 1 件 |
| **ファイル** | 予定表を読み取る。書き込み権限は付与しない |
| **外部ツール** | 最初のパイロットでは使わない |
| **アカウントアクセス** | メールやカレンダーのアカウントを使わない |
| **トリガー** | 手動依頼のみ |
| **メモリーとスキルの書き込み** | 有効な設定を記録し、ストアを無効にするか、パイロット中の書き込み承認を必須にする |
| **ログ** | 保存先、保持ルール、プロンプト、ソースの版、下書きを記録する |
| **確認** | 人が日付、時刻、場所、宛先一覧を確認する |
| **ロールバック** | 下書きを破棄してパイロットを無効にする |

**データフローもワークシートの一部です。** 入力がどこでコンピューターの外に出るのか、どのプロバイダーが処理するのか、会話記録やメモリーがどこに残るのかを記録します。ツールをメールに接続する場合は、読み取り、下書き作成、送信のどれを行うか記録してください。これらは別々の権限です。

## パイロットを判断する

**拒否：** 下書きだけのタスクなのに、エージェントがメールボックスへの広範な書き込み権限を必要とする場合、またはトリガーやログが不明な場合です。不適切な選択を拒否するために、インストールは必要ありません。

**パイロット：** 入力を合成予定表に限定し、手動トリガーを使い、送信を無効にして、下書きを 1 件確認します。期待する結果は、19 時という正しい時刻で、メッセージが送信されないことです。パイロットを実行した場合は、自分の観察結果を記録してください。

**用途を定めて承認：** パイロットが確認項目を満たし、責任者が正確なアクセス権、トリガー、保持期間、確認手順に同意した後に限ります。下書き作成の承認は、送信や後日の自動化を許可しません。

## 失敗を調べる

**リマインダーの下書きに 18 時と書かれているとします。** エージェントが最新の予定表を読んだか、保存されたメモリーや古いメッセージが古い時刻を渡したかを確認してください。古い入力を置き換え、手動パイロットを 1 回再実行し、送信は無効のままにします。2 回目の下書きが正しくても、最初の失敗を記録から消してはいけません。

**設定に MCP 接続が表示されているのに、ツールを利用できないとします。** [MCP 接続の状態](/articles/effective-ai-mcp-server-setup/)に戻ってください。サーバー設定が保存されているだけでは、読み取りに成功した証拠になりません。

## 練習して確認する

**成果物：** アクセスワークシートを完成させ、拒否、パイロット、用途を定めて承認のいずれかを選びます。トリガー、権限の境界、データフローに関する質問、エージェントを停止する方法を 1 つずつ記入してください。

**完了確認：** 別の読者が、エージェントの動作、読み取りと保存の対象、実行時期、結果の確認者、無効化の方法を把握できる必要があります。不明な項目があれば、拒否するか、より限定したパイロットを選びます。

## 理解度を確認する

1. **質問：** リマインダーの下書きだけを作るタスクに、メール送信権限は必要ですか。**回答：** いいえ。送信はパイロットの範囲外にします。
2. **質問：** 書き込みを制御するパイロットの前に、Hermes のどの設定を確認すべきですか。**回答：** 承認制御を含め、メモリーとスキルの有効な書き込み設定を確認します。
