[व्यावहारिक AI वर्कफ़्लो कोर्स पर लौटें](/effective-ai-course-start/)

**एजेंट का इस्तेमाल करने से पहले सुरक्षित अभ्यास जगह तैयार करें।** पाठ 1 और 2 इस लैब के बिना ब्राउज़र में किए जा सकते हैं। पूरा कोर्स करना हो तो पाठ 3 से पहले यहाँ लौटें। कोडिंग के अभ्यास वाले पाठों में Git, Python 3.10 या नया संस्करण और एक कोडिंग एजेंट इस्तेमाल होता है। अध्ययन मार्ग में उपलब्ध न होने वाली एजेंट कार्रवाइयों की जगह चिह्नित मैन्युअल काम दिया गया है।

**सीखने का लक्ष्य:** आप शुरुआती लैब चलाएँगे, स्थानीय आधार स्थिति सहेजेंगे और उपयोग के बाद वाली प्रति रीसेट करना समझाएँगे।

## मुख्य बातें

- **ब्राउज़र मार्ग:** ChatGPT या Claude में चैट, योजना, स्रोत-जाँच और समीक्षा के अभ्यास पूरे करें।
- **स्थानीय मार्ग:** कोडिंग अभ्यास के लिए टर्मिनल और दी गई Python लैब इस्तेमाल करें।
- **रीसेट मार्ग:** अभ्यास विफल होने पर लैब की नई प्रति निकालें।
- **सुरक्षा नियम:** निजी फ़ाइलें, ग्राहक रिकॉर्ड और लॉगिन जानकारी लैब से बाहर रखें।

## अपना मार्ग चुनें

| मार्ग | ज़रूरत | अभ्यास |
|---|---|---|
| **ब्राउज़र परिचय** | मौजूदा ब्राउज़र और ChatGPT या Claude खाता | पाठ 1 और 2, साथ में पाठ 1 का चैट कार्य-पैकेट |
| **स्थानीय अभ्यास** | Git, Python 3.10 या नया, टर्मिनल और एक कोडिंग एजेंट | फ़ाइलें, अंतर, परीक्षण और एजेंट के संपादन |
| **अध्ययन कोर्स** | ब्राउज़र, स्थानीय Python 3.10 या नया, और Git | लैब की सभी जाँचें; अनुपलब्ध एजेंट और MCP चरणों को नहीं चलाया गया चिह्नित करें |

**हर उत्पाद अपनी योजनाएँ और सीमाएँ तय करता है।** किसी सुविधा पर निर्भर होने से पहले [ChatGPT Projects](https://help.openai.com/en/articles/10169521-projects-in-chatgpt) और [Claude Projects](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects) देखें। अध्ययन मार्ग किसी अनुपलब्ध कोडिंग एजेंट के व्यावहारिक कौशल को साबित नहीं करता। अपनी पूर्णता टिप्पणियों में यह अंतर दर्ज करें।

**एक तय रास्ता अपनाएँ:** चैट अभ्यास के लिए ब्राउज़र में ChatGPT, फिर स्थानीय लैब के साथ कोई उपलब्ध कोडिंग एजेंट। चैट के लिए Claude समान विकल्प है। कोडिंग चरण में Codex CLI, Claude Code CLI या OpenCode चुनें। सभी विक्रेताओं के खाते आवश्यक नहीं हैं।

**कोडिंग एजेंट खोलने से पहले पाँच शुरुआती जाँचें दर्ज करें।** इससे स्थानीय लैब की जाँच और किसी खाते या होस्ट किए गए कार्यक्षेत्र के दावे में अंतर रहता है।

| जाँच | दर्ज करें |
|---|---|
| **कार्यस्थान** | निकाले गए लैब फ़ोल्डर का सटीक पथ जिसे एजेंट पढ़ेगा |
| **निष्पादन** | स्थानीय कंप्यूटर या चुना हुआ दूरस्थ कार्यस्थान |
| **प्रदाता** | इस काम में इस्तेमाल खाता या मॉडल प्रदाता |
| **अनुमतियाँ** | फ़ाइल लिखना और शेल कमांड चलाना अनुमत है या स्वीकृति चाहिए |
| **आधार स्थिति** | बदलाव से पहले दिखी संख्या और पास हुए दो परीक्षण |

**अभ्यास का मूल फ़ोल्डर सीमित रखें।** होस्ट किए गए कार्यस्थान में सिंथेटिक लैब की अलग प्रति चाहिए। स्थानीय रन से यह साबित नहीं होता कि दूरस्थ प्रति या खाते में वही फ़ाइलें और अनुमतियाँ हैं।

## स्थानीय शब्द सीखें

| शब्द | आसान अर्थ |
|---|---|
| **टर्मिनल** | वह ऐप जिसमें आप कमांड लिखते हैं |
| **शेल** | वह सॉफ़्टवेयर जो कमांड समझता है |
| **CLI** | प्रोग्राम का कमांड-लाइन इंटरफ़ेस |
| **कार्य निर्देशिका** | वह फ़ोल्डर जिसे कमांड डिफ़ॉल्ट रूप से इस्तेमाल करती है |
| **रिपॉज़िटरी** | Git द्वारा ट्रैक किया गया प्रोजेक्ट |
| **कमिट** | सहेजा हुआ Git स्नैपशॉट |
| **ब्रांच** | Git बदलावों की नामित शृंखला |
| **डिफ़** | जोड़ी या हटाई गई पंक्तियों का दृश्य |
| **परीक्षण** | अपेक्षित व्यवहार की बार-बार चलने वाली जाँच |
| **एक्ज़िट कोड** | कमांड की सफलता या विफलता बताने वाली संख्या |

**शुरुआती लैब के लिए GitHub की ज़रूरत नहीं।** Git आपके कंप्यूटर पर चलता है। GitHub अलग होस्टिंग सेवा है। स्थानीय कमिट फ़ाइलें कहीं भेजे बिना स्नैपशॉट सहेजता है।

## लैब तैयार करें

**[कोर्स की शुरुआती लैब डाउनलोड करें](/downloads/effective-ai-course-lab.zip)** और उसे अपने नियंत्रण वाले नए फ़ोल्डर में निकालें। उसी फ़ोल्डर में टर्मिनल खोलें। macOS या Linux पर Terminal खोलें और `cd` से निकाले फ़ोल्डर में जाएँ। Windows पर PowerShell या Windows Terminal और `cd` इस्तेमाल करें। Windows में Python कमांड अक्सर `python3` की जगह `py -3` होती है।

**ज़रूरत होने पर [Python 3.10 या नया](https://www.python.org/downloads/) और [Git](https://git-scm.com/downloads) इंस्टॉल करें।** लैब चलाने से पहले इंस्टॉल किए औज़ार जाँचें। शुरुआती दो कमांड संस्करण दिखाते हैं। `cd` कार्य निर्देशिका बदलता है। `ls` फ़ाइलों की सूची देता है। उदाहरण पथ को निकाले फ़ोल्डर के असली पथ से बदलें।

```bash
python3 --version
git --version
cd /path/to/effective-ai-course-lab
ls
```

**Windows PowerShell में,** `py -3 --version`, `git --version`, `cd C:\path\to\effective-ai-course-lab` और `Get-ChildItem` चलाएँ। सूची में `task_report.py`, `tasks.json`, `tests` और `docs` होने चाहिए। संस्करण कमांड विफल हो तो आगे बढ़ने से पहले इंस्टॉलेशन पूरा करें।

```bash
pwd
python3 task_report.py tasks.json
python3 -m unittest discover -s tests -v
```

**Windows PowerShell में,** चाहें तो `pwd` की जगह `Get-Location` इस्तेमाल करें और Python लॉन्चर इस्तेमाल करता हो तो `python3` की जगह `py -3` चलाएँ। पहली कमांड पथ दिखाती है। उसका अंत निकाले गए लैब फ़ोल्डर से होना चाहिए। फ़ाइल नाम भी जाँचें। `AGENTS.md.txt`, `AGENTS.md` की जगह नहीं लेती। Windows Explorer में फ़ाइल नाम एक्सटेंशन चालू करें ताकि पूरा नाम दिखे।

**अपेक्षित आउटपुट:** रिपोर्ट में `Total tasks: 4` आता है। परीक्षण कमांड दो परीक्षणों के नाम दिखाती है और `OK` पर समाप्त होती है। सफलता पर शेल एक्ज़िट कोड शून्य लौटाता है। अलग संख्या या traceback मिले तो फ़ोल्डर और Python सेटअप जाँचें।

**कमांड के हिस्से समझें।** `python3 task_report.py tasks.json` में `python3` Python शुरू करता है, `task_report.py` प्रोग्राम है और `tasks.json` इनपुट डेटा बताता है। छपी संख्या आउटपुट है, अगली कमांड नहीं। विफलता के बाद macOS और Linux `echo $?` से स्थिति दिखाते हैं। PowerShell आखिरी नेटिव प्रोग्राम की स्थिति `$LASTEXITCODE` में देता है।

**Python इंस्टॉल होने के बाद पहली बार के लिए करीब दस मिनट रखें:** लैब निकालें, रिपोर्ट चलाएँ और कुल संख्या को `tasks.json` की चार प्रविष्टियों से मिलाएँ। JSON फ़ाइल टेक्स्ट एडिटर में खोलकर प्रविष्टियाँ खुद गिनें।

## Git का सुरक्षित अभ्यास करें

**Git केवल निकाले गए लैब फ़ोल्डर में शुरू करें।** ये कमांड स्थानीय स्नैपशॉट सहेजती हैं। `git status` बदली हुई फ़ाइलें दिखाता है। ट्रैक की गई फ़ाइल संपादित करने के बाद `git diff` बदली हुई पंक्तियाँ दिखाता है।

```bash
git init
git add .
git commit -m "कोर्स लैब आधार स्थिति"
git status --short
```

**अपेक्षित स्थिति:** कमिट के बाद कोई फ़ाइल नाम नहीं दिखता। Git नाम और ईमेल माँगे तो इसी फ़ोल्डर में केवल लैब के लिए पहचान सेट करें और कमिट दोबारा चलाएँ। उदाहरण के मान अपनी निजी जानकारी से बदलें। पहचान या लॉगिन जानकारी सार्वजनिक चैट में न चिपकाएँ।

```bash
git config --local user.name "कोर्स का विद्यार्थी"
git config --local user.email "learner@example.invalid"
git commit -m "कोर्स लैब आधार स्थिति"
git status --short
```

**रीसेट के लिए Git कमांड नहीं चाहिए।** नोट लैब के बाहर सहेजें, निकाली गई अभ्यास प्रति हटाएँ और मूल ZIP फिर से निकालें। पाठ में बदलाव के बाद प्रोग्राम की स्थिति पता न हो तो यह तरीका अपनाएँ।

## अभ्यास की जगह सुरक्षित रखें

**सिंथेटिक उदाहरण इस्तेमाल करें।** निजी दस्तावेज़ कोर्स प्रोजेक्ट पर अपलोड न करें। API कुंजियाँ प्रॉम्प्ट, स्रोत फ़ाइलों, स्क्रीनशॉट या कमिट में न रखें। एजेंट की फ़ाइल और कमांड पहुँच अनुमतियों तथा खुले फ़ोल्डर पर निर्भर करती है। उसे चलाने से पहले दोनों जाँचें।

**अपलोड से पहले साझा करने की जाँच करें।** प्रोजेक्ट सदस्यों को फ़ाइलों तक पहुँच मिल सकती है। असली काम में अपने संगठन की नीति मानें। कोर्स काल्पनिक डेटा इस्तेमाल करता है, इसलिए लैब के लिए विशेष स्वीकृति की ज़रूरत नहीं।

## अभ्यास और जाँच

**आपका परिणाम:** चुना मार्ग, पाँच शुरुआती फ़ील्ड, रिपोर्ट की संख्या, परीक्षण का परिणाम और रीसेट तरीका दर्ज करें। नई लैब प्रति से पुष्टि करें कि आप रीसेट कर सकते हैं।

**अपेक्षित समझ:** आप जानते हैं कि कमांड किस फ़ोल्डर पर असर डालती है, स्थानीय Git और होस्टिंग का अंतर समझते हैं और एजेंट द्वारा फ़ाइल संपादन से पहले बहाली का तरीका रखते हैं।

## अपनी समझ जाँचें

1. **प्रश्न:** क्या केवल ब्राउज़र वाला परिचय स्थानीय लैब मार्ग पूरा करता है? **उत्तर:** नहीं। पूरे मार्ग के लिए स्थानीय Python और Git आधार स्थिति चाहिए।

2. **प्रश्न:** उपयोग के बाद फेंकने वाली लैब बदलने से पहले क्या सहेजें? **उत्तर:** शुरुआती परीक्षण का पास परिणाम और साफ़ रीसेट बिंदु।

## समस्या निवारण

- **Python कमांड नहीं मिलती:** आधिकारिक वितरक से Python 3 इंस्टॉल करें और टर्मिनल फिर खोलें।
- **फ़ाइल नहीं मिली:** कार्य निर्देशिका जाँचें और निकाले फ़ोल्डर की फ़ाइलें सूचीबद्ध करें।
- **परीक्षण नहीं चलते:** निकाली गई लैब के README में दी गई सटीक कमांड चलाएँ।
- **Git कमिट पहचान माँगे:** Git स्थानीय रूप से सेट करें और चुने गए मान कोर्स नोट्स से बाहर रखें।
