[Вернуться к практическому курсу по рабочим процессам с ИИ](/effective-ai-course-start/)

**Подготовьте безопасное место для практики до запуска агента.** Уроки 1 и 2 можно пройти в браузере без этой лаборатории. Вернитесь сюда перед уроком 3, если хотите пройти весь курс. Для практических занятий по программированию нужны Git, Python 3.10 или новее и один агент программирования. В учебном маршруте недоступные действия агента заменены отмеченными ручными заданиями.

**Результат обучения:** вы запустите начальную лабораторию, сохраните локальную исходную точку и объясните, как сбросить временную копию.

## Главное

- **Маршрут в браузере:** выполните упражнения по чату, планированию, проверке источников и рецензированию в ChatGPT или Claude.
- **Локальный маршрут:** используйте терминал и предоставленную лабораторию Python для заданий по программированию.
- **Сброс:** распакуйте новую копию лаборатории, если упражнение пошло не так.
- **Правило безопасности:** не храните в лаборатории личные файлы, данные клиентов и учетные данные.

## Выберите маршрут

| Маршрут | Что нужно | Практика |
|---|---|---|
| **Введение в браузере** | Современный браузер и аккаунт ChatGPT или Claude | Уроки 1 и 2, а также пакет заданий для чата из урока 1 |
| **Практика локально** | Git, Python 3.10 или новее, терминал и один агент программирования | Файлы, различия, тесты и изменения агента |
| **Учебный курс** | Браузер, локальные Python 3.10 или новее и Git | Все проверки лаборатории; недоступные шаги агента и MCP отмечены как невыполненные |

**Планы и ограничения каждый продукт определяет сам.** Перед использованием функции проверьте [ChatGPT Projects](https://help.openai.com/en/articles/10169521-projects-in-chatgpt) и [Claude Projects](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects). Учебный маршрут не подтверждает практическое владение недоступным агентом программирования. Зафиксируйте это различие в итоговых заметках.

**Используйте один основной путь:** ChatGPT в браузере для упражнений с чатом, затем доступный агент программирования с локальной лабораторией. Claude подходит для чата на тех же условиях. На этапе программирования можно выбрать Codex CLI, Claude Code CLI или OpenCode. Аккаунты у всех поставщиков не нужны.

**Запишите пять предварительных проверок перед запуском агента программирования.** Это отделяет проверку локальной лаборатории от утверждения об аккаунте или размещенной рабочей среде.

| Проверка | Запишите |
|---|---|
| **Рабочая среда** | Точную папку распакованной лаборатории, которую прочитает агент |
| **Выполнение** | Локальный компьютер или выбранную удаленную среду |
| **Поставщик** | Аккаунт или поставщика модели для этой задачи |
| **Разрешения** | Разрешены ли запись файлов и команды оболочки или требуется одобрение |
| **Исходная точка** | Наблюдаемое количество задач и два успешных теста до правок |

**Ограничьте корневую папку практики.** Для размещенной среды нужна отдельная копия синтетической лаборатории. Локальный запуск не доказывает, что удаленная копия или аккаунт имеют те же файлы и разрешения.

## Изучите местные термины

| Термин | Простое значение |
|---|---|
| **Терминал** | Приложение для ввода команд |
| **Оболочка (shell)** | Программа, интерпретирующая команды |
| **CLI** | Интерфейс командной строки программы |
| **Рабочий каталог** | Папка, которую команда использует по умолчанию |
| **Репозиторий** | Проект, отслеживаемый Git |
| **Коммит** | Сохраненный снимок состояния Git |
| **Ветка** | Именованная линия изменений Git |
| **Различия** | Просмотр добавленных и удаленных строк |
| **Тест** | Повторяемая проверка ожидаемого поведения |
| **Код завершения** | Число, сообщающее об успехе или сбое команды |

**Для начальной лаборатории GitHub не нужен.** Git работает на вашем компьютере. GitHub — отдельный сервис размещения. Локальный коммит сохраняет снимок, не отправляя файлы куда-либо.

## Подготовьте лабораторию

**Скачайте [начальную лабораторию курса](/downloads/effective-ai-course-lab.zip)** и распакуйте в новую папку под вашим контролем. Откройте терминал в этой папке. В macOS или Linux откройте Terminal и перейдите в распакованный каталог командой `cd`. В Windows используйте PowerShell или Windows Terminal и `cd`. В Windows вместо `python3` часто используется `py -3`.

**При необходимости установите [Python 3.10 или новее](https://www.python.org/downloads/) и [Git](https://git-scm.com/downloads).** Перед запуском лаборатории проверьте установленные программы. Первые две команды выводят версии. `cd` меняет рабочую папку. `ls` выводит список файлов. Замените пример пути на фактический путь распакованной папки.

```bash
python3 --version
git --version
cd /path/to/effective-ai-course-lab
ls
```

**В Windows PowerShell** выполните `py -3 --version`, `git --version`, `cd C:\path\to\effective-ai-course-lab` и `Get-ChildItem`. В списке должны быть `task_report.py`, `tasks.json`, `tests` и `docs`. Если команда версии не сработала, сначала завершите установку.

```bash
pwd
python3 task_report.py tasks.json
python3 -m unittest discover -s tests -v
```

**В Windows PowerShell** замените `pwd` на `Get-Location`, если так удобнее, а `python3` на `py -3`, если Python установлен с лаунчером. Первая команда показывает путь. В конце должна быть папка распакованной лаборатории. Проверьте и имена файлов. Файл `AGENTS.md.txt` не заменяет `AGENTS.md`. В Проводнике Windows включите отображение расширений, чтобы видеть полное имя.

**Ожидаемый вывод:** отчет содержит `Total tasks: 4`. Команда тестирования показывает два теста и заканчивается строкой `OK`. При успехе оболочка возвращает код 0. Другое число или traceback означает, что нужно проверить папку и настройку Python.

**Разберите команду на части.** В `python3 task_report.py tasks.json` команда `python3` запускает Python, `task_report.py` — программа, а `tasks.json` указывает входные данные. Напечатанное число — результат, а не следующая команда. После ошибки macOS и Linux показывают состояние с помощью `echo $?`. PowerShell предоставляет статус последней нативной программы через `$LASTEXITCODE`.

**После установки Python выделите около десяти минут на первый запуск:** распакуйте лабораторию, запустите отчет и сравните число с четырьмя записями в `tasks.json`. Откройте JSON в текстовом редакторе и пересчитайте записи вручную.

## Безопасно практикуйте Git

**Запускайте Git только в распакованной папке лаборатории.** Эти команды сохраняют локальный снимок. `git status` показывает измененные файлы. `git diff` показывает строки, измененные в отслеживаемом файле.

```bash
git init
git add .
git commit -m "Базовый снимок лаборатории курса"
git status --short
```

**Ожидаемое состояние:** после коммита имена файлов не выводятся. Если Git просит имя и электронную почту, задайте идентификатор только для лаборатории из этой папки и повторите коммит. Замените пример личными значениями. Не вставляйте сведения об идентичности или учетные данные в общедоступный чат.

```bash
git config --local user.name "Учащийся курса"
git config --local user.email "learner@example.invalid"
git commit -m "Базовый снимок лаборатории курса"
git status --short
```

**Для сброса команды Git не нужны.** Сохраните заметки за пределами лаборатории, удалите распакованную копию и снова распакуйте исходный ZIP. Используйте этот способ, если изменение в уроке оставило программу в неизвестном состоянии.

## Защитите место для практики

**Используйте синтетические примеры.** Не загружайте личные документы в проект курса. Не помещайте ключи API в запросы, исходники, снимки экрана или коммиты. Доступ агента к файлам и командам зависит от его разрешений и открытой папки. Проверьте оба пункта до запуска.

**Перед загрузкой проверьте настройки общего доступа.** Файлы проекта могут быть видны его участникам. При реальной работе соблюдайте правила организации. В курсе используются вымышленные данные, поэтому для самой лаборатории отдельное одобрение не требуется.

## Практика и проверка

**Ваш результат:** запишите выбранный маршрут, пять полей предварительной проверки, количество задач из отчета, результат тестов и способ сброса. Возьмите новую копию лаборатории и проверьте, что умеете ее сбросить.

**Ожидаемый вывод:** вы знаете, на какую папку влияют команды, отличаете локальный Git от хостинга и знаете способ восстановления до того, как агент изменит файлы.

## Проверьте понимание

1. **Вопрос:** Завершает ли вводный курс только в браузере локальный маршрут лаборатории? **Ответ:** Нет. Полный маршрут требует локальной исходной точки для Python и Git.

2. **Вопрос:** Что сохранить до изменения временной лаборатории? **Ответ:** Успешный результат начального теста и чистую точку сброса.

## Устранение неполадок

- **Команда Python не найдена:** установите Python 3 с официального сайта поставщика и снова откройте терминал.
- **Файл не найден:** проверьте рабочую папку и выведите список файлов распакованной лаборатории.
- **Тесты не запускаются:** используйте точную команду из README распакованной лаборатории.
- **Git запрашивает данные для коммита:** настройте Git локально и не включайте выбранные значения в заметки курса.
