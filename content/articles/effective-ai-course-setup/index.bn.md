[ব্যবহারিক এআই ওয়ার্কফ্লো কোর্সে ফিরে যান](/effective-ai-course-start/)

**এজেন্ট ব্যবহার করার আগে নিরাপদ অনুশীলনের জায়গা তৈরি করুন।** ১ ও ২ নম্বর পাঠ এই ল্যাব ছাড়াই ব্রাউজারে করা যায়। পুরো কোর্স করতে চাইলে ৩ নম্বর পাঠের আগে এখানে ফিরে আসুন। কোডিংয়ের হাতে-কলমে পাঠে Git, Python 3.10 বা পরের সংস্করণ এবং একটি কোডিং এজেন্ট লাগে। স্টাডি রুটে অনুপলভ্য এজেন্টের কাজের বদলে চিহ্নিত হাতে করা কাজ দেওয়া হয়েছে।

**শেখার ফল:** আপনি শুরুর ল্যাব চালাবেন, স্থানীয় বেসলাইন সংরক্ষণ করবেন এবং ব্যবহার শেষে ফেলে দেওয়ার কপি কীভাবে রিসেট করতে হয় তা ব্যাখ্যা করবেন।

## মূল বিষয়

- **ব্রাউজার রুট:** ChatGPT বা Claude-এ চ্যাট, পরিকল্পনা, উৎস যাচাই এবং পর্যালোচনার অনুশীলন শেষ করুন।
- **স্থানীয় রুট:** কোডিং অনুশীলনে টার্মিনাল ও দেওয়া Python ল্যাব ব্যবহার করুন।
- **রিসেট রুট:** কোনো অনুশীলন ভুল হলে ল্যাবের নতুন কপি বের করুন।
- **নিরাপত্তার নিয়ম:** ব্যক্তিগত ফাইল, গ্রাহকের নথি এবং পরিচয়-তথ্য ল্যাবের বাইরে রাখুন।

## আপনার রুট বেছে নিন

| রুট | যা দরকার | যা অনুশীলন করবেন |
|---|---|---|
| **ব্রাউজারে পরিচিতি** | হালনাগাদ ব্রাউজার এবং ChatGPT বা Claude অ্যাকাউন্ট | ১ ও ২ নম্বর পাঠ, সঙ্গে ১ নম্বর পাঠের চ্যাট টাস্ক প্যাকেট |
| **স্থানীয় হাতে-কলমে কাজ** | Git, Python 3.10 বা পরের সংস্করণ, টার্মিনাল এবং একটি কোডিং এজেন্ট | ফাইল, পার্থক্য, পরীক্ষা এবং এজেন্টের সম্পাদনা |
| **স্টাডি কোর্স** | ব্রাউজার, স্থানীয় Python 3.10 বা পরের সংস্করণ এবং Git | ল্যাবের সব পরীক্ষা; অনুপলভ্য এজেন্ট ও MCP ধাপ চালানো হয়নি বলে চিহ্নিত |

**প্রতিটি পণ্য নিজের পরিকল্পনা ও সীমা নির্ধারণ করে।** কোনো সুবিধার ওপর নির্ভর করার আগে [ChatGPT Projects](https://help.openai.com/en/articles/10169521-projects-in-chatgpt) এবং [Claude Projects](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects) দেখুন। স্টাডি রুট অনুপলভ্য কোডিং এজেন্টের হাতে-কলমে দক্ষতা প্রমাণ করে না। কোর্স শেষের নোটে এই পার্থক্য লিখুন।

**একটি ডিফল্ট পথ নিন:** চ্যাট অনুশীলনে ব্রাউজারে ChatGPT ব্যবহার করুন, তারপর স্থানীয় ল্যাবের সঙ্গে একটি উপলভ্য কোডিং এজেন্ট নিন। চ্যাটের জন্য Claude সমমানের বিকল্প। কোডিং পর্যায়ে Codex CLI, Claude Code CLI বা OpenCode বেছে নেওয়া যায়। সব সরবরাহকারীর অ্যাকাউন্ট দরকার নেই।

**কোডিং এজেন্ট খোলার আগে পাঁচটি প্রাথমিক পরীক্ষা লিখে রাখুন।** এতে স্থানীয় ল্যাব যাচাই এবং কোনো অ্যাকাউন্ট বা হোস্ট করা কর্মক্ষেত্রের দাবি আলাদা থাকে।

| পরীক্ষা | যা লিখবেন |
|---|---|
| **কর্মক্ষেত্র** | এজেন্ট যে বের করা ল্যাব ফোল্ডার পড়বে তার সঠিক পথ |
| **চালানোর স্থান** | স্থানীয় কম্পিউটার বা নির্বাচিত দূরবর্তী কর্মক্ষেত্র |
| **সরবরাহকারী** | এই কাজে ব্যবহৃত অ্যাকাউন্ট বা মডেল সরবরাহকারী |
| **অনুমতি** | ফাইল লেখা ও শেল কমান্ড চালানো অনুমোদিত, নাকি অনুমোদন লাগে |
| **বেসলাইন** | সম্পাদনার আগে দেখা সংখ্যা এবং পাস করা দুটি পরীক্ষা |

**অনুশীলনের মূল ফোল্ডার ছোট রাখুন।** হোস্ট করা কর্মক্ষেত্রে সিন্থেটিক ল্যাবের আলাদা কপি দরকার। স্থানীয়ভাবে চালানো থেকে প্রমাণ হয় না যে দূরবর্তী কপি বা অ্যাকাউন্টে একই ফাইল ও অনুমতি আছে।

## ল্যাব প্রস্তুত করুন

**[কোর্সের শুরুর ল্যাব ডাউনলোড করুন](/downloads/effective-ai-course-lab.zip)** এবং আপনার নিয়ন্ত্রণে থাকা নতুন ফোল্ডারে বের করুন। সেই ফোল্ডারে টার্মিনাল খুলুন। macOS বা Linux-এ Terminal খুলে `cd` দিয়ে বের করা ফোল্ডারে যান। Windows-এ PowerShell বা Windows Terminal এবং `cd` ব্যবহার করুন। Windows-এ Python কমান্ড প্রায়ই `python3`-এর বদলে `py -3` হয়।

**প্রয়োজন হলে [Python 3.10 বা পরের সংস্করণ](https://www.python.org/downloads/) এবং [Git](https://git-scm.com/downloads) ইনস্টল করুন।** ল্যাব চালানোর আগে ইনস্টল করা সরঞ্জাম পরীক্ষা করুন। প্রথম দুটি কমান্ড সংস্করণ নম্বর দেখায়। `cd` কাজের ডিরেক্টরি বদলায়। `ls` ফাইলের তালিকা দেখায়। উদাহরণ পথটি আপনার বের করা ফোল্ডারের আসল পথে বদলান।

```bash
python3 --version
git --version
cd /path/to/effective-ai-course-lab
ls
```

**Windows PowerShell-এ,** `py -3 --version`, `git --version`, `cd C:\path\to\effective-ai-course-lab` এবং `Get-ChildItem` ব্যবহার করুন। তালিকায় `task_report.py`, `tasks.json`, `tests` এবং `docs` থাকার কথা। সংস্করণ কমান্ড ব্যর্থ হলে আগে ইনস্টলেশন শেষ করুন।

```bash
pwd
python3 task_report.py tasks.json
python3 -m unittest discover -s tests -v
```

**Windows PowerShell-এ,** চাইলে `pwd`-এর বদলে `Get-Location` ব্যবহার করুন। Python লঞ্চার ব্যবহার করলে `python3`-এর বদলে `py -3` চালান। প্রথম কমান্ড যে পথ দেখায় তার শেষে বের করা ল্যাব ফোল্ডার থাকা উচিত। ফাইলের নামও পরীক্ষা করুন। `AGENTS.md.txt`, `AGENTS.md`-এর কাজ করে না। পূর্ণ নাম দেখতে Windows Explorer-এ ফাইলের নামের এক্সটেনশন চালু করুন।

**প্রত্যাশিত আউটপুট:** রিপোর্টে `Total tasks: 4` লেখা থাকে। পরীক্ষার কমান্ড দুটি পরীক্ষার নাম দেখিয়ে `OK` দিয়ে শেষ হয়। সফল হলে শেল শূন্য এক্সিট কোড দেয়। অন্য সংখ্যা বা traceback এলে ফোল্ডার ও Python সেটআপ পরীক্ষা করুন।

**কমান্ডকে অংশে ভাগ করে পড়ুন।** `python3 task_report.py tasks.json`-এ `python3` Python চালু করে, `task_report.py` প্রোগ্রাম এবং `tasks.json` ইনপুট ডেটার নাম। মুদ্রিত সংখ্যা আউটপুট, আরেকটি কমান্ড নয়। ব্যর্থতার পর macOS ও Linux `echo $?` দিয়ে অবস্থা দেখায়। PowerShell শেষ নেটিভ প্রোগ্রামের অবস্থা `$LASTEXITCODE`-এ দেয়।

**Python ইনস্টলের পর প্রথমবার চালাতে প্রায় দশ মিনিট রাখুন:** ল্যাব বের করুন, রিপোর্ট চালান এবং মোট সংখ্যা `tasks.json`-এর চারটি এন্ট্রির সঙ্গে মেলান। টেক্সট এডিটরে JSON ফাইল খুলে নিজে এন্ট্রি গুনুন।

## নিরাপদে Git অনুশীলন করুন

**Git শুধু বের করা ল্যাব ফোল্ডারের মধ্যে শুরু করুন।** এই কমান্ডগুলো স্থানীয় স্ন্যাপশট রাখে। `git status` বদলানো ফাইল দেখায়। ট্র্যাক করা ফাইল সম্পাদনার পর `git diff` বদলানো লাইন দেখায়।

```bash
git init
git add .
git commit -m "কোর্স ল্যাবের বেসলাইন"
git status --short
```

**প্রত্যাশিত অবস্থা:** কমিটের পর কোনো ফাইলের নাম দেখা যায় না। Git নাম ও ইমেইল চাইলে এই ফোল্ডার থেকে শুধু ল্যাবের জন্য পরিচয় সেট করে আবার কমিট চালান। উদাহরণ মান ব্যক্তিগত মান দিয়ে বদলান। পরিচয় বা লগইন তথ্যের আউটপুট জনসমক্ষে থাকা চ্যাটে পেস্ট করবেন না।

```bash
git config --local user.name "কোর্স শিক্ষার্থী"
git config --local user.email "learner@example.invalid"
git commit -m "কোর্স ল্যাবের বেসলাইন"
git status --short
```

**রিসেট করতে Git কমান্ড লাগে না।** নোট ল্যাবের বাইরে রাখুন, বের করা অনুশীলনের কপি মুছুন এবং আসল ZIP আবার বের করুন। পাঠের সম্পাদনায় প্রোগ্রাম অজানা অবস্থায় গেলে এই রিসেট ব্যবহার করুন।

## অনুশীলনের জায়গা সুরক্ষিত রাখুন

**সিন্থেটিক উদাহরণ ব্যবহার করুন।** ব্যক্তিগত নথি কোর্স প্রকল্পে আপলোড করবেন না। API কী প্রম্পট, সোর্স ফাইল, স্ক্রিনশট বা কমিটে রাখবেন না। কোডিং এজেন্টের ফাইল ও কমান্ডে প্রবেশাধিকার তার অনুমতি এবং খোলা ফোল্ডারের ওপর নির্ভর করে। চালাতে দেওয়ার আগে দুটোই দেখুন।

**আপলোডের আগে শেয়ারিং পরীক্ষা করুন।** প্রকল্পের সদস্যরা ফাইল দেখতে পারেন। বাস্তব কাজের জন্য প্রতিষ্ঠানের নীতি মেনে চলুন। কোর্সে কাল্পনিক ডেটা আছে, তাই ল্যাবের জন্য বিশেষ অনুমোদন লাগে না।

## অনুশীলন ও যাচাই

**আপনার ফলাফল:** বেছে নেওয়া রুট, পাঁচটি প্রাথমিক ঘর, রিপোর্টের সংখ্যা, পরীক্ষার ফল এবং রিসেট পদ্ধতি লিখুন। নতুন ল্যাব কপি ব্যবহার করে রিসেট করতে পারেন কি না নিশ্চিত করুন।

**প্রত্যাশিত বোঝাপড়া:** কমান্ড কোন ফোল্ডারে কাজ করে জানেন, স্থানীয় Git ও হোস্টিংয়ের পার্থক্য বোঝেন এবং এজেন্ট ফাইল সম্পাদনার আগে ফেরত যাওয়ার উপায় রাখেন।

## বোঝাপড়া যাচাই করুন

1. **প্রশ্ন:** শুধু ব্রাউজারের পরিচিতি কি স্থানীয় ল্যাব রুট শেষ করে? **উত্তর:** না। সম্পূর্ণ রুটে স্থানীয় Python ও Git বেসলাইন লাগে।

2. **প্রশ্ন:** ফেলে দেওয়ার ল্যাব বদলানোর আগে কী সংরক্ষণ করবেন? **উত্তর:** শুরুর পরীক্ষায় পাসের ফল এবং পরিষ্কার রিসেট পয়েন্ট।

## সমস্যা সমাধান

- **Python কমান্ড নেই:** অফিসিয়াল বিতরণকারী থেকে Python 3 ইনস্টল করে টার্মিনাল আবার খুলুন।
- **ফাইল পাওয়া যায়নি:** কাজের ডিরেক্টরি পরীক্ষা করুন এবং বের করা ফোল্ডারের ফাইল দেখুন।
- **পরীক্ষা চলে না:** বের করা ল্যাবের README-তে দেওয়া ঠিক কমান্ডটি ব্যবহার করুন।
- **Git কমিটের পরিচয় চায়:** Git স্থানীয়ভাবে কনফিগার করুন এবং বেছে নেওয়া মান কোর্স নোটে রাখবেন না।
