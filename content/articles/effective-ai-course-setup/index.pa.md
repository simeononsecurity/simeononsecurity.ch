[ਅਮਲੀ AI ਵਰਕਫ਼ਲੋ ਕੋਰਸ ਵੱਲ ਵਾਪਸ ਜਾਓ](/effective-ai-course-start/)

**ਏਜੰਟ ਵਰਤਣ ਤੋਂ ਪਹਿਲਾਂ ਇੱਕ ਸੁਰੱਖਿਅਤ ਅਭਿਆਸ ਥਾਂ ਤਿਆਰ ਕਰੋ।** ਪਾਠ 1 ਅਤੇ 2 ਇਸ ਲੈਬ ਤੋਂ ਬਿਨਾਂ ਬ੍ਰਾਊਜ਼ਰ ਵਿੱਚ ਹੋ ਸਕਦੇ ਹਨ। ਪੂਰਾ ਕੋਰਸ ਕਰਨਾ ਹੋਵੇ ਤਾਂ ਪਾਠ 3 ਤੋਂ ਪਹਿਲਾਂ ਇੱਥੇ ਵਾਪਸ ਆਓ। ਕੋਡਿੰਗ ਦੇ ਅਮਲੀ ਪਾਠਾਂ ਲਈ Git, Python 3.10 ਜਾਂ ਨਵਾਂ ਅਤੇ ਇੱਕ ਕੋਡਿੰਗ ਏਜੰਟ ਚਾਹੀਦਾ ਹੈ। ਅਧਿਐਨ ਰਾਹ ਵਿੱਚ ਨਾ-ਮਿਲਣ ਵਾਲੀਆਂ ਏਜੰਟ ਕਾਰਵਾਈਆਂ ਦੀ ਥਾਂ ਨਿਸ਼ਾਨ ਲੱਗੇ ਹੱਥੀਂ ਕੰਮ ਹੁੰਦੇ ਹਨ।

**ਸਿੱਖਣ ਦਾ ਨਤੀਜਾ:** ਤੁਸੀਂ ਸ਼ੁਰੂਆਤੀ ਲੈਬ ਚਲਾਓਗੇ, ਸਥਾਨਕ ਬੇਸਲਾਈਨ ਸੰਭਾਲੋਗੇ ਅਤੇ ਵਰਤੋਂ ਤੋਂ ਬਾਅਦ ਵਾਲੀ ਨਕਲ ਰੀਸੈੱਟ ਕਰਨਾ ਸਮਝਾਓਗੇ।

## ਮੁੱਖ ਗੱਲਾਂ

- **ਬ੍ਰਾਊਜ਼ਰ ਰਾਹ:** ChatGPT ਜਾਂ Claude ਵਿੱਚ ਚੈਟ, ਯੋਜਨਾ, ਸਰੋਤ-ਜਾਂਚ ਅਤੇ ਸਮੀਖਿਆ ਦੇ ਅਭਿਆਸ ਕਰੋ।
- **ਸਥਾਨਕ ਰਾਹ:** ਕੋਡਿੰਗ ਅਭਿਆਸਾਂ ਲਈ ਟਰਮੀਨਲ ਅਤੇ ਦਿੱਤੀ Python ਲੈਬ ਵਰਤੋ।
- **ਰੀਸੈੱਟ ਰਾਹ:** ਅਭਿਆਸ ਗਲਤ ਹੋਵੇ ਤਾਂ ਲੈਬ ਦੀ ਨਵੀਂ ਨਕਲ ਖੋਲ੍ਹੋ।
- **ਸੁਰੱਖਿਆ ਨਿਯਮ:** ਨਿੱਜੀ ਫ਼ਾਈਲਾਂ, ਗਾਹਕ ਰਿਕਾਰਡ ਅਤੇ ਲਾਗਇਨ ਜਾਣਕਾਰੀ ਲੈਬ ਤੋਂ ਬਾਹਰ ਰੱਖੋ।

## ਲੈਬ ਤਿਆਰ ਕਰੋ

**[ਕੋਰਸ ਦੀ ਸ਼ੁਰੂਆਤੀ ਲੈਬ ਡਾਊਨਲੋਡ ਕਰੋ](/downloads/effective-ai-course-lab.zip)** ਅਤੇ ਇਸਨੂੰ ਆਪਣੇ ਕਾਬੂ ਵਾਲੇ ਨਵੇਂ ਫੋਲਡਰ ਵਿੱਚ ਖੋਲ੍ਹੋ। ਉਸ ਫੋਲਡਰ ਵਿੱਚ ਟਰਮੀਨਲ ਖੋਲ੍ਹੋ। macOS ਜਾਂ Linux ਉੱਤੇ Terminal ਖੋਲ੍ਹ ਕੇ `cd` ਨਾਲ ਕੱਢੇ ਫੋਲਡਰ ਵਿੱਚ ਜਾਓ। Windows ਉੱਤੇ PowerShell ਜਾਂ Windows Terminal ਅਤੇ `cd` ਵਰਤੋ। Windows ਵਿੱਚ Python ਕਮਾਂਡ ਅਕਸਰ `python3` ਦੀ ਥਾਂ `py -3` ਹੁੰਦੀ ਹੈ।

**ਲੋੜ ਪਏ ਤਾਂ [Python 3.10 ਜਾਂ ਨਵਾਂ](https://www.python.org/downloads/) ਅਤੇ [Git](https://git-scm.com/downloads) ਇੰਸਟਾਲ ਕਰੋ।** ਲੈਬ ਚਲਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਇੰਸਟਾਲ ਟੂਲ ਜਾਂਚੋ। ਪਹਿਲੀਆਂ ਦੋ ਕਮਾਂਡਾਂ ਵਰਜਨ ਦਿਖਾਉਂਦੀਆਂ ਹਨ। `cd` ਵਰਕਿੰਗ ਡਾਇਰੈਕਟਰੀ ਬਦਲਦਾ ਹੈ ਅਤੇ `ls` ਫ਼ਾਈਲਾਂ ਦੀ ਸੂਚੀ ਦਿੰਦਾ ਹੈ। ਨਮੂਨਾ ਪਤਾ ਕੱਢੇ ਫੋਲਡਰ ਦੇ ਅਸਲ ਪਤੇ ਨਾਲ ਬਦਲੋ।

```bash
python3 --version
git --version
cd /path/to/effective-ai-course-lab
ls
```

**Windows PowerShell ਵਿੱਚ,** `py -3 --version`, `git --version`, `cd C:\path\to\effective-ai-course-lab` ਅਤੇ `Get-ChildItem` ਵਰਤੋ। ਸੂਚੀ ਵਿੱਚ `task_report.py`, `tasks.json`, `tests` ਅਤੇ `docs` ਹੋਣੇ ਚਾਹੀਦੇ ਹਨ। ਵਰਜਨ ਕਮਾਂਡ ਫੇਲ੍ਹ ਹੋਵੇ ਤਾਂ ਅੱਗੇ ਵਧਣ ਤੋਂ ਪਹਿਲਾਂ ਇੰਸਟਾਲੇਸ਼ਨ ਪੂਰੀ ਕਰੋ।

```bash
pwd
python3 task_report.py tasks.json
python3 -m unittest discover -s tests -v
```

**Windows PowerShell ਵਿੱਚ,** ਆਪਣੀ ਪਸੰਦ ਅਨੁਸਾਰ `pwd` ਨੂੰ `Get-Location` ਨਾਲ ਬਦਲੋ ਅਤੇ Python ਲਾਂਚਰ ਵਰਤਦਾ ਹੋਵੇ ਤਾਂ `python3` ਨੂੰ `py -3` ਨਾਲ ਬਦਲੋ। ਪਹਿਲੀ ਕਮਾਂਡ ਪਤਾ ਦਿਖਾਉਂਦੀ ਹੈ, ਜੋ ਕੱਢੇ ਲੈਬ ਫੋਲਡਰ ਉੱਤੇ ਮੁੱਕਣਾ ਚਾਹੀਦਾ ਹੈ। ਫ਼ਾਈਲ ਨਾਂ ਵੀ ਜਾਂਚੋ। `AGENTS.md.txt`, `AGENTS.md` ਦੀ ਥਾਂ ਨਹੀਂ ਲੈ ਸਕਦੀ। ਪੂਰਾ ਨਾਂ ਵੇਖਣ ਲਈ Windows Explorer ਵਿੱਚ ਫ਼ਾਈਲ ਨਾਂ ਦੇ ਐਕਸਟੈਂਸ਼ਨ ਦਿਖਾਓ।

**ਉਮੀਦ ਕੀਤਾ ਨਤੀਜਾ:** ਰਿਪੋਰਟ `Total tasks: 4` ਦੱਸਦੀ ਹੈ। ਟੈਸਟ ਕਮਾਂਡ ਦੋ ਟੈਸਟਾਂ ਦੇ ਨਾਂ ਦਿੰਦੀ ਹੈ ਅਤੇ `OK` ਨਾਲ ਮੁੱਕਦੀ ਹੈ। ਸਫਲਤਾ ਉੱਤੇ ਸ਼ੈੱਲ ਐਗਜ਼ਿਟ ਕੋਡ ਜ਼ੀਰੋ ਦਿੰਦਾ ਹੈ। ਹੋਰ ਗਿਣਤੀ ਜਾਂ traceback ਆਵੇ ਤਾਂ ਫੋਲਡਰ ਅਤੇ Python ਸੈਟਅੱਪ ਜਾਂਚੋ।

**ਕਮਾਂਡ ਦੇ ਹਿੱਸੇ ਸਮਝੋ।** `python3 task_report.py tasks.json` ਵਿੱਚ `python3` Python ਚਲਾਉਂਦਾ ਹੈ, `task_report.py` ਪ੍ਰੋਗਰਾਮ ਹੈ ਅਤੇ `tasks.json` ਇਨਪੁੱਟ ਡਾਟਾ ਦੱਸਦਾ ਹੈ। ਛਪੀ ਗਿਣਤੀ ਨਤੀਜਾ ਹੈ, ਹੋਰ ਕਮਾਂਡ ਨਹੀਂ। ਫੇਲ੍ਹ ਹੋਣ ਤੋਂ ਬਾਅਦ macOS ਅਤੇ Linux `echo $?` ਨਾਲ ਸਥਿਤੀ ਦਿਖਾਉਂਦੇ ਹਨ। PowerShell ਆਖ਼ਰੀ ਮੂਲ ਪ੍ਰੋਗਰਾਮ ਦੀ ਸਥਿਤੀ `$LASTEXITCODE` ਵਿੱਚ ਦਿੰਦਾ ਹੈ।

**Python ਇੰਸਟਾਲ ਹੋਣ ਪਿੱਛੋਂ ਪਹਿਲੀ ਵਾਰ ਲਈ ਲਗਭਗ ਦਸ ਮਿੰਟ ਰੱਖੋ:** ਲੈਬ ਖੋਲ੍ਹੋ, ਰਿਪੋਰਟ ਚਲਾਓ ਅਤੇ ਕੁੱਲ ਨੂੰ `tasks.json` ਦੀਆਂ ਚਾਰ ਐਂਟਰੀਆਂ ਨਾਲ ਮਿਲਾਓ। JSON ਫ਼ਾਈਲ ਟੈਕਸਟ ਐਡੀਟਰ ਵਿੱਚ ਖੋਲ੍ਹ ਕੇ ਐਂਟਰੀਆਂ ਆਪ ਗਿਣੋ।

## Git ਦਾ ਸੁਰੱਖਿਅਤ ਅਭਿਆਸ ਕਰੋ

**Git ਸਿਰਫ਼ ਕੱਢੇ ਲੈਬ ਫੋਲਡਰ ਵਿੱਚ ਸ਼ੁਰੂ ਕਰੋ।** ਇਹ ਕਮਾਂਡਾਂ ਸਥਾਨਕ ਨਕਲ ਸੰਭਾਲਦੀਆਂ ਹਨ। `git status` ਬਦਲੀਆਂ ਫ਼ਾਈਲਾਂ ਦਿਖਾਉਂਦਾ ਹੈ। ਟਰੈਕ ਕੀਤੀ ਫ਼ਾਈਲ ਸੋਧਣ ਪਿੱਛੋਂ `git diff` ਬਦਲੀਆਂ ਲਾਈਨਾਂ ਦਿਖਾਉਂਦਾ ਹੈ।

```bash
git init
git add .
git commit -m "ਕੋਰਸ ਲੈਬ ਦੀ ਬੇਸਲਾਈਨ"
git status --short
```

**ਉਮੀਦ ਕੀਤੀ ਸਥਿਤੀ:** ਕਮਿਟ ਤੋਂ ਬਾਅਦ ਕੋਈ ਫ਼ਾਈਲ ਨਾਂ ਨਹੀਂ ਆਉਂਦਾ। Git ਨਾਂ ਅਤੇ ਈਮੇਲ ਪੁੱਛੇ ਤਾਂ ਇਸ ਫੋਲਡਰ ਵਿੱਚ ਸਿਰਫ਼ ਲੈਬ ਲਈ ਪਛਾਣ ਸੈੱਟ ਕਰਕੇ ਕਮਿਟ ਮੁੜ ਚਲਾਓ। ਨਮੂਨਾ ਮੁੱਲ ਆਪਣਿਆਂ ਨਿੱਜੀ ਮੁੱਲਾਂ ਨਾਲ ਬਦਲੋ। ਪਛਾਣ ਜਾਂ ਲਾਗਇਨ ਜਾਣਕਾਰੀ ਦੀ ਆਉਟਪੁੱਟ ਜਨਤਕ ਚੈਟ ਵਿੱਚ ਨਾ ਪਾਓ।

```bash
git config --local user.name "ਕੋਰਸ ਸਿਖਿਆਰਥੀ"
git config --local user.email "learner@example.invalid"
git commit -m "ਕੋਰਸ ਲੈਬ ਦੀ ਬੇਸਲਾਈਨ"
git status --short
```

**ਰੀਸੈੱਟ ਲਈ Git ਕਮਾਂਡ ਨਹੀਂ ਚਾਹੀਦੀ।** ਨੋਟ ਲੈਬ ਤੋਂ ਬਾਹਰ ਸੰਭਾਲੋ, ਕੱਢੀ ਅਭਿਆਸੀ ਨਕਲ ਮਿਟਾਓ ਅਤੇ ਮੂਲ ZIP ਮੁੜ ਖੋਲ੍ਹੋ। ਜਦੋਂ ਪਾਠ ਦੀ ਸੋਧ ਪ੍ਰੋਗਰਾਮ ਨੂੰ ਅਣਜਾਣ ਸਥਿਤੀ ਵਿੱਚ ਛੱਡ ਦੇਵੇ, ਇਹ ਤਰੀਕਾ ਵਰਤੋ।

## ਅਭਿਆਸ ਥਾਂ ਦੀ ਰੱਖਿਆ ਕਰੋ

**ਸਿੰਥੈਟਿਕ ਉਦਾਹਰਨਾਂ ਵਰਤੋ।** ਨਿੱਜੀ ਦਸਤਾਵੇਜ਼ ਕੋਰਸ ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਅੱਪਲੋਡ ਨਾ ਕਰੋ। API ਕੁੰਜੀਆਂ ਪ੍ਰੌਂਪਟਾਂ, ਸਰੋਤ ਫ਼ਾਈਲਾਂ, ਸਕ੍ਰੀਨਸ਼ਾਟ ਜਾਂ ਕਮਿਟਾਂ ਵਿੱਚ ਨਾ ਪਾਓ। ਕੋਡਿੰਗ ਏਜੰਟ ਦੀ ਫ਼ਾਈਲਾਂ ਅਤੇ ਕਮਾਂਡਾਂ ਤੱਕ ਪਹੁੰਚ ਇਜਾਜ਼ਤਾਂ ਅਤੇ ਖੁੱਲ੍ਹੇ ਫੋਲਡਰ ਉੱਤੇ ਨਿਰਭਰ ਕਰਦੀ ਹੈ। ਚਲਾਉਣ ਦੇਣ ਤੋਂ ਪਹਿਲਾਂ ਦੋਵੇਂ ਜਾਂਚੋ।

**ਅੱਪਲੋਡ ਤੋਂ ਪਹਿਲਾਂ ਸਾਂਝਾ ਕਰਨ ਦੀ ਜਾਂਚ ਕਰੋ।** ਪ੍ਰੋਜੈਕਟ ਮੈਂਬਰਾਂ ਨੂੰ ਫ਼ਾਈਲਾਂ ਦਿਖ ਸਕਦੀਆਂ ਹਨ। ਅਸਲ ਕੰਮ ਲਈ ਆਪਣੀ ਸੰਸਥਾ ਦੀ ਨੀਤੀ ਮੰਨੋ। ਕੋਰਸ ਵਿੱਚ ਕਾਲਪਨਿਕ ਡਾਟਾ ਹੈ, ਇਸ ਲਈ ਲੈਬ ਲਈ ਖ਼ਾਸ ਮਨਜ਼ੂਰੀ ਨਹੀਂ ਚਾਹੀਦੀ।

## ਅਭਿਆਸ ਅਤੇ ਜਾਂਚ

**ਤੁਹਾਡਾ ਨਤੀਜਾ:** ਚੁਣਿਆ ਰਾਹ, ਪੰਜ ਪਹਿਲਾਂ ਵਾਲੇ ਖੇਤਰ, ਰਿਪੋਰਟ ਦੀ ਗਿਣਤੀ, ਟੈਸਟ ਨਤੀਜਾ ਅਤੇ ਰੀਸੈੱਟ ਤਰੀਕਾ ਲਿਖੋ। ਨਵੀਂ ਲੈਬ ਨਕਲ ਨਾਲ ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਤੁਸੀਂ ਰੀਸੈੱਟ ਕਰ ਸਕਦੇ ਹੋ।

**ਉਮੀਦ ਕੀਤੀ ਸਮਝ:** ਤੁਹਾਨੂੰ ਪਤਾ ਹੈ ਕਿ ਕਮਾਂਡਾਂ ਕਿਹੜੇ ਫੋਲਡਰ ਉੱਤੇ ਅਸਰ ਕਰਦੀਆਂ ਹਨ, ਸਥਾਨਕ Git ਅਤੇ ਹੋਸਟਿੰਗ ਦਾ ਫ਼ਰਕ ਸਮਝਦੇ ਹੋ ਅਤੇ ਏਜੰਟ ਵੱਲੋਂ ਫ਼ਾਈਲਾਂ ਸੋਧਣ ਤੋਂ ਪਹਿਲਾਂ ਵਾਪਸ ਮੁੜਨ ਦਾ ਤਰੀਕਾ ਹੈ।

1. **ਸਵਾਲ:** ਕੀ ਸਿਰਫ਼ ਬ੍ਰਾਊਜ਼ਰ ਵਾਲੀ ਜਾਣ-ਪਛਾਣ ਸਥਾਨਕ ਲੈਬ ਰਾਹ ਪੂਰਾ ਕਰਦੀ ਹੈ? **ਜਵਾਬ:** ਨਹੀਂ। ਪੂਰੇ ਰਾਹ ਲਈ Python ਅਤੇ Git ਦੀ ਸਥਾਨਕ ਬੇਸਲਾਈਨ ਚਾਹੀਦੀ ਹੈ।

2. **ਸਵਾਲ:** ਵਰਤੋਂ ਵਾਲੀ ਲੈਬ ਬਦਲਣ ਤੋਂ ਪਹਿਲਾਂ ਕੀ ਸੰਭਾਲਣਾ ਹੈ? **ਜਵਾਬ:** ਸ਼ੁਰੂਆਤੀ ਟੈਸਟ ਦਾ ਪਾਸ ਨਤੀਜਾ ਅਤੇ ਸਾਫ਼ ਰੀਸੈੱਟ ਬਿੰਦੂ।
