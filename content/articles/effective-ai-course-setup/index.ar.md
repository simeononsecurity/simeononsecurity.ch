[العودة إلى دورة سير عمل الذكاء الاصطناعي العملية](/effective-ai-course-start/)

**جهّز مساحة تدريب آمنة قبل استخدام وكيل.** يمكن تنفيذ الدرسين 1 و2 في المتصفح دون هذا المختبر. عُد إلى هنا قبل الدرس 3 إذا أردت إكمال الدورة كاملة. تستخدم دروس البرمجة العملية Git وPython 3.10 أو إصدارًا أحدث ووكيل برمجة واحدًا. يستبدل مسار الدراسة إجراءات الوكيل غير المتاحة بمهام يدوية موضحة.

**هدف التعلم:** ستشغّل المختبر التمهيدي، وتحفظ خط أساس محليًا، وتشرح كيفية إعادة ضبط نسخة مؤقتة.

## أهم النقاط

- **مسار المتصفح:** أكمل تمارين المحادثة والتخطيط والتحقق من المصادر والمراجعة في ChatGPT أو Claude.
- **المسار المحلي:** استخدم الطرفية ومختبر Python المرفق لتمارين البرمجة.
- **مسار إعادة الضبط:** استخرج نسخة جديدة من المختبر إذا تعذر إكمال تمرين.
- **قاعدة السلامة:** أبقِ الملفات الخاصة وسجلات العملاء وبيانات الاعتماد خارج المختبر.

## اختر مسارك

| المسار | ما تحتاج إليه | ما تتدرب عليه |
|---|---|---|
| **مقدمة عبر المتصفح** | متصفح حديث وحساب ChatGPT أو Claude | الدرسين 1 و2، بالإضافة إلى حزمة مهام المحادثة في الدرس 1 |
| **تدريب محلي** | Git وPython 3.10 أو أحدث وطرفية ووكيل برمجة واحد | الملفات والفروق والاختبارات وتعديلات الوكيل |
| **دورة للدراسة الذاتية** | متصفح وPython 3.10 أو أحدث محليًا وGit | جميع فحوص المختبر؛ تُعلّم خطوات الوكيل وMCP غير المتاحة بأنها لم تُنفذ |

**تحدد المنتجات خططها وحدودها بنفسها.** راجع [ChatGPT Projects](https://help.openai.com/en/articles/10169521-projects-in-chatgpt) و[Claude Projects](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects) قبل الاعتماد على ميزة. لا يثبت مسار الدراسة مهارة عملية في استخدام وكيل برمجة غير متاح. دوّن هذا الفرق في ملاحظات إكمال الدورة.

**اتبع مسارًا افتراضيًا واحدًا:** استخدم ChatGPT في المتصفح لتمارين المحادثة، ثم وكيل برمجة متاحًا مع المختبر المحلي. ويُعد Claude خيارًا مماثلًا للمحادثة. أما مرحلة البرمجة فتتيح Codex CLI أو Claude Code CLI أو OpenCode. لا تحتاج إلى حساب لدى كل مزود.

**دوّن خمسة فحوص مسبقة قبل فتح وكيل البرمجة.** يميز ذلك بين فحص للمختبر المحلي وادعاء عن حساب أو مساحة عمل مستضافة.

| الفحص | ما تسجله |
|---|---|
| **مساحة العمل** | المجلد الدقيق للمختبر المستخرج الذي سيقرأه الوكيل |
| **مكان التنفيذ** | الكمبيوتر المحلي أو مساحة العمل البعيدة المختارة |
| **المزود** | الحساب أو مزود النموذج المستخدم لهذه المهمة |
| **الأذونات** | هل يُسمح بكتابة الملفات وأوامر الصدفة أم تتطلب موافقة |
| **خط الأساس** | العدد المرصود واختباران ناجحان قبل التعديلات |

**أبقِ جذر التدريب محدودًا.** تحتاج مساحة العمل المستضافة إلى نسخة مستقلة من المختبر الاصطناعي. لا يثبت التشغيل المحلي أن النسخة البعيدة أو الحساب يملكان الملفات والأذونات نفسها.

## تعلّم المصطلحات المحلية

| المصطلح | المعنى المبسط |
|---|---|
| **الطرفية** | تطبيق تكتب فيه الأوامر |
| **الصدفة (Shell)** | برنامج يفسر تلك الأوامر |
| **CLI** | واجهة سطر الأوامر لبرنامج |
| **مجلد العمل** | المجلد الذي يستخدمه الأمر افتراضيًا |
| **مستودع** | مشروع يتتبعه Git |
| **Commit** | لقطة محفوظة من حالة Git |
| **فرع** | مسار مسمى لتغييرات Git |
| **Diff** | عرض للأسطر المضافة أو المحذوفة |
| **اختبار** | فحص متكرر للسلوك المتوقع |
| **رمز الخروج** | رقم يبيّن نجاح الأمر أو فشله |

**لا تحتاج إلى GitHub للمختبر التمهيدي.** يعمل Git على كمبيوترك. أما GitHub فهو خدمة استضافة منفصلة. يحفظ الالتزام المحلي لقطة دون إرسال ملفاتك إلى أي مكان.

## جهّز المختبر

**نزّل [المختبر التمهيدي للدورة](/downloads/effective-ai-course-lab.zip)** واستخرجه إلى مجلد جديد تتحكم فيه. افتح طرفية داخل المجلد. على macOS أو Linux، افتح Terminal واستخدم `cd` للانتقال إلى المجلد المستخرج. وعلى Windows، استخدم PowerShell أو Windows Terminal مع `cd`. غالبًا ما يكون أمر Python في Windows هو `py -3` بدلًا من `python3`.

**ثبّت [Python 3.10 أو إصدارًا أحدث](https://www.python.org/downloads/) و[Git](https://git-scm.com/downloads) عند الحاجة.** تحقق من الأدوات المثبتة قبل تشغيل المختبر. يعرض الأمران الأولان أرقام الإصدارات. يغيّر `cd` مجلد العمل، ويعرض `ls` الملفات. استبدل مسار المثال بالمسار الفعلي للمجلد المستخرج.

```bash
python3 --version
git --version
cd /path/to/effective-ai-course-lab
ls
```

**في Windows PowerShell،** استخدم `py -3 --version` و`git --version` و`cd C:\path\to\effective-ai-course-lab` و`Get-ChildItem`. ينبغي أن تتضمن القائمة `task_report.py` و`tasks.json` و`tests` و`docs`. إذا فشل أمر إصدار، فأكمل التثبيت قبل المتابعة.

```bash
pwd
python3 task_report.py tasks.json
python3 -m unittest discover -s tests -v
```

**في Windows PowerShell،** استبدل `pwd` بـ`Get-Location` إن رغبت، واستبدل `python3` بـ`py -3` إذا كان Python يستخدم المشغّل. يعرض الأمر الأول المسار، وينبغي أن ينتهي بمجلد المختبر المستخرج. افحص أسماء الملفات أيضًا. لا يقوم `AGENTS.md.txt` مقام `AGENTS.md`. فعّل امتدادات أسماء الملفات في مستكشف ملفات Windows لرؤية الاسم كاملًا.

**النتيجة المتوقعة:** يعرض التقرير `Total tasks: 4`. ويذكر أمر الاختبار اختبارين وينتهي بـ`OK`. تعيد الصدفة رمز خروج صفرًا عند النجاح. ويعني ظهور عدد مختلف أو traceback أن عليك فحص المجلد وإعداد Python.

**اقرأ الأمر جزءًا جزءًا.** في `python3 task_report.py tasks.json`، يشغّل `python3` لغة Python، ويمثل `task_report.py` البرنامج، ويحدد `tasks.json` بيانات الإدخال. العدد المطبوع هو ناتج، وليس أمرًا آخر. بعد الإخفاق، يعرض macOS وLinux الحالة عبر `echo $?`. ويتيح PowerShell حالة آخر برنامج أصلي عبر `$LASTEXITCODE`.

**خصص نحو عشر دقائق للتشغيل الأول** بعد تثبيت Python: استخرج المختبر، وشغّل التقرير، وقارن الإجمالي بالعناصر الأربعة في `tasks.json`. افتح ملف JSON في محرر نصوص وعدّ العناصر بنفسك.

## تدرب على Git بأمان

**ابدأ Git داخل مجلد المختبر المستخرج فقط.** تحفظ الأوامر التالية لقطة محلية. يعرض `git status` الملفات التي تغيرت. ويعرض `git diff` الأسطر المتغيرة بعد تحرير ملف يتتبعه Git.

```bash
git init
git add .
git commit -m "خط أساس مختبر الدورة"
git status --short
```

**الحالة المتوقعة:** لا تظهر أسماء ملفات بعد الالتزام. إذا طلب Git اسمًا وبريدًا إلكترونيًا، فاضبط هوية خاصة بالمختبر من هذا المجلد ثم أعد الالتزام. استبدل القيم النموذجية بقيم خاصة بك. لا تلصق مخرجات الهوية أو بيانات الاعتماد في دردشة عامة.

```bash
git config --local user.name "متعلم الدورة"
git config --local user.email "learner@example.invalid"
git commit -m "خط أساس مختبر الدورة"
git status --short
```

**لا تحتاج إلى أمر Git لإعادة الضبط.** احفظ الملاحظات خارج المختبر، واحذف نسخة التدريب المستخرجة، ثم استخرج ملف ZIP الأصلي مجددًا. استخدم هذه الطريقة عندما يترك تعديل الدرس البرنامج في حالة غير معروفة.

## احمِ مساحة التدريب

**استخدم أمثلة اصطناعية.** لا ترفع مستندات خاصة إلى مشروع الدورة. لا تضع مفاتيح API في الطلبات أو ملفات المصدر أو لقطات الشاشة أو الالتزامات. يعتمد وصول وكيل البرمجة إلى الملفات والأوامر على الأذونات والمجلد المفتوح. تحقق من الاثنين قبل السماح له بالتنفيذ.

**تحقق من المشاركة قبل الرفع.** قد يتمكن أعضاء المشروع من الوصول إلى ملفاته. اتبع سياسة مؤسستك في العمل الحقيقي. تستخدم الدورة بيانات وهمية، لذلك لا يحتاج المختبر نفسه إلى موافقة خاصة.

## تدرب وتحقق

**الناتج المطلوب منك:** سجّل المسار المختار، والحقول الخمسة للفحص المسبق، وعدد التقرير، ونتيجة الاختبارات، وطريقة إعادة الضبط. استخدم نسخة جديدة من المختبر لتتأكد من إتقان الاستعادة.

**الاستدلال المتوقع:** تعرف المجلد الذي تؤثر فيه الأوامر، وتميز Git المحلي عن الاستضافة، ولديك طريقة للاسترداد قبل أن يعدّل الوكيل الملفات.

## تحقق من فهمك

1. **سؤال:** هل تكمل مقدمة المتصفح وحدها مسار المختبر المحلي؟ **الإجابة:** لا. يتطلب المسار الكامل خط أساس محليًا لـPython وGit.

2. **سؤال:** ماذا تحفظ قبل تغيير المختبر المؤقت؟ **الإجابة:** نتيجة اختبار البداية الناجحة ونقطة استعادة نظيفة.

## استكشاف المشكلات

- **أمر Python غير موجود:** ثبّت Python 3 من الموزع الرسمي ثم أعد فتح الطرفية.
- **الملف غير موجود:** افحص مجلد العمل واعرض ملفات المجلد المستخرج.
- **الاختبارات لا تعمل:** استخدم الأمر نفسه الوارد في README للمختبر المستخرج.
- **يطلب Git هوية للالتزام:** اضبط Git محليًا وأبقِ القيم المختارة خارج ملاحظات الدورة.
