## MSFT Student Cert 提供的认证

MSFT Student Cert 计划提供云计算和人工智能领域的认证。下面介绍部分选项及其涵盖的主题。

### Azure Fundamentals (AZ-900)

**Azure Fundamentals 认证 (AZ-900)** 为刚开始学习云计算的学生打下坚实基础。考试涵盖云概念、Azure 核心服务、安全、隐私、合规和信任。

通过 AZ-900，你可以获得 Azure 方面的重要知识和技能。Azure 是主要云平台之一。这些基础知识也便于你继续学习更高级的 Azure 认证。

该认证介绍云计算和 Azure 的主要功能，内容包括基础设施即服务 (IaaS)、平台即服务 (PaaS)、软件即服务 (SaaS)，以及 Azure Virtual Machines、Azure Storage 和 Azure App Service。

AZ-900 证明你掌握 Azure 和云计算的基础知识。它有助于改善职业前景，也能体现你持续跟进技术发展的态度。

详情请参阅 Microsoft 官方文档：[Azure Fundamentals (AZ-900)](https://docs.microsoft.com/learn/certifications/azure-fundamentals/)

### AI Fundamentals (AI-900)

**AI Fundamentals 认证 (AI-900)** 全面介绍人工智能 (AI) 的概念和技术。考试涉及多种 AI 工作负载及其相关注意事项。

你将学习 AI 原理、Azure 机器学习、计算机视觉工作负载、自然语言处理 (NLP) 工作负载，以及 Azure 上的对话式 AI 工作负载。

AI-900 适合对 AI 感兴趣并希望理解其基本概念和应用的学生。它可以作为迈向高级 AI 认证或 AI 相关岗位的第一步。

该认证有助于证明你了解 AI 工作负载、机器学习算法、计算机视觉技术、NLP 应用和对话式 AI 技术。

Microsoft Azure 提供开发和部署 AI 解决方案的平台。AI Fundamentals 结合 Azure 介绍 AI 概念以及平台对 AI 工作负载的支持能力。

详情请参阅 Microsoft 官方文档：[AI Fundamentals (AI-900)](https://docs.microsoft.com/learn/certifications/azure-ai-fundamentals/)

### Microsoft 365 Fundamentals (MS-900)

**Microsoft 365 Fundamentals 认证 (MS-900)** 介绍 Microsoft 365 云服务的基础知识。内容包括云概念、Microsoft 365 核心服务、安全、合规、隐私和信任。

通过 MS-900，你将了解 Microsoft 365 及其核心服务。认证也介绍云计算，以及 Microsoft 365 中与安全、合规、隐私和信任有关的内容。

这项认证适合希望使用 Microsoft 365 服务的学生。课程会介绍 Microsoft Teams、SharePoint Online、Exchange Online 和 OneDrive for Business。

MS-900 能证明你理解云概念，并能有效使用 Microsoft 365 核心服务。内容包括协作与通信工具、文档管理和云端生产力应用。

Microsoft 365 为组织提供云服务，以支持生产力、协作和安全。MS-900 讲解其基本概念和功能，为后续职业发展打下基础。

详情请参阅 Microsoft 官方文档：[Microsoft 365 Fundamentals (MS-900)](https://learn.microsoft.com/en-us/certifications/exams/ms-900/)

### Microsoft Power Platform Fundamentals (PL-900)

**Microsoft Power Platform Fundamentals 认证 (PL-900)** 面向对低代码平台和使用 Microsoft Power Platform 构建应用感兴趣的学生。考试介绍平台的组成部分及其业务价值。

你将了解 Power BI、Power Apps、Power Automate 和 Power Virtual Agents。这些工具支持创建解决方案、自动化工作流、分析数据和构建聊天机器人，无需丰富的编程知识。

Power BI 可用于创建交互式报告和可视化，以分析数据。Power Apps 可帮助构建符合业务需求的应用。Power Automate 可自动执行重复任务和工作流。Power Virtual Agents 可用于创建 AI 聊天机器人，以支持客户服务和互动。

PL-900 证明你理解 Power Platform 的业务价值，以及它如何帮助组织推动创新和提高生产力。

Power Platform 提供数字化转型和构建自定义解决方案的工具。PL-900 为了解低代码开发和使用该平台打下基础。

详情请参阅 Microsoft 官方文档：[Microsoft Power Platform Fundamentals (PL-900)](https://docs.microsoft.com/learn/certifications/power-platform-fundamentals/)

### Microsoft Dynamics 365 Fundamentals CRM (MB-910)

**Microsoft Dynamics 365 Fundamentals CRM 认证 (MB-910)** 面向希望使用 Dynamics 365 学习客户关系管理 (CRM) 的学生。考试涵盖 Marketing、Sales、Customer Service、Field Service、Project Operations 模块和共享功能。

通过 MB-910，你将了解 Dynamics 365 如何帮助企业管理和改善客户关系。内容包括销售流程、营销活动自动化、客户服务、现场服务和项目管理。

Dynamics 365 Marketing 可用于创建定向营销活动并跟踪客户互动。Dynamics 365 Sales 帮助销售团队管理潜在客户、销售机会和销售渠道。Dynamics 365 Customer Service 支持及时提供个性化帮助。

MB-910 证明你能够使用 Dynamics 365 改善客户关系、简化业务流程并支持业务成果。该认证可能适用于销售、营销、客户服务和项目管理领域。

Dynamics 365 是一套 CRM 和 ERP 解决方案，可与其他 Microsoft 技术集成。MB-910 提供使用该平台和改善客户体验所需的基础知识。

详情请参阅 Microsoft 官方文档：[Microsoft Dynamics 365 Fundamentals CRM (MB-910)](https://learn.microsoft.com/en-us/certifications/exams/mb-910/)

### Microsoft Dynamics 365 Fundamentals ERP (MB-920)

**Microsoft Dynamics 365 Fundamentals ERP 认证 (MB-920)** 面向希望使用 Dynamics 365 学习企业资源规划 (ERP) 的学生。考试涵盖 Supply Chain Management、Finance、Commerce、Human Resources、Project Operations 模块和共享功能。

通过 MB-920，你将了解 Dynamics 365 如何简化运营、管理财务、优化供应链和改善人力资源管理。主题包括库存管理、财务流程、销售与客户互动、人才招聘与管理、项目规划与执行。

Dynamics 365 Supply Chain Management 可帮助企业管理库存、简化采购并优化供应链。Dynamics 365 Finance 提供预算、预测和财务报告功能。Dynamics 365 Commerce 帮助企业通过不同渠道提供一致的购物体验。

MB-920 证明你了解如何使用 Dynamics 365 提高运营效率、财务透明度和业务成果。该认证可能适用于制造、零售、分销和专业服务行业。

Dynamics 365 是一套集成式业务应用平台。MB-920 提供 ERP 基础知识，并介绍 ERP 对企业发展的作用。

详情请参阅 Microsoft 官方文档：[Microsoft Dynamics 365 Fundamentals ERP (MB-920)](https://learn.microsoft.com/en-us/certifications/exams/mb-920/)

### Microsoft Security, Compliance, and Identity Fundamentals (SC-900)

**Microsoft Security, Compliance, and Identity Fundamentals 认证 (SC-900)** 面向希望使用 Microsoft 技术学习网络安全和身份管理基础知识的学生。内容涵盖云概念、Microsoft 365 核心服务、安全、合规、隐私和信任。

通过 SC-900，你将学习在 Microsoft 生态系统中保护数据和身份、确保合规的原则和最佳实践。你还会了解 Microsoft 365、Azure 和其他 Microsoft 服务提供的安全与合规功能。

你将了解 Microsoft 365 的威胁防护、信息保护和安全管理功能。你会学习如何使用 Azure Active Directory 和 Azure AD Identity Protection 等技术实施身份与访问管理解决方案。课程还介绍隐私和合规法规的重要性，以及如何利用 Microsoft 解决方案满足要求。

SC-900 证明你理解网络安全、安全措施和身份管理原则。该认证可帮助你进入金融、医疗、政府和技术等重视安全与合规的行业。

Microsoft 致力于提供安全且符合要求的解决方案。SC-900 为你支持这项工作提供知识，也为后续安全和合规认证打下基础。

详情请参阅 Microsoft 官方文档：[Microsoft Security, Compliance, and Identity Fundamentals (SC-900)](https://learn.microsoft.com/en-us/certifications/exams/sc-900/)
