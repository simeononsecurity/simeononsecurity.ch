Windows ਦੀ ਕਲੀਨ ਇੰਸਟਾਲ ਚੁਣੀ ਡਰਾਈਵ ਮਿਟਾ ਦਿੰਦੀ ਹੈ। ਜੇ ਪੁਰਾਣੀ ਡਰਾਈਵ **BitLocker** ਜਾਂ **ਡਿਵਾਈਸ ਇਨਕ੍ਰਿਪਸ਼ਨ** ਵਰਤਦੀ ਹੈ, ਤਾਂ ਸੈੱਟਅੱਪ ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਰਿਕਵਰੀ ਕੁੰਜੀ ਲੱਭੋ ਅਤੇ ਆਪਣੀਆਂ ਫ਼ਾਈਲਾਂ ਦੀ ਨਕਲ ਬਣਾਓ। ਕੁੰਜੀ ਪੁਰਾਣੇ ਇਨਕ੍ਰਿਪਟ ਕੀਤੇ ਡਾਟੇ ਤੱਕ ਪਹੁੰਚ ਦਿੰਦੀ ਹੈ। Windows ਦੀ ਨਵੀਂ ਇੰਸਟਾਲ ਡਰਾਈਵ ਤੋਂ ਮਿਟੀਆਂ ਫ਼ਾਈਲਾਂ ਵਾਪਸ ਨਹੀਂ ਲਿਆਉਂਦੀ।

<!--more-->

## ਮੁੱਖ ਗੱਲਾਂ

- **ਸਹੀ ਕੁੰਜੀ ਲੱਭੋ:** Windows 'ਤੇ ਦਿਖਾਈ ਕੁੰਜੀ ID ਨੂੰ ਖਾਤੇ, ਛਪੀ ਨਕਲ ਜਾਂ USB ਬੈਕਅੱਪ ਵਾਲੀ ਕੁੰਜੀ ਨਾਲ ਮਿਲਾਓ।
- **ਪਹੁੰਚ ਜਾਂਚੋ:** ਬੈਕਅੱਪ ਖੋਲ੍ਹੋ, ID ਮਿਲਾਓ ਅਤੇ ਪਾਰਟੀਸ਼ਨ ਮਿਟਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਲਾਕ ਡਰਾਈਵ ਖੋਲ੍ਹੋ।
- **ਬੈਕਅੱਪ ਸੁਰੱਖਿਅਤ ਰੱਖੋ:** 48 ਅੰਕਾਂ ਦੀ ਕੁੰਜੀ ਕੰਪਿਊਟਰ ਅਤੇ ਇੰਸਟਾਲੇਸ਼ਨ USB ਤੋਂ ਵੱਖਰੀ ਰੱਖੋ।
- **ਢੁੱਕਵਾਂ ਰਾਹ ਚੁਣੋ:** ਪੁਰਾਣੀ ਇੰਸਟਾਲ ਦੀ ਲੋੜ ਹੋਵੇ ਤਾਂ ਰਿਕਵਰੀ ਵਿਕਲਪ ਵਰਤੋ। ਵੱਖਰੀ ਫ਼ਾਈਲ ਨਕਲ ਦੀ ਜਾਂਚ ਮਗਰੋਂ ਹੀ ਕਲੀਨ ਇੰਸਟਾਲ ਕਰੋ।

## ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ

ਤੁਹਾਨੂੰ ਪ੍ਰਭਾਵਿਤ ਕੰਪਿਊਟਰ ਤੱਕ ਪਹੁੰਚ, ਖਾਤਾ ਜਾਂ ਬੈਕਅੱਪ ਦੇਖਣ ਲਈ ਦੂਜੇ ਡਿਵਾਈਸ ਅਤੇ ਮਹੱਤਵਪੂਰਨ ਫ਼ਾਈਲਾਂ ਲਈ ਬਾਹਰੀ ਡਰਾਈਵ ਜਾਂ ਭਰੋਸੇਯੋਗ ਕਲਾਊਡ ਸਟੋਰੇਜ ਦੀ ਲੋੜ ਹੈ। **ਸਮਾਂ:** ਕੁੰਜੀ ਲੱਭਣ ਦਾ ਸਮਾਂ ਖਾਤੇ ਦੀ ਪਹੁੰਚ 'ਤੇ ਨਿਰਭਰ ਹੈ। ਫ਼ਾਈਲਾਂ ਕਾਪੀ ਕਰਨ ਦਾ ਸਮਾਂ ਡਾਟੇ ਦੀ ਮਾਤਰਾ 'ਤੇ ਨਿਰਭਰ ਕਰਦਾ ਹੈ। **ਮੁਸ਼ਕਲ:** ਖਾਤਾ ਜਾਂਚ ਲਈ ਬੁਨਿਆਦੀ, ਰਿਕਵਰੀ ਟੂਲਾਂ ਲਈ ਦਰਮਿਆਨੀ। ਇਹ ਗਾਈਡ Windows 10 ਅਤੇ Windows 11 ਦੀ ਤਿਆਰੀ ਅਤੇ ਰਿਕਵਰੀ ਫ਼ੈਸਲਿਆਂ ਬਾਰੇ ਹੈ। [Windows ਕਲੀਨ ਇੰਸਟਾਲ ਗਾਈਡ](/articles/how-to-install-windows-10-and-windows-11-from-scratch/) ਇੰਸਟਾਲੇਸ਼ਨ ਮੀਡੀਆ ਅਤੇ ਸੈੱਟਅੱਪ ਦੱਸਦੀ ਹੈ।

*Windows 10 ਦਾ ਮਿਆਰੀ ਸਹਿਯੋਗ 14 ਅਕਤੂਬਰ 2025 ਨੂੰ ਮੁੱਕ ਗਿਆ ਸੀ। ਜੇ ਤੁਹਾਡਾ ਡਿਵਾਈਸ ਲੋੜਾਂ ਪੂਰੀਆਂ ਕਰਦਾ ਹੈ ਤਾਂ ਸਮਰਥਿਤ Windows 11 ਇੰਸਟਾਲ ਦੀ ਯੋਜਨਾ ਬਣਾਓ। Microsoft [Windows 10 ਦੀ ਮਿਆਦ ਅਤੇ ਵਧੇਰੇ ਸਹਿਯੋਗ ਦੇ ਵਿਕਲਪ](https://learn.microsoft.com/en-us/lifecycle/announcements/windows-10-end-of-support) ਦੱਸਦਾ ਹੈ।*

> **ਚੇਤਾਵਨੀ:** ਜੇ ਪੁਰਾਣੀ ਇੰਸਟਾਲ ਦੀਆਂ ਫ਼ਾਈਲਾਂ ਚਾਹੀਦੀਆਂ ਹਨ ਤਾਂ BitLocker ਰਿਕਵਰੀ ਸੁਨੇਹਾ ਹਟਾਉਣ ਲਈ ਪਾਰਟੀਸ਼ਨ ਨਾ ਮਿਟਾਓ। Microsoft ਕਹਿੰਦਾ ਹੈ ਕਿ ਰਿਕਵਰੀ ਕੁੰਜੀ ਤੋਂ ਬਿਨਾਂ ਰੀਸੈੱਟ ਕਰਨ ਨਾਲ ਉਹ ਫ਼ਾਈਲਾਂ ਮਿਟ ਜਾਂਦੀਆਂ ਹਨ। [ਰਿਕਵਰੀ ਕੁੰਜੀ ਬਾਰੇ Microsoft ਦੀ ਸਲਾਹ](https://support.microsoft.com/en-us/windows/security/encryption/find-your-bitlocker-recovery-key) ਵੇਖੋ।

## ਜਾਂਚੋ ਕਿ ਇਨਕ੍ਰਿਪਸ਼ਨ ਚਾਲੂ ਹੈ

**ਡਿਵਾਈਸ ਇਨਕ੍ਰਿਪਸ਼ਨ** ਅਤੇ **BitLocker** ਡਰਾਈਵ ਨੂੰ ਇਨਕ੍ਰਿਪਟ ਕਰਦੇ ਹਨ ਤਾਂ ਜੋ ਸਹੀ ਪਛਾਣ ਜਾਣਕਾਰੀ ਤੋਂ ਬਿਨਾਂ ਕੋਈ ਸਮੱਗਰੀ ਨਾ ਪੜ੍ਹ ਸਕੇ। ਜੇ Windows ਹਾਲੇ ਚੱਲਦਾ ਹੈ, ਤਾਂ Windows 11 ਵਿੱਚ **ਸੈਟਿੰਗਾਂ > ਪਰਦੇਦਾਰੀ ਅਤੇ ਸੁਰੱਖਿਆ > ਡਿਵਾਈਸ ਇਨਕ੍ਰਿਪਸ਼ਨ** ਖੋਲ੍ਹੋ। BitLocker ਪ੍ਰਬੰਧਨ ਵਾਲੇ ਸੰਸਕਰਣਾਂ ਵਿੱਚ Start 'ਤੇ **BitLocker ਪ੍ਰਬੰਧਿਤ ਕਰੋ** ਲੱਭੋ। ਇਨਕ੍ਰਿਪਟ ਕੀਤੀ ਡਰਾਈਵ ਦਾ ਅੱਖਰ ਅਤੇ ਡਿਵਾਈਸ ਸੈੱਟਅੱਪ ਲਈ ਵਰਤਿਆ ਖਾਤਾ ਲਿਖ ਲਵੋ। ਕੰਮ ਜਾਂ ਸਕੂਲ ਦੇ ਪ੍ਰਬੰਧਿਤ ਡਿਵਾਈਸ ਦੀ ਕੁੰਜੀ ਅਕਸਰ ਸੰਸਥਾ ਕੋਲ ਹੁੰਦੀ ਹੈ।

ਤੁਸੀਂ ਕਮਾਂਡ ਲਾਈਨ ਤੋਂ ਵੀ ਹਾਲਤ ਦੇਖ ਸਕਦੇ ਹੋ। Start 'ਤੇ **ਕਮਾਂਡ ਪ੍ਰੋਂਪਟ** ਲੱਭੋ, **ਪ੍ਰਸ਼ਾਸਕ ਵਜੋਂ ਚਲਾਓ** ਚੁਣੋ ਅਤੇ ਇਹ ਕਮਾਂਡਾਂ ਲਿਖੋ। ਜੇ Windows ਹੋਰ ਅੱਖਰ ਵਰਤਦਾ ਹੈ ਤਾਂ `C:` ਬਦਲੋ। **ਪ੍ਰੋਟੈਕਟਰ** ਉਹ ਤਰੀਕਾ ਹੈ ਜਿਸ ਨਾਲ Windows ਇਨਕ੍ਰਿਪਟ ਕੀਤੀ ਡਰਾਈਵ ਖੋਲ੍ਹਦਾ ਹੈ।

```text
manage-bde.exe -status C:
manage-bde.exe -protectors -get C:
```

ਪਹਿਲੀ ਕਮਾਂਡ ਇਨਕ੍ਰਿਪਸ਼ਨ, ਸੁਰੱਖਿਆ ਅਤੇ ਲਾਕ ਦੀ ਹਾਲਤ ਦਿਖਾਉਂਦੀ ਹੈ। ਦੂਜੀ ਪ੍ਰੋਟੈਕਟਰਾਂ ਦੀਆਂ ਕਿਸਮਾਂ ਅਤੇ ID ਦਿਖਾਉਂਦੀ ਹੈ ਅਤੇ ਰਿਕਵਰੀ ਪਾਸਵਰਡ ਵੀ ਵਿਖਾ ਸਕਦੀ ਹੈ। Microsoft ਇਹ ਜਾਂਚਾਂ [BitLocker ਕਾਰਜ ਗਾਈਡ](https://learn.microsoft.com/en-us/windows/security/operating-system-security/data-protection/bitlocker/operations-guide) ਅਤੇ [ਹਾਲਤ ਕਮਾਂਡ ਸੰਦਰਭ](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/manage-bde-status) ਵਿੱਚ ਦਰਜ ਕਰਦਾ ਹੈ। **ਆਉਟਪੁੱਟ ਮਦਦ ਦੀ ਬੇਨਤੀ ਵਿੱਚ ਨਾ ਪੇਸਟ ਕਰੋ ਅਤੇ ਸਕ੍ਰੀਨਸ਼ਾਟ ਰਾਹੀਂ ਨਾ ਸਾਂਝੀ ਕਰੋ।** ਡਿਵਾਈਸ ਪਹਿਲਾਂ ਹੀ ਲਾਕ ਹੈ ਤਾਂ ਰਿਕਵਰੀ ਸਕ੍ਰੀਨ 'ਤੇ ਦਿਖਾਈ ID ਵਰਤੋ। ID ਦੇ ਪਹਿਲੇ ਅੱਠ ਅੰਕ ਸਹੀ ਕੁੰਜੀ ਚੁਣਨ ਵਿੱਚ ਮਦਦ ਕਰਦੇ ਹਨ।

## BitLocker ਰਿਕਵਰੀ ਕੁੰਜੀ ਕਿੱਥੇ ਮਿਲੇਗੀ

**ਰਿਕਵਰੀ ਕੁੰਜੀ ID** ਸੰਭਾਲੀ ਕੁੰਜੀ ਦੀ ਪਛਾਣ ਕਰਦੀ ਹੈ। **ਰਿਕਵਰੀ ਕੁੰਜੀ** ਵੱਖਰਾ 48-ਅੰਕਾਂ ਦਾ ਨੰਬਰ ਹੈ ਜੋ ਡਰਾਈਵ ਖੋਲ੍ਹਣ ਲਈ ਦਰਜ ਹੁੰਦਾ ਹੈ। ID ਨੂੰ ਰਿਕਵਰੀ ਪਾਸਵਰਡ ਵਾਲੇ ਖਾਨੇ ਵਿੱਚ ਨਾ ਦਿਓ।

| ਡਿਵਾਈਸ ਜਾਂ ਬੈਕਅੱਪ | ਕਿੱਥੇ ਲੱਭੋ |
|---|---|
| **ਨਿੱਜੀ Microsoft ਖਾਤਾ** | ਦੂਜੇ ਡਿਵਾਈਸ ਤੋਂ [Microsoft ਦੇ ਰਿਕਵਰੀ ਕੁੰਜੀ ਪੰਨੇ](https://aka.ms/myrecoverykey) 'ਤੇ ਸਾਈਨ ਇਨ ਕਰੋ। 48-ਅੰਕਾਂ ਦੀ ਕੁੰਜੀ ਵਰਤਣ ਤੋਂ ਪਹਿਲਾਂ ID ਮਿਲਾਓ। |
| **ਕੰਮ ਜਾਂ ਸਕੂਲ ਦਾ ਡਿਵਾਈਸ** | [ਕੰਮ ਜਾਂ ਸਕੂਲ ਖਾਤਿਆਂ ਲਈ Microsoft ਪੰਨੇ](https://aka.ms/aadrecoverykey) 'ਤੇ ਸੰਸਥਾ ਦਾ ਖਾਤਾ ਵੇਖੋ ਜਾਂ IT ਟੀਮ ਨੂੰ ਪੁੱਛੋ। |
| **ਛਪੀ ਕਾਪੀ ਜਾਂ USB ਬੈਕਅੱਪ** | ਇਨਕ੍ਰਿਪਸ਼ਨ ਚਾਲੂ ਕਰਨ ਵੇਲੇ ਬਣੀ ਛਪੀ ਕਾਪੀ ਜਾਂ ਟੈਕਸਟ ਫ਼ਾਈਲ ਲੱਭੋ। ਸਕ੍ਰੀਨ ਵਾਲੀ ID ਨਾਲ ਮਿਲਾਓ। |

Microsoft ਇਹ ਥਾਵਾਂ [BitLocker ਰਿਕਵਰੀ ਕੁੰਜੀ ਲੱਭੋ](https://support.microsoft.com/en-us/windows/security/encryption/find-your-bitlocker-recovery-key) ਵਿੱਚ ਦੱਸਦਾ ਹੈ। ਉਸ ਕੁੰਜੀ ਨਾਲ ਸ਼ੁਰੂ ਕਰੋ ਜਿਸ ਦੀ ID ਸੁਨੇਹੇ ਨਾਲ ਮਿਲਦੀ ਹੈ। ਕਿਸੇ ਹੋਰ ਡਿਵਾਈਸ ਜਾਂ ਹਟਾਏ ਪ੍ਰੋਟੈਕਟਰ ਦੀ ਕੁੰਜੀ ਇਸ ਵਾਲਿਊਮ ਨੂੰ ਨਾ ਖੋਲ੍ਹੇ। ਜੇ ਕਿਸੇ ਹੋਰ ਨੇ ਡਿਵਾਈਸ ਸੈੱਟ ਕੀਤਾ ਸੀ ਤਾਂ ਕੁੰਜੀ ਉਸ ਦੇ ਖਾਤੇ ਵਿੱਚ ਹੋ ਸਕਦੀ ਹੈ।

## ਕੁੰਜੀ ਦਾ ਵੱਖਰਾ ਬੈਕਅੱਪ ਬਣਾਓ

ਜੇ Windows Pro, Enterprise ਜਾਂ Education ਸੰਸਕਰਣ 'ਤੇ ਹਾਲੇ ਚੱਲਦਾ ਹੈ ਤਾਂ **BitLocker ਪ੍ਰਬੰਧਿਤ ਕਰੋ** ਲੱਭੋ। ਇਨਕ੍ਰਿਪਟ ਕੀਤੀ ਡਰਾਈਵ ਕੋਲ **ਰਿਕਵਰੀ ਕੁੰਜੀ ਦਾ ਬੈਕਅੱਪ ਬਣਾਓ** ਚੁਣੋ। Microsoft ਖਾਤੇ, USB ਡਰਾਈਵ, ਟੈਕਸਟ ਫ਼ਾਈਲ ਜਾਂ ਛਾਪੀ ਕਾਪੀ ਵਿੱਚ ਬੈਕਅੱਪ ਦੇ ਵਿਕਲਪ ਦਿੰਦਾ ਹੈ। ਟੈਕਸਟ ਫ਼ਾਈਲ ਜਾਂ USB ਨੂੰ ਸਿਰਫ਼ ਇਨਕ੍ਰਿਪਟ ਕੀਤੇ, ਪਹੁੰਚ-ਨਿਯੰਤਰਿਤ ਮੀਡੀਆ 'ਤੇ ਅਤੇ ਕੰਪਿਊਟਰ ਤੋਂ ਵੱਖਰਾ ਰੱਖੋ। ਬਿਨਾਂ ਇਨਕ੍ਰਿਪਸ਼ਨ ਵਾਲੀ ਥਾਂ ਨਾ ਵਰਤੋ। ਮੌਜੂਦਾ ਇੰਟਰਫੇਸ ਅਤੇ ਵਿਕਲਪਾਂ ਲਈ [BitLocker ਰਿਕਵਰੀ ਕੁੰਜੀ ਦਾ ਬੈਕਅੱਪ ਬਣਾਓ](https://support.microsoft.com/en-us/windows/security/encryption/back-up-your-bitlocker-recovery-key) ਵੇਖੋ।

Windows Home ਵਿੱਚ **BitLocker ਪ੍ਰਬੰਧਿਤ ਕਰੋ** ਨਹੀਂ ਹੁੰਦਾ। Windows 11 ਵਿੱਚ **ਸੈਟਿੰਗਾਂ > ਪਰਦੇਦਾਰੀ ਅਤੇ ਸੁਰੱਖਿਆ > ਡਿਵਾਈਸ ਇਨਕ੍ਰਿਪਸ਼ਨ** ਵੇਖੋ, ਫਿਰ ਸੈੱਟਅੱਪ ਵੇਲੇ ਵਰਤੇ Microsoft ਖਾਤੇ ਵਿੱਚ ਕੁੰਜੀ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ। Microsoft ਦੱਸਦਾ ਹੈ ਕਿ [ਡਿਵਾਈਸ ਇਨਕ੍ਰਿਪਸ਼ਨ](https://support.microsoft.com/en-us/windows/security/encryption/device-encryption-in-windows) ਚਾਲੂ ਹੋਣ 'ਤੇ ਲਿੰਕ ਕੀਤੇ Microsoft ਜਾਂ ਕੰਮ ਵਾਲੇ ਖਾਤੇ ਵਿੱਚ ਕੁੰਜੀ ਰੱਖਦਾ ਹੈ। ਜੇ ਸੈੱਟਅੱਪ ਨਿਰਯਾਤ ਦਾ ਤਰੀਕਾ ਦਿੰਦਾ ਹੈ ਤਾਂ ਵੱਖਰੀ ਸੁਰੱਖਿਅਤ ਕਾਪੀ ਬਣਾਓ।

ਡਿਜੀਟਲ ਬੈਕਅੱਪ ਦੂਜੇ ਡਿਵਾਈਸ 'ਤੇ ਖੋਲ੍ਹੋ। ਛਪੀ ਕਾਪੀ ਨੂੰ ਖਾਤੇ ਦੀ ਐਂਟਰੀ ਜਾਂ ਰਿਕਵਰੀ ਸਕ੍ਰੀਨ ਨਾਲ ਮਿਲਾਓ। **ਰਿਕਵਰੀ ਕੁੰਜੀ ID** ਨੂੰ ਸਕ੍ਰੀਨ ਜਾਂ ਪ੍ਰੋਟੈਕਟਰ ਸੂਚੀ ਵਾਲੀ ID ਨਾਲ ਮਿਲਾਓ। ਯਕੀਨੀ ਬਣਾਓ ਕਿ ਸੰਬੰਧਿਤ ਕੁੰਜੀ ਦੇ ਸਾਰੇ 48 ਅੰਕ ਹਨ। ਕਾਗਜ਼ ਜਾਂ ਹਟਾਈ ਜਾ ਸਕਣ ਵਾਲੀ ਕਾਪੀ ਇਨਕ੍ਰਿਪਟ ਕੀਤੇ ਕੰਪਿਊਟਰ ਤੋਂ ਦੂਰ ਰੱਖੋ। ਕੰਪਿਊਟਰ ਅਤੇ ਕੁੰਜੀ ਦੋਵੇਂ ਚੋਰੀ ਹੋਣ 'ਤੇ ਡਰਾਈਵ ਦੀ ਸੁਰੱਖਿਆ ਪਾਰ ਹੋ ਸਕਦੀ ਹੈ, Microsoft [ਬੈਕਅੱਪ ਸਲਾਹ](https://support.microsoft.com/en-us/windows/security/encryption/back-up-your-bitlocker-recovery-key) ਵਿੱਚ ਚੇਤਾਵਨੀ ਦਿੰਦਾ ਹੈ। ਸਹਾਇਤਾ ਟਿਕਟ ਨਾਲ ਕੁੰਜੀ ਨਾ ਜੋੜੋ।

> **ਉਮੀਦਿਤ ਨਤੀਜਾ:** ਤੁਹਾਡੇ ਕੋਲ ਕੰਪਿਊਟਰ ਤੋਂ ਬਾਹਰ ਮੈਲ ਖਾਂਦੀ ਰਿਕਵਰੀ ਕੁੰਜੀ ਹੈ।

## ਨਾ ਚੱਲਣ ਵਾਲੇ ਕੰਪਿਊਟਰ ਨੂੰ ਖੋਲ੍ਹੋ

ਜੇ **BitLocker ਰਿਕਵਰੀ ਸਕ੍ਰੀਨ** ਆਵੇ ਤਾਂ ID ਨਾਲ ਮਿਲਦੀ 48-ਅੰਕਾਂ ਦੀ ਕੁੰਜੀ ਦਰਜ ਕਰੋ। Windows ਸ਼ੁਰੂ ਹੋ ਜਾਵੇ ਤਾਂ ਪਾਰਟੀਸ਼ਨ ਬਦਲਣ ਤੋਂ ਪਹਿਲਾਂ ਫ਼ਾਈਲਾਂ ਕਾਪੀ ਕਰੋ। ਜੇ ਕੁੰਜੀ ਡਰਾਈਵ ਖੋਲ੍ਹਦੀ ਹੈ ਪਰ Windows ਫਿਰ ਵੀ ਸ਼ੁਰੂ ਨਹੀਂ ਹੁੰਦਾ ਤਾਂ [Windows ਰਿਕਵਰੀ ਵਾਤਾਵਰਣ](https://support.microsoft.com/en-us/windows/experience/backup-recovery/windows-recovery-environment) ਖੋਲ੍ਹੋ ਅਤੇ ਰੀਸੈੱਟ ਤੋਂ ਪਹਿਲਾਂ **ਸਟਾਰਟਅੱਪ ਮੁਰੰਮਤ** ਅਜ਼ਮਾਓ। ਡਰਾਈਵ ਇਨਕ੍ਰਿਪਟ ਹੋਣ ਵੇਲੇ ਕੁਝ ਰਿਕਵਰੀ ਟੂਲ ਕੁੰਜੀ ਮੰਗਦੇ ਹਨ।

ਰਿਕਵਰੀ ਟੂਲਾਂ ਤੋਂ ਫ਼ਾਈਲਾਂ ਕਾਪੀ ਕਰਨ ਲਈ Windows ਰਿਕਵਰੀ ਵਾਤਾਵਰਣ ਵਿੱਚ **ਸਮੱਸਿਆ ਹੱਲ > ਉੱਨਤ ਵਿਕਲਪ > ਕਮਾਂਡ ਪ੍ਰੋਂਪਟ** ਖੋਲ੍ਹੋ। ਇਨਕ੍ਰਿਪਟ ਕੀਤਾ Windows ਵਾਲਿਊਮ ਅਤੇ ਵੱਖਰੀ ਬਾਹਰੀ ਬੈਕਅੱਪ ਡਰਾਈਵ ਲੱਭਣ ਲਈ `manage-bde -status` ਤੇ `dir` ਵਰਤੋ। **ਡਰਾਈਵ ਦੇ ਅੱਖਰ ਆਮ Windows ਵਾਲੇ ਅੱਖਰਾਂ ਤੋਂ ਵੱਖਰੇ ਹੋ ਸਕਦੇ ਹਨ।** ਇੰਸਟਾਲੇਸ਼ਨ USB ਜਾਂ ਇਨਕ੍ਰਿਪਟ ਕੀਤੀ ਸਰੋਤ ਡਰਾਈਵ 'ਤੇ ਨਕਲ ਨਾ ਕਰੋ।

```text
manage-bde.exe -status
dir D:\Users
dir E:\
```

ਉੱਪਰਲੇ ਅੱਖਰ ਉਦਾਹਰਣ ਹਨ। ਸਹੀ ਵਾਲਿਊਮ ਪਛਾਣਨ ਮਗਰੋਂ ਮੈਲ ਖਾਂਦੀ ਕੁੰਜੀ ਨਾਲ Windows ਵਾਲਿਊਮ ਖੋਲ੍ਹੋ। ਉਦਾਹਰਣ ਅੱਖਰ ਅਤੇ ਥਾਂ-ਰਾਖਵੇਂ ਚਿੰਨ੍ਹ ਨੂੰ ਆਪਣੀਆਂ ਕਦਰਾਂ ਨਾਲ ਬਦਲੋ। ਅਸਲੀ 48-ਅੰਕਾਂ ਦੀ ਕੁੰਜੀ ਸਿਰਫ਼ ਆਪਣੇ ਡਿਵਾਈਸ 'ਤੇ ਲਿਖੋ। ਆਉਟਪੁੱਟ ਪ੍ਰਕਾਸ਼ਿਤ ਜਾਂ ਸਾਂਝੀ ਨਾ ਕਰੋ।

```text
manage-bde.exe -unlock D: -recoverypassword <48-digit-key>
```

ਦਸਤਾਵੇਜ਼ੀ `-recoverypassword` ਵਿਕਲਪ ਕਮਾਂਡ ਲਾਈਨ 'ਤੇ 48-ਅੰਕਾਂ ਦੀ ਕੁੰਜੀ ਲੈਂਦਾ ਹੈ। ਇਸ ਨਾਲ ਕੁੰਜੀ shell history, transcript ਅਤੇ process inspection ਵਿੱਚ ਦਿਸ ਸਕਦੀ ਹੈ। ਕਮਾਂਡ-ਲਾਈਨ ਆਰਗਿਊਮੈਂਟ ਤੋਂ ਬਿਨਾਂ ਕੁੰਜੀ ਦੇਣ ਲਈ Windows ਰਿਕਵਰੀ ਸਕ੍ਰੀਨ ਵਰਤੋ। ਵੱਖਰੀ `.bek` ਕੁੰਜੀ ਫ਼ਾਈਲ ਸੰਭਾਲੀ ਹੋਵੇ ਤਾਂ `-recoverykey <path-to-external-bek>` ਰਾਹੀਂ 48 ਅੰਕ ਟਾਈਪ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ। ਕੁੰਜੀ ਨੂੰ ਸਕ੍ਰੀਨਸ਼ਾਟ ਅਤੇ ਟਿਕਟਾਂ ਤੋਂ ਦੂਰ ਰੱਖੋ।

Microsoft [ਅਨਲੌਕ ਕਮਾਂਡ](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/manage-bde-unlock) ਦਸਤਾਵੇਜ਼ ਕਰਦਾ ਹੈ। [ਰਿਕਵਰੀ ਸਲਾਹ](https://learn.microsoft.com/en-us/troubleshoot/windows-client/windows-security/bitlocker-recovery-known-issues) ਅਨਲੌਕ ਮਗਰੋਂ ਹੋਰ ਡਰਾਈਵ 'ਤੇ ਵਰਤੋਂਕਾਰ ਦੀਆਂ ਫ਼ਾਈਲਾਂ ਕਾਪੀ ਕਰਨ ਬਾਰੇ ਵੀ ਦੱਸਦੀ ਹੈ। ਉਦਾਹਰਣ ਵਜੋਂ Documents ਕਾਪੀ ਕਰਨ ਲਈ ਪਹਿਲਾਂ Windows ਖਾਤੇ ਦਾ ਨਾਮ ਅਤੇ ਬਾਹਰੀ ਡਰਾਈਵ ਦਾ ਅੱਖਰ ਪੱਕਾ ਕਰੋ, ਫਿਰ ਦੋਵੇਂ ਰਸਤੇ ਬਦਲੋ:

```text
xcopy "D:\Users\Name\Documents" "E:\Backup\Documents" /S /E /I /H /V
```

**`/S /E`** ਖਾਲੀ ਸਮੇਤ ਸਬਫੋਲਡਰ ਸ਼ਾਮਲ ਕਰਦੇ ਹਨ। **`/I`** ਮੰਜ਼ਿਲ ਨੂੰ ਫੋਲਡਰ ਮੰਨਦਾ ਹੈ, **`/H`** ਲੁਕੀਆਂ ਫ਼ਾਈਲਾਂ ਰੱਖਦਾ ਹੈ ਅਤੇ **`/V`** ਲਿਖੀ ਹਰ ਫ਼ਾਈਲ ਜਾਂਚਦਾ ਹੈ। Microsoft ਇਹ ਵਿਕਲਪ [xcopy ਸੰਦਰਭ](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/xcopy) ਵਿੱਚ ਦੱਸਦਾ ਹੈ। ਹੋਰ ਲੋੜੀਂਦੇ ਫੋਲਡਰਾਂ ਲਈ ਦੁਹਰਾਓ। Windows ਡਰਾਈਵ ਮਿਟਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਕਾਪੀ ਕੀਤੀਆਂ ਫ਼ਾਈਲਾਂ ਦੂਜੇ ਡਿਵਾਈਸ 'ਤੇ ਖੋਲ੍ਹੋ। ਵਾਲਿਊਮ ਪਛਾਣ ਨਾ ਸਕੋ ਜਾਂ ਨਕਲ ਫੇਲ੍ਹ ਹੋਵੇ ਤਾਂ ਰੁਕੋ ਅਤੇ ਭਰੋਸੇਯੋਗ ਡਾਟਾ ਰਿਕਵਰੀ ਮਾਹਰ ਦੀ ਮਦਦ ਲਵੋ।

## ਫ਼ੈਸਲਾ ਕਰੋ ਕਿ ਮੁੜ ਇੰਸਟਾਲ ਕਰਨਾ ਹੈ ਜਾਂ ਨਹੀਂ

**ਕੁੰਜੀ ਦਾ ਬੈਕਅੱਪ ਫ਼ਾਈਲਾਂ ਦਾ ਬੈਕਅੱਪ ਨਹੀਂ ਹੁੰਦਾ।** ਮੁੜ ਇੰਸਟਾਲ ਦਾ ਰਾਹ ਚੁਣਨ ਤੋਂ ਪਹਿਲਾਂ ਇਹ ਕ੍ਰਮ ਅਪਣਾਓ:

1. ਇਨਕ੍ਰਿਪਟ ਕੀਤੀ ਡਰਾਈਵ ਅਤੇ ਉਸ ਦੀ ਰਿਕਵਰੀ ਕੁੰਜੀ ID ਪਛਾਣੋ।
2. ਖਾਤੇ, ਪ੍ਰਿੰਟ ਜਾਂ USB ਬੈਕਅੱਪ ਤੋਂ ਮੈਲ ਖਾਂਦੀ 48-ਅੰਕਾਂ ਦੀ ਕੁੰਜੀ ਲਵੋ।
3. ਡਰਾਈਵ ਲਾਕ ਹੋਵੇ ਤਾਂ ਰਿਕਵਰੀ ਸਕ੍ਰੀਨ ਜਾਂ ਟੂਲਾਂ ਰਾਹੀਂ ਖੋਲ੍ਹੋ।
4. Desktop, Documents, Pictures ਅਤੇ ਹੋਰ ਸਥਾਨਕ ਫੋਲਡਰ ਬਾਹਰੀ ਡਰਾਈਵ ਜਾਂ ਭਰੋਸੇਯੋਗ ਕਲਾਊਡ 'ਤੇ ਕਾਪੀ ਕਰੋ। ਲੋੜ ਹੋਵੇ ਤਾਂ ਬ੍ਰਾਊਜ਼ਰ ਨਿਰਯਾਤ, ਐਪ ਡਾਟਾ ਅਤੇ ਲਾਇਸੈਂਸ ਰਿਕਾਰਡ ਵੀ ਰੱਖੋ।
5. ਦੂਜੇ ਡਿਵਾਈਸ ਤੋਂ ਕਾਪੀ ਕੀਤੀਆਂ ਕੁਝ ਫ਼ਾਈਲਾਂ ਖੋਲ੍ਹੋ।
6. ਬੈਕਅੱਪ ਜਾਂਚਣ ਮਗਰੋਂ ਹੀ ਮੁਰੰਮਤ, ਰੀਸੈੱਟ ਜਾਂ ਮੁੜ ਇੰਸਟਾਲ ਚੁਣੋ।

> **ਉਮੀਦਿਤ ਨਤੀਜਾ:** ਮੈਲ ਖਾਂਦੀ ਕੁੰਜੀ ਅਤੇ ਮਹੱਤਵਪੂਰਨ ਫ਼ਾਈਲਾਂ ਪੁਰਾਣੀ Windows ਇੰਸਟਾਲ ਤੋਂ ਬਾਹਰ ਖੁੱਲ੍ਹਦੀਆਂ ਹਨ।

Microsoft [Windows ਰਿਕਵਰੀ ਵਿਕਲਪ](https://support.microsoft.com/en-us/windows/experience/backup-recovery/recovery-options-in-windows) ਦੱਸਦਾ ਹੈ, ਜਿਨ੍ਹਾਂ ਦਾ ਫ਼ਾਈਲਾਂ ਅਤੇ ਐਪਾਂ 'ਤੇ ਵੱਖਰਾ ਅਸਰ ਹੁੰਦਾ ਹੈ। BitLocker ਡਰਾਈਵ ਦੀ ਰੱਖਿਆ ਕਰਦਾ ਹੋਵੇ ਤਾਂ Windows ਰਿਕਵਰੀ ਵਾਤਾਵਰਣ ਦੇ ਕਈ ਵਿਕਲਪਾਂ ਲਈ ਕੁੰਜੀ ਚਾਹੀਦੀ ਹੈ। ਉੱਥੇ ਵਾਲਿਊਮ ਲਾਕ ਹੋਵੇ ਤਾਂ ਕੁੰਜੀ ਤੋਂ ਬਿਨਾਂ **ਮੇਰੀਆਂ ਫ਼ਾਈਲਾਂ ਰੱਖੋ** ਉਸ ਨੂੰ ਨਹੀਂ ਖੋਲ੍ਹਦਾ।

**ਸਟਾਰਟਅੱਪ ਮੁਰੰਮਤ** ਅਤੇ **ਸਿਸਟਮ ਰੀਸਟੋਰ** ਮੌਜੂਦਾ ਇੰਸਟਾਲ ਠੀਕ ਕਰਨ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਦੇ ਹਨ। **ਇਸ PC ਨੂੰ ਰੀਸੈੱਟ ਕਰੋ** ਵਿੱਚ **ਮੇਰੀਆਂ ਫ਼ਾਈਲਾਂ ਰੱਖੋ** ਵਿਕਲਪ ਹੈ, ਪਰ ਐਪਾਂ ਅਤੇ ਸੈਟਿੰਗਾਂ ਮਿਟ ਜਾਂਦੀਆਂ ਹਨ। **ਸਭ ਕੁਝ ਹਟਾਓ** ਨਿੱਜੀ ਫ਼ਾਈਲਾਂ ਮਿਟਾਉਂਦਾ ਹੈ। ਚੱਲਦੇ Windows ਸੈਸ਼ਨ ਵਿੱਚ **`setup.exe` ਚਲਾਉਣ ਨਾਲ** ਡਾਟਾ ਰੱਖਣ ਦੇ ਵਿਕਲਪਾਂ ਵਾਲਾ ਇਨ-ਪਲੇਸ ਮੁੜ ਇੰਸਟਾਲ ਹੁੰਦਾ ਹੈ। ਇੰਸਟਾਲੇਸ਼ਨ USB ਤੋਂ ਬੂਟ ਕਰਕੇ **Windows ਇੰਸਟਾਲ ਕਰੋ** ਚੁਣਨ ਨਾਲ ਕਲੀਨ ਇੰਸਟਾਲ ਸ਼ੁਰੂ ਹੁੰਦਾ ਹੈ, ਜੋ ਚੁਣੀ Windows ਇੰਸਟਾਲ ਦੇ ਫ਼ਾਈਲਾਂ, ਐਪਾਂ ਅਤੇ ਸੈਟਿੰਗਾਂ ਹਟਾਉਂਦਾ ਹੈ। ਉਹੀ ਮੀਡੀਆ ਮੁਰੰਮਤ ਦਾ ਰਾਹ ਵੀ ਦਿੰਦੀ ਹੈ। ਰੀਸੈੱਟ ਜਾਂ ਇੰਸਟਾਲ ਦੀ ਪੁਸ਼ਟੀ ਤੋਂ ਪਹਿਲਾਂ ਦਿਖਾਇਆ ਵਿਕਲਪ ਅਤੇ ਟਾਰਗੇਟ ਡਿਸਕ ਪੜ੍ਹੋ। Microsoft ਦੋਵੇਂ ਰਾਹ [ਮੁੜ ਇੰਸਟਾਲ ਨਿਰਦੇਸ਼ਾਂ](https://support.microsoft.com/en-us/windows/deployment/install-upgrade/reinstall-windows-with-the-installation-media) ਵਿੱਚ ਸਮਝਾਉਂਦਾ ਹੈ।

| ਹਾਲਤ | ਅਗਲਾ ਕਦਮ |
|---|---|
| **Windows ਚੱਲਦਾ ਹੈ ਅਤੇ ਫ਼ਾਈਲਾਂ ਚਾਹੀਦੀਆਂ ਹਨ** | ਫ਼ਾਈਲਾਂ ਦਾ ਬੈਕਅੱਪ ਲਵੋ, ਕੁੰਜੀ ਜਾਂਚੋ ਅਤੇ ਫਿਰ ਮੁਰੰਮਤ ਜਾਂ ਮੁੜ ਇੰਸਟਾਲ ਚੁਣੋ। |
| **Windows ਕੁੰਜੀ ਮੰਗਦਾ ਹੈ** | ਡਰਾਈਵ ਬਦਲਣ ਤੋਂ ਪਹਿਲਾਂ ਸਕ੍ਰੀਨ ID ਨੂੰ ਸੰਭਾਲੀ ਕੁੰਜੀ ਨਾਲ ਮਿਲਾਓ। |
| **ਮੈਲ ਖਾਂਦੀ ਕੁੰਜੀ ਵੀ ਨਹੀਂ ਅਤੇ ਫ਼ਾਈਲ ਬੈਕਅੱਪ ਵੀ ਨਹੀਂ** | ਡਰਾਈਵ ਮਿਟਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਰੁਕੋ। ਹਰ ਖਾਤਾ, ਪ੍ਰਿੰਟ, USB ਬੈਕਅੱਪ ਅਤੇ IT ਟੀਮ ਜਾਂਚੋ। |
| **ਫ਼ਾਈਲਾਂ ਕਾਪੀ ਹਨ ਅਤੇ ਨਵੀਂ ਸ਼ੁਰੂਆਤ ਚਾਹੁੰਦੇ ਹੋ** | Microsoft ਦੇ [ਮੁੜ ਇੰਸਟਾਲ ਨਿਰਦੇਸ਼](https://support.microsoft.com/en-us/windows/deployment/install-upgrade/reinstall-windows-with-the-installation-media) ਮੰਨੋ ਅਤੇ ਟਾਰਗੇਟ ਡਿਸਕ ਧਿਆਨ ਨਾਲ ਚੁਣੋ। |

Microsoft ਕਹਿੰਦਾ ਹੈ ਕਿ ਸਹਾਇਤਾ ਕਰਮਚਾਰੀ ਗੁੰਮ ਹੋਈ ਰਿਕਵਰੀ ਕੁੰਜੀ ਦੁਬਾਰਾ ਨਹੀਂ ਬਣਾ ਸਕਦੇ। ਕੁੰਜੀ ਨਾ ਮਿਲੇ ਤਾਂ firmware ਸੈਟਿੰਗਾਂ ਬਦਲਣੀਆਂ ਰੋਕੋ ਅਤੇ ਸਾਰੇ ਬੈਕਅੱਪ ਸਥਾਨ ਜਾਂਚੋ। ਪ੍ਰਬੰਧਿਤ ਡਿਵਾਈਸ ਲਈ ਪ੍ਰਸ਼ਾਸਕ ਤੋਂ ਮਦਦ ਲਵੋ। ਲੋੜੀਂਦੀ ਕੁੰਜੀ ਬਿਨਾਂ ਰੀਸੈੱਟ ਨਾਲ ਪੁਰਾਣੀਆਂ ਫ਼ਾਈਲਾਂ ਮਿਟਦੀਆਂ ਹਨ। ਕਲੀਨ ਇੰਸਟਾਲ ਚੁਣੀ ਇੰਸਟਾਲ ਦੀਆਂ ਨਿੱਜੀ ਫ਼ਾਈਲਾਂ, ਐਪਾਂ, ਡਿਵਾਈਸ ਬਦਲਾਅ ਅਤੇ ਸੈਟਿੰਗਾਂ ਵੀ ਮਿਟਾਉਂਦਾ ਹੈ। ਬੈਕਅੱਪ ਜਾਂਚਣ ਮਗਰੋਂ ਹੀ ਫ਼ੈਸਲਾ ਕਰੋ।

## ਸਮੱਸਿਆ ਹੱਲ

- **ਕੁੰਜੀ ਕੰਮ ਨਹੀਂ ਕਰਦੀ:** ID ਅਤੇ ਖਾਤਾ ਮੁੜ ਜਾਂਚੋ। ਡਿਵਾਈਸ 'ਤੇ ਕਈ ਕੁੰਜੀਆਂ ਹੋ ਸਕਦੀਆਂ ਹਨ।
- **BitLocker ਪ੍ਰਬੰਧਿਤ ਕਰੋ ਨਹੀਂ ਮਿਲਦਾ:** Windows Home ਯੋਗ ਡਿਵਾਈਸਾਂ 'ਤੇ ਡਿਵਾਈਸ ਇਨਕ੍ਰਿਪਸ਼ਨ ਵਰਤਦਾ ਹੈ। ਸੈਟਿੰਗਾਂ ਅਤੇ ਸੈੱਟਅੱਪ ਵਾਲਾ Microsoft ਖਾਤਾ ਜਾਂਚੋ।
- **ਖਾਤੇ ਵਿੱਚ ਕਈ ਕੁੰਜੀਆਂ ਹਨ:** ਸਕ੍ਰੀਨ ID ਦੇ ਪਹਿਲੇ ਅੱਠ ਅੰਕ ਸੰਭਾਲੀਆਂ ਐਂਟਰੀਆਂ ਨਾਲ ਮਿਲਾਓ। ਸਿਰਫ਼ ਡਿਵਾਈਸ ਦੇ ਨਾਮ ਨਾਲ ਕੁੰਜੀ ਨਾ ਚੁਣੋ।
- **ਕੁੰਜੀ ਡਰਾਈਵ ਖੋਲ੍ਹਦੀ ਹੈ ਪਰ Windows ਨਹੀਂ ਚੱਲਦਾ:** Windows ਰਿਕਵਰੀ ਵਾਤਾਵਰਣ ਤੋਂ ਸਟਾਰਟਅੱਪ ਮੁਰੰਮਤ ਅਜ਼ਮਾਓ। ਰੀਸੈੱਟ ਜਾਂ ਕਲੀਨ ਇੰਸਟਾਲ ਤੋਂ ਪਹਿਲਾਂ ਪਹੁੰਚ ਵਾਲੀਆਂ ਫ਼ਾਈਲਾਂ ਕਾਪੀ ਕਰੋ।
- **ਕੁੰਜੀ ਕੰਮ ਜਾਂ ਸਕੂਲ ਕੋਲ ਹੈ:** ਰੀਸੈੱਟ ਜਾਂ ਮੁੜ ਇੰਸਟਾਲ ਤੋਂ ਪਹਿਲਾਂ ਡਿਵਾਈਸ ਪ੍ਰਸ਼ਾਸਕ ਨਾਲ ਗੱਲ ਕਰੋ।
- **ਕੁੰਜੀ ਫ਼ਾਈਲ ਲਾਕ ਕੰਪਿਊਟਰ 'ਤੇ ਹੈ:** ਵੱਖਰਾ ਖਾਤਾ, ਪ੍ਰਿੰਟ ਜਾਂ ਹਟਾਈ ਜਾ ਸਕਣ ਵਾਲਾ ਬੈਕਅੱਪ ਲੱਭੋ। ਸਿਰਫ਼ ਲਾਕ ਇਨਕ੍ਰਿਪਟ ਕੀਤੀ ਡਰਾਈਵ ਵਾਲੀ ਕਾਪੀ ਮਦਦ ਨਹੀਂ ਕਰਦੀ।
- **Firmware ਬਦਲਣ ਤੋਂ ਬਾਅਦ ਸੁਨੇਹਾ ਆਇਆ:** ਬਦਲਾਅ ਲਿਖ ਲਵੋ ਅਤੇ ਹੋਰ firmware ਨਾ ਬਦਲੋ। ਮੈਲ ਖਾਂਦੀ ਕੁੰਜੀ ਲੱਭੋ ਜਾਂ ਪ੍ਰਸ਼ਾਸਕ ਨਾਲ ਸੰਪਰਕ ਕਰੋ।

## ਅਗਲੇ ਕਦਮ

ਕੁੰਜੀ ਅਤੇ ਫ਼ਾਈਲਾਂ ਜਾਂਚਣ ਮਗਰੋਂ ਜੇ ਕਲੀਨ ਇੰਸਟਾਲ ਤੁਹਾਡੇ ਉਦੇਸ਼ ਲਈ ਢੁੱਕਵੀਂ ਹੈ ਤਾਂ [Windows ਕਲੀਨ ਇੰਸਟਾਲ ਗਾਈਡ](/articles/how-to-install-windows-10-and-windows-11-from-scratch/) ਮੰਨੋ। Windows ਚੱਲਣ 'ਤੇ **ਸੈਟਿੰਗਾਂ > ਪਰਦੇਦਾਰੀ ਅਤੇ ਸੁਰੱਖਿਆ > ਡਿਵਾਈਸ ਇਨਕ੍ਰਿਪਸ਼ਨ** ਵੇਖੋ ਜਾਂ **BitLocker ਪ੍ਰਬੰਧਿਤ ਕਰੋ** ਲੱਭੋ। Pro, Enterprise ਜਾਂ Education ਵਿੱਚ **ਰਿਕਵਰੀ ਕੁੰਜੀ ਦਾ ਬੈਕਅੱਪ ਬਣਾਓ** ਚੁਣੋ। Home ਵਿੱਚ ਲਿੰਕ ਕੀਤੇ ਖਾਤੇ ਦੀ ਮੌਜੂਦਾ ਕੁੰਜੀ ਜਾਂਚੋ ਅਤੇ Windows ਨਿਰਯਾਤ ਦੇਵੇ ਤਾਂ ਵੱਖਰੀ ਕਾਪੀ ਰੱਖੋ। ਇਹ ਨਾ ਮੰਨੋ ਕਿ ਪੁਰਾਣੀ ਕੁੰਜੀ ਨਵੀਂ ਇਨਕ੍ਰਿਪਟ ਕੀਤੀ ਇੰਸਟਾਲ 'ਤੇ ਚੱਲੇਗੀ।
