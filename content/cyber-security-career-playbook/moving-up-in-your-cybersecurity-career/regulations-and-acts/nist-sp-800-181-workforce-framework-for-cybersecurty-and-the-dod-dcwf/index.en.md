The NICE Framework and the **DoD Cyber Workforce Framework (DCWF)** share workforce concepts and mappings. They serve different governance contexts. A mapping does not make the two systems identical.

## Compare the Purpose

| Item | NICE Framework | DoD DCWF and 8140 program |
|---|---|---|
| **Primary purpose** | Common language for cybersecurity work and capability | DoD workforce identification, coding, qualification, and management |
| **Audience** | Public and private employers, learners, educators, providers | Covered DoD organizations, positions, personnel, and contracts |
| **Core records** | Work Role Categories, Work Roles, Competency Areas, and TKS statements | Workforce elements, work roles, proficiency levels, coded positions, qualification matrices |
| **Qualification rule** | NICE does not mandate a credential for a job | DoD program and component rules set accepted qualification paths |
| **Update source** | NIST current-versions page | DoD issuances, matrices, procedures, and component guidance |

Older NICE articles often use seven categories, Specialty Areas, and Knowledge, Skills, and Abilities as current structure. Use SP 800-181 Rev. 1 and the current Components instead.

## Map Without Overclaiming

Start with actual position duties. Map them to the exact current framework elements. Record gaps and non-equivalences. Do not infer an accepted DoD qualification from a NICE match.

## Exercise

Use this fictional task: “Review identity logs, document suspicious access, and escalate according to the incident plan.”

Create a record with:

1. Task and expected output
2. Current NICE Work Role and Components version
3. Candidate DCWF work role and source date
4. Overlap
5. Work present in one model but absent from the other mapping
6. Position coding authority
7. Qualification decision source

**Pass condition:** The record cites current sources, distinguishes mapping from qualification, and assigns coding and qualification decisions to the proper organization.
