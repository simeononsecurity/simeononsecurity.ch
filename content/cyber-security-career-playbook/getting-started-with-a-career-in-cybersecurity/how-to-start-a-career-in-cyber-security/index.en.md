Start with a role and a small work sample. Avoid buying a long list of courses or credentials before you know which tasks employers request.

## Days 1 to 5: Choose a Role

Compare three role families in [Cybersecurity Specializations](/cyber-security-career-playbook/getting-started-with-a-career-in-cybersecurity/exploring-different-cybersecurity-specalizations/). Collect five current postings for each. Record tasks, filters, location, schedule, and tools.

Select one primary path and one adjacent route.

## Days 6 to 10: Check Foundations

Test your understanding of operating systems, networking, scripting, and security basics. Use small tasks:

- Explain a DNS lookup and TLS connection.
- Create a user and review permissions in a disposable VM.
- Parse a short log file with a script or spreadsheet.
- Write an alert note which separates evidence from assumptions.

Record gaps. Do not hide them behind a course-completion badge.

## Days 11 to 24: Build One Project

Choose a project tied to a repeated job task. Define scope, starting state, steps, expected result, failure case, cleanup, and portfolio artifact.

Use owned, authorized, or disposable systems. Offensive testing needs written scope. Keep vulnerable targets on an isolated host-only network.

## Days 25 to 27: Request Review

Ask one peer or practitioner to score accuracy, safety, reproducibility, and clarity. Give the reviewer the objective and pass condition. Revise the artifact once.

## Days 28 to 30: Compare Evidence

Revisit the 15 postings. Mark each repeated task as proved, practiced, missing, or blocked. Write one truthful resume bullet and one 60-second project explanation.

## Completion Check

Your 30-day packet should include:

1. Fifteen-posting comparison
2. Foundation gap list
3. One safe project artifact
4. Reviewer feedback and revision
5. Resume bullet and explanation
6. Next 30-day target

**Pass condition:** The project matches a repeated task, the reviewer finds no safety issue, every claim links to evidence, and the next step closes an observed gap.
