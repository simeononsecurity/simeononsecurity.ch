## AWS Certification Path for Developers

AWS publishes Foundational, Associate, Professional, and Specialty credentials. The catalog changes, so confirm the current exam page before purchase.

### Tier 1: Foundational

**AWS Certified Cloud Practitioner (CLF-C02)**

- **What it covers**: cloud concepts, AWS global infrastructure, core services overview, billing and pricing.
- **Who it is for**: learners seeking broad AWS concepts. AWS does not require this credential before an Associate exam.
- **Plan**: compare the current exam guide, price, delivery rules, and renewal policy with your target posting evidence.

### Tier 2: Associate

**AWS Certified Developer – Associate (DVA-C02)**

- **What it covers**: developing, deploying, and debugging cloud-native applications on AWS. Lambda, API Gateway, DynamoDB, S3, CodePipeline, CloudFormation, IAM for developers.
- **Who it is for**: developers actively building applications on AWS.
- **Preparation**: use the current DVA-C02 exam guide and close skill gaps with a bounded lab.
- **Role fit**: target postings which name AWS application development tasks.

**AWS Certified Solutions Architect – Associate (SAA-C03)**

- **What it covers**: designing distributed systems, selecting appropriate AWS services, cost optimization, security architecture.
- **Who it is for**: developers moving toward cloud engineering, architecture, or DevOps.
- **Preparation**: use the current SAA-C03 exam guide and practice design trade-offs.
- **Role fit**: target postings which include AWS architecture or cloud engineering work.

### Tier 3: Professional

**AWS Certified Solutions Architect – Professional (SAP-C02)**

- **What it covers**: advanced architecture for complex, large-scale deployments, migration strategies, cost optimization at scale.
- **Who it is for**: experienced cloud engineers or senior developers with 2+ years of hands-on AWS.
- **Preparation**: plan from the current exam guide and your measured practice results.

AWS does not require an Associate credential before a Professional exam. Compare the current exam guide and recommended experience with your evidence before scheduling.

## Azure Certification Path for Developers

**Microsoft Certified: Azure AI Cloud Developer Associate (AI-200)**

- **What it covers**: containerized Azure applications, AI data services, event-driven components, security, monitoring, and troubleshooting.
- **Who it is for**: developers implementing AI solutions and supporting backend services on Azure.
- **Preparation**: compare the current [AI-200 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-200) with your work and build a small Azure project before choosing an exam date.

The former Azure Developer Associate exam, AZ-204, [retired on July 31, 2026](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-204). AI-200 is the current AI cloud developer path. Its scope differs from AZ-204, so check the objectives before treating it as a direct replacement for every Azure developer role.

**Microsoft Azure Solutions Architect Expert (AZ-305)**

- **What it covers**: designing Azure-based solutions covering identity, governance, data, business continuity, and infrastructure.
- **Who it is for**: senior developers and cloud architects.
- **Certification requirement**: earn Azure Administrator Associate, based on AZ-104, and pass AZ-305 to earn Azure Solutions Architect Expert.

## Google Cloud Certification Path for Developers

**Google Associate Cloud Engineer**

- **What it covers**: deploying applications, monitoring operations, and managing GCP infrastructure including Compute Engine, Kubernetes Engine, Cloud Storage, BigQuery, and Cloud Operations.
- **Who it is for**: developers working in GCP environments.
- **Preparation**: use the current official exam guide and measure readiness with hands-on tasks.

**Google Professional Cloud Developer**

- **What it covers**: building scalable applications, designing APIs, implementing CI/CD pipelines, and managing cloud resources programmatically.
- **Who it is for**: developers building production applications on GCP.
- **Preparation**: use the current official exam guide and build the listed skills before scheduling.
