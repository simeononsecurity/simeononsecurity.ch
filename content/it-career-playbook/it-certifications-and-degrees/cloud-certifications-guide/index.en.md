Choose a cloud credential after checking the platform used in your target roles. A certification verifies performance against an exam blueprint. It does not, by itself, show production experience or guarantee a pay increase. Exam names, objectives, prices, and prerequisites change.

## Compare Current Role Paths

The following examples were checked against provider pages in October 2026. Use the linked provider catalog before booking an exam.

| Platform | Starting point | Role-focused next step |
|---|---|---|
| [AWS](https://aws.amazon.com/certification/) | Cloud Practitioner for fundamentals | Solutions Architect Associate for design, Developer Associate for application work, or [CloudOps Engineer Associate](https://aws.amazon.com/certification/certified-cloudops-engineer-associate/) for operations |
| [Microsoft Azure](https://learn.microsoft.com/en-us/credentials/) | AZ-900 for Azure fundamentals | AZ-104 for administration, [AI-200](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-200) for AI cloud development, or [SC-500](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/sc-500) for cloud and AI security |
| [Google Cloud](https://cloud.google.com/learn/certification) | Cloud Digital Leader for fundamentals | [Associate Cloud Engineer](https://cloud.google.com/learn/certification/guides/cloud-engineer) for operations or a professional exam aligned to your work |

AWS renamed SysOps Administrator Associate to CloudOps Engineer Associate for its current SOA-C03 exam. Microsoft retired AZ-204, AZ-500, and MS-900 in 2026. The new AI-200 and SC-500 paths cover different scopes from the former exams. Review the [Microsoft retired-exam list](https://learn.microsoft.com/en-us/credentials/support/retired-certification-exams) and each current study guide before choosing one.

## Pick by Duties, Not a Ranking

Read five target postings. Count which platforms and tasks appear. A posting that requires Azure identity administration points to different preparation from one that asks for AWS deployment or Google Cloud data processing. Do not choose a provider based on a broad market-share claim without a dated source and a defined market.

Download the current exam guide. Mark every domain as practiced, studied, or new. If the exam assumes professional experience, build that experience through authorized work or a realistic lab before paying for an attempt. No fixed study-hour estimate applies to everyone.

## Build a Small Lab Record

For an operations path, create a disposable cloud resource under your own account. Set a budget alert and least-privilege access. Record the resource, one configuration change, a monitoring check, and a cleanup check. Capture no secrets in screenshots or public notes. Confirm the resource is deleted and review charges afterward.

If cloud charges are a concern, begin with provider documentation or a local simulation. A free training page does not guarantee free cloud resources. Use the [training resources guide](/it-career-playbook/getting-started-in-it/it-training-resources-online/) to compare access and current costs.

## Decision Exercise

Write a one-page plan with your target role, five posting links, chosen provider, current exam code, three objective gaps, one practice task, and a cost limit. Recheck the exam version and booking rules before registering.
