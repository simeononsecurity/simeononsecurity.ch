Cisco credentials cover network support, administration, design, security, and automation. A credential demonstrates tested knowledge under its exam rules. A lab or work record shows how you applied the skill. Check the [current Cisco certification map](https://www.cisco.com/site/us/en/learn/training-certifications/certifications/index.html) before registering because names and exams change.

## Start with the Work You Want

| Target work | Credential to investigate | Practice evidence |
|---|---|---|
| Network support and administration | CCNA 200-301 | Subnet plan, VLAN and routing configuration, verification output |
| Enterprise networks | CCNP Enterprise | A documented routing or switching design with failure testing |
| Security operations on Cisco platforms | Current Cisco cybersecurity or security track | Segmentation policy and permitted-traffic test |
| Network automation | CCNA, CCNP, or CCIE Automation | A script against an authorized lab API, with rollback and error handling |
| Expert design and troubleshooting | Relevant CCIE track | A multi-site lab with a written design, tests, and recovery record |

Cisco [rebranded the DevNet track as CCNA, CCNP, and CCIE Automation in February 2026](https://blogs.cisco.com/learning/par-merat-announces-learn-with-cisco). Older materials might still say DevNet. Compare the exam code and current topic list, not only the course title.

## CCNA 200-301

Cisco's [CCNA exam page](https://www.cisco.com/site/us/en/learn/training-certifications/exams/ccna.html) describes version 1.1 as a 120-minute exam covering network fundamentals, network access, IP connectivity, IP services, security fundamentals, and automation. Cisco does not publish one stable passing score or a guaranteed question count for learners to plan around. Use the official topics and the current booking page for exam details.

Practice in an authorized simulator or on devices you own. For a first lab, create two VLANs, assign one test host to each, configure inter-VLAN routing, and record pings and route or interface output before and after a deliberate misconfiguration. Restore the working configuration and save both the commands and observed results. Do not test a third-party network.

[Follow the site's CCNA topic guide](/ccna-start/) for concepts, then compare its lessons with Cisco's official exam topics. The site course is a topic guide and does not replace full hands-on preparation for every objective.

## Professional and Expert Paths

Cisco's [professional certification page](https://www.cisco.com/site/us/en/learn/training-certifications/certifications/professional/index.html) describes a core exam plus a concentration exam for a CCNP track. Choose the track named in your target roles, then confirm current exam codes and topics. A core exam in a technology track can also qualify a candidate for the matching CCIE lab, subject to Cisco's current rules.

The [CCIE practical exam format](https://learningnetwork.cisco.com/s/article/ccie-practical-exam-format) describes an eight-hour lab. Cisco has announced format changes beginning in 2027, so verify the format for your track and date. Do not rely on claims about average attempts, pass rates, or salary premiums without a defined dataset.

## Decision Exercise

Collect three real network-role postings in your area. Mark each named platform and skill. Select one Cisco track only if it matches those duties. Download its official topic list, mark two skills you can already demonstrate, and pick one lab to close a gap. Record the exam version and review date in your study plan.
