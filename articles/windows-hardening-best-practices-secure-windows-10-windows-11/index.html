परिचय #

दुनिया भर में व्यक्ति और संगठन Windows ऑपरेटिंग सिस्टम का व्यापक उपयोग करते हैं। इन सिस्टम की सुरक्षा और अखंडता बनाए रखने के लिए Windows सुरक्षा सुदृढ़ीकरण के सर्वोत्तम तरीके लागू करें। सुदृढ़ीकरण में हमले की सतह घटाकर और संभावित कमज़ोरियों का जोखिम कम करके ऑपरेटिंग सिस्टम को सुरक्षित करना शामिल है। इस लेख में Windows 10 और नए Windows 11 को सुदृढ़ करने के सर्वोत्तम तरीके बताए गए हैं, ताकि आपके Windows परिवेश की सुरक्षा बेहतर हो।

Windows सुरक्षा सुदृढ़ीकरण को समझना #

Windows सुरक्षा सुदृढ़ीकरण का अर्थ Windows ऑपरेटिंग सिस्टम की सुरक्षा मज़बूत करना है। इसमें अनधिकृत पहुँच, मैलवेयर और अन्य खतरों से बचाव के लिए अलग-अलग सेटिंग कॉन्फ़िगर करना और सुरक्षा उपाय लागू करना शामिल है। Windows सिस्टम को सुदृढ़ करके आप साइबर हमलों से जुड़े जोखिम घटा सकते हैं और अपने डेटा की गोपनीयता, अखंडता तथा उपलब्धता सुनिश्चित कर सकते हैं।

Windows 10 को सुदृढ़ करना #

Windows 10 दुनिया भर में सबसे अधिक उपयोग किए जाने वाले ऑपरेटिंग सिस्टमों में से एक है। अपने Windows 10 परिवेश को सुदृढ़ करने के लिए इन सर्वोत्तम तरीकों पर विचार करें:

1. Windows Defender चालू करें #

Windows Defender, Windows 10 में शामिल एक मज़बूत एंटीवायरस समाधान है। इसमें मैलवेयर, जैसे वायरस, स्पाइवेयर और रैनसमवेयर, से सिस्टम की रक्षा करने वाली कई सुविधाएँ हैं। Windows Defender चालू करके आप अपने Windows 10 परिवेश की सुरक्षा को उल्लेखनीय रूप से बढ़ा सकते हैं।

Windows Defender चालू करने के लिए:

  • टास्कबार के Windows Security आइकन पर क्लिक करें या Start मेनू में “Windows Security” खोजें और Windows Security ऐप खोलें।
  • ऐप के बाईं ओर के नेविगेशन पैन में “वायरस और खतरे से सुरक्षा” चुनें।
  • “वायरस और खतरे से सुरक्षा की सेटिंग” के नीचे “सेटिंग प्रबंधित करें” पर क्लिक करें।
  • सुनिश्चित करें कि “रीयल-टाइम सुरक्षा” टॉगल “चालू” पर है। इससे Windows Defender रीयल टाइम में आपके सिस्टम को स्कैन और सुरक्षित करता है।
  • “स्कैन विकल्प” और “अपवाद जोड़ें या हटाएँ” पर क्लिक करके स्कैन विकल्प और अपवादों को अपनी आवश्यकता के अनुसार बदलें।

Windows Defender को नियमित रूप से अपडेट करें, ताकि उसमें नवीनतम मैलवेयर परिभाषाएँ और सुरक्षा सुधार हों। नए खतरों और कमज़ोरियों से निपटने के लिए Microsoft नियमित अपडेट जारी करता है। Windows Defender अपडेट करने के लिए:

  • Windows Security ऐप खोलें।
  • बाईं ओर के नेविगेशन पैन में “वायरस और खतरे से सुरक्षा” पर जाएँ।
  • “वायरस और खतरे से सुरक्षा अपडेट” के नीचे “अपडेट जाँचें” पर क्लिक करें।
  • Windows उपलब्ध अपडेट जाँचेगा और ज़रूरत पड़ने पर उन्हें डाउनलोड तथा इंस्टॉल करेगा।

Windows Defender चालू रखकर और उसे अपडेट करके आप अपने Windows 10 सिस्टम को मैलवेयर और अन्य सुरक्षा खतरों से सक्रिय रूप से बचा सकते हैं। संभावित खतरों का पता लगाने और उन्हें हटाने के लिए Windows Defender से सिस्टम स्कैन नियमित रूप से करना भी उचित है।

याद रखें, Windows Defender अच्छी सुरक्षा देता है, फिर भी सुरक्षित ब्राउज़िंग की आदतें अपनाएँ, सॉफ़्टवेयर नियमित अपडेट करें और Windows 10 परिवेश को सुरक्षित रखने के लिए अन्य सुरक्षा उपाय भी लागू करें।

2. Windows 10 अपडेट रखें #

Windows अपडेट नियमित रूप से इंस्टॉल करना Windows 10 सुरक्षा सुदृढ़ीकरण का अहम हिस्सा है। इन अपडेट में सुरक्षा पैच, बग सुधार और प्रदर्शन सुधार शामिल होते हैं। ये सुरक्षा कमज़ोरियों के पैच लगाने और सिस्टम की स्थिरता बेहतर करने में मदद करते हैं।

नए सामने आए सुरक्षा मुद्दों का समाधान करने और उपयोगकर्ता अनुभव सुधारने के लिए Microsoft नियमित अपडेट जारी करता है। सिस्टम को अपडेट रखने से ऑपरेटिंग सिस्टम में उभरते खतरों से बचाव के लिए नवीनतम सुरक्षा सुधार उपलब्ध रहते हैं।

Windows 10 अपडेट रखने के लिए:

  1. स्वचालित अपडेट चालू करें: डिफ़ॉल्ट रूप से Windows 10 अपडेट अपने आप डाउनलोड और इंस्टॉल करने के लिए सेट होता है। इससे बिना हाथ से प्रक्रिया शुरू किए ज़रूरी अपडेट मिलते हैं। स्वचालित अपडेट चालू हैं या नहीं, यह जाँचने के लिए:

    • Start मेनू खोलें और गियर आइकन चुनकर सेटिंग्स पर जाएँ।
    • Update & Security (अपडेट और सुरक्षा) चुनें।
    • बाईं ओर के नेविगेशन पैन में Windows Update पर क्लिक करें।
    • “Windows Update सेटिंग” के नीचे “स्वचालित” चुना है या नहीं देखें। यदि नहीं, तो “सक्रिय घंटे बदलें” लिंक पर क्लिक करके वे घंटे तय करें जिनमें Windows अपडेट इंस्टॉल न करे।

  2. अपडेट हाथ से इंस्टॉल करें: अपडेट प्रक्रिया पर अधिक नियंत्रण चाहिए, तो Windows 10 सिस्टम पर अपडेट स्वयं इंस्टॉल करें:

    • Settings (सेटिंग) > Update & Security (अपडेट और सुरक्षा) > Windows Update पर जाएँ।
    • सिस्टम के लिए उपलब्ध अपडेट देखने को “अपडेट जाँचें” पर क्लिक करें।
    • अपडेट मिलने पर इंस्टॉलेशन शुरू करने के लिए “डाउनलोड” और “इंस्टॉल” चुनें।

अपडेट इंस्टॉल करने के बाद सिस्टम को नियमित रूप से रीस्टार्ट करना ज़रूरी है। कुछ अपडेट को बदलाव पूरी तरह लागू करने और उनका असर सुनिश्चित करने के लिए रीस्टार्ट चाहिए।

Windows 10 सिस्टम अपडेट रखने से उसकी सुरक्षा बेहतर होती है और नवीनतम सुविधाएँ, प्रदर्शन सुधार तथा अनुकूलता सुधार भी मिलते हैं। यह सिस्टम को संभावित सुरक्षा खतरों के विरुद्ध मज़बूत बनाए रखने का सक्रिय उपाय है।

3. User Account Control (UAC) कॉन्फ़िगर करें #

User Account Control (UAC) Windows 10 की सुरक्षा सुविधा है। ज़रूरत पड़ने पर यह प्रशासक की मंज़ूरी माँगकर आपके सिस्टम में अनधिकृत बदलाव रोकने में मदद करती है। यह दुर्भावनापूर्ण सॉफ़्टवेयर या अनधिकृत उपयोगकर्ताओं को ऐसे बदलाव करने से रोकती है जो सिस्टम की सुरक्षा या स्थिरता को प्रभावित कर सकते हैं।

Windows 10 सुरक्षा सुदृढ़ीकरण के लिए UAC सेटिंग सही स्तर पर रखना ज़रूरी है। सुरक्षा और उपयोग-सुविधा में संतुलन रखें, ताकि UAC बिना अनावश्यक रुकावट के सिस्टम की प्रभावी रक्षा करे।

Windows 10 में UAC सेटिंग कॉन्फ़िगर करने के लिए:

  1. खोज बार में “Control Panel” लिखें और परिणामों से चुनकर Control Panel (नियंत्रण कक्ष) खोलें।

  2. Control Panel में “उपयोगकर्ता खाते” पर क्लिक करें।

  3. “User Account Control सेटिंग बदलें” चुनें।

  4. UAC के अलग-अलग स्तर वाला स्लाइडर दिखाई देगा:

    • “हमेशा सूचित करें”: UAC सुरक्षा का सबसे ऊँचा स्तर। सामान्य कामों सहित किसी भी सिस्टम बदलाव के लिए आपकी सहमति माँगी जाती है।
    • “केवल ऐप्स द्वारा कंप्यूटर में बदलाव की कोशिश पर सूचित करें, डिफ़ॉल्ट”: सुरक्षा और उपयोग-सुविधा का अनुशंसित संतुलन। ऐप्स बदलाव करें तो सहमति माँगी जाती है, लेकिन Windows सेटिंग बदलने पर नहीं।
    • “केवल ऐप्स द्वारा कंप्यूटर में बदलाव की कोशिश पर सूचित करें, डेस्कटॉप धुँधला न करें”: पिछले विकल्प जैसा, लेकिन UAC संकेत आने पर डेस्कटॉप धुँधला नहीं होता।
    • “कभी सूचित न करें”: UAC सुरक्षा का सबसे निचला स्तर। किसी सिस्टम बदलाव के लिए सहमति नहीं माँगी जाती।

  5. स्लाइडर को मनचाही जगह ले जाकर अपनी ज़रूरत के अनुसार UAC सुरक्षा स्तर चुनें।

  6. बदलाव सेव करने के लिए “ठीक है” पर क्लिक करें।

UAC चालू रखें और उसे ऐसे स्तर पर सेट करें जो सुरक्षा और उपयोग-सुविधा में उचित संतुलन दे। UAC पूरी तरह बंद करने से आपका सिस्टम अनधिकृत बदलावों के प्रति अधिक संवेदनशील हो सकता है और उसकी सुरक्षा से समझौता हो सकता है।

UAC सेटिंग कॉन्फ़िगर करने से अहम सिस्टम बदलावों के लिए प्रशासनिक विशेषाधिकार ज़रूरी होते हैं। इससे अनधिकृत पहुँच और मैलवेयर संक्रमण का जोखिम घटता है तथा Windows 10 सिस्टम की सुरक्षा बढ़ती है।

4. मज़बूत पासवर्ड इस्तेमाल करें #

Windows 10 सिस्टम की सुरक्षा बनाए रखने और अनधिकृत पहुँच रोकने के लिए मज़बूत पासवर्ड ज़रूरी हैं। कमज़ोर या आसानी से अनुमान लगाए जा सकने वाले पासवर्ड से सिस्टम brute-force हमलों या पासवर्ड क्रैकिंग के प्रति असुरक्षित हो सकता है।

अपने Windows 10 सिस्टम के सभी उपयोगकर्ता खातों में मज़बूत पासवर्ड रखने के लिए ये तरीके अपनाएँ:

  1. जटिलता: उपयोगकर्ताओं को ऐसे पासवर्ड बनाने के लिए कहें जिनका अनुमान लगाना कठिन हो। मज़बूत पासवर्ड में बड़े और छोटे अक्षरों, अंकों और विशेष चिह्नों का मेल होना चाहिए। आम शब्दों और अनुमानित क्रम से बचें।

  2. लंबाई: लंबे पासवर्ड आम तौर पर अधिक सुरक्षित होते हैं। उपयोगकर्ताओं को कम-से-कम 8 अक्षरों के पासवर्ड बनाने के लिए कहें, बेहतर हो तो इससे लंबे। पासवर्ड जितना लंबा होगा, उसे क्रैक करना उतना कठिन होगा।

  3. अद्वितीयता: हर उपयोगकर्ता खाते का अलग पासवर्ड होना चाहिए। कई खातों में एक ही पासवर्ड इस्तेमाल करने से सुरक्षा उल्लंघन का जोखिम बढ़ता है। अलग-अलग खातों के लिए अलग पासवर्ड रखें।

  4. व्यक्तिगत जानकारी से बचें: पासवर्ड में नाम, जन्मतिथि या पता जैसी निजी जानकारी न रखें। हमलावर यह जानकारी आसानी से ढूँढ़ या अनुमान लगा सकते हैं।

  5. पासवर्ड मैनेजर: पासवर्ड सुरक्षित रूप से रखने और प्रबंधित करने के लिए पासवर्ड मैनेजर पर विचार करें। यह हर खाते के लिए मज़बूत, अलग पासवर्ड बना सकता है और उन्हें एन्क्रिप्टेड डेटाबेस में रख सकता है।

  6. पासवर्ड नियमित बदलें: सुरक्षा बनाए रखने के लिए समय-समय पर पासवर्ड बदलें। पासवर्ड की समय-सीमा तय करने की नीति बनाएँ और नियमित रूप से पासवर्ड अपडेट करने का महत्व समझाएँ।

मज़बूत पासवर्ड के तरीके लागू करने से Windows 10 सिस्टम की सुरक्षा बढ़ती है और अनधिकृत पहुँच या डेटा उल्लंघन का जोखिम घटता है। उपयोगकर्ताओं को पासवर्ड सुरक्षा के बारे में नियमित जानकारी दें और मज़बूत पासवर्ड बनाने में मदद के लिए पासवर्ड-मज़बूती मीटर या पासवर्ड बनाने के दिशा-निर्देश जैसे साधन दें।

मज़बूत पासवर्ड बनाने और सर्वोत्तम तरीकों के बारे में अधिक जानकारी के लिए यह लेख देखें। इसमें पासवर्ड सुरक्षा पर विस्तृत मार्गदर्शन और मज़बूत, याद रखने योग्य पासवर्ड बनाने के सुझाव हैं।

याद रखें, मज़बूत पासवर्ड सिस्टम सुरक्षा का बुनियादी हिस्सा हैं। संवेदनशील डेटा की रक्षा और Windows 10 परिवेश की अखंडता बनाए रखने के लिए इन्हें प्राथमिकता दें।

5. BitLocker एन्क्रिप्शन चालू करें #

Windows 10 सिस्टम में संवेदनशील डेटा की रक्षा करने का एक प्रभावी तरीका BitLocker एन्क्रिप्शन चालू करना है। BitLocker पूरी डिस्क को एन्क्रिप्ट करता है। इसलिए डिवाइस खो जाने या चोरी होने पर भी आपका डेटा सुरक्षित रहता है और अनधिकृत लोग उसे नहीं पढ़ सकते।

BitLocker एन्क्रिप्शन चालू करके संवेदनशील जानकारी सुरक्षित रखने के लिए:

  1. सिस्टम की आवश्यकताएँ जाँचें: सुनिश्चित करें कि आपका Windows 10 संस्करण BitLocker का समर्थन करता है। BitLocker Windows 10 Pro, Enterprise और Education संस्करणों में उपलब्ध है।

  2. BitLocker चालू करें: Control Panel खोलें और “सिस्टम और सुरक्षा” श्रेणी में जाएँ। “BitLocker ड्राइव एन्क्रिप्शन” पर क्लिक करें और जिन ड्राइव को एन्क्रिप्ट करना है उन्हें चुनें। एन्क्रिप्शन शुरू करने के लिए स्क्रीन पर दिए निर्देशों का पालन करें।

  3. एन्क्रिप्शन विकल्प चुनें: BitLocker सेटअप के दौरान पासवर्ड, स्मार्ट कार्ड या दोनों जैसे तरीकों में से चुन सकते हैं। अपनी सुरक्षा आवश्यकताओं और पसंद के अनुसार तरीका चुनें।

  4. Recovery key का बैकअप लें: BitLocker पुनर्प्राप्ति कुंजी का बैकअप रखना ज़रूरी है। पासवर्ड भूलने या एन्क्रिप्टेड ड्राइव खोलने में समस्या आने पर यह कुंजी सुरक्षा उपाय के रूप में काम करती है। इसे डिवाइस से अलग किसी सुरक्षित स्थान पर रखें।

  5. BitLocker सेटिंग प्रबंधित करें: BitLocker चालू करने के बाद अतिरिक्त सेटिंग बदली जा सकती हैं, जैसे कुछ ड्राइव को अपने आप अनलॉक करना या अधिक सुरक्षा के लिए TPM (विश्वसनीय प्लेटफ़ॉर्म मॉड्यूल) का उपयोग कॉन्फ़िगर करना। ये विकल्प BitLocker प्रबंधन इंटरफ़ेस में मिलते हैं।

BitLocker एन्क्रिप्शन चालू करने से Windows 10 सिस्टम में अतिरिक्त सुरक्षा जुड़ती है। डिवाइस गलत हाथों में पड़ने पर भी आपका डेटा सुरक्षित और अपठनीय रहता है। सुरक्षा के सर्वोत्तम तरीकों के अनुसार BitLocker सेटिंग नियमित अपडेट और देखरेख के साथ रखें।

BitLocker एन्क्रिप्शन चालू करने और प्रबंधित करने के बारे में अधिक जानकारी के लिए Microsoft का आधिकारिक दस्तावेज़ देखें। इसमें उन्नत सुविधाओं और कॉन्फ़िगरेशन विकल्पों सहित विस्तृत मार्गदर्शन है।

BitLocker एन्क्रिप्शन चालू करके संवेदनशील डेटा सुरक्षित रखें और डिवाइस खोने या चोरी होने की स्थिति में भी जानकारी सुरक्षित होने का भरोसा पाएँ।

6. अनावश्यक सेवाएँ और सुविधाएँ बंद करें #

Windows 10 सिस्टम की सुरक्षा बढ़ाने के लिए अनावश्यक सेवाओं और सुविधाओं की समीक्षा करके उन्हें बंद करें। इससे हमले की सतह घटती है और दुर्भावनापूर्ण लोगों द्वारा उनका दुरुपयोग किए जाने की संभावना कम होती है।

Windows 10 में अनावश्यक सेवाएँ और सुविधाएँ बंद करने के लिए:

  1. अनावश्यक सेवाएँ पहचानें: पहले अपने सिस्टम पर चल रही सेवाएँ पहचानें। Windows कुंजी + R दबाएँ, services.msc लिखें और Enter दबाकर Services प्रबंधन कंसोल खोलें। सूची की सेवाएँ देखें और उनके काम की जाँच करें, ताकि पता चले कि सिस्टम के सामान्य कामकाज के लिए कौन-सी ज़रूरी हैं।

  2. अनावश्यक सेवाएँ बंद करें: जिन सेवाओं की ज़रूरत नहीं है, उनमें से हर एक पर दायाँ-क्लिक करके Properties (गुण) चुनें। गुण विंडो में स्टार्टअप प्रकार को अक्षम करें। इससे सिस्टम बूट होने पर सेवा अपने आप शुरू नहीं होगी। सावधानी बरतें और केवल ऐसी सेवाएँ बंद करें जो सामान्य काम के लिए ज़रूरी नहीं हैं।

  3. अनावश्यक सुविधाएँ बंद करें: Windows 10 में ऐसी सुविधाएँ भी हैं जिनकी आपके सिस्टम को ज़रूरत नहीं हो सकती। Control Panel (नियंत्रण कक्ष) खोलें, Programs (प्रोग्राम) या प्रोग्राम और सुविधाएँ पर जाएँ और “Windows सुविधाएँ चालू या बंद करें” चुनें। जिन सुविधाओं की ज़रूरत नहीं, उनका चयन हटाएँ। इससे हमले की सतह और घटती है तथा अनावश्यक सुविधाओं द्वारा इस्तेमाल होने वाले संसाधन बचते हैं।

  4. नियमित समीक्षा और अपडेट करें: Windows 10 सिस्टम में चालू सेवाओं और सुविधाओं की सूची नियमित रूप से देखें। समय के साथ सिस्टम की ज़रूरतें बदल सकती हैं, इसलिए आवश्यक सेवाओं और सुविधाओं का फिर से आकलन करें। सतर्क रहें और ज़रूरत के अनुसार कॉन्फ़िगरेशन अपडेट करें।

अनावश्यक सेवाएँ और सुविधाएँ बंद करने से हमलावरों के संभावित प्रवेश बिंदु सीमित होते हैं और Windows 10 सिस्टम की कुल हमले की सतह घटती है। इससे सिस्टम की सुरक्षा स्थिति बेहतर होती है और दुरुपयोग का जोखिम कम होता है।

Windows 10 सेवाओं और सुविधाओं को प्रबंधित करने के बारे में विस्तृत मार्गदर्शन के लिए यह लेख देखें।

सेवाएँ और सुविधाएँ बंद करते समय सावधानी बरतें, क्योंकि ज़रूरी घटक बंद होने से सिस्टम का कामकाज बिगड़ सकता है। कोई बदलाव करने से पहले सेवा या सुविधा का उद्देश्य समझें और जाँचें।

7. फ़ायरवॉल नियम लागू करें #

Windows Defender Firewall नेटवर्क ट्रैफ़िक नियंत्रित करके अनधिकृत पहुँच रोकने में मदद करता है। केवल ज़रूरी कनेक्शन की अनुमति दें और हर नियम को उसके उपयोग के अनुसार सीमित रखें।

  1. फ़ायरवॉल सेटिंग खोलें: Control Panel (नियंत्रण कक्ष) खोलें, Windows Defender Firewall (Windows Defender फ़ायरवॉल) खोजें और परिणाम चुनें।
  2. इनबाउंड नियम बनाएँ: फ़ायरवॉल विंडो में उन्नत सेटिंग चुनें। इनबाउंड नियम आने वाले कनेक्शन नियंत्रित करते हैं। केवल आवश्यक ऐप, पोर्ट और नेटवर्क प्रोफ़ाइल के लिए नियम बनाएँ।
  3. आउटबाउंड नियम बनाएँ: इसी तरह Outbound Rules (आउटबाउंड नियम) चुनें। बाहर जाने वाले कनेक्शन सीमित करने से पहले ऐप की ज़रूरत और निर्भरता जाँचें।
  4. नियमों की नियमित समीक्षा करें: नेटवर्क और सिस्टम बदलने पर नियमों की फिर जाँच करें। अनावश्यक या पुराने नियम हटाएँ और बदलाव का कारण दर्ज करें।

सही ढंग से कॉन्फ़िगर किया गया फ़ायरवॉल व्यापक सुरक्षा रणनीति का अहम हिस्सा है। इसे अन्य सुरक्षा उपायों के साथ इस्तेमाल करें।

Windows Defender Firewall कॉन्फ़िगर करने के बारे में अधिक जानकारी के लिए Microsoft की फ़ायरवॉल सर्वोत्तम प्रक्रियाएँ देखें।

8. AppLocker इस्तेमाल करें #

AppLocker Windows 10 में उपलब्ध सुविधा है। इससे आप नियंत्रित कर सकते हैं कि कौन-से ऐप सिस्टम पर चलें। AppLocker नीतियाँ अनधिकृत या संभावित रूप से दुर्भावनापूर्ण ऐप चलने से रोक सकती हैं।

Windows 10 पर AppLocker इस्तेमाल करने के लिए:

  1. AppLocker सेटिंग खोलें: Windows कुंजी + R दबाएँ, gpedit.msc लिखें और OK (ठीक है) चुनकर Local Group Policy Editor (स्थानीय समूह नीति संपादक) खोलें। आप Start मेनू में Group Policy Editor (समूह नीति संपादक) भी खोज सकते हैं।
  2. AppLocker नीतियाँ कॉन्फ़िगर करें: संपादक में Computer Configuration > Windows Settings > Security Settings > Application Control Policies > AppLocker पर जाएँ। यहाँ Executable Rules, Windows Installer Rules, Script Rules, और Packaged App Rules जैसी नीतियाँ कॉन्फ़िगर करें।
  3. नियम बनाएँ: नीति फ़ोल्डर, जैसे Executable Rules, पर दायाँ-क्लिक करें और Create New Rule (नया नियम बनाएँ) चुनें। स्क्रीन पर दिए निर्देशों से शर्तें और अपवाद तय करें। नियम फ़ाइल पथ, प्रकाशक, फ़ाइल हैश या अन्य विशेषताओं पर आधारित हो सकते हैं।
  4. नीतियों की जाँच और सुधार करें: नियमों को पहले परीक्षण समूह या सिस्टम पर लागू करें। पुष्टि करें कि केवल स्वीकृत ऐप चलें। परीक्षण के नतीजों के आधार पर नियम सुधारें।
  5. नीतियों की नियमित समीक्षा करें: ऐप और सिस्टम की ज़रूरतें बदलने पर नीतियाँ अपडेट करें। नए ऐप को अनुमति चाहिए हो सकती है, जबकि पुराने ऐप जोखिम बन सकते हैं।

AppLocker ऐप चलाने पर बारीक नियंत्रण देता है। इससे मैलवेयर संक्रमण, अनधिकृत ऐप इंस्टॉल होने और अन्य सुरक्षा घटनाओं का जोखिम घट सकता है।

नियम लागू करने के बारे में अधिक जानकारी के लिए Microsoft का आधिकारिक दस्तावेज़ देखें या अतिरिक्त उदाहरणों के लिए हमारा AppLocker GitHub भंडार देखें।

ऐप की ज़रूरतें और खतरे बदलने पर AppLocker नीतियों की नियमित समीक्षा और अपडेट करें।

9. डेटा का नियमित बैकअप लें #

नियमित बैकअप से सुरक्षा घटना, हार्डवेयर विफलता या दूसरी अप्रत्याशित स्थिति में डेटा हानि का असर घटता है। बैकअप बनाकर उसकी अखंडता जाँचें, ताकि ज़रूरत पड़ने पर अहम डेटा वापस पाया जा सके।

Windows 10 पर नियमित बैकअप के लिए:

  1. महत्वपूर्ण डेटा पहचानें: उन दस्तावेज़ों, निजी फ़ाइलों, सिस्टम कॉन्फ़िगरेशन, ऐप सेटिंग और अन्य डेटा की सूची बनाएँ जिन्हें सुरक्षित रखना है।
  2. बैकअप समाधान चुनें: अपनी ज़रूरत के अनुसार भरोसेमंद समाधान चुनें। Windows 10 में File History (फ़ाइल इतिहास) और Windows बैकअप और पुनर्स्थापना जैसे अंतर्निहित विकल्प हैं। तीसरे पक्ष के सॉफ़्टवेयर में अतिरिक्त सुविधाएँ मिल सकती हैं।
  3. बैकअप का अंतराल तय करें: डेटा के महत्व और बदलाव की आवृत्ति के अनुसार तय करें कि कौन-सा डेटा रोज़ाना, साप्ताहिक या मासिक बैकअप होगा।
  4. बैकअप संग्रहण चुनें: बाहरी ड्राइव, नेटवर्क-संलग्न संग्रहण (NAS), क्लाउड संग्रहण या इनका संयोजन चुनें। संग्रहण माध्यम सुरक्षित और भरोसेमंद होना चाहिए।
  5. बैकअप सेटिंग कॉन्फ़िगर करें: बैकअप में शामिल डेटा, गंतव्य और एन्क्रिप्शन या संपीड़न जैसी अतिरिक्त सेटिंग तय करें।
  6. पुनर्स्थापना का परीक्षण करें: नियमित रूप से परीक्षण बैकअप से फ़ाइलें वापस लाएँ। इससे पुष्टि होती है कि बैकअप काम करता है और डेटा पुनर्प्राप्त किया जा सकता है।
  7. निगरानी और अपडेट करें: बैकअप प्रक्रिया की निगरानी करें। डेटा या ज़रूरत बदलने पर समाधान और सेटिंग अपडेट करें।

नियमित बैकअप से डेटा हानि का असर कम होता है और महत्वपूर्ण जानकारी उपलब्ध रहती है। बैकअप को मूल डेटा से अलग सुरक्षित स्थान पर रखें। 3-2-1 बैकअप नियम अपनाने पर विचार करें: डेटा की कम से कम तीन प्रतियाँ रखें, दो अलग-अलग माध्यमों पर, और एक प्रति दूसरी जगह।

बैकअप के बारे में अधिक जानकारी के लिए 3-2-1 बैकअप नियम क्या है और इसका इस्तेमाल क्यों करें लेख देखें। इसमें प्रभावी बैकअप रणनीति के सुझाव दिए गए हैं।

नियमित बैकअप डेटा को सुरक्षित रखते हैं और अप्रत्याशित घटना के बाद उसे उपलब्ध कराने में मदद करते हैं। इन्हें Windows 10 सुरक्षा योजना का हिस्सा बनाएँ।

Windows 11 को सुदृढ़ करना #

Windows 11 में नए फ़ीचर और बेहतर सुरक्षा शामिल हैं। अपने Windows 11 परिवेश को सुदृढ़ करने के लिए ये उपाय अपनाएँ:

1. Secure Boot और TPM #

Secure Boot और TPM (विश्वसनीय प्लेटफ़ॉर्म मॉड्यूल) अनधिकृत पहुँच रोकने और ऑपरेटिंग सिस्टम की अखंडता बनाए रखने में मदद करते हैं। इन्हें चालू करके Windows 11 सिस्टम की सुरक्षा बढ़ाएँ।

अपने डिवाइस पर Secure Boot और TPM चालू करने के लिए:

  1. अनुकूलता जाँचें: पुष्टि करें कि डिवाइस इन सुविधाओं का समर्थन करता है और हार्डवेयर तथा फ़र्मवेयर आवश्यकताएँ पूरी करता है।
  2. UEFI/BIOS सेटिंग खोलें: डिवाइस पुनः चालू करके UEFI (एकीकृत विस्तार योग्य फ़र्मवेयर इंटरफ़ेस) या BIOS (मूल इनपुट/आउटपुट प्रणाली) सेटिंग खोलें। इसे खोलने की कुंजी डिवाइस के अनुसार बदलती है। आम कुंजियाँ Del, F2, F10 और Esc हैं। सही निर्देशों के लिए निर्माता का दस्तावेज़ देखें।
  3. Secure Boot चालू करें: UEFI/BIOS में Secure Boot सेटिंग खोलें और इसे चालू करें। इससे बूट के दौरान केवल भरोसेमंद ऑपरेटिंग सिस्टम और घटक चलने की अनुमति मिलती है।
  4. TPM चालू करें: UEFI/BIOS में TPM सेटिंग ढूँढ़कर चालू करें। TPM मदरबोर्ड पर मौजूद समर्पित चिप है, जो हार्डवेयर-आधारित सुरक्षा सुविधाएँ देती है।
  5. TPM सुरक्षा कॉन्फ़िगर करें: डिवाइस और फ़र्मवेयर के अनुसार TPM पासवर्ड या फ़र्मवेयर अपडेट जैसी अतिरिक्त सेटिंग उपलब्ध हो सकती हैं। उन्हें अपनी सुरक्षा ज़रूरत के अनुसार तय करें।
  6. सहेजें और बाहर निकलें: बदलाव सहेजकर UEFI/BIOS से बाहर निकलें। सिस्टम पुनः चालू होगा और नई सेटिंग लागू होंगी।

Secure Boot और TPM अनधिकृत बदलावों, रूटकिट और अन्य खतरों से सुरक्षा की बुनियाद देते हैं। इन सुविधाओं की उपलब्धता और चालू करने के चरण निर्माता तथा फ़र्मवेयर के अनुसार बदल सकते हैं। सटीक निर्देशों के लिए निर्माता का दस्तावेज़ देखें।

2. Microsoft Defender Antivirus चालू करें #

Windows 11 में Microsoft Defender Antivirus अंतर्निहित है। यह वायरस, रैनसमवेयर और स्पाइवेयर सहित कई प्रकार के मैलवेयर से सुरक्षा देता है। इसे चालू रखें और नियमित रूप से अपडेट करें, ताकि रीयल-टाइम में खतरों का पता लगे और उन्हें रोका जा सके।

  1. एंटीवायरस की स्थिति जाँचें: Start मेनू में Windows Security (Windows सुरक्षा) खोजें और ऐप खोलें। वायरस और खतरे से सुरक्षा में Microsoft Defender Antivirus की स्थिति देखें। नए Windows 11 इंस्टॉलेशन में यह डिफ़ॉल्ट रूप से चालू होना चाहिए।
  2. रीयल-टाइम सुरक्षा चालू करें: सुनिश्चित करें कि रीयल-टाइम सुरक्षा चालू है। यह मैलवेयर और संदिग्ध गतिविधि पर लगातार नज़र रखती है। यदि बंद हो, तो टॉगल चालू करें।
  3. परिभाषाएँ अपडेट करें: वायरस और खतरे से सुरक्षा में अपडेट जाँचें चुनें। इससे नवीनतम पहचान हस्ताक्षर और पहचान क्षमताएँ मिलती हैं।
  4. स्कैन चलाएँ: त्वरित स्कैन या पूर्ण स्कैन चुनें। स्कैन विकल्प से स्कैन की सेटिंग और नियमित समय तय करें।
  5. अतिरिक्त सेटिंग कॉन्फ़िगर करें: अपनी सुरक्षा ज़रूरत के अनुसार ऐप और ब्राउज़र नियंत्रण, डिवाइस सुरक्षा, और फ़ायरवॉल और नेटवर्क सुरक्षा की जाँच करें।

Microsoft Defender Antivirus को अपडेट रखें और अपनी ज़रूरत के अनुसार अतिरिक्त सुरक्षा सुविधाएँ कॉन्फ़िगर करें।

3. डिफ़ॉल्ट हार्डवेयर-आधारित पृथक्करण लागू करें #

Windows 11 का हार्डवेयर-आधारित पृथक्करण संवेदनशील प्रक्रियाओं को अलग रखकर सुरक्षा बढ़ाता है। इसमें वर्चुअलाइज़ेशन-आधारित सुरक्षा (VBS) और Hypervisor-protected Code Integrity (HVCI) शामिल हो सकते हैं।

  1. वर्चुअलाइज़ेशन चालू करें: जाँचें कि प्रोसेसर इसका समर्थन करता है। BIOS या UEFI फ़र्मवेयर में Intel VT-x या AMD-V विकल्प चालू करें। सही नाम और चरण निर्माता के अनुसार बदलते हैं।

  2. VBS चालू करें: Windows 11 में VBS हार्डवेयर वर्चुअलाइज़ेशन से Virtual Secure Mode (VSM) नाम के अलग कंटेनर बनाता है। VSM महत्वपूर्ण सिस्टम घटकों के लिए सुरक्षित निष्पादन वातावरण देता है। इसे चालू करने के लिए:

    • Windows कुंजी + R दबाकर Run संवाद खोलें।
    • gpedit.msc लिखें और Enter दबाकर Local Group Policy Editor खोलें।
    • Computer Configuration > Administrative Templates > System > Device Guard पर जाएँ।
    • Turn on Virtualization Based Security नीति खोलें।
    • Enabled (चालू) चुनें और OK (ठीक है) दबाएँ।

    VBS के लिए संगत हार्डवेयर और कुछ सिस्टम आवश्यकताएँ हो सकती हैं। अधिक जानकारी के लिए Microsoft का आधिकारिक दस्तावेज़ देखें।

  3. HVCI चालू करें: Hypervisor-protected Code Integrity (HVCI) हाइपरवाइज़र से कोड-अखंडता नीतियाँ लागू करता है। इससे अनधिकृत कोड चलने से रुकता है। इसे चालू करने के लिए:

    • Windows कुंजी + R दबाकर Run संवाद खोलें।
    • msconfig लिखें और Enter दबाकर System Configuration खोलें।
    • Boot (बूट) टैब चुनें।
    • उन्नत विकल्प चुनें।
    • Enable Hypervisor-protected Code Integrity विकल्प चुनें।
    • बदलाव सहेजने के लिए OK (ठीक है) चुनें और सिस्टम पुनः चालू करें।

    HVCI के लिए संगत हार्डवेयर और कुछ सिस्टम आवश्यकताएँ होती हैं। अधिक जानकारी के लिए Microsoft का आधिकारिक दस्तावेज़ देखें।

VBS और HVCI जैसे डिफ़ॉल्ट हार्डवेयर-आधारित पृथक्करण से Windows 11 की सुरक्षा मजबूत होती है। ये सुविधाएँ सिस्टम घटकों को ऐसे हमलों से बचाने में मदद करती हैं जो सिस्टम कोड या कॉन्फ़िगरेशन बदलने या उनका दुरुपयोग करने की कोशिश करते हैं।

नवीनतम सुरक्षा सुधार और शमन पाने के लिए सिस्टम तथा फ़र्मवेयर अपडेट रखें। इन सुविधाओं की उपलब्धता और ज़रूरतें हार्डवेयर तथा Windows 11 संस्करण के अनुसार बदलती हैं। सही लागूकरण से पहले अनुकूलता जाँचें और Microsoft के आधिकारिक दस्तावेज़ देखें।

इन सुविधाओं को लागू करने से पहले हार्डवेयर और ड्राइवर अनुकूलता जाँचें।

4. Windows Sandbox इस्तेमाल करें #

Windows Sandbox अविश्वसनीय ऐप या सॉफ़्टवेयर को अलग वातावरण में चलाने देता है। Sandbox बंद करने पर उसके बदलाव मिट जाते हैं, इसलिए मुख्य ऑपरेटिंग सिस्टम पर उनका असर नहीं पड़ता।

  1. सिस्टम आवश्यकताएँ जाँचें: आम तौर पर Windows 10 Pro या Enterprise और BIOS/UEFI में चालू वर्चुअलाइज़ेशन वाला प्रोसेसर चाहिए। विस्तृत जानकारी के लिए आधिकारिक Microsoft दस्तावेज़ देखें।
  2. Windows Sandbox चालू करें:
    • Windows कुंजी + R दबाएँ।
    • appwiz.cpl लिखें और Enter दबाएँ।
    • Windows सुविधाएँ चालू या बंद करें चुनें।
    • सूची में Windows Sandbox ढूँढ़ें।
    • उसके पास वाला बॉक्स चुनें और OK (ठीक है) दबाएँ।
    • Windows आवश्यक घटक इंस्टॉल करेगा। बदलाव लागू करने के लिए पुनः चालू करना पड़ सकता है।
  3. Sandbox खोलें:
    • Start मेनू में Windows Sandbox खोजें।
    • ऐप चुनें। अलग विंडो में Sandbox खुलेगा।
    • अविश्वसनीय ऐप या सॉफ़्टवेयर को इसी अलग वातावरण में चलाएँ।

Sandbox के भीतर बनाई गई फ़ाइलें बाहर सहेजें, यदि उन्हें बाद में रखना हो। इसका इस्तेमाल अज्ञात सॉफ़्टवेयर जाँचने, संदिग्ध फ़ाइल खोलने या जोखिमपूर्ण वेबसाइट देखने के लिए करें।

Windows Sandbox के बारे में अधिक जानकारी के लिए आधिकारिक Microsoft दस्तावेज़ देखें।

5. Microsoft Defender Application Guard लागू करें #

Microsoft Defender Application Guard, Microsoft Edge ब्राउज़र सत्रों को ऑपरेटिंग सिस्टम से अलग रखता है। इससे ब्राउज़र-आधारित हमलों और दुर्भावनापूर्ण वेबसाइटों का जोखिम घटता है।

  1. अनुकूलता जाँचें: आम तौर पर Windows 10 Pro या Enterprise, वर्चुअलाइज़ेशन-सक्षम संगत प्रोसेसर और कम से कम 8 GB RAM चाहिए। विस्तृत जानकारी के लिए आधिकारिक Microsoft दस्तावेज़ देखें।
  2. Application Guard चालू करें: यह Windows 10 में वैकल्पिक सुविधा है। इसे चालू करने के लिए:
    • Windows कुंजी + R दबाएँ।
    • appwiz.cpl लिखें और Enter दबाकर प्रोग्राम और सुविधाएँ विंडो खोलें।
    • Windows सुविधाएँ चालू या बंद करें चुनें।
    • सूची में Microsoft Defender Application Guard ढूँढ़ें।
    • इसके पास वाला बॉक्स चुनें और OK (ठीक है) दबाएँ।
    • Windows आवश्यक घटक इंस्टॉल करेगा। बदलाव लागू करने के लिए पुनः चालू करना पड़ सकता है।
  3. सेटिंग कॉन्फ़िगर करें: Windows Security ऐप या Group Policy में पृथक्करण का स्तर और अविश्वसनीय वेबसाइटों तथा फ़ाइलों का व्यवहार तय करें।
  4. परीक्षण करें: Microsoft Edge में सुरक्षित परीक्षण वेबसाइट खोलें और पुष्टि करें कि ब्राउज़र सत्र अलग वातावरण में चलता है।

Application Guard ब्राउज़र सत्र अलग रखकर ड्राइव-बाय डाउनलोड, दुर्भावनापूर्ण स्क्रिप्ट और ज़ीरो-डे हमलों का असर सीमित करने में मदद करता है। कॉन्फ़िगरेशन के लिए आधिकारिक Microsoft दस्तावेज़ देखें।

6. नियंत्रित फ़ोल्डर पहुँच चालू करें #

Controlled Folder Access (नियंत्रित फ़ोल्डर पहुँच) रैनसमवेयर और अन्य दुर्भावनापूर्ण सॉफ़्टवेयर द्वारा सुरक्षित फ़ोल्डरों में अनधिकृत बदलाव रोकने में मदद करता है। सुविधा चालू करें और आवश्यक फ़ोल्डरों को सुरक्षित सूची में जोड़ें।

  1. Windows सुरक्षा ऐप खोलें: कीबोर्ड पर Windows कुंजी दबाएँ, Windows Security (Windows सुरक्षा) लिखें और ऐप चुनें।
  2. सुरक्षा सेटिंग खोलें: बाएँ मेनू में वायरस और खतरे से सुरक्षा चुनें।
  3. सेटिंग तक जाएँ: रैनसमवेयर सुरक्षा के नीचे रैनसमवेयर सुरक्षा प्रबंधित करें चुनें।
  4. Controlled Folder Access (नियंत्रित फ़ोल्डर पहुँच) चालू करें: टॉगल को On (चालू) करें। Windows केवल भरोसेमंद ऐप को सुरक्षित फ़ोल्डरों तक पहुँच देने की चेतावनी दिखाएगा।
  5. फ़ोल्डर जोड़ें: सुरक्षित फ़ोल्डर चुनें, फिर सुरक्षित फ़ोल्डर जोड़ें चुनें। आवश्यक फ़ोल्डर चुनकर OK (ठीक है) दबाएँ। Documents, Pictures, Videos और महत्वपूर्ण डेटा वाले दूसरे फ़ोल्डर शामिल करें।
    • Documents, Pictures, Videos और अन्य महत्वपूर्ण डेटा वाले फ़ोल्डर सुरक्षित सूची में जोड़ें।
  6. ऐप को अनुमति दें या रोकें: डिफ़ॉल्ट रूप से भरोसेमंद ऐप सुरक्षित फ़ोल्डर खोल सकते हैं। सुविधा में ऐप को अनुमति दें या रोकें में खास ऐप को अनुमति दें या रोकें।
  7. निगरानी करें: हाल में रोके गए ऐप के नीचे समीक्षा चुनकर लॉग देखें।

इस सुविधा की सुरक्षित फ़ोल्डर सूची की नियमित समीक्षा करें और उसे अपनी ज़रूरत के अनुरूप रखें। अधिक जानकारी के लिए Microsoft का दस्तावेज़ देखें।

7. Windows का स्वचालित रखरखाव चालू करें #

Windows 11 की Automatic Maintenance (स्वचालित रखरखाव) सुविधा नियमित रखरखाव कार्य चलाकर सिस्टम को अद्यतित और सुरक्षित रखने में मदद करती है।

  1. Windows सेटिंग्स खोलें: Windows कुंजी दबाएँ, सेटिंग्स लिखें और ऐप चुनें।
  2. रखरखाव सेटिंग खोलें: सिस्टम > परिचय चुनें। पृष्ठ के नीचे सिस्टम जानकारी लिंक चुनें।
  3. रखरखाव खोलें: सिस्टम जानकारी विंडो में नीचे रखरखाव लिंक चुनें।
  4. Automatic Maintenance (स्वचालित रखरखाव) चालू करें: टॉगल को On (चालू) करें।
  5. समय तय करें: Windows डिफ़ॉल्ट रूप से रोज़ 2:00 बजे रखरखाव चलाता है। समय या आवृत्ति बदलने के लिए रखरखाव सेटिंग बदलें चुनें।
  6. अतिरिक्त सेटिंग की समीक्षा करें: स्वचालित रखरखाव के टॉगल के नीचे रखरखाव से जुड़ी अतिरिक्त सेटिंग मिलती हैं। इनमें निर्धारित समय पर कंप्यूटर को जगाने के लिए रखरखाव की अनुमति दें और बैटरी पर होने पर भी निर्धारित रखरखाव चलाने की अनुमति दें जैसे विकल्प शामिल हैं। इन्हें अपनी ज़रूरत के अनुसार तय करें।
  7. गतिविधि देखें: Windows निर्धारित समय पर पृष्ठभूमि में रखरखाव चलाएगा। Windows Security (Windows सुरक्षा) ऐप के रखरखाव भाग या इवेंट व्यूअर (Event Viewer) के रखरखाव लॉग देखें।

Automatic Maintenance (स्वचालित रखरखाव) सॉफ़्टवेयर अपडेट, डिस्क अनुकूलन और सुरक्षा स्कैन जैसे कार्य चलाती है। अधिक जानकारी के लिए Microsoft का दस्तावेज़ देखें।

सुदृढ़ीकरण का सुझाया क्रम #

पहले पहुँच और पुनर्प्राप्ति सुरक्षित करें, फिर अन्य नियंत्रण लागू करें:

  1. Windows संस्करण, बिल्ड, समर्थन स्थिति, हार्डवेयर सुरक्षा सुविधाएँ और पुनर्प्राप्ति विकल्प की पुष्टि करें।
  2. मौजूदा सुरक्षा अपडेट इंस्टॉल करें और नियोजित समय पर पुनः चालू करें।
  3. परीक्षण किया हुआ बैकअप बनाएँ। मौजूदा फ़ायरवॉल, Defender, BitLocker, सेवाओं और स्थानीय नीतियों की स्थिति दर्ज करें।
  4. UAC चालू रखें, अलग व्यवस्थापक खाते इस्तेमाल करें और समर्थित रिमोट तथा क्लाउड पहुँच के लिए MFA माँगें।
  5. संस्करण और हार्डवेयर समर्थन के अनुसार Defender सुरक्षा, फ़ायरवॉल प्रोफ़ाइल, Secure Boot, BitLocker और हार्डवेयर पृथक्करण चालू करें।
  6. ASR नियमों, Controlled Folder Access (नियंत्रित फ़ोल्डर पहुँच), AppLocker और सेवा बदलावों को व्यापक रूप से लागू करने से पहले ऑडिट या पायलट समूह में जाँचें।
  7. लॉग एक जगह जमा करें। विफल लॉगऑन, नीति बदलाव, Defender घटनाएँ और फ़ायरवॉल द्वारा रोके गए कनेक्शन देखें।
  8. सिस्टम पुनः चालू करें, ज़रूरी ऐप जाँचें, पुनर्प्राप्ति पहुँच की पुष्टि करें और अंतिम स्थिति दर्ज करें।

Microsoft का Security Compliance Toolkit Windows 10, Windows 11 और Windows Server के संस्करण-विशिष्ट बेसलाइन देता है। सही बेसलाइन को समीक्षा के बाद शुरुआती बिंदु बनाएँ। Microsoft उत्पादन में लागू करने से पहले बदलावों का परीक्षण करने की सलाह देता है।

Windows 10 का समर्थन सीमा #

Microsoft ने Windows 10 संस्करण 22H2 का समर्थन 14 अक्टूबर 2025 को समाप्त कर दिया। उस तारीख के बाद सामान्य सुरक्षा अपडेट नहीं मिलते, जब तक अलग जीवनचक्र या Extended Security Update व्यवस्था लागू न हो। सुरक्षा योजना में माइग्रेशन, डिवाइस बदलना या स्वीकृत अपवाद शामिल करें। सुदृढ़ीकरण से उत्पाद का समर्थन काल नहीं बढ़ता। Windows 10 समर्थन समाप्ति पर Microsoft की सूचना देखें।

सेवा और सुविधा बदलाव वापस लें #

सेवा बंद करने से पहले निर्भरताएँ और उपयोग का परीक्षण करें। किसी सामान्य सूची के आधार पर RPC, Windows Update, Windows Event Log या दूसरी सेवा बंद न करें। केवल सेवा का नाम उसके सिस्टम में काम को स्पष्ट नहीं करता।

बदलाव से पहले सेवा कॉन्फ़िगरेशन निर्यात करें और निर्भर सेवाएँ दर्ज करें:

$name = 'Spooler'
Get-CimInstance Win32_Service -Filter "Name='$name'" |
    Select-Object Name, DisplayName, State, StartMode, StartName, PathName |
    Export-Csv "C:\Temp\$name-before.csv" -NoTypeInformation
Get-Service -Name $name -DependentServices
Get-Service -Name $name -RequiredServices

एक समय में एक सेवा बदलें। काम की ज़रूरत के अनुसार सेवा अपने आप चालू होती हो, तो अक्षम से पहले Manual (मैन्युअल) चुनें। पुराना स्टार्टअप मोड दर्ज करें। परीक्षण के बाद ऐप, Event Viewer, Windows Update, प्रिंटिंग, रिमोट प्रबंधन, VPN पहुँच और शेड्यूल किए गए कार्य जाँचें।

वापस लौटाने के लिए दर्ज स्टार्टअप मोड बहाल करें। निर्भरताएँ जाँचने के बाद ही सेवा चालू करें:

Set-Service -Name $name -StartupType Manual
Start-Service -Name $name
Get-Service -Name $name

बड़ी नीति बदलने पर उसी प्रबंधन टूल से सहेजा GPO या रजिस्ट्री बैकअप बहाल करें। रिमोट बदलाव से पहले ऑफ़लाइन पुनर्प्राप्ति तरीका और स्थानीय व्यवस्थापक खाता तैयार रखें। Microsoft sc.exe config दस्तावेज़ में सेवा कॉन्फ़िगरेशन का सिंटैक्स बताता है।

नियंत्रण सत्यापन रिकॉर्ड #

हर बदलाव के लिए नियंत्रण, दायरा, पुराना और नया मान, परीक्षण परिणाम, जाँचे गए इवेंट ID, मालिक और वापस लेने का कमांड दर्ज करें। ऐप का रुकना या प्रिंटर का काम न करना संचालन संबंधी निष्कर्ष है, इससे नियंत्रण गलत सिद्ध नहीं होता। साक्ष्य देखने के बाद दायरा, अपवाद या लागू करने का समूह समायोजित करें।

निष्कर्ष #

इन Windows सुरक्षा सुदृढ़ीकरण उपायों से सिस्टम की सुरक्षा बढ़ती है। ऑपरेटिंग सिस्टम अपडेट करके कमज़ोरियों के पैच लगाएँ। एंटीवायरस और एन्क्रिप्शन से डेटा सुरक्षित करें। पहुँच नियंत्रण सही ढंग से कॉन्फ़िगर करके अनधिकृत बदलाव और संवेदनशील संसाधनों तक पहुँच रोकें।

इन तरीकों से Windows परिवेश, डेटा और डिजिटल ढाँचे की अखंडता सुरक्षित रहती है। संभावित खतरों से आगे रहने के लिए सुरक्षा उपायों की नियमित समीक्षा और अपडेट करें।

Windows सुदृढ़ीकरण लगातार चलने वाली प्रक्रिया है। नवीनतम सुरक्षा अपडेट और तरीकों की जानकारी रखें और अपने सिस्टम की सुरक्षा जाँचते रहें।

अधिक जानकारी के लिए Microsoft के दस्तावेज़, सुरक्षा फ़ोरम और भरोसेमंद साइबर सुरक्षा वेबसाइट देखें।
