Что такое ATS Resume Improver? #

ATS Resume Improver — это браузерный оптимизатор резюме с открытым исходным кодом. Он сравнивает резюме с описанием вакансии и помогает устранить разрыв между вашим опытом и тем, что оценивают системы отслеживания кандидатов (ATS). Инструмент создан на React 19, Vite и TypeScript. Весь процесс разбора и оценки выполняется в браузере, серверная часть не нужна.

Исходный код находится на репозиторий ATS Resume Improver на GitHub . Используйте размещённую версию, разверните свою на Vercel/Netlify/Cloudflare/GitHub Pages одним нажатием или запустите локально в Docker.

Какой риск для конфиденциальности устраняется #

Большинство сервисов оптимизации резюме загружает документы на свои серверы, применяет закрытые алгоритмы оценки и сохраняет данные. ATS Resume Improver устроен иначе.

Режим Какие данные покидают устройство
Без ключа ИИ Никакие. Всё выполняется локально в браузере.
OpenAI / Anthropic Текст резюме и описание вакансии отправляются напрямую в API поставщика ИИ с вашим ключом, без промежуточного сервера.
Ollama (локально) Никакие. Модель работает на вашем компьютере.

Ключи API хранятся только в памяти и исчезают после закрытия вкладки. Нет аналитики, отслеживания и файлов cookie.

Основные функции #

Что работает без ключа ИИ #

Для полезной работы ключ API не нужен. Режим без ключа включает:

  • Загрузка резюме: PDF, DOCX, TXT или Markdown
  • Извлечение текста ATS: показывает, что именно ATS распознаёт в файле, включая потерю форматирования
  • Определение типа резюме: автоматически выбирает один из 7 профилей и меняет порядок разделов
  • Распознавание разделов и предупреждения о формате: отмечает отсутствующие разделы и форматы, неудобные для парсеров
  • Оценка ATS (0–100) с разбивкой на 5 показателей
  • Анализ пробелов в ключевых словах: сравнение с описанием вакансии по правилам
  • Детерминированная оптимизация ATS: локальная перестройка по правилам
  • Просмотр различий до и после: точно показывает, что изменилось
  • Профессиональный экспорт в PDF, DOCX, TXT и Markdown

Что даёт ИИ #

Подключите OpenAI, Anthropic Claude или локальную Ollama, чтобы получить дополнительные функции:

  • Семантический анализ ключевых слов: понимает контекст, а не только совпадения строк. Показывает степень соответствия (сильная/средняя/частичная), место совпадения (“найдено в навыках и 3 должностях”), важность каждого слова (критическая/высокая/средняя/низкая) и краткое резюме ИИ из 2–3 предложений
  • Оптимизация резюме с ИИ: полная переработка с промптами, основанными на рекомендациях ATS
  • Экспорт с улучшениями ИИ: ИИ форматирует PDF/DOCX перед загрузкой
  • Создание сопроводительного письма: правила стиля удаляют характерные признаки текста ИИ (см. ниже)
  • Предсказание вопросов для собеседования: по описанию вакансии
  • Оценка диапазона зарплаты

Определение типа резюме #

Приложение автоматически относит резюме к одному из 7 профилей и размещает разделы в порядке, соответствующем ожиданиям рекрутеров и ATS для данного этапа карьеры:

Профиль Для кого Приоритет разделов
🏢 Опытный специалист Более 5 лет, последовательная карьера Опыт → Навыки → Образование
🌱 Средний уровень 2–5 лет Опыт → Навыки → Образование
🎓 Начальный уровень 0–2 года Навыки → Образование → Проекты → Опыт
🎒 Студент / недавний выпускник Продолжает учиться Образование → Проекты → Навыки → Опыт
🔬 Учёный / исследователь Кандидат наук, публикации Образование → Исследования → Публикации → Опыт
📜 Много сертификатов Сертификаты важнее диплома Сертификаты → Навыки → Опыт → Образование
🔄 Смена карьеры Обнаружен перерыв или переход Резюме → Переносимые навыки → Образование → Опыт

Порядок разделов одинаков при оптимизации и экспорте в PDF, DOCX, TXT и Markdown, а не только на экране.

Семантический анализ ключевых слов с ИИ #

Здесь инструмент отличается от простых счётчиков ключевых слов. После настройки поставщика ИИ анализ пробелов переходит от поиска совпадений строк к семантическому рассуждению:

Показатель Без ИИ С ИИ
Метод сопоставления Только точное совпадение строки Семантическое понимание контекста
Степень соответствия — Оценка: сильная / средняя / частичная
Контекст совпадения — “найдено в навыках и 3 должностях”
Важность пробела Все пробелы равнозначны Критическая / высокая / средняя / низкая
Рекомендации Общие советы Практические рекомендации для каждого слова
Охват % По числу совпавших строк С семантическим весом
Резюме — Краткое резюме ИИ из 2–3 предложений

Локальный анализ по правилам выполняется сразу. ИИ дополняет результаты асинхронно, пока вы их изучаете.

Естественный стиль сопроводительных писем #

Генератор сопроводительных писем использует продуманные правила стиля, чтобы убрать характерные признаки текста ИИ. Правила основаны на методике очеловечивания текста ИИ Сабрины Рамонов . Каждое письмо соответствует этим требованиям:

  • Без длинного тире em dash: самый заметный признак ИИ удаляется полностью
  • Более 50 запрещённых слов и выражений: leverage, utilize, dive deep, delve, embark, game-changer, groundbreaking, cutting-edge, pivotal, tapestry, harness, moreover, in conclusion, it’s worth noting, ever-evolving, landscape, testament, not only…but also и другие
  • Без Markdown в тексте письма: никаких звёздочек для выделения, хэштегов или точек с запятой
  • Преимущественно действительный залог: страдательный используется только если исполнитель действительно не важен
  • Обязательные сокращения: “I’ve”, “I’m”, “it’s”, а не “I have”, “I am”, “it is”
  • Разная длина предложений: короткие выразительные фразы чередуются с длинными
  • Без пустых вступлений: вместо “It’s important to note that X” сразу говорится “X”
  • Конкретная деталь вакансии в первом абзаце: показывает, что письмо не взято из шаблона

Результат читается как человеческий текст, потому что правила заставляют модель писать естественно.

git clone https://github.com/simeononsecurity/ats-resume-improver
cd ats-resume-improver

make install

# Продакшен: nginx на http://localhost:8080

Практическое руководство #

Шаг 1: загрузите резюме #

Загрузите файл PDF, DOCX, TXT или Markdown. Откройте вкладку “What the ATS Sees”, чтобы проверить, правильно ли парсер извлёк содержимое. Если разделы отсутствуют или искажены, ATS-система рекрутера столкнётся с тем же.

Шаг 2: вставьте описание вакансии #

Вставьте полное объявление в панель Job Description. Чем полнее объявление, тем точнее анализ ключевых слов. Не сокращайте раздел требований.

Шаг 3: проверьте оценку ATS #

Панель показывает общий результат от 0 до 100 и разбивку по 5 показателям. Она подсказывает, над чем работать: проблемы форматирования снижают один показатель, отсутствующие ключевые слова — другой, а слабое описание опыта — третий.

Шаг 4: проверьте пробелы в ключевых словах #

Представление Keyword Analysis показывает, какие слова из вакансии есть в резюме, а каких нет. При включённом ИИ вы получите семантическое сопоставление и оценку важности. Пробел “Critical” в ключевом техническом навыке заслуживает большего внимания, чем “Low” в общем слове о мягком навыке.

Шаг 5: оптимизируйте #

  • Детерминированный режим: перестраивает документ по правилам. Безопасно, быстро, без затрат на API.
  • Режим ИИ: полная переработка языковой моделью с промптами по лучшим практикам ATS.

Просмотрите сравнение до и после, чтобы понять все изменения перед их принятием.

Шаг 6: экспортируйте #

Экспортируйте в PDF, DOCX, TXT или Markdown. С включённым ИИ экспорт форматируется для профессиональной подачи. Шаблон PDF использует подходящую типографику и знакомый рекрутерам макет.

Часто задаваемые вопросы #

Инструмент сохраняет моё резюме? #

Нет. Приложение полностью работает на стороне клиента. Ничего не сохраняется на сервере. Данные сеанса находятся в памяти браузера и исчезают после закрытия вкладки.

Резюме получило низкую оценку. Стоит ли беспокоиться? #

Оценки ATS показывают направление, а не результат “прошёл/не прошёл”. Оценка 60 не означает, что ATS вас отклонит. Она указывает на измеримые различия между вашим резюме и конкретной вакансией. Используйте оценку, чтобы расставить приоритеты изменений, а не как окончательный вердикт.

Можно ли использовать инструмент с несколькими вакансиями? #

Да. Вставьте новое описание вакансии в любое время. Анализ ключевых слов и оптимизация повторятся для новой вакансии. Каждый анализ выполняется независимо.

Интеграция Ollama действительно работает офлайн? #

Да, если Ollama запущена на вашем компьютере или в локальной сети. Приложение отправляет текст экземпляру Ollama по HTTP. Данные не уходят во внешние службы.

Насколько точно определяется тип резюме? #

Детектор применяет основанные на правилах эвристики к содержимому резюме: учитывает годы опыта, признаки образования, разделы публикаций и исследований, а также сигналы перерывов в карьере. Для большинства резюме он работает хорошо, но в необычных случаях возможна ошибка. Применённый порядок разделов всегда можно изменить.

Заключение #

ATS Resume Improver закрывает реальную потребность: серьёзный анализ резюме без передачи данных посредникам. Режим без ключа сразу даёт полезные замечания по форматированию и покрытию ключевых слов. Ключ ИИ добавляет семантический анализ, написание сопроводительных писем и подготовку к собеседованию. Каждая проверка стоит несколько центов или полностью бесплатна с Ollama.
