現場展開システムの電源と環境耐性

現場展開型サーバーの信頼性は電源に左右されます。 どれほど優れた筐体や高速なコンピューターでも、設置場所の電源が失われ、負荷を引き継ぐものがなければ役に立ちません。電源計画は構成の付属品ではありません。最初に故障しやすい構成要素です。

これは、迅速に展開できる小型サーバーとネットワーク機器を扱う全4回シリーズの第2回です。 第1回 では筐体と計算能力を扱いました。この回では機器への給電と、熱、ほこり、水、電気的な異常からの保護を説明します。 第3回 は接続性とデータ保護を扱い、 第4回 では細かな注意事項をまとめます。

現場用UPSの容量を選ぶ #

**UPS（無停電電源装置）**は、停電からシャットダウンまたは予備電源への切り替えまでの時間をつなぎます。現場向けの容量選定は簡単な計算から始めます。

  1. ケース内にあるコンピューター、スイッチ、アクセスポイント、ストレージなど、各機器の消費電力を合計します。
  2. 起動時の突入電流に備え、合計に1.5～1.6を掛けて余裕を持たせます。
  3. UPSの定格ワット時容量を総負荷電力で割り、稼働時間を時間単位で見積もります。

バッテリー容量は経年と温度によって低下します。メーカーの稼働時間は保証ではなく、最良条件での値として扱ってください。 特に高温環境ではバッテリーの容量が速く低下するため、実際の稼働時間を短めに見積もります。

Schneider Electric / APC はUPSの容量選定とバッテリー動作に関する詳しい情報を公開しています。 現場構成にも同じ基本ルールが当てはまります。UPSは壁のコンセントまたは発電機の出力へ直接接続し、サージ保護付き電源タップには接続しません。追加のコンセントが必要なら、UPSの下流に別のPDUを設置します。

UPSの種類適した用途トレードオフ
ラインインタラクティブUPS商用電源または発電機を使う多くの現場構成停電時の切り替え時間が短い。通常10ミリ秒未満
オンライン方式（ダブルコンバージョン）UPS不安定またはノイズの多い電源につなぐ精密機器1ワット当たりの重量と価格が大きい
インバーター内蔵DCバッテリーパック従来型UPSが収まらない超小型構成DCからAC、さらにDCへ変換するため効率が低い

DC電源を使い、インバーターを省く #

ACからDCへの変換では、毎回エネルギーの一部が熱として失われます。機器が対応していれば、DCから直接給電することで変換段階と故障箇所を一つ減らせます。

  • 12Vシステムは、シングルボードコンピューター、シンクライアント、小型スイッチなどの小規模構成に向きます。車両や船舶の一般的なバッテリー電圧にも合います。
  • 48Vシステムは大規模構成に向き、通信事業者の電源設備で使われる標準電圧と一致します。そのため、通信機器向けDC装置を中古で安く入手できることがあります。
  • 多くのネットワークスイッチやアクセスポイントはPoEまたはDC入力に対応しています。インバーターが必要だと決めつける前に仕様を確認してください。

DCネイティブ構成は、同じバッテリー容量でもインバーターを介するAC構成より長く動作します。インバーター自身の損失がなくなるためです。

ソーラーと発電機を組み合わせる #

単一のバッテリーパックより長い展開では、バッテリーバンクと充電源を組み合わせます。

  • 充電コントローラー付きの携帯型ソーラーパネルは、安定した日照がある場所で、昼に充電して夜にバッテリーを使う運用に適しています。
  • 小型インバーター発電機は天候に左右されず素早く充電できますが、燃料の輸送が必要で騒音も出ます。隠密性が必要な展開や騒音に敏感な場所では大きな問題です。
  • ハイブリッド構成ではソーラーを主電源、発電機を予備電源とし、悪天候で数日間ソーラー出力が不足する場合に備えます。

充電源がない状態で少なくとも丸1日自律稼働できるようにバッテリーバンクを選びます。 常に晴れることや燃料が確実に届くことを前提にした充電計画は、レジリエントではありません。

現場用バッテリーの化学系 #

揺れ、暑さ、寒さに繰り返しさらされるケースに、すべてのバッテリーパックが適しているわけではありません。ラベルに記載されたワット時の値と同じく、セルの化学系も重要です。

化学系適した用途トレードオフ
LiFePO4（リン酸鉄リチウム）多くの現場構成。長いサイクル寿命と最も安全な故障特性他のリチウム化学系よりワット時当たりの重量が大きい
リチウムイオン（NMC/NCA）グラム単位で重量を抑えたい構成高温や深放電への耐性が低く、サイクル寿命も短い
密閉型鉛蓄電池（AGM/ゲル）低予算の構成、または手元にある電池での一時的な対応重く、利用可能容量が少なく、3種類の中でサイクル寿命が最も短い

Battery Universityの二次電池化学系の比較 では、サイクル寿命と比エネルギーのトレードオフを詳しく説明しています。 LiFePO4は例外的に、高温、荒い扱い、完全放電への耐性が他の2種類より優れています。現場のケースが受ける条件に合っています。

どの化学系を選んでも、熱はバッテリーを劣化させます。 Battery Universityによるリチウムイオン容量劣化の調査 は、熱や高速充電サイクルが加わると、実環境の容量低下がメーカーの実験室定格を大幅に超えることを示しています。 同じ理由で、このシリーズでは暑い気候で定格より短い稼働時間を見込むよう勧めています。

USB-C PDで機器に給電する #

小型構成で使うシンクライアント、アクセスポイント、周辺機器の多くは、 USB Power Delivery（USB PD）仕様 に対応したUSB-Cから給電できます。現場用キットを大幅に簡素化できます。

  • USB PD対応のモバイルバッテリー1台で複数の専用電源アダプターを置き換えられます。 ケースに入れるケーブルやアダプターが減ります。
  • ケーブルの最大定格だけでなく、機器が実際にネゴシエートする電力を確認します。 出力不足のPD電源は、負荷中に機器の性能をひそかに制限したり、充電できなかったりします。
  • キット内で最大の電力に対応するPDケーブルを携行します。 60W定格の安価な充電専用ケーブルは、明確な警告なしに100W機器の電力を制限します。

USB-C PDは、上記のUPSやバッテリーバンクの容量設計の代わりにはなりません。小型周辺機器に便利な給電方法であり、ケース全体の主電源構成ではありません。

UPSを推測でなく監視する #

UPSが1時間前にバッテリーへ切り替わっていても、放電するまで誰も気づかなければ機器は守られません。 多くのUPSはUSBまたはネットワークカード経由で状態を提供します。現場構成では状態を読み取り、正常だと決めつけないでください。

  • Network UPS Tools（NUT） は1000を超えるUPSモデルを支援するオープンソースプロジェクトです。 メーカー固有プロトコルに関係なく、共通の監視・制御ツールを提供します。
  • バッテリー残量が定めたしきい値に達したら、コンピューターを自動的かつ正常にシャットダウンします。 UPSがゼロまで放電し、稼働中のファイルシステムから電源を奪う事態を避けます。
  • 現在の充電率だけでなく、バッテリーの状態と稼働時間の推移を記録します。 容量が静かに低下するバッテリーは、故障当日まで分かりやすい兆候を示さないことがあります。

監視されないUPSは、有効期限の分からないバッテリーです。 NUTまたは同等のメーカー製ツールを一度設定すれば、その後の展開ごとに状態を把握できます。

インターネットなしで時刻を同期する #

正確な時刻は、多くの構成が想定する以上に現場で重要です。 ログの突き合わせ、証明書の有効性、暗号化トンネルのハンドシェイク、展開中に作られるタイムスタンプ付き証跡に影響します。

  • ケース内のローカルNTPサーバーをGPS受信機またはインターネット接続時のstratum 1ソースと同期すれば、通信が途切れても全機器の時刻を合わせられます。
  • GPS同期時計はインターネットなしで動作します。 シリーズ後半で扱うメッシュや衛星バックアップの構成で役立ちます。
  • 数分のずれでもTLS証明書の検証やVPNハンドシェイクが失敗します。 ネットワーク障害に見える問題が、誰も確認しなかった時刻のずれであることがあります。

NTPバージョン4仕様のRFC 5905 は、これらのツールの大半が実装するプロトコルを定義しています。 サーバーの動的検出により、ケース内の小型NTPサーバーから他の機器へ最小限の設定で時刻を配信できます。

IPとNEMAの保護等級 #

2つの等級体系で、筐体や機器が投入先の環境に耐えられるかを判断できます。どちらも「堅牢」の言い換えではありません。具体的で検証可能な値を示します。

IEC 60529で定義される** IP（Ingress Protection）コード **は2桁です。1桁目はほこりなどの固体粒子に対する保護、2桁目は水などの液体に対する保護を示します。

IP等級意味
IP54ほこりと、あらゆる方向からの水しぶきから保護
IP65防じん構造で、低圧の噴流水から保護
IP67防じん構造で、最大1メートルの一時的な浸水から保護
IP68防じん構造で、メーカー指定の深さと時間にわたり、1メートルを超える継続的な浸水から保護

北米の産業機器でよく使われる** NEMA筐体等級 **は数字の組ではなくタイプ番号を使います。NEMA 3Rは一般的な屋外環境向けです。NEMA 4Xは防水性と耐食性を加え、沿岸や洗浄環境に適します。NEMA 6Pは一時的な浸水を対象とします。

最大の数字ではなく、展開場所の実際の危険に合わせて等級を選びます。 水にさらされない砂漠でIP68ケースを使うのは無駄な出費です。冷却やバッテリー容量に予算を回してください。

温度、振動、湿度 #

ほこりや水のほかに、3つの環境要因が現場の電子機器を静かに劣化させます。

  • 極端な温度はバッテリー寿命を縮め、コンピューターの速度を落としたり停止させたりします。筐体だけでなく、すべての部品の動作温度範囲を確認してください。
  • 振動は移動を繰り返すうちにコネクターを緩め、はんだ接合部を疲労させます。コンピュータートレイとケースの間にゴム製防振マウントを設け、振動が機器へ伝わる前に吸収します。
  • 湿度と結露はケースを冷えた車内から暖かく湿った空気へ移したときに発生します。大きな温度変化がある場合、開ける前に閉じたまま数分置いて順応させます。密閉ケースには小型乾燥剤も検討します。

接地とサージ保護 #

発電機などの現場電源は、商用電源よりノイズが多く予測しにくいものです。現場には、サージや接地不良が機器に届く前に止める建物の電気技師はいません。

  • 電源を接続する前に、ケースと金属ラックレールを適切に接地します。 状況に応じて接地棒または車両のシャーシグランドを使います。
  • 実際の電源に適したサージ保護機器を使います。 発電機の電圧変動は、安定した商用電源では起きない形で発生することがあります。
  • UPSを未処理の電源と機器の間に設置します。 逆にすると、UPSのサージ抑制が最も汚れた電源を最初に受け止められません。

設置を5分早く終えるために接地を省くと、ケース内の機器全体を危険にさらします。

電源と環境のチェックリスト #

  • UPSまたはバッテリーバンクの容量が総負荷の1.5～1.6倍の余裕を含む
  • 充電源なしで丸1日以上稼働できる
  • 筐体のIPまたはNEMA等級が現場の実際の危険に合っている
  • 筐体だけでなく、各部品の動作温度範囲を確認した
  • 長距離または悪路輸送に備えた防振対策がある
  • 発電機などの現場電源を接続する前に正しく接地した

次のステップ #

電源と環境保護を整えたら、次はシステムを外部ネットワークにつなぎ、通信中のデータを守る方法を考えます。 第3回：エッジノードの接続性とデータセキュリティ へ進んでください。

まだ読んでいない場合は、 第1回：ハードウェアと筐体の選定 で、この電源計画に合わせるコンピューターとケースを選びます。 第4回 ではその他の注意事項を扱います。
