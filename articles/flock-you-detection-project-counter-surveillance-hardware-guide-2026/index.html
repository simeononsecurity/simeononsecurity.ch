Введение: Контрнаблюдение с открытым исходным кодом #

Проект Flock-You — это инициатива с открытым исходным кодом, основанная на сообществе, для обнаружения и картографирования инфраструктуры ALPR-наблюдения Flock Safety. Размещённый на GitHub по адресу colonelpanichacks/flock-you, этот проект использует доступное оборудование на базе ESP32 для идентификации камер Flock по их сетевым сигнатурам WiFi.

Это исчерпывающее руководство охватывает всё: от технической методологии обнаружения Flock до пошаговых инструкций по настройке трёх аппаратных платформ, установки прошивки и информации о покупке у авторизованных поставщиков. Независимо от того, являетесь ли вы сторонником конфиденциальности, исследователем безопасности или обеспокоенным гражданином, это руководство поможет вам создать или приобрести собственное устройство обнаружения.

Для понимания важности этой технологии и более широкого ландшафта слежки читайте наш сопутствующий материал: Слежка с помощью камер Flock Safety: распространённость, проблемы конфиденциальности и стратегии защиты .

Хотите узнать, где уже нанесены на карту камеры Flock? Flock Finder — инструмент с открытым исходным кодом, отображающий более 40 000 предполагаемых камер Flock Safety по всему миру с использованием данных WiFi WiGLE и снятия отпечатков OUI — обновляется ежедневно. Исходный код на GitHub .

Понимание методологии обнаружения Flock-You #

Техническая основа #

Камеры Flock Safety содержат встроенные модули WiFi для подключения и удалённого управления. Эти модули транслируют идентифицируемые сетевые сигнатуры, обнаруживаемые устройствами, работающими в режиме прослушивания WiFi. Проект Flock-You использует эту характеристику через:

1. Обнаружение WiFi OUI (организационно уникального идентификатора) #

Каждый сетевой интерфейс имеет MAC-адрес, состоящий из:

  • Первых 3 байт (24 бита): OUI, идентифицирующий производителя
  • Последних 3 байт: идентификатор конкретного устройства

Исследователи @NitekryDPaul и сообщество DeFlockJoplin обнаружили 31 конкретный OUI, постоянно присутствующий в развёртываниях камер Flock Safety:

Основные OUI Espressif (модули на базе ESP32):
D4:AD:FC - Espressif Inc. (распространённый ESP32-S3)
AC:67:B2 - Espressif Inc. (ESP32-WROOM)
84:F3:EB - Espressif Inc. (варианты ESP32-S3)
B4:E6:2D - Espressif Inc. (ESP32-C3)
CC:DB:A7 - Espressif Inc. (на базе ESP32)
24:0A:C4 - Espressif Inc. (ESP32-SOLO)
30:AE:A4 - Espressif Inc. (ESP32-WROVER)
94:B9:7E - Espressif Inc. (на базе ESP32)
A4:CF:12 - Espressif Inc. (ESP32-S2)
C0:49:EF - Espressif Inc. (ESP32-C6)

Когда устройство обнаружения сканирует трафик WiFi в режиме прослушивания, оно идентифицирует любое устройство, транслирующее фреймы с этими OUI.

2. Обнаружение зондирующих запросов Wildcard #

Камеры Flock периодически отправляют запросы зондирования wildcard в поисках доступных сетей. У них есть отличительные характеристики:

  • Управляющий фрейм 802.11: тип=0, подтип=4
  • Информационный элемент SSID: длина=0 (пустой/wildcard)
  • Структура фрейма: предсказуемый паттерн в тайминге зондирования
  • Специфичные для производителя IE: дополнительные индикаторы в полезной нагрузке фрейма

Прошивка обнаружения анализирует эти паттерны зондирующих запросов для повышения уверенности в идентификации камеры Flock сверх простого сопоставления OUI.

3. Мониторинг WiFi в режиме прослушивания #

Стандартная работа WiFi принимает только фреймы, адресованные вашему устройству. Режим прослушивания захватывает все WiFi-фреймы в пределах досягаемости:

  • Структура фрейма 802.11: анализ полей addr1, addr2, addr3
  • Управляющие фреймы: зондирующие запросы, маяки, запросы на ассоциацию
  • Фреймы данных: раскрывают паттерны поведения сети
  • Управляющие фреймы: ACK, RTS, CTS предоставляют информацию о тайминге

Микроконтроллеры ESP32 поддерживают режим прослушивания через esp_wifi API, обеспечивая недорогое оборудование для обнаружения.

4. Анализ мощности сигнала #

Устройства обнаружения измеряют RSSI (индикатор мощности принятого сигнала) для:

  • Оценки расстояния до обнаруженных камер
  • Триангуляции местоположений при нескольких измерениях
  • Фильтрации ложных срабатываний на основе ожидаемых характеристик сигнала
  • Создания тепловых карт плотности камер

Точность обнаружения и ложные срабатывания #

Методология Flock-You обеспечивает высокую точность:

  • Частота истинных срабатываний: ~95% для подтверждённых камер Flock в зоне действия
  • Частота ложных срабатываний: ~5-10% в зависимости от окружения
  • Дальность обнаружения: 15-90 метров в зависимости от препятствий и антенны
  • Оценка уверенности: многофакторный анализ снижает количество ложных тревог

Распространённые источники ложных срабатываний:

  • Платы разработки ESP32, используемые в других IoT-устройствах
  • Коммерческие продукты на базе ESP32 (умный дом, датчики)
  • Другие камеры видеонаблюдения, использующие аналогичные компоненты
  • Оборудование для тестирования WiFi, обслуживаемое техниками

Стратегии смягчения:

  • Многосигнатурное обнаружение: сочетание OUI + паттерн зондирования + физическая верификация
  • Корреляция местоположения: сопоставление с известными местоположениями камер
  • Визуальное подтверждение: физический осмотр после электронного обнаружения
  • База данных сообщества: валидация обнаружений краудсорсингом

Подробный анализ платформ #

1. Сборка DIY ESP32 ($5-12) #

Обзор: Наиболее доступный вариант, использующий стандартные платы разработки ESP32 с открытой прошивкой.

Технические характеристики:

  • Микроконтроллер: ESP32-WROOM-32 или аналогичный (двухъядерный, 240МГц)
  • WiFi: 802.11 b/g/n, поддерживает режим прослушивания
  • Память: 520КБ SRAM, 4МБ+ Flash
  • Дисплей: Опционально (встроенного LED достаточно)
  • Питание: USB или внешний аккумулятор
  • Зуммер: Опциональный пассивный зуммерный модуль (KY-006)
  • Индикаторы: Встроенный LED + опциональный зуммер
  • Расширяемость: Совместим с макетной платой, лёгкие модификации

Прошивка: Форк с открытым исходным кодом simeononsecurity/flock-you-esp32:

  • Модифицирован для стандартного оборудования ESP32 (GPIO 25, 2, 17)
  • Стартовая мелодия из Super Mario Bros. (подтверждает работу зуммера)
  • Два быстрых нарастающих сигнала при новом обнаружении
  • Сигналы heartbeat каждые 10 секунд при активном слежении
  • Поддержка панели управления Flask для вардрайвинга с GPS
  • Экспорт в форматы JSON, CSV, KML

Варианты сборки:

  • Только LED ($5): Голый ESP32 + USB-кабель, только визуальная обратная связь
  • Макетная плата ($9-11): Добавьте пассивный зуммер + макетная плата + перемычки, звуковые оповещения
  • В корпусе ($10-12): Добавьте 3D-печатный корпус со защёлкивающейся крышкой

Преимущества:

  • ✅ Самый дешёвый вариант (экономия 85-95% по сравнению с OUI-SPY)
  • ✅ Полностью открытый исходный код и возможность модификации
  • ✅ Использует широко доступные платы ESP32
  • ✅ Образовательный, обучает встраиваемым системам
  • ✅ Обширная документация и руководства
  • ✅ Доступны файлы корпуса для 3D-печати
  • ✅ Такая же точность обнаружения, как у премиальных устройств

Недостатки:

  • ❌ Требует самостоятельной сборки (макетная плата без пайки или 3D-корпус)
  • ❌ Необходима ручная прошивка
  • ❌ Нет встроенного аккумулятора (питание USB или внешний)
  • ❌ Только базовая звуковая обратная связь (нет дисплея)
  • ❌ Требует времени на поиск компонентов

Лучше всего для: мейкеров, студентов, сторонников конфиденциальности с ограниченным бюджетом, тех, кто хочет понять, как работает обнаружение, любителей DIY-проектов.

Покупка компонентов:

  • Amazon: Искать «ESP32 DevKit» или «ESP32 Breadboard Kit»
  • AliExpress/eBay: Доступны скидки при оптовых закупках
  • Adafruit: Качественные отобранные детали с обучающими материалами

Ресурсы по настройке:

  • Репозиторий GitHub: github.com/simeononsecurity/flock-you-esp32
  • Руководство по сборке: Бессварочная сборка за 10-15 минут
  • Файлы корпуса: Параметрический дизайн OpenSCAD + STL-файлы

2. M5 Atom Lite с предустановленной прошивкой от STS Collective ($39.99) #

Обзор: Компактное устройство обнаружения с предустановленной прошивкой, готово к использованию сразу из коробки.

Технические характеристики:

  • Микроконтроллер: ESP32-PICO-D4 (двухъядерный, 240МГц)

  • Питание: 5В через USB-C или разъём Grove
  • Аккумулятор: Не включён (рекомендуется внешний USB-аккумулятор)
  • Индикатор: Программируемый RGB LED (синий=обнаружение)
  • Кнопки: 1 программируемая кнопка
  • Ввод/вывод: Разъём Grove для расширения
  • Размер: Ультракомпактный 24×24×14мм
  • Корпус: Прочный пластиковый модуль

Прошивка: Пользовательский порт FlockYou от STS Collective (проприетарный):

  • Предустановлен и готов к использованию
  • Синий светодиод при обнаружении камеры Flock
  • Основан на исследовании FlockYou от colonelpanichacks
  • Не требует настройки или прошивки
  • Простая работа plug-and-play
  • Опциональная поддержка панели управления

Преимущества:

  • ✅ Предустановленная прошивка, техническая настройка не требуется
  • ✅ Доступное решение готово к использованию
  • ✅ Чрезвычайно компактный и портативный
  • ✅ Проверенная аппаратная платформа
  • ✅ Простой синий LED = обнаружение
  • ✅ Питание от USB-C (автомобиль, внешний аккумулятор, ноутбук)
  • ✅ Качественная поддержка поставщика
  • ✅ Обычная цена $99.99, по акции $39.99

Недостатки:

  • ❌ Нет встроенного аккумулятора (требуется питание USB)
  • ❌ Ограниченный дисплей (только RGB LED, нет экрана)
  • ❌ Прошивка проприетарная, пока не с открытым исходным кодом
  • ❌ Нет ведения журнала без подключения к компьютеру
  • ❌ Одна кнопка ограничивает функциональность

Лучше всего для: пользователей, желающих мгновенного обнаружения без DIY-работы, приоритета портативности, тех, кто доволен простой обратной связью через LED, экономных покупателей, желающих готовое решение.

3. OUI-SPY от Colonel Panic Tech ($85) #

Обзор: Многорежимная плата обнаружения слежки с четырьмя различными режимами прошивки, выбираемыми через меню WiFi.

Технические характеристики:

  • Микроконтроллер: ESP32-S3 двухъядерный Xtensa LX7, 8МБ Flash
  • WiFi: 802.11 b/g/n, поддерживает режим прослушивания
  • Память: 8МБ Flash
  • Дисплей: Отсутствует (голая PCB с LED-индикаторами)
  • Аккумулятор: Не включён
  • Зарядка: Питание и программирование через USB-C
  • Хранилище: Отсутствует (только режимы обнаружения)
  • Индикаторы: Встроенный PWM-зуммер с мелодиями для каждого режима
  • Кнопки: Кнопка Boot для переключения режимов
  • Антенна: Переключаемая, встроенная керамическая 2.4ГГц ИЛИ внешняя через разъём MMCX
  • Корпус: Отсутствует (голая PCB с художественным оформлением)
  • Уникальная особенность: Рандомизация MAC при каждой загрузке

Прошивка: OUI-SPY Unified Blue с 4 выбираемыми режимами:

  1. Режим Detector: Многоцелевой BLE-сканер с фильтрацией OUI + веб-портал конфигурации
  2. Режим Foxhunter: RSSI-трекер близости к одной цели для радиопеленгования
  3. Режим Flock-You: Обнаружение камер Flock Safety и Raven с GPS-вардрайвингом, экспортом JSON/CSV/KML
  4. Режим Sky Spy: Детектор RemoteID дронов (OpenDroneID / ASTM F3411) с отслеживанием нескольких дронов

Выбор режима:

  • Меню загрузки WiFi по адресу 192.168.4.1

Подробный технический разбор: понимание кода #

Основной алгоритм обнаружения (упрощённый) #

Для тех, кто интересуется технической реализацией, вот упрощённый вид логики обнаружения:

// Flock-You Detection Core (Conceptual - not full code)

// OUI Database (31 known Flock-associated OUIs)
const uint8_t FLOCK_OUI_LIST[][3] = {
    {0xD4, 0xAD, 0xFC}, // Espressif ESP32-S3
    {0xAC, 0x67, 0xB2}, // Espressif ESP32-WROOM
    {0x84, 0xF3, 0xEB}, // Espressif ESP32-S3 variant
    // ... 28 more OUIs ...
};

// Promiscuous mode callback
void wifi_sniffer_callback(void* buf, wifi_promiscuous_pkt_type_t type) {
    wifi_promiscuous_pkt_t *pkt = (wifi_promiscuous_pkt_t*)buf;
    
    // Extract MAC address from frame
    uint8_t *mac = pkt->payload + 10; // addr2 field position
    
    // Check against OUI database
    for (int i = 0; i < NUM_OUIS; i++) {
        if (memcmp(mac, FLOCK_OUI_LIST[i], 3) == 0) {
            // OUI match found
            int rssi = pkt->rx_ctrl.rssi;
            
            // Check signal strength threshold
            if (rssi > RSSI_THRESHOLD) {
                // Analyze frame for additional signatures
                if (is_wildcard_probe_request(pkt)) {
                    // High confidence detection
                    trigger_alert(mac, rssi, HIGH_CONFIDENCE);
                } else {
                    // OUI match only
                    trigger_alert(mac, rssi, MEDIUM_CONFIDENCE);
                }
            }
        }
    }
}

// Wildcard probe detection
bool is_wildcard_probe_request(wifi_promiscuous_pkt_t *pkt) {
    // Management frame, subtype probe request
    if ((pkt->payload[0] & 0x0F) != 0x04) return false;
    
    // Check for empty SSID IE (wildcard)
    // Position depends on frame structure
    uint8_t *ie = &pkt->payload[24]; // Start of IEs
    if (ie[0] == 0x00 && ie[1] == 0x00) {
        return true; // Wildcard probe
    }
    return false;
}

Ключевые технические концепции #

Режим прослушивания: Вместо получения только фреймов, адресованных вашему устройству, ESP32 захватывает все WiFi-фреймы в пределах досягаемости. Это необходимо для обнаружения близлежащих устройств, не взаимодействующих с вашим детектором.

Структура MAC-адреса: Каждый WiFi-фрейм содержит несколько MAC-адресов:

  • addr1: Адрес получателя
  • addr2: Адрес передатчика (содержит OUI)
  • addr3: Адрес конечного назначения/источника

RSSI (индикатор мощности принятого сигнала): Мощность сигнала в дБм (отрицательные децибелы относительно 1 милливатта). Типичные значения:

  • -30 дБм: Чрезвычайно сильный (очень близко)
  • -50 дБм: Сильный сигнал
  • -70 дБм: Слабый, но используемый
  • -90 дБм: Очень слабый (граница диапазона)

Зондирующие запросы: WiFi-устройства отправляют зондирующие запросы для обнаружения доступных сетей. Зондирование wildcard (пустой SSID) ищет любую сеть, что характерно для IoT-устройств, таких как камеры Flock, делая их надёжно обнаруживаемыми.

Устранение распространённых проблем #

Проблема: Нет обнаружений, хотя известная камера находится рядом #

Возможные причины:

  1. Камера отключена/выключена: Камеры Flock временно неактивны иногда
  2. Сигнал заблокирован: Строительные материалы поглощают WiFi (металл, бетон)
  3. Вне зоны действия: Эффективная дальность ~30-90 метров в зависимости от препятствий
  4. Проблема прошивки: Устаревшая прошивка пропускает более новые варианты OUI

Решения:

  • Убедитесь, что камера видна и работает (солнечные панели, огни)
  • Подойдите ближе к предполагаемому местоположению камеры
  • Попробуйте различные ориентации антенны
  • Обновите до последней прошивки Flock-You
  • Проверьте, что устройство активно сканирует (проверьте активность LED/дисплея)

Проблема: Чрезмерные ложные срабатывания #

Возможные причины:

  1. Высокая плотность ESP32-устройств: Устройства умного дома, IoT широко распространены
  2. Слишком высокая чувствительность: Обнаружение удалённых/нерелевантных устройств
  3. Другие камеры видеонаблюдения: Многие используют ESP32-модули

Решения:

  • Уменьшите настройку чувствительности
  • Включите обнаружение зондирования wildcard (более высокая уверенность)
  • Физически проверяйте обнаружения перед регистрацией
  • Используйте мощность сигнала для фильтрации (оповещайте только при сильных сигналах)
  • Обновите базу данных OUI для фокусировки на подтверждённых OUI Flock

Проблема: Аккумулятор быстро разряжается #

Возможные причины:

  1. Непрерывное сканирование: Нет управления sleep/питанием
  2. Дисплей постоянно включён: Экран потребляет значительную мощность
  3. GPS активен: GPS-модули энергоёмкие
  4. Старый аккумулятор: Li-Po аккумуляторы деградируют со временем

Решения:

  • Включите режим пассивного сканирования (периодическое vs. непрерывное)
  • Установите таймаут дисплея
  • Отключите GPS, когда картографирование не нужно
  • Замените аккумулятор (OUI-SPY/mesh-detect v2 имеют заменяемые аккумуляторы)
  • Используйте внешний аккумулятор для расширенных сессий

Проблема: GPS не получает захват #

Возможные причины:

  1. Использование в помещении: GPS требует видимости неба
  2. Антенна не подключена: mesh-detect v2 требует подключения внешней антенны
  3. Холодный старт: Первый захват GPS занимает 5-15 минут
  4. Помехи: Близлежащая электроника мешает сигналу

Решения:

  • Переместитесь на позицию с чистым видом неба
  • Убедитесь в правильном подключении антенны (разъём SMA)
  • Дождитесь начального захвата (последующие захваты быстрее)
  • Отдалитесь от источников радиочастотных помех
  • Убедитесь, что GPS включён в настройках

Проблема: Данные не записываются на SD-карту #

Возможные причины:

  1. SD-карта не отформатирована: Должна быть в формате FAT32
  2. SD-карта заполнена: Нет оставшегося места
  3. Карта не обнаружена: Не полностью вставлена
  4. Повреждение файловой системы: Карта повреждена

Решения:

  • Отформатируйте SD-карту как FAT32 (максимум 32ГБ для совместимости)
  • Удалите старые журналы или используйте большую карту
  • Вставьте карту полностью (должен быть щелчок)
  • Переформатируйте карту или замените при повреждении
  • Убедитесь, что устройство распознаёт карту (меню покажет статус SD)

  • ❌ Незаконно: Активное глушение/помехи работе камеры
  • ❌ Незаконно: Попытки взлома или доступа к системам камер
