攻击类型是技术类别，而不是某个单独工具。勒索软件、网络钓鱼和凭据填充都指攻击者反复针对多个目标使用、只做少量变体的方法。了解这些类别，有助于你整理在安全团队中遇到的告警。

单个恶意软件家族可能在几个月内出现又消失。下列攻击类别多年来一直相对稳定，并且每种都会在终端、身份、网络或电子邮件遥测数据中留下可识别的痕迹。

要点 #

  • 学习攻击模式，而非载荷。 攻击类别的变化速度远慢于单个工具。
  • 每种类别都会留下证据。 检测工作从了解哪种遥测记录了活动开始。
  • 通过复现攻击来理解它。 家庭实验室能把抽象的攻击类别变成有记录的观察结果。
  • 记录你的发现。 简短的调查记录既能证明工作，也能说明收集到的证据。

常见攻击类型一览 #

下表列出了安全团队最常遇到的攻击类别。后续各节会介绍每种类别、常见变体，以及防御人员为检测它而查看的数据。

攻击类型作用
恶意软件运行勒索软件、间谍软件和木马等恶意程序
拒绝服务用流量淹没服务，直到合法用户无法访问
网络钓鱼诱骗他人泄露凭据或运行恶意文件
欺骗伪装成可信系统、发件人或地址
基于身份的攻击滥用被盗或伪造的凭据，以有效用户身份行事
代码注入向应用程序插入恶意代码，改变其行为
供应链攻击入侵可信供应商、库或更新渠道
社会工程操纵他人采取不安全的行动
内部威胁滥用现任或前任员工拥有的访问权限
DNS 隧道在 DNS 查询中编码数据，以绕过控制措施
物联网攻击针对联网设备进行横向移动、监视或加入僵尸网络
人工智能攻击使用机器学习生成内容、冒充他人或绕过过滤器

范围说明： 这些类别会相互交叉。网络钓鱼邮件经常携带恶意软件，凭据被盗后也常会出现基于身份的攻击。请把列表当作不同的观察角度，而不是互不相干的固定类别。

恶意软件 #

恶意软件是任何旨在破坏、控制系统或从系统获利的程序。该术语涵盖勒索软件、无文件恶意软件、间谍软件、广告软件、木马、蠕虫、Rootkit、键盘记录器和僵尸网络。

子类型行为
勒索软件加密文件，并要求支付解密密钥费用
无文件恶意软件通过系统内置工具运行，很少写入磁盘
间谍软件在用户不知情的情况下收集活动数据
木马伪装成合法软件，诱使用户运行
蠕虫无需用户操作便在主机之间复制自身
Rootkit隐藏在操作系统中以长期维持控制权

证据所在位置： 终端检测与响应工具，即 EDR，会记录进程树、命令行、文件写入和注册表更改。无文件攻击同样会产生进程和脚本遥测，因为操作系统仍会启动攻击所滥用的工具。

拒绝服务 #

拒绝服务（DoS）攻击向目标发送大量请求，直到合法用户无法访问。分布式拒绝服务（DDoS）攻击同时从多个系统重复相同做法，因此更难按源地址过滤流量。

特征DoSDDoS
来源一个系统多个系统
阻止难度中等高，因为来源分布在多个网络中
典型影响可用性丧失大规模可用性丧失

证据所在位置： 与基线相比的流量大小、每个来源的连接数、请求速率峰值和错误率变化。可用性监控通常会在安全团队发现事件之前发出告警。

网络钓鱼 #

网络钓鱼利用电子邮件、短信、电话或社交媒体，诱使他人泄露凭据或运行恶意附件。不同变体按照目标和渠道区分。

变体目标和渠道
鱼叉式网络钓鱼通过电子邮件针对特定个人或团队
高管钓鱼针对高级或执行人员，通常意在转移资金或数据
短信钓鱼欺诈性短信
语音钓鱼欺诈性电话或语音消息

证据所在位置： 邮件网关日志、URL 检查结果、附件分析和用户报告。谨慎员工的报告是此列表中价值最高的信号之一。

欺骗 #

欺骗攻击将攻击者隐藏在可信身份背后，使目标接受连接、消息或地址。伪装为攻击者争取时间，并绕过基于信任的检查。

类型伪造对象
域名欺骗冒充真实品牌的相似网站或电子邮件域名
电子邮件欺骗消息的发件人地址
ARP 欺骗本地网络地址，用于拦截两个主机之间的流量

证据所在位置： 邮件标头中的 SPF、DKIM 和 DMARC 结果、域名注册年限、证书不匹配，以及本地网络上的重复地址警告。

基于身份的攻击 #

基于身份的攻击使用有效账户，而非利用软件漏洞。攻击者拥有可用凭据，所以活动看起来像正常使用，并混在背景噪声中。这类攻击占**安全运营中心（SOC）**每日处理告警的很大一部分。

如果你只在家庭实验室中练习一种攻击类型，就选择这一类。相关信号丰富，练习可重复，而且设置规模不大。

技术过程
Kerberoasting请求服务票证，然后离线破解其中的加密密码
中间人攻击（MITM）插入双方之间，以读取或修改会话
哈希重用攻击 (Pass-the-Hash)重用被盗的密码哈希来开启新会话
Golden ticket伪造 Kerberos 票证以获得广泛的域访问权限
Silver ticket伪造某项特定服务的服务票证
凭据收集批量收集用户名和密码
凭据填充在许多互不相关的网站上重复尝试同一组凭据
密码喷洒对许多账户尝试一个常见密码
暴力破解对一个账户尝试许多密码
降级攻击迫使连接使用较弱版本的协议

证据所在位置： 登录记录、身份验证失败次数、令牌异常、不可能的行程告警和身份风险检测。对手中间人（AiTM）网络钓鱼也属于此类，因为攻击者窃取的是有效会话令牌而非密码；从陌生基础设施重放令牌会触发身份风险引擎。

代码注入 #

代码注入把攻击者控制的代码放进有漏洞的应用程序，使应用程序在正常工作时运行这些代码。执行有害操作的是应用程序，而不是攻击者本人。

类型目标
SQL 注入使用未经验证的输入构建的数据库查询
跨站脚本（XSS）在访客浏览器中运行攻击者脚本的网页
恶意广告被恶意代码填充的合法广告位
数据投毒AI 或机器学习模型的训练数据集

证据所在位置： Web 应用日志、数据库查询记录、内容安全策略报告，以及不同于正常应用使用的请求模式。

供应链攻击 #

供应链攻击针对受信任的第三方，该第三方的产品或服务会触达许多客户。软件供应链攻击会将恶意代码注入应用程序、库或更新，再交付给该产品的所有用户。硬件供应链攻击则在发货前入侵实体组件。

现代软件依赖第三方库，因此一个被入侵的依赖项可能影响远超原始供应商的用户。

证据所在位置： 软件组成分析、构建流水线记录、可信更新产生的意外出站连接，以及已发布制品的完整性检查。

社会工程 #

社会工程利用心理压力诱使他人采取不安全的行动。攻击者诉诸权威、紧迫感、恐惧、金钱或信任。

技术手法
借口编造编造可信情境以获取信任
商业电子邮件欺诈（BEC）冒充可信同事，以转移款项或索取数据
虚假信息通过社交媒体和机器人传播虚假说法
互惠交换以奖励换取信息或访问权限
情感陷阱建立虚假关系以获取金钱、数据或访问权限
尾随进入跟随员工通过安全门

证据所在位置： 电子邮件身份验证结果、异常的付款更改请求、服务台记录和物理访问日志。

内部威胁 #

内部威胁是现任或前任员工、承包商或合作伙伴滥用访问权限。有些人出于金钱或不满而故意行动，另一些人则因疏忽而造成风险，例如把凭据留在共享文档中。

事件报告中，疏忽的内部人员比恶意内部人员更常见。两种情况都需要相同的检测控制：将访问行为与该角色的基线进行比较。

证据所在位置： 数据传输量、非正常工作时间的活动、权限变更，以及从敏感代码库批量下载文件的记录。

DNS 隧道 #

DNS 隧道在 DNS 查询和响应中编码数据。几乎所有网络都允许 DNS，因此这种方法能绕过为检查 Web 流量而设的控制措施。

检测依赖流量大小和形态。单个主机向一个域名发送数千次查询，会明显偏离正常基线；异常长的子域名则可能包含编码后的载荷。

证据所在位置： DNS 查询记录、每台主机的查询长度和数量、TXT 等不常见的记录类型，以及对几天前才注册的域名发起的查询。

物联网攻击 #

物联网攻击针对摄像头、打印机、恒温器或传感器等联网设备。较弱的默认凭据和罕见的固件更新，使这些设备成为常见的入侵入口。设备被攻陷后，可能加入僵尸网络、泄露数据，或成为进入更大网络的通道。

5G 部署会大规模增加联网设备，每台新设备都是一个补丁周期较长的新目标。

证据所在位置： 设备清单、出站连接模式、固定用途设备产生的异常数据传输，以及设备群中的固件版本差异。

人工智能攻击 #

人工智能攻击将机器学习应用于攻击者的工作。

技术用途
对抗性 AI/ML操纵训练数据或输入以误导模型
Dark AI专门运用 AI 和机器学习来利用漏洞
深度伪造生成逼真的伪造音频、视频或图像
AI 生成的社会工程大规模进行令人信服的聊天或语音交流

深度伪造语音电话或流畅的钓鱼聊天，会让老套路更有说服力。底层技术仍然熟悉，因此基于行为的检测技能比绑定某个工具的技能更经久耐用。

证据所在位置： 内容来源信号、通过其他渠道核实金钱或访问请求，以及身份和付款变更前后的行为异常。

将攻击与遥测数据对应起来 #

每种类别都会进入不同的数据源。下表将二者对应起来，为检测工作提供一个起点。

攻击类型主要遥测数据
恶意软件EDR 中的进程、文件和注册表记录
拒绝服务网络流量和可用性监控
网络钓鱼邮件网关和 URL 分析记录
欺骗邮件身份验证和网络地址记录
基于身份登录和身份保护记录
代码注入Web 应用和数据库查询日志
供应链构建流水线和依赖项清单
社会工程邮件、服务台和物理访问记录
内部威胁数据访问和传输记录
DNS 隧道DNS 查询记录
物联网设备清单和出站流量记录
基于 AI身份、付款和内容来源记录

从遥测数据列开始检测。有效规则应基于已知数据源和已知行为，而非工具名称。

事件中不同类别会相互交叉。 一封钓鱼邮件可能导致凭据被盗、恶意软件运行和基于身份的入侵。标记最初的访问技术，然后分别记录后续行为。这样不会把一个事件拆成四个互不相关的告警，也能让调查时间线更清晰。

在实验室中练习检测 #

除非亲眼观察，否则攻击类别仍然抽象。家庭实验室让你能够生成活动、收集遥测数据，并将告警与原始记录进行比较。 搭建安全运营中心的职业视频 展示了完整搭建过程，帮助你在受聘前积累工作经验。

从身份类别开始。创建测试用户，启用登录记录，然后连续执行失败和成功的登录。接着阅读登录记录，写下哪些字段能够区分正常使用和练习活动。

可重复的练习：

  1. 从上面的遥测表中选择一个类别。
  2. 在自己的测试系统或账户上复现安全版本的活动。
  3. 收集该类别产生的遥测数据。
  4. 将检测思路写成规则、已保存的搜索或查询。
  5. 用练习活动测试规则，确认它会针对预期行为触发。
  6. 记录规则的限制，包括它无法检测到的活动。

Microsoft SOC Home Lab 指南 详细介绍了环境搭建，包括许可、网络分段、日志收集和身份控制测试。 Mad Hat Cyber Range 指南 将同一思路扩展为适用于工作坊的环境，并包含攻击、检测和防御练习。

为保持术语一致，请将观察到的行为映射到相应的 MITRE ATT&CK 技术 。把映射当作分析师的辅助工具，而不是归因证据。请将原始事件、查询、规则版本和已知盲点与练习记录一并保存。

后续步骤 #

从一个类别和一个练习开始。完成并记录第一个练习后，再加入第二个类别。目标是深入开展一次调查，而不是列出一份工具清单。

  • Microsoft SOC Home Lab 指南 为这些练习搭建环境。
  • 搭建家庭 IT 实验室 介绍安全实验室所需的底层基础设施。
  • IT 简历写作建议 展示如何把有记录的实验室作为实践经验写进简历。
  • 五大网络攻击途径及其缓解措施 将范围缩小到最常见的攻击途径。

参考资料： 攻击类别及其子类型参考了 Kurt Baker 撰写的 CrowdStrike 常见网络攻击概述 。产品和参考链接指向 Microsoft 文档。
