أساسيات الشبكات: فهم طبقات OSI ونموذج TCP IP #

مقدمة #

في الشبكات، من الضروري فهم البروتوكولات والنماذج التي تنظّم الاتصال. ومن أشهر الأطر نموذج OSI (الربط البيني للأنظمة المفتوحة) ونموذج TCP IP (بروتوكول التحكم في الإرسال/بروتوكول الإنترنت). يوفّر النموذجان طريقة منظمة لفهم الشبكات، ويشكلان أساسًا لبناء الأنظمة واستكشاف أعطالها. يشرح هذا المقال طبقات OSI ونموذج TCP IP بوضوح.

طبقات OSI #

نموذج OSI إطار مفاهيمي يصف تفاعل بروتوكولات الشبكة وكيفية تمكين الاتصال بين الأنظمة. ويتكون من سبع طبقات، لكل منها مسؤولياتها.

طبقة OSIوصف الطبقةأمثلةالبروتوكولاتالمعايير
الطبقة الفيزيائيةتنقل البيانات ماديًاكابلات، موصلاتEthernet، USB، HDMIIEEE 802.3، USB 3.0
طبقة ربط البياناتتضمن نقلًا موثوقًا بين العقد المتجاورةمحولات، NICsEthernet، Wi-Fi (802.11)، PPPIEEE 802.3، IEEE 802.11، RFC 1662
طبقة الشبكةتوجه حزم البيانات عبر شبكات مختلفةموجّهاتIP، ICMP، ARPIPv4 (RFC 791)، IPv6 (RFC 2460)، ARP (RFC 826)
طبقة النقلتوفر تسليمًا موثوقًا للبيانات من طرف إلى طرفبواباتTCP، UDPTCP (RFC 793)، UDP (RFC 768)
طبقة الجلسةتدير جلسات الاتصال بين التطبيقاتNetBIOSNetBIOS، SIPRFC 1001، RFC 1002، RFC 3261
طبقة العرضتعالج صياغة المعلومات ومعناهاSSL، HTTPSSL/TLS، HTTPSSL/TLS (RFC 5246)، HTTP (RFC 2616)
طبقة التطبيقتتفاعل مباشرة مع تطبيقات المستخدم النهائيمتصفحات، عملاء بريدHTTP، FTP، SMTP، DNSHTTP (RFC 2616)، FTP (RFC 959)، SMTP (RFC 5321)، DNS (RFC 1035)

إليك شرحًا موجزًا لكل طبقة:

الطبقة 1: الطبقة الفيزيائية #

الطبقة الفيزيائية أدنى طبقات OSI، وتتولى الإرسال المادي للبيانات عبر الشبكة. تحدد مكونات الأجهزة، مثل الكابلات والموصلات وواجهات الشبكة، التي تنقل الإشارات الثنائية (0 و1). من أمثلة البروتوكولات فيها Ethernet وUSB وHDMI.

الطبقة 2: طبقة ربط البيانات #

تتولى طبقة ربط البيانات النقل الموثوق بين العقد المتجاورة، مثل المحولات وبطاقات واجهة الشبكة (NIC). وتضمن إرسالًا خاليًا من الأخطاء وتوفر آليات التحكم في التدفق واكتشاف الأخطاء. من بروتوكولاتها الشائعة Ethernet وWi-Fi (802.11) وبروتوكول نقطة إلى نقطة (PPP).

الطبقة 3: طبقة الشبكة #

تتولى طبقة الشبكة توجيه حزم البيانات بين الشبكات. وتحدد المسار الأمثل اعتمادًا على ظروف الشبكة وعناوينها. ويُعد بروتوكول الإنترنت (IP) أساسيًا هنا؛ إذ يخصص عناوين IP فريدة للأجهزة للتعريف بها وتوجيه البيانات إليها.

الطبقة 4: طبقة النقل #

توفر طبقة النقل تسليمًا موثوقًا وفعالًا من طرف إلى طرف بين التطبيقات على أجهزة مختلفة. وتنشئ الاتصالات، وتقسيم البيانات إلى وحدات أصغر عند الحاجة، وتوفر آليات استعادة الأخطاء والتحكم في التدفق. ومن بروتوكولاتها الشائعة TCP وUDP.

الطبقة 5: طبقة الجلسة #

تدير طبقة الجلسة جلسات الاتصال بين التطبيقات على أجهزة مختلفة. فهي تنشئ الجلسات وتحافظ عليها وتنهيها لتمكين تبادل البيانات بين العمليات. وتشمل مسؤولياتها المزامنة والتحكم في الحوار. من أمثلتها NetBIOS وبروتوكول بدء الجلسة (SIP).

الطبقة 6: طبقة العرض #

تعالج طبقة العرض صياغة المعلومات ومعناها عند تبادلها بين الأنظمة. وتضمن تنسيق البيانات وترميزها وتشفيرها للنقل الآمن. كما تتولى ضغط البيانات والتشفير وتحويل البروتوكولات. من أمثلتها Secure Sockets Layer (SSL) وHypertext Transfer Protocol (HTTP).

الطبقة 7: طبقة التطبيق #

طبقة التطبيق أعلى طبقات OSI وتتفاعل مباشرة مع تطبيقات المستخدم النهائي. وتوفر خدمات تمكّن تواصل المستخدمين وتبادل البيانات. من أمثلتها HTTP وFTP وSMTP وDNS.

نموذج TCP IP #

يوفر نموذج OSI إطارًا مفاهيميًا، أما نموذج TCP IP فهو مجموعة البروتوكولات المستخدمة فعليًا على الإنترنت. ويتكون من أربع طبقات تقابل بعض طبقات OSI.

طبقة TCP IPوصف الطبقةأمثلةالبروتوكولات
طبقة واجهة الشبكةتتولى النقل المادي للبياناتبطاقات NIC، كابلات EthernetEthernet، Wi-Fi (802.11)
طبقة الإنترنتمسؤولة عن العنونة والتوجيه وتجزئة البياناتموجّهاتIP، ICMP، ARP
طبقة النقلتوفر اتصالًا موثوقًا وموجهًا بالاتصالبواباتTCP، UDP
طبقة التطبيقتمثل الواجهة بين التطبيقات والبروتوكولاتمتصفحات، عملاء بريدHTTP، FTP، SMTP، DNS

إليك نظرة على هذه الطبقات:

الطبقة 1: طبقة واجهة الشبكة #

تقابل طبقة واجهة الشبكة مجموع الطبقتين الفيزيائية وربط البيانات في نموذج OSI. وهي تتولى نقل البيانات ماديًا عبر الشبكة وتوفر بروتوكولات للتحكم في ربط البيانات.

الطبقة 2: طبقة الإنترنت #

تعادل طبقة الإنترنت طبقة الشبكة في نموذج OSI. وتشمل بروتوكول IP المسؤول عن عنونة حزم البيانات وتوجيهها وتجزئتها لإرسالها عبر الشبكات.

الطبقة 3: طبقة النقل #

تقابل طبقة النقل في نموذج TCP IP طبقة النقل في OSI. وتوفر اتصالًا موثوقًا وموجهًا بالاتصال باستخدام TCP، أو اتصالًا خفيفًا بلا اتصال باستخدام UDP.

الطبقة 4: طبقة التطبيق #

تضم طبقة التطبيق في TCP IP وظائف طبقات الجلسة والعرض والتطبيق في OSI. وهي الواجهة بين التطبيقات وبروتوكولات الشبكة الأساسية.

الخلاصة #

يُعد فهم طبقات OSI ونموذج TCP IP ضروريًا للعاملين في الشبكات. يوفر النموذجان إطارًا لفهم عمل الشبكات والبروتوكولات التي تتيح الاتصال. ومعرفة وظيفة كل طبقة تساعد مسؤولي الشبكات والمهندسين على استكشاف الأعطال بفعالية وتصميم أنظمة قوية.
