Linux एक लोकप्रिय ऑपरेटिंग सिस्टम है, जिसका उपयोग व्यक्ति और व्यवसाय दोनों करते हैं। ओपन-सोर्स प्रकृति के कारण इसे अक्सर अन्य ऑपरेटिंग सिस्टम से अधिक सुरक्षित माना जाता है, फिर भी सिस्टम और उसमें मौजूद डेटा की सुरक्षा के लिए इसे उचित रूप से मजबूत करना आवश्यक है। इस लेख में Linux सिस्टम को सुरक्षित रखने के लिए कुछ सामान्य उपाय और उनसे बचने वाली गलतियाँ बताई गई हैं।

क्या करें: #

सिस्टम को अपडेट रखें #

अपने Linux सिस्टम को अपडेट रखना उसकी सुरक्षा बनाए रखने के लिए ज़रूरी है। नियमित अपडेट सुरक्षा कमज़ोरियों और बग को ठीक करते हैं, जिससे सिस्टम संभावित हमलों से सुरक्षित रहता है। apt-get या yum पैकेज मैनेजर से Linux सिस्टम अपडेट करने के कुछ उदाहरण:

apt-get से Ubuntu अपडेट करना #

apt-get से Ubuntu सिस्टम अपडेट करने के लिए टर्मिनल खोलें और लिखें:

sudo apt-get update

इससे Ubuntu पैकेज रिपॉज़िटरी से नवीनतम पैकेज सूचियाँ डाउनलोड होंगी। कमांड पूरा होने पर उपलब्ध अपडेट इंस्टॉल करने के लिए यह कमांड चलाएँ:

sudo apt-get upgrade

इससे आपके सिस्टम के उपलब्ध अपडेट डाउनलोड और इंस्टॉल होंगे।

yum से CentOS अपडेट करना #

yum से CentOS सिस्टम अपडेट करने के लिए टर्मिनल खोलें और लिखें:

sudo yum update

इससे उपलब्ध अपडेट डाउनलोड और इंस्टॉल होंगे। पुराने या अप्रयुक्त पैकेज हटाने के लिए यह कमांड भी चला सकते हैं:

sudo yum autoremove

इससे सिस्टम में अब आवश्यक न रहने वाले पैकेज हट जाएँगे।

Linux सिस्टम की सुरक्षा और स्थिरता बनाए रखने के लिए नियमित रूप से अपडेट जाँचें और इंस्टॉल करें।

फ़ायरवॉल का उपयोग करें #

फ़ायरवॉल हर Linux सिस्टम के लिए एक आवश्यक सुरक्षा उपाय है, जो अनधिकृत पहुँच और अन्य साइबर खतरों से बचाता है। Linux पर ufw फ़ायरवॉल का उपयोग इस तरह करें:

Ubuntu आधारित सिस्टम पर ufw इंस्टॉल और सक्षम करना #

ufw इंस्टॉल और सक्षम करने के लिए टर्मिनल खोलें और लिखें:

sudo apt install ufw -y
sudo ufw allow ssh
sudo ufw enable

आने वाले HTTP ट्रैफ़िक (पोर्ट 80) की अनुमति देने के लिए:

sudo ufw allow http

किसी खास IP पते से आने वाला ट्रैफ़िक रोकने के लिए:

sudo ufw deny from <ip_address>

कोई नियम हटाने के लिए:

sudo ufw delete <rule_number>

मौजूदा ufw नियम देखने के लिए लिखें:

sudo ufw status

इससे मौजूदा नियम और उनकी स्थिति दिखाई देगी।

संभावित खतरों से सिस्टम को सुरक्षित रखने के लिए ufw नियमों की नियमित समीक्षा और अद्यतन करें।

CentOS आधारित सिस्टम पर firewalld इंस्टॉल और सक्षम करना #

CentOS के डिफ़ॉल्ट फ़ायरवॉल firewalld को इंस्टॉल और सक्षम करने के लिए ये कमांड चलाएँ:

sudo yum install firewalld
sudo systemctl enable firewalld
sudo systemctl start firewalld

इससे firewalld इंस्टॉल होकर सिस्टम पर सक्षम हो जाएगा।

CentOS आधारित सिस्टम पर firewalld नियम कॉन्फ़िगर करना #

firewalld सक्षम होने के बाद, आने-जाने वाले ट्रैफ़िक को अनुमति देने या रोकने के लिए नियम कॉन्फ़िगर कर सकते हैं। कुछ उदाहरण:

आने वाले SSH ट्रैफ़िक (पोर्ट 22) की अनुमति देने के लिए:

sudo firewall-cmd --permanent --add-service=ssh
sudo firewall-cmd --reload

आने वाले HTTP ट्रैफ़िक (पोर्ट 80) की अनुमति देने के लिए:

sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --reload

किसी खास IP पते से आने वाला ट्रैफ़िक रोकने के लिए:

sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="<ip_address>" reject'
sudo firewall-cmd --reload

कोई नियम हटाने के लिए:

sudo firewall-cmd --permanent --remove-<type>=<rule>
sudo firewall-cmd --reload

मौजूदा firewalld नियम देखने के लिए लिखें:

sudo firewall-cmd --list-all

इससे मौजूदा नियम और उनकी स्थिति दिखाई देगी।

सिस्टम सुरक्षित रहे, इसके लिए firewalld नियमों की नियमित समीक्षा और अद्यतन करें

SELinux या AppArmor सक्षम करें #

SELinux (Security-Enhanced Linux) और AppArmor दो सुरक्षा मॉड्यूल हैं, जिनसे Linux सिस्टम में अनिवार्य एक्सेस नियंत्रण नीतियाँ लागू की जा सकती हैं। अधिकांश आधुनिक Linux वितरणों में इनमें से एक या दोनों मौजूद होते हैं। सिस्टम की सुरक्षा बढ़ाने के लिए इन्हें सक्षम और कॉन्फ़िगर किया जा सकता है।

CentOS आधारित सिस्टम पर SELinux सक्षम करना #

सिस्टम पर SELinux सक्षम है या नहीं, यह जाँचने के लिए यह कमांड चलाएँ:

sestatus

यदि SELinux इंस्टॉल नहीं है, तो इसे इस कमांड से इंस्टॉल कर सकते हैं:

sudo yum install selinux-policy selinux-policy-targeted

SELinux सक्षम करने के लिए /etc/selinux/config फ़ाइल संपादित करें और SELINUX वेरिएबल का मान enforcing रखें:

sudo nano /etc/selinux/config

SELINUX=enforcing बदलें

SELINUX=enforcing

फ़ाइल सहेजें और CTRL+X, फिर Y और Enter दबाकर बाहर निकलें। इसके बाद सिस्टम रीबूट करें।

Ubuntu आधारित सिस्टम पर AppArmor सक्षम करना #

AppArmor सक्षम है या नहीं जाँचने के लिए यह कमांड चलाएँ:

sudo apparmor_status

यदि AppArmor इंस्टॉल नहीं है, तो इसे इस कमांड से इंस्टॉल कर सकते हैं:

sudo apt-get install apparmor

AppArmor सक्षम करने के लिए /etc/default/grub फ़ाइल संपादित करें और GRUB_CMDLINE_LINUX वेरिएबल में security=apparmor पैरामीटर जोड़ें:

sudo nano /etc/default/grub

security=apparmor जोड़ें

GRUB_CMDLINE_LINUX="... security=apparmor"

फ़ाइल सहेजें और CTRL+X, फिर Y और Enter दबाकर बाहर निकलें। फिर बूटलोडर कॉन्फ़िगरेशन अपडेट करने के लिए यह कमांड चलाएँ:

sudo update-grub

अंत में, सिस्टम रीबूट करें।

SELinux या AppArmor सक्षम होने के बाद, प्रक्रियाओं के विशेषाधिकार सीमित करने और सिस्टम संसाधनों तक उनकी पहुँच नियंत्रित करने के लिए नीतियाँ कॉन्फ़िगर कर सकते हैं। इससे सफल हमले का संभावित असर घटता है और समग्र सुरक्षा बेहतर होती है।

पासवर्ड नीतियाँ कॉन्फ़िगर करें #

Linux सुरक्षा को मजबूत बनाने के लिए पासवर्ड नीतियाँ कॉन्फ़िगर करना ज़रूरी है। मज़बूत पासवर्ड की शर्तें लागू करके उपयोगकर्ता खातों को संभावित हमलों से सुरक्षित रखा जा सकता है। Linux पर पासवर्ड नीतियाँ इस तरह कॉन्फ़िगर करें:

Ubuntu पर पासवर्ड नीतियाँ कॉन्फ़िगर करना #

Ubuntu में पासवर्ड नीतियाँ लागू करने के लिए pam_pwquality मॉड्यूल उपयोग कर सकते हैं। यह पासवर्ड की मज़बूती जाँचने के नियम देता है। इसे इंस्टॉल करने के लिए टर्मिनल खोलें और लिखें:

sudo apt-get install libpam-pwquality

pam_pwquality मॉड्यूल इंस्टॉल होने के बाद, सेटिंग बदलने के लिए /etc/pam.d/common-password फ़ाइल संपादित करें। उदाहरण के लिए, कम से कम 8 अक्षर और एक बड़ा अक्षर, एक छोटा अक्षर, एक अंक तथा एक विशेष चिह्न अनिवार्य करने के लिए यह पंक्ति जोड़ें:

password requisite pam_pwquality.so minlen=8 ucredit=-1 lcredit=-1 dcredit=-1 ocredit=-1

फ़ाइल में पंक्तियाँ जोड़कर अधिकतम पासवर्ड आयु जैसी अन्य सेटिंग भी कॉन्फ़िगर कर सकते हैं।

CentOS पर पासवर्ड नीतियाँ कॉन्फ़िगर करना #

CentOS पर पासवर्ड नीतियाँ सेट करने के लिए authconfig टूल उपयोग कर सकते हैं। इसमें नीति कॉन्फ़िगरेशन के कई विकल्प हैं। कम से कम 8 अक्षर और एक बड़ा अक्षर, एक छोटा अक्षर, एक अंक तथा एक विशेष चिह्न अनिवार्य करने के लिए यह कमांड चलाएँ:

sudo authconfig --passalgo=sha512 --update --enablereqlower --enablerequpper --enablereqdigit --enablereqother --passminlen=8

यह निर्दिष्ट पासवर्ड नीतियाँ लागू करने के लिए सिस्टम की /etc/pam.d/system-auth और /etc/pam.d/password-auth फ़ाइलें अपडेट करेगा।

संभावित हमलों के विरुद्ध प्रभावी बनाए रखने के लिए पासवर्ड नीतियों की नियमित समीक्षा और अद्यतन करें।

सिस्टम लॉग पर नज़र रखें #

Linux सुरक्षा बनाए रखने के लिए सिस्टम लॉग की निगरानी ज़रूरी है। लॉग सिस्टम गतिविधियाँ दर्ज करते हैं, जैसे विफल लॉगिन प्रयास, त्रुटियाँ और अन्य महत्वपूर्ण घटनाएँ। उनसे संभावित सुरक्षा खतरों या ध्यान माँगने वाली समस्याओं के बारे में उपयोगी जानकारी मिल सकती है। लॉग की निगरानी इस तरह करें:

journalctl कमांड का उपयोग #

अधिकांश आधुनिक Linux वितरणों में सिस्टम लॉग देखने के लिए journalctl कमांड उपलब्ध है। इसमें लॉग प्रविष्टियाँ फ़िल्टर और खोजने के कई विकल्प हैं।

सभी लॉग प्रविष्टियाँ देखने के लिए यह कमांड चलाएँ:

sudo journalctl

इससे सभी लॉग प्रविष्टियाँ दिखाई देंगी, सबसे नई प्रविष्टियाँ सबसे नीचे होंगी।

किसी खास यूनिट, जैसे सेवा या प्रक्रिया, के लॉग फ़िल्टर करने के लिए -u विकल्प के बाद यूनिट का नाम दें। उदाहरण के लिए, sshd सेवा के लॉग देखने के लिए यह कमांड चलाएँ:

sudo journalctl -u sshd

समय-सीमा के अनुसार लॉग फ़िल्टर करने के लिए टाइमस्टैम्प या अवधि के साथ –since और –until विकल्प उपयोग करें। पिछले घंटे के लॉग देखने के लिए यह कमांड चलाएँ:

sudo journalctl --since "1 hour ago"

लॉग प्रबंधन टूल का उपयोग #

बड़े या जटिल सिस्टम में लॉग इकट्ठा और विश्लेषित करने के लिए लॉग प्रबंधन टूल उपयोगी हो सकता है। इसमें वास्तविक समय निगरानी, लॉग एकत्र करना और विश्लेषण जैसी सुविधाएँ होती हैं, जो संभावित सुरक्षा खतरों को जल्दी पहचानने और उनसे निपटने में मदद करती हैं।

Linux के लॉग प्रबंधन टूल के उदाहरण:

  • Logwatch: सरल लॉग विश्लेषण टूल, जो रोज़ सिस्टम लॉग का सारांश ईमेल करता है
  • Logrotate: डिस्क स्थान बचाने के लिए लॉग फ़ाइलों को अपने आप घुमाता और संकुचित करता है
  • ELK स्टैक: लोकप्रिय ओपन-सोर्स लॉग प्रबंधन टूल, जो वास्तविक समय लॉग निगरानी और विश्लेषण के लिए Elasticsearch, Logstash और Kibana को जोड़ता है

संभावित सुरक्षा खतरों का समय पर पता लगाने और जवाब देने के लिए सिस्टम लॉग की नियमित समीक्षा और विश्लेषण करें।

क्या न करें: #

कमज़ोर पासवर्ड न रखें #

कमज़ोर पासवर्ड एक आम गलती है, जो Linux सिस्टम को हमलों के प्रति असुरक्षित बना सकती है। हमलावर आम शब्दों, नामों या तारीखों पर आधारित पासवर्ड का अनुमान लगाने वाले टूल उपयोग कर सकते हैं। मज़बूत और अलग-अलग पासवर्ड रखें, जिनका अनुमान लगाना आसान न हो।

बड़े और छोटे अक्षर, अंक तथा विशेष चिह्न मिलाकर मज़बूत पासवर्ड बनाएँ। जटिल पासवर्ड सुरक्षित रूप से बनाने और रखने के लिए पासवर्ड मैनेजर का उपयोग करें। पासवर्ड मैनेजर पासवर्ड याद रखने और कई खातों में एक ही पासवर्ड दोहराने से बचने में भी मदद करते हैं।

root खाते को SSH पहुँच न दें #

root खाते को SSH पहुँच देना सुरक्षा जोखिम है और हमलावरों को Linux सिस्टम पर पूरा नियंत्रण दे सकता है। इसके बजाय, root से अलग उपयोगकर्ता खाते से लॉग इन करें और फिर sudo कमांड से ज़रूरी विशेषाधिकार बढ़ाएँ। उपयोगकर्ता खातों के विशेषाधिकार सीमित रखने से हमले का संभावित असर घटता है।

अनावश्यक सॉफ़्टवेयर इंस्टॉल न करें #

अनावश्यक सॉफ़्टवेयर इंस्टॉल करने से Linux सिस्टम का आक्रमण क्षेत्र बढ़ता है और वह हमलों के प्रति अधिक संवेदनशील होता है। केवल ज़रूरी सॉफ़्टवेयर इंस्टॉल करें और बाकी हटा दें। इससे संभावित कमज़ोरियों और सफल हमले का जोखिम घटता है।

पुराना सॉफ़्टवेयर न चलाएँ #

पुराना सॉफ़्टवेयर ज्ञात कमज़ोरियों का फायदा उठाने वाले हमलों के लिए सिस्टम को असुरक्षित छोड़ सकता है। सुरक्षा के लिए सॉफ़्टवेयर के नवीनतम संस्करण का उपयोग करें और नियमित रूप से अपडेट करें। इससे ज्ञात कमज़ोरियाँ ठीक होती हैं और संभावित हमलों से सुरक्षा मिलती है।

निष्कर्ष #

Linux सिस्टम को मजबूत करना उसकी सुरक्षा और उसमें मौजूद डेटा बचाने के लिए आवश्यक है। इस लेख की सलाह मानकर सिस्टम सुरक्षित करें और साइबर खतरों का जोखिम घटाएँ। सिस्टम अपडेट रखें, फ़ायरवॉल उपयोग करें, पासवर्ड नीतियाँ सेट करें और लॉग देखें। कमज़ोर पासवर्ड, स्वचालित अपडेट बंद करना, root खाते को SSH पहुँच देना, अनावश्यक सॉफ़्टवेयर इंस्टॉल करना और पुराना सॉफ़्टवेयर चलाना टालें। इन सुरक्षा उपायों से आपका Linux सिस्टम सुरक्षित रहेगा।
