Linux ਇੱਕ ਪ੍ਰਸਿੱਧ ਓਪਰੇਟਿੰਗ ਸਿਸਟਮ ਹੈ, ਜਿਸਦੀ ਵਰਤੋਂ ਵਿਅਕਤੀ ਅਤੇ ਕਾਰੋਬਾਰ ਦੋਵੇਂ ਕਰਦੇ ਹਨ। ਓਪਨ-ਸੋਰਸ ਹੋਣ ਕਰਕੇ ਇਸਨੂੰ ਅਕਸਰ ਹੋਰ ਓਪਰੇਟਿੰਗ ਸਿਸਟਮਾਂ ਨਾਲੋਂ ਵੱਧ ਸੁਰੱਖਿਅਤ ਮੰਨਿਆ ਜਾਂਦਾ ਹੈ, ਪਰ ਸਿਸਟਮ ਅਤੇ ਇਸਦੇ ਡੇਟੇ ਦੀ ਰੱਖਿਆ ਲਈ ਇਸਦੀ ਢੰਗ ਨਾਲ ਸੁਰੱਖਿਆ ਮਜ਼ਬੂਤ ਕਰਨੀ ਲੋੜੀਂਦੀ ਹੈ। ਇਸ ਲੇਖ ਵਿੱਚ Linux ਸਿਸਟਮ ਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖਣ ਲਈ ਕੁਝ ਆਮ ਕਰਨਯੋਗ ਅਤੇ ਨਾ ਕਰਨਯੋਗ ਗੱਲਾਂ ਦਿੱਤੀਆਂ ਹਨ।

ਕੀ ਕਰਨਾ ਹੈ: #

ਸਿਸਟਮ ਅੱਪਡੇਟ ਰੱਖੋ #

ਆਪਣੇ Linux ਸਿਸਟਮ ਨੂੰ ਅੱਪ-ਟੂ-ਡੇਟ ਰੱਖਣਾ ਇਸਦੀ ਸੁਰੱਖਿਆ ਲਈ ਬਹੁਤ ਜ਼ਰੂਰੀ ਹੈ। ਨਿਯਮਤ ਅੱਪਡੇਟ ਸੁਰੱਖਿਆ ਕਮਜ਼ੋਰੀਆਂ ਅਤੇ ਤਰੁੱਟੀਆਂ ਠੀਕ ਕਰਦੇ ਹਨ ਅਤੇ ਸੰਭਾਵੀ ਹਮਲਿਆਂ ਤੋਂ ਸਿਸਟਮ ਦੀ ਰੱਖਿਆ ਕਰਦੇ ਹਨ। apt-get ਜਾਂ yum ਪੈਕੇਜ ਮੈਨੇਜਰ ਨਾਲ Linux ਸਿਸਟਮ ਅੱਪਡੇਟ ਕਰਨ ਦੀਆਂ ਕੁਝ ਉਦਾਹਰਨਾਂ:

apt-get ਨਾਲ Ubuntu ਅੱਪਡੇਟ ਕਰਨਾ #

apt-get ਨਾਲ Ubuntu ਸਿਸਟਮ ਅੱਪਡੇਟ ਕਰਨ ਲਈ ਟਰਮੀਨਲ ਖੋਲ੍ਹੋ ਅਤੇ ਲਿਖੋ:

sudo apt-get update

ਇਸ ਨਾਲ Ubuntu ਪੈਕੇਜ ਰਿਪੋਜ਼ਟਰੀਆਂ ਤੋਂ ਨਵੀਆਂ ਪੈਕੇਜ ਸੂਚੀਆਂ ਡਾਊਨਲੋਡ ਹੋਣਗੀਆਂ। ਇਹ ਕਮਾਂਡ ਪੂਰੀ ਹੋਣ ਤੋਂ ਬਾਅਦ ਉਪਲਬਧ ਅੱਪਡੇਟ ਇੰਸਟਾਲ ਕਰਨ ਲਈ ਅਗਲੀ ਕਮਾਂਡ ਚਲਾਓ:

sudo apt-get upgrade

ਇਸ ਨਾਲ ਸਿਸਟਮ ਲਈ ਉਪਲਬਧ ਅੱਪਡੇਟ ਡਾਊਨਲੋਡ ਅਤੇ ਇੰਸਟਾਲ ਹੋਣਗੇ।

yum ਨਾਲ CentOS ਅੱਪਡੇਟ ਕਰਨਾ #

yum ਨਾਲ CentOS ਸਿਸਟਮ ਅੱਪਡੇਟ ਕਰਨ ਲਈ ਟਰਮੀਨਲ ਖੋਲ੍ਹੋ ਅਤੇ ਲਿਖੋ:

sudo yum update

ਇਸ ਨਾਲ ਉਪਲਬਧ ਅੱਪਡੇਟ ਡਾਊਨਲੋਡ ਅਤੇ ਇੰਸਟਾਲ ਹੋਣਗੇ। ਪੁਰਾਣੇ ਜਾਂ ਬੇਲੋੜੇ ਪੈਕੇਜ ਹਟਾਉਣ ਲਈ ਇਹ ਕਮਾਂਡ ਵੀ ਵਰਤ ਸਕਦੇ ਹੋ:

sudo yum autoremove

ਇਸ ਨਾਲ ਸਿਸਟਮ ਵਿੱਚ ਹੁਣ ਲੋੜੀਂਦੇ ਨਾ ਰਹੇ ਪੈਕੇਜ ਹਟ ਜਾਣਗੇ।

Linux ਸਿਸਟਮ ਦੀ ਸੁਰੱਖਿਆ ਅਤੇ ਸਥਿਰਤਾ ਲਈ ਨਿਯਮਤ ਤੌਰ ਤੇ ਅੱਪਡੇਟ ਜਾਂਚੋ ਅਤੇ ਇੰਸਟਾਲ ਕਰੋ।

ਫਾਇਰਵਾਲ ਵਰਤੋ #

ਹਰ Linux ਸਿਸਟਮ ਲਈ ਫਾਇਰਵਾਲ ਇੱਕ ਜ਼ਰੂਰੀ ਸੁਰੱਖਿਆ ਉਪਾਅ ਹੈ, ਕਿਉਂਕਿ ਇਹ ਬਿਨਾਂ ਅਧਿਕਾਰ ਪਹੁੰਚ ਅਤੇ ਹੋਰ ਸਾਈਬਰ ਖਤਰਿਆਂ ਤੋਂ ਬਚਾਉਂਦੀ ਹੈ। Linux ਸਿਸਟਮ ਉੱਤੇ ufw ਫਾਇਰਵਾਲ ਇਸ ਤਰ੍ਹਾਂ ਵਰਤੋ:

Ubuntu-ਆਧਾਰਿਤ ਸਿਸਟਮਾਂ ਉੱਤੇ ufw ਇੰਸਟਾਲ ਅਤੇ ਚਾਲੂ ਕਰਨਾ #

ufw ਇੰਸਟਾਲ ਅਤੇ ਚਾਲੂ ਕਰਨ ਲਈ ਟਰਮੀਨਲ ਖੋਲ੍ਹੋ ਅਤੇ ਲਿਖੋ:

sudo apt install ufw -y
sudo ufw allow ssh
sudo ufw enable

ਆਉਣ ਵਾਲੇ HTTP ਟ੍ਰੈਫਿਕ (ਪੋਰਟ 80) ਦੀ ਇਜਾਜ਼ਤ ਦੇਣ ਲਈ:

sudo ufw allow http

ਕਿਸੇ ਖਾਸ IP ਪਤੇ ਤੋਂ ਆਉਂਦਾ ਟ੍ਰੈਫਿਕ ਰੋਕਣ ਲਈ:

sudo ufw deny from <ip_address>

ਕੋਈ ਨਿਯਮ ਮਿਟਾਉਣ ਲਈ:

sudo ufw delete <rule_number>

ਮੌਜੂਦਾ ufw ਨਿਯਮ ਦੇਖਣ ਲਈ ਲਿਖੋ:

sudo ufw status

ਇਸ ਨਾਲ ਮੌਜੂਦਾ ਨਿਯਮ ਅਤੇ ਉਨ੍ਹਾਂ ਦੀ ਸਥਿਤੀ ਦਿਖਾਈ ਦੇਵੇਗੀ।

ਸੰਭਾਵੀ ਖਤਰਿਆਂ ਤੋਂ ਸਿਸਟਮ ਦੀ ਰੱਖਿਆ ਲਈ ufw ਨਿਯਮਾਂ ਦੀ ਨਿਯਮਤ ਸਮੀਖਿਆ ਅਤੇ ਅੱਪਡੇਟ ਕਰੋ।

CentOS-ਆਧਾਰਿਤ ਸਿਸਟਮਾਂ ਉੱਤੇ firewalld ਇੰਸਟਾਲ ਅਤੇ ਚਾਲੂ ਕਰਨਾ #

CentOS ਦੀ ਮੂਲ ਫਾਇਰਵਾਲ firewalld ਨੂੰ ਇੰਸਟਾਲ ਅਤੇ ਚਾਲੂ ਕਰਨ ਲਈ ਇਹ ਕਮਾਂਡਾਂ ਵਰਤੋ:

sudo yum install firewalld
sudo systemctl enable firewalld
sudo systemctl start firewalld

ਇਸ ਨਾਲ firewalld ਇੰਸਟਾਲ ਹੋਵੇਗਾ ਅਤੇ ਸਿਸਟਮ ਉੱਤੇ ਚਾਲੂ ਹੋ ਜਾਵੇਗਾ।

CentOS-ਆਧਾਰਿਤ ਸਿਸਟਮਾਂ ਉੱਤੇ firewalld ਨਿਯਮ ਕੌਂਫਿਗਰ ਕਰਨਾ #

firewalld ਚਾਲੂ ਹੋਣ ਤੋਂ ਬਾਅਦ ਆਉਣ-ਜਾਣ ਵਾਲੇ ਟ੍ਰੈਫਿਕ ਨੂੰ ਮਨਜ਼ੂਰ ਜਾਂ ਰੋਕਣ ਲਈ ਇਸਦੇ ਨਿਯਮ ਕੌਂਫਿਗਰ ਕਰ ਸਕਦੇ ਹੋ। ਕੁਝ ਉਦਾਹਰਨਾਂ:

ਆਉਣ ਵਾਲੇ SSH ਟ੍ਰੈਫਿਕ (ਪੋਰਟ 22) ਦੀ ਇਜਾਜ਼ਤ ਦੇਣ ਲਈ:

sudo firewall-cmd --permanent --add-service=ssh
sudo firewall-cmd --reload

ਆਉਣ ਵਾਲੇ HTTP ਟ੍ਰੈਫਿਕ (ਪੋਰਟ 80) ਦੀ ਇਜਾਜ਼ਤ ਦੇਣ ਲਈ:

sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --reload

ਕਿਸੇ ਖਾਸ IP ਪਤੇ ਤੋਂ ਆਉਂਦਾ ਟ੍ਰੈਫਿਕ ਰੋਕਣ ਲਈ:

sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="<ip_address>" reject'
sudo firewall-cmd --reload

ਕੋਈ ਨਿਯਮ ਮਿਟਾਉਣ ਲਈ:

sudo firewall-cmd --permanent --remove-<type>=<rule>
sudo firewall-cmd --reload

ਮੌਜੂਦਾ firewalld ਨਿਯਮ ਦੇਖਣ ਲਈ ਲਿਖੋ:

sudo firewall-cmd --list-all

ਇਸ ਨਾਲ ਮੌਜੂਦਾ ਨਿਯਮ ਅਤੇ ਉਨ੍ਹਾਂ ਦੀ ਸਥਿਤੀ ਦਿਖਾਈ ਦੇਵੇਗੀ।

ਸਿਸਟਮ ਦੀ ਸੁਰੱਖਿਆ ਯਕੀਨੀ ਬਣਾਉਣ ਲਈ firewalld ਨਿਯਮਾਂ ਦੀ ਨਿਯਮਤ ਸਮੀਖਿਆ ਅਤੇ ਅੱਪਡੇਟ ਕਰੋ

SELinux ਜਾਂ AppArmor ਚਾਲੂ ਕਰੋ #

SELinux (Security-Enhanced Linux) ਅਤੇ AppArmor ਦੋ ਸੁਰੱਖਿਆ ਮੋਡੀਊਲ ਹਨ ਜੋ Linux ਸਿਸਟਮਾਂ ਉੱਤੇ ਲਾਜ਼ਮੀ ਪਹੁੰਚ-ਨਿਯੰਤਰਣ ਨੀਤੀਆਂ ਲਾਗੂ ਕਰਦੇ ਹਨ। ਜ਼ਿਆਦਾਤਰ ਆਧੁਨਿਕ Linux ਡਿਸਟ੍ਰਿਬਿਊਸ਼ਨਾਂ ਵਿੱਚ SELinux ਜਾਂ AppArmor ਮੌਜੂਦ ਹੁੰਦਾ ਹੈ। ਸਿਸਟਮ ਦੀ ਸੁਰੱਖਿਆ ਵਧਾਉਣ ਲਈ ਇਨ੍ਹਾਂ ਨੂੰ ਚਾਲੂ ਅਤੇ ਕੌਂਫਿਗਰ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ।

CentOS-ਆਧਾਰਿਤ ਸਿਸਟਮਾਂ ਉੱਤੇ SELinux ਚਾਲੂ ਕਰਨਾ #

SELinux ਚਾਲੂ ਹੈ ਜਾਂ ਨਹੀਂ, ਇਹ ਜਾਂਚਣ ਲਈ ਇਹ ਕਮਾਂਡ ਚਲਾਓ:

sestatus

ਜੇ SELinux ਇੰਸਟਾਲ ਨਹੀਂ ਹੈ, ਤਾਂ ਇਸ ਕਮਾਂਡ ਨਾਲ ਇੰਸਟਾਲ ਕਰ ਸਕਦੇ ਹੋ:

sudo yum install selinux-policy selinux-policy-targeted

SELinux ਚਾਲੂ ਕਰਨ ਲਈ /etc/selinux/config ਫਾਈਲ ਸੋਧੋ ਅਤੇ SELINUX ਵੇਰੀਏਬਲ ਨੂੰ enforcing ਤੇ ਸੈੱਟ ਕਰੋ:

sudo nano /etc/selinux/config

SELINUX=enforcing ਬਦਲੋ

SELINUX=enforcing

ਫਾਈਲ ਸੰਭਾਲ ਕੇ ਬਾਹਰ ਨਿਕਲਣ ਲਈ CTRL+X, ਫਿਰ Y ਅਤੇ Enter ਦਬਾਓ, ਫਿਰ ਸਿਸਟਮ ਰੀਬੂਟ ਕਰੋ।

Ubuntu-ਆਧਾਰਿਤ ਸਿਸਟਮਾਂ ਉੱਤੇ AppArmor ਚਾਲੂ ਕਰਨਾ #

AppArmor ਚਾਲੂ ਹੈ ਜਾਂ ਨਹੀਂ, ਇਹ ਜਾਂਚਣ ਲਈ ਇਹ ਕਮਾਂਡ ਚਲਾਓ:

sudo apparmor_status

ਜੇ AppArmor ਇੰਸਟਾਲ ਨਹੀਂ ਹੈ, ਤਾਂ ਇਸ ਕਮਾਂਡ ਨਾਲ ਇੰਸਟਾਲ ਕਰ ਸਕਦੇ ਹੋ:

sudo apt-get install apparmor

AppArmor ਚਾਲੂ ਕਰਨ ਲਈ /etc/default/grub ਫਾਈਲ ਸੋਧੋ ਅਤੇ GRUB_CMDLINE_LINUX ਵੇਰੀਏਬਲ ਵਿੱਚ security=apparmor ਪੈਰਾਮੀਟਰ ਜੋੜੋ:

sudo nano /etc/default/grub

security=apparmor ਜੋੜੋ

GRUB_CMDLINE_LINUX="... security=apparmor"

ਫਾਈਲ ਸੰਭਾਲ ਕੇ CTRL+X, ਫਿਰ Y ਅਤੇ Enter ਦਬਾ ਕੇ ਬਾਹਰ ਨਿਕਲੋ। ਇਸ ਤੋਂ ਬਾਅਦ ਬੂਟਲੋਡਰ ਸੰਰਚਨਾ ਅੱਪਡੇਟ ਕਰਨ ਲਈ ਇਹ ਕਮਾਂਡ ਚਲਾਓ:

sudo update-grub

ਅੰਤ ਵਿੱਚ ਸਿਸਟਮ ਰੀਬੂਟ ਕਰੋ।

SELinux ਜਾਂ AppArmor ਚਾਲੂ ਹੋਣ ਮਗਰੋਂ, ਪ੍ਰਕਿਰਿਆਵਾਂ ਦੇ ਵਿਸ਼ੇਸ਼ ਅਧਿਕਾਰ ਸੀਮਿਤ ਕਰਨ ਅਤੇ ਸਿਸਟਮ ਸਰੋਤਾਂ ਤੱਕ ਉਨ੍ਹਾਂ ਦੀ ਪਹੁੰਚ ਸੀਮਿਤ ਕਰਨ ਲਈ ਨੀਤੀਆਂ ਕੌਂਫਿਗਰ ਕਰੋ। ਇਸ ਨਾਲ ਸਫਲ ਹਮਲੇ ਦਾ ਸੰਭਾਵੀ ਅਸਰ ਘਟਦਾ ਹੈ ਅਤੇ ਸਮੁੱਚੀ ਸੁਰੱਖਿਆ ਵਧਦੀ ਹੈ।

ਪਾਸਵਰਡ ਨੀਤੀਆਂ ਕੌਂਫਿਗਰ ਕਰੋ #

Linux ਸਿਸਟਮ ਦੀ ਸੁਰੱਖਿਆ ਮਜ਼ਬੂਤ ਕਰਨ ਲਈ ਪਾਸਵਰਡ ਨੀਤੀਆਂ ਕੌਂਫਿਗਰ ਕਰਨਾ ਮਹੱਤਵਪੂਰਨ ਹੈ। ਮਜ਼ਬੂਤ ਪਾਸਵਰਡ ਦੀਆਂ ਸ਼ਰਤਾਂ ਲਾਗੂ ਕਰਕੇ ਵਰਤੋਂਕਾਰ ਖਾਤਿਆਂ ਨੂੰ ਸੰਭਾਵੀ ਹਮਲਿਆਂ ਤੋਂ ਸੁਰੱਖਿਅਤ ਰੱਖਿਆ ਜਾ ਸਕਦਾ ਹੈ। Linux ਉੱਤੇ ਪਾਸਵਰਡ ਨੀਤੀਆਂ ਕੌਂਫਿਗਰ ਕਰਨ ਦਾ ਤਰੀਕਾ:

Ubuntu ਉੱਤੇ ਪਾਸਵਰਡ ਨੀਤੀਆਂ ਕੌਂਫਿਗਰ ਕਰਨਾ #

Ubuntu ਉੱਤੇ ਪਾਸਵਰਡ ਨੀਤੀਆਂ ਕੌਂਫਿਗਰ ਕਰਨ ਲਈ pam_pwquality ਮੋਡੀਊਲ ਵਰਤਿਆ ਜਾ ਸਕਦਾ ਹੈ। ਇਹ ਪਾਸਵਰਡ ਦੀ ਮਜ਼ਬੂਤੀ ਜਾਂਚਣ ਵਾਲੇ ਨਿਯਮ ਦਿੰਦਾ ਹੈ। pam_pwquality ਇੰਸਟਾਲ ਕਰਨ ਲਈ ਟਰਮੀਨਲ ਖੋਲ੍ਹੋ ਅਤੇ ਲਿਖੋ:

sudo apt-get install libpam-pwquality

ਮੋਡੀਊਲ ਇੰਸਟਾਲ ਹੋਣ ਮਗਰੋਂ, ਸੈਟਿੰਗਾਂ ਬਦਲਣ ਲਈ /etc/pam.d/common-password ਫਾਈਲ ਸੋਧੋ। ਉਦਾਹਰਨ ਲਈ, ਘੱਟੋ-ਘੱਟ 8 ਅੱਖਰ ਅਤੇ ਇੱਕ ਵੱਡਾ ਅੱਖਰ, ਇੱਕ ਛੋਟਾ ਅੱਖਰ, ਇੱਕ ਅੰਕ ਅਤੇ ਇੱਕ ਖਾਸ ਚਿੰਨ੍ਹ ਲਾਜ਼ਮੀ ਕਰਨ ਲਈ ਇਹ ਲਾਈਨ ਜੋੜੋ:

password requisite pam_pwquality.so minlen=8 ucredit=-1 lcredit=-1 dcredit=-1 ocredit=-1

ਵੱਧ ਤੋਂ ਵੱਧ ਪਾਸਵਰਡ ਮਿਆਦ ਵਰਗੀਆਂ ਹੋਰ ਸੈਟਿੰਗਾਂ ਵੀ ਫਾਈਲ ਵਿੱਚ ਲਾਈਨਾਂ ਜੋੜ ਕੇ ਕੌਂਫਿਗਰ ਕੀਤੀਆਂ ਜਾ ਸਕਦੀਆਂ ਹਨ।

CentOS ਉੱਤੇ ਪਾਸਵਰਡ ਨੀਤੀਆਂ ਕੌਂਫਿਗਰ ਕਰਨਾ #

CentOS ਉੱਤੇ ਪਾਸਵਰਡ ਨੀਤੀਆਂ ਕੌਂਫਿਗਰ ਕਰਨ ਲਈ authconfig ਟੂਲ ਵਰਤਿਆ ਜਾ ਸਕਦਾ ਹੈ। ਇਹ ਕਈ ਚੋਣਾਂ ਦਿੰਦਾ ਹੈ। ਘੱਟੋ-ਘੱਟ 8 ਅੱਖਰ ਅਤੇ ਇੱਕ ਵੱਡਾ ਅੱਖਰ, ਇੱਕ ਛੋਟਾ ਅੱਖਰ, ਇੱਕ ਅੰਕ ਅਤੇ ਇੱਕ ਖਾਸ ਚਿੰਨ੍ਹ ਲਾਜ਼ਮੀ ਕਰਨ ਲਈ ਇਹ ਕਮਾਂਡ ਵਰਤੋ:

sudo authconfig --passalgo=sha512 --update --enablereqlower --enablerequpper --enablereqdigit --enablereqother --passminlen=8

ਇਹ ਨਿਰਧਾਰਤ ਪਾਸਵਰਡ ਨੀਤੀਆਂ ਲਾਗੂ ਕਰਨ ਲਈ ਸਿਸਟਮ ਦੀਆਂ /etc/pam.d/system-auth ਅਤੇ /etc/pam.d/password-auth ਫਾਈਲਾਂ ਅੱਪਡੇਟ ਕਰੇਗੀ।

ਸੰਭਾਵੀ ਹਮਲਿਆਂ ਤੋਂ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਸੁਰੱਖਿਆ ਲਈ ਪਾਸਵਰਡ ਨੀਤੀਆਂ ਦੀ ਨਿਯਮਤ ਸਮੀਖਿਆ ਅਤੇ ਅੱਪਡੇਟ ਕਰੋ।

ਸਿਸਟਮ ਲੌਗਾਂ ਦੀ ਨਿਗਰਾਨੀ ਕਰੋ #

Linux ਸਿਸਟਮ ਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖਣ ਲਈ ਸਿਸਟਮ ਲੌਗਾਂ ਦੀ ਨਿਗਰਾਨੀ ਮਹੱਤਵਪੂਰਨ ਹੈ। ਲੌਗ ਸਿਸਟਮ ਦੀਆਂ ਗਤੀਵਿਧੀਆਂ ਦਰਜ ਕਰਦੇ ਹਨ, ਜਿਵੇਂ ਅਸਫਲ ਲੌਗਇਨ ਕੋਸ਼ਿਸ਼ਾਂ, ਤਰੁੱਟੀਆਂ ਅਤੇ ਹੋਰ ਜ਼ਰੂਰੀ ਘਟਨਾਵਾਂ। ਇਹ ਸੰਭਾਵੀ ਸੁਰੱਖਿਆ ਖਤਰਿਆਂ ਜਾਂ ਧਿਆਨ ਮੰਗਣ ਵਾਲੀਆਂ ਸਮੱਸਿਆਵਾਂ ਬਾਰੇ ਲਾਭਦਾਇਕ ਜਾਣਕਾਰੀ ਦਿੰਦੇ ਹਨ। ਲੌਗ ਇਉਂ ਵੇਖੋ:

journalctl ਕਮਾਂਡ ਵਰਤਣਾ #

ਜ਼ਿਆਦਾਤਰ ਆਧੁਨਿਕ Linux ਡਿਸਟ੍ਰਿਬਿਊਸ਼ਨਾਂ ਵਿੱਚ ਸਿਸਟਮ ਲੌਗ ਵੇਖਣ ਲਈ journalctl ਕਮਾਂਡ ਵਰਤੀ ਜਾਂਦੀ ਹੈ। ਇਸ ਵਿੱਚ ਲੌਗ ਐਂਟਰੀਆਂ ਫਿਲਟਰ ਅਤੇ ਖੋਜਣ ਲਈ ਕਈ ਵਿਕਲਪ ਹਨ।

ਸਾਰੀਆਂ ਲੌਗ ਐਂਟਰੀਆਂ ਵੇਖਣ ਲਈ ਇਹ ਕਮਾਂਡ ਚਲਾਓ:

sudo journalctl

ਇਸ ਨਾਲ ਸਾਰੀਆਂ ਲੌਗ ਐਂਟਰੀਆਂ ਦਿਖਣਗੀਆਂ ਅਤੇ ਸਭ ਤੋਂ ਨਵੀਆਂ ਐਂਟਰੀਆਂ ਹੇਠਾਂ ਹੋਣਗੀਆਂ।

ਕਿਸੇ ਖਾਸ ਯੂਨਿਟ, ਜਿਵੇਂ ਸੇਵਾ ਜਾਂ ਪ੍ਰਕਿਰਿਆ, ਦੀਆਂ ਲੌਗ ਐਂਟਰੀਆਂ ਫਿਲਟਰ ਕਰਨ ਲਈ ਯੂਨਿਟ ਦੇ ਨਾਂ ਮਗਰੋਂ -u ਵਿਕਲਪ ਵਰਤੋ। ਉਦਾਹਰਨ ਲਈ, sshd ਸੇਵਾ ਦੀਆਂ ਐਂਟਰੀਆਂ ਵੇਖਣ ਲਈ ਇਹ ਕਮਾਂਡ ਚਲਾਓ:

sudo journalctl -u sshd

ਸਮੇਂ ਦੀ ਹੱਦ ਅਨੁਸਾਰ ਐਂਟਰੀਆਂ ਫਿਲਟਰ ਕਰਨ ਲਈ ਸਮੇਂ ਦੇ ਨਿਸ਼ਾਨ ਜਾਂ ਮਿਆਦ ਨਾਲ –since ਅਤੇ –until ਵਿਕਲਪ ਵਰਤੋ। ਪਿਛਲੇ ਘੰਟੇ ਦੀਆਂ ਲੌਗ ਐਂਟਰੀਆਂ ਵੇਖਣ ਲਈ ਇਹ ਕਮਾਂਡ ਚਲਾਓ:

sudo journalctl --since "1 hour ago"

ਲੌਗ ਪ੍ਰਬੰਧਨ ਟੂਲ ਵਰਤਣਾ #

ਵੱਡੇ ਜਾਂ ਜਟਿਲ ਸਿਸਟਮਾਂ ਵਿੱਚ ਲੌਗ ਇਕੱਠੇ ਕਰਨ ਅਤੇ ਵਿਸ਼ਲੇਸ਼ਣ ਲਈ ਲੌਗ ਪ੍ਰਬੰਧਨ ਟੂਲ ਲਾਭਦਾਇਕ ਹੋ ਸਕਦਾ ਹੈ। ਇਹ ਅਸਲ-ਸਮੇਂ ਦੀ ਨਿਗਰਾਨੀ, ਲੌਗ ਇਕੱਠੇ ਕਰਨਾ ਅਤੇ ਵਿਸ਼ਲੇਸ਼ਣ ਵਰਗੀਆਂ ਸੁਵਿਧਾਵਾਂ ਦਿੰਦੇ ਹਨ ਅਤੇ ਸੰਭਾਵੀ ਸੁਰੱਖਿਆ ਖਤਰਿਆਂ ਨੂੰ ਜਲਦੀ ਪਛਾਣਨ ਅਤੇ ਜਵਾਬ ਦੇਣ ਵਿੱਚ ਮਦਦ ਕਰਦੇ ਹਨ।

Linux ਲਈ ਲੌਗ ਪ੍ਰਬੰਧਨ ਟੂਲਾਂ ਦੀਆਂ ਉਦਾਹਰਨਾਂ:

  • Logwatch: ਸਧਾਰਨ ਲੌਗ ਵਿਸ਼ਲੇਸ਼ਣ ਟੂਲ, ਜੋ ਹਰ ਰੋਜ਼ ਈਮੇਲ ਰਾਹੀਂ ਸਿਸਟਮ ਲੌਗਾਂ ਦਾ ਸਾਰ ਭੇਜਦਾ ਹੈ
  • Logrotate: ਡਿਸਕ ਥਾਂ ਬਚਾਉਣ ਲਈ ਲੌਗ ਫਾਈਲਾਂ ਨੂੰ ਆਪਣੇ ਆਪ ਘੁਮਾਉਂਦਾ ਅਤੇ ਸੰਕੁਚਿਤ ਕਰਦਾ ਹੈ
  • ELK ਸਟੈਕ: ਪ੍ਰਸਿੱਧ ਓਪਨ-ਸੋਰਸ ਲੌਗ ਪ੍ਰਬੰਧਨ ਟੂਲ, ਜੋ ਅਸਲ ਸਮੇਂ ਦੀ ਨਿਗਰਾਨੀ ਅਤੇ ਵਿਸ਼ਲੇਸ਼ਣ ਲਈ Elasticsearch, Logstash ਅਤੇ Kibana ਨੂੰ ਜੋੜਦਾ ਹੈ

ਸੰਭਾਵੀ ਸੁਰੱਖਿਆ ਖਤਰਿਆਂ ਨੂੰ ਸਮੇਂ ਸਿਰ ਪਛਾਣਨ ਅਤੇ ਜਵਾਬ ਦੇਣ ਲਈ ਸਿਸਟਮ ਲੌਗਾਂ ਦੀ ਨਿਯਮਤ ਸਮੀਖਿਆ ਅਤੇ ਵਿਸ਼ਲੇਸ਼ਣ ਕਰੋ।

ਕੀ ਨਹੀਂ ਕਰਨਾ: #

ਕਮਜ਼ੋਰ ਪਾਸਵਰਡ ਨਾ ਵਰਤੋ #

ਕਮਜ਼ੋਰ ਪਾਸਵਰਡ ਵਰਤਣਾ ਆਮ ਗਲਤੀ ਹੈ, ਜਿਸ ਨਾਲ Linux ਸਿਸਟਮ ਹਮਲਿਆਂ ਲਈ ਕਮਜ਼ੋਰ ਹੋ ਸਕਦਾ ਹੈ। ਹਮਲਾਵਰ ਆਮ ਸ਼ਬਦਾਂ, ਨਾਵਾਂ ਜਾਂ ਤਾਰੀਖਾਂ ਦੇ ਆਧਾਰ ਤੇ ਪਾਸਵਰਡ ਅਨੁਮਾਨਣ ਵਾਲੇ ਟੂਲ ਵਰਤ ਸਕਦੇ ਹਨ। ਮਜ਼ਬੂਤ ਅਤੇ ਵਿਲੱਖਣ ਪਾਸਵਰਡ ਚੁਣੋ ਜਿਨ੍ਹਾਂ ਦਾ ਅਨੁਮਾਨ ਲਗਾਉਣਾ ਸੌਖਾ ਨਾ ਹੋਵੇ।

ਵੱਡੇ ਅਤੇ ਛੋਟੇ ਅੱਖਰਾਂ, ਅੰਕਾਂ ਅਤੇ ਖਾਸ ਚਿੰਨ੍ਹਾਂ ਦੇ ਜੋੜ ਨਾਲ ਮਜ਼ਬੂਤ ਪਾਸਵਰਡ ਬਣਾਓ। ਜਟਿਲ ਪਾਸਵਰਡ ਸੁਰੱਖਿਅਤ ਤਰੀਕੇ ਨਾਲ ਬਣਾਉਣ ਅਤੇ ਸੰਭਾਲਣ ਲਈ ਪਾਸਵਰਡ ਮੈਨੇਜਰ ਵਰਤਣਾ ਵੀ ਚੰਗਾ ਤਰੀਕਾ ਹੈ। ਪਾਸਵਰਡ ਮੈਨੇਜਰ ਪਾਸਵਰਡ ਯਾਦ ਰੱਖਣ ਅਤੇ ਕਈ ਖਾਤਿਆਂ ਲਈ ਇੱਕੋ ਪਾਸਵਰਡ ਵਰਤਣ ਤੋਂ ਬਚਣ ਵਿੱਚ ਵੀ ਮਦਦ ਕਰਦੇ ਹਨ।

root ਖਾਤੇ ਨੂੰ SSH ਪਹੁੰਚ ਨਾ ਦਿਓ #

root ਖਾਤੇ ਨੂੰ SSH ਪਹੁੰਚ ਦੇਣਾ ਸੁਰੱਖਿਆ ਖਤਰਾ ਹੈ, ਜਿਸ ਨਾਲ ਹਮਲਾਵਰ Linux ਸਿਸਟਮ ਦਾ ਪੂਰਾ ਕੰਟਰੋਲ ਲੈ ਸਕਦੇ ਹਨ। ਇਸ ਦੀ ਥਾਂ root ਤੋਂ ਇਲਾਵਾ ਵਰਤੋਂਕਾਰ ਖਾਤੇ ਨਾਲ ਲੌਗਇਨ ਕਰੋ ਅਤੇ ਫਿਰ sudo ਕਮਾਂਡ ਰਾਹੀਂ ਵਿਸ਼ੇਸ਼ ਅਧਿਕਾਰ ਵਧਾਓ। ਵਰਤੋਂਕਾਰ ਖਾਤਿਆਂ ਦੇ ਅਧਿਕਾਰ ਸੀਮਿਤ ਕਰਨ ਨਾਲ ਹਮਲੇ ਦਾ ਸੰਭਾਵੀ ਅਸਰ ਘਟਦਾ ਹੈ।

ਬੇਲੋੜਾ ਸਾਫਟਵੇਅਰ ਇੰਸਟਾਲ ਨਾ ਕਰੋ #

ਬੇਲੋੜਾ ਸਾਫਟਵੇਅਰ ਇੰਸਟਾਲ ਕਰਨ ਨਾਲ Linux ਸਿਸਟਮ ਦਾ ਹਮਲਾ-ਖੇਤਰ ਵਧਦਾ ਹੈ ਅਤੇ ਹਮਲੇ ਦਾ ਖਤਰਾ ਵੱਧਦਾ ਹੈ। ਸਿਰਫ਼ ਲੋੜੀਂਦਾ ਸਾਫਟਵੇਅਰ ਇੰਸਟਾਲ ਕਰੋ ਅਤੇ ਬਾਕੀ ਹਟਾਓ। ਇਸ ਨਾਲ ਸੰਭਾਵੀ ਕਮਜ਼ੋਰੀਆਂ ਦੀ ਗਿਣਤੀ ਅਤੇ ਸਫਲ ਹਮਲੇ ਦਾ ਖਤਰਾ ਘਟਦਾ ਹੈ।

ਪੁਰਾਣਾ ਸਾਫਟਵੇਅਰ ਨਾ ਵਰਤੋ #

ਪੁਰਾਣਾ ਸਾਫਟਵੇਅਰ ਜਾਣੀਆਂ ਕਮਜ਼ੋਰੀਆਂ ਦਾ ਫਾਇਦਾ ਲੈਣ ਵਾਲੇ ਹਮਲਿਆਂ ਲਈ ਸਿਸਟਮ ਨੂੰ ਖੁੱਲ੍ਹਾ ਛੱਡ ਸਕਦਾ ਹੈ। ਸੁਰੱਖਿਆ ਲਈ ਸਾਫਟਵੇਅਰ ਦਾ ਨਵਾਂ ਵਰਜਨ ਵਰਤੋ ਅਤੇ ਇਸਨੂੰ ਨਿਯਮਤ ਅੱਪਡੇਟ ਕਰੋ। ਇਸ ਨਾਲ ਜਾਣੀਆਂ ਕਮਜ਼ੋਰੀਆਂ ਠੀਕ ਹੁੰਦੀਆਂ ਹਨ ਅਤੇ ਸੰਭਾਵੀ ਹਮਲਿਆਂ ਤੋਂ ਬਚਾਅ ਹੁੰਦਾ ਹੈ।

ਨਤੀਜਾ #

Linux ਸਿਸਟਮ ਦੀ ਸੁਰੱਖਿਆ ਮਜ਼ਬੂਤ ਕਰਨੀ ਇਸਦੀ ਰੱਖਿਆ ਅਤੇ ਅੰਦਰਲੇ ਡੇਟੇ ਨੂੰ ਬਚਾਉਣ ਲਈ ਜ਼ਰੂਰੀ ਹੈ। ਇਸ ਲੇਖ ਦੇ ਕਰਨਯੋਗ ਅਤੇ ਨਾ ਕਰਨਯੋਗ ਸੁਝਾਅ ਅਪਣਾਕੇ ਸਿਸਟਮ ਨੂੰ ਸੁਰੱਖਿਅਤ ਕਰੋ ਅਤੇ ਸਾਈਬਰ ਖਤਰਿਆਂ ਦਾ ਜੋਖਮ ਘਟਾਓ। ਸਿਸਟਮ ਅੱਪਡੇਟ ਰੱਖੋ, ਫਾਇਰਵਾਲ ਵਰਤੋ, ਪਾਸਵਰਡ ਨੀਤੀਆਂ ਕੌਂਫਿਗਰ ਕਰੋ ਅਤੇ ਲੌਗਾਂ ਦੀ ਨਿਗਰਾਨੀ ਕਰੋ। ਕਮਜ਼ੋਰ ਪਾਸਵਰਡ, ਆਟੋਮੈਟਿਕ ਅੱਪਡੇਟ ਬੰਦ ਕਰਨਾ, root ਖਾਤੇ ਨੂੰ SSH ਪਹੁੰਚ ਦੇਣਾ, ਬੇਲੋੜਾ ਜਾਂ ਪੁਰਾਣਾ ਸਾਫਟਵੇਅਰ ਇੰਸਟਾਲ ਕਰਨਾ ਨਾ ਕਰੋ। ਇਹ ਸੁਰੱਖਿਆ ਅਮਲ Linux ਸਿਸਟਮ ਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖਣ ਵਿੱਚ ਮਦਦ ਕਰਨਗੇ।
