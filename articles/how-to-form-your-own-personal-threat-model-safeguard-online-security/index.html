個人脅威モデルは、誰があなたを狙う可能性があり、何を求め、どのように接触するかという3つの問いへの短い書面回答です。漠然とした不安を実行できる計画に変えます。

セキュリティにかけられる労力は限られています。脅威モデルを使えば、実際に受ける可能性が高い攻撃に集中でき、起こりそうにない問題に力を使わずに済みます。

個人脅威モデルとは？ #

脅威モデリングとは、資産、資産を狙う可能性のある相手、その相手が使う経路を洗い出す作業です。玄関に鍵をかけても、ガレージの自転車には鍵をかけない判断をするように、日常でも簡易的に行っています。書面にまとめると、判断を意識的に繰り返せます。

資産を挙げ、攻撃者を特定し、経路を調べてから対策を選びます。各段階で候補が絞られ、一般的なチェックリストではなく自分の状況に合う保護策になります。

要点： 個人脅威モデルは一度だけ記入するシートではありません。定期的に見直し、転職、引っ越し、世間の注目を集める問題など、生活に大きな変化があったときにも更新します。

要点 #

  • 資産から始めます。 抽象的な「安全」ではなく、具体的な対象を守ります。
  • 脅威となる相手はそれぞれ異なります。 詐欺師、ストーカー、国家レベルの攻撃者には異なる対策が必要です。
  • 攻撃経路には繰り返しがあります。 フィッシング、マルウェア、パスワードの使い回し、端末の紛失は大きな被害を招きます。
  • 優先順位は被害の大きさで決めます。 最も避けたい損失に対策を割り当てます。
  • 対策は意図的にシンプルです。 強いパスワード、MFA、更新で多くの攻撃を防げます。

7つの手順 #

手順行動成果
1資産を特定する保護対象の優先順位付きリスト
2脅威となる相手を評価するあなたを狙う可能性が高い相手
3動機と能力を評価する攻撃者のプロファイル
4攻撃経路を特定する攻撃者が侵入する方法
5結果を評価する損失ごとの影響
6リスク軽減策を実施する導入する管理策
7見直して更新する継続的に使う文書

各手順は前の手順を土台にします。飛ばした手順は攻撃者に利用される隙になります。

無料の個人脅威モデルチェックリスト #

  • 資産を列挙する。 金銭、デジタル、個人、仕事の各資産を価値順に並べます。
  • 脅威となる相手を挙げる。 各資産を狙う可能性の高い相手を特定します。
  • 動機と能力を書く。 技術の低い相手から国家の支援を受ける相手まで記載します。
  • 攻撃経路を整理する。 フィッシング、マルウェア、パスワード攻撃、端末の盗難などを挙げます。
  • 結果を評価する。 各資産を失う、または漏えいする場合の影響を考えます。
  • 軽減策を適用する。 固有のパスワード、MFA、更新、プライバシー設定などを使います。
  • 見直しを予定する。 数か月ごとと生活の大きな変化の後に確認します。

手順1：資産を特定する #

資産とは、あなたや攻撃者にとって価値のあるものです。金銭、データ、身元、評判が含まれます。資産を守るため、まず一覧にします。

資産の種類例
金融銀行口座、カード、投資、暗号資産ウォレット
デジタルメール、ソーシャルプロフィール、クラウド上のファイル、写真
個人身分証明書、医療記録、自宅住所
仕事知的財産、顧客データ、企業秘密

失ったり公開されたりした場合の損失で各項目を順位付けします。上位の項目をもとに残りのモデルを作ります。

メールを忘れないでください。他のすべてのアカウントを開くマスターキーです。

手順2：脅威となる相手を評価する #

脅威アクターとは、資産にアクセスする理由と手段を持つ相手です。相手ごとに狙うものが違うため、対策も変わります。

脅威アクター狙うもの
ハッカー認証情報、データ、アクセス権
詐欺師金銭、カード番号、ギフトカード
サイバーストーカー威圧、支配、嫌がらせ
競合相手あなたの知的財産と顧客
国家の攻撃者情報、影響力、アクセス権

ジャーナリスト、経営幹部、学生では、直面する相手と能力が異なります。最も恐ろしい相手ではなく、最も可能性が高い相手を各資産に結び付けます。

手順3：動機と能力を評価する #

脅威アクターには動機（攻撃する理由）と能力（利用できる資源）があります。動機から狙いを、能力から必要な防御水準を判断します。

動機背景
金銭目的身代金、詐欺、盗難データの販売
報復個人的または仕事上の恨み
スパイ活動秘密や知的財産
ハクティビズム大義、宣伝、妨害

能力はスクリプトを使う機会狙いの詐欺師から、独自ツールを持つ資金豊富なチームまで幅があります。技術が低い攻撃者も危険です。同じフィッシングやパスワード攻撃を大規模に実行できるからです。 最も可能性の高い能力に合わせて対策を選び、それ以下の残余リスクを受け入れます。

手順4：攻撃経路を特定する #

攻撃経路とは、攻撃者が資産に到達するための道筋です。個人への侵害の多くは限られた経路を使います。

攻撃経路侵入方法
フィッシング偽のメール、SMS、リンク、ログインページ
マルウェアダウンロード、添付ファイル、自動インストール
ソーシャルエンジニアリング圧力をかける、他人になりすます
パスワード攻撃使い回し、総当たり、漏えい認証情報
物理的な盗難盗まれた端末、放置された端末

自分の資産と脅威アクターに該当する経路を挙げます。手順6で各経路に対策を割り当てます。

手順5：結果を評価する #

結果とは、資産を失った場合に負う損失です。評価したうえで、最も避けたい結果に防御を割り当てます。

結果影響
金銭的損失口座の残高消失、不正請求
評判の悪化中傷、偽プロフィール、メッセージの漏えい
個人情報の盗用あなた名義の新規口座やローン
精神的苦痛嫌がらせ、恐怖、支配権の喪失

同じ資産を持つ人でも優先順位は異なります。著名人は評判を最優先し、退職者は金銭的損失を優先するかもしれません。この順位が手順の成果です。

手順6：リスク軽減策を実施する #

軽減策は攻撃経路を塞ぎます。使いやすさではなく、結果の重大さに基づいて対策を適用します。

対策防ぐもの
強固で固有のパスワード とパスワードマネージャーパスワード攻撃
二要素認証（2FA）認証情報の窃取
ソフトウェアとファームウェアの更新既知の脆弱性
ファイアウォールとウイルス対策マルウェア
プライバシー設定公開状態での露出
セキュリティ教育フィッシングとソーシャルエンジニアリング

ヒント： 脅威モデルは非公開の暗号化された場所に保管してください。資産と弱点が書かれているため、漏えいするとそれ自体が攻撃対象になります。

これらの対策がシンプルなのは有効だからです。攻撃者は人々が対策を省くことを期待しています。

手順7：見直して更新する #

生活や周囲の脅威が変わると、脅威モデルは古くなります。定期的に、また大きな出来事の後に見直してください。

  • 最新情報を得る。 新しい攻撃や詐欺について、 SecurityWeek や Krebs on Security などを確認します。
  • 新しい脅威を監視する。 新しい攻撃手法を追うには、 MITRE ATT&CK と CISA を参照します。
  • 新技術を再評価する。 端末、アプリ、サービスを追加する前に、セキュリティとプライバシーの実績を調べます。
  • 規制を確認する。 データに適用される規則について、 GDPR と CCPA を確認します。
  • 定期的にリスクを評価する。 手順1から6を見直し、抜けや古い対策を探します。

次の手順 #

脅威モデルは行動に移して初めて役立ちます。具体的な対策に進みましょう。

  • 強固で固有のパスワードを作成し 、マネージャーに保存します。
  • MFAの要素を理解し 、すべての場所で2FAを有効にします。
  • フィッシングの見分け方を学び 、クリックする前に確認します。
  • ウイルス対策とエンドポイント保護 を検討します。

次の見直しは3か月後に予定しましょう。放置する完璧なモデルより、見直し続けるモデルのほうが役立ちます。
