Ubiquiti UniFi Express: un gateway compacto y potente para redes domésticas y pequeñas empresas

En el mercado de soluciones de red, que evoluciona rápidamente, UniFi Express de Ubiquiti destaca por ofrecer un gateway compacto y potente junto con un punto de acceso WiFi 6. Este análisis detallado repasa sus especificaciones, funciones y diferencias con otros dispositivos, y evalúa si sirve para redes domésticas y de pequeñas empresas.

Conoce UniFi Express #

UniFi Express simplifica la administración de redes al combinar un firewall de última generación, funciones con reconocimiento de aplicaciones y un punto de acceso WiFi 6 integrado en un diseño delgado y compacto. Este análisis examina sus capacidades y limitaciones y lo compara con otros gateways UniFi.

Características técnicas: especificaciones de UniFi Express #

UniFi Express incluye una CPU ARM Cortex-A53 de doble núcleo a 1 GHz y 1 GB de memoria DDR3L. Su pantalla de 0,9 pulgadas muestra información en tiempo real y complementa sus especificaciones técnicas. El rendimiento máximo es de 1 Gbps, pero hay limitaciones: no incluye las funciones Suspicious Activity y admite solo 5 dispositivos UniFi.

  • CPU: ARM Cortex-A53 de doble núcleo a 1 GHz
  • Memoria: 1 GB DDR3L
  • Almacenamiento flash integrado: 10 GB
  • Pantalla: 0,9 pulgadas
  • Rendimiento máximo de SQM: 1 Gbps
  • Puertos WAN: 1x Gigabit RJ45
  • Puertos LAN: 1x Gigabit RJ45
  • Alimentación: USB-C (5 V / 3 A)
  • Consumo máximo: 10 W
  • Dimensiones: 98 x 98 x 30 mm

Estos datos técnicos ayudan a evaluar el rendimiento de UniFi Express en distintos escenarios de red.

Funciones de WiFi 6: el punto de acceso integrado #

Una de las principales funciones de UniFi Express es el punto de acceso WiFi 6 integrado. No admite la banda de 6 GHz (WiFi 6E), pero ofrece un alto rendimiento en las bandas de 2,4 GHz y 5 GHz. Su cobertura aproximada de 140 m² (1.500 ft²) proporciona una conexión fiable dentro de esa zona.

  • Potencia de transmisión a 2,4 GHz: 22 dBm
  • Potencia de transmisión a 5 GHz: 25 dBm
  • MIMO: 2 x 2 (DL/UL MU-MIMO)
  • Rendimiento a 2,4 GHz: 573,5 Mbps
  • Rendimiento a 5 GHz: 2,4 Gbps
  • Clientes simultáneos: más de 60

UniFi Express también puede funcionar como punto de acceso mesh, lo que facilita ampliar la red.

UniFi Express frente a otros gateways #

Comparar UniFi Express, UniFi Gateway Lite, UniFi Dream Router (UDR) y UniFi Dream Machine Pro (UDM Pro/SE) ayuda a elegir el gateway adecuado para cada necesidad de red.

UniFi Express #

UniFi Express es un gateway compacto y potente todo en uno con punto de acceso WiFi 6. Ejecuta la aplicación UniFi Network, ofrece un rendimiento de enrutamiento de 1 Gbps, incluye un punto de acceso integrado y cuesta 149 $. No ofrece detección de amenazas IDS ni IPS.

UniFi Gateway Lite #

UniFi Gateway Lite es el sucesor de UniFi Security Gateway y requiere una consola adicional para administrarlo. Cuesta 129 $ y ofrece el mismo rendimiento de enrutamiento que UniFi Express, 1 Gbps, pero no incluye punto de acceso integrado. Sí ofrece detección de amenazas IDS e IPS para una protección avanzada.

UniFi Dream Router (UDR) #

UniFi Dream Router (UDR) está diseñado para el hogar y combina varias funciones en un solo dispositivo. Incluye una CPU ARM Cortex-A53 de doble núcleo a 1 GHz, 2 GB de memoria y un rendimiento de enrutamiento de 1 Gbps. Ejecuta UniFi Network y UniFi Protect y admite detección de amenazas IDS e IPS. Por 199 $, también incluye un punto de acceso, por lo que resulta adecuado para una red doméstica completa.

UniFi Dream Machine Pro (UDM Pro/SE) #

UniFi Dream Machine Pro (UDM Pro/SE) es una solución empresarial. El gateway incorpora una CPU Arm Cortex-A57 de doble núcleo a 1,7 GHz, 4 GB de RAM y un rendimiento de enrutamiento de 10 Gbps. Es compatible con UniFi Network y UniFi Protect, detección de amenazas IDS e IPS y varios puertos PoE. Está pensado para redes más grandes. Su precio va de 379 a 499 $. Ofrece funciones completas para instalaciones complejas.

Cómo elegir el gateway adecuado #

Para elegir entre estos gateways, considera las necesidades específicas de tu red. Si bastan la administración sencilla, un diseño compacto y la protección básica frente a amenazas, UniFi Express es una buena opción. Si priorizas la detección avanzada de amenazas, conviene UniFi Gateway Lite. UniFi Dream Router y UniFi Dream Machine Pro/SE se orientan respectivamente a hogares y empresas, con funciones para redes más amplias.

Configura UniFi Express: un inicio sencillo #

UniFi Express confirma su reputación plug-and-play durante la configuración. Conecta el dispositivo a Internet mediante el puerto WAN y abre la aplicación UniFi Network en el teléfono para iniciar la configuración sencilla. Necesitas una cuenta de Ubiquiti para vincular el dispositivo con su entorno de software fácil de usar.

Configuración inicial #

  1. Conecta UniFi Express a Internet.
  2. Abre la aplicación UniFi Network en el teléfono.
  3. Sigue las instrucciones en pantalla, asigna un nombre a UniFi Express y configura la red inalámbrica.
  4. Cuando se solicite, conéctate a la nueva red inalámbrica.

La configuración sencilla hace que UniFi Express sea una buena opción para quienes priorizan la facilidad sin renunciar a funciones.

Configuración de UniFi Network #

Lo mejor es ajustar la red en la aplicación UniFi Network basada en navegador. Inicia sesión con la dirección IP del gateway o desde https://unifi.ui.com para acceder a la configuración. El siguiente video muestra la configuración completa de los dispositivos Ubiquiti UniFi.

UniFi Express como punto de acceso mesh: más posibilidades #

Además de funcionar como gateway independiente, UniFi Express puede servir como punto de acceso mesh en una red existente. Puedes usar un enlace ascendente cableado o inalámbrico. El dispositivo se integra con facilidad y ofrece flexibilidad.

  • Dispositivos compatibles: otros 4 dispositivos UniFi Network
  • Ambos puertos utilizables como LAN: sí, en modo mesh
  • Compatibilidad mesh: todos los puntos de acceso UniFi de segunda generación o posteriores
  • Compatibilidad con VLAN: no disponible en los puertos LAN/WAN
  • Gateway para CloudKey: no, se requiere UniFi Gateway Lite

Esta flexibilidad permite usar UniFi Express como punto de acceso y ampliar la red cuando cambian las necesidades.

Preguntas frecuentes #

  1. ¿Cuántos dispositivos admite UniFi Express (UX)?

    • UniFi Express puede administrar otros 4 dispositivos UniFi Network.

  2. ¿Se pueden usar ambos puertos como LAN cuando está en modo mesh?

    • Sí. Al conectar UniFi Express a una red mesh, ambos puertos pueden utilizarse como LAN.

  3. ¿UX puede crear una red mesh con puntos de acceso UniFi normales?

    • Sí. UX es compatible con todos los puntos de acceso UniFi de segunda generación o posteriores.

  4. ¿Los puertos LAN/WAN admiten VLAN?

    • No se pueden asignar VLAN a los puertos LAN ni WAN.

  5. ¿UniFi Express puede servir como gateway para un CloudKey?

    • No. Si tienes un CloudKey, UX solo puede funcionar como punto de acceso. Necesitas UniFi Gateway Lite.

Resumen #

UniFi Express es un atractivo Cloud Gateway básico, especialmente para redes domésticas sencillas y oficinas pequeñas. Tiene un límite en la cantidad de dispositivos admitidos y no incluye IDS/IPS, pero su diseño compacto y el punto de acceso integrado lo convierten en una solución todo en uno para muchos usuarios. Si cambian las necesidades de la red, puedes seguir usando UniFi Express como punto de acceso.
