RAIDを理解する：データストレージの種類と用途 #

RAID（Redundant Array of Independent Disks、独立ディスクの冗長配列）は、性能、信頼性、耐障害性を高めるストレージ技術です。複数の物理ディスクを1つの論理ユニットにまとめ、冗長性を確保しながらデータへのアクセスを高速化します。RAIDは長年にわたって進化し、さまざまなレベルや実装方式が異なる利点とトレードオフをもたらします。この記事では、RAIDの種類とデータストレージでの用途を紹介します。

要点 #

  • RAIDはデータストレージの性能、信頼性、耐障害性を高める技術です。
  • RAID 0、RAID 1、RAID 5、RAID 10、RAID 6など複数のレベルがあり、それぞれに異なる利点と用途があります。
  • RAIDはハードウェアコントローラーまたはソフトウェアソリューションで実装できます。
  • データのバックアップと復旧、性能向上、耐障害性、大規模データストレージ、動画編集やメディア制作の支援などがRAIDの利点です。
  • RAIDを使う際は、コストと性能のトレードオフ、データセキュリティ、再構築時間、互換性と相互運用性、RAIDの障害やデータ損失のリスクを検討してください。

RAIDの概要 #

RAIDとは？ #

RAIDはRedundant Array of Independent Disksの略で、複数の物理ディスクを1つの論理ユニットにまとめるストレージ技術です。性能と耐障害性を高め、ストレージ容量を増やします。

RAIDはデータストライピングという技術を使い、データをブロックに分割して複数のディスクに分散します。データを複数のディスクに分散することで、読み取りと書き込みを並行して実行でき、アクセスや転送を高速化できます。

RAIDはミラーリングやパリティなどの方法でも冗長性を確保します。ミラーリングでは、複数のディスクにデータの完全なコピーを作成します。そのため、1台が故障してもデータを利用できます。パリティでは追加情報を計算して保存し、ディスク故障時のデータ再構築に使います。

このようにRAIDは、複数のディスクを1つの論理ユニットにまとめることで、ストレージ性能の向上、データ損失への保護、容量の拡大を実現します。

RAIDの歴史 #

RAID（Redundant Array of Independent Disks）は、データストレージの信頼性と性能を高めるため、1980年代後半に導入されました。カリフォルニア大学バークレー校で、David Patterson教授が率いる研究チームによって開発されました。この概念は、従来の単一ディスクストレージシステムの限界を解決するために生まれました。

RAID技術は長年にわたって進化してきました。各RAIDレベルは、データ冗長性、性能、容量について異なる特性を提供します。現在では、高い可用性、耐障害性、効率的なデータ保存と取得が必要な幅広い業界や用途で使われています。

RAIDの主な歴史的節目は次のとおりです。

  • RAID 0はストライピングとも呼ばれ、最初に登場したRAIDレベルです。複数のディスクにデータを分散して性能を高めます。
  • RAID 1はミラーリングとも呼ばれ、2台以上のディスクにデータの完全なコピーを作成して冗長性を確保します。
  • RAID 5では分散パリティが導入され、1台のディスク故障後にデータを復旧できるようになりました。
  • RAID 10はミラーリングとストライピングを組み合わせ、性能と冗長性を両立します。
  • RAID 6は二重パリティを追加し、2台のディスク故障後もデータを復旧できます。

各RAIDレベルには固有の強みと用途があります。RAIDの歴史を知ることで、データストレージ技術の進歩と現代のコンピューティングにもたらす利点を理解できます。

RAIDの利点 #

RAIDはデータストレージで広く使われており、次のような利点があります。

  • 性能向上：データを複数のディスクに分散し、並行アクセスを可能にして読み書き速度を高めます。
  • データ冗長性：複数のディスクにデータのコピーを保存し、ディスク故障時のデータ損失リスクを抑えます。
  • 耐障害性：1台以上のディスクが故障しても動作を続け、データへのアクセスを維持できます。
  • 拡張性：ディスクを追加してRAIDシステムのストレージ容量を増やせます。
  • コスト効率：低価格のディスクを使いながら、性能や信頼性を維持できます。
  • 柔軟性：異なるRAIDレベルで、性能、容量、冗長性の要件に対応できます。
  • データへのアクセス性：複数のディスクへ同時にアクセスしてレイテンシーを下げ、システム全体の性能を向上させます。

RAIDレベル #

RAID 0：ストライピング #

RAID 0はストライピングとも呼ばれ、データ転送速度と性能を高めることを重視します。データをブロックに分割し、複数のディスクへ同時に分散します。

  • データを分散すると、読み取りと書き込みを並行して実行でき、全体のスループットが大幅に向上します。
  • RAID 0は冗長性も耐障害性も提供しません。1台のディスクが故障すると、アレイ全体が利用できなくなり、データを失います。
  • 動画編集やゲームなど、冗長性より性能を優先し、高速なデータアクセスを必要とする用途に適しています。

RAID 0の主な特徴

特徴説明
性能向上RAID 0は複数のディスクへ並行してアクセスし、読み書き速度を高めます。
冗長性なしRAID 0はデータ冗長性も耐障害性も提供しません。
ストレージ容量の増加合計容量はアレイ内の全ディスクの容量を合計した値です。

ヒント：重要なデータやデータ保護が必要な用途にはRAID 0を使わないでください。1台のディスク故障でデータを完全に失う可能性があります。

RAID 1：ミラーリング #

RAID 1はミラーリングとも呼ばれ、2台以上のディスクにデータの完全なコピーを作成します。この冗長性により、信頼性と耐障害性が高まります。

  • RAID 1アレイの各ディスクには同じデータが保存されます。1台が故障しても、残りのディスクからデータにアクセスできます。
  • 複数のディスクから同時にデータを読み取れるため、読み取り性能に優れています。
  • 一方、書き込み性能はアレイ内で最も遅いディスクの速度に制限されます。
  • データの完全性と可用性が特に重要なデータベースサーバーや金融システムなどでよく使われます。

RAID 1の利点：

  • データ冗長性と耐障害性の向上
  • 読み取り性能の向上
  • ディスク故障時の迅速なデータ復旧
  • 高いデータ完全性と可用性が必要な用途に適する

ヒント：RAID 1は重要なデータを保護できますが、ミラーリングには追加のストレージ容量が必要です。

RAID 5：分散パリティ #

RAID 5は分散パリティを使い、耐障害性とデータ保護を提供します。性能とデータ冗長性の両方が重要なストレージシステムでよく使われます。

RAID 5はRAID 0と同様にデータを複数のディスクへ分散しますが、パリティ情報も含みます。パリティ情報は計算され、アレイ内のすべてのディスクに分散されます。これによってディスク故障時の冗長性を確保します。

RAID 5の重要な特徴は、ディスク故障後にデータを再構築できることです。欠損したデータは、パリティ情報と残りのディスク上のデータから復元できます。この再構築処理によって、データの完全性と可用性を維持できます。

RAID 5の主なポイント：

  • 複数のディスクにパリティ情報を分散し、耐障害性を提供します。
  • 性能とデータ冗長性を適切に両立します。
  • 少なくとも3台のディスクが必要です。
  • 1台のディスク故障なら、データを失わずに運用できます。
  • 故障後の再構築には時間がかかる場合があり、大容量ディスクでは特に長くなります。

つまりRAID 5は、ストライピングと分散パリティを組み合わせて性能と耐障害性を提供します。冗長性と性能の両方が重要なストレージシステムでよく使われます。

RAID 10：ミラーリングとストライピングの組み合わせ #

RAID 10はミラーリングとストライピングの利点を組み合わせ、性能と耐障害性を提供します。RAID 1+0とも呼ばれます。

RAID 10では、まずRAID 0と同様に複数のディスクへデータを分散し、読み書き性能を高めます。次に、分散した各セットを別のディスクセットにミラーリングして冗長性と耐障害性を確保します。1台が故障するとミラー側のディスクが引き継ぎ、データの可用性を維持します。

RAID 10には最低4台のディスクが必要です。少なくとも2台をストライピングに、2台をミラーリングに使います。利用可能な容量は全ディスク容量の半分です。

RAID 10の利点：

  • ストライピングによる高性能
  • ミラーリングによる高い耐障害性
  • ディスク故障後の迅速な再構築
  • 異なるミラーセットで複数のディスク故障に耐えられる

データベース、仮想化、重要なビジネスアプリケーションなど、性能とデータ保護の両方が必要な用途でよく使われます。

RAID 6：二重パリティ #

RAID 6は高いデータ保護と耐障害性を提供します。RAID 5と同様に分散パリティを使いますが、パリティブロックをもう1つ追加し、二重に保護します。

  • RAID 6は2台のディスクが同時に故障しても対応できるように設計されており、RAID 5より高い耐障害性を備えています。
  • 二重パリティにより2台の故障後もデータを再構築でき、データ損失のリスクを軽減します。
  • RAID 6には最低4台のディスクが必要で、2台をデータ用、2台をパリティ用に使います。
  • 大規模データストレージや重要データのバックアップなど、高い耐障害性が必要な用途に適しています。

ヒント：RAID 6を選ぶときは、追加の保護、ディスク増設のコスト、性能への影響を比較してください。

RAIDの用途 #

データのバックアップと復旧 #

データのバックアップと復旧は、データストレージに欠かせない要素です。重要なデータのコピーを作成して損失を防ぎ、障害時に復元できるようにします。バックアップはデータの複製を作成すること、復旧はそのコピーからデータを戻すことです。

  • バックアップと復旧は、事業継続および災害復旧の計画に不可欠です。
  • 定期的なバックアップは、誤削除およびハードウェア障害およびソフトウェアエラーおよびサイバー攻撃からデータを保護します。
  • バックアップ戦略には、フルバックアップおよび増分バックアップおよび差分バックアップがあります。
  • オフサイトバックアップは、自然災害や盗難による物理的な損傷やデータ損失を防ぎます。

ヒント：バックアップと復旧の手順を定期的にテストし、正常に動作することと必要なときにデータを戻せることを確認してください。

性能の向上 #

性能の向上はRAIDの主な利点の1つです。複数のディスクにデータを分散し、並行アクセスを可能にすることで、読み書き速度を大幅に高められます。これはデータベースサーバーや動画編集用ワークステーションなど、高いデータスループットが必要な用途で特に有効です。

RAIDは次のような方法で性能を高めます。

  • ストライピング：RAID 0はデータをブロックに分割して複数のディスクに分散します。同時にアクセスできるため、読み書きが速くなります。
  • 並列処理：RAID 5やRAID 6などは分散パリティを使い、複数のディスクでデータを並行処理します。
  • キャッシュ：一部のRAIDコントローラーは、よく使うデータをキャッシュに保存して取得を高速化します。

性能の向上により、RAIDはデータへの高速かつ効率的なアクセスが必要な用途に適しています。

耐障害性 #

耐障害性はRAIDの重要な特性であり、ハードウェア障害時にもデータを利用可能にします。RAIDは複数のディスクにデータを冗長に分散し、1台以上のディスクが故障した場合にデータを復旧できるようにします。

  • RAID 1、RAID 5、RAID 6は、それぞれミラーリング、分散パリティ、二重パリティによって耐障害性を提供します。
  • RAID 1とも呼ばれるミラーリングは、2台以上のディスクにデータの完全なコピーを作成します。冗長性によりディスク故障後もデータを復旧できます。
  • RAID 5はアレイ内のすべてのディスクにパリティ情報を分散し、1台の故障後にデータを再構築できます。
  • RAID 6は二重パリティを使うため、2台のディスクが同時に故障してもデータを復旧できます。

表：RAIDレベルと耐障害性

RAIDレベル耐障害性
RAID 0耐障害性なし
RAID 1高い耐障害性
RAID 5中程度の耐障害性
RAID 6高い耐障害性

RAIDは耐障害性に加えて性能とデータセキュリティも高め、さまざまなストレージニーズに対応します。

大規模データストレージ #

大規模データストレージでは、RAIDを使って大量のデータを保存、管理します。クラウドサービスプロバイダー、データセンター、科学研究機関など、大規模なデータセットを扱う組織で特に重要です。

大規模データストレージにおけるRAIDの利点：

  • 性能向上：並列アクセスと複数ディスクへのデータ分散により、読み書き速度が上がります。
  • 耐障害性：冗長性によって、1台以上のディスク故障後もデータを利用できます。
  • 拡張性：ストレージ需要が増えたときにディスクを追加できます。
  • データストライピング：ストライピングでデータを複数ディスクに分散し、総容量を増やして効率よく取得できます。

ヒント：大規模データストレージにRAIDを導入する際は、組織の具体的な要件に基づいて適切なレベルと構成を選びましょう。

大規模データストレージのRAID構成例：

RAIDレベル説明
RAID 5複数ディスクに分散するパリティ
RAID 6耐障害性を高める二重パリティ

RAID 5またはRAID 6を使うと、組織は大規模ストレージの性能、耐障害性、効率性を両立できます。

動画編集とメディア制作 #

動画編集とメディア制作では、高性能なストレージが必要です。RAIDは必要な耐障害性と性能向上を提供します。動画編集者やメディア制作者は、ディスク故障からデータを守り、大容量の動画ファイルにすばやく効率的にアクセスして処理できます。

RAIDはストレージ容量の拡張にも役立ち、大きな動画ライブラリを保存できます。冗長性により、ディスクが故障してもデータにアクセスでき、作業を中断せずに続けられます。

動画編集とメディア制作には、性能と耐障害性のバランスが良いRAID 5が適しています。RAID 5は複数のディスクにパリティ情報を分散し、データ分散と冗長性の両方を提供します。高い読み書き速度を実現しながら、ディスク故障からデータを保護できます。

つまりRAIDは、耐障害性、性能、拡張性、データ保護を提供するため、動画編集とメディア制作に重要な技術です。

RAIDの実装 #

ハードウェアRAID #

ハードウェアRAIDは、コンピューターに取り付ける専用のハードウェアコントローラーを使ってRAIDアレイを管理します。

ハードウェアRAIDで考慮すべき点：

  • 性能：ハードウェアコントローラーには専用プロセッサーやキャッシュメモリーが搭載され、アレイ性能を大幅に高める場合があります。
  • 信頼性：複雑なRAID構成に対応するよう設計されており、優れた耐障害性とデータ保護を提供します。
  • 拡張性：多くのRAIDレベルと大容量をサポートするため、企業向けストレージに適しています。
  • 使いやすさ：通常は管理ソフトウェアが付属し、アレイの構成や監視が簡単です。

ソフトウェアRAIDと比べ、ハードウェアRAIDは性能、信頼性、拡張性、使いやすさに優れています。

ソフトウェアRAID #

ソフトウェアRAIDは専用ハードウェアではなくソフトウェアを使って実装します。コンピューターシステムの既存リソースを使ってRAIDアレイを作成できます。

ソフトウェアRAIDの利点：

  • 柔軟性：必要なソフトウェアに対応するコンピューターなら実装できます。専用RAIDハードウェアがない中小企業や個人にとって、コスト効率のよい選択肢です。
  • 簡単なセットアップ：OS標準のツールまたはサードパーティー製ソフトウェアを使って設定できます。
  • 互換性：Windows、macOS、Linuxなど、多くのOSで利用できます。

一方、次の点も考慮が必要です。

  • 性能：特に負荷の高い環境では、ハードウェアRAIDより性能が低い場合があります。
  • システムリソース：CPUとメモリーを使うため、システム全体の性能に影響する場合があります。
  • 拡張性の制限：対応できるディスク数やRAIDレベルに制限がある場合があります。

ソフトウェアRAIDは柔軟でコスト効率のよい方法です。専用ハードウェアほどの性能は得られない場合がありますが、多くのOSに対応し、既存リソースを使って設定できます。

RAIDコントローラー #

RAIDコントローラーは、RAIDシステムのデータ保存を管理する重要な役割を担います。OSとRAIDアレイ間のデータ転送を調整し、システムを効率よく動作させるためのハードウェアとファームウェアを提供します。

  • RAIDコントローラーにはハードウェア型とソフトウェア型があります。ハードウェア型は専用の拡張カードで、ソフトウェア型はOSを介して実装します。
  • ハードウェアコントローラーは専用リソースと高度な機能により、通常は性能と信頼性に優れています。
  • ソフトウェアコントローラーはCPUとメモリーに依存するため、システム全体の性能に影響する場合があります。

コントローラーを選ぶときは、希望するRAIDレベル、対応ディスク数、必要な性能と信頼性を検討してください。OSやRAID構成ソフトウェアとの互換性も確認します。

ヒント：高性能アプリケーションや重要データの保存には、ハードウェアコントローラーがおすすめです。ソフトウェアコントローラーは小規模または重要度の低い構成に適しています。

RAIDの構成 #

RAIDの構成とは、必要な性能とデータ保護を得られるようにアレイを設定して整理することです。

  • システム要件に応じて適切なRAIDレベルを選びます。
  • アレイで使うHDDまたはSSDの台数と容量を決めます。
  • ストライピングやミラーリングのパラメーターとして、ストライプサイズやブロックサイズを設定します。
  • ホットスワップやホットスペアなどの機能を設定する場合もあります。

RAID構成は、アレイの性能、信頼性、データ保護能力を左右します。

ホットスワップとホットスペア #

ホットスワップとホットスペアは、RAID実装における重要な概念です。

ホットスワップとは、システムを停止せずにRAIDアレイの故障または不良ディスクを交換できる機能です。システム稼働中に取り付けや取り外しが可能なディスクを使います。ダウンタイムを抑え、保守やアップグレードを簡単にできます。

ホットスペアは、RAIDアレイに追加しておく予備ディスクです。別のディスクが故障するまで非アクティブのまま待機します。故障が起きると自動的に引き継ぎ、アレイの継続性を保ちます。通常、容量と種類はアレイ内の他のディスクと同じです。

ホットスワップとホットスペアを導入すると、耐障害性が増し、ストレージシステムの信頼性が向上します。

主な違いを表にまとめます。

ホットスワップとホットスペアは併用できます。組み合わせると、RAIDシステムの耐障害性と可用性をさらに高められます。

RAIDを使う際の注意点 #

コストと性能 #

RAIDを導入するときは、コストおよび性能のトレードオフが重要です。RAIDレベルごとに性能や費用対効果が異なります。

  • RAID 0は複数ディスクにデータを分散して高性能を実現しますが、冗長性がなく、データ損失のリスクが高まります。
  • RAID 1はミラーリングで完全な冗長性を提供しますが、利用可能な容量と書き込み性能が低下します。
  • RAID 5は分散パリティによって性能と冗長性を両立し、1台のディスク故障後にデータを復旧できます。
  • RAID 10はストライピングとミラーリングを組み合わせて性能と冗長性を提供しますが、より多くのディスクが必要です。
  • RAID 6は二重パリティで耐障害性を高めますが、ディスク数が増えてコストも高くなります。

RAIDレベルは、ストレージシステムの要件に合わせて選び、コストと性能の適切なバランスを見つけてください。

データセキュリティ #

RAID実装ではデータセキュリティも重要です。データ侵害やサイバー攻撃の脅威が高まるなか、機密情報を保護する必要があります。RAIDには次のようなセキュリティ機能があります。

  • 冗長性：RAID 1、RAID 5、RAID 6などは複数のディスクにデータのコピーを保存します。1台が故障しても、残りのディスクからデータを取得できます。

  • データ暗号化：一部のRAIDコントローラーやソフトウェアRAIDは暗号化をサポートし、保護を強化します。AES（Advanced Encryption Standard、高度暗号化標準）などの暗号化アルゴリズムで、ブロック単位にデータを暗号化できます。

  • アクセス制御：RAIDシステムには、管理者がユーザー権限を定義し、不正アクセスを制限する仕組みが備わっている場合があります。

  • 監視と監査：データへのアクセスを追跡し、疑わしい動きを検出する機能を備える場合があります。

  • バックアップと災害復旧：RAIDをバックアップや災害復旧の戦略と併用すると、障害や災害時のデータ可用性と保護を確保できます。

RAIDシステムを導入する際は、データセキュリティを優先してください。各レベルと構成が提供するセキュリティ機能を慎重に評価する必要があります。

RAIDの再構築時間 #

RAIDの再構築時間とは、ディスク故障後にRAIDアレイを再構築するために必要な時間です。データの可用性とシステム全体の性能に影響します。

  • アレイ内のディスク容量と保存データ量によって変わります。ディスクとデータ量が大きいほど再構築に時間がかかります。
  • 再構築中はシステム負荷が増加し、他の処理の性能に影響する場合があります。
  • 専用ハードウェアを搭載したRAIDコントローラーは、ソフトウェア方式より速く再構築できる場合があります。
  • 再構築の進行状況を監視し、重要なデータを優先してください。

ヒント：定期的なバックアップは、再構築が長引いた場合の影響とデータ損失のリスクを抑えます。

  • 特に大きなアレイでは再構築に時間がかかる場合があります。保守やアップグレードの計画に反映してください。
  • ホットスワップやホットスペアを使うと、システムを停止せずに故障ディスクを交換でき、再構築時間を短縮できます。
  • RAID再構築時間やベストプラクティスの具体的な指針は、メーカーのドキュメントを参照するか、専門家に相談してください。

互換性と相互運用性 #

RAIDシステムを導入するときは、既存のハードウェアやソフトウェアとの互換性と相互運用性を考慮します。互換性は、OS、ドライバー、アプリケーションなど他のコンポーネントと円滑に動作する能力です。相互運用性は、異なるデバイスやシステムと通信し、正しく動作する能力です。

互換性と相互運用性を確保する方法：

  • OSとハードウェアがサポートするRAIDレベルを選ぶ。
  • RAIDコントローラーまたはソフトウェアがシステムアーキテクチャに対応することを確認する。
  • 特定のハードウェアやソフトウェアコンポーネントに既知の互換性問題や制限がないか確認する。
  • 将来の拡張やアップグレードを検討し、新しいコンポーネントとの互換性を確認する。

互換性と相互運用性は、RAIDの実装方式や使用技術によって異なります。詳細は、RAIDメーカーまたはソフトウェア開発者が提供するドキュメントやサポート情報を参照してください。

RAIDの故障とデータ損失 #

RAIDシステムは耐障害性とデータ保護を提供するよう設計されていますが、他の技術と同様に故障やデータ損失を完全には防げません。リスクを理解し、適切な対策を講じる必要があります。

RAIDの故障とデータ損失の主な原因

  • ハードウェア故障：ハードディスク、RAIDコントローラー、電源装置が故障し、データ損失につながる場合があります。
  • 人的ミス：誤ってデータを削除、フォーマット、上書きすると、永久に失われる可能性があります。
  • ソフトウェアの問題：RAID管理ソフトウェアやファームウェアの不具合は、データ破損やシステム不安定の原因になります。
  • 自然災害：火災、洪水などが物理インフラを損傷し、データ損失につながる場合があります。

RAIDの故障とデータ損失のリスクを抑える方法

リスクを減らすには、次の対策を検討してください。

  1. 定期的なバックアップ：ハードウェア故障や災害に備え、オフサイトストレージを含むバックアップ戦略を実施する。
  2. 監視と保守：RAIDコンポーネントの状態を定期的に監視し、ファームウェアの更新やディスク交換など必要な作業を行う。
  3. 冗長性：単一ディスクの故障に備え、RAID 1やRAID 6など冗長性のあるレベルを選ぶ。
  4. 再構築時間：故障後のアレイ再構築にかかる時間を把握し、計画に反映する。
  5. データ復旧サービス：深刻なデータ損失が発生した場合は、RAIDシステムを専門とするデータ復旧サービスを検討する。

ヒント：バックアップの完全性を定期的にテストし、必要なときに正しく復元できることを確認してください。

RAIDの故障とデータ損失の原因を理解し、適切な対策を導入すると、リスクを抑えてRAIDストレージの信頼性を確保できます。

まとめ #

RAID（Redundant Array of Independent Disks、独立ディスクの冗長配列）は、データ保護、性能向上、容量拡張のためのさまざまなレベルを提供します。現代のストレージシステムに欠かせない技術となり、耐障害性、性能向上、データのバックアップと復旧などの利点があります。RAID 0、RAID 1、RAID 5、RAID 10、RAID 6には、それぞれ異なる利点と用途があります。RAIDの導入時は、コストと性能のトレードオフ、データセキュリティ、再構築時間、互換性、RAIDの故障やデータ損失の可能性を考慮してください。RAIDは、大規模データストレージ、動画編集、メディア制作など多様な業界のニーズに対応する柔軟な技術です。

よくある質問 #

RAIDとは？ #

RAIDはRedundant Array of Independent Disks (独立ディスクの冗長配列)の略です。複数の物理ディスクを1つの論理ユニットにまとめ、性能、耐障害性、データ保護を高めるストレージ技術です。

RAIDにはどのようなレベルがありますか？ #

RAIDのレベルには、RAID 0、RAID 1、RAID 5、RAID 10、RAID 6があります。それぞれデータストレージでの特徴と用途が異なります。

RAID 0とは？ #

RAID 0はストライピングとも呼ばれ、冗長性を持たせずにデータを複数のディスクへ分散します。複数のディスクで同時に読み書きできるため、性能が向上します。

RAID 1とは？ #

RAID 1はミラーリングとも呼ばれ、冗長性のために複数ディスクへデータを複製します。1台のディスクが故障しても耐障害性を保ち、データへアクセスできます。

RAID 5とは？ #

RAID 5は分散パリティを使って耐障害性と性能向上を実現します。アレイ内のすべてのディスクにパリティ情報を分散し、1台の故障後にデータを復旧できます。

ストレージ復旧の確認 #

RAIDは、想定するディスク故障モデルに対する可用性や読み書き性能を高めます。誤削除、ランサムウェア、コントローラー故障、火災、誤った同期処理からデータを保護するものではありません。

構成を選ぶ前に、利用可能な容量、再構築時間、ディスク交換手順、監視方法、バックアップ先を記録してください。単一ファイルとシステム全体の復元をテストします。ストレージプラットフォームのドキュメントで、サポートするディスク容量と拡張制限を確認してください。

RAID 10とは？ #

RAID 10はミラーリングとストライピングを組み合わせ、冗長性と性能向上を実現します。最低4台のディスクが必要で、RAID 5より高い耐障害性を提供します。
