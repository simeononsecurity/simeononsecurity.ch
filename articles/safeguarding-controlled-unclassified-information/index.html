次のうち、CUIの例ではないものはどれですか？

管理対象の非機密情報（CUI）は、機密扱いに分類されていないものの、不正アクセス、開示、悪用を防ぐために保護が必要な情報です。機密情報を日常的に扱う個人や組織にとって、CUIの理解は欠かせません。この記事では、CUIの定義と重要性、各カテゴリー、一般的な例、CUIに該当しない例、保護方法と取り扱い方を説明します。## 管理対象の非機密情報（CUI）の概要

CUIの定義と重要性 #

管理対象の非機密情報（CUI）とは、機密性が高いため保護を要するものの、機密情報として分類する基準には該当しない情報です。企業の専有情報、個人識別情報（PII）、法執行機関の機密情報など、幅広い情報が含まれます。

CUIを保護すると、機密性、完全性、可用性を維持できます。まず、適用されるCUIカテゴリー、アクセスを許可された利用者、保管場所、承認済みの共有経路を特定します。次に、それらの対策を契約や機関の取り扱い要件と照合します。

CUIの保護には、アクセス制御、暗号化、監視、文書化された取り扱い手順が必要です。組織には、共有、保管、インシデント報告に関する研修とレビュープロセスも必要です。

組織は、変化する脅威や脆弱性に対応できるよう、セキュリティ対策を定期的に評価し、更新する必要があります。これには、リスク評価、セキュリティ意識向上プログラム、新しい技術や情報セキュリティのベストプラクティスに関する情報収集が含まれます。

CUIの歴史と発展 #

機密扱いではない機密性の高い情報を保護する必要性が高まるにつれ、CUIの概念は発展してきました。米国政府は2010年にControlled Unclassified Informationプログラムを設立し、機密情報の取り扱いと保護を標準化しました。連邦機関ごとに異なっていた取り扱いを改善することが目的でした。

CUIプログラムの設立前は、各機関が機密扱いではない機密情報の保護について、異なる方針や手順を採用していました。この不統一により情報共有や連携が難しくなり、不正開示のリスクも高まっていました。

CUIプログラムは、情報のライフサイクル全体を通じた保護、共有、配布の明確な指針と要件を定めます。CUIの分類、表示、取り扱い、管理解除に共通の枠組みを設けることで、政府機関と協力先の連携を促します。

設立以来、CUIプログラムは新たな脅威や技術の進歩に対応するため、何度も更新、改善されてきました。情報セキュリティの変化に合わせて発展し、機密扱いではない機密情報を保護し続けています。

技術が進歩し、情報量が増えるにつれて、CUIの保護は複雑になります。組織は警戒を続け、リスクを効果的に軽減するためにセキュリティ対策を調整する必要があります。人工知能や機械学習などの高度な技術を使えば、潜在的な脅威をリアルタイムで検出し、対応できます。

政府機関、業界の協力先、海外の関係機関の間で連携し、情報を共有することもCUI保護の強化に役立ちます。ベストプラクティス、得られた教訓、脅威情報を共有することで、組織は防御を共同で強化し、機密情報に関するリスクを軽減できます。

管理対象の非機密情報のカテゴリー #

管理対象の非機密情報（CUI）は、個人や組織のプライバシー、機密性、完全性を守るために保護が必要な情報です。CUIには複数のカテゴリーがあり、それぞれに固有の特徴と取り扱い要件があります。

CUI Basic #

CUI Basicは、ほかの特定のCUIカテゴリーに含まれない、機密扱いではない機密情報のカテゴリーです。個人や組織を保護するために、情報の保護が必要です。このカテゴリーには、個人識別情報（PII）や機密性の高い財務データなどが含まれます。

個人識別情報（PII）とは、氏名、住所、社会保障番号、財務情報など、個人を特定できる情報です。PIIの保護は、個人情報の盗難、詐欺、その他の悪用を防ぐために重要です。

機密性の高い財務データには、金融取引、口座番号、クレジットカード情報、銀行情報などが含まれます。これを保護すると、不正アクセス、金融詐欺、その他の金銭的搾取を防げます。

CUI Specified #

CUI Specifiedは、保護対象として指定され、固有の取り扱い要件がある管理対象の非機密情報カテゴリーです。国家安全保障やその他の重要分野に関わる機密情報を含みます。

管理対象技術情報とは、輸出管理法令の対象となる技術データや情報です。防衛関連品、軍事技術、その他の機密性の高い技術開発に関する情報が含まれる場合があります。保護することで、機密技術への不正アクセスや、権限のない個人・組織への移転を防げます。

輸出管理対象情報は、国家安全保障を守り、機密情報や技術が外国の組織に不正に移転されるのを防ぐ法令の対象です。防衛関連品、軍民両用技術、その他の輸出管理対象に関する情報が含まれます。

重要インフラ情報は、発電所、輸送システム、通信網などの重要なインフラシステムに関する情報です。保護することで、重要なサービスを中断させ、国家安全保障を脅かす可能性がある脅威や攻撃を防ぎます。

機密データを扱う個人や組織は、管理対象の非機密情報のカテゴリーを理解する必要があります。カテゴリーを特定して適切に保護することで、個人や組織のプライバシー、機密性、完全性を守れます。

管理対象の非機密情報（CUI）の一般的な例 #

CUIには、国家安全保障、プライバシー、企業の利益に影響を及ぼす可能性があるため、保護が必要な機密情報が数多く含まれます。一般的な例を紹介します。

個人識別情報（PII） #

個人識別情報（PII）はCUIの一種で、個人を特定できる情報を指します。氏名、住所、社会保障番号、その他の識別データなどが該当します。PIIを保護すると、個人情報の盗難、詐欺、個人情報への不正アクセスを防げます。

デジタル化が進む中、PIIの保護はますます重要になっています。サイバー犯罪者は、システムの脆弱性を悪用してPIIを不正な目的で取得しようとします。組織は、暗号化、アクセス制御、定期的なセキュリティ監査などの強固な対策を実施し、PIIの機密性と完全性を保つ必要があります。

ソーシャルメディアやオンラインプラットフォームの普及に伴い、個人もPIIの共有に注意する必要があります。オンラインで共有する情報に気を配り、必要な場合に限り、信頼できる相手に機密性の高い個人情報を提供してください。

法執行機関の機密情報 #

法執行機関の機密情報とは、開示されると進行中の法執行活動や捜査を危険にさらす可能性がある情報です。作戦の詳細、情報源、法執行機関が使用する機密性の高い手法などが含まれます。この情報の保護は、法執行機関の効果的な活動と公共の安全を支えるために重要です。

法執行機関の業務では、機密情報や秘匿情報を扱うことがよくあります。潜入捜査から犯罪組織に関する情報収集まで、内容はさまざまです。不正開示は進行中の捜査を妨げるだけでなく、法執行官や情報提供者の命を危険にさらす可能性があります。

法執行機関は、厳格なアクセス制御、暗号化、その他のセキュリティ対策でこうした情報を保護します。また、職員は適切な取り扱いと保護について徹底した研修を受け、不正開示のリスクを減らします。

企業の専有情報 #

企業の専有情報もCUIの一例です。企業が所有し、競争上の優位性をもたらす機密情報を指します。営業秘密、知的財産、社外秘の事業戦略などが含まれる場合があります。これを保護することは、企業の経済的利益と市場での地位を守るために重要です。

競争の激しい現在のビジネス環境では、企業は優位性を得るために研究開発へ多くの資源を投じます。営業秘密や革新的な技術などの専有情報は、企業の成功を左右することがあります。そのため、不正アクセスや開示から守ることが重要です。

企業は、秘密保持契約、物理的なセキュリティ管理、デジタル著作権管理システムなど、さまざまな対策を使います。従業員向けの研修や意識向上プログラムも、専有情報の保護が重要な理由や、侵害された場合の影響を理解するのに役立ちます。

このように、CUIには慎重な取り扱いと保護が必要な機密データが数多く含まれます。個人識別情報、法執行機関の機密情報、企業の専有情報のいずれであっても、個人や組織は不正アクセス、開示、被害を防ぐ強固な対策を優先する必要があります。

管理対象の非機密情報に該当しない例 #

公開情報 #

公開情報は自由にアクセスでき、配布や利用の制限を受けません。一般公開されているウェブサイト、出版された書籍、その他の公開情報源で広く入手できる情報が該当します。

インターネット上には膨大な情報があります。ニュース記事、研究論文、ブログ、ソーシャルメディアの投稿など、多くの情報が公開されています。簡単な検索で歴史的事実、科学データ、娯楽ニュースを見つけられます。

出版された書籍も、公開情報の優れた情報源です。図書館や書店には、小説やノンフィクションから自己啓発書、学術教科書まで、多くのテーマを扱った本があります。必要な人に知識や洞察を提供します。

公開ウェブサイトも、一般の人々が情報にアクセスできるようにする重要な役割を果たします。政府機関、教育機関、さまざまな組織のウェブサイトには、法律や規則、教育資料、研究結果などの情報が掲載されています。インターネットに接続できれば誰でも閲覧できるため、公開情報の有用な情報源です。

機密情報 #

CUIとは異なり、機密情報には国家安全保障への影響に応じて、Confidential、Secret、Top Secretなどの特定の機密区分が割り当てられます。CUIより厳しいアクセス制御と取り扱い手順の対象です。

機密情報には、権限のない人がアクセスしたり開示したりすると国家安全保障に損害を与える可能性があるため、保護が必要なデータが含まれます。軍事作戦、情報収集の手法、外交交渉、機密性の高い技術開発に関する情報などが該当します。

たとえば、機密情報には部隊の移動、戦略目標、戦術的な作戦行動など、軍事作戦の詳細な計画が含まれる場合があります。情報を機密に保つことは、作戦の成功と参加する軍人の安全に欠かせません。

情報機関も国家安全保障上の利益を守るため、機密情報を収集します。国内外の脅威の可能性に関するデータを収集、分析し、意思決定者に重要な判断材料を提供する場合があります。情報の機密性が高いため、不正開示を防ぐ厳格なアクセス制御と保護策が必要です。

外交上の連絡にも機密情報が含まれることがあります。国家間の機密性の高い交渉、国際協定の協議、外交戦略などは、関係国の利益と安全を守るために機密扱いになります。

最後に、機密情報は軍事利用の可能性がある技術開発にも関係します。先進兵器、暗号化方式、監視技術に関する研究開発プロジェクトは、このカテゴリーに該当します。保護することで、敵対者が国家安全保障を損なう可能性のある重要な知識を得るのを防ぎます。

CUIの保護と取り扱い #

CUIを保護する指針 #

CUIの保護には、機密性、完全性、可用性を確保するための具体的な指針と実践が必要です。主な対策には、アクセス制御、データ暗号化、安全な保管、CUIの適切な取り扱いに関する従業員研修があります。定期的な監査と評価は、保護上の脆弱性や不足を特定し、対処するのに役立ちます。

CUIを不適切に扱った場合の結果 #

CUIの不適切な取り扱いは、個人や組織に深刻な結果をもたらす可能性があります。内容や規模によっては、法的措置、金銭的な罰則、評判の低下、事業機会の損失につながることがあります。こうした悪影響を避けるには、個人や組織がCUIの保護と取り扱いを真剣に考える必要があります。

まとめ #

機密情報を扱う個人や組織にとって、管理対象の非機密情報（CUI）の理解は欠かせません。CUIのカテゴリー、一般的な例、該当しない例を認識すると、不正アクセス、開示、悪用を防ぐために情報を適切に保護、管理できます。保護の指針に従い、不適切な取り扱いの結果を理解することは、機密情報の機密性、完全性、可用性を維持する重要な手順です。
