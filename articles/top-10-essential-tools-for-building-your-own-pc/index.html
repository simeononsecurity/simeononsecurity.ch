10 eines essencials per muntar el teu PC #

Muntar el teu PC et permet triar cada component segons les teves necessitats. La tasca pot semblar difícil, sobretot si no ho has fet mai. Aquests deu components i eines essencials t’ajudaran a començar.

Idees principals #

  • Triar el processador adequat és essencial per al rendiment del PC.
  • La placa base és el fonament del PC i determina la compatibilitat de la resta de components.
  • Una targeta gràfica és necessària per als jocs i les tasques amb gràfics intensius.
  • La RAM és important per a la multitasca i el rendiment general del sistema.
  • Tria l’emmagatzematge segons la velocitat, la capacitat i el pressupost que necessitis.

Triar el processador adequat #

Entendre les especificacions de la CPU #

Quan analitzis les especificacions de la CPU, considera diversos factors. La velocitat del rellotge determina la rapidesa amb què el processador executa instruccions. El nombre de nuclis indica quantes tasques pot gestionar la CPU alhora. La mida de la memòria cau desa dades d’ús freqüent per accedir-hi més de pressa. El valor TDP (Thermal Design Power) indica la calor que genera la CPU i la refrigeració que necessita.

En resum:

  • Velocitat del rellotge: determina la velocitat del processador.
  • Nombre de nuclis: indica la capacitat per fer diverses tasques.
  • Mida de la memòria cau: desa dades freqüents per consultar-les ràpidament.
  • Valor TDP: indica la calor generada i les necessitats de refrigeració.

Tingues en compte aquestes especificacions quan triïs el processador adequat a les teves necessitats.

Comparar els processadors Intel i AMD #

Intel i AMD són els principals fabricants de processadors per a PC. Totes dues empreses ofereixen models amb especificacions i nivells de rendiment diferents. Quan els comparis, considera aquests punts:

  • Rendiment: els processadors Intel són coneguts pel bon rendiment d’un sol nucli, útil per als jocs i les tasques d’un sol fil. Els processadors AMD solen oferir millor rendiment amb diversos nuclis, adequat per a l’edició de vídeo i la creació de contingut.
  • Preu: els processadors AMD acostumen a oferir una bona relació qualitat-preu. Sovint proporcionen un rendiment semblant per menys diners, una opció útil amb pressupostos ajustats.
  • Compatibilitat: Intel i AMD fan servir sòcols i xipsets de placa base diferents. Confirma que el processador triat sigui compatible amb la placa base.
  • Overclocking: tant els processadors Intel com els AMD es poden accelerar per obtenir més rendiment. En general, es considera que els Intel de gamma alta ofereixen més marge d’overclocking.
  • Actualitzacions futures: AMD sovint manté el suport per a plaques base antigues durant més temps, cosa que pot facilitar les actualitzacions.

Valora aquests factors segons les teves necessitats i el pressupost abans de triar un processador Intel o AMD.

Determinar el millor processador per a les teves necessitats #

Quan triïs processador, considera el rendiment, la compatibilitat i el preu. El rendiment influeix en la rapidesa amb què el PC gestiona les tasques, però no tots els processadors són compatibles amb totes les plaques base.

  • Investiga els processadors disponibles i compara’n les especificacions.
  • Defineix el pressupost i busca el processador amb millor rendiment dins d’aquest límit.
  • Llegeix ressenyes i benchmarks per conèixer el rendiment en situacions reals.

Consell: si faràs servir el PC per jugar o per a altres tasques exigents, considera un processador amb diversos nuclis i una velocitat de rellotge alta.

El millor processador depèn dels teus requisits i pressupost. Investiga i compara les opcions per trobar el model adequat per al teu muntatge.

Triar la placa base adequada #

Explorar els diferents formats #

El factor de forma determina les dimensions físiques i la distribució de la placa base, i influeix en la mida i la compatibilitat de la caixa del PC.

  • ATX: el format més habitual, amb un bon equilibri entre mida i capacitat d’ampliació. Adequat per a la majoria d’ordinadors de sobretaula.
  • Micro-ATX: més petit que ATX, però encara ofereix una quantitat raonable de ranures d’expansió. És una bona opció per a muntatges compactes.
  • Mini-ITX: ideal per a muntatges petits, però ofereix poques opcions d’expansió.

Considera la mida de la caixa i les ranures d’expansió necessàries. Comprova també la compatibilitat amb el sòcol de la CPU i les ranures de RAM.

Considerar les ranures d’expansió i els ports #

Les ranures d’expansió permeten afegir components com ara targetes gràfiques, de so o de xarxa. Els ports connecten dispositius externs, com ara aparells USB, monitors i altaveus.

  • Nombre de ranures d’expansió: determina quantes en necessites segons els components que vulguis afegir.
  • Tipus de ranures d’expansió: les plaques base poden admetre PCI, PCIe o M.2. Comprova que hi hagi les ranures necessàries.
  • Nombre i tipus de ports: considera els perifèrics i dispositius que faràs servir. Els ports habituals inclouen USB, HDMI, DisplayPort i connectors d’àudio.

Consell: tria una placa base amb més ranures i ports dels que necessites ara per facilitar les actualitzacions futures.

Revisar amb cura les ranures i els ports ajuda a garantir la compatibilitat i el funcionament dels components i perifèrics.

Triar el xipset adequat #

El xipset determina les funcions i capacitats de la placa base. Tria’n un que s’ajusti a les teves necessitats.

Intel i AMD són els principals fabricants de xipsets. Les seves funcions i la compatibilitat amb els processadors varien. Compara’n les especificacions i la compatibilitat abans de decidir-te.

  • Compatibilitat del sòcol: confirma que el xipset sigui compatible amb el sòcol del processador de la placa base.
  • Ranures d’expansió i ports: comprova’n el nombre i els tipus disponibles. Determinen les opcions de connexió del PC.
  • Compatibilitat amb overclocking: si vols accelerar el processador, comprova que el xipset ho admeti.

El xipset influeix en el rendiment i la compatibilitat del PC. Informa-te’n i tria l’opció adequada al muntatge.

Triar la targeta gràfica adequada #

Entendre l’arquitectura de la GPU #

L’arquitectura de la GPU és el disseny i l’estructura de la unitat de processament gràfic. Influeix en el rendiment i les capacitats de la targeta gràfica. Una funció clau de les GPU modernes és el processament paral·lel, que executa diverses tasques alhora i ajuda a gestionar eficientment gràfics complexos i càlculs intensius.

Quan comparis targetes Nvidia i AMD, considera’n les arquitectures. Nvidia destaca els nuclis CUDA i el ray tracing, útils en jocs i aplicacions professionals. AMD posa èmfasi en els processadors de flux i el rendiment de càlcul, adequats per a l’edició de vídeo i el renderitzat 3D.

Per triar una targeta segons el pressupost, compara el nombre de nuclis, la velocitat del rellotge i l’amplada de banda de la memòria. Aquests factors afecten els jocs i altres tasques que exigeixen la GPU. Comprova també el consum d’energia i el disseny tèrmic per assegurar la compatibilitat amb la font d’alimentació i la refrigeració.

Entendre l’arquitectura de la GPU ajuda a avaluar el rendiment i triar una targeta adequada a les teves necessitats i pressupost.

Comparar les targetes gràfiques Nvidia i AMD #

Nvidia i AMD ofereixen targetes gràfiques amb nivells de rendiment i preus diferents.

Rendiment: les targetes Nvidia són conegudes pel seu rendiment en jocs de gamma alta i aplicacions professionals. Sovint superen les AMD en potència bruta i eficiència.

Preu: les targetes AMD acostumen a ser més assequibles. Ofereixen bon rendiment pel preu i són populars entre els jugadors que vigilen el pressupost.

Programari i controladors: Nvidia té bona reputació pel suport de programari i controladors, que s’actualitzen sovint per als jocs i les aplicacions recents. AMD ha millorat els darrers anys, però encara queda enrere en aquest aspecte.

Funcions: algunes targetes Nvidia inclouen ray tracing i DLSS (Deep Learning Super Sampling), que poden millorar la imatge i el rendiment en jocs compatibles.

Compatibilitat: les targetes Nvidia i AMD funcionen amb la majoria de plaques base i sistemes operatius moderns. Revisa els requisits de la targeta i la compatibilitat amb el teu sistema.

Les targetes Nvidia ofereixen rendiment alt i funcions avançades a un preu superior. Les AMD ofereixen bona relació qualitat-preu i són adequades si vols estalviar.

Determinar la millor targeta gràfica per al pressupost #

Considera el rendiment, el preu i la compatibilitat quan triïs targeta gràfica:

  • Investiga benchmarks i ressenyes de les targetes dins del teu pressupost.
  • Consulta els requisits dels jocs i les aplicacions que faràs servir. No totes les tasques necessiten una targeta de gamma alta.
  • Tingues en compte el consum de la targeta i comprova que la font d’alimentació la pugui alimentar.
  • Verifica la compatibilitat amb la placa base i els altres components.

Compara les opcions per trobar l’equilibri adequat entre rendiment i preu.

Triar la RAM adequada #

Entendre la velocitat i la capacitat de la RAM #

La velocitat i la capacitat són factors importants quan tries RAM per al PC.

  • Velocitat de la RAM: freqüència amb què es llegeixen o s’escriuen dades al mòdul. Una velocitat més alta pot accelerar la transferència i millorar el rendiment general.
  • Capacitat de la RAM: quantitat de memòria del mòdul. Més capacitat permet executar diverses aplicacions i gestionar conjunts de dades més grans.

Equilibra la velocitat i la capacitat segons les aplicacions i les càrregues de treball.

Les velocitats més altes poden requerir maquinari compatible i suport de la placa base. Comprova també la capacitat màxima de RAM admesa.

Consell: si fas servir el PC principalment per jugar o per a tasques que consumeixen molta memòria, més velocitat i capacitat poden millorar el rendiment.

Comparar DDR4 i DDR3 #

Quan triïs RAM, considera les diferències entre DDR4 i DDR3. DDR4 és una generació més recent i ofereix diversos avantatges:

  • Rendiment: DDR4 acostuma a oferir velocitats de transferència més altes i latència inferior a DDR3.
  • Eficiència energètica: DDR4 funciona amb menys voltatge i pot reduir el consum d’energia.
  • Compatibilitat: DDR4 no funciona en ranures DDR3. Comprova que la placa base admeti DDR4.
  • Disponibilitat: DDR4 és més habitual en sistemes nous; pot ser més difícil trobar DDR3.

Si la placa base l’admet, DDR4 és una bona elecció per rendiment, eficiència i futures actualitzacions.

Determinar la quantitat de RAM adequada #

La RAM (Random Access Memory) és un component essencial del PC que desa les dades que l’ordinador fa servir activament.

  • Considera l’ús: 8GB poden ser suficients per navegar, consultar el correu i fer tasques bàsiques d’oficina. Els jugadors i els professionals que fan edició de vídeo o renderitzat 3D poden necessitar 16GB o 32GB.
  • Preparació per al futur: si conservaràs el PC durant anys, considera més RAM per afrontar les demandes creixents del programari i les aplicacions.
  • Requisits del sistema operatiu: consulta la RAM recomanada per al sistema que faràs servir i assegura’t que n’hi hagi prou perquè funcioni amb fluïdesa.
  • Pressupost: els preus de la RAM varien. Ajusta’n la quantitat al pressupost i busca ofertes abans de comprar.
  • Possibilitat d’actualització: les ranures lliures a la placa base poden facilitar una ampliació futura. Amb poques ranures o en un portàtil, actualitzar pot ser difícil o impossible.

Considera les necessitats, els plans futurs, el sistema operatiu, el pressupost i la possibilitat d’ampliar per triar la quantitat adequada de RAM i mantenir el PC àgil.

Triar la millor solució d’emmagatzematge #

Explorar els diferents tipus d’unitats #

Cada tipus d’unitat d’emmagatzematge té avantatges i aspectes a considerar:

  • Discs durs (HDD): ofereixen més capacitat per un cost inferior per gigabyte. Són útils per desar fitxers grans i aplicacions.
  • Unitats d’estat sòlid (SSD): són més ràpides i fiables que les HDD. La memòria flaix accelera l’arrencada i el rendiment del sistema.
  • Unitats NVMe: són una de les opcions més ràpides. Es connecten directament a la placa base per PCIe i transfereixen dades a gran velocitat.

Considera el pressupost, l’espai i el rendiment necessaris. Les SSD i les NVMe són recomanables per a sistemes ràpids; les HDD són econòmiques quan vols molta capacitat.

Comparar SSD i HDD #

Triar entre SSD i HDD és una decisió important. Les SSD llegeixen i escriuen dades més de pressa, de manera que l’arrencada i la transferència de fitxers són més ràpides. En canvi, les HDD ofereixen més capacitat per un cost inferior per gigabyte.

  • Velocitat: les SSD són molt més ràpides i útils per a jocs i edició de vídeo.
  • Capacitat: les HDD ofereixen més espai per a fitxers grans, pel·lícules i col·leccions de música.
  • Durabilitat: les SSD no tenen peces mòbils, cosa que redueix el risc de dany físic o avaria.
  • Preu: les HDD solen ser més assequibles, sobretot amb capacitats grans.

Valora les necessitats i el pressupost per decidir si la velocitat i la durabilitat d’una SSD compensen el preu o si t’encaixen més l’espai i el cost d’una HDD.

Determinar la capacitat d’emmagatzematge necessària #

La capacitat d’emmagatzematge és la quantitat de dades que una unitat pot desar.

  • Ús: navegar i editar documents pot requerir poca capacitat. Els fitxers grans i les biblioteques multimèdia necessiten més espai.
  • Sistema operatiu i programari: considera l’espai que ocupen el sistema i les aplicacions. Els jocs i els programes d’edició de vídeo poden consumir-ne molt.
  • Ampliació futura: si preveus necessitar més espai, tria ara una unitat més gran per evitar haver-la d’actualitzar després.
  • Pressupost: les capacitats més grans acostumen a costar més. Equilibra les necessitats amb el pressupost.

Tria prou espai per a les teves necessitats sense pagar per capacitat que no faràs servir.

Triar la font d’alimentació adequada #

Entendre l’eficiència de la font #

L’eficiència indica amb quina eficàcia la font converteix el corrent AC de la presa en corrent DC per als components. Una qualificació més alta implica menys energia malbaratada i una factura elèctrica inferior.

  • L’eficiència s’expressa normalment en percentatge; un percentatge més alt indica una eficiència superior.
  • 80 Plus és un estàndard conegut amb nivells com 80 Plus, Bronze, Silver, Gold, Platinum i Titanium.
  • Una font més eficient pot reduir costos a llarg termini i l’impacte ambiental.

No passis per alt l’eficiència quan triïs una font. Afecta el consum energètic i el rendiment del PC.

Considerar la potència i el disseny modular #

Quan triïs una font, considera la potència i si vols un disseny modular o no modular. La potència indica quanta energia pot subministrar la font als components.

  • Les fonts de més potència són recomanables per a PC de jocs o sistemes amb components de gamma alta.
  • Les fonts modulars permeten connectar només els cables necessaris, cosa que redueix l’embolic i millora el flux d’aire.
  • Les fonts no modulars porten tots els cables connectats i poden ser més difícils d’endreçar.

Tria una font que satisfaci les necessitats dels components i considera com vols gestionar els cables. Calcula el consum i tria prou potència i el nivell de modularitat adequat.

Determinar la font adequada per al PC #

La potència és una de les especificacions més importants, perquè determina l’energia que arriba als components. Tria una font que cobreixi les necessitats del PC, incloent-hi l’overclocking i les actualitzacions futures. Considera també l’eficiència, que redueix l’energia malbaratada.

  • Calcula les necessitats de CPU, targeta gràfica i perifèrics. Les calculadores de fonts en línia poden ajudar.
  • Tria una potència superior a la calculada per permetre actualitzacions i mantenir l’estabilitat.
  • Busca la certificació 80 Plus, que indica una eficiència més alta.
  • Decideix entre un disseny modular i un de no modular. El modular redueix els cables i millora el flux d’aire.

Consell: inverteix en una font d’alta qualitat d’una marca de confiança per guanyar fiabilitat i durada.

Segueix aquests criteris per triar la font adequada i mantenir el rendiment i l’estabilitat del PC.

Triar la caixa adequada #

Explorar les mides i els formats de caixa #

Les caixes tenen mides i formats diferents, cadascun amb avantatges i limitacions:

  • ATX: el format més comú, amb espai ampli per als components i l’expansió. Adequat per a la majoria de muntatges.
  • Micro-ATX: més petit que ATX, però encara ofereix prou espai. És una bona opció per a muntatges compactes.
  • Mini-ITX: el format més petit, ideal per a muntatges reduïts i amb poc espai.

Considera la mida dels components i l’espai disponible. Pensa en les ranures d’expansió i les badies d’unitat necessàries. Tria una caixa que pugui contenir tots els components i permeti un flux d’aire adequat.

Consell: comprova les dimensions i les especificacions abans de comprar per garantir la compatibilitat.

Considerar el flux d’aire i les opcions de refrigeració #

El flux d’aire i la refrigeració ajuden a mantenir el rendiment i evitar el sobreescalfament. El flux d’aire és el moviment de l’aire dins la caixa. Les opcions de refrigeració són els mètodes per dissipar la calor dels components.

  • Un flux d’aire adequat és essencial. Instal·la prou ventiladors d’entrada i de sortida per fer circular l’aire per la caixa.
  • La gestió dels cables influeix en el flux d’aire. Endreça els cables i aparta’ls del recorregut de l’aire.
  • Considera la posició dels components. Situar amb criteri el refrigerador de CPU, la targeta gràfica i altres peces que generen calor pot optimitzar el flux.

Consell: la pols acumulada pot obstruir el flux d’aire i causar sobreescalfament. Neteja el PC regularment i fes servir filtres antipols.

Mantenir un flux d’aire i una refrigeració adequats ajuda a allargar la vida útil i el rendiment del PC.

Determinar la caixa adequada per al muntatge #

La mida determina l’espai per als components i el volum total del PC. Les caixes petites són bones per a muntatges compactes; les grans ofereixen més marge d’ampliació.

El flux d’aire també és important per mantenir els components frescos i evitar el sobreescalfament. Busca caixes amb ventilació suficient i llocs per instal·lar ventiladors. Considera també l’aspecte i tria una caixa que encaixi amb el teu estil i espai.

  • Factor de forma: tria una caixa compatible amb el factor de forma de la placa base.
  • Ranures d’expansió: comprova que n’hi hagi prou per a les teves necessitats.
  • Gestió dels cables: busca opcions per mantenir el muntatge endreçat.
  • Badies d’unitat: considera’n el nombre i els tipus disponibles.

Consell: comprova l’alçada màxima del refrigerador de CPU i la llargada màxima de GPU que admet la caixa.

Triar la solució de refrigeració adequada #

Entendre els mètodes de refrigeració de la CPU #

Hi ha diversos mètodes per refredar la CPU, cadascun amb avantatges i aspectes a considerar:

  1. Refrigeració per aire: el mètode més comú i assequible. Un dissipador i un ventilador allunyen la calor de la CPU. És eficaç per a la majoria de muntatges i relativament fàcil d’instal·lar.
  2. Refrigeració líquida: utilitza un circuit tancat que fa circular el refrigerant al voltant de la CPU. És més eficient i controla millor la temperatura. És popular entre els entusiastes i els qui fan overclocking.
  3. Refrigeració híbrida: combina refrigeració per aire i líquida per millorar el rendiment i reduir el soroll.

Considera el pressupost, el nivell d’overclocking previst i la mida de la caixa. Comprova la compatibilitat amb el sòcol de la CPU i la placa base. Instal·la i mantén correctament la solució triada.

Comparar la refrigeració per aire i la líquida #

Les dues opcions principals són la refrigeració per aire i la refrigeració líquida. Cadascuna té avantatges i aspectes a considerar.

La refrigeració per aire és habitual i assequible. Els ventiladors dissipen la calor de la CPU i altres components. És fàcil d’instal·lar i mantenir, i és suficient per a la majoria de PC. Però pot ocupar força espai i ser menys eficaç amb overclocking extrem.

La refrigeració líquida utilitza un líquid per allunyar la calor de la CPU. Pot oferir més rendiment, sobretot en sistemes de gamma alta o amb CPU accelerades. Sol ser més cara i cal comprovar el nivell del refrigerant i possibles fuites.

  • La refrigeració per aire acostuma a ser més econòmica i fàcil d’instal·lar; la líquida ofereix més rendiment tèrmic.
  • Els refrigeradors per aire solen ser més silenciosos perquè no tenen bombes ni altres peces mòbils.
  • Els refrigeradors líquids poden tenir un aspecte atractiu, amb il·luminació RGB i disseny elegant.
  • La refrigeració líquida requereix més manteniment i pot fallar per fuites o avaries de la bomba.

Tria segons les teves necessitats. La refrigeració per aire és una opció senzilla i econòmica. La líquida pot servir si vols més rendiment i acceptes el cost i la complexitat addicionals.

Triar el sistema operatiu ideal #

Explorar els diferents sistemes operatius #

Hi ha diversos sistemes operatius per a PC, cadascun amb punts forts i febles. Entén què necessites abans de triar.

Windows: el sistema més popular, conegut per una interfície fàcil d’utilitzar i una àmplia compatibilitat amb programari. És adequat per jugar i treballar.

macOS: dissenyat per als ordinadors Apple. S’integra bé amb altres dispositius Apple i ofereix una interfície senzilla i intuïtiva. És conegut per l’estabilitat i la seguretat.

Linux: sistema de codi obert, flexible i personalitzable. És popular entre desenvolupadors i usuaris avançats que prefereixen la línia d’ordres o necessiten programari específic.

Considera la compatibilitat del programari, la interfície que prefereixes i les necessitats del teu PC.

Comparar Windows, macOS i Linux #

Windows, macOS i Linux tenen avantatges i limitacions diferents.

Windows és molt utilitzat i ofereix una interfície familiar. La seva àmplia biblioteca de programes i jocs el fa popular entre jugadors i usuaris en general. Però és vulnerable a virus i programari maliciós, així que aplica mesures de seguretat adequades.

macOS s’utilitza exclusivament en ordinadors Apple. Té un disseny elegant, una interfície intuïtiva i s’integra amb altres dispositius Apple. És conegut per l’estabilitat i la seguretat, però ofereix menys opcions de programari que Windows.

Linux és de codi obert i ofereix molt control i personalització. Els desenvolupadors i els usuaris avançats en valoren l’estabilitat, la seguretat i la varietat de programari. Configurar-lo i fer-lo servir pot requerir més coneixements tècnics.

Determinar el sistema adequat a les teves necessitats #

Considera diversos factors quan triïs OS:

  • Explorar sistemes operatius: investiga les funcions i capacitats de Windows, macOS, Linux i altres sistemes.
  • Comparar Windows, macOS i Linux: avalua la compatibilitat, la interfície, la disponibilitat de programari i la personalització.
  • Triar l’OS per a les teves necessitats: pensa si jugues, crees contingut o treballes en un àmbit específic. Tria el sistema adequat a les tasques.

El sistema operatiu és la base del PC. Tria amb cura per tenir una experiència estable i fluida.

Triar els perifèrics adequats #

Entendre la importància d’un bon teclat i ratolí #

Un bon teclat i ratolí ajuden a treballar còmodament i amb productivitat. El teclat serveix per escriure i executar ordres. El ratolí permet controlar el cursor amb precisió i navegar.

  • Ergonomia: tria dispositius que redueixin la tensió i mantinguin les mans en una posició natural.
  • Teclats mecànics o de membrana: els mecànics ofereixen resposta tàctil i durabilitat; els de membrana són més silenciosos i econòmics.
  • Amb cable o sense fil: els dispositius amb cable ofereixen connexió fiable i no necessiten piles. Els sense fil donen flexibilitat i un espai ordenat.

Consell: considera comprar un conjunt de teclat i ratolí per tenir una experiència coordinada.

Els perifèrics adequats poden augmentar la productivitat i la comoditat en fer servir el PC.

Considerar la mida i la resolució del monitor #

Quan triïs un monitor, considera la mida i la resolució. La mida indica les dimensions físiques; la resolució, el nombre de píxels que mostra.

  • Mida: un monitor més gran ofereix una experiència més immersiva, però ocupa més espai a l’escriptori.
  • Resolució: resolucions altes com 4K o QHD mostren imatges més nítides i detallades, però poden requerir maquinari més potent.

Equilibra mida i resolució amb les necessitats i el pressupost. El monitor adequat millora els jocs, el disseny gràfic i la productivitat.

Consell: si no saps quina mida i resolució triar, consulta ressenyes en línia o demana consell a persones amb experiència muntant PC.

Determinar els perifèrics adequats per a la configuració #

Considera la compatibilitat dels perifèrics amb el sistema operatiu i els altres components. No ignoris l’ergonomia, perquè els dispositius còmodes milloren l’experiència.

  1. Teclat i ratolí: tria models còmodes per a períodes llargs. Considera interruptors mecànics, DPI ajustable i botons programables.
  2. Monitor: tria la mida, la resolució i la freqüència d’actualització segons les necessitats. Considera HDR, G-Sync o FreeSync.
  3. Àudio: uns bons auriculars o altaveus milloren els jocs i el contingut multimèdia. Busca so envoltant, cancel·lació de soroll i EQ ajustable.
  4. Càmera web: si fas videoconferències o emissions en directe, una càmera web de qualitat ofereix una imatge nítida.

Els perifèrics adequats milloren la productivitat i el gaudi del PC. Investiga les opcions i tria amb cura.

Preguntes freqüents #

1. Puc combinar components Intel i AMD al meu PC? #

No. Els components Intel i AMD no són compatibles entre si. Tria un processador Intel amb una placa base compatible o un processador AMD amb una placa base compatible.

2. Quanta RAM necessito per jugar? #

La quantitat depèn dels jocs i dels requisits generals del sistema. Entre 8GB i 16GB solen ser suficients per a la majoria de PC de jocs.

3. Quina diferència hi ha entre SSD i HDD? #

SSD (Solid State Drive) és més ràpid i fiable que HDD (Hard Disk Drive). Les SSD fan servir memòria flaix; les HDD fan servir discs giratoris. Les SSD costen més, però acceleren l’arrencada i la transferència de dades.

4. Puc actualitzar la targeta gràfica més endavant? #

Sí, sempre que la placa base tingui una ranura d’expansió compatible i la font pugui cobrir les necessitats energètiques de la nova targeta.

5. Quin sistema operatiu és millor per jugar? #

Windows és el més popular per als jocs per la seva àmplia compatibilitat amb jocs i maquinari de joc. Linux i macOS també poden executar jocs i admeten cada vegada més títols.

6. Necessito un refrigerador de CPU addicional? #

Depèn de la CPU i de l’ús previst. El refrigerador inclòs acostuma a ser suficient per a l’ús general i per a CPUs sense overclocking. Un refrigerador addicional pot reduir la temperatura si fas overclocking o tens una CPU d’alt rendiment.
