Инструмент с открытым исходным кодом для повышения осведомлённости о слежке, картирующий камеры ALPR Flock Safety с помощью краудсорсинговых данных WiFi.

Что такое Flock Finder? #

Flock Finder — это проект с открытым исходным кодом, картирующий камеры ALPR (автоматического распознавания номерных знаков) Flock Safety по всей территории США и в 108 других странах. Он сочетает 31 известный WiFi-префикс OUI (организационно уникальный идентификатор) Flock Safety с краудсорсинговой базой данных WiFi WiGLE для выявления и отображения предполагаемых местоположений камер на интерактивной карте.

Проект размещён по адресу github.com/simeononsecurity/flock-finder , автоматически обновляется ежедневно с помощью GitHub Actions и по состоянию на июль 2026 года нанёс на карту более 40 000 предполагаемых камер в 964 регионах мира.

Принцип работы: OUI-отпечатки через WiGLE #

Ключевая идея #

Камеры Flock Safety содержат WiFi-трансиверы, которые периодически выходят из режима сна для загрузки захваченных данных о номерных знаках в облако. В эти короткие активные периоды камера транслирует WiFi-кадры, содержащие её MAC-адрес — а первые три байта каждого MAC-адреса идентифицируют производителя. Это и есть OUI (организационно уникальный идентификатор).

Исследователь безопасности @NitekryDPaul обнаружил 30 OUI-префиксов, постоянно связанных с аппаратным обеспечением камер Flock Safety, с помощью анализа в неразборчивом режиме на частоте 2,4 ГГц. 31-й префикс (82:6B:F2) был предоставлен Michael / DeFlockJoplin во время полевых испытаний в Джоплине, штат Миссури.

Flock Finder берёт эти 31 OUI, запрашивает WiGLE на предмет любых зафиксированных WiFi-сетей, соответствующих этим префиксам, и отображает результаты на карте.

Техника обнаружения addr1 #

Ключевое открытие @NitekryDPaul выходит за рамки простого сопоставления по MAC-адресу передатчика. Камеры Flock проводят большую часть своего рабочего цикла в спящем режиме. Когда соседняя точка доступа отправляет кадр, адресованный к камере, MAC-адрес камеры появляется как addr1 (адрес получателя) в кадрах 802.11 — даже пока сама камера не ведёт активную передачу.

В сочетании с обнаружением wildcard-запросов зондирования (управляющие кадры 802.11 тип=0, подтип=4, пустой SSID) это даёт очень точную сигнатуру обнаружения. Полевые испытания в Джоплине, штат Миссури, позволили обнаружить 11 из 12 камер при всего 2 ложных срабатываниях.

⚠️ Важно: Карта Flock Finder на основе WiGLE не реализует технику addr1. WiGLE — это исторический, пассивно собранный набор данных — он фиксирует только передатчики, но не приёмники. Для обнаружения в реальном времени с использованием метода @NitekryDPaul вам нужно специализированное оборудование, работающее в полевых условиях.

Ключевые ограничения #

Воспринимайте карту критически. WiGLE — это краудсорсинговый, нерегулярно обновляемый набор данных, а не живой поток.

  • Камеры Flock не транслируют непрерывно. Они кратковременно активируются для загрузки данных, поэтому записи WiGLE полностью зависят от того, находился ли водрайвер рядом именно в нужный момент.
  • Данные могут быть устаревшими на месяцы или годы. Камеры, перемещённые или удалённые, могут по-прежнему отображаться.
  • Сопоставление OUI — это эвристика. OUI могут быть общими, переназначенными или подделанными. Каждый результат — это предполагаемое устройство Flock, а не подтверждённое.
  • Охват неравномерен. В густонаселённых городских районах больше данных WiGLE; в сельских районах значительно меньше.

Используйте карту для общего представления о плотности слежки в вашем районе. Для получения достоверных данных в реальном времени смотрите аппаратные варианты ниже.

Самостоятельный запуск Flock Finder #

Предварительные требования #

  • Python 3.8+
  • Бесплатный аккаунт WiGLE с учётными данными API

Настройка # 

# Clone the repository
git clone https://github.com/simeononsecurity/flock-finder.git
cd flock-finder

# Install dependencies
pip install -r requirements.txt

# Set up your WiGLE API credentials
cp .env.example .env
# Edit .env with your WiGLE API Name and Token

Запуск сканера # 

# Full scan — all 31 OUI prefixes, worldwide
python3 scripts/wigle_query.py

# Single OUI test
python3 scripts/wigle_query.py --oui 70:C9:4E

# US only
python3 scripts/wigle_query.py --country US

# Specific bounding box (lat1,lon1,lat2,lon2)
python3 scripts/wigle_query.py --bbox 37,-97,39,-94

# Dry run — verify auth, no API queries
python3 scripts/wigle_query.py --dry-run

Локальный просмотр карты # 

python3 -m http.server 8080 --directory docs/
# Open http://localhost:8080 in your browser

Автоматические ежедневные обновления через GitHub Actions #

Сделайте форк репозитория и добавьте свои учётные данные WiGLE как секреты репозитория (WIGLE_API_NAME и WIGLE_API_TOKEN). Включённый рабочий процесс запускается ежедневно в 6:00 UTC и автоматически фиксирует обновлённые файлы данных при обнаружении новых камер.

Часто задаваемые вопросы #

Это законно? #

Да. Flock Finder использует только общедоступные данные из базы данных WiGLE, которая агрегирует добровольно предоставленные данные WiFi-съёмки. Никакого взлома, несанкционированного доступа или проприетарных систем не задействовано. Пассивный мониторинг WiFi для обнаружения OUI-сигнатур является законным в Соединённых Штатах.

Действительно ли каждая нанесённая на карту камера является камерой Flock? #

Нет. Сопоставление OUI — это эвристика. OUI-префиксы могут быть общими для нескольких производителей, переназначенными или поддельными. Каждая запись в базе данных — это предполагаемое устройство Flock — не подтверждённое. Прочитайте Политику данных для получения подробной информации о том, как запросить исправление.

Почему некоторые OUI-префиксы не показывают камер? #

Охват WiGLE неравномерен. Если ни один водрайвер не сканировал данную область с этим конкретным активным OUI, записей не будет. Отсутствие данных не означает отсутствия камер.

Насколько актуальны данные? #

Рабочий процесс GitHub Actions запускается ежедневно и получает последние результаты WiGLE. Однако сам WiGLE может иметь записи от нескольких дней до нескольких лет для любого конкретного местоположения. Проверьте файл scan_stats.json на наличие временной метки последнего сканирования.

Могу ли я вносить свои данные о вардрайве? #

Да. Загрузите данные своего вардрайва в WiGLE — они автоматически попадут в следующее ежедневное сканирование Flock Finder. Вы также можете вносить OUI-префиксы или улучшения кода через Руководство по участию .
