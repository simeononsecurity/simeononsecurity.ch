ਜਾਣ-ਪਛਾਣ: ਹੈਕਰਾਂ ਦਾ ਹੌਟਸਪੌਟ #

DagShell, Orbic RCL400 ਮੋਬਾਈਲ ਹੌਟਸਪੌਟ ਲਈ ਓਪਨ-ਸੋਰਸ ਕਸਟਮ ਫਰਮਵੇਅਰ ਹੈ। ਇਹ ਆਮ ਸੈਲੂਲਰ ਡਿਵਾਈਸ ਨੂੰ ਪੋਰਟੇਬਲ ਸੁਰੱਖਿਆ ਖੋਜ ਅਤੇ ਗੋਪਨੀਯਤਾ ਟੂਲਕਿੱਟ ਵਿੱਚ ਬਦਲਦਾ ਹੈ। ਸੁਰੱਖਿਆ ਖੋਜਕਾਰ “dag” ਵੱਲੋਂ ਬਣਾਇਆ ਇਹ ਟਰਮੀਨਲ-ਸ਼ੈਲੀ ਫਰਮਵੇਅਰ ਹਰੇ-ਕਾਲੇ ਹੈਕਰ ਇੰਟਰਫੇਸ ਵਿੱਚ ਹੈਕਿੰਗ ਟੂਲ, ਗੋਪਨੀਯਤਾ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਅਤੇ ਨੈੱਟਵਰਕ ਨਿਗਰਾਨੀ ਦਿੰਦਾ ਹੈ।

ਇਸ ਵਿਸਤ੍ਰਿਤ ਗਾਈਡ ਵਿੱਚ ਇਹ ਸ਼ਾਮਲ ਹੈ:

  • DagShell ਕੀ ਹੈ ਅਤੇ ਇਸ ਦੀਆਂ ਸਾਰੀਆਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ
  • ਕਦਮ-ਦਰ-ਕਦਮ ਇੰਸਟਾਲੇਸ਼ਨ (ਵੈੱਬ ਫਲੈਸ਼ਰ ਅਤੇ ਹੱਥੀਂ ਤਰੀਕੇ)
  • ਸਾਰੇ ਟੂਲ ਅਤੇ ਉਨ੍ਹਾਂ ਦੀਆਂ ਸਮਰੱਥਾਵਾਂ
  • ਵਾਧੂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਲਈ Raspberry Pi ਸਾਥੀ ਸੈੱਟਅੱਪ
  • ਮੋਬਾਈਲ ਸੁਰੱਖਿਆ ਲਈ DagShell ਨੂੰ RayHunter ਨਾਲ ਜੋੜਨ ਦਾ ਕਾਰਨ
  • ਸੁਰੱਖਿਆ ਖੋਜਕਾਰਾਂ ਅਤੇ ਗੋਪਨੀਯਤਾ ਸਮਰਥਕਾਂ ਲਈ ਅਸਲ ਵਰਤੋਂ ਦੇ ਮਾਮਲੇ
  • ਕਾਨੂੰਨੀ ਅਤੇ ਨੈਤਿਕ ਵਿਚਾਰ

DagShell ਕੀ ਹੈ? #

ਝਲਕ #

DagShell ਓਪਨ-ਸੋਰਸ ਕਸਟਮ ਫਰਮਵੇਅਰ ਹੈ, ਜੋ Orbic RCL400 ਦੇ ਮੂਲ ਵੈੱਬ ਇੰਟਰਫੇਸ ਦੀ ਥਾਂ ਸੁਰੱਖਿਆ ਟੂਲਕਿੱਟ ਦਿੰਦਾ ਹੈ। ਇਸ ਵਿੱਚ ਸ਼ਾਮਲ ਹਨ:

  • ASCII ਕਲਾ ਅਤੇ ਹੈਕਰ ਦਿੱਖ ਵਾਲਾ ਟਰਮੀਨਲ-ਸ਼ੈਲੀ ਇੰਟਰਫੇਸ
  • TLS 1.2+ ਇਨਕ੍ਰਿਪਸ਼ਨ ਵਾਲਾ ਵੈੱਬ ਇੰਟਰਫੇਸ (ਆਪਣੇ ਦਸਤਖ਼ਤ ਵਾਲਾ ਸਰਟੀਫਿਕੇਟ)
  • ਗੋਪਨੀਯਤਾ ਸੁਰੱਖਿਆ ਟੂਲ (TTL ਮਾਸਕਿੰਗ, MAC ਸਪੂਫਿੰਗ, DNS ਰਾਹੀਂ ਵਿਗਿਆਪਨ ਰੋਕਣਾ)
  • ਨੈੱਟਵਰਕ ਨਿਗਰਾਨੀ (ਸਰਗਰਮ ਕਨੈਕਸ਼ਨ, ਰੂਟਿੰਗ ਟੇਬਲਾਂ, DNS ਸਵਾਲ)
  • ਹੈਕਿੰਗ ਟੂਲ (IMSI ਕੈਚਰ ਪਛਾਣ, ਪੋਰਟ ਸਕੈਨਿੰਗ, ARP ਖੋਜ)
  • ਹਮਲਾ ਕਰਨ ਦੀਆਂ ਸਮਰੱਥਾਵਾਂ (Evil Twin AP, ਕੈਪਟਿਵ ਪੋਰਟਲ ਫਿਸ਼ਿੰਗ, ਡੀ-ਆਥ ਹਮਲੇ)
  • Wigle-ਅਨੁਕੂਲ CSV ਨਿਰਯਾਤ ਨਾਲ GPS ਟ੍ਰੈਕਿੰਗ ਅਤੇ ਵਾਰਡਰਾਈਵਿੰਗ
  • GPS, Bluetooth ਸਕੈਨਿੰਗ ਅਤੇ WiFi ਜਾਂਚ ਲਈ Raspberry Pi ਸਾਥੀ
  • ਬ੍ਰਾਊਜ਼ਰ ਫਾਈਲ ਮੈਨੇਜਰ ਰਾਹੀਂ ਫਾਈਲ ਸਿਸਟਮ ਪਹੁੰਚ
  • AT ਕਮਾਂਡਾਂ ਰਾਹੀਂ SMS ਵਿਸ਼ੇਸ਼ਤਾ
  • ਸਥਾਈ ਸ਼ੁਰੂਆਤ: ਬੂਟ ਵੇਲੇ ਆਪਣੇ ਆਪ ਚੱਲਦਾ ਹੈ

  • ਹਰ ਪੰਨੇ ਉੱਤੇ ASCII ਕਲਾ ਵਾਲਾ ਲੋਗੋ
  • ਕਾਲੇ ਪਿਛੋਕੜ ਉੱਤੇ ਹਰਾ ਰੰਗ (Matrix-ਸ਼ੈਲੀ)
  • Monospace ਫੌਂਟ (Fira Code)
  • ਸਕੈਨਲਾਈਨ ਪ੍ਰਭਾਵ ਅਤੇ ਚਮਕਦਾ ਲਿਖਤ
  • ਟਰਮੀਨਲ ਤੋਂ ਪ੍ਰੇਰਿਤ ਲੇਆਉਟ

🏠 ਡੈਸ਼ਬੋਰਡ #

ਸਿਸਟਮ ਝਲਕ:

  • ਚੱਲਣ ਦਾ ਸਮਾਂ: ਡਿਵਾਈਸ ਕਿੰਨੇ ਸਮੇਂ ਤੋਂ ਚੱਲ ਰਿਹਾ ਹੈ
  • AT ਕਮਾਂਡ ਇੰਟਰਫੇਸ: ਤਜਰਬੇਕਾਰ ਵਰਤੋਂਕਾਰਾਂ ਲਈ ਸਿੱਧਾ ਮੋਡਮ ਕੰਟਰੋਲ
  • ਤੁਰੰਤ ਸਥਿਤੀ: IP ਪਤਾ ਅਤੇ ਕਨੈਕਸ਼ਨ ਦੀ ਹਾਲਤ

AT ਕਮਾਂਡਾਂ ਮੋਡਮ ਉੱਤੇ ਹੇਠਲੇ ਪੱਧਰ ਦਾ ਕੰਟਰੋਲ ਦਿੰਦੀਆਂ ਹਨ:

AT ਕਮਾਂਡਾਂ ਦੀਆਂ ਉਦਾਹਰਨਾਂ:
AT+CSQ       - ਸਿਗਨਲ ਦੀ ਗੁਣਵੱਤਾ
AT+COPS?     - ਮੌਜੂਦਾ ਨੈੱਟਵਰਕ ਆਪਰੇਟਰ
AT+CREG?     - ਨੈੱਟਵਰਕ ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਸਥਿਤੀ
AT+CIMI      - IMSI ਪ੍ਰਾਪਤ ਕਰੋ (ਗਾਹਕ ਦੀ ਪਛਾਣ)
AT+CGSN      - IMEI ਪ੍ਰਾਪਤ ਕਰੋ (ਡਿਵਾਈਸ ਪਛਾਣਕਰਤਾ)

🌐 ਨੈੱਟਵਰਕ ਟੂਲ #

ਮੌਜੂਦਾ ਨੈੱਟਵਰਕ ਜਾਣਕਾਰੀ:

  • IP ਪਤਾ ਅਤੇ ਇੰਟਰਫੇਸ ਦੇ ਵੇਰਵੇ
  • ਸਬਨੈੱਟ ਮਾਸਕ, ਗੇਟਵੇ, ਬਰਾਡਕਾਸਟ ਪਤਾ
  • ਨੈੱਟਵਰਕ ਅੰਕੜੇ (ਭੇਜੇ ਅਤੇ ਪ੍ਰਾਪਤ ਕੀਤੇ ਪੈਕੇਟ)

ਰੂਟਿੰਗ ਟੇਬਲ ਦਰਸ਼ਕ:

  • ਸਾਰੇ ਨੈੱਟਵਰਕ ਰੂਟ ਵੇਖੋ
  • ਮੂਲ ਗੇਟਵੇ ਦੀ ਜਾਣਕਾਰੀ
  • ਇੰਟਰਫੇਸਾਂ ਦੀ ਮੈਪਿੰਗ

ਸਰਗਰਮ ਕਨੈਕਸ਼ਨ ਨਿਗਰਾਨੀ:

  • ਰੀਅਲ-ਟਾਈਮ ਵਿੱਚ ਸਾਰੇ TCP/UDP ਕਨੈਕਸ਼ਨਾਂ ਦੀ ਸੂਚੀ
  • ਸਥਾਨਕ ਅਤੇ ਦੂਰਲੇ IP ਪਤੇ
  • ਪੋਰਟ ਨੰਬਰ ਅਤੇ ਕਨੈਕਸ਼ਨ ਦੀਆਂ ਸਥਿਤੀਆਂ
  • ਡਿਵਾਈਸ ਕਿਸ ਨਾਲ ਸੰਚਾਰ ਕਰਦਾ ਹੈ, ਇਹ ਨਿਗਰਾਨੀ ਕਰਨ ਲਈ ਲਾਭਦਾਇਕ

TTL ਸੁਧਾਰ #

ਉਦੇਸ਼: ਕੈਰੀਅਰ ਦੀ ਪਛਾਣ ਤੋਂ ਹੌਟਸਪੌਟ ਟ੍ਰੈਫਿਕ ਲੁਕਾਉਣਾ

ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ:

  • IP ਪੈਕੇਟਾਂ ਵਿੱਚ Time To Live (TTL) ਮੁੱਲ ਨੂੰ 65 ਕਰਦਾ ਹੈ
  • TTL ਘਟਣ ਰਾਹੀਂ ਕੈਰੀਅਰ ਟੈਦਰਿੰਗ ਪਛਾਣਦੇ ਹਨ (ਫੋਨ=64, ਟੈਦਰ ਕੀਤਾ ਡਿਵਾਈਸ=63)
  • TTL ਨੂੰ 65 ਕਰਨ ਨਾਲ ਸਾਰਾ ਟ੍ਰੈਫਿਕ ਸਥਾਨਕ ਦਿਸਦਾ ਹੈ

ਵਰਤੋਂ: ਕੈਰੀਅਰ ਦੀਆਂ ਟੈਦਰਿੰਗ ਪਾਬੰਦੀਆਂ ਜਾਂ ਗਤੀ ਸੀਮਾਵਾਂ ਤੋਂ ਬਚਣਾ

ਕਮਾਂਡਾਂ:

# TTL ਸੁਧਾਰ ਚਾਲੂ ਕਰੋ
iptables -t mangle -A POSTROUTING -j TTL --ttl-set 65

# TTL ਸੁਧਾਰ ਬੰਦ ਕਰੋ
iptables -t mangle -D POSTROUTING -j TTL --ttl-set 65

MAC ਪਤਾ ਸਪੂਫਿੰਗ #

ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ:

  • WiFi ਇੰਟਰਫੇਸ wlan0 ਦਾ MAC ਪਤਾ ਬਦਲਦਾ ਹੈ
  • ਬੇਤਰਤੀਬ MAC ਬਣਾਉਂਦਾ ਹੈ ਜਾਂ ਆਪਣਾ ਮੁੱਲ ਦਰਜ ਕਰਨ ਦਿੰਦਾ ਹੈ
  • ਵੱਖ-ਵੱਖ ਸੈਸ਼ਨਾਂ ਵਿੱਚ ਡਿਵਾਈਸ ਨੂੰ ਟ੍ਰੈਕ ਕਰਨਾ ਔਖਾ ਕਰਦਾ ਹੈ

ਵਰਤੋਂ: ਜਿਨ੍ਹਾਂ ਨੈੱਟਵਰਕਾਂ ਨਾਲ ਤੁਸੀਂ ਜੁੜਦੇ ਹੋ, ਉਨ੍ਹਾਂ ਵੱਲੋਂ MAC ਅਧਾਰਿਤ ਟ੍ਰੈਕਿੰਗ ਰੋਕਣਾ

ਪ੍ਰਕਿਰਿਆ:

  1. ਇੰਟਰਫੇਸ ਬੰਦ ਹੁੰਦਾ ਹੈ
  2. ਨਵਾਂ MAC ਪਤਾ ਲਾਗੂ ਹੁੰਦਾ ਹੈ
  3. ਇੰਟਰਫੇਸ ਮੁੜ ਚਾਲੂ ਹੁੰਦਾ ਹੈ
  4. ਕਨੈਕਸ਼ਨ ਮੁੜ ਸਥਾਪਤ ਹੁੰਦਾ ਹੈ

IMSI ਕੈਚਰ ਡਿਟੈਕਟਰ #

ਉਦੇਸ਼: ਸੈੱਲ ਟਾਵਰਾਂ ਦੀ ਜਾਣਕਾਰੀ ਵਿੱਚ ਉਹ ਅਸਧਾਰਨਤਾਵਾਂ ਵੇਖਣਾ ਜੋ IMSI ਕੈਚਰ/Stingray ਡਿਵਾਈਸਾਂ ਵੱਲ ਇਸ਼ਾਰਾ ਕਰਦੀਆਂ ਹਨ

ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ:

  • ਮੋਡਮ ਤੋਂ ਸੈੱਲ ਟਾਵਰ ਡਾਟਾ ਲੈਂਦਾ ਹੈ:
    • Cell ID (ਟਾਵਰ ਦੀ ਪਛਾਣ)
    • LAC (Location Area Code)
    • MCC/MNC (Mobile Country/Network Code)
    • ਸਿਗਨਲ ਤਾਕਤ (RSSI)
    • ਨੈੱਟਵਰਕ ਪੀੜ੍ਹੀ (2G/3G/4G)
  • ਸ਼ੱਕੀ ਟਾਵਰ ਬਦਲਾਅ ਪਛਾਣਨ ਲਈ ਬਦਲਾਅ ਲੌਗ ਕਰਦਾ ਹੈ
  • ਆਮ ਇਲਾਕਾਈ ਟਾਵਰਾਂ ਦੀ ਮੁੱਢਲੀ ਸਥਿਤੀ ਦਰਜ ਕਰਦਾ ਹੈ

ਪਛਾਣ ਦੇ ਸੰਕੇਤ:

  • ਸਥਿਰ ਰਹਿੰਦਿਆਂ ਸੈੱਲ ਟਾਵਰ ਦਾ ਅਚਾਨਕ ਬਦਲਣਾ
  • 2G ਉੱਤੇ ਘਟਣਾ (IMSI ਕੈਚਰ ਅਕਸਰ ਇਨਕ੍ਰਿਪਸ਼ਨ ਹਟਾਉਣ ਲਈ 2G ਮਜਬੂਰ ਕਰਦੇ ਹਨ)
  • ਅਣਜਾਣ Cell ID ਦਾ ਦਿਖਣਾ
  • ਨਕਲੀ ਟਾਵਰ ਤੋਂ ਕਮਜ਼ੋਰ ਸਿਗਨਲ
  • ਵਾਰ-ਵਾਰ ਮੁੜ ਕਨੈਕਸ਼ਨ

RayHunter ਨਾਲ ਸਾਂਝਾ ਕੰਮ: DagShell ਸੈੱਲ ਟਾਵਰਾਂ ਦੀ ਨਿਗਰਾਨੀ ਕਰਦਾ ਹੈ, ਜਦਕਿ RayHunter ਹੋਰ ਗਹਿਰੇ ਵਿਸ਼ਲੇਸ਼ਣ ਨਾਲ IMSI ਕੈਚਰਾਂ ਦੀ ਖ਼ਾਸ ਪਛਾਣ ਕਰਦਾ ਹੈ (ਹੇਠਾਂ ਭਾਗ ਵੇਖੋ)।

ਪੋਰਟ ਸਕੈਨਰ #

ਉਦੇਸ਼: ਖੁੱਲ੍ਹੇ ਪੋਰਟ ਲੱਭਣ ਲਈ ਨਿਸ਼ਾਨਾ IP ਪਤਿਆਂ ਨੂੰ ਸਕੈਨ ਕਰਨਾ

ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ:

  • TCP SYN ਸਕੈਨਿੰਗ: ਨਿਸ਼ਾਨਾ ਪੋਰਟਾਂ ਵੱਲ SYN ਪੈਕੇਟ ਭੇਜਦਾ ਹੈ
  • ਟਾਈਮਆਉਟ ਪਛਾਣ: ਖੁੱਲ੍ਹਾ, ਬੰਦ ਜਾਂ ਫਿਲਟਰ ਕੀਤਾ ਪੋਰਟ ਪਛਾਣਦਾ ਹੈ
  • ਰੇਂਜ ਸਹਾਇਤਾ: ਇਕ ਪੋਰਟ ਜਾਂ ਪੋਰਟਾਂ ਦੀ ਰੇਂਜ ਸਕੈਨ ਕਰੋ

ਵਰਤੋਂ:

  • ਨੈੱਟਵਰਕ ਰੀਕਾਨੈਸੈਂਸ
  • IoT ਡਿਵਾਈਸ ਖੋਜ
  • ਸਥਾਨਕ ਨੈੱਟਵਰਕਾਂ ਦਾ ਸੁਰੱਖਿਆ ਆਡਿਟ
  • ਸੇਵਾਵਾਂ ਦੀ ਪਛਾਣ

ਕਮਾਂਡ:

# target ਉੱਤੇ ਪੋਰਟ 1–1000 ਸਕੈਨ ਕਰੋ
nc -zv -w 2 TARGET_IP 1-1000 2>&1

ਫਾਇਰਵਾਲ ਮੈਨੇਜਰ #

ਉਦੇਸ਼: iptables ਰਾਹੀਂ IP ਪਤੇ ਰੋਕਣ ਜਾਂ ਮੁੜ ਖੋਲ੍ਹਣੇ

ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ:

  • ਦਿੱਤੇ IP ਤੋਂ ਜਾਂ ਵੱਲ ਆਉਂਦੇ ਪੈਕੇਟ DROP ਕਰਨ ਲਈ iptables ਨਿਯਮ
  • ਸੰਭਾਲੇ ਹੋਣ ਉੱਤੇ ਸਥਾਈ ਨਿਯਮ ਰੀਬੂਟ ਤੋਂ ਬਾਅਦ ਵੀ ਲਾਗੂ ਰਹਿੰਦੇ ਹਨ
  • ਵਾਈਟਲਿਸਟ/ਬਲੈਕਲਿਸਟ ਵਿਸ਼ੇਸ਼ਤਾ

ਵਰਤੋਂ:

  • ਖ਼ਤਰਨਾਕ IP ਰੋਕੋ
  • ਬਿਨਾਂ ਇਜਾਜ਼ਤ ਪਹੁੰਚ ਰੋਕੋ
  • ਟ੍ਰੈਫਿਕ ਨੂੰ ਤਰਜੀਹ ਦੇਣਾ ਜਾਂ ਫਿਲਟਰ ਕਰਨਾ
  • ਮਾਪਿਆਂ ਦੇ ਕੰਟਰੋਲ

ਕਮਾਂਡਾਂ:

# IP ਬਲਾਕ ਕਰੋ
iptables -I INPUT -s IP_ADDRESS -j DROP
iptables -I OUTPUT -d IP_ADDRESS -j DROP

# IP ਅਨਬਲੌਕ ਕਰੋ
iptables -D INPUT -s IP_ADDRESS -j DROP
iptables -D OUTPUT -d IP_ADDRESS -j DROP

⚔️ ਹਮਲਾ ਟੂਲ #

ਮਹੱਤਵਪੂਰਨ ਕਾਨੂੰਨੀ ਸੂਚਨਾ: ਇਹ ਟੂਲ ਸਿਰਫ਼ ਅਧਿਕਾਰਤ ਸੁਰੱਖਿਆ ਟੈਸਟਿੰਗ ਲਈ ਹਨ। ਜਿਨ੍ਹਾਂ ਨੈੱਟਵਰਕਾਂ ਦੇ ਤੁਸੀਂ ਮਾਲਕ ਨਹੀਂ ਜਾਂ ਜਿਨ੍ਹਾਂ ਦੀ ਲਿਖਤੀ ਇਜਾਜ਼ਤ ਨਹੀਂ, ਉਨ੍ਹਾਂ ਉੱਤੇ ਵਰਤਣਾ ਜ਼ਿਆਦਾਤਰ ਖੇਤਰਾਂ ਵਿੱਚ ਗੈਰਕਾਨੂੰਨੀ ਹੈ (ਅਮਰੀਕਾ ਦਾ Computer Fraud and Abuse Act (ਕੰਪਿਊਟਰ ਧੋਖਾਧੜੀ ਅਤੇ ਦੁਰਵਰਤੋਂ ਕਾਨੂੰਨ), ਬ੍ਰਿਟੇਨ ਦਾ Computer Misuse Act (ਕੰਪਿਊਟਰ ਦੀ ਦੁਰਵਰਤੋਂ ਕਾਨੂੰਨ) ਆਦਿ)। ਇਨ੍ਹਾਂ ਨੂੰ ਸਿਰਫ਼ ਆਪਣੇ ਨੈੱਟਵਰਕਾਂ ਜਾਂ ਨਿਯੰਤਰਿਤ ਲੈਬ ਮਾਹੌਲ ਵਿੱਚ ਵਰਤੋ।

DNS ਸਨਿਫ਼ਰ #

ਉਦੇਸ਼: ਜੁੜੇ ਕਲਾਇੰਟਾਂ ਦੇ DNS ਸਵਾਲ ਲੌਗ ਕਰਨਾ

ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ:

  • DNS ਪੋਰਟ 53 ਉੱਤੇ iptables ਲੌਗਿੰਗ
  • ਨੈੱਟਵਰਕ ਇੰਟਰਫੇਸ ਉੱਤੇ ਆਉਣ ਵਾਲੇ ਸਾਰੇ ਫਰੇਮ ਸੁਣਨ ਵਾਲੇ ਮੋਡ ਦੀ ਲੋੜ ਨਹੀਂ
  • ਹੌਟਸਪੌਟ ਕਲਾਇੰਟਾਂ ਦੀਆਂ ਸਾਰੀਆਂ DNS ਬੇਨਤੀਆਂ ਲੌਗ ਕਰਦਾ ਹੈ
  • ਕਲਾਇੰਟ ਕਿਹੜੀਆਂ ਵੈੱਬਸਾਈਟਾਂ ਜਾਂ ਸੇਵਾਵਾਂ ਖੋਲ੍ਹ ਰਹੇ ਹਨ, ਇਹ ਦਿਖਾਉਂਦਾ ਹੈ

ਵਰਤੋਂ (ਅਧਿਕਾਰਤ):

  • ਨੈੱਟਵਰਕ ਟ੍ਰੈਫਿਕ ਵਿਸ਼ਲੇਸ਼ਣ
  • ਮਾਪਿਆਂ ਦੀ ਨਿਗਰਾਨੀ (ਆਪਣੇ ਪਰਿਵਾਰ ਲਈ)
  • ਆਪਣੇ ਡਿਵਾਈਸਾਂ ਉੱਤੇ ਸੁਰੱਖਿਆ ਖੋਜ
  • ਮੈਲਵੇਅਰ ਵਿਹਾਰ ਵਿਸ਼ਲੇਸ਼ਣ

ਇਹ ਜੁੜੇ ਕਲਾਇੰਟਾਂ ਤੋਂ ਮੈਟਾਡਾਟਾ (ਖੋਲ੍ਹੇ ਡੋਮੇਨ) ਇਕੱਠਾ ਕਰਦਾ ਹੈ। ਇਸ ਨੂੰ ਸਿਰਫ਼ ਆਪਣੇ ਜਾਂ ਆਪਣੇ ਪ੍ਰਬੰਧ ਹੇਠਲੇ ਨੈੱਟਵਰਕਾਂ ਉੱਤੇ ਲਾਗੂ ਕਰੋ।

  • OUI ਖੋਜ ਨਿਰਮਾਤਾ ਦੀ ਪਛਾਣ ਕਰਦੀ ਹੈ (Apple, Samsung ਆਦਿ)
  • ਸਰਗਰਮ ਡਿਵਾਈਸਾਂ ਦਾ ਨੈੱਟਵਰਕ ਨਕਸ਼ਾ ਬਣਾਉਂਦਾ ਹੈ

ਵਰਤੋਂ:

  • ਨੈੱਟਵਰਕ ਸੂਚੀ
  • ਅਣਜਾਣ ਡਿਵਾਈਸ ਪਛਾਣ

Traceroute #

ਉਦੇਸ਼: ਮੰਜ਼ਿਲ ਤੱਕ ਨੈੱਟਵਰਕ ਰਸਤਾ ਦਿਖਾਉਣਾ

ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ:

  • ਵਧਦੇ TTL ਵਾਲੇ ਪੈਕੇਟ ਭੇਜਦਾ ਹੈ
  • ਹਰ hop TTL ਘਟਾਉਂਦਾ ਹੈ ਅਤੇ ICMP Time Exceeded ਜਵਾਬ ਦਿੰਦਾ ਹੈ
  • ਮੰਜ਼ਿਲ ਤੱਕ ਦੇ ਰਾਊਟਰ ਅਤੇ ਰਸਤਾ ਦਿਖਾਉਂਦਾ ਹੈ
  • ਹਰ hop ਲਈ Round-Trip Time (RTT) ਮਾਪਦਾ ਹੈ

ਵਰਤੋਂ:

  • ਨੈੱਟਵਰਕ ਸਮੱਸਿਆ ਹੱਲ
  • ਰਸਤੇ ਦਾ ਵਿਸ਼ਲੇਸ਼ਣ
  • ਲੈਟੈਂਸੀ ਦੀ ਜਾਂਚ
  • ISP ਪੀਅਰਿੰਗ ਦੀ ਜਾਂਚ

WiFi ਸਕੈਨਿੰਗ #

ਉਦੇਸ਼: Pi WiFi ਨੈੱਟਵਰਕ ਸਕੈਨ ਕਰਦਾ ਹੈ ਅਤੇ ਡਾਟਾ Orbic ਨੂੰ ਭੇਜਦਾ ਹੈ

  • ਦੋਵੇਂ ਸਕੈਨ ਸਰੋਤਾਂ ਨੂੰ ਇਕੋ ਲੌਗ ਵਿੱਚ ਜੋੜਦਾ ਹੈ

ਡੀ-ਆਥ ਹਮਲੇ #

ਉਦੇਸ਼: ਲੈਬ ਟੈਸਟਿੰਗ ਲਈ ਕਲਾਇੰਟਾਂ ਨੂੰ WiFi ਨੈੱਟਵਰਕ ਤੋਂ ਡਿਸਕਨੈਕਟ ਕਰਨਾ

ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ:

  • 802.11 deauthentication ਫਰੇਮ ਭੇਜਦਾ ਹੈ
  • AP ਦਾ MAC ਪਤਾ ਸਪੂਫ ਕਰਦਾ ਹੈ
  • ਕਲਾਇੰਟ ਨੂੰ AP ਵੱਲੋਂ ਡਿਸਕਨੈਕਸ਼ਨ ਸੁਨੇਹਾ ਮਿਲਦਾ ਹੈ
  • ਕਲਾਇੰਟ ਕਨੈਕਸ਼ਨ ਛੱਡ ਕੇ ਮੁੜ ਜੁੜਨ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਦਾ ਹੈ

ਕੰਟਰੋਲ ਤਰੀਕੇ:

  • ਇਕ ਵਾਰ ਦਾ deauth: ਫਰੇਮਾਂ ਦਾ ਇਕ ਛੋਟਾ ਸਮੂਹ
  • ਲਗਾਤਾਰ deauth: ਮੁੜ ਜੁੜਨ ਤੋਂ ਰੋਕਦਾ ਹੈ (DoS)
  • ਦੂਰੋਂ ਕੰਟਰੋਲ: DagShell ਸਕੈਨ ਪੰਨੇ ਤੋਂ ਚਾਲੂ ਹੁੰਦਾ ਹੈ

ਵਰਤੋਂ ਦੇ ਮਾਮਲੇ (ਅਧਿਕਾਰਤ):

  • ਆਪਣੇ ਨੈੱਟਵਰਕ ਤੋਂ ਗੈਰ-ਮਨਜ਼ੂਰ ਡਿਵਾਈਸ ਹਟਾਉਣਾ

ਹਾਰਡਵੇਅਰ ਸੈੱਟਅੱਪ #

ਕਦਮ 1: ਹਿੱਸੇ ਇਕੱਠੇ ਕਰੋ

  • Raspberry Pi 3B+ ਜਾਂ ਨਵਾਂ ($35-55)
  • U-Blox 7 chipset ਵਾਲਾ USB GPS ਡੌਂਗਲ ($15-30)
  • Pi OS ਲਈ ਘੱਟੋ-ਘੱਟ 16GB ਦਾ MicroSD ਕਾਰਡ ($10)
  • Pi ਲਈ ਪਾਵਰ ਸਪਲਾਈ ($10)

ਕਦਮ 2: Raspberry Pi OS ਇੰਸਟਾਲ ਕਰੋ

# Raspberry Pi Imager ਡਾਊਨਲੋਡ ਕਰੋ

# SD ਕਾਰਡ ਉੱਤੇ Raspberry Pi OS Lite ਲਿਖੋ
# Pi ਚਾਲੂ ਕਰਕੇ ਸੈੱਟਅੱਪ ਪੂਰਾ ਕਰੋ

  • ls /dev/ttyUSB* ਜਾਂ ls /dev/ttyACM* ਨਾਲ ਸੀਰੀਅਲ ਪੋਰਟ ਵੇਖੋ

ਕਦਮ 3: GPS daemon ਸੈੱਟ ਕਰੋ

# gpsd ਕੌਂਫਿਗ ਸੋਧੋ
sudo nano /etc/default/gpsd

# DEVICES ਲਾਈਨ ਵਿੱਚ GPS ਸੀਰੀਅਲ ਪੋਰਟ ਦਿਓ
DEVICES="/dev/ttyUSB0"  # ਲੋੜ ਅਨੁਸਾਰ ਬਦਲੋ

# gpsd ਮੁੜ ਚਾਲੂ ਕਰੋ
sudo systemctl restart gpsd

# GPS ਜਾਂਚੋ
cgps -s  # ਲਗਭਗ 30 ਸਕਿੰਟ ਬਾਅਦ ਸੈਟੇਲਾਈਟ ਡਾਟਾ ਦਿਖਣਾ ਚਾਹੀਦਾ ਹੈ

ਕਦਮ 4: Pi ਸਾਥੀ ਸੈੱਟ ਕਰੋ

# ਸੇਵ ਕਰਕੇ ਬਾਹਰ ਆਓ

ਕਦਮ 5: systemd ਸੇਵਾ ਇੰਸਟਾਲ ਕਰੋ

ਕਾਨੂੰਨੀ ਵਰਤੋਂ: ✅ ਆਪਣੇ ਨੈੱਟਵਰਕ: ਆਪਣੇ ਡਿਵਾਈਸਾਂ ਅਤੇ ਨੈੱਟਵਰਕਾਂ ਦੀ ਜਾਂਚ ਕਰੋ ✅ ਅਧਿਕਾਰਤ ਟੈਸਟਿੰਗ: ਲਿਖਤੀ ਇਜਾਜ਼ਤ ਨਾਲ ਪੈਨੀਟ੍ਰੇਸ਼ਨ ਟੈਸਟਿੰਗ ✅ ਸਿੱਖਿਆ: ਅਲੱਗ ਲੈਬ ਮਾਹੌਲ ਵਿੱਚ ਸਿੱਖਣਾ ✅ ਗੋਪਨੀਯਤਾ ਸੁਰੱਖਿਆ: ਆਪਣੇ ਡਿਵਾਈਸ ਉੱਤੇ TTL ਸੁਧਾਰ ਅਤੇ MAC ਸਪੂਫਿੰਗ ✅ ਸੁਰੱਖਿਆ ਖੋਜ: ਜ਼ਿੰਮੇਵਾਰ ਖੁਲਾਸੇ ਨਾਲ ਕਮਜ਼ੋਰੀਆਂ ਦੀ ਖੋਜ

ਗੈਰਕਾਨੂੰਨੀ ਵਰਤੋਂ: ❌ ਬਿਨਾਂ ਅਧਿਕਾਰ ਪਹੁੰਚ: ਆਪਣੇ ਨਾ ਹੋਣ ਵਾਲੇ ਨੈੱਟਵਰਕਾਂ ਉੱਤੇ ਹਮਲਾ (CFAA ਦੀ ਉਲੰਘਣਾ) ❌ ਹੋਰ ਨੈੱਟਵਰਕਾਂ ਉੱਤੇ deauth ਹਮਲੇ (FCC ਦੀ ਉਲੰਘਣਾ ਅਤੇ ਸੰਭਾਵਿਤ ਗੰਭੀਰ ਜੁਰਮ) ❌ ਜਨਤਕ ਲੋਕਾਂ ਵਿਰੁੱਧ Evil Twin ਹਮਲੇ (ਸੰਚਾਰ ਧੋਖਾਧੜੀ, ਪਛਾਣ ਚੋਰੀ) ❌ ਸਹਿਮਤੀ ਤੋਂ ਬਿਨਾਂ ਹੋਰਾਂ ਦਾ DNS ਸਨਿਫ਼ ਕਰਨਾ (ਸੰਚਾਰ ਵਿੱਚ ਗੈਰਕਾਨੂੰਨੀ ਦਖ਼ਲ) ❌ ਧੋਖਾਧੜੀ ਲਈ ਸੁਰੱਖਿਆ ਨੂੰ ਬਾਈਪਾਸ ਕਰਨਾ

ਧਿਆਨ ਵਿੱਚ ਰੱਖਣ ਵਾਲੇ ਕਾਨੂੰਨ #

  • Computer Fraud and Abuse Act (ਕੰਪਿਊਟਰ ਧੋਖਾਧੜੀ ਅਤੇ ਦੁਰਵਰਤੋਂ ਕਾਨੂੰਨ, CFAA): ਕੰਪਿਊਟਰਾਂ ਜਾਂ ਨੈੱਟਵਰਕਾਂ ਤੱਕ ਬਿਨਾਂ ਅਧਿਕਾਰ ਪਹੁੰਚ
  • Wiretap Act: ਇਲੈਕਟ੍ਰਾਨਿਕ ਸੰਚਾਰ ਨੂੰ ਰੋਕ ਕੇ ਪੜ੍ਹਨਾ
  • FCC ਨਿਯਮ: ਰੇਡੀਓ ਫ੍ਰੀਕਵੈਂਸੀ ਵਿੱਚ ਦਖ਼ਲ (deauth ਹਮਲੇ)

ਯੂਨਾਈਟਡ ਕਿੰਗਡਮ:

  • Computer Misuse Act 1990 (ਕੰਪਿਊਟਰ ਦੀ ਦੁਰਵਰਤੋਂ ਕਾਨੂੰਨ): CFAA ਵਰਗਾ ਕਾਨੂੰਨ
  • Regulation of Investigatory Powers Act (RIPA): ਸੰਚਾਰ ਰੋਕਣ ਉੱਤੇ ਪਾਬੰਦੀਆਂ

ਯੂਰਪੀ ਸੰਘ:

  • ਸਥਾਨਕ ਕਾਨੂੰਨ ਅਤੇ ਉਨ੍ਹਾਂ ਦੀ ਲਾਗੂਅਤ ਦੇਸ਼ ਅਨੁਸਾਰ ਵੱਖਰੇ ਹਨ
