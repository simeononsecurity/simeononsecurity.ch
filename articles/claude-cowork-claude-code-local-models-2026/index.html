Агентские инструменты Claude теперь работают с моделями на вашем оборудовании: без API-ключа, подписки и передачи данных за пределы компьютера. Ollama предоставляет совместимый с Anthropic API, к которому Claude Code и Claude Desktop подключаются несколькими командами.

Во многих руководствах упускают одну важную деталь. В них рассказывают о Claude Cowork, а затем дают инструкции, настраивающие интерфейс командной строки. Это две разные интеграции, и только одна из них предоставляет Cowork.

В этом руководстве описаны оба способа подключения, пропускаемая в популярных инструкциях переменная среды, подходящие модели по состоянию на сентябрь 2026 года и функции, которые останутся доступными только в облаке при любой конфигурации.

Результат для читателя: выберите нужную интеграцию, подключите ее документированным способом Ollama и проверьте конечную точку одним тестом вызова инструмента. Локальный вывод сохраняет запросы модели на вашем устройстве только при выборе локальной модели и отказе от функций, использующих облако.

Краткий ответ #

Ollama подключается к Claude двумя разными способами. Выбор неправильного способа чаще всего приводит к тому, что после завершения инструкции работает терминал, но нет Cowork.

Интеграция Возможности Способ настройки Платформа
Claude Desktop Cowork, субагенты, веб-поиск, автоматический режим Приложение Ollama, затем Apps и Connect Claude Только macOS
Claude Code Агент для программирования в CLI, вызов инструментов и изменение файлов ollama launch claude или переменные среды macOS, Linux, Windows

Если нужен Cowork, используйте интеграцию Claude Desktop. Это графический процесс в приложении Ollama. Пока поддержка Windows указана как ожидаемая, процесс доступен только на macOS.

Если нужен агент в терминале, используйте Claude Code. Для этого достаточно одной команды.

Оба варианта бесплатны. Расходы связаны только с оборудованием и электроэнергией.

Это две интеграции #

Путаница начинается с названий. Claude Cowork — это функция Claude Desktop, а не отдельное приложение и не другое название Claude Code.

В документации Ollama эти интеграции описаны на разных страницах и в отдельных разделах. Claude Desktop находится в категории Assistants рядом с OpenClaw и Hermes. Claude Code находится в категории Coding рядом с OpenCode, Cline и Codex CLI.

Это различие важно, потому что настройка полностью отличается:

  • Claude Desktop настраивается в интерфейсе приложения Ollama. Профиль оболочки не изменяется.
  • Claude Code настраивается переменными среды или одной командой запуска.

Руководство, в котором предлагается экспортировать ANTHROPIC_BASE_URL и запустить claude, настраивает инструмент командной строки. Если вы ожидали получить настольный интерфейс Cowork, с настройкой всё в порядке. Вы настроили другой продукт.

Настройка Claude Desktop и Cowork #

Этот способ использует приложение Ollama, а не терминал.

Требования #

  • Установленная Ollama на macOS. Поддержка Windows указана как ожидаемая.
  • Сначала скачанная модель, если планируете локальный вывод. Для облачной модели войдите в Ollama и включите облачные модели. Для некоторых облачных моделей нужен платный тариф.
  • Установленный Claude. Если его нет, Ollama предложит скачать его во время настройки.

Шаги #

  1. Откройте Ollama и выберите Apps.
  2. Выберите Connect Claude.
  3. Следуйте подсказкам. Установите Claude, если появится запрос, и перезапустите его по предложению приложения.

Это весь процесс. Чтобы позднее сменить модели, откройте Ollama Settings, перейдите в Apps, выберите модели и нажмите Restart Claude.

Доступные функции #

В документации Ollama указана поддержка четырех функций в этой интеграции:

  • Cowork для выполнения сложных задач
  • Субагенты для разделения крупных задач между агентами
  • Веб-поиск, который Ollama предоставляет по умолчанию
  • Автоматический режим, в котором агент сам решает, когда спросить разрешение перед изменениями

Cowork есть в этом списке. Эта интеграция поддерживает Cowork, а интеграция командной строки — нет.

Отключение #

При отключении восстанавливается прежняя конфигурация Claude, поэтому изменение не является разрушительным.

  • В интерфейсе откройте Apps, отключите Claude и перезапустите его, когда появится запрос.
  • В терминале выполните ollama launch claude-desktop --restore.
  • Если закрыть Ollama, пока Claude подключен, обычная конфигурация Claude также восстановится. Чтобы сохранить локальную настройку, оставьте Ollama запущенной.

Настройка Claude Code в CLI #

Такой путь описан почти во всех руководствах. Для работы в терминале он подходит.

Настройка одной командой # 

ollama launch claude

Команда задает необходимые переменные среды, направляет Claude Code на локальный экземпляр Ollama и запускает его. Выберите модель из списка и нажмите Enter. Чтобы задать модель сразу, укажите флаг:

ollama launch claude --model qwen3.5

Оболочка сама задает переменные среды. Всё равно прочитайте следующий раздел: понимание этих параметров поможет при диагностике.

Переменные среды вручную # 

export ANTHROPIC_AUTH_TOKEN=ollama
export ANTHROPIC_API_KEY=""
export ANTHROPIC_BASE_URL=http://localhost:11434

claude --model qwen3.5

Во многих популярных руководствах пропущена вторая строка. Пустое значение ANTHROPIC_API_KEY не дает ранее экспортированному действующему ключу вмешаться в локальное подключение. Если опубликовать руководство с переменными, но не включить эту строку, читатели с уже заданным ключом столкнутся с непонятной ошибкой.

Чтобы не менять профиль оболочки, передайте все параметры в одной строке:

ANTHROPIC_AUTH_TOKEN=ollama ANTHROPIC_BASE_URL=http://localhost:11434 ANTHROPIC_API_KEY="" claude --model kimi-k2.7-code:cloud

В официальной документации отмечены два важных момента:

  • ANTHROPIC_AUTH_TOKEN содержит bearer-токен, поэтому в локальном режиме его значение — строка ollama.
  • Файлы настроек Claude имеют приоритет над переменными оболочки. Если после экспорта новых значений подключение работает странно, проверьте файлы настроек и запустите /status в Claude Code, чтобы увидеть используемую конечную точку.

Прямое подключение к Ollama Cloud #

Для этого способа устанавливать Ollama не нужно. Укажите API-ключ и направьте Claude Code на размещенную в облаке конечную точку Ollama:

ANTHROPIC_BASE_URL=https://ollama.com \
ANTHROPIC_AUTH_TOKEN="$OLLAMA_API_KEY" \
ANTHROPIC_API_KEY="" \
claude --model glm-5.3-flash

Здесь есть одно ограничение. По документации Ollama, размещенный веб-поиск и расширенные настройки инструментов поддерживаются не полностью. Базовый чат, изменение файлов и вызов инструментов работают с совместимыми моделями.

Выбор модели на сентябрь 2026 года #

В течение 2026 года линейка моделей значительно изменилась, поэтому рекомендации весны стоит перепроверить. Текущее состояние такое:

Модель Тип Контекст Причина выбора
Qwen3.8 27B Локальная, 18 ГБ 256K Лучшая универсальная локальная модель с поддержкой изображений, вызовом инструментов и управлением рассуждением
Qwen3 Coder Next Локальная, MoE: 80B всего / 3B активных 256K Создана для постоянно работающих агентов программирования; режим без рассуждений повышает скорость
Qwen3.6 35B A3B Локальная, MoE: 35B / 3B активных 262K Apache 2.0 и эффективная работа при ограниченной памяти
kimi-k2.7-code:cloud Облачная Большое Облачная модель для программирования, не требующая локального оборудования
glm-5.3-flash Облачная Большое Модель, которую первой рекомендует документация самой Ollama

При достаточном объеме памяти начните с Qwen3.8 27B. Модель работает локально с контекстным окном 256K, встроенной поддержкой изображений, вызовом инструментов и управлением режимом рассуждений для каждого запроса. На видеокарте с 24 ГБ памяти или более она подходит для повседневных задач.

Если ресурсов недостаточно, начните с облачной модели. Подключить Claude Code к размещенной модели можно бесплатно. Это снимает вопрос об оборудовании, но код покидает компьютер.

Предупреждение о троичных моделях #

Если вы читали наше руководство по локальному ИИ на 2026 год , то знаете, что троичная Bonsai 2 27B запускает полную модель 27B в 5,53 ГиБ. Возникает соблазн использовать ее здесь.

В этом процессе она не работает. Троичные ядра находятся в форке llama.cpp от Prism ML, а стандартная Ollama не загружает эти файлы. Команда вроде ollama launch claude --model Ternary-Bonsai-2-27B завершится ошибкой до начала вывода. Для Claude Code используйте стандартный пакет Qwen3.8 27B, а троичные пакеты оставьте для среды выполнения, которая их поддерживает.

Удобство и максимальная эффективность здесь расходятся. Интегрированные инструменты требуют стандартный GGUF.

Установите контекст 64K, прежде чем обвинять модель #

В документации Ollama для работы с репозиториями есть прямое указание: выберите модель и задайте контекстное окно не меньше 64K, а для крупных репозиториев увеличьте его.

Причина техническая. Claude Code помещает содержимое файлов, различия и вывод команд в контекстное окно. Если оставить небольшое значение по умолчанию, модель исчерпает контекст в середине задачи. Ошибка будет похожа на проблему с рассуждением, хотя причина заключается в настройках.

Контекст Подходящие задачи
Менее 32K Изменение одного файла и короткие вопросы
64K Работа с несколькими файлами в небольшом репозитории
128K Крупные репозитории и длинный вывод команд
256K Полное окно Qwen3.8 27B

Если Claude Code теряет нить задачи на середине, проверьте настройку контекста, прежде чем менять модель.

Проверьте вызов инструментов одной командой #

Вызов инструментов отличает агента от генератора текста. Это стоит проверить, а не предполагать.

Когда Claude Code запущен, попросите его:

Прочитайте текущий каталог и перечислите все файлы

Если он перечислит реальные файлы, вызов инструментов работает. Если он ответит, что прочитал бы каталог, и опишет, что ожидает найти, вызов инструментов не подключен. Вы общаетесь с чат-моделью, которой добавили подсказку для программирования. Никакие дополнительные формулировки не исправят подключение.

Проверяйте возможные причины в таком порядке:

  1. Переключитесь на модель с подтвержденной поддержкой вызова инструментов. Эту функцию поддерживают не все модели, и число параметров не показывает разницу.
  2. Убедитесь, что среда указывает на Ollama. Выполните ollama --version и проверьте, что ANTHROPIC_BASE_URL указывает на локальную конечную точку.
  3. Запустите /status в Claude Code. Базовый URL или учетные данные в собственных настройках Claude имеют приоритет над недавно экспортированными переменными оболочки.

Что остается только в облаке #

Перед перестройкой процесса на локальный вывод выясните, где проходят его границы.

Функция С локальными моделями Облако
Чат и изменение файлов Да Да
Вызов инструментов Зависит от модели Да
Субагенты Да Да
Веб-поиск Предоставляет Ollama Да
Cowork Через интеграцию Claude Desktop Да
Автоматический режим Через интеграцию Claude Desktop Да
Запланированные запросы Через /loop в Claude Code Да

У локального варианта есть три ограничения:

  • Многофайловое рассуждение ухудшается раньше, чем снижается скорость. Локальная модель хорошо справляется с одним файлом, приемлемо — с тремя, но с целым репозиторием работает плохо. Соразмеряйте задачу с возможностями модели.
  • Для некоторых облачных моделей нужен платный тариф Ollama. Также необходимо войти в учетную запись и включить облачные модели.
  • При прямом подключении к облаку доступны не все функции. Размещенный веб-поиск и расширенные настройки инструментов не поддерживаются полностью, если не устанавливать Ollama локально.

Локальный вывод подходит для ограниченных и проверяемых задач и хуже справляется с масштабными неоднозначными задачами. Учитывайте это при планировании.

Автоматизация #

Две функции превращают этот инструмент из интерактивного помощника в основу автоматизации.

Запуск без интерфейса для скриптов и CI #

Флаг --yes пропускает интерактивный выбор и при необходимости скачивает модель. Для него нужен флаг --model, а все аргументы после -- передаются Claude Code:

ollama launch claude --model gemma4:cloud --yes -- -p "how does this repository work?"

Учитывайте модель разрешений. Claude Code запрашивает разрешение перед большинством действий. Поэтому для запуска без интерфейса нужны настроенные правила разрешений или изолированная среда. Не направляйте агента без присмотра на важный для вас репозиторий.

Запланированные запросы с помощью /loop #

В сеансе Claude Code команда /loop запускает запрос или slash-команду с заданным интервалом:

/loop 30m Проверьте мои открытые PR и кратко изложите их статус
/loop 1h Найдите последние новости об ИИ и кратко изложите важные события
/loop 15m Проверьте новые задачи GitHub и расставьте приоритеты

Команда работает, пока открыт сеанс. Это не фоновая служба, поэтому она завершится вместе с сеансом.

Устранение неполадок #

Симптом Вероятная причина Решение
Соединение отклонено Ollama не запущена Выполните ollama serve, затем проверьте curl http://localhost:11434/api/tags
Модель описывает действия вместо их выполнения Выбранная модель не поддерживает вызов инструментов Переключитесь на модель с подтвержденной поддержкой инструментов
Используется настоящий API-ключ вместо локальной конечной точки Переменная ANTHROPIC_API_KEY всё еще экспортирована Задайте ей пустую строку, как показано выше
После настройки нет Cowork Настроен Claude Code CLI вместо Claude Desktop Для Cowork используйте процесс Apps в Ollama
Вывод медленный Слишком большой контекст или плотная модель вместо разреженной Уменьшите контекст, затем попробуйте модель со смесью экспертов
Экспортированные переменные не действуют Файлы настроек Claude имеют приоритет над переменными оболочки Проверьте файлы настроек и запустите /status
Фоновые запросы завершаются ошибкой Claude Code использует небольшую модель для внутренних задач Направьте переопределение малой модели на ту же локальную модель

Две из этих семи проблем сводятся к одному. Большинство сбоев настройки связано с неправильной конечной точкой или моделью без вызова инструментов.

Основные выводы #

  • Claude Desktop и Claude Code — отдельные интеграции. Cowork доступен в Claude Desktop и настраивается через панель Apps в Ollama на macOS. Через CLI получить Cowork нельзя.
  • Для запуска CLI достаточно команды ollama launch claude. Вручную нужно задать три переменные, и ANTHROPIC_API_KEY="" чаще всего пропускают в руководствах.
  • Локальная установка Ollama необязательна. Направьте Claude Code на https://ollama.com и укажите API-ключ.
  • Перед оценкой модели установите контекст не меньше 64K. Малое окно выглядит как ошибка рассуждения.
  • Проверьте вызов инструментов одним запросом. Если модель лишь описывает предполагаемое действие, это генератор текста, а не агент.
  • Троичные пакеты Bonsai здесь не работают. Они требуют форк llama.cpp от Prism ML, а стандартная Ollama не может их загрузить.
  • Отключение безопасно. При закрытии Ollama конфигурация Claude восстанавливается. Из терминала это можно сделать командой ollama launch claude-desktop --restore.

Следующие шаги #

  1. Установите Ollama и скачайте модель с подтвержденной поддержкой вызова инструментов: библиотека моделей Ollama
  2. Ознакомьтесь со страницей Claude Code от Ollama для актуальных флагов и списка моделей: интеграция Claude Code
  3. Если нужен Cowork, используйте страницу Claude Desktop: интеграция Claude Desktop
